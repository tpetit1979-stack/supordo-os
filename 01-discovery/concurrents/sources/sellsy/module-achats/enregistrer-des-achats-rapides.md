# Enregistrer des achats rapides

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261906193/ac269e52b16785ae314c1782b112/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=c4084f15ab1c6c3d94af68e183a6461040b235d3b26331a9e7e0a61cf68b4166&req=dSIhF8B%2Bm4BWWvMW1HO4zaE7pW04edHv6lCL%2FQQAjHyadmI9N62MhUsfHGjS%0AsAB3MeowP5b2ZSn3pOU%3D%0A)

L'entrée rapide de vos achats est une fonctionnalité qui vous permet de saisir rapidement ces derniers à la main, ne faisant pas partie de votre processus de vente habituel.

Cela peut être :

- votre loyer,
- abonnements téléphoniques,
- vos achats informatiques.

En résumé, tout paiement **qui ne nécessite pas un suivi commercial** (stock, catalogue...).

Ces entrées sont enregistrées directement dans vos ventes de journaux si vous choisissez cette option.

Pour saisir des achats rapides, cliquez sur le menu d'achat puis sur “Saisie rapide facture fournisseur”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446282243/7eef961d569cc91aa7adefbd/vjUrnJKnV984iL40hLUrNutWV0t0mD4c0J-nCtHEVeRpRl81ju7qssvuP2mYylYN6prPhYaOXgQNZi7CiuZTKFeTqv5pRfyKhzpKUnt-Dcpi6LX-21S_xM1uidHz8TcweOdkmvH1?expires=1788635700&signature=1d290f31f4686219280e018c24d68ef8ca5e0b1b9ee567ec88d19c011c115ba5&req=cCQhFMF8n4VcFb4f3HP0gDtvUj9JGXfw3o8XJp64b%2BjatgqIgWPJRawWFMfR%0A1eikCQstaBDzUVBpsw%3D%3D%0A)

Sur la page qui apparaît, vous pouvez entrer les détails de votre achat.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446282249/a4654f54bdc01ec0ec9b6e5c/G5-SRh4GxBeIdBCJt_ksmrKZ8TymCMwo2PTUgrkilMgTiFPB0_lZ7M6i7ZQy3iBtjsGBJIrF2b34ySsVkqSug-lvi66p26tc5V63JotRdvhmE_JXtqgsJV71W14iWpS1YaIH3lHj?expires=1788635700&signature=70bc9f42d6fef5ec4e5cd982d02d32b1a2176c3bfdc36109aa9a5ecfaeeb1893&req=cCQhFMF8n4VWFb4f3HP0gA32R%2Fkduw3HHX1HoofYcuXaNnzpLtgm%2BPlIOfCv%0A7poSmonWnFQhBC8xcw%3D%3D%0A)

Si vous avez besoin d'ajouter d'autres achats, vous pouvez le faire très simplement en cliquant sur “Ajouter une nouvelle facture” en bas de votre page.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446282253/bffd295c5d2e9b9f488ef30b/REQQFY70MDCAkc8KIp51AVf_JdBWGF33jxAJtLrZEI5QvugTAbtUMbORP-hb8o_1T9nU5wi4Qc4T3bBAajHFqOGmKgC-ImfSPT6WEAUiqI5w3fJ7ivBIZZPk1ZG3bdZOq3ai3KwQ?expires=1788635700&signature=4ce25461a54fd41bed6dab78b8867bcb0e91e20ab94a7e61f11fbaad0262cb05&req=cCQhFMF8n4RcFb4f3HP0gPnI%2BOrweuY9zOWLXjbM%2FMDKzKqpAqjMCTbuJ5bl%0AB0UpETmhnaHob5Zziw%3D%3D%0A)

Lorsque vous avez terminé votre saisie, confirmez en cliquant simplement sur le bouton “Enregistrer” en bas de la page.

Vous retrouverez l’ensemble de vos factures fournisseurs dans le menu “Achat”, “Liste des factures fournisseurs”.
