# Prendre en compte les coûts internes dans le calcul de marge

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261907101/b38dea18cb86732bac9e5f4dce04/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=7e5478680cd11f99fde07407a0eb88334f7ca40f4d6074aa452b090aceaffcd5&req=dSIhF8B%2BmoBfWPMW1HO4zTtw8iJ0CAW7JFxvOpNG3BltMs%2FzHfh1yN0nsoqt%0APB2ryQU%2F7zZCqORkL%2B0%3D%0A)

Pour le calcul de vos marges, votre activité peut comporter des coûts internes qui ne font pas l'objet d'une facturation fournisseur.

Il peut s'agir, par exemple, d'un coût de production ou d'une commission à reverser.

Pour ajouter un coût interne sur un devis ou une facture et calculer ainsi la marge, rendez-vous dans l’onglet “Rentabilité” de votre document. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446281398/4d26eda1638828181365748c/I1L8ElJwKtR_o1htykZbgae5Uv8iOW_KXdazX_tAevz4OB6_PHfZJrmvlEkynx_dubE7nwAFS7anz_VeE3Y0WfFFOomeMkeZ4iWKusGaxyJQQDeZkc-aePw7pUyE-5NWJnHGlhrp?expires=1788635700&signature=87a1fe304e3ec900f16e360b6ec93e15784fb787ba854794332e2adf2bbfba9d&req=cCQhFMF%2FnohXFb4f3HP0gEPvnb3k5%2FL3179xl61qUte7%2BGsGz8Fjle%2FcsSPr%0ACNbJ56zdl3cdCY24zA%3D%3D%0A)

Cliquez ensuite sur “Ajouter une entrée” dans la section “Produits ponctuels et coûts internes”. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446281410/bf91d7bc43a4479a524bdd49/KvV9sLMII-l6FeXkuxkv0K7DlDX5-pjTn5zdBz2dPkaNnkd2flZek2ROZf_VT8ZL3dYceclRblK57JUFUtiaDAcvoNTz3HPy0dfgI3d5QJICBHLf6iHMIIVc77xkfGKYY5hF0UqA?expires=1788635700&signature=5dd859c423991d1eaa1c445711bcf24e8833d2bde69dd0a7d38e49ccebb0d846&req=cCQhFMF%2FmYBfFb4f3HP0gJF4HlhUDGP9JgSxe%2F%2BJ2y%2Bzjl%2BBdIEEp4KasgP7%0AzzqXSgCCiI9vQLdSbg%3D%3D%0A)

Ajoutez ensuite un libellé, puis un produit unitaire HT ainsi que les quantités.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446281421/94aac9a1d175a2f8a6d46f58/SJ3qIuFXkUUmT3abJp0w2D7Fcx6Ml40YgBGce03ao8BzWlTo3bMLDzvn8XaSxdlgzRAwoK7RXLHVHUyXqLipz30SvIJp0i3I9OpAqSHOh6YB4M2Fu-K7ImONxBBSU0B6hM44W6O5?expires=1788635700&signature=f3a527bab84b087d00a0b06500ad4eef3329ee28e3ca8c86fcae633dd80ba0e9&req=cCQhFMF%2FmYNeFb4f3HP0gGqPFyzBuqlA2mgap0KOkKP%2BeuKdkHJyDjmfVC31%0AB0lrCl3C0rZ%2Bqv7pDg%3D%3D%0A)

Une fois enregistré, la ligne apparaît alors dans le récapitulatif de marges.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446281428/98939455d963c702a4a33f3f/z5XUZvznwIkKs1hHNKXcQ6NE_hy_uo07fZhDygG-URUWMu1mdKTWLfMxc04Tio7p6gQxkTiBAQlvgLpr7Rak9udtInD_4BWQeNVf_wtQRrzK3MUcScYsLSahdkTENNN6gX5GO-48?expires=1788635700&signature=3e896f8e190c4db28783608b1b45ee439de59d4462b8aaae2dcf06619e333a19&req=cCQhFMF%2FmYNXFb4f3HP0gIvWcM8%2FInRVTo0E%2BEUoPxcXKpwV9xAova6g%2FDuW%0Ate7u6V90BuM7ijdyHA%3D%3D%0A)

Vous retrouvez ensuite la charge dans le calcul de votre marge.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446281431/2e409efac4787212aacafc1e/fYyZPbd5-ikd6Zno2fHzIk14Tm496u_OZM0ADsfOdIAsKTc4ohWV0z-grE8uZr7ngaq4ca6VKAHDS3YJ6y6pLR6jQ7xDI1iwGi7_hoxGJXzMJPGoHJmri_pnHhv0FPmGkAu_aTgg?expires=1788635700&signature=3331dc869df79ac2d151648bc57c125c5b1fc5ac9cb74c76c4ef6a7c92832dd7&req=cCQhFMF%2FmYJeFb4f3HP0gKJtuJsAPN80%2F4GX9bgoLScANB97%2F2P8tnrsPAHK%0AxhVQiGrM0vBKuRA5Kw%3D%3D%0A)
