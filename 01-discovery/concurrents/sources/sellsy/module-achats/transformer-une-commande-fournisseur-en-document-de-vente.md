# Transformer une commande fournisseur en document de vente

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261905440/11a73b75f9428bc152fbbf052849/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=ead38d41d1136a43befc10cb2925917da0d3d649ee12ab9914bb7370f2264375&req=dSIhF8B%2BmIVbWfMW1HO4zcqRV1AgW3KO4oov1dKTS7G47bVgbj38aZuQba8X%0AD7Brf3fcKWRlA6bMGD4%3D%0A)

Sellsy vous permet de transformer facilement une commande fournisseur en vente (ou autre document de vente).

Pour ce faire, depuis l'aperçu de la commande, cliquez sur “Créer un doc de vente”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446283393/a03c11ec51db5532259bc564/UueVcrF_ndS5T4JGxXrO66KVeitmXHqdQ0vkU3rPSElBtOmVW1I8BeTDoJcG1B-msDnz8mTkS0odreCpMkaqNitxYtzNcIsIrZac87UYJdu0deAZ25Dx1D0D3HvcboRBk3uIytgx?expires=1788635700&signature=e0dbb8a2aee8f5a1b60ec6c04a148baa4f44edc2e36464e3c5f6c24d7ce30f00&req=cCQhFMF9nohcFb4f3HP0gFrSfa3bOO04BCr6AckBKbuPzIoaY4Hu8Lt%2BbiXT%0AIjtwKsUl3IH2puJvyw%3D%3D%0A)

Dans la fenêtre qui apparaît, choisissez le client concerné ou créez-le.

Choisissez ensuite le type de document souhaité, puis cliquez sur Créer un document.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446283397/4a5de2a331bd0048a56df5d6/E99ZvxAQChY7cXhcE0PUKyOzwOs1F0Kvogi4YAXs3WQZ0Ty5utUy3nOkxglAm0zjcA3mzVlrveFLKibHzcXxn7FpttjkdDyTNO88gpSdCFD_f4J_BmIT8e7Ndm4NRK3WJWC99jhj?expires=1788635700&signature=e36db61a76165d36377d218e47eb06255eeca01dfb4c049c660040f9f8f027c1&req=cCQhFMF9nohYFb4f3HP0gDU6XBfB0E2bcO5mHsymrKQX9%2BON5FIks5OvqMlv%0AXloEwp4fneXTH00fuA%3D%3D%0A)

Enfin, vous devez simplement enregistrer votre document.
