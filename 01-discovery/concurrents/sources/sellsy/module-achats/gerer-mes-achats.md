# Gérer mes achats

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261905836/859b4a02d7ca8c9ae4a96d5c30bf/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=cb783b275c56ab4f3c074268319e81696d4d308156940b873523093500543cb2&req=dSIhF8B%2BmIlcX%2FMW1HO4zdAQmF0E4u7kcFqiXrJN%2F2GEwlVybNNiqLJSXjsC%0AeIW8m6ViW3IitboKnFo%3D%0A)

Sellsy étant un système souple, nous ne vous bloquons pas dans le respect des étapes de gestion des achats. Cependant, dans le cadre d'une activité de négoce, le respect des étapes vous permettra un **contrôle optimal **de vos approvisionnements.

Au contraire, dans une activité de service ou pour des achats non revendus, une saisie basique est suffisante.

La gestion des achats s'effectue selon un cycle défini et trois étapes :

- La création d’un bon de commande fournisseur,
- La génération d’un bon de livraison,
- L’enregistrement de la facture fournisseur.

> **Bon à savoir** : Consultez **[cette vidéo de formation](https://www.sellsy.com/sellsy-academy?ms_url=%2Fcourses%2F95dbb82b-1ab0-4056-99bc-2d705545e9fb%2Fstep%2F4403eb94-361f-4097-9b56-5eb6f9560888)** pour découvrir toutes les fonctionnalités.

___________________________________________________________

### **Étape 1 : créer un bon de commande fournisseur**

La commande fournisseur donne lieu à l'établissement d'un bon de commande fournisseur. Pour créer un bon de commande, rendez-vous dans le menu “Achat”, “Créer un bon de commande”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446282957/3124f7820cc3f5e4d7d66609/So0JkHL3rY0fPsKzxTgMrDAWnEEEf9UhViP37MmZxzlR4J5RVoK_k21RmG62tDKCx4w-mtzaIovXGbaokRbjETXz4iE4PgMd-IE_gTyezu6KtRZ5gMx9IxlWhaU7GkbFTOxPZvQp?expires=1788635700&signature=96e33b14fdd2800e312ece04a75e09d55df83f89dd27935a2cafa5d071c2d40b&req=cCQhFMF8lIRYFb4f3HP0gNapN%2F%2FTreDCfj%2FzZm%2FkCzPmpy3rLjSfmgXpgxet%0AQFrd1UzI2Ru18cP1dA%3D%3D%0A)

Vous serez ensuite redirigé vers un éditeur de document classique comparable aux éditeurs de documents de vente. 

Vous pourrez retrouver votre bon de commande dans votre menu “Achat”, “Liste des bons de commande”.

Plusieurs actions sont possibles depuis la vue détail de votre bon de commande : 

- Envoyer le bon de commande à votre fournisseur,
- transformer le bon de commande en un ou plusieurs bons de livraison,
- facturer directement le bon de commande.

___________________________________________________________

### **Étape 2 : générer un bon de livraison**

Suite à une commande fournisseur, vous pourrez générer des bons de livraison. Ces derniers vous permettent de constater l'arrivée en stock des marchandises.

Il est possible de convertir directement votre bon de commande fournisseur depuis la fiche détail du bon de commande. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446282964/6667b12e9d8d5d985fd49084/KbGXv-mBrilDBa5mN7zQyCGtP15QnguxKtVFkfXVOGdDMb9LODmWs01dEE6kNMy1zJhy9IFuyvDrUouJ500YdpnGaIXhR_x2nKSls07HbmxZmR1ANDwO4tqaXouvkTnR-nKf2hyz?expires=1788635700&signature=07a8053c67a26df49f2f880e5f490792d7d6bad85320aa2a982cddccf164f7ec&req=cCQhFMF8lIdbFb4f3HP0gGn06ihNx%2BBPgb0aXOF%2Bo03cn3mVTd6pJ32YWr9D%0AXBNrs3o3Ryp7L0oKJQ%3D%3D%0A)

La fenêtre de validation de la livraison s'affiche, vous n'avez qu'à valider les quantités reçues à droite du tableau.

Si votre livraison est complète, le bon de commande initial affiche “Livré”. Dans le cas contraire, “Livraison partielle” est affiché.

L’historique de votre document est alors consultable depuis l’onglet “Historique du document”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446282972/2445d36a1d3ae623ebbe85ad/D7KxcD2kNto739WdyXZsqWVAHPFpjD7kQO5fwBlEWyOmgKFnI6bVA-z9afsjos2ep2O7MJITm17sWRoGJCO_OGvT8hlChr5MR8t5tRaFWX2faUeIV_1ZzhjoS6lhDh1nJ7d5au3X?expires=1788635700&signature=07d2270bddd22954aaa2c91e0213455eb519e67a31ff44e683df968008d2937e&req=cCQhFMF8lIZdFb4f3HP0gG8WJNn1%2BeeXsqfVyPMWmG0DHGi0phWybpq0ekC8%0AJuod1FK1rerUVBE%2BUw%3D%3D%0A)

Sinon, il est également possible d’en créer un depuis le menu “Achat” puis sur “Créer un bon de livraison”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446282978/b6ddf341bea7e9274dd9c5bc/SPDB-71p-oXFtx_xuZNyBV1he7zI2RoGeXJ87zEzt3SSGkOUoEu3akih9e9HWCBy3OI43Si7mN-WQFykhWOyeLAmaea7Z9QX5uueWI1mJQyUyEDzX8KHWPSDm_gAoR0YdvnNNVY-?expires=1788635700&signature=6a7492d5d9a473c88780ebf9ebf9818f56a6d5de7b3f4512d191189e9b8ff41f&req=cCQhFMF8lIZXFb4f3HP0gAUuUzj0TrOfBxhPXCdhwHuw%2FRSQdGPN%2FNhdYWki%0ACl%2BkoSsI7V4XSTd%2BmQ%3D%3D%0A)

### **Étape 3 : enregistrer la facture fournisseur **

La dernière étape est l’enregistrement de la facture fournisseur. C'est l'étape finale de votre cycle d'approvisionnement, celle qui va permettre de générer les lignes comptables de votre achat. Depuis votre bon de livraison, cliquez sur l’action de conversion “Créer une facture fournisseur”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446282984/f0e24e2f44a197eaf10b5eca/Wj0d0nnyh5CkuUh187SOp7duJ3UWtSTQfFXiZkr0AjVAUpS0tQ7WFO4FwLjZVSkkd5RI31ZCvNSUs4pwOJJ-u6yGsp6XaDnvG-yXcKlZpoY5FhUt6yoe9GkAm4XaSbKUBcYNyr8o?expires=1788635700&signature=cc732b0940a6dbaf7b79bde7a2137e95b3105c2ccb86923afd04520dfa9b3ac3&req=cCQhFMF8lIlbFb4f3HP0gHDNg47y6r12EHW5IsthYoRJq86a%2F0WyiBERk7X2%0Apq7%2BZRSS78mw0HWKvw%3D%3D%0A)

Une fois votre document enregistré, vous pourrez retrouver l’historique du document depuis l’onglet “Historique du document”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446282992/527f492e91b9b81208df06c6/hovMj-EWpUAnYRArxSGoDA5F8tNoVH0QwHx9osBz2wcWyElrnVckqVwdrkpg6nmrdAtY_knePluFLCLYY2qKvifSqwsszPx5UxSs_m3dnM19MNRjGK80NH4KwRZl58ekl16bu1LQ?expires=1788635700&signature=2d74fa0273211868ce81e9fc81831dc1a66abb559ddf2254d4ceff1542fc1bf3&req=cCQhFMF8lIhdFb4f3HP0gF1L1sVuiJwL0Xv0uqVEqPWgInnY5xStqTRmi7iU%0Ao5%2FX0DpFkqOvOxo7Mw%3D%3D%0A)

Il est également possible de créer la facture fournisseur depuis le menu “Achat”, “Créer une facture fournisseur”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446282997/741203554690970ab6da657e/-y5GsNtlRDZ0m80vO5DuXgOC2vyw6RwUJlLOw-fK_hLlv48HU0QS8HjKguL4EFZixtE_U6eoY0su6_jxLl0hLu0r3H2Glv6oO_LL61egdpPY-5bpiB8hhDqMmAlwsXdjBK6eSGGL?expires=1788635700&signature=f0778d1bfc43b2e377f73ff4f19bade6ba19e68604124f43f9dd917f15a108b0&req=cCQhFMF8lIhYFb4f3HP0gIRg5bruISeMThFIVcgAuLCh1Kq4Vo4DyhJplXyV%0AfVLJjXuXc%2F8S1oIhFw%3D%3D%0A)
