# Afficher les champs personnalisés dans une liste

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1879053069/c45a3409eafaf641274f2f92d223/FAQ-Bannie-CC-80reAcademy-2-2B-282-29-2B-281-29.png?expires=1788635700&signature=80dfc6c44247555e7e05a291f48d56cc07a278fa08ed35646d20ec21d06353c0&req=dSggH8l7noFZUPMW1HO4zZIXcxvvxtYOl6S57IVlFj%2Fl%2BpD1WA9niCP7Rdx8%0AJ%2BkNfp3RiGS5EtgK1Mk%3D%0A)


Sellsy vous permet de gérer l'affichage de vos listes pour y inclure les champs que vous désirez, y compris les champs personnalisés.

Cliquez sur la roue crantée au-dessus à droite de votre liste, puis sur “*Gestion des colonnes*”.
​

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446351442/690b60804d40eb86d8bd5c56/Xcsq6umdqo5zuC83nqcuRzsojs3K8FLrB5i6fB-96unqWEaBbHzjGQCgcI1DByvs545lFBbso9f9CAAMbXiozeClgDuc4Z_hXegqzU_j4LxU5OTZb2WJt5X1aZDBTXNQHJcL51vs?expires=1788635700&signature=adeacf7b303ea8e558d21666aedb085031ebd0ec96dd2598cf5654536ae4623f&req=cCQhFcx%2FmYVdFb4f3HP0gH3N4unAW769hJdyd%2BT4ZKra1sHJX6uRbiOSPpTV%0ABdAaLYDahlIO%2FnF2Og%3D%3D%0A)

Recherchez le champ personnalisé que vous avez créé grâce à la barre de recherche puis sélectionnez-le. Ensuite, cliquez sur “*Appliquer*”.  
​

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446351451/0d2d31fc8f0b22cd9fdc1e6f/3DtpI2H0QBpnnIXTfd46FAS2G8vg6D3Xf4TLPQ4AUCQI2Txgvjoi0G1YCkl74sR15goG9v3B7RXfGlu-7I1227YlhMSeUfpdUy6DF61HiOQmGjXFcEmhbTy-FgMCAxTI35DNG1vJ?expires=1788635700&signature=c1fd030a2f1e49e2ba2b07b638e6c9dae37abb3b56f22e219a66e25a72491cfb&req=cCQhFcx%2FmYReFb4f3HP0gNBuA4clqHdBnJSr6AZZY73ftWUWe%2BYFobXC8E09%0AfsrkHUmlbiiQpCPWUQ%3D%3D%0A)

Votre champ personnalisé sera alors visible depuis votre liste.
