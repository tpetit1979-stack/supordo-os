### **Activer le module Dropbox**

La synchronisation avec le service de stockage Dropbox vous permet de copier vos documents Sellsy vers votre compte Dropbox.

Pour bénéficier de cette fonctionnalité, vous devez tout d'abord activer le module Dropbox (gratuit) depuis la page de gestion des modules complémentaires en cliquant sur “*Menu*”, “*Réglages*”, “*Module Sellsy*”, “*Ajouter des modules*”.

Recherchez le module Dropbox puis cliquez sur “*Activer*”.

### **Activer la synchronisation automatique**

Une fois le module activé, cliquez sur Dropbox dans la liste de vos modules externes. Vous serez alors invité à vous authentifier sur Dropbox.

Si vous cochez “*Activer la synchronisation automatique*”, tout document créé ou modifié sera automatiquement synchronisé sur votre compte Dropbox dans un dossier Sellsy Synchronisation dans les Applications.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446359920/efd27f72d96836c7b43f814e/zk7MqlIP75vzcLJx1R3bUKdUKoAMv6DUdcUQcdR8BhLtHJP1rnVXGJLa0IS27T-GqKG4uXdSLxB-3GQEo9c8Gbt70WJy9dUxVwq3c4WZPBHk1_Qz2wfuX5wMmA8DSZZO8dxsRbMD?expires=1788635700&signature=7c173956d627d8bbdca79f2d8e02f3ba43069a0d3252fcb14561c293bc3ac0a5&req=cCQhFcx3lINfFb4f3HP0gNaTb1GpGhFJf%2FSMNn9udfaz8ablu45EXjjKQ8dq%0AntxQJSZl01hezxz0rQ%3D%3D%0A)

Vous pouvez également synchroniser vos documents manuellement à partir de l'onglet Fichiers. Ouvrez l'un de vos dossiers de documents Sellsy dans la colonne de droite.

Dans la liste, sélectionnez les documents que vous souhaitez synchroniser, puis cliquez sur “*Actions groupées*” , puis sur  “*Synchro Dropbox”* .

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446359930/3f99a997088942c6e7850e11/6yQbwtY3v8i1Zf2NSONhhf35B_6JrCrybln4BYxzdklCC5oLleRBn3aBMs_6imJB0UKBa_j3O-r0KVVNHrNQPAeutDmuYLbt7w0t8RAYHqRJWPqwumkz9phI-2jYjZin_xSblsEU?expires=1788635700&signature=9949c0d7ca5a72fd66c4128018676742e9ae191bc20e781f32f4c34107719d1f&req=cCQhFcx3lIJfFb4f3HP0gG%2FlQTpx10tl8bUDlvG2GNbTjykC67s7qqRURuDU%0AjTcZnCcj6jlGEv1IsA%3D%3D%0A)

Vos fichiers vont aussitôt être transférés vers le dossier Sellsy Synchronisation dans les Applications de votre compte Dropbox.
