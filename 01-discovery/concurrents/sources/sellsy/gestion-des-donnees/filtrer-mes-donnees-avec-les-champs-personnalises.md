# Filtrer mes données avec les champs personnalisés

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261793016/a0fdf4448096b44576acbf0a741d/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=c914533fc1044cc33dd2afaf1dd08baedf8d8d38f557e534677a19676909da27&req=dSIhF853noFeX%2FMW1HO4zeSZfJ6SHBpFBymwntAsHOM2GWbHDLAbgKqE%2BHcq%0AVPMiGduQtGPUK6tcPpQ%3D%0A)

Vous pouvez très facilement filtrer vos données en utilisant **vos champs personnalisés**.

Une fois créé, ce dernier apparaît dans vos critères de filtrage sur vos listes. Dans notre exemple, le champ personnalisé *“VIP”* est disponible parmi les filtres.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446351983/0f13f3989297842d311b4f5c/ywMdhLnmCXMtyZpR4IKLitDMvUsHKL1b0RVg6aHkBoq9cN04M9S0MXcQdi49XSUD1UUOOBlicpr5zlfdDS6VBIoFo5odH8MQpGx-PrdFJpUqqLirO3GCm5BP7q6sAaO7Fq5MDi8F?expires=1788635700&signature=8a2cd93b4ec68c3f642c3374d7eb5a58ec4afd47a95cd6a19604d29c6fa608c5&req=cCQhFcx%2FlIlcFb4f3HP0gPvptuoM75AOEH6QqAPbnUtSt0pAAOXxyqkQxulZ%0AXWr74WCvMwTwDunv3g%3D%3D%0A)

En cliquant sur le filtre, vous aurez plusieurs options d’affichage.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446351988/26062bf0f507b0d5722abf2e/eXyXL_jgZc8KSpVLt4W3oDoKJiAjDa90JiazhqD_lY4eJI-71Hh_WWTg1Jg2JX8KkkYvmsdhRnh_sxkZgsMOfYIe7dA38SYoOrvDWN7kxHkLCH6kWJjM9bQ3-8yhruRh_fzCnBrV?expires=1788635700&signature=f6447d457448aa3d423460c3fcfef23f6f5b97cdaa45c8d51b0c7149c6011453&req=cCQhFcx%2FlIlXFb4f3HP0gJxpe432iMrAQ6EAaly3IOVVUr4eCug%2BQPWHSByv%0ABr5LilGbbKLBrwHTeg%3D%3D%0A)

Pour faire apparaître vos clients VIP uniquement, choisissez l’option *“Est”* puis entrez la valeur *“VIP”. *Enfin, cliquez sur *“Appliquer le filtre”.*
