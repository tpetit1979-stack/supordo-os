# Imports d'opportunités

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740109605/0a54d61c20c8f4a333bfe224cc83/FAQ-Bannie-CC-80reAcademy-2%2B-282-29.png?expires=1788635700&signature=e1182893008ba0a803ee80fd125fc51f4ad6bf2b1f08a6475a9a7070f7983ee2&req=dScjFsh%2BlIdfXPMW1HO4zRA317dVpkGRgXLOicqjLXRH3TXbDLPSDcBzH0fE%0AkXVqNgOBdYdwxOk%2BxFU%3D%0A)

L'import d'opportunités dans Sellsy vous permet d'importer facilement vos données commerciales depuis votre ancien logiciel ou toute autre source de données. Cette fonctionnalité vous fait gagner du temps en évitant la saisie manuelle de vos opportunités.

> **Bon à savoir :** Afin de pouvoir importer des données, vous devez avoir le droit *“Autoriser l’accès à la plateforme d’import”* dans votre profil de privilèges. 
> Pour [modifier votre profil de privilège](https://help.sellsy.com/fr/articles/5864116-comment-gerer-les-privileges-de-mes-collaborateurs), veuillez prendre contact avec un administrateur de votre compte Sellsy. 
> Les comptes en essai peuvent importer 100 objets maximum à la fois.

___________________________________________________________

### **Accéder à la plateforme d'import** 

Pour commencer l'import de vos opportunités :

Cliquez sur *"Menu"* puis *"Réglages"*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740190930/85c2f1637f6ca5a07e8a6e197e50/step-1.png?expires=1788635700&signature=679abe79a1604b25ffdca1fa1d0a876bb794f84f0f8bac85670838dc697d340e&req=dScjFsh3nYhcWfMW1HO4zYo%2F4kxLSV0NFrtrBfI9GbGDr0uZhK6sAlj5Ld6Q%0AiOmMk8eY5j%2BpdyfMXj4%3D%0A)

 Ensuite, rendez-vous sur *"Import de données"*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740196683/6b1e1e4891c836a64d6cb1aa0642/au8MRA_GeGZ1cFrKIsVVhpCA5iISBFcBATlFer-gNf_7CpTHn8IrbNM7G_80oyjUjKdreABRdHFLpociSlBHEmWYce80OzifwVlTqNaqHZ-H1If66nNb3NJNC13uX0DtO4nz4n2w-3Ds1600.png?expires=1788635700&signature=927f669bfd599b947aa5175ae3ddf5badda2bf021c5cbfbf6a997ab901619821&req=dScjFsh3m4dXWvMW1HO4zeUpC%2FkMyYir9TNewHLnBdzzmLX%2BfCup636%2F9SuY%0Ac6kVg6CtK6F%2FO%2BghnnA%3D%0A)

Vous accédez à l'interface d'historique de vos imports. Lisez attentivement les informations présentes sur la page d'accueil avant de commencer.

Puis, cliquez sur *"Démarrer un import"*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740198205/e20277882a6dfd3132609ad2691a/step3.png?expires=1788635700&signature=d8aa31fcb21c80784f3ba84c3089f710bceb008c8b19f57ee242b84f14061faf&req=dScjFsh3lYNfXPMW1HO4zWwqhb1PUSLl2FjJU0aVaeu0BaW2F41GRa7hvPl5%0AcZ7Zwj31LmOyYsuCNvg%3D%0A)

Sélectionnez les données "*Opportunités" *et commencez votre import en appuyant sur *“Continuer”.*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740199714/5229afda7ec2e175e40919c41507/capture.png?expires=1788635700&signature=91ca34dc5bd6607debdb2ee01c2cf420447a9b07cd40fb408e591c9ac821dc99&req=dScjFsh3lIZeXfMW1HO4zYmL7jtMYVaz5r0UJT2zpojRUP9YzlwEuMHqh2BH%0Ag6lt4n0%2Fr3H2XsvO%2Bfo%3D%0A)

> **Bon à savoir :** Les champs de couleurs orange sont les champs obligatoires pour l'import.

___________________________________________________________

### **Champs obligatoires**

Pour importer vos opportunités, trois champs sont obligatoires :

- **Nom d'opportunité** : texte libre décrivant votre opportunité
- **Identifiant Opportunité** : texte libre servant d'identifiant unique
- **Nom société** : doit obligatoirement correspondre au nom d'une société existante sur votre compte

___________________________________________________________

### **Préparer votre fichier d'import**

Vous avez la possibilité de télécharger un modèle d'import en cliquant sur *"Télécharger le modèle.csv"* ou *"Télécharger le modèle.xlsx"* afin d'assurer un import en toute conformité.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740205146/bbf629c494d87939ee8d7fa90a5d/image.png?expires=1788635700&signature=dc6c963641083da32164e60c8881a525732b802ad1a1b1d8cb6d56ccf8d765a6&req=dScjFst%2BmIBbX%2FMW1HO4zaaXdsbhSsYvF8efk5rpZKNANJ4Ip96JWDeGvCYY%0A9eyrnj4ZNWzyLOswv3o%3D%0A)

Une fois votre fichier préparé selon le modèle, cliquez sur *"Continuer"* pour passer à l'étape suivante.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740208205/e74539321ef958eb3861e226b16b/image.png?expires=1788635700&signature=7ed9f272710325939848676d8d7f7cec13e67bc11fa20f0fee79aa7346e6b841&req=dScjFst%2BlYNfXPMW1HO4zdK3pnKTheYw3x4I7ryZdhrN3ljt%2B%2BHacZweBJc%2F%0AViO6%2F2zSMqjUXc33%2Bug%3D%0A)

Puis, définissez les paramètres de votre import via différents choix.

___________________________________________________________

### **Définir les critères de comparaison**

Cette étape vous permet de déterminer sur quel critère Sellsy va vérifier si une opportunité existe déjà dans vos données.

Pour les **opportunités** ; vous pouvez choisir entre :

- **Identifiant d'opportunité** : Identifiant de l'opportunité affiché sur la fiche opportunité (OPP-XXX)
- **ID d'opportunité** : Récupéré à partir d’un export Sellsy, ce critère sert uniquement à mettre à jour une opportunité existante et ne peut pas être utilisé pour en créer une nouvelle.

Pour les **sociétés** ; vous pouvez choisir entre :

- **ID société** : Récupéré uniquement depuis un export Sellsy de société, ce critère peut être utilisé aussi bien pour mettre à jour une opportunité existante que pour en créer une nouvelle.
- **Nom de société** : Nom de la société à laquelle vous souhaitez lier l'opportunité

Une fois vos critères sélectionnés, cliquez sur *"Continuer"*.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740217251/6a5e35bb52950eb8795bc3de4628/step-5.png?expires=1788635700&signature=6ec1b26bf868d2e7b5c0f06442b0e6a45a535c26fe3cb9e5257271c74e840484&req=dScjFst%2FmoNaWPMW1HO4zR0YVWpraG6HtkX0sgSenp7ynmpLCbaVHXVgst0U%0ACtN%2B%2FoNJMItyC8%2FqBgw%3D%0A)

Si l'opportunité de votre fichier n'existe pas dans Sellsy, elle sera automatiquement ajoutée.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740222205/47e43da322a3eaedaed8eeadd1d9/step-6-create.png?expires=1788635700&signature=b5e911785249b0a91ddd957435dd166d99432f7bb6cbd95259e06001ccc24fdf&req=dScjFst8n4NfXPMW1HO4zaxbKmaakVPaQQ%2Bj%2BuGwmWuhUw%2F2AvVqtUhBsghd%0AilNH7NsGytvtlL%2FXzAQ%3D%0A)

### **Mise à jour des données existantes**

Si l'opportunité de votre fichier existe déjà dans Sellsy, elle sera mise à jour avec les nouvelles informations.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740224839/fcbd1e1e4281ca8cc77a07c8bb59/step-7-update.png?expires=1788635700&signature=b17aa43c9585fe5ef3e22346d8925a54110fc1077c42d370ab8334135aaf93ca&req=dScjFst8mYlcUPMW1HO4zet%2Bpat%2Fsl2SmYbUxwDvX7fhQ2NTUPraMdHFFOxB%0A6k8wInA2Hnm%2B6r%2BytfI%3D%0A)

Les cellules vides de votre fichier seront ignorées et ne remplaceront pas les données existantes.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740225165/77d1e353b0c079717c3048a8f8fc/step-8-cell-empty.png?expires=1788635700&signature=5e6c7802c33af46859a8f2786ff60c036e89cec3a8fcf24336a03ff73be8c01d&req=dScjFst8mIBZXPMW1HO4zT5rVyMK5r2ziQX9SiKs4gqrF%2Bkvr%2Bzl3wsbb%2BIT%0AbQvJEX%2BqTsWVfzKKwyE%3D%0A)

Les Smart-tags de votre fichier seront ajoutés à ceux déjà présents sur l'opportunité.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740226309/2793191279624ea69dac6cc44c57/step-9-smarttag.png?expires=1788635700&signature=40f3187f26c475b0c99098adeba849d200606b511912611b2d4e28f817c36fbc&req=dScjFst8m4JfUPMW1HO4zaztTxHiLgphrPp9UXdvIJhhfy2Nx08xCwkVKrhh%0AzYAeKWJqTkkUen2y2Rk%3D%0A)

> **Bon à savoir :** En survolant l'icône *"i"* au bout de chaque ligne, vous obtiendrez des informations supplémentaires sur les différentes options possibles.

Lorsque vos paramètres sont configurés, cliquez sur *"Continuer"*, puis sur *"Importer mon fichier"*.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740227474/0bf9ce9cdfe0f7a0ce119c18a645/step14.png?expires=1788635700&signature=991e13efc8053684be52ec39172c892fd86bd7573a0b6138c9752ea8959fc28a&req=dScjFst8moVYXfMW1HO4zQi%2FYiC4m5%2BFXunSFmW4jeJ5rkBkFIk4A7IA1RdQ%0AbMDKcFs2QWaEq0em7d0%3D%0A)

### **Importer votre fichier**

L'import peut se faire de deux façons :

- Glissez votre fichier directement sur l'interface
- Choisissez-le depuis votre ordinateur en cliquant sur *"Ajouter un fichier"*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740228388/33a10a3a7e37b792505c8f4b2e87/step-1.png?expires=1788635700&signature=562fffb2a75a95d23d0a655643f66a7a4b9e21cca232ec9cc8d7197d8a314271&req=dScjFst8lYJXUfMW1HO4zfhE5SAZVm0cliA2%2FUsWDDGvxkM9T2BaRTBRFMxh%0ALujEql7ZeVcTW183k%2BA%3D%0A)

Si la correspondance de vos données n'est pas automatiquement reconnue, vous devrez faire correspondre le nom des colonnes de votre fichier (à gauche); aux champs du template Sellsy (à droite).

Pour finaliser cette étape, cliquez sur *“Continuer”* en haut à droite.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1743656737/2ad23aff212727b30298af1caa8f/step-10-match-field-fix.png?expires=1788635700&signature=9b31148b536d8516076f56821357dd652263ea83d874714c3a93b80545e4b293&req=dScjFc97m4ZcXvMW1HO4zdaPrsYG1CgtYIuiHPK22mtAVg47Hcjekq4KZ9dN%0AJnFY%2FYv12hqBo6UH9JY%3D%0A)

Avant de lancer l'import :

- Vérifiez vos données dans l'aperçu
- Rectifiez les erreurs directement depuis l'interface si nécessaire
- Cliquez sur *"Importer"* en haut à droite

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740231710/ec80606fa96544bc9cd6df088e11/step-11-fixdata.png?expires=1788635700&signature=95a58905df571a8c766a0fcc7c071e18d889a6c799106ef7f03724c45ee92d4c&req=dScjFst9nIZeWfMW1HO4zWU3yRxm52EeGAIo412%2FJ1gYqika162SjYPbfekP%0AkoZbpLmhi7bcS3OZGp0%3D%0A)

- Confirmez le lancement de votre import en cliquant sur *"Importer"*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740234444/f347dc5d7bf2d40c132c694aa9c0/step-12-launchimport.png?expires=1788635700&signature=86de322e2af70052e76f2b365ace593426538481c478a90d5b4277ca1b4df91d&req=dScjFst9mYVbXfMW1HO4zf04UqTkk2bqwBUTRuFKrGl7G8Z7eJOVg45vfkYy%0AXm46p93NqBA0Sa8%2FvJI%3D%0A)

### **Suivi de votre import**

> **Bon à savoir :** L'import réalisé apparaît dans votre historique avec le statut de l'import (en attente, en cours de traitement, traité, annulé). Vous avez la possibilité de cliquer sur *"Voir"* pour consulter l'ensemble des détails.

Depuis l'historique, vous pouvez réaliser différentes actions, comme télécharger le fichier d’import ou d’erreur, et annuler l’import.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1740238830/fc98e61e8b60ddc8487c540fb220/step-14-import-detail.png?expires=1788635700&signature=853bef8adecb3032f09f11a1c11ea3e1d6dc2ebc7735358976ffcca63369b468&req=dScjFst9lYlcWfMW1HO4zSgDtibxgI6sKZKGALmYm4TOpC4aksvnmgHwbbd0%0AMJbf%2FNqdfYZm2o5cn8A%3D%0A)

Votre import d'opportunités est maintenant terminé et vos données sont disponibles dans Sellsy.
