# Importer mon catalogue de services

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2142750872/6bcb2cc8f8309871bf5787275fb1/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=131df1183df92e203e27660e6d05fa0c3856270673c4e4481a9c1837af568bdd&req=diEjFM57nYlYW%2FMW1HO4ze%2BUsQpf4YYjFjbTj4cgWxj5DuOeAU5We6y7jyxQ%0AzNRzmfznA809zCPAbzI%3D%0A)

> **Attention :** les comptes en essai peuvent importer 100 objets maximum à la fois.

> **Bon à savoir :** afin de pouvoir importer des données, vous devez avoir le droit “Autoriser l’accès à la plateforme d’import” dans votre profil de privilèges. Pour [modifier votre profil de privilège](https://help.sellsy.com/fr/articles/5864116-comment-gerer-les-privileges-de-mes-collaborateurs), veuillez prendre contact avec un administrateur de votre compte Sellsy.

___________________________________________________________

### **Démarrer un import de services**

Avec Sellsy, vous pouvez très simplement importer votre catalogue de services.

Pour importer votre catalogue, cliquez sur l'onglet “Catalogue” puis sur “Liste des services”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408066/b15e927a704197b2d05136f7/maen3AAJqWF5eosf67Kfd2OTYbosSgqTvm0zTYr0YvTRS5VRXW_tnNGGvrtPgAwvzO4QO76D435_9HMQDq2oou-nHwpxvkBcRLj4BIw7fXSXXZrsj-gsTNJkGGWoLstpe6NMKZ4pL2Hl-3F-OvdHMMY?expires=1788635700&signature=a89bc687183fa46a9313ba7e331d6fbd2b99110841215207bfc72cc80304fc42&req=fCYgEsl2nYdZFb4f3HP0gCIjzGjWvGXUn%2F%2FXU0mjRYMrsOl2o3J75eZYezUr%0AFSEEnQ%2BHPyaOHwsUAA%3D%3D%0A)

Cliquez ensuite sur le bouton “Actions” puis sur “Importer des services”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408112/d1bb2da351e64932237bfc33/FikyJPMnyeOWDRURXv4Xkr-skYLbIfXG8gbV7YUpk4jlxK-P6SUE6ays2fVnef8YcdWFHD9jmMpvPxyDz0LAqBf1f7IhbRX7o9xtEt3U2K8jcle2N1pSwESlce1jW2zinZM_z9shmzeSVvnCC4Dd5_8?expires=1788635700&signature=2699d973daecf5370dc500017ff17448483cd8fcf08271c648aea88979720d55&req=fCYgEsl2nIBdFb4f3HP0gNL5tDDtYvFU%2BxPE4SRgsMKPp0GBDep5Al1KUMiq%0AwspD0w1x9KuhUICA5w%3D%3D%0A)

Puis, sélectionnez les données "Services" et commencez votre import en appuyant sur “Continuer".

![](https://downloads.intercomcdn.com/i/o/991504795/96b4d251e2d5e133a84827a5/services.png?expires=1788635700&signature=ba053da59ddad2c930f9b2c63478b857b5a8ca48062f77f7dc0390a6bd9aec13&req=fSkmE8l6mohaFb4f3HP0gNfWPOjrNhHGNuIDD8EbbK9YfpKcHDc83dvhmE9Y%0Aq1Ppl%2B35Kk8%2BupPWgA%3D%3D%0A)

Vous accédez ensuite à la plateforme d’import Sellsy. 

Nous vous conseillons de lire les informations présentes sur la page d’accueil avant de commencer l’import.

> **Bon à savoir :** Les champs de couleurs orange sont les champs obligatoires pour l'import.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408238/53e24e76d507ca8a78ba4de6/C5_XRRIb1TnOOzaLwc-dS9nxsRsxFdLIB1pgA-PE6CZVCbbwHJFKcx6OT8Nk3Svq-jT-oPSWugicwhg5S-DROGE2F6wsbPJ5XGFGm5VrmlcZntYmRL3JK2FONDTx7-UKtXhGigfd4rftVJ2KItf65G4?expires=1788635700&signature=638aa5dd78eb40c4dbdc9501185fef7f689e29cfc490135fff16c8ca6cd5a5fb&req=fCYgEsl2n4JXFb4f3HP0gId9Hwpqk%2B4Tx2jRjJ7efPRwTh63oa1Y2r1ZoAHz%0ASOMSWbdoWfw7PDUn%2FQ%3D%3D%0A)

Ici, le champ obligatoire est :

- **Référence : “**Référence ou code service unique dans votre catalogue”

> **Bon à savoir : **Vous avez la possibilité de télécharger un modèle d’import en cliquant sur “*Télécharger le modèle .csv”* ou “*Télécharger le modèle .xlsx”*  afin d’assurer un import en toute conformité.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408263/36277d0095298a74e87a5367/lmt0-lWQdeCLqkR-mVHGkx-6VoZkrwOd-9qMKvHpN_xr4e_QI_YHcYsEJNw0sBWHhbyur-H55hTdLnvco5WzWK9HHvGOWQI2n25WrmipVU-2507iB4jz1MhKH2RyjC4mJMC-jMGm7-g96-4TsXP_Cok?expires=1788635700&signature=c91295046a14291b212b48574c47344b2e26655ca3ba6204d361ff68f6ec779a&req=fCYgEsl2n4dcFb4f3HP0gBQ9U3WBv1QBjhGC87qjVHlwWonO77p79%2FXbko75%0A%2BeSB4Q9g8WxSlzJqyw%3D%3D%0A)

### Définir les paramètres de votre import

Dans un premier temps, sélectionnez vos critères de comparaison afin de déterminer le critère sur lequel nous allons déterminer si un service existe déjà dans vos données Sellsy.

Vous pouvez sélectionner votre critère de comparaison par : 

- **“Référence”** : Référence ou code du service unique dans le catalogue.

Ou par : 

- **“Identifiant Service”** : Récupéré depuis un export Sellsy.

Puis, cliquez sur “Continuer”. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408320/fb4b5268e4abfef20463446a/1S7tP0zXDiOSO7HgAvCDBsL0Q7Er-lPNc2LfzgULhxZQ3YKfPc8esYpkbjMcqKEXqQ-KkQBjyHRwLSI3mKgdoK-Ng0VBsNeuTHnm8gnOb-ZAKOi3CScgAAboGvPkXaOQiSHPuamzPqC817COe_2rykA?expires=1788635700&signature=6b1669988a9b6224489dd19c3aeffb532af9c4f0bc9b7c92f4f0ce64c598de48&req=fCYgEsl2noNfFb4f3HP0gP4wHh%2Bpvj%2Bw6nG%2B1wC3urtBQAwednByIcAJKYzA%0AQwxRrov%2FHFwTv%2BBOgQ%3D%3D%0A)

Par la suite, sélectionnez en détail les paramètres de votre import, afin de déterminer les actions que nous allons effectuer lors du traitement de votre import.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408344/47471f796280403f7ba842d1/dlnQvlw-az1ZQf9K3lpvIWS7eA-VQUWkAjiJDiuhvkCU41F8MwWa1BaMUdP5voOj1VZxzTXfwr5LJ_Ho_HJzRvP3r6GzQMPOGVnL2RP07cVs_FwHxbcyiqt8_JYFoexkYxVoyyAeDwD4wSiujNIXfXo?expires=1788635700&signature=568e150069fd5a17c7c62590020b0ab1947e23324cd963d9bda4571a5633cf83&req=fCYgEsl2noVbFb4f3HP0gF44oRZZAfxIhZAaqaDbF1nqozKK735VZzKqn7xW%0A%2B55Q1eq92PSKHd4ypg%3D%3D%0A)

Concernant les options de création : 

Si un service de votre fichier n’existe pas dans Sellsy, vous avez deux possibilités : 

- **Ajouter votre service** pour qu’il puisse être pris en compte.
- **Ignorer et ne pas l’ajouter** pour qu’il ne soit pas importé.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408365/6a4efe60eb2619586188038c/xquiVqHe4eqiWynaPKeWxIE-uTfb5xv-Z-EcGWeSpgsrvh1iH-BbDXRK0blCCmRaGeYcOmhIusBrY54nO4rT1S43kQLBd1a7dnDcRlbUQMbKceKBkyndy8fp2ZlbqfuCI-wrQrBsPpSfX0hSC8Zli1Y?expires=1788635700&signature=36d09aec3e09b14102ca3eb1ef0bd7252f1759720fac6027a5d4ebd291a47853&req=fCYgEsl2nodaFb4f3HP0gOiNsPkuyiXTdkzcpQ%2FcrKNx9WTxqjyTeuNVbu2u%0A0kp0mOGoCRVdpKRDRA%3D%3D%0A)

Concernant la mise à jour :

Si le service de votre fichier est identique à celui de Sellsy, vous avez deux possibilités :

- **Mettre à jour le service : **Le service identique du fichier trouvé par rapport au critère de comparaison renseigné est mis à jour dans Sellsy.
- **Ignorer et de ne pas le mettre à jour :** Le service identique du fichier trouvé par rapport au critère de comparaison renseigné est ignoré et n’est pas mis à jour dans Sellsy.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408444/26fd019c039927cfc002c2cc/24a9giWbpK4VC2SR3RSYDsC_Cv1xWHFfNn5KUfSHDt68uBmHlEopWOoo_AV1bFt-y3zfJkNTtwNt26uGF8k2Kv0eHUiVQrhddyqE0NzDCxrgTBi0I8DvRkDZcCiP9MG2zvAUWxLzmiG_YdRTh29Z4EA?expires=1788635700&signature=98a117e2998313b7bb6870c1870051981f111eabcb0dc58674a10d13ea7962a6&req=fCYgEsl2mYVbFb4f3HP0gDQKZ%2FutAJ3%2FQuJ7gBmGvDCXoglE0q2Q%2FC6i8926%0AQT%2FnJq8iPMhCQedyVw%3D%3D%0A)

Si une cellule de votre fichier est vide, vous avez deux possibilités : 

- **Ignorer et de ne rien faire :** La cellule du fichier est ignorée et n’est pas importée dans Sellsy.
- **Remplacer par une valeur vide : **La cellule du fichier est prise en compte et une valeur vide remplace celle existante dans Sellsy.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408465/8b940b2c34e9915ef438cf92/2ZJkKKeXRu7yQ0lks-HV57UNwGSVrEeHOiSx2Vst53DRJt1tJmVJ2teDCQVw1wfK6br6i8mHQCVFKYdWBvfT7K-Q3VXRMjSkZkp2bYFpxUOgYA6_C-1Dl1tRFSg9QgwEu35I6qlF03cBDf7f8wd_yQ4?expires=1788635700&signature=634e38ae9babe39e3e3663f802379c50b0b0f7f4cd2b4b4f3ca5a5c9b589a134&req=fCYgEsl2mYdaFb4f3HP0gEiJsuaxGtBpSFK8jwu3CCwkcUBIvEZMtt8bwHd1%0AIESvgUfbiOQNtFzmYw%3D%3D%0A)

Concernant les Smart-tags de votre fichier, vous avez deux possibilités :

- **Ajouter les Smart-tags** de votre fichier à ceux déjà existants dans Sellsy.
- **Remplacer les Smart-tags** existants dans Sellsy par ceux de votre fichier.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408483/f018012521bb44b793c5be01/IRE9z9j5XnltMnBpCpBGkvUjL-Arb6DMkqxyD4QrshNsiK-HqMqf0XlzSEIM-svVWJWVZCUG_TE-_GrEmtDIR3cBfEGgzv0FVaEfgHJd59r25bbiUqBBE6t38QTzU0h9dE50G6Oa7Bhwp9K-SqRO4V0?expires=1788635700&signature=11480d36c09f22803534885819df9e3d5a2cf69a9f92bd6ce347f6531bce85a5&req=fCYgEsl2mYlcFb4f3HP0gGG3NiJtRPlmqm3VUDBbXsNjTfSwfFKr3CgbGfW0%0AyL8yJCDK2wYXFn1QNg%3D%3D%0A)

> **Bon à savoir : **En survolant l'icône "i" au bout de chaque ligne, vous obtiendrez des informations supplémentaires sur les différentes options possibles.

Lorsque ces paramètres sont sélectionnés, cliquez sur “Continuer”, puis sur “Importer mon fichier”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408517/13a535e4254258bf72807f9d/cqPQcWe7OG378XJq5qcoERPisZDWmMaVxNPnADNaERBfumodjeM0_-NcIMRzUcm7QQkhhYgM1KsLH7LKeycMDzouIu0RyxZtY37NS-aJjU6VA0nLUGvN_9h8n0477THwBMXQVBvGKWDb5Wnt-GsbRV8?expires=1788635700&signature=c2a0ef400c36891396ff093e39fc1e373a4fa8fa790742fe630a5b75b6c501c2&req=fCYgEsl2mIBYFb4f3HP0gJzy27AfKRJN%2F%2B42sNjPOWVubvV2adigasD2xOat%0A2nhL3Y6s7vrUUL32rA%3D%3D%0A)

L’import de données peut se faire de deux façons : glisser votre fichier directement sur l’interface ou choisissez-le depuis votre ordinateur en cliquant sur “Sélectionner un fichier”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408576/7bfd96db36c8f825cbc72dde/OBbrFjn-Vm4O7krNJ28POV8awiU60ITPrCC2AP7LYrQK4gbv57xFhENhyhrLg8KE8VtC6btv0iEoMKK-MZNs1nroOJ7nZaMROeTLHjweHMd9D0Kik30KIV2-EiAu-2Lpqncj9zVuZEtnyfPaY2VdMLg?expires=1788635700&signature=99c4738aafe2b496d66babf2093f5b77cb770a8e57477b51bdabfbc5d3092dae&req=fCYgEsl2mIZZFb4f3HP0gMUi72LPsiJq26FSB%2BF76PenRILIvGIQjtSDywl4%0AEbxyNWP9MkA%2BNt23FQ%3D%3D%0A)

Une fois sélectionné, confirmez ou modifiez la ligne d’en-tête de votre fichier puis validez en appuyant sur “Continuer”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408608/5cd9e76b87e909447fa1fff8/P-SoOiKKr5y5uBQ3e-6eD0daQZRjbsxFr-C5awIMwyLAVJQAS71qJfcRGh0kcI-nm7yYZaW1hWWdVS0ktECmusQH7XlXMS7U7FLout9qdJLtCO40i46glIZZmNelbJ7oDu2bsMeHuQFg6TrFSkK0zLA?expires=1788635700&signature=bca550a8631170c703c7c072e48625981eda2b297562ab3db0ab27eff0e6a9be&req=fCYgEsl2m4FXFb4f3HP0gBe1wtyzOCLJYkMpbFZWa4ecmS59KEgf%2BOVTsZSh%0AbWQ3o9tFO7PopraRcw%3D%3D%0A)

> **Bon à savoir : **Vous avez la possibilité de ne pas sélectionner la ligne d’en-tête de votre fichier, il vous suffit de cliquer sur “Ignorez et utilisez des signes alphabétiques comme en-têtes” ou bien d’aller sur le carré vide en haut à gauche. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408691/ac311367862ba8e0bae8d792/9z3MdzPVSS7BJj3sZL8XkB5MkwMcfA-__sqz02AmPms6w891WRHCdVj0lxPtBGflPXE9HuscsfpqH1B96kfVgDpmUFTpKxNyb-qJllE0mE6THUcPKaOA2QSlXpxcteRah0fSpL8MyFHfm7yDRKvg4eY?expires=1788635700&signature=ee889d78babcae76502d4c0481741a5990e9ea5e858a4ed1674ec8adadf1895b&req=fCYgEsl2m4heFb4f3HP0gCJH4Hgild4lu6693nrTWSHE%2Fg37X%2FaL4Qvystns%0AXvdYeWKbyCwkTICuXA%3D%3D%0A)

Puis, si la correspondance de vos données n’est pas tout à fait exacte, vous êtes amenés à faire correspondre le nom des colonnes de votre fichier (à gauche) aux champs du template correspondant au type de données sélectionné (à droite). 

Pour finaliser cette étape, cliquez sur “Continuer”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408718/302ae21cf408ce225dcfdfb6/TSbEgM9rVSPdFfZM29_AmgiJez5bGA1k-EX130RS9ckyN_Za3C8rIQgsGN2VoNeu3dLheJ1cH9GOysqZWif-wmCDNPSsZQ2_GCDwowqmgVeRZ2QOs4aFbLgPoMnEy13zV04-d0JF4xBb3-SyOdfl1Ks?expires=1788635700&signature=cd2f7d6ace65f8a7e3721d34ecdee347ad9099d111864d875824bd14402a4137&req=fCYgEsl2moBXFb4f3HP0gMjGZDrUo5aDSsODnnb82fbenP1iBxCXAn2RYNjm%0ARwEyR6sqbvoUKnylQQ%3D%3D%0A)

Par la suite, vérifiez et visualisez vos données en rectifiant les erreurs directement depuis l’interface d’import si nécessaire. Continuez l’import en cliquant sur “Importer X lignes”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408764/9e79a836cbe39b074a487c51/b1LuElhEb0duaQN8Hj0FS0lBC6WcOhVjAPui8sh3_mCbFmGNzR9i9qOGgzgM3pizJBzAw4l_ptH8SJVhscddUfBha15RooFDgFuaEus2mAf-IKaM3gamaJeLyQyEKnFIbePcRcTGlibJBdqYvMOW_Cw?expires=1788635700&signature=3a4171886aeb9cf7b58d4d88fbf9bff5bcb4996a40872e254e9314f3f80bd024&req=fCYgEsl2modbFb4f3HP0gKVhW5Ntm3%2FKg5Guc%2Be7TUzY0u%2BD6u%2Bev2W7Kqjz%0A0QC%2Fjfbm%2FJiAiWSv6w%3D%3D%0A)

Confirmez le lancement de votre import de catalogue service en cliquant sur “Envoyer”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408804/5b9c3052b53730fe04af1e23/oZGDIYO6Hpm7D4MXhrH9d9UAVSAEmYK0fC0RS1GsmV9fSMEpUyE2uqbMOC86gei24ynSJvtQ8XQ_MlXDlP1AjSz8ip-VohUX5KWePu8Hto0CYwASGWPqDczEIGOSGwB6Uo-x1BvQpUDTlBpebWmFxlU?expires=1788635700&signature=95f2bb8c61fd4d5f701b8197d6bc18a30ef9bdb46fc8465654c958ec7dda5591&req=fCYgEsl2lYFbFb4f3HP0gJL1ViFDABylY78i168MlEci6yfGUMJ33rb%2Bwzg3%0AYI5X%2FfylvHkkkzYRKA%3D%3D%0A)

> **Bon à savoir :** L’import réalisé apparaît dans votre historique avec son état d’avancement (en attente / en cours / traité / annulé), vous pouvez cliquer sur “Voir” pour consulter l’ensemble des détails. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867408854/882b5b9d62db867254d5ad06/qEYQ98vgZsXlbNFAXTZenz9DH5uRpP9EP64upvLcT1wYv3l_4NwpGSIMKg_jMTNPqMubA5PvMYqgbdzlC-FdEQzlQZ-oqwmGNs68l4P1z1zg_JkqNOmLO-vdBIObAzLB9uklqmFT6rQl97VMD2DaLCM?expires=1788635700&signature=64a2a5125f52e281c43a7ebd34a3a265bd2a1628f9eff4b3c63ec7edb6cd3cbf&req=fCYgEsl2lYRbFb4f3HP0gJ5g7XgtiNl0kb664SDUQNFo1et24NYwq8908jAl%0AyPqNi69rbVxF5A4owQ%3D%3D%0A)
