### **Ajouter un fichier**

Pour ajouter un nouveau fichier dans Sellsy :

1. Cliquez sur *"Fichiers"* dans le menu principal
2. Accédez à l'onglet *"Mes documents"*
3. Cliquez sur *"Ajouter un fichier"*
4. Sélectionnez le fichier depuis votre ordinateur

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2142671537/990cf3c753c2a9d931a746536b20/_LnKl1tgx0nnnWwjbj4b2qyxgV9YzKhelcHqnJNaPYlOYXK5_30UUs30wDG4Sc502wjJWjXmQfGQJVnref2-uJr5lJheKkMUMMxxv9VuXgUlyFSfMDHO_0IKxoKH6PBc7SjuXYoJ?expires=1788635700&signature=3810d7dd9a3878ba9da50d65751fa32fb2e168a00c176ffdfc0f0e8ce63b4411&req=diEjFM95nIRcXvMW1HO4zf2LUz5om3r43QnaRp%2BDtKJvdGz%2FWGRiSY3e%2FZDt%0AuO%2F5JQS93JowsXLFOjU%3D%0A)

> **Bon à savoir :** Vous avez la possibilité de créer un nouveau dossier avant d'ajouter votre fichier, ce qui vous permet d'organiser vos documents dès le départ.

Vous pouvez également ajouter un fichier de manière plus rapide en utilisant la fonctionnalité de glisser-déposer :

1. Sélectionnez le fichier depuis votre ordinateur
2. Faites-le glisser directement vers la zone *"Mes documents"*
3. Relâchez le fichier

### **Suivi du téléchargement**

Une barre de progression s'affiche pendant le téléchargement de votre fichier. Une fois le téléchargement terminé, le fichier apparaît automatiquement dans la liste de vos documents.
