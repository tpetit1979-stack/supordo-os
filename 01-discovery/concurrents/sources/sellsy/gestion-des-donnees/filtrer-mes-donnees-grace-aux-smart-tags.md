# Filtrer mes données grâce aux smart tags

Lorsque vous êtes sur une liste, la liste de vos clients par exemple, vous avez la possibilité de les filtrer à l’aide des smart-tags. Inscrivez *“Smart Tags” *dans la barre de recherche des filtres puis cliquez sur le filtre proposé.

### **Les différentes options de filtrage**

Différentes **options de filtres** sont à votre disposition :

**1. Contient au moins 1 smart-tag** **:** affichera les clients avec un ou plusieurs smart-tags, peu importe le/les smart-tags

**2. Au moins un des smart-tags suivants : **affichera les clients disposants d'au moins un des smart-tags inscrits

- Ex : VIP + immo
- Client avec VIP = oui
- Client avec immo = oui
- Client avec VIP, à relancer = oui

**3. Tous les smart-tags suivants : **affichera les clients disposants du cumul de smart-tag inscrit

- Ex : VIP + immo
- Client avec VIP, immo = oui
- Client avec VIP, immo, à relancer = oui
- Client avec VIP, à relancer = non

**4. Uniquement les smart-tags suivants :** affichera les clients disposants uniquement du cumul de smart-tag inscrit

- Ex : VIP + immo
- Client avec VIP, immo = oui
- Client avec VIP, immo, à relancer = non

**5. Ne contient pas un des smart-tags suivants :** affichera les clients qui ne disposent pas des smart-tags inscrits

- Ex : VIP + immo 
- Client avec VIP, immo = non
- Client avec VIP, immo, à relancer = non
- Client avec immo, à relancer = non
- Client avec à relancer = oui

**6. Ne contient aucun des smart-tags suivants :** affichera les clients qui ne disposent pas uniquement du cumul de smart-tag inscrit

- Ex : VIP + immo 
- Client avec VIP, immo = non
- Client avec VIP, immo, à relancer = oui
- Client avec immo, à relancer = oui
- Client avec à relancer = oui

**7. Aucun : **affichera les clients sans smart-tag

> **Bon à savoir :** l'utilisation du filtre "Smart Tags" fonctionne uniquement par liste. 
> Exemple : sur la liste des opportunités, il sera seulement possible de filtrer en fonction des smart tags renseignés sur les opportunités ; il ne sera pas possible de filtrer la liste des opportunités en fonction des smart tags renseignés sur les sociétés.
