# Ouvrir un fichier CSV avec Open-Office

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2142845102/c081b8e46b66c320897983148aa5/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=7d00b52da2167aecfce91d7151cee92df2221ccb484da9e42ab14ec1a5d586cd&req=diEjFMF6mIBfW%2FMW1HO4zRujadFsIRoXYqMtAzcqH%2FlLQac54bncLOMMscSc%0AuAG20DsyOUfPSi4NXwI%3D%0A)

> **Bon à savoir :** le comportement d'Open-Office peut varier considérablement entre les plates-formes, les versions et les régions. Dans la plupart des cas, le simple fait d'ouvrir le fichier ne fonctionnera pas et/ou les caractères spéciaux ne seront pas reconnus. Veuillez suivre ces étapes pour ouvrir votre fichier CSV. 

1. Après avoir exporté au format CSV (encodé en UTF-8) vos données.
![](https://downloads.intercomcdn.com/i/o/740466747/1babf294abe433a6c460122e/CSV_UTF8.png?expires=1788635700&signature=46084ca2f1d9ba586a93db2e6ab23e788f38c03a220ca149f52b7196ac0f2fc0&req=cyQnEs94moVYFb4f3HP0gIB4k80%2BUi2Tyfum5G1cN0T3W1%2FAL%2FeXOUaViZ4C%0Aqs4%3D%0A)
2. Faire un clic droit sur le fichier ainsi téléchargé, puis “ouvrir avec” et sélectionnez “OpenOffice.app”.
![](https://downloads.intercomcdn.com/i/o/446457701/be417c27f3fb5be04a63f1b0/Capture+d%E2%80%99e%CC%81cran+2022-01-11+a%CC%80+14.17.25.png?expires=1788635700&signature=595bc19f6d08e5316ffbaa78a86bec60e8d8f5e41553404ef4ff3d0e57ae6243&req=cCQhEsx5moFeFb4f3HP0gMxCRXWiOLOanW4In52fsbhY%2B75KGz81nm1AvSYV%0AoOs%3D%0A)
3. Dans la partie "Jeu de caractères", vous devez sélectionner le même encodage (UTF-8 dans notre exemple) que celui utilisé durant votre export du fichier en CSV (étape 1). 
Le séparateur du fichier doit être le point-virgule.
![](https://downloads.intercomcdn.com/i/o/446457883/3650a6a1029cba7c366eed0a/Capture+d%E2%80%99e%CC%81cran+2022-01-11+a%CC%80+14.17.34.png?expires=1788635700&signature=70625e3df2e109bcb30a3d7bd6b75800c1ed93c13107fa818fac35415a2a676f&req=cCQhEsx5lYlcFb4f3HP0gPsFUwhouIA3MtnQoSdxF9aoCsTEVDlRfIsGG0Es%0A6UE%3D%0A)
4. Une fois les préférences appliquées, cliquez sur le bouton “ok” (en haut à droite).
