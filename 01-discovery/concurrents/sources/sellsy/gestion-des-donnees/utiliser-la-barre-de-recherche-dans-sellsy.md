### Bien démarrer avec la barre de recherche

Pour accéder à la barre de recherche, vous disposez de deux options :

- Cliquez sur *"Rechercher"* dans la barre de navigation en haut de l'écran
- Utilisez le raccourci clavier **Ctrl + K** sur Windows ou **Cmd + K** sur Mac

### Filtrer ma recherche

Vous pouvez affiner vos recherches en sélectionnant un type d'information spécifique. Les filtres disponibles vous permettent de rechercher parmi :

- Sociétés
- Contacts
- Opportunités
- Documents
- Produits et services
- Tickets support
- Particuliers

Vous pouvez appliquer un filtre avant de lancer votre recherche ou après avoir saisi vos mots-clés.

> **Bon à savoir :** pour désactiver un filtre, il vous suffit de cliquer à nouveau dessus.

![](https://downloads.intercomcdn.com/i/o/928515603/6b57944517d760395cb8984c/Untitled+%281%29.png?expires=1788635700&signature=3b3d4757096c6b8e80a234568621136a15b3201edcaf7779061ed2ef68e81d21&req=fSIvE8h7m4FcFb4f3HP0gIYpskznqwnWtKfP4U7x%2BpI8zVRjFipwR%2FH8LKHh%0AjvQvyIhsp3k09cktbg%3D%3D%0A)

 Informations utilisées dans la recherche :

Lorsque vous effectuez une recherche dans Sellsy, le système analyse automatiquement les champs suivants selon le type d'information :

- **Sociétés et Particuliers :** nom, référence, email, téléphone, mobile, fax, ville, code postal
- **Contacts :** nom, prénom, email, téléphone, mobile, fax, ville, code postal
- **Opportunités :** nom, identifiant, contact lié, société ou particulier lié
- **Documents de Vente :** objet du document, numéro du document, société ou particulier lié (factures, devis, bons de commande, etc.)
- **Produits et Services :** nom système, nom commercial, description
- **Documents Redactor :** nom, numéro du document, société ou particulier lié
- **Tickets Support :** nom, numéro de ticket

Les mots-clés correspondant à votre recherche sont automatiquement surlignés dans les résultats, ce qui vous permet d'identifier rapidement le champ concerné.

### Faire une recherche approximative

Si votre recherche ne donne aucun résultat direct, Sellsy lance automatiquement une recherche approximative pour trouver des éléments similaires. Cette fonctionnalité est particulièrement utile en cas d'erreur de frappe ou lorsque le nom recherché est complexe à orthographier.

![](https://downloads.intercomcdn.com/i/o/928517567/b0b5b1c9b2cbd550790497a2/Untitled+%283%29.png?expires=1788635700&signature=d012ef8a21470e585c74ae5dbadbe52b6e9f9f3b87cda6a5d8d7a472202116a3&req=fSIvE8h5mIdYFb4f3HP0gJfCOeljMODGm9mNSZFX3UBY%2BvhjGFRFht%2BqsBWh%0ArRpRJuZoq5O5MyK0Ow%3D%3D%0A)

### **Accéder aux fiches récentes**

La section *"Récemment ouverts"* de la barre de recherche vous permet de retrouver rapidement les dernières fiches ou documents que vous avez consultés, sans avoir à effectuer une nouvelle recherche.

![](https://downloads.intercomcdn.com/i/o/928517865/c49ac291e1d31372393739ba/Untitled+%284%29.png?expires=1788635700&signature=394138fce20f3fe4edf0f24fd345d5fd05181e039c31c3003d75f05193b9d60d&req=fSIvE8h5lYdaFb4f3HP0gCq%2BeV2oVwd7XnNcYpcdviQl9RL0WjMcVG488Wcq%0AF5uJolBVciyvB11kpQ%3D%3D%0A)

### Créer des sociétés depuis la barre de recherche

Si la société que vous recherchez n'existe pas encore dans votre compte Sellsy, vous pouvez la créer directement depuis la barre de recherche grâce à l'Annuaire des Sociétés.

Pour cela :

1. Dans la section *"Allez plus loin"* de la barre de recherche, cliquez sur *"Chercher dans l'annuaire des sociétés"*

2. Identifiez la société souhaitée dans les résultats

![](https://downloads.intercomcdn.com/i/o/928518447/f296917cc2c142597f3c3d00/Untitled+%285%29.png?expires=1788635700&signature=c9a35c81650572736eeb880f137e33f251fadac0c062d13ec9cd14158c9fcac0&req=fSIvE8h2mYVYFb4f3HP0gFtKbEA0JWCrjZ6bcoJRGEOWJZd3zoLF6hk0AtvE%0AMxhSnbL7BO1q%2BOd7GQ%3D%3D%0A)

3. Cliquez sur *"Ajouter"* en bout de ligne pour l'intégrer à votre liste de prospects, clients ou fournisseurs 

![](https://downloads.intercomcdn.com/i/o/928518631/7ecdedcf105a22d2b05a701e/Untitled+%286%29.png?expires=1788635700&signature=75a6ee3b70e9861fc20c7c3b8c66fd3183193b1e8527e9bcd3b5be56e4fb0ffc&req=fSIvE8h2m4JeFb4f3HP0gGwadcme7kW%2FvJrTmfC0A8bg49FDW%2BwEmbwDaYzZ%0AiAfhkyrs3CTsEr6iqw%3D%3D%0A)

### Aller plus vite avec les raccourcis clavier

Vous pouvez utiliser les raccourcis clavier suivants pour accélérer vos recherches dans Sellsy:

- **Ctrl+K** (Windows), **Cmd+K** (Mac) : ouvrir la barre de recherche
- **Échappe** : fermer la barre de recherche
- **Flèches** haut et bas : naviguer les résultats
- **Entrée** : ouvrir un résultat
