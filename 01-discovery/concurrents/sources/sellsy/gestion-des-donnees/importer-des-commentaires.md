# Importer des commentaires

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1876355101/24860e3a0815053f4844521809ee/image.png?expires=1788635700&signature=3a38153de8c9458dcd0e185b8253a2dd7c060e72e3d2e5af35a0f93d1b306234&req=dSggEMp7mIBfWPMW1HO4zZu0uTUymR%2FAonrSkoTsfQsc7b6zqQLxHphfBwXk%0AbqvW35k6DpTI9EWUrZM%3D%0A)

___________________________________________________________

L'import de commentaires dans Sellsy vous permet d'importer facilement vos données depuis votre ancien logiciel ou toute autre source de données. Cette fonctionnalité vous fait gagner du temps en évitant la saisie manuelle de vos commentaires.

> **Bon à savoir :** Afin de pouvoir importer des données, vous devez avoir le droit *“Autoriser l’accès à la plateforme d’import”* dans votre profil de privilèges.
> Pour [modifier votre profil de privilège](https://help.sellsy.com/fr/articles/5864116-comment-gerer-les-privileges-de-mes-collaborateurs), veuillez prendre contact avec un administrateur de votre compte Sellsy.

___________________________________________________________

### **Accéder à la plateforme d'import**

Pour commencer l'import de vos opportunités :

Cliquez sur *"Menu"* puis *"Réglages".* Ensuite, rendez-vous sur *"Import de données"*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1876367170/bcbdcae2ff3df6d8fbe7f7262734/1.png?expires=1788635700&signature=c5c637cc18de93e5a5762b7bbf8137aeac25276164fba088d328d53da4911b73&req=dSggEMp4moBYWfMW1HO4zYMcjn2ZybQwkesE%2B%2BVij54s5cqCUXFa46r0Hzrm%0ARXOZkB97Qcpes5Y%2Bwzg%3D%0A)


Vous accédez à l'interface d'historique de vos imports. Lisez attentivement les informations présentes sur la page d'accueil avant de commencer.

Puis, cliquer sur *“Démarrer un import”*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1876368217/5906f466a66c4ef5ca9148681a92/2.png?expires=1788635700&signature=2bf223b89de7eadfd87fc41a46d76c26747465c766937fd513c584e4ed2bf5eb&req=dSggEMp4lYNeXvMW1HO4zZBb6W2C4TyKcicaO6ddm1xfT3ltK%2B6KHrhOTTqR%0AoWbfsc0Sc5os3ir128s%3D%0A)


Sélectionnez les données "Commentaires".

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1876372326/fb0806c2b66bb06d0795b0d7dfdf/3Bis.png?expires=1788635700&signature=8490021036e742e7239516c5020f783f792407541f9cb6fa74969d34d0a29110&req=dSggEMp5n4JdX%2FMW1HO4zTWkH2IgqCV5BG77SRzVzZ3U62bz8n%2BAPCN%2BK7MU%0AkXaQ9S1kl790fesTHFQ%3D%0A)

> **Attention :**
> Pour importer vos commentaires **:**
> **• Maximum 5 000 commentaires dans votre import **
> **• Maximum 10 000 sociétés sur votre compte **
> **• Aucun caractère spécial dans les commentaires (emoji, guillemets, etc.)**

Commencez votre import en appuyant sur *“Continuer”.*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1876370040/dc450b2f5f7909bbdce00bd00bf0/3.png?expires=1788635700&signature=1deae67ef07ef1d9590de7561740c636972781b1423302d73eee32244bc60cf1&req=dSggEMp5nYFbWfMW1HO4zVkenq2Ff0ZWFd1duzNmsvomBD1m0dNqbac81tdz%0AYffw1Uj0p78wUdykteU%3D%0A)

### **Préparer et importer votre fichier**

Vous accédez à la plateforme d’import Sellsy. Sélectionnez ensuite *“Prospects > Import de commentaires”* en haut de l’écran.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1876384757/b3120b2f45d2fb4b9520de2948f7/4.png?expires=1788635700&signature=88bb8997e73da4f28b42d8f416f42c2ba9a812c4a707cdb8b2ad294682882ff3&req=dSggEMp2mYZaXvMW1HO4ze0uIH2yPYy8h0Dd%2BEUsSFrKZ8CLkdnNaI1GaWaP%0AnXs1uj%2FaMIW0m3AC2FQ%3D%0A)

> **Bon à savoir** : Vous avez la possibilité de télécharger un modèle d'import en cliquant sur *"Télécharger le modèle.csv"* afin d'assurer un import en toute conformité.

Une fois votre fichier préparé selon le modèle :

1. Téléchargez votre fichier CSV
2. Cliquez sur *"Commencer l'import"*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1876392425/30a3bc5feaea94254d5863ab2eff/5.png?expires=1788635700&signature=b387a62a07e0975de2c6bef8aa25ba78a90df32e90f08978373a7593876c1204&req=dSggEMp3n4VdXPMW1HO4zfBVzIoHnIC%2BMZIujRbkBFdF0RhiuSUpSfpZw%2FS%2B%0Ay0GAZO63U4EiWo9Bwaw%3D%0A)

Vos données s'affichent à l'écran. Sélectionnez les colonnes que vous souhaitez importer.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1876394129/1c7c935e40d460d82b7d687c89fe/6+bis.png?expires=1788635700&signature=60f3b1a774b8586ceebfa8681a85c412dbfb308d62a3623a4bf89933236b17c7&req=dSggEMp3mYBdUPMW1HO4zSfl9R3vwileMEYl6k7t6Oe5Zhlu%2BrQ9uQD63%2FVF%0ALNwSjFR4nHofW4HzVO8%3D%0A)

Les données sont ensuite prêtes à être importées. Cliquez sur *"Passer à l'étape suivante"*.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1876396043/8f5cc9402cbedf48d65a5a9f3548/6.png?expires=1788635700&signature=0aa720580ad5486af75f45bb62c0bf94dd51d65377acc435d7fc272cdf1a3952&req=dSggEMp3m4FbWvMW1HO4zYp8B%2FbhFuxSErajS9EsxShtBdFbNJGVEpyPt%2BYt%0AJ9Mo4udxGWh60Jl7klo%3D%0A)

Cliquez sur “importer” pour finaliser votre import de commentaires.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1876397891/c0b4edc08a4e83ea9b0508735b55/7.png?expires=1788635700&signature=0215a3861ed746418106575b304a34553ad02007c265f38389b3e26d3f4259f2&req=dSggEMp3molWWPMW1HO4zfmS7CfmE6zugrsMIgiSqQGtM38auAZbKvAvwNqg%0AZDQJRl1H%2FoTLWywsTPY%3D%0A)

Félicitations ! Votre import de commentaires est réussi. Vos commentaires sont désormais disponibles dans Sellsy.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1876399124/87192b10c9f282dadbe4c094e52c/8.png?expires=1788635700&signature=33616903728f07869b2cabccfc02a088c0d3ec74b716ac137c36606f833142a0&req=dSggEMp3lIBdXfMW1HO4zXs0wAGaG%2BgQsgW58bHZLmY2ZCVC2jMKgWKncILD%0ALwxBHoHtr%2B0AZGgsrfg%3D%0A)
