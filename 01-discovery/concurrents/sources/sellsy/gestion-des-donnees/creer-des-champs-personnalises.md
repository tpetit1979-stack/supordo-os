# Créer des champs personnalisés

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261792296/aa08325112c647b10033aee2f199/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=6782eeadbc93c1dc60f58455ddaa175a0d2dd0b0abaf4ad835223a9099416073&req=dSIhF853n4NWX%2FMW1HO4zS%2BlwY0Uf3V%2BYmnpsYEB2AIHntiIpwimW6xCczSd%0AFVY6%2FvL%2BOhET7Z0gmVA%3D%0A)

> **Attention : **la création de champs personnalisés est réservée aux créateurs de compte et administrateurs. 

Nous allons choisir pour cet exemple la création d’un **champ personnalisé utilisable sur les clients** pour une entreprise qui souhaiterait stocker un numéro de contrat. Les étapes à suivre sont les mêmes, peu importe le type de champ personnalisé que vous aurez choisi. 

Pour ajouter un champ personnalisé, rendez-vous dans *Menu > Réglages > Champs personnalisés*. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446350793/091110023cfd522c7843ebfd/Dn-8OF9SJFMJVg58IMemvi_PqEyrGnLsJ6Yp_PU1Z8C4ZTvPvahA6WiUoKxWUFK9hdj0lpalGONcyg-VhNEx0blLrzcjOja6BJHEo072Xl22sJwXV2wY243RCk1IFqh0EbbTcm2V?expires=1788635700&signature=8aa48161bf23a5d570ecf9f8a0faf3e3e3c57cad8fdba4488ad2963be17dc9e6&req=cCQhFcx%2BmohcFb4f3HP0gHzq51FKt%2FUqKBVvC5MRgckQat7%2FA7m08UvQY8Xc%0AKFv0SFc6319PUo0VOA%3D%3D%0A)

Dans la page qui s'affiche, cliquez sur *"Ajouter un champ personnalisé"*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446350806/b77548a2cee279c6043dfe05/MU0r89IC3JPV5nVOOqBfrUta4HkKINP2Z8jOrMztM8mO7OsecDuGXX9pjJaON8yS9xqSznOAwV-YONawQ_lAHY4MFlM22upxNahmhtxr2yIIcZO_m9nVEFWwRSaykJKQ_fMpMtCI?expires=1788635700&signature=6ed0ec7ce8d20042332e7fdea9113b31ba35209dc58946a7bb4c6e6a8c9274e9&req=cCQhFcx%2BlYFZFb4f3HP0gKVCQfTceX4sl1JEWrdQFIv71cQ61G4ff4tKPkN1%0A4oJyQFpwp0XIp4shuQ%3D%3D%0A)

Comme les numéros de contrat comprennent des lettres, nous choisissons le type de champ *"Texte simple"*.

Le code du champ sera utile pour les imports ou l'API, entrez une **valeur simple** (sans accents et sans espaces) ou **un code**.

Vous pouvez également rendre le champ obligatoire si vous souhaitez obliger vos équipes à le qualifier.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446350813/76dbdd31d14515140e75978d/-B_QKeKuqP_Q8DRzEBFHIdDfQmaFD_KeagmSsd1iOrhPPQY3PoFULBIut04ZEucTrOA5Kv62PjveqYY-I21SCk7A1WShPOO8-JlWgTpVKG11hYrWBff454P8XbmJzYMF7w7gBgRE?expires=1788635700&signature=0cebae2511b48b32ec10b8581947899d85e76ef955e95517f4a5730e1fa85606&req=cCQhFcx%2BlYBcFb4f3HP0gNYYLP9HKj%2F%2B2Mv3pJXS1%2BrTprusRi2Peerx%2BiLL%0APMGuEdJ6WisFxOtfZw%3D%3D%0A)

Juste en dessous, les paramètres généraux du champ permettent d'en définir le périmètre. Vous avez la possibilité de choisir les lieux d’affichage de votre champ personnalisé et son utilisation. Dans notre exemple, seuls les clients sont concernés.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446350820/203e67ccdfc81066505cff39/QrkpbAFaySMB_TXquUhV_8IoQabQKksv3-QsLcfwyJKsGsCnoW2pvVJHFKBW8FTEoLuIghIY6SArXVTqu7ldbLPvrj7vG-gYbXtTrOCcPT6Ac9_Pr1kX38Q9GgFdDp63peICKyln?expires=1788635700&signature=e5d4060db1f6e9b043fc4ec61d159066018b4a47c1c628ade296ae6ab0e7ece8&req=cCQhFcx%2BlYNfFb4f3HP0gNK1l6H6Yw6M9JxjKlSALjE2Bkbvc3Q2Y0%2BoJUVQ%0AuLYSYp9Vm1HkNxrZgg%3D%3D%0A)

La troisième partie des réglages vous permet de définir des préférences. Celles-ci varient selon le type de champ.

Dans notre exemple, nous savons que le numéro de contrat est toujours de 15 caractères. Nous définissons ainsi des limites qui permettront d'éviter d'éventuelles erreurs de saisie. 
​

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446350822/418ca937ba3778c919889045/1ud1EztQfNOsvXw8wEyC4Ff1Lqd9t1jRi0R36WBHyLV5amO2YipQ4FwuVA8_w-zJJRu0-6WM5m0B_YWjj9_1Xj6PAUx6wCXECp19Mb9IqCLBJXTpBKCDaH7Y1HIZvfZvuLB1TXsn?expires=1788635700&signature=63d318a271a59dc63ba03bcd9d44601cbbb2fa863ca9c5924f4489eee08799fc&req=cCQhFcx%2BlYNdFb4f3HP0gCBMMDGa8IdoW3yxGejM0f6buT%2BKd%2BzLE0gCjAkm%0AM1MF9A%2Fr5QbBDc1waQ%3D%3D%0A)

Cliquez sur *“Enregistrer”.* Le champ apparaît désormais dans la liste de vos champs personnalisés. À chaque création de client, il devra donc être obligatoirement rempli.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446350830/0dcc65fff144476c9d42f4b8/BUllGwUvZZgwhUl2MqvzA3cy86mbu6oAOafshje2OD-Ypu3zrkoXYXyfg8x-RdVyfk7hYZIbxMAAv70LFtSLH75Lw35XdEe5v2y59sit9iyLhpeK7Sfuj-xlqUKczEL8M3eXwQmf?expires=1788635700&signature=6a684c4669a7fa6a4678492fc3ebd68892575f04609040519962143daadd6a0b&req=cCQhFcx%2BlYJfFb4f3HP0gHSkdfw0IsasALW1UkXGlBrBlJBGT7UbdWhnjuMj%0AvZRFGAY67G%2FCvJjBYw%3D%3D%0A)

> **Bon à savoir :** 
> - Pour modifier ou supprimer un champ personnalisé, cliquez sur les 3 points à droite de la ligne correspondant à votre champ personnalisé puis cliquez sur *“Modifier le champ”* ou *“Supprimer le champ”*.
> - Une fois qu'un champ personnalisé a été créé, il n'est plus possible de modifier son type (texte simple, liste de choix, choix multiples, etc.).
