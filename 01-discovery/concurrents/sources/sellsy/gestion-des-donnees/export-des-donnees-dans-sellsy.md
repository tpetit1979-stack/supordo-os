# Export des données dans Sellsy

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2142838306/bfc7a038a05c56f72e2895e0e444/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=f2473a4e793b33d1c2a3a0a8e908df6fd20e0892f7f390b2a26deaa5ae4d16e4&req=diEjFMF9lYJfX%2FMW1HO4zR5jzgWeiYMZ0zvE2tCFaxx8R2WHVA%2BgSAu9RVok%0AubdDr2ode%2B%2B85QxBckI%3D%0A)

Sellsy vous offre la possibilité d'exporter vos données au format CSV (compatible Excel) ou PDF. Une option d'export avancé est également disponible pour exporter vos données aux formats JSON et PARQUET, particulièrement adaptés aux intégrations via API.

> **Bon à savoir :** afin de pouvoir exporter des données, vous devez avoir les droits nécessaires dans votre profil de privilèges. Pour [modifier votre profil de privilèges](https://help.sellsy.com/fr/articles/5864116-gerer-les-profils-de-privileges-de-mes-collaborateurs), veuillez prendre contact avec un administrateur de votre compte Sellsy.

___________________________________________________________

### **Paramétrer le tableau avant l'export**

Les exports comportent toutes les colonnes affichées dans les listes, vous pouvez donc les utiliser pour réaliser des tableaux, des rapports.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-1.com/i/o/446461104/9f58f2ba50de47a1d7e36099/f57f4ee9-2bf7-46e4-a5c3-f3a8d36f015b-8a39c324-0144-479d-81c1-1da68a18acfb.jpg?expires=1788635700&signature=c4eb6d2bd77569808198eac3d1fa463509f26eda5e2e0b70c7a252c9d1d1f2c8&req=cCQhEs9%2FnIFbFb4f3HP0gEuyv5BpRtmkzJlTeXIo%2BOMo6r8BMSEQMRXGgPrj%0ArSXqCP5YfYHfdI7SqA%3D%3D%0A)

Si vous souhaitez **ajouter ou retirer des colonnes** de votre tableau pour l'export, cliquez sur la roue crantée en haut à droite de votre tableau, puis sur "Gestion des colonnes".

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446461107/764a3fe89818d4c4e3435187/2c9f134a-7d21-4c7d-b8c4-07a1f47965a3?expires=1788635700&signature=2e530b8c49d042af44e96afbf2dcec7478a7e80eee133afdd296f1af8c9f234a&req=cCQhEs9%2FnIFYFb4f3HP0gMNNAUKh9ltsNDKTXV5JX60j%2BF3HpIsfCEf%2BdJ0p%0AYnFQojKUG6My2N9fCA%3D%3D%0A)

Vous aurez ainsi la possibilité d'ajouter ou de retirer des éléments de votre tableau.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446461110/9a98a2b507601c8cdba7560b/fb547421-11e6-4f8c-8f4a-9cec982353a3?expires=1788635700&signature=ecf7afc7fd83d9ffd1f1be6c33d70f9e06da0cecd95b1862b71cc62d0cd708b3&req=cCQhEs9%2FnIBfFb4f3HP0gOIj5z%2BW754JnQdG3heFTAKMPUJgPwLI9M65Xe8Z%0AIN4Dm6KEJ0qOkhu%2FMw%3D%3D%0A)

Vous avez également la possibilité de **sélectionner les données** que vous souhaitez exporter en fonction de filtres que vous retrouvez à gauche de votre écran.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446461112/c78963383beeb34eec7a2d4a/e4843296-94d0-45f4-8a84-a8d84b61f391?expires=1788635700&signature=d2f21f5d9876436c14a8b54284a0b70e888c6d68a556f9b35e20f9d4af5d3e33&req=cCQhEs9%2FnIBdFb4f3HP0gH0DswtGWVHHqXWuwXjboPUJytdZUt9fA639HkCE%0AMPyzxc%2BEM2U8vjY0hQ%3D%3D%0A)

### **Lancer un export de données**

La fonction d'export de vos données est accessible en haut à droite de chaque liste (devis, factures, clients, prospect...) via le bouton "Actions" :

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2434178242/526eb44bf290d0f12fe0339f2554/1.png?expires=1788635700&signature=786b9e4e2b79b7b4a33775fb91cedc2b0d057533a8cb0295f3a294ceff90fde3&req=diQkEsh5lYNbW%2FMW1HO4zXVEMg9AA5VZmpgTXNv%2BgT6FtCHc7wDyg0bKC9bL%0APdiGYd%2B93CIa4gJc8VY%3D%0A)

Vous avez le choix d'exporter uniquement les colonnes affichées dans la liste ou la totalité des colonnes (selon les filtres appliqués). 

> **Bon à savoir : **si vous êtes développeur, vous pouvez également accéder à vos données via [l'API Sellsy](http://api.sellsy.com/) 

___________________________________________________________

### **Export avancé**

L'option *"Export avancé"* est disponible sur tous les exports. Elle vous permet d'exporter vos données aux formats JSON ou PARQUET, plus facilement exploitables dans le cadre d'intégrations API sans nécessiter de retraitement.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2434337277/53356f76bb7d015ea7d329a7118c/2.png?expires=1788635700&signature=c35498e5d1ae8143074256729e1c21f2b5f5518436c90dc85e2ba1ee20941315&req=diQkEsp9moNYXvMW1HO4zREIUDX%2BjuJKFRbkaaolPkqaasgEX%2FM3FLkURqcY%0A%2BhsDg%2FWS16eoRHG5eOY%3D%0A)

**Télécharger un export**

À la génération d'un export, un bandeau de notification s'affiche directement dans l'interface pour vous informer que votre export est prêt. Vous pouvez télécharger le fichier immédiatement depuis ce bandeau, sans attendre la réception d'un email.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2434337738/457a1af3c2ad4bad3220b04eba54/3.png?expires=1788635700&signature=7b121cc37f386de1d81f16dc76bdef9856095d6167e85a7c4a7997b67219f350&req=diQkEsp9moZcUfMW1HO4zcKBvmIHeaRsI%2BW8rlO8mFrhZQetvtsewLJR01W9%0ACqlbRSji%2BIsSXKe0cU4%3D%0A)

Un email de notification vous est également envoyé pour vous informer de la disponibilité de l'export.

**Retrouver vos exports dans les notifications**

Une section *"Export"* est disponible dans votre centre de notifications. Elle vous permet de consulter vos exports récents et de les télécharger directement depuis cet espace.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2434341948/9295f78eb9ef2fd19aff8db4fd2c/4.png?expires=1788635700&signature=7a864d839f027082bd7a29883a0d553561cecf01bae3f8659c08c81efdb5293e&req=diQkEsp6nIhbUfMW1HO4zT8gRB%2BNiXpiQcLX9SR7qQZ4N%2FIh0Ktw3FySKRi0%0AfAK3Os7FzoEmc4KfQbM%3D%0A)

**Gérer l'historique de vos exports**

L'ensemble de vos exports est accessible depuis *"Réglages"* > *"Données"* > *"Export de données"*. Depuis cette section, vous pouvez :

- Renommer un export.
- Relancer un export existant.
- Télécharger un export précédemment généré.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2434343980/615d54314a44c7639fd51c64a970/5.png?expires=1788635700&signature=86321057d8c0061db4642a5e1c41e23555daa6193b323f47716c26665d553d7f&req=diQkEsp6nohXWfMW1HO4zcVAJJgAZktfeDLYnhCox%2Fo1NYQEIuizTA%2BgfKrr%0AC0CO3tkJD%2Fl3O8oaAp4%3D%0A)
