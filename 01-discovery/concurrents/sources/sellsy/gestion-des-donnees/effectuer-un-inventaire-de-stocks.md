# Effectuer un inventaire de stocks

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2142766347/089a593ffdbfa32017b0073d9be5/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=c125202f4ca609dcb1180fd97461e5cb1645e2e25f4b34dc8dd5bb79bfe1f437&req=diEjFM54m4JbXvMW1HO4zY5W1Ips5TzaRdBOg5iR1YClCWcOLs3RxsroDAgn%0AA9T%2FsjgWVHjbSi%2BVLGc%3D%0A)

Vous pouvez à tout moment effectuer un inventaire de vos stocks. Pour cela, cliquez sur “Stocks” dans le menu principal, puis “Inventaire”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446367641/6a91e6d29e7d8813ead6f108/roRGGq0Xl0F0_wJ5w5A71wyj_efRMW2NUXzOzT11a5tnZOl2W17ug-mvfFa9ethJxqB0iiTTPXg4fvrkSzFSsUSHSsd4qRJ-JQ5bCgWA0Ld7npyhh56z1a-UhqnpBMVbCkNcVjb2?expires=1788635700&signature=36d449b3c2b587ae0518fc8fed1e139bc98ece374e33b591edd10bd86c3c408c&req=cCQhFc95m4VeFb4f3HP0gFLDZv3Z4gGi%2FsxUn2bRpTIOrzFtPnrR27k4dRwW%0A8oq%2B2kGj%2BdbPmngikg%3D%3D%0A)

Dans la page qui s'affiche, vous trouverez des précisions sur la procédure.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446367651/4d57474c4743e18b5b8406d2/4SfA2BXuzAFrQW9zCjTXHEbNu-XqDVl1gfQ0ABE6zJmJBnSCq2ayVaVzLI223TWhrVrfmB166Avrz4Rztt702fzr-d6WsyR9_VMh-StjmQ6O7pFxnHAK3oUY7KzcwWfEOrMIXw83?expires=1788635700&signature=dd168bcb9bd37c06d0c1f6a8051c014f9a77f107624b0b759623dbe6c0cdd358&req=cCQhFc95m4ReFb4f3HP0gF4LMcDPtsf5wO45tT8JaXwQqVpwnq%2BDSL3tQwsB%0AFfZnZaL26RoogWCwYA%3D%3D%0A)

Pour commencer, choisissez les produits que vous souhaitez exporter pour inventaire.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446367657/a0477975a774bb12db0ee6c7/1Su0L-KChOPMfDJ9Zs_zL8i7Vn367RhM5pb3m0Pbjpe8QoG2JqWRZ0p5uFPhGVj0fnmHP2EAgBDuE7I49A9lKvfHG-qlTBgy4_O8wA4nL9G0siYBcvdQSGWywSOLaE6tHmCXjZVz?expires=1788635700&signature=a559fddecb162f6824c24e8e7a78c72ddfa8a7d4afde8dd8dcc492d7101e74f7&req=cCQhFc95m4RYFb4f3HP0gNS3MNL8KAwJdkrq1auKdzeVSBUdxJYGitNW0uq5%0A0%2BqauyVLoLUqsKn0IA%3D%3D%0A)

> **Bon à savoir : **vous pouvez également utiliser cet outil pour activer les stocks massivement sur des produits de votre catalogue. Dans ce cas de figure, choisissez l'option Produit sans le stock activé.

Quand vous cliquez sur le bouton télécharger le CSV, un fichier est directement téléchargé sur votre ordinateur. Il vous suffit de l'ouvrir avec un tableur comme Excel ou OpenOffice.

Il ne vous reste plus qu'à effectuer vos modifications dans votre tableur puis d'enregistrer vos modifications.

Pour mettre à jour votre inventaire, cliquez sur “Plateforme d'import”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446367662/700e72e1551cff4da6d43d92/-cPwrpj7zsWTCsSs5V3fKp4lDL2EB1pGQjxRt64k5xiNGUC069b-GYLc-y9o3kWArcbnwqagTHMASi0V8Rxu8yMH3oxWjuM9m_KmCStQQuRrJM9JyXwVWR7hk1cea1YJXkOYO4nM?expires=1788635700&signature=2b02a6b68de7842b486d7c81e42234b75d579a7eb30be9da43365afe5564eaca&req=cCQhFc95m4ddFb4f3HP0gElUS%2B5FOLeDYhM4aYwHgVq%2B00S4873qo0Itgzxt%0ALF%2BnLBk6SqJFFVjujA%3D%3D%0A)

Vous serez directement redirigé vers la plateforme d'import. Il vous suffit alors de choisir votre type d'import dans le menu Inventaire.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446367669/e90629285da2fcfb52d6d2e0/N2RXCP3zcfIHDwb-Cf9ywDZJ9pv30cahVFk049Dc9LmZLeENKEOWQS8WLDoUq2_m3Lwnu6ip6lxI0DpB0fvGXrNyViWaDj-oRCgPh-Ww8JxCuEoI_Elqf-jU7i84dzrp0lNsnlu2?expires=1788635700&signature=7a21345fd405617f7d8e21389cc1924101b0358da09c6de71ba52718e76df7fd&req=cCQhFc95m4dWFb4f3HP0gLridas0OHNUnwx9jVrn6nNgt0w%2FMHqKhiu9ySc3%0AOGCrZK8UNQjc%2Bz1h5g%3D%3D%0A)
