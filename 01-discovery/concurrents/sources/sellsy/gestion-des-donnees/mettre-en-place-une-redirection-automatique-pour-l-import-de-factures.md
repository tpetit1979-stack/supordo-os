# Mettre en place une redirection automatique pour l’import de factures

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2154756748/ada70c9ddfeb4028a8b622eb16ad/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=98daeb2174d0544b510997ca15946156d8c58454d1af32ce298ef371b340982a&req=diEiEs57m4ZbUfMW1HO4zX8DP6WeYg6fF6wl7SkNI7IQ2kp7gzpSFQVjEY2g%0Awp17ng1liHh3RmDQ0Co%3D%0A)

Pour être importées automatiquement dans Sellsy, les factures peuvent être envoyées depuis une adresse e-mail associée à votre compte Sellsy.

Si une facture est envoyée depuis une adresse non associée, elle ne pourra pas être traitée automatiquement.

___________________________________________________________

### Contourner cette limitation

Vous pouvez contourner cette limitation en configurant une règle de redirection automatique depuis votre boîte mail non associée.

Le principe est simple : tous les e-mails (ou uniquement certains e-mails spécifiques) sont automatiquement transférés vers l'adresse e-mail associée à votre compte Sellsy. Ainsi, les factures sont bien reçues depuis une adresse reconnue et peuvent être importées automatiquement.

___________________________________________________________

### Configuration de la redirection automatique

La procédure varie selon votre fournisseur de messagerie (Gmail, Outlook, Microsoft 365, Yahoo, iCloud, etc.), mais le fonctionnement reste généralement similaire.

**Étapes générales :**

1. Accédez aux paramètres de votre boîte mail non associée.
2. Ouvrez la section *"Règles"*, *"Filtres"* ou *"Transfert automatique"*.
3. Créez une nouvelle règle de redirection.
4. Indiquez l'adresse e-mail associée à votre compte Sellsy comme adresse de destination.
5. Enregistrez la règle.

Vous pouvez choisir de rediriger :

- Tous les e-mails,
- Ou uniquement certains messages (par exemple ceux contenant le mot « facture » ou provenant d'un expéditeur spécifique).

> **Bon à savoir :** Avant de déployer votre règle de redirection en production, vérifiez les points suivants :
> - Les pièces jointes sont bien conservées lors du transfert.
> - L'objet et le contenu du message ne sont pas modifiés.
> - Testez la règle avec un envoi de facture test pour vous assurer du bon fonctionnement.
