# Importer les catégories tarifaires de mon catalogue produit

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2142760102/fedf7c9cb2f6e1bce9fce75de9d2/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=13471d95135bc756c8e0537dc4606d7ed7bf6c70b4f96bc0885765a49470e2e2&req=diEjFM54nYBfW%2FMW1HO4zT5hVKVhjK2kZRHRHxD1tzXAqoa%2FE2kIHlkZROXQ%0ARfc5%2FvWhJdKOONEVGOE%3D%0A)

> **Attention :** les comptes en essai peuvent importer 100 objets maximum à la fois.

> **Bon à savoir :** afin de pouvoir importer des données, vous devez avoir le droit “Autoriser l’accès à la plateforme d’import” dans votre profil de privilèges. Pour [modifier votre profil de privilège](https://help.sellsy.com/fr/articles/5864116-comment-gerer-les-privileges-de-mes-collaborateurs), veuillez prendre contact avec un administrateur de votre compte Sellsy.

### **Démarrer un import de catégories tarifaires**

Avec Sellsy, vous pouvez très simplement importer vos catégories tarifaires. 

Pour importer vos données, cliquez sur “Menu” puis “Réglages”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867425918/2abf43e8b14ff52f4bdbafb9/mcBS5yzM36Di63xFL8nkvhUTuFKGGbDRzT8Jk-TiKTDLuMdM9v9h9IcgrIShVQDbVxKeabaMHpaugdAoV1qtA2lku2m316U9WRf96asQoSefuwwEys7rmzrNKaAsk83hMXkZUYhwqIcLJ7k4JUVikLk?expires=1788635700&signature=fa36c9d53c7c813812abffa5ead35f552acbaf3b9930ac11e04d91ad55cab1c5&req=fCYgEst7lIBXFb4f3HP0gH6065A43cxLz4k2bP4j3N4zM%2BUGM8Piizn2eqxF%0AeiKJyB4UBZsbg3DxHA%3D%3D%0A)

Ensuite, rendez-vous sur “Import de données”. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867425931/fa195a8f2bfca8e85e976e61/W9zzNz6OCflkotjlk0MxdOYX-IzdgJlQvuKc8EwQo1rZf0LTidHUUhF4S-7OCc5B9r6Ww-cIZbiXgcOOENuPYyr3DW0pMhffw3I7WvL8Fu8tXcVcCfbtcydD1tFlpGd7MZ0JHN4453ofZ9ACjPgkkec?expires=1788635700&signature=c467fe15ef6694c054fdaa42cde9494cd57c8da4a0c6da7170d2bf58470a7b71&req=fCYgEst7lIJeFb4f3HP0gG2ntuHMv%2BX%2BmPQ15sKh6UDZ%2BYA1P6Lfb9Z7AuaG%0Agmn9Y6kkwUV0a8Q8zg%3D%3D%0A)

Vous arrivez alors sur l’interface d'historique de vos imports.

Nous vous conseillons de lire les informations présentes sur la page d’accueil avant de commencer l’import.

Puis, cliquez sur “Démarrer un import” pour choisir quel type de données vous souhaitez importer.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867425949/51b92f1e82fa54399520068d/JdUdPWWUIfFtMrKpTkPOQ0j5jgiiudKr4-P6qMJcWNlf6QDgMxsIklA5AdN_c4bdkfjCnedcJBksOsgeYkgWP3kF4drADoMRWJn7RSQE_d2CeiCQmzzIhP2rH-Xju64EGsQD9c_zc_qJ9X8OT6S6p5s?expires=1788635700&signature=6900f30cd568b1b68245fae1c0076013eddd627171fd1201d3c6ab3562edd2ff&req=fCYgEst7lIVWFb4f3HP0gPtnRLt6kcp%2BtWUui7QmqeTk%2BEuwBNMcBYFdXKBt%0Ahlu6%2FgjKzPAzCnrkMw%3D%3D%0A)

Sélectionnez les données "Produits > Catégorie tarifaire" et commencez votre import en appuyant sur “Continuer”.

![](https://downloads.intercomcdn.com/i/o/991516834/8c31040b0ed27250cbaefe9b/cat+tarif+produits.png?expires=1788635700&signature=e0d9a1d4457c70a08e71bc6969ac8e5599162cd713d71d94fa559a8afda90bc2&req=fSkmE8h4lYJbFb4f3HP0gEkyOGbtghtOVqXR2VedaIqoUc40Zv9%2Fy%2BBGTY2u%0ASZdORptJbvQ8%2BPCgJA%3D%3D%0A)

Ensuite, vous accédez à la plateforme d’import Sellsy. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867425985/dc2fb91ef0992e49a90cb8a5/OmkPCK_R01bmVW9lFWIvrWEmlnIA4tPUdyXnUFx8EK3ovpUKjztnptgJQMGQb9iKR4pd97TscYer89ux7boDTIoxfkkrSMaBBGuhC8oSf6tm1VZqDAjhjb6ZTQnrnABBSwij3WSEb81VON5XkjyG-Ao?expires=1788635700&signature=45d7fbdad487823c8bbbce6557836afeb18506f3c227372e0f8b34cc94890783&req=fCYgEst7lIlaFb4f3HP0gEp24X4eGi1mOzl5gmPm2swc%2Fy6sX8GJ%2BFJJdGXf%0AxxxQjol7SkSEdF%2BteQ%3D%3D%0A)

> **Bon à savoir : **Vous avez la possibilité de télécharger un modèle d’import en cliquant sur “*Télécharger le modèle .csv”* ou “*Télécharger le modèle .xlsx”*  afin d’assurer un import en toute conformité.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867426001/2deb851394907fbb9e917035/18cWts35v0ZJEkSZrMR1VT8eTIbMWJmGfPiazz4pf1K0bnrdOFvBH4X7H0fgJ0KOrY7zfSOlT0H3Cw1pM-k7ii_Orc_ZNRXAMlJH5PfIS-KnTmGDz1EriJ38jyauVB7EUI4yiYhgw6u0HoIbI7W8dg4?expires=1788635700&signature=b0560b34a866f5adf393943a0c9e54f104a395cfe2487aa5f507cf7102f73eac&req=fCYgEst4nYFeFb4f3HP0gBSoDt0SZzqg%2BuJbdiyUscD0vvBC6QsvNo8TZDLq%0A9XTmknwWOy0FFKWVnw%3D%3D%0A)

Une fois votre fichier préparé, cliquez sur “Continuez”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867426024/39ec9327209d48d5058f0441/8lKBpJ0BFK_cuqFV3tmiJCsng2blPxNwEhxFjRxHedobUzkTPCpPtNek41C2l9kEfj9VjQcyeS6L9EcIuEc-_zfwk1YSVq0Q60Umtny74HMzVpJeV4uxMP1AuodbLmwWA-vO4M7uyjE4xnO6FO0cuPk?expires=1788635700&signature=16a1fbdd069c328da5bfd57c9b210c6fa71d0c77efc49aacc0a00814d3a90805&req=fCYgEst4nYNbFb4f3HP0gFJ5AIgVXRP5lC823LEf6IxCs36xWj2fZPu7W6nl%0ACuWEwI5EqDs4q8kn4Q%3D%3D%0A)

### **Configurer les paramètres de l'import**

Dans un premier temps, sélectionnez vos critères de comparaison afin de déterminer le critère sur lequel nous allons déterminer si un produit existe déjà dans vos données Sellsy.

Vous pouvez sélectionner votre critère de comparaison pour les déclinaisons : 

- **“Référence Déclinaison” : **Référence de la déclinaison produit unique sur lequel la catégorie tarifaire sera mise à jour.
- **“Identifiant déclinaison” : **Récupéré uniquement depuis un export Sellsy.

Ainsi que pour les produits :  

- **“Référence produit’ **: Référence ou code du produit unique.
- **“Identifiant produit” : **Récupéré uniquement depuis un export Sellsy.

Puis, cliquez sur “Continuer”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867426057/50e59311d8e84630d6633d25/oQFfRSHT6bD1ROnGM8If_JZ_gIyqhrl1ZdCmzGPOLtcecSYo6lu8MktuzQw9IiLCFQBOWfTTBGURgH-CFlLYPgCiA9SMi8CDacBYtRhGANcMd76P5YoIFAkJJaoPLduWOsWmskWF01rHMX6YIJpv1bM?expires=1788635700&signature=6af9952a3f9bfaf9dc0b198a13507c80b6c199ab699efd10c5da4ea87532a94c&req=fCYgEst4nYRYFb4f3HP0gMOtNZ8YhmKMYAdo%2FYSpi8MewmcFKg569Gwy%2B5fg%0ATemeddXWzpeaeCdZew%3D%3D%0A)

Par la suite, sélectionnez en détail les paramètres de votre import, afin de déterminer les actions que nous allons effectuer lors du traitement de votre import. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867426090/9b2ee1e07480c6847cec48f5/gUMV8PuFfagqBcbM9xLT1dV7Y7XgqYs_iAqMzgiYDXwYFx2-gL4IhhHhDXlRYQOg2W7vtCAVEl8e2zLLRHwupt6XK1oawEaoAaO8rbyOLcPEWVAUL4KuadjP-c5pc3Y-m0wrD1rZCA4C2mGfAZ-bmo4?expires=1788635700&signature=067964792938dc23ca2067751276681e5c0020a2cf8f25e437f15fc117f4553f&req=fCYgEst4nYhfFb4f3HP0gHbqkn%2FBfLISwd%2FbTennGAVC68T6OEINnMevuWl3%0AIWVfGPYK0aWeltuHLA%3D%3D%0A)

Concernant la mise à jour :

Si une cellule de votre fichier est vide, vous avez deux possibilités :

- **Ignorer et ne rien faire :** La cellule du fichier est ignorée et n’est pas importée dans Sellsy.

- **Remplacer par une valeur vide : **La cellule du fichier est prise en compte et une valeur vide remplace celle existante dans Sellsy.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867426122/2644294b97db0f172d96ad78/ydlf2vpPiT-840SFns6kXm_c1r5o_qQEFw-PFj1iimlNcsb0cuq4_pyQP5Cv-hKJb1egraQHFVNrM0ROTlQSGWBjsscDZUzfKuno6qm9KPdYxQG6lcFf-EkSE2C2okggCxma4I65dy1JYlRLfRYOsrw?expires=1788635700&signature=db5d4b87073ef847e211cacae25e4d67cbcbbbce3480599303ff88d84200633a&req=fCYgEst4nINdFb4f3HP0gKw1SpWP1zVjWknB0%2BST7vUXNf6BexucZDO2xwId%0AsQXb1YN%2FVK%2B9xgceEQ%3D%3D%0A)

> **Bon à savoir :** En survolant l'icône "i" au bout de chaque ligne, vous obtiendrez des informations supplémentaires sur les différentes options possibles.

Lorsque ces paramètres sont sélectionnés, cliquez sur “Continuer”, puis sur “Importer mon fichier”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867426140/04c75e338e833c609bfea0cb/yv4PJmHhflvJ7sJWe0L-0xZpRqmnLUz7ZufzjUkqi0EZSTSupV-FW3RFZLOXLNqdOecQM7t3WCSFUwNJIZFVLVAa_mamRx0yFgvY336SGJs5M7TbzVoR4MsDLFiEmAFBwjJFZAqXjdFznFqjEV7aKDk?expires=1788635700&signature=f62b44cba4e3bfc01de6165b7b612729b9f6a6c54f42bc83baba9419ba9f34b1&req=fCYgEst4nIVfFb4f3HP0gFLCZ72BCQN85GWNpCQolCEacc10Om%2FbxWCjfC5h%0ApZrgttqcuftv4S3Q7w%3D%3D%0A)

L’import de données peut se faire de deux façons : glisser votre fichier directement sur l’interface ou choisissez-le depuis votre ordinateur en cliquant sur “Sélectionner un fichier”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867426159/d02e11494d6af288226836c9/QSUXTk5UJ2FWp0updB8gf4zAKSPjA4I8-oGy6PrClMnQ-Ob4PVZk40be3y0v5dPqWeFL4LCAzyuYdny6VyhJzCEwrB0lDHhoreUHzUc3I_Dl0FZB32yoWstvxndpT5HU8Oqm7MRHY0JwtuIksUmel2s?expires=1788635700&signature=4052dfc97e97873fda6fbc5f6e820f8d3a08efcdbe92f50d2ff6e392a970af6c&req=fCYgEst4nIRWFb4f3HP0gHGNURP4loMFjeKdI%2BOq0o3smyzNt%2Fzl2tTiS%2BwC%0AVqRHTCREB%2FB3FxUi9A%3D%3D%0A)

Une fois sélectionné, confirmez ou modifiez la ligne d’en-tête de votre fichier puis validez en appuyant sur “Continuer”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867426196/9f73cd608cc1581bd70025b5/bkOkycG9n0--FC0KMbPwgvDskIrZ10KJ_j8CzWcVbRdrqZ_IPSBMPQxCMkyQmRL_wj2e3fygGP3YAlfqTZ7-YoiR84j__HpJNT0oVZM0OgFJU6t5n_Tjct5nGwbHmYI-BsVddY-s6PpsAIQNfJYE2vE?expires=1788635700&signature=af09a5dd5eb2d9f153fb6754ade3c216f4ca083753c714e3ba6639c602af309e&req=fCYgEst4nIhZFb4f3HP0gOkkEMaMoAL4uYkaK9xvbM6B7nEaN5j0Vk%2BiH1Sw%0A8HCFDmpYXI2V7HzwsQ%3D%3D%0A)

> **Bon à savoir : **Vous avez la possibilité de ne pas sélectionner la ligne d’en-tête de votre fichier, il vous suffit de cliquer sur “Ignorez et utilisez des signes alphabétiques comme en-têtes” ou bien d’aller sur le carré vide en haut à gauche.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867426216/92782ff8545316a2974ff076/cdTZ_hHbSUEJ8dfGysxQIvu1zF9mPqbUhgCZgGbqd0j55WK0A7FcDhT4-d4iVTaZx6iG5TWPsoExiCa-k95Q4pghwg6wWDmuHaa7zuF_3aFU9YGH3ZbaMqaK9veWEzKK-ku84-XhSyC-klCAXc345Kk?expires=1788635700&signature=8092a37089e03701133399c25dbb43aa5bcb8a984c29ee062154488a7b3aebee&req=fCYgEst4n4BZFb4f3HP0gIcoIdPyAla6uhPlFsOfa2EPa1jxYUpCUdAaU6X6%0A4%2F4Yfx9oIJvvKDhrwA%3D%3D%0A)

Puis, si la correspondance de vos données n’est pas tout à fait exacte, vous êtes amenés à faire correspondre le nom des colonnes de votre fichier (à gauche) aux champs du template correspondant au type de données sélectionné (à droite). 

Pour finaliser cette étape, cliquez sur “Continuer”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867426242/a25417b6ab3886e8c350d54b/fCrMH7SwMgASHQhNvn5R1LsB0tvfHQjw85Nlq9Itd2eU7fokQqlytm4Or8Bu8qNINwBmQNOZZk8k4f9rRz5YjRzYplUBsH371tOTI_CUSGfb4IWHLtiJkI6LcMbGNWfu3Kp4REqtGQnjiwNZO7Mv4Ks?expires=1788635700&signature=0abb89624c9218c68f75eec114aca22e1749698d999048fc78c082df5f62823a&req=fCYgEst4n4VdFb4f3HP0gEG9M0HDcDzv3%2Fb%2BbRyni1cf5xdzKd%2FDuhKavXq3%0Aum2%2FMCXaW86wCCdY%2Fw%3D%3D%0A)

> **Bon à savoir :** L’import réalisé apparaît dans votre historique avec son état d’avancement (en attente / en cours / traité / annulé), vous avez la possibilité de cliquer sur “Voir” pour consulter l’ensemble des détails.
