# Éditer les valeurs des champs personnalisés en masse

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1879051871/591ee8eeb63f98fb1d915bb861f2/FAQ-Bannie-CC-80reAcademy-2-2B-282-29-2B-281-29.png?expires=1788635700&signature=ce02ca5dca9ccfd49a7abcbd2340c7c7c253a3abec05bd754b197bb3b136a20d&req=dSggH8l7nIlYWPMW1HO4zT7O0yR0ae%2F3fyRJZcUDBVaFsTMk1LfMMJ3GCxe4%0AzF9rJqdCw%2FDuh82rtbw%3D%0A)


Nous allons choisir pour cet exemple l'édition, en masse, des valeurs des champs personnalisés de plusieurs clients. 

Les étapes à suivre sont les mêmes sur les autres types d'objets. 

**1. **Rendez-vous sur la liste des clients.

**2. **Cochez les clients pour lesquels vous souhaitez modifier les valeurs des champs personnalisés.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1580399519/2d6724d88f6089229f83eefa4bca/1.png?expires=1788635700&signature=05d0caa1b03d4096838a56523aa5b92a1007c5853b03b2a6ed9521997e74f779&req=dSUvFsp3lIReUPMW1HO4zdmEFqRNm4sWS2eRq%2BsTKiHHDxwcB8Mzw4QVzZQe%0AX6blPi%2BbbrWZIw%2FBl7E%3D%0A)

**3. **Dans la liste déroulante nommée *"Choisissez une action à effectuer"*, sélectionnez *"Éditer les champs personnalisés"* puis cliquez sur *"Valider"*. 

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1580403222/a5c3f48c8ec97cef5594c2f84b17/2.png?expires=1788635700&signature=0205195e96f96e14e22c0445d6b6f4cf3994b71ed8ed21e8bf65d7fce695a194&req=dSUvFs1%2BnoNdW%2FMW1HO4zRpoUsklQXNV0onX8QwwlVh1Vwe1axsVVeLyWuMh%0AKF5K0LPnlpE%2BWdpoGa4%3D%0A)

**4. **Sélectionnez les champs personnalisés à modifier, renseignez les valeurs souhaitées pour chaque champ puis cliquez sur *"Enregistrer"*. 

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1580405641/a1c0c9797b8f6b363374c05537f6/3.png?expires=1788635700&signature=247676a51a36aa634c4b9abecfcdca97b376de03a5f1b2db9de0da5433eead78&req=dSUvFs1%2BmIdbWPMW1HO4zZ%2BcSBww3lvd7eliRb74GIeSCAwCt7HbYXWY1S%2F3%0AnenwdTMnvtoFa9s0XV8%3D%0A)

> **Attention :** L‘ensemble des champs personnalisés sélectionnés dans la liste seront modifiés.
> Les champs affichés mais laissés vides seront également appliqués.
