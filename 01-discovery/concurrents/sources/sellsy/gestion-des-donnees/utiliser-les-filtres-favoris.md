# Utiliser les filtres favoris

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1879059821/0007272a064df3e89cdaa7d61257/FAQ-Bannie-CC-80reAcademy-2-2B-282-29-2B-281-29.png?expires=1788635700&signature=cac754bddad47a59654f67b042abbfb871fb91b5bd95855bed8a28ba56272e00&req=dSggH8l7lIldWPMW1HO4zZTT1SEAI%2B4i8Ee5Cw4k8EnxJ5%2F0wlRWq9I4XJM8%0Ai7FnekKcMve5JYkUrTw%3D%0A)


Les listes vous donnent la possibilité d’utiliser des **filtres favoris **afin d’accéder plus rapidement à vos données. Voici nos conseils pour profiter pleinement de cette fonctionnalité.

___________________________________________________________

### **Rechercher un filtre**

Pour utiliser les filtres, vous devez vous rendre sur une liste : prospect, client, fournisseur, contact, opportunité ou devis, facture...

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/457822036/47c168d7a85c3d0b04a8c4a9/foYLC5nmk_8g3HlX8EX-TE01EoQ7jgLqEGayChllr47sVibvc5LfEZQfak046g2vlS2dd7DOtXXGh2HBO_69e3r5SD6QJl5Xvyx6_CdS0Pce7pqm9VWQfddm-sUn_BiAJlDTf0pD%3Ds1600?expires=1788635700&signature=8fbc68c5068f15f6f6184a878e4cb5533c9ec5d8cda5bec80186e045e3e69024&req=cCUgHst8nYJZFb4f3HP0gHrAF9vHGUefNuEiQoWxGMtUc9guy8qI%2F2n5sXxu%0AeByBkYQqonNH%2F8zgsw%3D%3D%0A)

La liste des filtres disponibles apparaît et vous pouvez chercher un filtre précis parmi les champs réguliers et les champs personnalisés.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/457822046/0ca8138abd50410372be2b9e/e9d1cca1-64e2-4c55-b052-169cc5821081?expires=1788635700&signature=338feb5dab8ea2f0264f2d4381b137c57d5845271d20e64161622a6c8ea0a493&req=cCUgHst8nYVZFb4f3HP0gA2FqQK0fjQzP2Yfk7yIjum1fW6eeD2OQNNF6ngF%0Az3gFUJ8V9AY50Ua%2F2Q%3D%3D%0A)

___________________________________________________________

### **Appliquer un filtre sur une liste**

Si vous souhaitez **appliquer** le filtre propriétaire à votre liste, vous devez :

1. Cliquer sur le libellé  “Propriétaire” dans la liste des résultats,
2. Si vous appliquez le filtre propriétaire, vous devez indiquer les lettres que contiennent ou ne contiennent pas le nom du propriétaire.
3. Une fois que vous avez ajouté ces informations, vous devez appliquer le filtre en cliquant sur “Appliquer le filtre”.

Le nouveau filtre est maintenant appliqué et les résultats s’actualisent dans la liste des sociétés.

> **Bon à savoir :** Vous pouvez appliquer autant de filtre que vous le souhaitez.

___________________________________________________________

### **Enregistrer mes filtres favoris**

Une fois que vous avez appliqué les filtres sur votre recherche, vous pouvez enregistrer cette recherche en tant que** favori**. Pour cela, vous devez cliquer sur “Enregistrer en tant que favori”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/457822048/90bff1d01f7c1f29f2bc4ece/bd449a74-4dcb-4338-877d-08000e71899f?expires=1788635700&signature=1d1d26766a9dd53432c2b680544f93a499e54cdb32b13b0d543e9606f1ae84e2&req=cCUgHst8nYVXFb4f3HP0gD2dsHtTKIPTqEUpbk6fYw9saNR6UIkh2eH8FQe3%0AA%2BwF%2B53F6uvEjVKbXA%3D%3D%0A)

La fenêtre suivante permet de définir le nom du favori et de le **partager avec vos collaborateurs**.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/457822059/55a987ea6c0f5c57367b7833/-XPv8ZW4AgjxksPyJR4yDtEN7RtCPVW-D2zSiwwDUDNnStGq5IcKyAE1NOsTourjaiLvTLpvuGVcUjvjQ-R_XHil9mwV5WYEXTuh4crRFbS6nTlRc1C6p3p6bHlqvVAKodfSwud4%3Ds1600?expires=1788635700&signature=7814fb05aebf258e17424dc4d1057cbd79cac9180b6f7aa7031af200445eced9&req=cCUgHst8nYRWFb4f3HP0gAKKSI4jmAeQjUnMeQ0HIw9ELUmwMnbzic3aUZmZ%0AZVxLinVOMWvYbI4ezg%3D%3D%0A)

**Partager vos filtres favoris** pourrait bien faire gagner un temps précieux à vos collaborateurs. En activant le bouton de partage, ils retrouveront dans la liste de leurs filtre en cliquant sur “voir tous" l’onglet “partagé avec moi” le filtre que vous avez créé. 

Ce filtre favori apparaît maintenant dans la liste des favoris et est **défini en raccourci automatiquement**.

> **Attention :** Si vous n'avez pas la possibilité d'enregistrer un filtre en favori, veuillez vous rapprocher de votre administrateur afin qu'il modifie vos droits dans votre profil de privilèges.

___________________________________________________________

### **Gérer les raccourcis de favoris**

Par défaut, chaque filtre favori est ajouté en raccourci et apparaît en haut de la liste des filtres. Vous pouvez** supprimer ces raccourcis** si vous utilisez rarement certains filtres.

En cliquant sur les trois points à droite de votre favori, vous pouvez supprimer le raccourci en cliquant sur “Enlever le raccourci”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/457822069/c15054b4135f359dec5c5ff9/8c31c891-e115-47d1-9534-16f476bf8135?expires=1788635700&signature=523a740a67c36649f03d9d8d6b8d3be383e9df0698655bcdfcfab4e686697c00&req=cCUgHst8nYdWFb4f3HP0gMfeGNHae9dGWRJLgl1%2BvhOhXHKCg8NJRmxxa4pK%0AXM%2FyDiI%2F0bMH%2FBCx5w%3D%3D%0A)

Pour remettre un favori en raccourci il suffit de cliquer sur Voir tous, de cliquer sur les trois points à droite du filtre et cliquer sur “Mettre en raccourci”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/457822072/b2790f158e3207dc14be8de7/e48f2ba1-fc34-4ae1-baf3-abc6aa68de07?expires=1788635700&signature=079510f05bba2a5bbd6de31b9dc2ce81ce0b1beeb1819460426edec52b705c69&req=cCUgHst8nYZdFb4f3HP0gG0jxoNFMVyZ3JLNSNm5y0iNxDOBete3nB67zJh%2F%0Aijx%2Fu3w5diaDELePIg%3D%3D%0A)

> **Bon à savoir :** Pour créer vos propres filtres, vous avez la possibilité de créer des champs personnalisés. Pour en savoir plus, cliquez [ici ](https://help.sellsy.com/hc/donnees/creating-custom-fields)
