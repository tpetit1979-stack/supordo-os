# Afficher un champ personnalisé sur un document de vente

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261793957/e5d87b8728c59649e782f9f60043/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=4a60dedc6c5de345c64f7816d7ee013609c21172891786f755a7fc06c81c2c6b&req=dSIhF853nohaXvMW1HO4zULSTCImDot76DWq8pFj86PF8DfEYQjj%2BLLtxsl4%0Afl%2FtJT0XXjzCvWhTU0Y%3D%0A)

Avec Sellsy, vous pouvez afficher vos champs personnalisés directement sur les PDF de vos documents.

Deux grandes fonctionnalités sont disponibles : l'affichage de champs personnalisés à la suite du document ou l'affichage de champs personnalisés produit dans vos lignes de document provenant du catalogue.

___________________________________________________________

### **Affichage de champs personnalisés à la suite du document**

Vous pouvez facilement définir l'affichage de vos champs personnalisés depuis les paramètres du champ personnalisé. Rendez-vous dans *Menu > Réglages > Champs personnalisés*. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446353258/3bf1bd80ae69b987d9618953/c3y84bIS2XWI9O3K7y6s9z3VGiMp5uICGMmkNXGPul0Yu11YYPnnyAR6iwg53e0Kn4RGX0N-fflZghyTU2J_uIfAQ6epKuIuwi5gUTYo0492I54h-07SFNnALNiA5-gSPc8h80ul?expires=1788635700&signature=f74a61db0427deb040bd321a3491838768ffff6b9f6c1c39523b2dd633c4f3c0&req=cCQhFcx9n4RXFb4f3HP0gGqiaF2wblmpfXjoAeg58maleTHf8GK4DSRCzvmv%0A9DAvZ%2B6u9HsRQhzmmQ%3D%3D%0A)

Vous retrouverez sur cette page la liste de vos champs personnalisés. Pour modifier un paramètre de votre champ personnalisé, cliquez sur les trois points à droite de votre ligne, puis sur *“Modifier le champ”*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446353267/52389aea272e26004ac87290/XSw3MrWZ_OC0yFqTcENFimJL4QNlB0DRIhrj6I5IjVh2_DVVA8P9vb9v_0HUBlHnMXYyVaE8cc9lJlaio7yEOvQzOg2ilfq_QpTisDoMdbV4qUOcpJv501OADYtZxP0ktIwLYGHM?expires=1788635700&signature=03131a35a6429118cbee18bdf00e8fbf2d4538fcd4ae161a7aea096fba934abc&req=cCQhFcx9n4dYFb4f3HP0gINP7MC6lFBpRTKqpAKdOw1b2X%2BPRE41VJAtzDwH%0A8RZE91TmHY6sDSdDUQ%3D%3D%0A)

Pour afficher votre champ personnalisé sur vos documents PDF, cochez la case *“Afficher sur les PDFs”*, choisissez également vos paramètres d’utilisation du champ. Une fois terminé, cliquez sur *“enregistrer”*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446353273/8b20be7040f877dd03877d88/utwgsaAMZ08jbaZvhire7mmTanFSlrW8ORvHSIXCzB0WU45DTsw_V4cYBfk4uNfGOrw0hifMRjxDTToe5Z3p6UFQN8h70ccyLKsC3axH3zgVmPzLwtKfFqGfwrGOUMumCncG0W9f?expires=1788635700&signature=c16f9f742025a039e5422871bd94ba4b77f99c18e1f8d036b88beffd495b8c7c&req=cCQhFcx9n4ZcFb4f3HP0gPVlB5AH7cdpfNfGGuoLkJmwtIhQQEPg%2FXpeJs2j%0AvGL6AcQLW%2FWJYDcvbA%3D%3D%0A)

À partir de ce moment, le champ sera affiché par défaut sur vos documents.

Lors de l’édition de votre document, cliquez sur* “Modifier les préférences du document”* en bas de votre page, puis cliquez sur l’onglet *“Champs perso”*. Vous retrouverez alors votre champ personnalisé à remplir. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446353278/3665554868642bf355a52461/tCB6cGVgLvNG_X6hB2tzr3SwMnYRIUOJDsKQgvAwXtH03al_WAZkRDMTPY1RKHLcZK8qE8jCib62FiqXRZZJEls9sIFy1MRuADB2YIisVih00xm4i2EwCPo7rw36UhVrpcMfT38J?expires=1788635700&signature=3dfde09860556cb886e0c9a082920d7c3b7ba6bd0787cc88d6a8cc7bd685bd25&req=cCQhFcx9n4ZXFb4f3HP0gHPMMZBAUGyXoa092XnJMPu27vtkZvYVmBMfi4gT%0Ab%2FwDuHpxAyAgJu0JZA%3D%3D%0A)

Après avoir enregistré votre document, votre champ personnalisé apparaît à la fin de votre document, dans une page séparée (cet emplacement n'est pas personnalisable). 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446353281/a717f79096c8f243e6029407/g0JhdAjPKnCQkrmzseAYg3Ocjcx2HvyTsetUU57sXFHfYSzN4EtvuhUa7shqB6T-tPxtWiEpDk9IlOoDUnfSX88BATHxPexeCynte1H27rOQaMexoUi-Efe-3gwWLHcRF_8Ddf3D?expires=1788635700&signature=66491b6b1b89f088f160238622f5bb9f9daecf9190daadcb27354985b144550e&req=cCQhFcx9n4leFb4f3HP0gAMRgTqIinjqmV1Fg%2BDRTg3Etrl7QyWbsJGqCLOf%0ASR2BBYBSnBvwgbR1yA%3D%3D%0A)

### **Affichage de champs personnalisés dans les descriptions de produits ou services**

Vous pouvez également afficher des champs personnalisés de type produit ou service à la suite de la description dans les lignes de vos documents.

Pour ce faire, depuis l'édition du champ personnalisé, cochez *“afficher dans les descriptions”*. Une fois terminé, cliquez sur *“enregistrer”*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446353284/446817267b087974574f2c5a/oRS9cLfCXxxUpIgnuSyioUAGoN6n38EO1HOWJZohQuP1FZOfgHrpBqI2YduFDfD2X49-pEyjJTTH1DWebsRH2wKVJbMk1YouEWQEuIWU3pSO6PrwZlW3wrkR5_-fLNrPMdQYDR--?expires=1788635700&signature=645e32dc2ea4214a20005af8c7fc2c58ebe9b4ebdd43b3c3c15cdf7009e8b21a&req=cCQhFcx9n4lbFb4f3HP0gM6dUt3qp5Fumw7JZEiwv8ItTIAJPyqTs8tB50u6%0ANvK93cqB4MAXceuZzg%3D%3D%0A)

À partir de ce moment le champ sera affiché à la suite de la description.

> **Bon à savoir :** les champs personnalisés sont ajoutés à l'enregistrement du document. Ils ne sont pas visibles pendant l'édition.
