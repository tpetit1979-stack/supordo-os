# Importer mon catalogue de produits

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261802567/897f906db1dad148a33dede1a44a/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=29978ec7fa0bbc530c9a26b933107841e7becb7454a13753baa124fab78d298f&req=dSIhF8F%2Bn4RZXvMW1HO4zaRzYfNbDC20puN3p24sy4mna8v4vkqRleL8Nh%2Bh%0AIkiXeY5dPYt%2BMjLgeSI%3D%0A)

> **Attention :** les comptes en essai peuvent importer 100 objets maximum à la fois.

> **Bon à savoir :** afin de pouvoir importer des données, vous devez avoir le droit “Autoriser l’accès à la plateforme d’import” dans votre profil de privilèges. Pour [modifier votre profil de privilège](https://help.sellsy.com/fr/articles/5864116-comment-gerer-les-privileges-de-mes-collaborateurs), veuillez prendre contact avec un administrateur de votre compte Sellsy.

___________________________________________________________

### **Démarrer un import de produits**

Pour importer votre catalogue, cliquez sur l'onglet “Catalogue” puis sur “Liste des Produits”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867376523/c4036b8f8204e914efac8c76/Yof-aRQ-wDOYe9J5f7KGfddLRoxPKaSXQbQM_icE8iOdyNcXkjxETbb5cLmGwoifDMN2kBR24rg5RhDLA8FDaUrghd3dpwux0ItONOXf49dcwG4J5k9fy_gDmhRPZWYOD9TOThUGy9azdWS9JPBB0wE?expires=1788635700&signature=19f09ba10397642b062162101b59d52d696ab28e620c416ff15a8244f2fdd2ec&req=fCYgFc54mINcFb4f3HP0gCemz8IyMdr8h6gA5X5%2BDVihcyU0DEx0RBlf2od%2F%0A3XNNgi2PxAC23aCfzA%3D%3D%0A)

Cliquez ensuite sur le bouton “Actions” puis sur “Importer des produits”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867376589/04d60a0cf2853ba861fef6ab/Rib-vH3ciqfws_1MTrvkOSYXYL4Z4ROjZKXwxwSd-sxBpzU2d33_4gOtmuMyugCrwmbxkyXvv09Srhv3fcpCDh_bhP7MVBH85shXrOR5r2vaUcUX9378B0ZQbhnoYJL96WGXBt0Ae5lODxLI5V_f-1I?expires=1788635700&signature=fbaef0e1b52d3545fcaeb74ac7d9c2e0b663481d11c5e4b087624c75e4a4f231&req=fCYgFc54mIlWFb4f3HP0gCvCkqK6AhD1YWyNLR5GdhTJ36XKJYPRT0I7ow5n%0AvII81MXOPukWKkxMUA%3D%3D%0A)

Puis, sélectionnez les données "Produits" et commencez votre import en appuyant sur “Continuer".

![](https://downloads.intercomcdn.com/i/o/991502395/9b7cf88ea7118761af45b960/produits.png?expires=1788635700&signature=147332169df6f5e341d41ab333fd12166af35590e98b593ab34147e28407736c&req=fSkmE8l8nohaFb4f3HP0gCtTBE0qmrB3jp3bLsYr0VwLL%2BnfFsWMK22UvA%2FI%0AQEoXfzVzcahWZ0gWnw%3D%3D%0A)

Vous accédez ensuite à la plateforme d’import Sellsy.

### **Utiliser le modèle d'import**

> **Bon à savoir : **Vous avez la possibilité de télécharger un modèle d’import en cliquant sur “*Télécharger le modèle .csv”* ou “*Télécharger le modèle .xlsx”*  afin d’assurer un import en toute conformité.

### Champs obligatoires 

Nous vous conseillons de lire les informations présentes sur la page d’accueil avant de commencer l’import.

> **Bon à savoir :** Les champs de couleurs orange sont les champs obligatoires pour l'import.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867376754/93e74eacefbdcf95894ecacf/xQrlI1DYzarELkr7cbg3isUFn5jd-6r-0x9fe7ljSGjRv0FkL4wKZYxqUzRBvj2uCf438K98-yzEm6cdkgQ13anhfCHvkoC9-w9gGwFqvjMhBdfNLlRsrlR6GNr4IcaoFFG31na1Q9CnPnlKqA2_li8?expires=1788635700&signature=08b24b40081f1587f37cee5dc8aaf0d7aa3b316a29e78151c072e9b6a2b86f4f&req=fCYgFc54moRbFb4f3HP0gAJZXzbyKIeaMCIcENANK%2FZErr2QUf8L%2Bv52zVps%0Avam2z42LLykMFWSZbA%3D%3D%0A)

Ici, le champ obligatoire est :

- **Référence : “**Référence ou code produit unique dans votre catalogue”

Une fois votre fichier préparé, cliquez sur “Continuer”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867376839/c76785d87d0ee0fe83d169e2/CruGC5GMxxvc0ra0mWvjvGQKJrOBKRib6MaOs4bjBeYrb5PNEyZuu8TE5GE156LLuW7cPZ5Fkw5Bc6dpdo_QouPPCtb6kw_rGBMSnO8ZVJ4MgGKpELj05BSUu_iMOijprHkAvk4e1Si_9_6VwMq0Fds?expires=1788635700&signature=a2190477592e09db1fa6f0ccc29839a940ea6eb0f8a96b1af1fda57ac449755f&req=fCYgFc54lYJWFb4f3HP0gKSSFVR7%2FLJ114%2FfnD94gLO8O1yIzeO19Tsbm8aD%0AkU2uwlZ38yzCulg0WA%3D%3D%0A)

Puis, définissez les paramètres de votre import via différents choix.

Dans un premier temps, sélectionnez vos critères de comparaison afin de déterminer le critère sur lequel nous allons déterminer si un produit existe déjà dans vos données Sellsy.

Vous pouvez sélectionner votre critère de comparaison par : 

- **“Référence”** : Référence ou code du produit unique dans le catalogue.

Ou par :  

- **“Identifiant produit”** : Récupéré depuis un export Sellsy.

Puis, cliquez sur “Continuer”. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867376874/9d0106f467ea967b98c59a5a/qfNbCT71eWxNxtubazBgoE24XOa-q1wsp6xXH8f_SK8erbMSfKdml4DJ78KtCN2NXWRezTDmLyKuFTZgkw9MDxfIspv98_VElUK5RJGANlcdm1ONUqHfPOIt1QQS1dd4WlvKnqMeUlQ7rXNsgjgWfy8?expires=1788635700&signature=35fc0cd59fbe8001615dd9c068c34c07940bca9ce384087e0ac2e59f11d19dd7&req=fCYgFc54lYZbFb4f3HP0gKMLMpFTAI%2FVq%2FYFG%2FL%2F6DsJ8YQz2eOTjblTafKw%0AFkUvQuaKpIZiE0guXA%3D%3D%0A)

### **Configurer les paramètres de l'import**

Par la suite, sélectionnez en détail les paramètres de votre import, afin de déterminer les actions que nous allons effectuer lors du traitement de votre import. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867376979/72bcfeda68e72fb909a91b94/Gt_Q7zZ_2mErQFchbAMxEE8lujSKTu8oGMcN9_w5bpDE0LDUr8IzrfMAWlx7LrQrtCzhoJUPvklmNPMdUzLs0HyGsK0SEBve_d1Xifodjq4LdoYoLe4_KNqcBjXeU682WDvRlkicxN3ufehzrxE9-No?expires=1788635700&signature=2e169213685be3b72b3b2922b026ff05f7979ed78348109bf96d5e8188a906fc&req=fCYgFc54lIZWFb4f3HP0gF2nO4J0q%2FpJcGYNCqVeM8RPHCxzOduLSQKX9Z7U%0Ap8KAXBDlFI%2FXz8OtDw%3D%3D%0A)

Concernant les options de création : 

Si un produit de votre fichier n’existe pas dans Sellsy, vous avez deux possibilités :   

- **Ajouter votre produit** pour qu’il puisse être pris en compte.
- **Ignorer et ne pas l’ajouter** pour qu’il ne soit pas importé.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867377043/eee67fb7eae33611f5a47f35/aA26AgdaOTlIgu2xKe9s15ZWhIs_4r4akUQ67Nxa1TM3n6wVdGYyusyYEZjDliETDwY0fPE_zvHdfsCZOGGh6AiO8x0JfT7rV0huWKUjsvlQmcKQfGdw2mS3wylXxbprSdWPnWGe9Ump7Vx20ZraXgM?expires=1788635700&signature=b10869f892098ff54c81924c141d756be7196a34a1a6bafdc1c1fe0f23d83d80&req=fCYgFc55nYVcFb4f3HP0gNIheMI9rIIouexmLnrjLD2uKayWBm0KypK9PbeD%0AaNGY1lyT8iTw7Mj2mg%3D%3D%0A)

Concernant la mise à jour : 

Si le produit de votre fichier est identique à celui de Sellsy, vous avez deux possibilités :

- **Mettre à jour le produit : **Le produit identique du fichier trouvé par rapport au critère de comparaison renseigné est mis à jour dans Sellsy.
- **Ignorer et de ne pas le mettre à jour :** Le produit identique du fichier trouvé par rapport au critère de comparaison renseigné est ignoré et n’est pas mis à jour dans Sellsy.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867377076/ee37aac4a522cff20ba47303/k2F6Y5QmWl-AJoAdFL_hEiPVwpXWqwciUfStyPreMoB2jz1iErZCBj4FkIlj6pmdDO25Dfo3aRgbc_RUQjs6W4WUxHsrDQ_7al4AYcwcgrqPNBp9XROv7zZk9nwlgZ6jw_2eJeObvgRVF7Vqhud1JGQ?expires=1788635700&signature=ddd0ae43bf0227c1303ac5eba310eacec11977ad0d95ff1693f0e57c0259e905&req=fCYgFc55nYZZFb4f3HP0gKjxvDire3ezJFnD6aVTRSYf2GjWV%2BJHLdV9MsaL%0AfF7ucB88iSkJgMMj%2Bg%3D%3D%0A)

Si une cellule de votre fichier est vide, vous avez deux possibilités :

- **Ignorer et de ne rien faire :** La cellule du fichier est ignorée et n’est pas importé dans Sellsy.
- **Remplacer par une valeur vide : **La cellule du fichier est prise en compte et une valeur vide remplace celle existante dans Sellsy.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867377105/d71319f805b0306dcf1c7360/nP_LFUznu1W8tyWG-aR2KGAliFEb3avL5lvQRuy-IEWclz0R20wUy3shOAY7N-q0TtXW11je8QaRFbL8nhKD9vO-B9tyczgWEwm8F24eNdvga8icWGF041e-cFKrnw59RZzmquYMuxK9RF8bZYrvWWY?expires=1788635700&signature=65c569451c61a04ab25c27a6bc404ff943e03d8e9133afe417fdaa6f4ee2ba1f&req=fCYgFc55nIFaFb4f3HP0gKJCgSl%2BcipwFjLyNv8NXrxyzMKG268gGGnS8Ruw%0AcvWwhPel1GBLRASfrA%3D%3D%0A)

Concernant les Smart-tags de votre fichier, vous avez deux possibilités :

- **Ajouter les Smart-tags** de votre fichier à ceux déjà existants dans Sellsy.
- **Remplacer les Smart-tags existants** dans Sellsy par ceux de votre fichier.

> **Bon à savoir : **En survolant l'icône "i" au bout de chaque ligne, vous obtiendrez des informations supplémentaires sur les différentes options possibles.

Lorsque ces paramètres sont sélectionnés, cliquez sur “Continuer”, puis sur “Importer mon fichier”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867377171/ea023d85ef98509e06bbe10b/-YukpTt7LKreR2Qy1Ux6u1mw9BrheEaVoMqCCud1B2HCN55D12H3lBAERKBn5XuyHyziSIE1Lc_otReHesjyxVXK2rwTMWI_CSc1BnwUlDPo133eeiMseIVmKsH8C2KmK4zEvLp0TKTPst4oglaKKi8?expires=1788635700&signature=6a76b214a565be1e0fd2fb8de00716576be264cabe595bb44e50c0ccf24f538e&req=fCYgFc55nIZeFb4f3HP0gJcxJKiyZIIYnW4QbahRApmfwJqT4D4c8eCUMa9u%0A93qCbBTQ0H3pA7iKdg%3D%3D%0A)

L’import de données peut se faire de deux façons : glisser votre fichier directement sur l’interface ou choisissez-le depuis votre ordinateur en cliquant sur “Sélectionner un fichier”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867377205/b79aad590a8091b32ec60a48/nrbu-wZ0_wOUWdGLGYcAnDQoaxLF6IMR4LlhE65Ut-f-hg1berdIXSBEWwj3_xY1nWMNV276ohuFQuFA4ABO6mK_-RLvRLaUoBw8kg9bLj2XXKO0wGNKNsH-1bK8RvMKmoJW4fe54V-7Q9Xc0uorqpk?expires=1788635700&signature=c64250ccfb44d323584118632b7f94ea2607bc51eb0ef09e7628f3ad8bdd8618&req=fCYgFc55n4FaFb4f3HP0gIweA3ZZgNoOkgSLB4d1C23CQs%2F37fhE42ydZc8O%0AYLr8%2FKLtmifn0PcnfQ%3D%3D%0A)

Une fois sélectionné, confirmez ou modifiez la ligne d’en-tête de votre fichier puis validez en appuyant sur “Continuer”

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867377249/edd4e150100fdce98cdb4b08/jPUHcyc2Ovx7IIik_xHdQdByPF-FrWQCHKG7uR6s-7eAPp1ySzcjam-qTkxRGK5h2ZN3qcbIQC7GYI2ijZaq1ODd_DoHbedFPMj-Zxl2GDW5sxQpxcPA5-92M4ofbsXfUZikid3V1UxpXQrYxN84oWU?expires=1788635700&signature=69bc1debe79dd0296d2438b921d05a659ac6d5a2c63a3f0f4fd6834328c3a813&req=fCYgFc55n4VWFb4f3HP0gDHJ4fZaf5zrZjCIGTU%2BbYcLgEdRr6iDxG0V6QAi%0ACDzj%2Bk15yZGK615O4g%3D%3D%0A)

> **Bon à savoir : **Vous avez la possibilité de ne pas sélectionner la ligne d’en-tête de votre fichier, il vous suffit de cliquer sur “Ignorez et utilisez des signes alphabétiques comme en-têtes” ou bien d’aller sur le carré vide en haut à gauche.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867377339/145ba849bdf92b406785663b/OF3jBeqE52ljmXyxmhBcOx7recOp_RH30ZuIBNCkLz83AZTZCOdbgyQPvgDORignokwJlk34ToXS2ig_bkNHCg6o_z3Ne6hnspFXl28INo2H2jRZ8bU8P-RJpljTYfA6UhNKFBHQkLEhlGNKmi-7YmE?expires=1788635700&signature=f69fa8fcf1341fe7faf4ec6a124bbc809d24df2495baec86ee1df1e3ac3477cd&req=fCYgFc55noJWFb4f3HP0gEn6IISQlmNR%2FtDM0Z9ciP3xbfVTONYWvP5pyLsp%0ABAgIJocPRI%2ButKtY%2FA%3D%3D%0A)

Puis, si la correspondance de vos données n’est pas tout à fait exacte, vous êtes amenés à faire correspondre le nom des colonnes de votre fichier (à gauche) aux champs du template correspondant au type de données sélectionné (à droite). 

Pour finaliser cette étape, cliquez sur “Continuer”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867377364/735c1da4383c8d20e54d7edf/XjB-3RRTd8yjQf3k68Yvwk3Q-BcREzFgmQxYxgbIduSykI1_8nHhFHJ6lhnCyy6Sd5834r4JQyDPxmJpylPKq5Hwiy5pIz-Hm4IAOUGnF2ffrr1TZQahay6HXFs5ooPRt5ADpvXU8OcuDwq_REgcRHA?expires=1788635700&signature=e938e8597a2904405da5ca50074a9b2f6111498c5b219479f435db29c5890749&req=fCYgFc55nodbFb4f3HP0gGBzvA%2FaKCWnoHch0t5ROV5NDqeSOCWLYLTrB6gG%0A0l06MTaz5tWeOr3MuQ%3D%3D%0A)

Par la suite, vérifiez et visualisez vos données en rectifiant les erreurs directement depuis l’interface d’import si nécessaire. Continuez l’import en cliquant sur “Importer X lignes”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867377387/1c4da6579528927be585823c/7vt2owtskO2W6id4Pr18LD-NAMYRgBzGP4LA98bkfqdkwovJjsx3EV7_s4wkjgjBLbIQI2KyToY5Y9SSqY-e9PfRKUbSOEc29iYG9JkvIxYTR19xxBQH6HiurugnJDRKpY762rWHTnyav_yjm6t1hU8?expires=1788635700&signature=8581fa8c40408c9347e417bf6bfe52d1eb1cc4e8ecd0cb6eb14b96b82948c3b9&req=fCYgFc55nolYFb4f3HP0gMvLYswJk4oXBFn8hP8xzpjusId%2FbuhS8uFgmOpX%0AS0qs1fxl0h1cb0mQQg%3D%3D%0A)

Confirmez le lancement de votre import de catalogue produit en cliquant sur “Envoyer”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867377411/6037dcd78692ae312a32b68c/7nIRiWRlJCI977WQpoAhaT5E372WXCoTjCxWavJtMUMKEMR4s47SGkNbPzbv17sevVuyT2rGEe-yK2aIr-HWzaICkiFgcURCrvC8BC3ja_FHaCyZhIMujtXHgKeXwaXfZXUsiIpcejdUe3ZU-uRC6ZI?expires=1788635700&signature=7f02dc41e1e808da0dd4ff30798d7411354463550d47341eac7237af0ae88604&req=fCYgFc55mYBeFb4f3HP0gDTEOBDyJ2ckJnsyeOxJQlOwMGloP2zhZqUrWcAu%0Aps873Cn0ODYqJqWoQQ%3D%3D%0A)

> **Bon à savoir :** L’import réalisé apparaît dans votre historique avec son état d’avancement (en attente / en cours / traité / annulé), vous avez la possibilité de cliquer sur “Voir” pour consulter l’ensemble des détails. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867377429/05a7f3cd39710306ce80bf21/BzGrP0iSPtflm3zixRKKcFaonKN9pOW8YMiDB_kMDOcmbMebHNbCi2R__Lxe5GLRoPRUNuoGpW3nx51g_RU-l-OGh67It-EI_0ea6x92U9d2Q8Nxi8lXOcBcRClSQfi9aTB7lR0rpzA6bKD5ziqIP0k?expires=1788635700&signature=7b5f7a30c6b9e5593e05d93990d204b1d0ef079b508ed0c3e05413f26f0f87fd&req=fCYgFc55mYNWFb4f3HP0gDHkVpmroOoLLktp%2B%2F1mLj7ps7eFuW73qEDmhFYX%0AWOo9o4Lbg3fWeU3Ntg%3D%3D%0A)

Vous pouvez réaliser différentes actions, comme télécharger le fichier d’import ou d’erreur, et annuler l’import. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/867377529/4d9925ce569a8da8a2e1c4e0/GN7Vt39X0zAhCnP4JdTFiHh6dOwkFEC1T96FkIov9YeoUyZ6Yarr8AEZVI5UfdeR1lFX_Q-5TgBhmcsAfK5b0j-vpMmJh0-AkH19rOr6I7KCxFNt8eXFxTufrditDhOKLlb09fykNIeKhKg4GAgV-5g?expires=1788635700&signature=f7255334ab460025574ffc3f3c929a5d5e8078096a688438deb69059f061bbda&req=fCYgFc55mINWFb4f3HP0gA8rlM3MnHVpNeLcmDQZMYqxWyix3TjVmGg%2BP5JS%0AqUfarh4HwweHti7L4g%3D%3D%0A)
