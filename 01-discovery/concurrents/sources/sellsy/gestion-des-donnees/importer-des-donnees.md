# Importer des données

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2142719746/e93a2a48027a6b2a5e156ae45e4a/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=6ba364a6d852832311627bbad53f20cac881be9bb1ced0200a300188a160f3b2&req=diEjFM5%2FlIZbX%2FMW1HO4zbFeqdLx7S0GPrFN5ks9kTRMNiAxrPRBfArDHEEo%0A7hyyqw5B2Md%2BRYiXT2g%3D%0A)

Sellsy vous propose une interface pour gérer vos imports de données. 

> **Attention :** pour les comptes en essai, nous ne pouvons pas importer plus de 100 objets à la fois.

> **Bon à savoir :** afin de pouvoir importer des données, vous devez avoir le droit “Autoriser l’accès à la plateforme d’import” dans votre profil de privilèges. Pour [modifier votre profil de privilèges](https://help.sellsy.com/fr/articles/5864116-gerer-les-profils-de-privileges-de-mes-collaborateurs), veuillez prendre contact avec un administrateur de votre compte Sellsy.

___________________________________________________________

### **Accéder à la fonctionnalité d'import **

Pour importer vos données, cliquez sur “Menu” puis “Réglages”. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446356643/fcaef59bf4f0175fb38f14a1/lEexFlEVK7R5yJcq2bbZ4TyshO1mWXT_fhq7unGTETh-78prqov5Q06nFQ3jVo57o476vAPi073uHmDaCRkJHlUq8OtP3EN035k-l-co8NowBkxpzhzKmHa7SZ7rW3FmxNlHDb_t%3Ds1600?expires=1788635700&signature=888bbd9320683ac24fdc89b894e1b6fabb741c675b82727fe5337ebf2b8177ad&req=cCQhFcx4m4VcFb4f3HP0gPeTOfCl6qrXdxe04Xoy%2FONQj3UWRvUC5FVM%2FQx8%0Az0MiEW27lgIEOLRxEg%3D%3D%0A)

Ensuite, rendez-vous sur “Imports de données”. Vous arrivez alors sur l’interface d'historique de vos imports.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446356660/2eb037995948f08635dc80e9/au8MRA_GeGZ1cFrKIsVVhpCA5iISBFcBATlFer-gNf_7CpTHn8IrbNM7G_80oyjUjKdreABRdHFLpociSlBHEmWYce80OzifwVlTqNaqHZ-H1If66nNb3NJNC13uX0DtO4nz4n2w%3Ds1600?expires=1788635700&signature=a0334fa6302f3f8ccbd879e8be8811812d43119082232012d99b2e028e1985e4&req=cCQhFcx4m4dfFb4f3HP0gJXTEES%2BhR0imHIfjfgthcyvEzrcoAyBdQ8Rix4B%0AzRis1rViqn%2F55yioMQ%3D%3D%0A)

Cliquez sur “Démarrer un import” pour choisir quel** type de données** vous souhaitez importer.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/677152911/cd0640cfbd18144bc12fc8d0/zL4HCoy1Ta7R1h9mSnecWpzqEROOe5B3Yw_xqJEzow3DPKgMPFcD1JpkWxvxNzBP7zwF7Cftc9onTfoqLSBZfa7N_mHGYu9fiuM0x0esQ7WpbPYCKm-PCGkGyS2xaYK9kvM4A645eoBUlx-TNrcgcDE?expires=1788635700&signature=f27c29f3e01d98447a4f451135e4c8f03cb334d9d60f2dbea19906b62589fa8a&req=cicgF8x8lIBeFb4f3HP0gLlopvW8y8xNPIYcvOGiHkq13oL4PWTsP1OEArgV%0AQqCT0gkvRnHNYOdiLg%3D%3D%0A)

Puis, sélectionnez les données de votre choix. 

![](https://downloads.intercomcdn.com/i/o/991460458/fde52e69a0fcd38052e880b1/Quelles+donne%CC%81es.png?expires=1788635700&signature=b8a808bb8d5437b91d82ed706a10d9ee3bb5b308553b50a1e9b871d235850848&req=fSkmEs9%2BmYRXFb4f3HP0gNUCXK8eoDvv%2BeJLBsyFnJz%2FdE%2Byr466K4HFtQr2%0AvrMpOyFts8GE5RaMog%3D%3D%0A)
