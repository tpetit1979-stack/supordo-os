# Importer un relevé bancaire

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2142768835/128f77728bd95c79713c4f063b42/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=f2d59145254b3a4dc3c24ce73d5435e9fd4cbd512b5ba1dff45887bbc82bc3ce&req=diEjFM54lYlcXPMW1HO4zdkjisFWqNH2ernK1LjhFOa9dJDPw4PrZI9O%2Btna%0AAW2oHWWR2fHjUYc7eF0%3D%0A)

Si vous ne souhaitez pas connecter un compte bancaire dans Sellsy ou si votre banque n'est pas disponible pour une connexion automatique, vous avez la possibilité d'importer manuellement vos relevés bancaires au format CSV.

___________________________________________________________

### **Accéder à l'import de relevés**

Pour importer un relevé bancaire, rendez-vous dans le menu *Banque > Rapprochement bancaire*.

Deux options s'offrent à vous selon votre situation :

- **Si vous n'avez aucun compte connecté :** cliquez sur *"Importer mes relevés"* sur la page d'accueil du module
- **Si vous avez déjà un ou plusieurs comptes connectés :** cliquez sur le bouton *"Actions"* en haut à droite de la liste des transactions, puis sélectionnez *"Importer un relevé bancaire"*

Vous devez ensuite suivre 4 étapes :

**Étape 1 : Impo**rter votre fichier CSV et choisir votre compte

Dans cette première étape :

1. Sélectionnez le compte bancaire dans lequel vous souhaitez importer votre relevé (la liste des comptes est modifiable dans *Banque > Liste des banques*)
2. Saisissez le solde du compte
3. Sélectionnez le fichier CSV à importer

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446359175/867ed4e266b3657d05d9297c/Ee16WuZod9yvmX-7Yn1cWO_ejvYMIZXNnZtRF3DSDCb7TPyl0ffhp8dbyKZeq-MagQ7pnoNQsr-fpxgL_M0oXwjtpl6GalovaUULPGQ94bw4ZHQxtGTZpI3_xe-XP2RVfpc8-Oe6?expires=1788635700&signature=1e7e79d337aa49a768f951555cfa61bba66ea1cf75c54e54b0b9b4cae8a7459d&req=cCQhFcx3nIZaFb4f3HP0gOgoVThoWrMOM%2FByPqXkw4PoDJduWB%2BzgqT%2FOxup%0Av4xoJ3%2BLiTEsEcl1Zw%3D%3D%0A)

**Étape 2 : Sélectionner la colonne date et son format**

Indiquez quelle colonne de votre fichier CSV contient la date de vos transactions, puis précisez le format de date utilisé.

**Étape 3 : Sélectionner la ou les colonnes montant**

Définissez comment les montants sont présentés dans votre fichier CSV. Trois options sont possibles :

- En une seule colonne
- En deux colonnes distinctes
- Une colonne montant et une colonne type

**Étape 4 : Sélectionner la ou les colonnes libellé**

Indiquez quelle colonne contient le libellé de vos transactions. Vous pouvez sélectionner jusqu'à 3 colonnes qui seront fusionnées lors de l'import.

Enfin, vérifiez et validez votre import.

___________________________________________________________

### **Sauvegarde du paramétrage**

Une fois votre premier import effectué, Sellsy sauvegarde automatiquement votre paramétrage. Lors de vos prochains imports, vous passerez directement de la première étape à la dernière, sans avoir à reconfigurer les paramètres.

Vous aurez bien sûr la possibilité de modifier ce paramétrage si votre fichier CSV évolue.

___________________________________________________________

### **Gérer vos transactions importées**

Pour les comptes avec des relevés importés, vous pouvez supprimer des transactions en utilisant les actions en masse disponibles dans la liste des transactions.
