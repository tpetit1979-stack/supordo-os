# Créer un groupe de champs personnalisés

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1879054168/d96739c8138e87ab40b371d8e5b6/FAQ-Bannie-CC-80reAcademy-2-2B-282-29-2B-281-29.png?expires=1788635700&signature=a19011be3a0f36e80a2189b7e963d89f657d28de16dc17a29a20cd335725c736&req=dSggH8l7mYBZUfMW1HO4zaIa8aMIHYxCUzs8sH35wGp8ELdDKTAE5pw22hO4%0Ai8s4qaNWLWhBTVoN0Tk%3D%0A)


Afin de vous permettre d'optimiser l'utilisation des champs personnalisés, Sellsy vous propose de créer des groupes de champs personnalisés.

Pour commencer, cliquez sur votre menu,  “*Réglages*" puis sur “*Groupes de champs personnalisés*”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446352436/1b7ce9c3c1676f0acafbd6e5/zGDSqqu8XUN7jfnLNyn52KZvNiPyprTcXi-_tW7o5Sf2q49LFwpBIfM6LjZQVWe47-BKeubO1ZCcP1W92b82EC3ySRMWT7Cy0LkTAsULxL4srFupj07j1qpGWrp6c7adKskUk9yS?expires=1788635700&signature=28952870b308ff2ed2e3b7328922d6ae1af08716f68195ca4318bb313c0c262b&req=cCQhFcx8mYJZFb4f3HP0gDAovMpWsYt23g7D1X3Pcyivu3rPPE8fr2zw1oUw%0Awdj3A2vJWo2NC%2FaHxQ%3D%3D%0A)

Cliquez ensuite sur Ajouter un groupe de champs.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446352443/e90383f46a86b6a33a6424f8/awNSMIiwqa0N7J0fKKWx1zcbq51wSud5AWA3Wmy6BpQ5Ime7Mkb3Pt-g-cE3AIo18D6mgfsI9ilTMCTewNANz3mOgTVFDY60E4W1tsFiV_WQI5cCKi_LnD-BvQQc8qzzDxTGBw-e?expires=1788635700&signature=e326955a4e872c6356ea4c1c12b320c8ad22e5ee4ca636facb4f63772652fea8&req=cCQhFcx8mYVcFb4f3HP0gOfZq1A2pjDTLuUi%2BwQkqxjN0WIn7NXpwUZLGn7S%0AmQzF%2B11pNEOhYvWaMw%3D%3D%0A)

Il vous suffit de remplir le nom du groupe et de choisir le ou les champs personnalisés qui s'y rattachent. Une fois les informations complétées, cliquez sur “enregistrer”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446352449/2199e03d68c39113f443cf11/ihkUaeAqj-56Wg_20lrM4eAgrMs0Ff2KgNGwa2-aESoccqGpLffqNl_ym9BIwnxald4vX4KafVZFx5jUopBJYyU0HYi9SleB5KHP065H1RRS4x2zxTRrjez-97NlkhFOKMV_NXJa?expires=1788635700&signature=914eeae8fd9c65e98b81f484aa866a468800c01b52f6443bf4f974c88c325304&req=cCQhFcx8mYVWFb4f3HP0gEKHqY%2FVn3jJw2OfGMOVxhvPwm70JqjfIp3fbqNp%0ADSBHtjsVE6fN1bLebg%3D%3D%0A)

Vous pourrez ensuite retrouver la liste de vos groupes de champs personnalisés sur votre page “*Groupes de champs personnalisés*”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446352460/beb434eddaf14abd6459495d/Quzn_EsDkGcFHaJ3A_07-n4vQ6pczG6NmPFcTVIO-h2Jtfo2SMhcY5O2SdgY66HfDTgY13kBRPyeJzaSxwWbooReUaGGxNuStpUqE3SmuSaj2odJXFU5LpmUqdnyrihcza9QR9MA?expires=1788635700&signature=5e2c7fddefff4b52819982ff1e4eee78ae978ba3586bb03f8be14d5a3865175a&req=cCQhFcx8mYdfFb4f3HP0gIMCuHtzjgxbAy01nt%2FXUVcD6kt4U3iKLWFFhutW%0Acj0S7oZ9iRvA9gv%2F%2FA%3D%3D%0A)
