# Modifier les informations société dans le cadre de la facturation électronique

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2432984501/47c730c2757576566f5eee42b9f8/FAQ-Bannie%CC%80reAcademy-2+-2-.png?expires=1788635700&signature=fdd53909e8d2ed5ab1f3ad6ec76ea6ec75a86c1a8e93aa52adbebd371720bc68&req=diQkFMB2mYRfWPMW1HO4zUuNOb1eocuvidke%2FIeKz9XKxzeUVWnF0kEZuZRt%0AE2kuHNX5T1qoJ0kuNsw%3D%0A)

### **Modifier les informations juridiques de votre société**

Après [validation de vos informations société dans le cadre de la facturation électronique](https://help.sellsy.com/fr/articles/12683463-completer-vos-informations-societe-dans-le-cadre-de-la-facturation-electronique), certaines données juridiques sont verrouillées afin de garantir la conformité de vos documents.

Vous pouvez retrouver l'ensemble de ces informations dans *"Infos société"*.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2432985142/f15f24dc5f0716bb7771f7978b57/Capture+d%E2%80%99e%CC%81cran+2026-05-27+a%CC%80+17_48_45.png?expires=1788635700&signature=6e59e5ab73a0690d42f020db13de9634b55d1f3f457667ec3e5b795027d4db22&req=diQkFMB2mIBbW%2FMW1HO4zYXMZ%2BJspUGZZtp8HzSycY9v%2BNDNdrCgWLDv6yfJ%0AIkAw4jh0ZyW9BGFIc9k%3D%0A)

___________________________________________________________

### **Informations verrouillées et modifiables**

Le tableau ci-dessous récapitule les informations concernées et leur statut de modification.

| **Information** | **Modifiable par l'utilisateur** | **Modifiable via le support** |
| --- | --- | --- |
| Pays | Non | Oui |
| SIREN / SIRET | Non | Oui |
| Numéro TVA intracommunautaire | Non | Oui |
| Dénomination sociale | Non | Oui |
| Forme juridique | Oui | Non |
| Capital social | Oui | Non |
| Code NAF | Oui | Non |
| RCS | Oui | Non |
| Téléphone / Email | Oui | Non |

> **Bon à savoir :** pour toute modification d'une information verrouillée, vous devez contacter le support Sellsy. Des justificatifs pourront vous être demandés, tels qu'un extrait Kbis ou une pièce d'identité.

___________________________________________________________

### **Impact sur vos documents existants** :

Les modifications apportées à vos informations juridiques :

- n'affectent pas vos anciennes factures ;
- ne modifient pas votre historique ;
- ne s'appliquent pas aux documents déjà émis.

Cependant, certaines modifications entraînent une mise à jour obligatoire du mandat PA. C'est le cas pour :

- le changement de Pays ;
- le changement de SIREN ;
- le changement de numéro TVA intracommunautaire.
