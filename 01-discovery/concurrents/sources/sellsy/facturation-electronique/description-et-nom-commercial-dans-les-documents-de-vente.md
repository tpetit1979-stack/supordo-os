# Description et nom commercial dans les documents de vente

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1781496345/af1b4cc95086532f8330ddee9084/FAQ-Bannie-CC-80reAcademy-2-2B-282-29.png?expires=1788635700&signature=44c00c81fcd1d00e374d5a79c9102297bde56304255a26b25a25b7f0aaa8057b&req=dScvF813m4JbXPMW1HO4zecg1CDL1%2FnwTITEZcYWooC3qI4YE1QjA3FlKtfi%0AVKddX93D3bjkJoor3kM%3D%0A)

### Description des produits et services

Dans le cadre de la conformité FacturX, chaque ligne d’un document de vente doit comporter une **description claire et obligatoire**.

- Ce champ ne peut plus être masqué.
- Il doit contenir **au moins 10 caractères** pour être valide.

___________________________________________________________

### Nom commercial des produits et services

Le **nom commercial** est désormais un élément obligatoire pour chaque produit ou service. Chez Sellsy, il est renseigné automatiquement :

- Si un nom commercial existe dans le catalogue, il est utilisé.
- S’il n’existe pas, il est automatiquement généré à partir du **début du champ Description**.

___________________________________________________________

### Documents concernés

Ces changements s’appliquent à l’ensemble des **documents de vente** :

- Devis
- Factures de vente (simples, partielles, d’avancement)
- Avoirs
- Bons de commande
- Bons de livraison
- Modèles de documents
- Abonnements

Ils ne concernent pas les **documents d’achat**.

___________________________________________________________

### Activation de la colonne *Description*

La colonne *Description* devient obligatoire dans tous les documents de vente.

- Si la colonne était déjà affichée dans vos réglages, elle ne pourra plus être masquée.
- Si elle était masquée et que vous choisissez de l’afficher, ce choix sera **irréversible**.
- Si vous l’affichez sur un document précis (par exemple un devis), elle restera affichée sur ce document et sur tous les documents liés (factures d’avancement, avoirs, etc.).

En résumé, une fois activée, la colonne *Description* reste définitivement visible afin de garantir la conformité au format FacturX.

___________________________________________________________

### Impact sur les modèles existants

Les modèles de documents créés **sans description** resteront sans description. Ces documents ne seront donc **pas conformes** et ne pourront pas être émis comme factures électroniques.

___________________________________________________________

### Changements dans l’API

- L’API indique dès à présent que le champ *Description* devient obligatoire.
- Cette obligation sera appliquée concrètement dans un second temps.

___________________________________________________________

### Clients concernés par la première mise en place

À partir du **16 septembre**, seuls les **nouveaux clients** sont concernés par ces évolutions. Les clients actuels seront informés **avant l’activation du changement** sur leurs comptes.

Si vous êtes un nouveau client, aucune action particulière n’est requise : les évolutions sont appliquées automatiquement dans vos documents.
