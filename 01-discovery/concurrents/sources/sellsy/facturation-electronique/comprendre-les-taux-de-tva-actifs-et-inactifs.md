# Comprendre les taux de TVA actifs et inactifs

### **Accéder à la configuration des taux de TVA**

La page *"Configuration des taux de TVA"* vous permet de gérer les taux utilisables dans votre compte. Vous y retrouvez deux catégories : les taux actifs et les taux inactifs.

### **Les taux actifs**

Un taux actif peut être sélectionné dans :

- Les produits et services
- Les frais de port et emballages
- Les catégories tarifaires
- Les documents de facturation et achats

Un taux actif correspond à un usage réel et actuel de votre activité.

> **Bon à savoir** : Il est recommandé de n'activer que les taux réellement nécessaires pour simplifier la gestion de votre compte et éviter les erreurs de saisie.

___________________________________________________________

### **Les taux inactifs**

Un taux inactif ne peut plus être sélectionné sur de nouveaux éléments. Il reste cependant visible dans votre compte pour :

- Conserver l'historique
- Assurer la cohérence des anciens documents

Il est conseillé de rendre un **taux inactif** lorsque :

- Il n'est plus utilisé dans votre activité
- Il a été remplacé par une exemption de TVA
- Il correspond à un ancien paramétrage (par exemple, les anciens taux à 0%)

> **Bon à savoir :** 
> - votre historique de documents est conservé ;
> - les anciens taux restent visibles sur vos anciens documents ;
> - vos documents passés ne sont pas modifiés.
> Seuls les nouveaux documents doivent désormais utiliser les nouvelles exemptions conformes.

___________________________________________________________

### Je suis un nouveau client Sellsy

Pour les nouveaux comptes (après décembre 2025) :

- Les taux standards légaux sont activés par défaut
- Les exemptions courantes sont disponibles
- Les taux non pertinents peuvent être désactivés à tout moment


Vous pouvez renommer les taux pour plus de clarté et faciliter leur identification. Par exemple :

- *"TVA 20% – Services"*

___________________________________________________________

### Je suis un ancien client Sellsy

Pour les anciens comptes :

- Certains taux peuvent être actifs ou inactifs selon l’historique
- Les anciens taux à 0 % sont désactivés
- Les nouveaux taux ou exemptions peuvent être activés progressivement

L’objectif est de **nettoyer les paramètres sans casser l’existant**.

___________________________________________________________

### Bonnes pratiques recommandées

- Un taux = un usage clair
- Désactiver plutôt que supprimer
- Vérifier régulièrement les indicateurs de conformité
- Éviter de multiplier les taux actifs inutiles

> ### À retenir
> - **Actif = utilisable**
> - **Inactif = conservé pour l’historique**
> - Les exemptions remplacent les taux à 0 %
> - Les codes VATEX assurent la conformité réglementaire
