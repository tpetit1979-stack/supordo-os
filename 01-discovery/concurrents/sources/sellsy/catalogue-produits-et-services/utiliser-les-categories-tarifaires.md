# Utiliser les catégories tarifaires

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261800865/4545c56fc417e5f9a5cbb548caa4/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=b80e0ce3df53811ce52ba0cee1bd01877c60b1209b2894764b272f1cc5817683&req=dSIhF8F%2BnYlZXPMW1HO4zfFvVyO1nHSUjGDw8nBhR0GaTfNmGJqvH5gpaPoE%0A5yhG43v2IOyjMnqofwc%3D%0A)

Les catégories tarifaires vous permettent de **définir plusieurs prix de vente pour vos produits**, pour des clients différents, ainsi que différents paramètres comme le code comptable, le taux de TVA et/ou l'apparence du document.

Par exemple, vous pouvez gérer un tarif pour les particuliers, un tarif pour les entreprises et un tarif pour l'export.

Une catégorie tarifaire comprend soit des prix hors taxes, soit des prix TTC, ainsi que le taux de TVA, le code comptable et le modèle de document.

### Créer une catégorie tarifaire

Pour ajouter une catégorie tarifaire, cliquez sur *“Réglages”* dans votre menu puis sur *“Tarifs et taxes”*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444829560/21c335915dd24159c2d6f8db/xVTOoeqgiZuhv6eMQDIxkUejpkva1NZPx_JPZegBuuquCoHuUnbcbbWLJZUzEC6LA848rqMeXyolya26PAL2I9eFKca_E50JxObFDM_3iAtSqnQJpBzD7CuzrBBHCU4_UHOjZlP4?expires=1788635700&signature=e46f25adb39ceee84f611c493478dc0323f4b7f7f787dd23a3e68b20a364c530&req=cCQjHst3mIdfFb4f3HP0gAiEkfraT2iMh8Oi1FXQkKl7gZYw22YtgFvoi1%2BI%0AC4ViPz4owHiuuAfrIg%3D%3D%0A)

La page suivante affiche les catégories existantes, que vous pouvez modifier. Pour ajouter une catégorie tarifaire, cliquez sur *“Ajouter une catégorie tarifaire”*.

![](https://downloads.intercomcdn.com/i/o/660634950/5e9f923cd514f8bd6659d3f3/Capture+d%E2%80%99e%CC%81cran+2023-01-27+a%CC%80+09.40.28.png?expires=1788635700&signature=80920515899b7d7801fdd0a531d52f85ab70767985554de2ecdbcd8bd5b77adc&req=ciYnEMp6lIRfFb4f3HP0gH%2F36NnmEikNTaZY%2Fo08OIhQmZAQywp8ADf8cEWR%0AGW2SFFdBQ0WiRV6vsQ%3D%3D%0A)

Nommez votre catégorie tarifaire, choisissez le mode de TVA et les codes comptables à appliquer. Vous pouvez également attribuer à cette catégorie une apparence par défaut. Pour finir, vous avez le choix entre : 

- Appliquer un montant par produit,
- Appliquer un pourcentage du montant de référence du produit.

![](https://downloads.intercomcdn.com/i/o/660635331/9c3b361a86fdcfa5f1a7730e/Capture+d%E2%80%99e%CC%81cran+2023-01-27+a%CC%80+09.41.48.png?expires=1788635700&signature=7a9e37f19c1abd6d6fa9a7911eeac7148dd2efcbaa0ccb68e59a9074011cb284&req=ciYnEMp7noJeFb4f3HP0gBCRJS8YClRuEKoc%2FiJePPvVYUOb%2BzUAKuzoKocL%0AT6aPnTKfZAUKoLqOJw%3D%3D%0A)

Votre catégorie tarifaire devient alors disponible dans vos fiches produits dans lesquelles vous pourrez renseigner les tarifs.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444829585/00a74c845112cb27772e89e4/xa4Dc5eEEzh7kgL9ODOn1OD-nmxFbU6MaKi3tyvZMYmbQ4QW7Qb1U_k2NxN0mDBltsqA40DtpJMN-gdJxsJjGtZ2YSDaWSIXr1XH72I5IjRsZ3OoFsiuu0PGN3B8qpjJ6AECrPDz?expires=1788635700&signature=70f5ab9f9eb3c480cef10206bcd7054a5be6225983b331efe57b9acf84d2dd1c&req=cCQjHst3mIlaFb4f3HP0gPOJ%2BblCorZiz5zWK8H6TUfSxWZUrF9tfX5rBv9o%0AI1PYKrWY%2FBaaipEPCg%3D%3D%0A)

### Attribuer une catégorie tarifaire à un client

1. Au cas par cas 

Rendez-vous sur une fiche client puis cliquez sur le menu *"Actions"* en haut à droite et choisissez *"Modifier la société"*. 

Choisissez la catégorie tarifaire souhaitée dans la liste déroulante puis cliquez sur *“Enregistrer”*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444829602/c9092f841900a0ee9c95d924/AJrUyX7OGv1i1b5n2I0sNs10zmUIMNJpDe6bYWYwVhGYhpfZWq75LK9kIcQ0IW_7Y6pYRjAzklmRjs-zCqmje6tPljXlj8cQU2SqHNggwJGDxH3uEBJJWp9s2Y-1zCr3fsNmDU5R?expires=1788635700&signature=597afd8239439e684b5a1e33b6311f5bc84a8b5643572e1f2a66ca1382d25b11&req=cCQjHst3m4FdFb4f3HP0gPB3dixI%2B4w6i345WRCYN%2F5i%2FSwa%2FN%2FTq352Al3Y%0A9DXAR7q24c1w7LV3Qw%3D%3D%0A)

2. En masse

Rendez-vous dans la liste des clients et cochez les clients pour lesquels vous souhaitez modifier la catégorie tarifaire affectée. 

Dans la liste déroulante *"Choisissez une action à effectuer"*, sélectionnez *"Éditer les préférences"* et validez. 

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1699380211/6efd7d81f525afed3647a25e956f/1.png?expires=1788635700&signature=37fb12867f4a6fdf6af19e139fe8f78040010235e97340424882a3bd50f282ab&req=dSYuH8p2nYNeWPMW1HO4zXivUV5C2%2FMyJpdhVmtetGVm52iWAoXCKQI%2FEvhh%0AbuJnkg1Wal3a6UFLUSs%3D%0A)

Sur la page suivante, sélectionnez le champ *"Catégorie tarifaire"* puis la catégorie tarifaire souhaitée dans la liste déroulante et enregistrez. 

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1699382587/007e425f1539b2b74a1b6c440664/2.png?expires=1788635700&signature=d5e49aeb55b35f162f1180a0893aa0874e983206c655e48649233112287a16b8&req=dSYuH8p2n4RXXvMW1HO4zcYrtqPNV1QFuoa0z7a79WHXjtiRSyu30sEndtWv%0ABnI2EZ0fJsuK87enlf8%3D%0A)

### Choisir une catégorie tarifaire lors de l’édition d’un document

À la toute première étape de la création d’un document de vente, vous avez la possibilité de choisir une autre catégorie tarifaire que celle renseignée par défaut. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444829609/54f3913f77c246abb496eb48/fbsyLQq4-xquZOnJF58pDTQ2moBJrss9x24LsGsuYf7-FJvrNM4jFsjLR0BnNpnPGtLY5rODbYc-Z7T1y1M4cGKeXbF5GqoludsgDvGvlTee7h1naJOO0vL8a0v6d9ujJkLR1Wdi?expires=1788635700&signature=9f13e9cf6700e6f6bf290c40ed94f45123ebbbd24988d70088c599c758b704e7&req=cCQjHst3m4FWFb4f3HP0gLj4a7w3PhsBKq72jVjYHWhpt%2ByJhAJmZhn6bx8u%0AXDGYdMwAZSEZn%2FYUyg%3D%3D%0A)

> **Attention :** une fois le document créé, la catégorie tarifaire ne peut plus être modifiée.
