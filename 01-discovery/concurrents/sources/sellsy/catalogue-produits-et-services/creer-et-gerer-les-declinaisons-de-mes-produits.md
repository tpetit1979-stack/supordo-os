# Créer et gérer les déclinaisons de mes produits

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261798053/5526d9abe253ab3909f18e43d3e6/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=617db4b7eddc1d5ef9781d46e3e9b45569bcde3de46116e37d2f7bcafa3cbf7f&req=dSIhF853lYFaWvMW1HO4zXSQEGkKWQiJ5yOmE0pyOvp47QCBDKSiB%2BHLWmi%2F%0ALQq4qRwJR%2Brhed5FA%2B4%3D%0A)

Sellsy vous permet de gérer facilement des déclinaisons par produit. Vous pouvez donc, à partir d'un produit parent, créer des variantes.

Les déclinaisons sont entièrement paramétrables, il peut s'agir de tailles, de couleurs, de formes, etc. 

> **Bon à savoir :** 
> - Sellsy vous permet d'ajouter jusqu'à trois variantes par produit (par exemple : taille, couleur et matière).
> - Si vous souhaitez [gérer les stocks d'un produit décliné](https://help.sellsy.com/fr/articles/5876565-activer-la-gestion-des-stocks-pour-les-declinaisons-de-produits), il est impératif de n'activer la gestion stocks qu'après avoir créé les déclinaisons.

___________________________________________________________

### Créer une déclinaison de produit  

Pour créer une déclinaison, cliquez sur *"Catalogue"* dans le menu latéral à gauche de l'interface puis sur *"Déclinaisons"*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444826013/6d24169238a5f25dfa6997a5/7mu13sQrijJF7xD31GbYq5AGRojNQfIMRIQWGz07TgxF-Uc4wreiJDE1Hl24BnS2D8PEPpI_yzm2Axhnz_2acyGIzBRQvng1HDL7ssC2u2h9mI4s1GwpEZcc2CbRyOu_8L2bPnv0?expires=1788635700&signature=255532030c2f7e0cd48dd4a2897ef23aec41aec7396fa6b6fa6951cb1ff7e2f3&req=cCQjHst4nYBcFb4f3HP0gLrj7nJ5RqRwYc%2B%2BmnSLauc7BLiRib4%2Bhlq53JOS%0ASa53KCMhWZ7oTmXMLA%3D%3D%0A)

Vous arrivez sur la page de gestion des déclinaisons. Cliquez sur *“Ajouter une déclinaison”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444826026/75a9c1b0638e353754bf53be/sWGzPkjm4bLWMZbxi220dk6_JQwqbIUbfDoQjN9M5auPQgcj2zlbWsLmqnbCjCc9I5mxCPB7amRVrhRAeFLJTQMrgLZ8yLIrLMmQuKcWko0y33xeuTIT5raHcaGMCzqenIhqIFSW?expires=1788635700&signature=e500c6ea0bf75a89f6f1653d8a1853dec70ea36d798d013cda6c1c92c4b1dd5b&req=cCQjHst4nYNZFb4f3HP0gN21HuH6P3CfH%2B13wIhyPaku%2BMXciV91XVLWbrDZ%0A1wYDR9pEDBKGCZppfg%3D%3D%0A)

Dans la fenêtre qui s'affiche, donnez un nom et un code à votre déclinaison. Cliquez ensuite sur* “Ajouter une valeur”, *puis entrez le code et le nom de la valeur.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444826035/0a125e437ad06965eadc5c1e/tU6h6Eny0yLMc3zT3FMTGhYuZusuWPnoCJwE8ocRnyQZ3TyvhIsaZwOCjd3DwBYxRlLTv4miTdBwolgmaWRK_8SMNT4x1lJyNTZWcU4fKQvVXhMFKNgzuujkJqFpAJRk5mgdm5R7?expires=1788635700&signature=cf8eecb77a431437409c9dd40aa191bf9c28053d65e9812a050cdcfe6df6824c&req=cCQjHst4nYJaFb4f3HP0gJi%2BJ5IPwLqTfFPvucxbXQ2XsIyF5wBNNOabyn6h%0A4%2FI4MKZ81F2vbmCTfg%3D%3D%0A)

Quand vous avez terminé, cliquez sur *"Enregistrer"*.

Si besoin, vous pourrez toujours venir modifier la déclinaison plus tard afin d'y ajouter de nouvelles valeurs. 

> **Bon à savoir :** le code de la valeur permet d'identifier facilement les déclinaisons lors des imports ou via l'API. Entrez un code simple et unique, si possible mémo technique. Attention, une fois qu'une déclinaison est utilisée dans un produit, le code de la valeur n'est plus modifiable.

Votre déclinaison est désormais créée. Voyons maintenant comment l'utiliser sur un produit.

> **Attention :** Assurez-vous de bien choisir toutes les déclinaisons souhaitées à l'étape de l'activation des déclinaisons. En effet, il n'est pas possible d'ajouter une nouvelle déclinaison à un produit déjà décliné. Il est uniquement possible d'ajouter des valeurs d'une déclinaison déjà activée sur le produit.
> *Exemple : *
> *Vous activez uniquement la déclinaison "Taille" sur un produit : *
> - *vous pourrez ajouter de nouvelles valeurs de taille sur ce produit : XS, XXL, etc. *
> - *vous ne pourrez plus ajouter la déclinaison "Couleur" à ce produit*

### Gérer les déclinaisons 

À ce stade, chaque déclinaison se comportera comme un produit distinct dans votre compte Sellsy.

Le produit parent ne pourra plus être ajouté dans vos documents, uniquement ses déclinaisons. 

Chaque déclinaison dispose de sa propre page produit, accessible avec le bouton* “Aller sur la déclinaison”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444826091/347d553c82e42ab7c247d9af/65qIYUvkDWUV-A3UfOgEoVS4L1L7IW1Wpfv2aFinNSr7QEDN0zZnnlhdmfS1lB69ZrYLBgoqRREzfvBxzbp9djNkA6JSHk-J-4O3kL7n1t5PEtTJXBRB99faf_pBj7OBKGcc-5VC?expires=1788635700&signature=49f02cf54487dca41e8613bc56594fed0a14d4a1b170b97ee3dd2e3464deee50&req=cCQjHst4nYheFb4f3HP0gIYqYrp1RBRNAvcST28VvKM7E4p9%2FwmYsydOcKcv%0AjtEQH6bHwwYDXzmcxQ%3D%3D%0A)

Quand vous accédez à la fiche d'une déclinaison, une mention est affichée sous le nom du produit :

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444826104/33be8a562bb8b55cc9f430ef/6r9xmMoBQ8ZrYN_p5ndUocpEmOkH4GPokImHd1nNiYK4PLMVW5gIcWCVATV0I1m17GIdaKh2MpF41O7m7d6l34TbwBfDGMo4uNuJLWHNw5XCwaE64gZDDJYRFFZj1o3zNoaNdkN6?expires=1788635700&signature=84306c1037b24d82c9de23ab70a807dc77af92c06dfa957ccbafb9a8358bd77f&req=cCQjHst4nIFbFb4f3HP0gMkrTWxfykYLT7D1yPpP4WJCCN7I5WmODaC2pSTg%0Aowr13mUkYgEt8cIdAw%3D%3D%0A)

Ainsi, vous pourrez gérer facilement les différents éléments composant votre déclinaison, comme les images, la description, les statistiques de vente ou encore le code barre.

Tous ces éléments se gèrent exactement comme sur une fiche produit simple.

> **Bon à savoir : **
> - Lorsqu'un produit est décliné, il n'est pas possible de revenir en arrière. Dans ce cas, nous vous conseillons d'archiver le produit décliné puis d'en créer un nouveau sans déclinaisons.
> - L'archivage est disponible uniquement sur la fiche du produit parent et a pour effet d'archiver la totalité de ses déclinaisons.
