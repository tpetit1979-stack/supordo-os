# Gestion des codes promotionnels

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261799216/42bebbdf871c6a6ea116bbadd345/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=04c39ac0c0039a619e792f155f89460df39f27738010b04306981503e34f3d4e&req=dSIhF853lINeX%2FMW1HO4zb5F3xFHsGlQeEdTVe3kOq5EBGQ%2BknEqU240Bse2%0AaPRrw%2Bi9e2vSTkpop6I%3D%0A)

Sellsy vous permet de gérer très simplement vos opérations de promotion via des codes promotionnels.

___________________________________________________________

### Créer un code promotionnel 

Pour créer votre code promotionnel, vous devez vous rendre dans le menu “Catalogue” et “Créer un code promotionnel”.

Une page d’ajout d’un code promotionnel s’ouvre.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444840270/7cd6eba6c275a987c4330e86/ymoF9PvHu97zXpMkYyZpv8Y8VOCpxxxI4AHZuQfDpOpeINRy3Bu7g5BCDd5mXhtr4PPPI-9adY07J5GVUSe3yfXdUyTKesYdlfW_WCADsXVfupVh-KXQAH3G0i1q9FwvyE8-k-Sm?expires=1788635700&signature=c9b247a5d281e7d5a0bd810443c21a4473b0437e8c90e3e55e7029235a79d336&req=cCQjHs1%2Bn4ZfFb4f3HP0gDLCXovaMpJF%2BJd8fmateb6oVDZ%2BW%2BX4efrz17F9%0AVkPHz6Ck3kmwq4bb9Q%3D%3D%0A)

Pour chaque code promotionnel, vous pouvez définir les éléments suivants :

- **Code : **Un code promotionnel que vous pouvez générer (ex: 8OZUHFK) directement,
- **Quantité totale disponible : **Une quantité totale disponible du code promotionnel,
- **Quantité totale par utilisateur : **Un nombre total d’utilisations du code promotionnel pour un utilisateur,
- **Frais de livraison offert : **Si le code promotionnel offre les frais de port ou non,
- **Accessible aux types : **Si le code promotionnel est utilisable par des prospects ou des clients ou par les deux,
- **Montant total HT de la commande exigé : **Un montant minimal de commande pour que le code promotionnel s’applique.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444840282/3d3198ec95415a226868d933/_o95pb7oMeGtZOKuV7hFwGTq13C5EF5vBO6Ad7KMZyTo7PZ5ICX694Q97Xv8XagM0QhGcs3UetWUcGNJ2X_VDV2Aiho99kV2XuZvT2KcUPSd3EGCIzpIawG_wI-SMGTaXBD5S7iG?expires=1788635700&signature=c48d9629a462908c7c8c1461ef9fb821619aee2e1b96e39a6774da38f789a65b&req=cCQjHs1%2Bn4ldFb4f3HP0gNPIzBhi4X0bozXw3ZJjV%2B21AzYDUffO6iYKb%2BnU%0A9PHr28L4F%2FA%2BkJP0IQ%3D%3D%0A)

Ensuite, vous devez paramétrer les détails de la promotion : 

- **Le nom de la promotion,**
- **La description :** vous permet d'ajouter une indication à la suite de la description dans vos documents (devis, factures...).
- **Les dates de début et de fin de promotion :** vous pouvez ainsi programmer une promotion dans le futur. Si vous le désirez, vous pouvez aussi cocher la case afin que la promotion n'expire jamais.
- **La visibilité sur les documents de vente :** devis, factures, avoir, bons de commande, bons de livraison, proforma.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444840294/2040393428a5aed31f224a97/z7CgoXuWdUxFwgsX5HLPqS3vyEIOMbVCFFAejG8RdthDshzp60mCpWWGQZTlVFm2n5br7Q2sQBGcykvgmRbTTFS4GBkj9j2yTuWeiZQzcg7YLrjlMG_mW7vkN5ChtzGXCLnjfXe-?expires=1788635700&signature=94f1c9ec9e03a1343b7c77e6ad0257ae062b7770c2db9e89bd3306c97d02907a&req=cCQjHs1%2Bn4hbFb4f3HP0gCaoFVkXwGBvKciaDp7%2FXBlne3IS6NBSo6gmBU1u%0AAu4eQZml6OFrsAzuGQ%3D%3D%0A)

Ensuite, renseignez le type de la réduction ainsi que sa valeur. Pour finir, choisissez les catégories tarifaires concernées par le bon de réduction puis validez en cliquant sur “Enregistrer la promotion”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444840301/c1db376b9484072890c92b7e/aAYhyLg33R2avwMO8T_H6VcUYQdH9nxZmpufT6_B2o2ouQv92E2nd6YuEFGNsoueud2q7pMezZoCu5sQw6oRDczhJAgeFb0HOzgpC6u1HP5-vt_jIrZOCyY3QYsmRKWiw-QHg5FX?expires=1788635700&signature=ee261a9173875e066cdf4b2f39cfa48ede85d27e06464f3620324d0a3050e868&req=cCQjHs1%2BnoFeFb4f3HP0gI%2FnjAQTWJa%2FIp25634R0vnsVgi0aoZdvUcrIjRx%0A6kqQP7n6unzmHkgjaA%3D%3D%0A)

### **Utiliser un code promotionnel**

Pour saisir un code promotionnel dans un document de vente, rendez-vous sur “Modifier les préférences du document" en bas de votre document, cliquez sur l’onglet “Remises et acomptes” puis sélectionnez le code promotionnel souhaité.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444840306/ffe0b0f5c807119600f44d8d/kR0U28DxAWU4ffRmz4G0aTO2FXbcMNISHGwIE4INhXzGl4CTuz_oRKZcw1x_w7GdQmOA4W3Jr1255WzVrU53nZ4lScrLnSLQsfNO3c8Z0aUyyQPq4nLjulKcm5MDIQszlJWlikxS?expires=1788635700&signature=e8c7bde012b7f52f08e75a56299a31d97e0c36d7258892ddad5456c1b837a0bd&req=cCQjHs1%2BnoFZFb4f3HP0gByvU77fo%2B%2FXTJexQ2H9zln0%2BVQkqNM3L92Z3vjo%0AcZ1467dR7fYzIRMQvw%3D%3D%0A)

Vous pouvez retrouver vos codes promotionnels dans la liste des promotions depuis le menu “Catalogue” et “Liste des promotions”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444840317/aaa8280b4cde2d45f2e79e57/tpS_0jl6fb6qRceNK6V9ra8OGt6jT16_xc1omBbOYvGOiFNE0KKza4y22it5mLMaQYVQSvdravqeHBrD2GPGbXhrdK1pPhVEGV8fGNiusOaBoBbHCaAZVdfAXSl8EZy_yF-Q1Gfy?expires=1788635700&signature=808efadb69849105bccaf26e69071a1692e6933b7978c0ce80bde392f77a027a&req=cCQjHs1%2BnoBYFb4f3HP0gDcTqzgo9CoB0JyhcX4ZsC%2BUfM4x%2BuLOaMneBYdN%0AIM4l8bKmwAhn991PUw%3D%3D%0A)

> **Bon à savoir :** Le code promotionnel est cumulable avec une promotion catalogue (la réciproque est vraie).
