# Utiliser les smart tags pour trier les tickets de support

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1595646525/42110cca34e88b4ff47f4060500f/FAQ-Bannie%CC%80reAcademy-2.png?expires=1788635700&signature=b93b71b15ecd86308404518bc877ec0fc794cbd8a8b8faf3ed54e3d4b68ca5a4&req=dSUuE896m4RdXPMW1HO4zSIyTq3eArtQj24TWLJ%2Be8rFVCNm4MMi1Zd%2F99aS%0AoP0BuECxcYfG%2BvvxBR0%3D%0A)

Le module de support client intègre la fonctionnalité des smart tags. Ces derniers vous permettent de créer facilement des catégories de tickets.

Vous pouvez par exemple organiser vos tickets par catégories ("*Demande de fonctionnalité", "Bug", "Problème bloquant".*..) ou créer des statuts de priorité (*"Urgent", "Normal"*...).

Pour créer un smart tag, entrez le simplement dans la case lors de la création du ticket puis cliquez sur entrez. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446346609/f6ad8aff79736b1c2a635bcb/11nisVMS6cmBwnsxLAj0UpNRiFAIuXxWfHE9EhOked6ZpGRzGQx8pKIUs27fgbwqtPt0Tp1gg2hlKaUMhlgXY7HNZ9mJ5wvi-HQ_V2FjorTIirqcFtVO_V1dRdxmf46wqZRxMiDw?expires=1788635700&signature=2b957d338be3b36559d33c845d9baee2aaed1752bd4bf024440e32ccf3b98c60&req=cCQhFc14m4FWFb4f3HP0gGaMjz99ksm6xU7rAF4Yx%2FAj1ofqvreiarHmi9Dq%0AIz8qOIM9nQzY2HKPDg%3D%3D%0A)

Pour filtrer vos tickets par la suite, entrez un ou plusieurs smart tags dans les filtres de la liste de tickets.
