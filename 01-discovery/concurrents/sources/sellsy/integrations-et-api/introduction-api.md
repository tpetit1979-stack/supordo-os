### **API** 

L'API (Application Programming Interface) sert d'interface entre deux applications différentes afin qu'elles puissent communiquer entre elles. Sellsy met à disposition son API **gratuitement** pour vos besoins d'intégration.

L'API vous permet de :

- Synchroniser vos données entre Sellsy et d'autres applications
- Automatiser des processus de création, modification ou suppression de données
- Développer des intégrations personnalisées adaptées à vos besoins
- Connecter Sellsy à votre écosystème d'outils métier

___________________________________________________________

### **Qui peut utiliser l'API **

**Avec des compétences techniques**

Il est conseillé d'avoir des notions en développement pour utiliser l'API directement. Si vous ou votre équipe disposez de compétences techniques, vous pouvez exploiter pleinement les possibilités offertes par l'API Sellsy.

**Sans compétences techniques**

Dans le cas contraire, des intégrateurs tels que **Make** ou **Zapier** peuvent vous aider à connecter plusieurs applications entre elles sans écrire une seule ligne de code.

> **Bon à savoir :** Pour en savoir plus sur les intégrateurs, consultez [cet article](https://help.sellsy.com/fr/articles/7924203-connectez-sellsy-a-vos-outils-preferes).

___________________________________________________________

### **Quelle version de l'API utiliser **

Sellsy propose deux versions de son API, chacune ayant ses spécificités.

**API V2 (recommandée)**

Une version 2 de l'API est actuellement en phase de développement. **Nous vous conseillons de l'utiliser en priorité** pour vos nouveaux projets.

**Accéder à la documentation :** **[API V2](https://api.sellsy.com/doc/v2/)**

**API V1 (toujours disponible)**

L'API V1 reste disponible et fonctionnelle. Elle dispose actuellement de plus de possibilités que l'API V2.

**Accéder à la documentation :** **[API V1](https://api.sellsy.fr/)**

> **Bon à savoir :** L'API V2 ne dispose pas encore de toutes les possibilités de l'API V1. **N'hésitez donc pas à utiliser les deux versions si nécessaire** pour couvrir l'ensemble de vos besoins d'intégration.
