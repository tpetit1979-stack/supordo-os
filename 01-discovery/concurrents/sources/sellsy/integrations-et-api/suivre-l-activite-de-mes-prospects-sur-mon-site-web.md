# Suivre l'activité de mes prospects sur mon site web

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2159326096/f79d121a91becc1c2fd056783827/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=bfb2a140e503891049111f1cee0b33997793c0e9f2923d6f4879fa9c95594df0&req=diEiH8p8m4FWX%2FMW1HO4zb%2FO5qc9yc%2BPF6KVSq9F%2F2m6sFDo0F77qOXjH8i4%0A%2FC2Wt4f0AmYKrsU9vzk%3D%0A)

Dans une optique de conversion de vos prospects en client, il peut être intéressant de connaître le parcours de votre prospect sur votre site web.

Pour activer le tracking, cochez la case “*Tracking des clients/prospects*” lors de la [création de votre widget. ](https://help.sellsy.com/fr/articles/5876628-comment-creer-et-personnaliser-mon-premier-widget)

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446375628/7411177c59bd6b6d5d9c1444/0Ao4AvNVOt7KNwHj2FqObWhfHOwInnOIx0DYNfbICf31xYl3x04b1h7eERfg9dHnf67Be5643jiDMX44f4qkmsucNrygGxJPtJILR3wWPjIQKrJueJpme-2xs4bxPSFg6RNEdGCc?expires=1788635700&signature=8fe0ddbd4487cd487f3d10686629c694a044473eacf4b9c6ed2163cd50fcc6fc&req=cCQhFc57m4NXFb4f3HP0gKyGrtm31cRx%2FM3RG260M64tauBF18tfGPu38YKE%0Au1PQwhHhepGrUF%2Bx1A%3D%3D%0A)

Une fois l’option activée et le widget présent sur votre site, l’ensemble des actions du visiteur de votre site web seront stockées dans un cookie sur son navigateur.

**Utm_source :** Si une utm_source est présente dans l'url lors de la soumission du widget, il sera utilisé dans la source de l'opportunité créée.

> **Bon à savoir :** l'utm_source est stockée dans un cookie. Donc si votre visiteur navigue sur votre site, puis valide le widget, alors l'utm_source ainsi stocké sera utilisé.

Toutes les pages (disposant du widget) visitées par un internaute sont enregistrées. Puis lors de la soumission du formulaire du widget, ce dernier va récupérer l’ensemble des données de navigation pour les enregistrer et récupérer le parcours de votre visiteur.

Vous pouvez retrouver le parcours utilisateur sur la fiche prospect de ce dernier, puis dans le menu nommé “*Tracking widget”*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446375633/4a260b261e98ac8082c5b989/BGZbpjmMJ_xMQcdN1mlEUUE_nQuoo087xB8fFjg6H8lrvNEf2SmJLayOj8fZ_ZHHRrdP1NjMs4SlArEAc9cJ2EiQhhqunFIqJzAdT_o66tWcKpo7k9D_5n2EzXhUt14i48ono77e?expires=1788635700&signature=1b3799d5fc8080cd129fbe3caa7be51930d2bbf29f05de1e22fc03b44b3ff3d1&req=cCQhFc57m4JcFb4f3HP0gNye11%2BxnyUxx6tOftXnun8dNRN1h%2BNuB42he2XR%0ABs%2FelaIjfibRAWiutQ%3D%3D%0A)

Sur la fiche société, vous retrouverez la rubrique *"Activité"* et vous pouvez filtrer par activité de type tracking.
