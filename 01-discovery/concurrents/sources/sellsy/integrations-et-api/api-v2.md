### Création d’un token 

> **Bon à savoir :** Le niveau de privilège de vos tokens dépend du niveau de privilège du créateur. **Il est donc recommandé qu'un administrateur crée l'accès API** pour bénéficier de tous les droits. 

Depuis votre compte, vous devez vous rendre dans la rubrique *"Menu" > "Réglages" > "Portail Développeur".*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/454004222/8038da29c9fe9e822e844d42/a2b5b06f-1dd6-4b73-8892-2b0d45daa940?expires=1788635700&signature=2ae67656fbbba701d2ecc64ff165a4c3a07da7287099b22f6c6adcc1d409fdf8&req=cCUjFsl6n4NdFb4f3HP0gCKR%2FC4puK7pWKfW9gBrVFw1cM%2F8UB4wzgjFVAJw%0Az1PS5VzkGnTOh%2FQMMQ%3D%3D%0A)

Depuis la page développeur, vous trouverez un nouvel onglet API V2 (bêta). Cliquez sur *"Créer un accès API"*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/454004228/e156ea2973ecc4e7f4cc86d8/a7dd2f00-0134-4526-8be9-570c8f9e1c14?expires=1788635700&signature=606a2c3b444d4dbe49935775dd1bac92dd9b7324df50287ed41073357bba784c&req=cCUjFsl6n4NXFb4f3HP0gEtAOakkzh1rNoAF8mGfuNyOURSN0h7ozrl78Vrd%0AKngMIMK3q4U5I2zq4Q%3D%3D%0A)

 
​[3 types d'accès](https://help.sellsy.com/hc/api-54ff3eba-c44a-42a7-b9d0-47524bd81ab9/types-d-acces-api?searched=true) sont disponibles.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/454004233/8d3b2944ea184129403eb2da/15ad6652-3308-4046-8d8d-8f72d125d507?expires=1788635700&signature=4c40e95783db9d5c7fe7fa10b4492312311fe1ceadb2c82419a749f56089f4bb&req=cCUjFsl6n4JcFb4f3HP0gBTI54xFLImjgRUqgoHNwKa%2F4dTSrSAqp9z5DqmL%0AcJEwgEf39IbjshZ19Q%3D%3D%0A)

Définissez ensuite le nom de l'accès ainsi que le collaborateur lié à l'accès API puis choisissez les autorisations que vous souhaitez donner à votre accès API. 

Les scopes permettent de limiter, si nécessaire, les droits de l’accès. Si vous ne voulez aucune restriction, il faudra donc tous les cocher. Cliquez ensuite sur *"Enregistrer"* en bas de la page. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/454004236/2774c6ab28eb98547c850004/ac01350d-f871-47b3-ab8b-bc8c0dd6497a?expires=1788635700&signature=c3fcebadb21412f426d2897faf4c657709f0490d3017605111643d45c18b5c2b&req=cCUjFsl6n4JZFb4f3HP0gLKGKdF91nHED9FnzFHzCL8QlTLFmlfqXiC74%2Beu%0AVeQVYhxBH8pF%2FL4DMA%3D%3D%0A)

> **Bon à savoir :** L’URL API pour une authentification en V2 est : 
> [https://login.sellsy.com/oauth2/access-tokens](https://login.sellsy.com/oauth2/access-tokens)

Vous pouvez retrouver plus d'informations sur l’authentification dans la rubrique [API management](https://api.sellsy.com/doc/v2/#section/Authentication).

> **Attention :** Si le compte du collaborateur venait à être désactivé ou supprimé, les tokens associés deviendraient automatiquement inutilisables. Le créateur des accès API doit donc toujours avoir un accès à Sellsy.
> ![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1385548403/afb37171995dfb8677db4db47b39/V2.png?expires=1788635700&signature=1d80831566d77cd5c1fad1a12f96d236ba446002f4c05ecf607e724959e6dc30&req=dSMvE8x6lYVfWvMW1HO4zdlhuuvkss5JEIZDqdkhaGyKqRsCDSblIuB%2FyIN3%0A3fvygHBIJ8NpVwcHRGA%3D%0A)
