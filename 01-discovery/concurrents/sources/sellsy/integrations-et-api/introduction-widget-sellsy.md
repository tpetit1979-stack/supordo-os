# Introduction : widget Sellsy

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2159315823/8b7045b583140e87a20839c79ea1/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=b7d114d074c549e9d1e0c428c9aff385195f9268666758a40e869be6f1afe4d2&req=diEiH8p%2FmIldWvMW1HO4zdLwIkRqNdMRNyx0m9hFb4o2nArWCmfT5XAWFj3t%0AuV0KnDeAXhgIJZYHjQ8%3D%0A)

Sellsy vous propose gratuitement un widget que vous pouvez très facilement placer sur votre site web.

Le widget Sellsy vous propose plusieurs fonctionnalités que vous pouvez combiner :

- Un formulaire de support (crée des tickets et nécessite le module support),
- Un formulaire de contact (crée des opportunités et nécessite le module CRM),
- Le tracking des clients/prospects,
- L’envoi d’une copie de la demande par email.

Si vous n'utilisez aucun de ces modules, vous pouvez quand même utiliser le widget en utilisant la fonctionnalité de transfert par email.

L'utilisation du widget Sellsy est entièrement gratuite.
