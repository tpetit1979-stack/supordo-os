# Personnaliser le formulaire d’inscription aux campagnes marketing

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2159332619/f4c0df33b102cd5ae353de117174/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=73e5ee975c686ca618258453eac1a0988726260862f3e437f77403db0c60b658&req=diEiH8p9n4deUPMW1HO4zRC9ivrtNhc0%2BK0aJKzJtLFdxHs1z6rF%2FEODorO6%0AOlX6FtOFsGU2r4fMW2I%3D%0A)

Rendez-vous sur votre menu puis sur “*Réglages*”, “*Portail développeurs*”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446445293/34acf90574329371f3a3742a/foVEpWLvHmiwYLpweNGtiweSk8BhfWwRE4xVJf8UOMNDcTecDX1XAwfu-k55uyiChpGzeokfeg1Ro8p902zUYu5AJP-46_06NkTMyxRSCKOgqgQgSLeGy6pJX9n1fXepzjNJNog8?expires=1788635700&signature=d0db3f7e50a84c18875d3bed53dcdf187e88dd81a38ee205d7c8c43748b68e4b&req=cCQhEs17n4hcFb4f3HP0gCmT2vCrXckqVS9a7rKRrDkkRncRA8wdDHm5mXyK%0A%2Fj6WKQyx7wR%2BZO6fhg%3D%3D%0A)

Ensuite, cliquez sur l’onglet  “*Widgets*”. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446445311/51ea76673b625d1d06b52245/eW8wK8-xuWEWZemHMAuNqW8hEupU-OgZWDbAs8jpz02W2HX74gqjaHHfbtKQAMIR1v5fgOVwoifBUQbLaM6nC1Z9JTxBVYSNDKBm_iMNW_NRxFIeWAN5J-waGnOdtl_RbMDWdWDU?expires=1788635700&signature=437308e81221f400a18018f848540d8d1cf9d692bbb7ae716e97b3fb4bb6f9c9&req=cCQhEs17noBeFb4f3HP0gArydJe5h99nIPLyC9E%2F6cv7%2Fs4sywws8cn7MVBH%0AGFdLlS6ht6MB0dq%2FYw%3D%3D%0A)

Cliquez ensuite sur *"Ajouter un Widget”*. 

Vous pouvez retrouver un champ “*Inscription campagnes marketing*”. 

Il permet de proposer à vos contacts de choisir s’ils acceptent d’être contacté par votre société selon différents canaux (Email, Téléphone, Sms, Courrier).

Si le contact choisi la valeur **Oui** alors il sera automatiquement inscrit aux types de campagnes : Email, Téléphone, Courrier, Marketing personnalisé.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446445318/56d53af0689d4ea40e30e255/ak_dQaSajqf0Q24c_m3llKb_Hek0XrTL4-wxuwacuP04BC7-1RRUgJsXkFNopA7ibmzt7DJLrUbNQygZjrJ385yT7DFzI5LX6qK7qNgTAOvx0E0V4PKjzqsrdfDJmlLEaWuiE50d?expires=1788635700&signature=83c822648ff6db9d2ff62ac777a4a59a8818d3a9ae67811c04f00d042c63a69c&req=cCQhEs17noBXFb4f3HP0gMBD8Oqfq%2BqeqTXj4u4zWGvt4g1cqB72L7IgLmfR%0ATbISunvYZSvHM%2B4qAA%3D%3D%0A)

Ce champ sera ajouté au formulaire du widget : **"J’accepte d’être contacté par la société Sellsy."**

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446445321/3b7f21f0ef252e813b0fa125/S-KyqTlH9GM-JFI9gZEMlNhRCLlhQ-N_S3AgLjhkTCoC2rlYGotIjJiFfYZcQIK1YKk9rjEtmDkGugnuhWn6EsW8O4aartc4SXmOUs7ezbwSChNN1N1nlPWWe-1-9ffs-B0tMx-p?expires=1788635700&signature=25178a5fbcac7a6139cf6abaad29a2b874aa2cee45f9a84a31c26f1b4be18e60&req=cCQhEs17noNeFb4f3HP0gHkBj8WcNwTO9Y%2BrC4%2FeDNJKV%2Fdna%2FXt0LcdrExA%0Amo%2F%2BsOmIuLKvOCAKNQ%3D%3D%0A)

Il est également possible de modifier le libellé de ce champ dans la rubrique *"Texte"* de la configuration du widget.
