# Installer un Widget Sellsy sur mon site web

Une fois votre widget paramétré, il apparaît dans la liste des widgets.

Pour l'installer sur votre site, c'est très simple : 

- Copiez le code de l'encadré dans le code source de votre site web.
- Dans la plupart des cas, si vous en disposez, vous choisirez une partie de votre site présente sur toutes vos pages, comme le header ou le footer.
- Si vous utilisez un CMS type Wordpress ou Drupal, nous vous conseillons de choisir le fichier de votre footer.
- Si vous ne maîtrisez pas les aspects techniques, vous pouvez demander à votre webmaster.
