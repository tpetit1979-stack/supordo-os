### Les connecteurs natifs

Depuis votre compte Sellsy, vous pouvez retrouver l'ensemble des connecteurs natifs ayant pour objectif de vous faire gagner du temps. Vous pouvez retrouver ces connecteurs depuis *"Menu" >  "Réglages" > "[Module Externe](https://www.sellsy.com/settings/home/external)".*

![](https://downloads.intercomcdn.com/i/o/745286517/cfa1c1fcf2272245ded6f93b/Connecteurs_natifs.png?expires=1788635700&signature=23af0afce9b143cb4f1b0830646f04f21dd38a6b0db008276aa235bffa0acbbb&req=cyQiFMF4mIBYFb4f3HP0gPihltiHjE7prE1irIR7oX1P9lo1iJh6tt83ZdIl%0A9KlHgwACSzIQYq5e4w%3D%3D%0A)

Ces connecteurs sont directement intégrés à Sellsy. Ils sont disponibles dans la page *"Modules"* de votre compte Sellsy. Exemples : [Stripe](https://stripe.com/fr), [Paypal](https://www.paypal.com/fr/home), [Dropbox](https://www.dropbox.com/), [Google Suite](https://workspace.google.fr/intl/fr/)…

![](https://downloads.intercomcdn.com/i/o/745289971/e33d72f473bcb80998a2718b/Modules.png?expires=1788635700&signature=d43806830cb21cd5b0239debb950b811555bcf0e8ae0ab014603857bbb033588&req=cyQiFMF3lIZeFb4f3HP0gFHlcFXHSGLKIthm5n9hMiyDpDrfCHKftTus5LA2%0AqAtxu%2Bot%2F94A76wdlQ%3D%3D%0A)

Entre également dans cette catégorie notre plugin [Wordpress](https://help.sellsy.com/fr/articles/5877018-module-sellsy-pour-wordpress), qui vous permet de créer facilement des formulaires de capture de leads. Les activer est simple et gratuit.

### Les connecteurs partenaires

De nombreux sites ont créé des intégrations avec Sellsy dans leur propre interface. Exemples : [Plezi](https://go.sellsy.com/applications/plezi), [Modjo](https://go.sellsy.com/applications/modjo), [Inqom](https://go.sellsy.com/applications/inqom)...

Dans ce cas de figure, l’activation de l'intégration est à effectuer directement chez le site partenaire.

Marketplace Sellsy

Vous pouvez retrouver l'ensemble de ces connecteurs sur notre [marketplace Sellsy](https://go.sellsy.com/marketplace).

Quelques exemples des connecteurs :

- [Ringover](https://go.sellsy.com/applications/ringover) pour passer vos appels en 1 clic depuis Sellsy, vous permettant également d'historiser directement vos appels dans le CRM.

- [Xeno](https://go.sellsy.com/applications/xeno), pour attirer, convertir et fidéliser vos clients. Un chat en ligne entièrement intégré à Sellsy.

- [Plezi](https://go.sellsy.com/applications/plezi), [Webmecanik](https://go.sellsy.com/applications/webmecanik) en tant que solution de marketing automation.
- [Shopify](https://go.sellsy.com/applications/shopify), l'une des références sur le marché du CMS e-commerce.
- [Pennylane](https://go.sellsy.com/applications/pennylane), la première plateforme qui réunit logiciel de production pour les experts-comptables et outil de gestion financière pour les entreprises.

 Make

[Make](https://help.sellsy.com/fr/articles/7994804-make)  est une plateforme no-code, à l’image de Zapier, elle vous permet de bâtir des scénarios complexes de manière intuitive et visuelle. 

N8N

[N8N](https://n8n.io/workflows/2465-building-your-first-whatsapp-chatbot/) est un outil d'automatisation no-code open source. Il offre la possibilité de connecter des applications et d'automatiser des workflows. De plus, il permet de créer des agents IA pour lier Sellsy à l'intelligence artificielle. Ce qui distingue N8N des autres outils similaires, c'est son approche orientée vers les développeurs, tout en restant accessible à ceux qui n'ont pas de compétences techniques, même s'il demande une certaine technicité.

Zapier

[Zapier](https://help.sellsy.com/fr/articles/5877017-zapier) est une solution pour connecter des applications en ligne (SaaS) entre elles. Le connecteur permet à ce jour de gérer les clients, les contacts et les opportunités. Vous pouvez donc l’utiliser pour toute application susceptible de créer ou mettre à jour des contacts dans Sellsy, par exemple un outil de gestion de landing pages comme Unbounce ou tout simplement les nouveaux inscrits à vos newsletters Mailchimp.

Synchron.io

[Synchron.io](https://go.sellsy.com/applications/synchron-io) permet d'interconnecter rapidement divers outils et d'automatiser les processus facilement. Contrairement à d'autres intégrateurs, la connexion est payante, mais justifiée par une assistance et un connecteur de qualité, particulièrement utilisé par les utilisateurs de [Shopify](https://go.sellsy.com/applications/shopify) et [Prestashop](https://go.sellsy.com/applications/prestashop).

### L'API Sellsy   

Une API (interface de programmation) permet à différentes applications de communiquer entre elles, d’automatiser des actions répétitives et de partager des données en temps réel.

Ainsi, par exemple, grâce à l'API, il est possible de connecter votre site e-commerce à Sellsy et de générer automatiquement une facture dans Sellsy à chaque validation de commande sur votre site.

De multiples partenariats ont été établis par Sellsy, offrant ainsi une intégration avec divers outils via un large éventail de connecteurs.

Vous pouvez vérifier si un connecteur est disponible sur notre [Marketplace](%E2%80%8Bhttps://go.sellsy.com/marketplace).

Si votre outil ne fait pas partie de cette liste, et qu’il a une API ouverte, vous pourrez connecter Sellsy par un script ou un développement spécifique ou un outil no-code grâce à l'[API Sellsy](https://help.sellsy.com/fr/collections/3289358-api) 

Pour développer un connecteur avec l’API, vous avez trois possibilités :

- Déléguer la gestion et l’exécution de votre projet [aux équipes de Sellsy Services](https://go.sellsy.com/services)
- Utiliser des ressources techniques (développeurs) en interne

- Sous-traiter le projet à une équipe partenaire
