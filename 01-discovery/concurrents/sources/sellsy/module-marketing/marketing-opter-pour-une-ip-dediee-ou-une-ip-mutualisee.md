# Marketing - Opter pour une IP dédiée ou une IP mutualisée

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1909472654/c203ea9f2cc7fdc26cdf16a16862/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=57ca8d31f6c8032118730470a71450f70f3b1df3ca4650f6d6399fcb827a54ee&req=dSknH815n4daXfMW1HO4zXXjdSAdTI7zhzVzc1gwJEfRFz2VLsGJfbXkBlYW%0AtffWmkMe8I86HqBCQOE%3D%0A)

> **Attention :** Assurez-vous d’avoir authentifié votre domaine d'envoi. Cette étape est primordiale pour optimiser la délivrabilité de vos emailings. Pour savoir comment faire, consultez l'article [Marketing - Authentifier un domaine d'envoi](https://help.sellsy.com/fr/articles/8363773-marketing-authentifier-un-domaine-d-envoi)

L'utilisation d'une IP dédiée s'avère particulièrement avantageuse pour la communication interne et les échanges avec une base de partenaires établie. Cette option permet d’autoriser votre adresse IP sur les serveurs de réception, garantissant ainsi une meilleure réception de vos emails, tandis que le système standard de Sellsy Marketing utilise des IP aléatoires gérées par nos équipes techniques.

Une adresse IP "chaude" est une IP qui est techniquement vue comme régulièrement émettrice d'envoi de mails (sans spam) développant ainsi une réputation (bonne, neutre ou mauvaise) auprès des serveurs de réception. Par défaut, Sellsy Marketing mutualise ces IP entre tous ses clients pour maintenir un volume d'envoi optimal et une bonne réputation.

Bien que l'IP dédiée puisse améliorer la délivrabilité dans certains contextes, son efficacité varie selon les usages.  Notre équipe évalue chaque situation et vous conseille en fonction de vos usages spécifiques, notamment pour les envois massifs où une IP dédiée permet d'isoler ces envois. Vous pouvez toutefois avoir votre ou vos IP dédiées qui seront exclusivement utilisées pour l'envoi de vos emailings.

> **Bon à savoir :** Une adresse IP est un numéro de type « 193.70.32.140 ». Chaque adresse IP représente techniquement un serveur et apparait dans l’en-tête du message envoyé.

### Cas où nous recommandons d'utiliser une adresse IP dédiée

- Appliquer les autres paramétrages (email émettrice et tracking dédiés)

- Déterminer l’utilité d’avoir une IP dédiée :
- Envoi régulier : minimum une fois par mois
- Déontologie lors de la collecte et adéquation des emails envoyés avec le contexte du consentement

- Déterminer l’utilité d’avoir plusieurs adresses IP :
- Si vous envoyez beaucoup d'email dans une même campagne
- Et si enjeu d’envoi rapide (vs réception sur plusieurs jours)
