# App Sellsy CRM - Créer un client, prospect ou fournisseur

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1911555479/590a8dba701bdae3cf07af87e988/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=36accc6b32ef47a557cc6d3e62ccdc1adadc071c706cdda6c6b3623b70131d56&req=dSkmF8x7mIVYUPMW1HO4zXReBetEOBo24xHssIIV71716Y6Qza%2F8fHgSkxod%0AVMxdhezbgOWBgsxsAkE%3D%0A)

Pour créer un client, prospect ou fournisseur sur l’application Sellsy CRM, rendez-vous sur le module répertoire puis cliquez sur " Créer" en bas à droite de votre écran. 

![](https://downloads.intercomcdn.com/i/o/759164647/aaa7feceb87b64e951dcddb5/Capture+d%E2%80%99e%CC%81cran+2023-06-08+a%CC%80+11.36.24.png?expires=1788635700&signature=06058c83ba6298b97ec70597589d236cd0fbcb27bc954b97e8fc3a5ffce4c420&req=cyUuF896m4VYFb4f3HP0gMANFHgfeuOiVIc8ChPBKnueM8siWV1UiKsrOGm3%0A4k6nsHVUaBlCM%2FJgug%3D%3D%0A)

 Choisissez ce vous souhaitez créer. 

![](https://downloads.intercomcdn.com/i/o/759166072/12215bd722b73244dcb307a3/Capture+d%E2%80%99e%CC%81cran+2023-06-08+a%CC%80+11.35.21.png?expires=1788635700&signature=9e6690c31fd7dc7f84736e83bc9afb01faf880103c331be84f40672f1f5be807&req=cyUuF894nYZdFb4f3HP0gM3113vJYxiQhl6%2BOALPEP9FN43WJVle%2FumCfs27%0AsrO3OdOk1O1h4OXw2Q%3D%3D%0A)

Puis remplissez les informations suivantes : 

- Le nom
- Le type : client, prospect, fournisseur
- L’email
- Le téléphone
- L’adresse
- Les champs personnalisés

![](https://downloads.intercomcdn.com/i/o/759167697/87d45cbf48231334db190cf4/Capture+d%E2%80%99e%CC%81cran+2023-06-08+a%CC%80+11.41.22.png?expires=1788635700&signature=2e186f3a38f7870f539882efb76576bacfe1491d7b8da16181e6e69a50d74c72&req=cyUuF895m4hYFb4f3HP0gIpGFR2ss%2F5YQrRC8UCeSDZQPueNT8njuVSshTUs%0ANvOPN30b7oxjAXe%2Bjw%3D%3D%0A)

En cliquant sur “Contacts”, vous allez pouvoir définir un contact associé à votre client, prospect ou fournisseur.

Si le contact est déjà existant sur Sellsy, cliquez sur “Ajouter un contact existant”. Vous pourrez alors directement taper le nom et prénom du contact.

Si vous souhaitez créer le contact, cliquez sur “Créer un nouveau contact” puis entrez les informations demandées.  

Il ne vous restera plus qu'à enregistrer les informations.  

Vous pouvez également voir l'ensemble de votre liste de clients, prospects et/ou fournisseurs  sur une carte en cliquant sur l'icône "Vue carte" en haut à droite de votre liste.
