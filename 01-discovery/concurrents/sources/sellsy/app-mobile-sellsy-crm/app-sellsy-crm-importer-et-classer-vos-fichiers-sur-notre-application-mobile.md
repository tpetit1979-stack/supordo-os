# App Sellsy CRM - Importer et classer vos fichiers sur notre application mobile

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1911557384/87cb6008b0ac72d600e72bc9d4f2/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=a74089cb32220d1ca838a0add2cfa1b7175fafc18625d1385ed3958aa7c268ab&req=dSkmF8x7moJXXfMW1HO4zRxAYUkvi8c98voLiTAFfWvBlpMjg6KY%2F3S6D8Qt%0A2pQAyST8jQY32dLYDUc%3D%0A)

Sur notre application mobile, vous avez la possibilité de télécharger, déplacer et supprimer des fichiers (images, sons) sur vos fiches sociétés, particuliers, contacts et opportunités.

___________________________________________________________

### Importer un fichier 

- Accédez à la la rubrique répertoire
- Cliquez sur la fiche souhaitée
- Importez le document en cliquant sur le bouton “Nouveau” en bas de votre écran

![](https://downloads.intercomcdn.com/i/o/756425137/424c4868c6364c58b011de24/Capture+d%E2%80%99e%CC%81cran+2023-06-05+a%CC%80+10.24.24.png?expires=1788635700&signature=a2e934555b57e812f1f494febbac8a3bd9e6a1924721f22f1e6ebe5bdb91adf7&req=cyUhEst7nIJYFb4f3HP0gPXuumtEEaFiyUd5%2FyeIrCWBnGWjMHaJIevBjj6y%0AdeBsxh6WJn3FVkG%2F9A%3D%3D%0A)

Vous pouvez importer des fichiers, des médias et prendre des photos qui seront directement importés sur la fiche de votre choix.

![](https://downloads.intercomcdn.com/i/o/756418861/394e48571042ad29fc231699/Capture+d%E2%80%99e%CC%81cran+2023-06-05+a%CC%80+10.17.43.png?expires=1788635700&signature=5a0bbe572d562cabeebf3454a81f9db47d4e2ad99e387bb51bce1a7e6666a736&req=cyUhEsh2lYdeFb4f3HP0gIU86KKUGYH9oSwtaxYvnQKK%2FMw%2BK87T0gYH0O9q%0AbZW8pWEHqAopYddWgQ%3D%3D%0A)

Ensuite, il vous suffira de cliquer sur les points à côté de votre fichier importé pour le télécharger, le déplacer ou le supprimer.

![](https://downloads.intercomcdn.com/i/o/756437781/92ce62ce9a767dc6d156aaa8/Capture+d%E2%80%99e%CC%81cran+2023-06-05+a%CC%80+10.39.15.png?expires=1788635700&signature=34a2d229d92dff7bcf47bcac52e6d27f4bf636dd071227bcdd51ceff4cfdbe96&req=cyUhEsp5moleFb4f3HP0gAFr9i5OdsL2MyLbz7wJQpTlVlALBW0pI3yfFH%2FJ%0AgFY1piyWESFUnC4ROw%3D%3D%0A)

Par la suite, vous pouvez classer vos documents déposés sur les fiches du répertoire et les opportunités dans des dossiers.

___________________________________________________________

### **Classer un fichier dans un dossier **

> **Attention :** Pour pouvoir classer vos fichiers, il est nécessaire que vos dossiers soient créés au préalable sur la version web de Sellsy.

- Rendez-vous sur Sellsy depuis votre ordinateur et choisissez votre client concerné dans la liste
- Allez dans le module “Fichiers"

![](https://downloads.intercomcdn.com/i/o/643073744/e56a2f4fefc0dc765436de35/Capture+d%E2%80%99e%CC%81cran+2022-12-29+a%CC%80+14.19.08.png?expires=1788635700&signature=ec395bdbe1e8f8081596d6333b7c44ce9520fc41a2037be903ef762f8131e0ce&req=ciQkFs59moVbFb4f3HP0gKCX0QOkeKfl648WGO0mhC5Tqs563rYSxlzGWgoP%0A0aAPuyZ69l7C%2FG%2F%2B3g%3D%3D%0A)

- Puis créez votre dossier

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/643062214/1641a22a53c17990f367478c/WLFvof0Pb9TsmZV4YCWS853HVmF4aUnrga_SS4gSPU-OiM9tE2ZSEOh7Q2EmfKsno4wfXgxDlDvX1aoffbeaJqfBEkdHIAvdtEJRIUkGdg1lX8RlniT3SNKSi5hBytS0h5KaqGi5E0qmz43wT_GylJlHEgui2Fyi9NxJJ4vUq5GIAlBk6zvTH7RrKbVT2Q?expires=1788635700&signature=90647159d0718eacc90f219e1a64892fa4d06eb692759a581d39eede43d98f43&req=ciQkFs98n4BbFb4f3HP0gNMhXi8zGuY%2BAJE4ojAmqqus3%2FP8wKG7rul5v0F8%0AWRzKjfCVVLDAXusSiA%3D%3D%0A)

- Retournez sur l’application mobile
- Accédez à la rubrique "Répertoire"
- Sélectionnez la fiche souhaitée
- Cliquez sur les points à côté de votre fichier importé pour le déplacer dans le dossier de votre choix

![](https://downloads.intercomcdn.com/i/o/756438451/26f474efa0cb13690f6370e5/Capture+d%E2%80%99e%CC%81cran+2023-06-05+a%CC%80+10.25.16.png?expires=1788635700&signature=236ee9ca86d2dbf498e8be3e6ea34b4fe17088c01778e33b9d9e363914a35fc1&req=cyUhEsp2mYReFb4f3HP0gOC2m%2BO9KKxgg81fyJa8mfDwM03rkgfhYhoULtHy%0AGHDd6Zig8wOP6sMJzQ%3D%3D%0A)
