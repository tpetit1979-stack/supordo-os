# App Sellsy CRM - Ajouter une opportunité

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1911573556/6afe381b62eb39a0e28a91924ebb/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=e47540c050f09e93a1048b2c89d71b7e9c7bbe4f65aecd79c968a7e857bbaf53&req=dSkmF8x5noRaX%2FMW1HO4zZLd7BNgw4N2RMQPvHrgAoPGwI3OFOZh2tbNfabH%0AicP%2BNTZoq2T%2BfgP4MB0%3D%0A)

Sur votre application Sellsy CRM, vous pouvez désormais gérer vos opportunités d’affaires. 

En effet, vos pipelines sont consultables depuis le menu opportunités. Vous pouvez également créer de nouvelles opportunités directement sur l’application. Il vous suffit de   cliquer sur "+Créer" en bas à droite de votre écran.

![](https://downloads.intercomcdn.com/i/o/759442451/91c8d9096f0b40893bce9f95/Capture+d%E2%80%99e%CC%81cran+2023-06-08+a%CC%80+17.15.51.png?expires=1788635700&signature=5665a3cae80def44d662fb13e27c6751abde5f9abe6acec3b2ef72612807af3d&req=cyUuEs18mYReFb4f3HP0gGK1KAuQPtM5cZCx66IZqGSDkTSIoWYLdQ4YhWYm%0A%2FyiqkaZjl8JS9MLD%2FQ%3D%3D%0A)

Vous allez pouvoir dans un premier temps, lier l’opportunité à une société ou un particulier existants. 

![](https://downloads.intercomcdn.com/i/o/759444202/b08b40a92e2e5e4984053c76/Capture+d%E2%80%99e%CC%81cran+2023-06-08+a%CC%80+17.20.10.png?expires=1788635700&signature=a373f7ffb15bd8912d20a47ef631d1be162ebb9eb24d9e47a7d0e0022fa8af38&req=cyUuEs16n4FdFb4f3HP0gP9logtVW%2BIQIvN52UsXpW%2BjfhToHvr8cL1NptJK%0AmkG6q8q8cETfeIRT5g%3D%3D%0A)

 En cliquant sur "Détails", vous allez pouvoir définir les détails de votre opportunité : 

- La source,
- La date d’échéance,
- Le nom de l’affaire,
- Le montant estimé de l’affaire,
- Le pipeline concerné,
- L’étape du pipeline,
- Les champs personnalisés associés.

![](https://downloads.intercomcdn.com/i/o/759444878/11aaaf89f550e980dc1da302/Capture+d%E2%80%99e%CC%81cran+2023-06-08+a%CC%80+17.20.53.png?expires=1788635700&signature=fe82508f46b57b2555ec947bfcbd6d59db866da6b9b00869898795d7c7d2993a&req=cyUuEs16lYZXFb4f3HP0gA8TXNGD538vd%2B%2BH%2B459jiiZKZWdvCFpOjfCrrk3%0A%2BpD6GrRY1ENpkbBRQQ%3D%3D%0A)

Pour valider, il ne vous reste plus qu'à cliquer sur "Enregistrer les informations" en haut à droite de votre écran.

Votre nouvelle opportunité sera alors automatiquement ajoutée sur votre pipeline.
