# App Sellsy CRM - Ajouter une activité sur une fiche du répertoire

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1911556959/2114165615fff256ede737d65f7a/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=c67ce41654b17e5437918d414b41ec26b76b0bffdbedd5ff445829932da865e3&req=dSkmF8x7m4haUPMW1HO4zV%2FC%2FNWuQGsUbeAjy8lQN3uhqQpD2QFBlQ%2F9NEbY%0AcILQwi%2B%2BqwUr7WGzo0g%3D%0A)

Pour ajouter une activité sur une société, un particulier ou un contact, rendez-vous dans le module répertoire. 

Cliquez ensuite sur l’élément concerné. 

Une fois sur la fiche détaillée, cliquez sur le bouton “ + Créer” en bas à droite de votre écran. 

![](https://downloads.intercomcdn.com/i/o/759380294/7fac951e62e456c324d06ba6/Capture+d%E2%80%99e%CC%81cran+2023-06-08+a%CC%80+16.09.47.png?expires=1788635700&signature=d7bc0ea2e318acaa704a55ab8f5ad64fcdde4cf05233f0536089fc6423a9c3cf&req=cyUuFcF%2Bn4hbFb4f3HP0gE38Mgxrf1dKiBEqv7Jwq0pgiuRPQV5SsVft2jGn%0AbOdqHg8o6qxDCnbCoA%3D%3D%0A)

 Différents types d’activités peuvent être ajoutés :

- Un appel,
- Un événement,
- Une tâche,
- Un commentaire.

![](https://downloads.intercomcdn.com/i/o/759381898/7eefa9f44a203fe186738666/Capture+d%E2%80%99e%CC%81cran+2023-06-08+a%CC%80+16.12.05.png?expires=1788635700&signature=ac93a19579a1b51fd374321ca4f1ab53d3157bc786076fa00130d995cfbd4d49&req=cyUuFcF%2FlYhXFb4f3HP0gML5tjy2e4jcuxqv22V%2F0ZJ44Ps%2B1Jx4EpV%2B9OvL%0ACZLG%2B0xNOrxB%2B7bFsg%3D%3D%0A)

 Remplissez ensuite les informations que vous souhaitez ajouter à votre activité.
