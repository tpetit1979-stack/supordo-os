# App Sellsy CRM - Introduction : gestion des opportunités et pipeline

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1911572948/1720feba56660d196b83cb58eb3d/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=99ff95be5dfdeedbe31922c6a5d1f1329f4a03ca71d1d46e8377a66abc4311ab&req=dSkmF8x5n4hbUfMW1HO4zbBgNYZs7%2BysSQH4qSyjDmA9%2F1uJrhMAMfrqwzpQ%0Anuzpok%2FNWKg2K1S%2BWaY%3D%0A)

Le module opportunités est désormais disponible sur l’application Sellsy CRM. 

Il vous permettra de : 

- Consulter vos différents pipelines,
- Créer, consulter et enrichir vos opportunités,
- Déplacer vos opportunités dans le pipeline,
- Trier vos opportunités.
