# App Sellsy CRM - Visualiser les sociétés sur une carte

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1911554994/830caa588e97eb0e76fde270d55a/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=21afd1d119fc8d3b135ec8e700f571694b6727e1e669e00e98f7a88aad15a87f&req=dSkmF8x7mYhWXfMW1HO4zapan1AVVtVKbZK2XLKp3kMOyf77jRWoyOYwWBD5%0A3XDyfP5eBPcwdXzQdTE%3D%0A)

Si vous travaillez en mobilité, voir vos clients / prospects sur une carte peut vous être bien utile lors de vos déplacements. 

Pour cela, nous vous proposons de voir les sociétés de votre répertoire directement sur une carte depuis votre mobile.

Rendez-vous sur votre application Sellsy CRM, puis dans répertoire. Un bouton vous permettant d’accéder à la vue carte se situe en haut à droite de votre écran.

![](https://downloads.intercomcdn.com/i/o/759148528/f656680e6207cb14f98e4c94/Capture+d%E2%80%99e%CC%81cran+2023-06-08+a%CC%80+11.15.10.png?expires=1788635700&signature=c6f0a1bba81051c2eae5365fc724069517a0e2b2f0eb0071cfe266eae6604b83&req=cyUuF812mINXFb4f3HP0gIW5JafhnweG%2F88pZ776eVFx613BL3bt%2FhfIY8SG%0AOF5CRA%2FwCRsINHErzg%3D%3D%0A)

 Votre application vous demandera l'autorisation d'utiliser votre position exacte et d'afficher les sociétés et contacts près de vous. 

Vous retrouverez alors vos clients, prospects, fournisseurs sur une carte, que vous pouvez décider d’afficher ou non selon vos besoins. 

![](https://downloads.intercomcdn.com/i/o/759150187/b3ad8183a398f7c482982889/Capture+d%E2%80%99e%CC%81cran+2023-06-08+a%CC%80+11.18.34.png?expires=1788635700&signature=2c663fd2dc3700af2520a1c01561f3a2d5c702f212ad35f95b6ac4a2a748bbec&req=cyUuF8x%2BnIlYFb4f3HP0gJUyjGRtl6%2F8lepy4sCpJn%2FsRHr380MkyRN%2BJ%2Fuw%0A8%2BdvXSYPrdvFn2qe1w%3D%3D%0A)

En cliquant sur un icône de localisation, vous retrouverez des informations sur la société.

![](https://downloads.intercomcdn.com/i/o/759151941/02b71a8154d25bd3997e6f52/Capture+d%E2%80%99e%CC%81cran+2023-06-08+a%CC%80+11.20.19.png?expires=1788635700&signature=2147b5e165b52b96498f072fe96eedee873efd4616de8b5ca88efb55fd4d4a75&req=cyUuF8x%2FlIVeFb4f3HP0gFgRK28tQpjpE0zLvMYYYgJAObPL7eCRiXHNsp9X%0ArBKLp2Gg4B3%2BjORl9w%3D%3D%0A)

 Vous souhaitez rendre visite à l’un de vos clients ? En cliquant sur le nom de la société, vous accédez directement à sa fiche détaillée.

Cliquez ensuite sur l'icône position pour ouvrir votre application map et suivre les instructions de trajet.
