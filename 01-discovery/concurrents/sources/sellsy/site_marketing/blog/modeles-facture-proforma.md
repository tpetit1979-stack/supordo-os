# Modèles facture proforma en Excel/Word/PDF

### Sommaire

Une [facture proforma](https://go.sellsy.com/blog/facture-proforma-quest-ce-que-cest-et-comment-la-faire) est un document commercial utilisé pour **estimer les coûts d’une transaction avant la livraison de biens ou services**. Bien qu’elle n’ait pas de valeur légale pour le paiement, elle détaille les termes de l’accord, facilite leur négociation et simplifie les formalités douanières pour les transactions internationales.
