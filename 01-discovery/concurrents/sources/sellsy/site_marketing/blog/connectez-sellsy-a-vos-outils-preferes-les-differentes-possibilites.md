# Connectez Sellsy à vos outils préférés : les différentes possibilités

### Sommaire

Système ouvert, Sellsy a pour vocation de s’intégrer avec vos outils en ligne préférés ou vos applications métiers.




Plusieurs possibilités existent pour cela.


## Les connecteurs natifs


Depuis votre compte Sellsy, vous pouvez retrouver l'ensemble des connecteurs natifs ayant pour objectif de vous faire gagner du temps. Vous pouvez retrouver ces connecteurs depuis votre compte dans Menu / Réglages / Modules Externe

Ces connecteurs sont directement intégrés à Sellsy. Ils sont disponibles dans la page Modules de votre compte Sellsy. Exemples : [Stripe](https://stripe.com/fr), [Paypal](https://www.paypal.com/fr/home), [Dropbox](https://www.dropbox.com/), [Google Suite](https://gsuite.google.fr/intl/fr/)…

Entre également dans cette catégorie notre plugin [Wordpress](https://wordpress.org/), qui vous permet de créer facilement des formulaires de capture de leads. Les activer est simple et gratuit.

Pour les [e-commerçants,](https://go.sellsy.com/marketplace) nous avons également un environnement complet à vous proposer : plugin [Woocommerce](https://go.sellsy.com/applications/woocommerce), catalogue synchronisé, génération automatique de documents, synchronisation des paiements,...

## Les connecteurs partenaires


De nombreux sites ont créé des intégrations avec Sellsy dans leur propre interface. Exemples : [Plezi](https://www.plezi.co/fr/), [Modjo](https://www.modjo.ai/), [Inqom](https://www.inqom.com/)...

Dans ce cas de figure, l’activation de l'intégration est à effectuer directement chez le site partenaire.


### Marketplace Sellsy

Vous pouvez retrouver l'ensemble de ces connecteurs sur notre [marketplace Sellsy](https://go.sellsy.com/marketplace).

Quelques exemples des connecteurs :

- [Ringover](https://www.ringover.fr/sellsy) par exemple pour passer vos appels en 1 clic depuis Sellsy, vous permettant également d'historiser directement vos appels dans le CRM.
- [Xeno](https://xenoapp.com/) , pour attirer, convertir et fidéliser vos clients. Un chat en ligne entièrement intégré à Sellsy.
- [Plezi](https://www.plezi.co/fr/) , [Webmecanik](https://www.webmecanik.com/?utm_source=sellsy&utm_medium=2021&utm_campaign=synchro) en tant que solution de marketing automation


[**Découvrez + de 100 intégrations sur notre marketplace**](https://go.sellsy.com/marketplace)


### Synchron.io


[Synchron.io](http://synchron.io) est une plateforme qui vous permet d'interconnecter vos outils en quelques secondes. Que ce soit vos outils e-commerce, vos outils de marketing automation ou vos outils de caisse. Vous pourrez en quelques secondes automatiser vos processus avec un paramétrage aisé.


### Integromat


La solution sans limite, comme Zapier, [Integromat](https://www.integromat.com/en) va vous permettre de réaliser des scénarios complexes en toute simplicité.

### Zapier



[Zapier](https://zapier.com/) est une solution reconnue pour connecter des applications en ligne (SaaS) entre elles. Le connecteur permet à ce jour de gérer les clients, les contacts et les opportunités.

Vous pouvez donc l’utiliser pour toute application susceptible de créer ou mettre à jour des contacts dans Sellsy, par exemple un outil de gestion de landing pages comme Unbounce ou tout simplement les nouveaux inscrits à vos newsletters Mailchimp.

Sellsy propose [de nombreux modèles de zaps](https://zapier.com/apps/sellsy/integrations) (nom des intégrations chez Zapier), que vous pouvez activer et même modifier dans votre compte Zapier. Bien entendu, vous pouvez également créer vos zaps vous-même avec les outils de Zapier.

Zapier est une solution en self-service qui dispose [d’une version gratuite et de forfaits payants](https://zapier.com/pricing/), selon votre usage.


### Blendr


Comme Zapier, [Blendr](https://www.blendr.io/) est une solution qui permet de connecter des applications en ligne. À la différence de Zapier, elle assure la synchronisation de beaucoup plus d'objets et la création de scénarios complexes.

Basées en Belgique, les équipes de Blendr peuvent vous accompagner en mode projet. C’est la solution idéale si vous recherchez un outil fonctionnel sans effort de votre part.


## L’API Sellsy


[L’API Sellsy](https://api.sellsy.fr/) est le langage permettant à Sellsy de se connecter avec d’autres applications. Avec l’API, les intégrations les plus complexes, comme les commandes d’un site e-commerce, sont possibles.

C’est le choix à privilégier pour des connexions critiques et complexes (mais elle fonctionne parfaitement également pour des besoins simples, comme la création d’un contact via un formulaire).

Pour développer un connecteur avec l’API, vous avez trois possibilités :

- Utiliser des ressources techniques (développeurs) en interne
- Sous-traiter le projet à une équipe partenaire
- Déléguer la gestion et l’exécution de votre projet [aux équipes de Sellsy Services](https://go.sellsy.com/services)
