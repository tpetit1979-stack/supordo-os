# Deestree

**Deestree centralise vos interfaces de prise de commandes et transforme vos bons de commande entrants (PDF, XML, image, etc.) pour les synchroniser avec Sellsy. La solution gère également la tarification dégressive par volume et la gratuité, configurables par client ou canal.**

**Deestree** simplifie vos processus de commande pour booster vos ventes et fidéliser vos clients.

Grâce aux interfaces variées de passation de commande, vos clients ont désormais plusieurs options pour acheter : web, bon de commande connecté, smartphone, tablette, ou même douchette codes-barres. Ces solutions répondent à leurs besoins et s’adaptent à leurs habitudes.

Avec l'OCR (Reconnaissance Optique de Caractères) boosté à l'IA, Deestree transforme tous les documents de commande entrants (PDF, Excel, image, XML, EDI…) en commandes digitalisées. Celles-ci sont ensuite automatiquement synchronisées dans Sellsy, avec contrôle des conditions, prix et frais de port.

## Principales fonctionnalités de l'intégration

Ce flux d'intégration permet de **synchroniser automatiquement les commandes entrantes de vos clients** avec Sellsy, peu importe leur format (interface web, smartphone, commande avec douchette barcode, PDF, Excel, XML, image…). 

Terminé les ressaisies et les tâches répétitives : Les commandes arrivent directement dans Sellsy, il vous suffit de les contrôler et les valider. 

Deestree gère les commandes multi-tarifs et multi-sources. Sellsy s’occupe du reste. 

## Tarif

Deestree est proposé à 49 € par licence jusqu’à 300 produits, puis à 79 € par licence au-delà. **L’intégration avec Sellsy est incluse quel que soit le nombre d’utilisateurs.** Les frais de mise en place, habituellement facturés 1 200 €, sont offerts pour les clients Sellsy.

## Guide d'installation

**Pour activer le flux, suivez ces étapes simples :**

**1.** Récupérez les tokens API de Sellsy. Un identifiant + clé secrète peut être généré depuis l’interface d’administration Sellsy avec les permissions de l’image ci-dessous.

**2.** Communiquez ces identifiants à l’équipe Deestree qui se chargera d’activer la connexion (2 minutes).

**3.** Les nouvelles commandes remonteront automatiquement dans Sellsy. Les anciennes commandes peuvent aussi, en option, être synchronisées.
