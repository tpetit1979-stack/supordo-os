# Activer la gestion des stocks pour les déclinaisons de produits

La gestion des déclinaisons Sellsy est compatible avec la gestion des stocks. Dans ce cas de figure, chaque déclinaison bénéficie de sa propre gestion de stocks.

La gestion des stocks pour les produits avec déclinaisons peut s'effectuer en CMUP (coût moyen unitaire pondéré) ou par numéro de série.

Vous pouvez par exemple facilement gérer des ordinateurs dont la déclinaison correspond à la taille de l'écran, mais avec chacun des caractéristiques différentes (processeur, disque dur...).

> **Bon à savoir : **il est impératif de d'activer les stocks seulement après avoir créé les déclinaisons pour le produit concerné.

Pour activer les stocks sur un produit avec déclinaisons, ouvrez la fiche produit et après avoir créé les déclinaisons, cliquez sur “*Activer les stocks*”.

Dans la fenêtre qui s'affiche, activez les stocks comme vous le feriez pour un produit simple.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446362968/bb7990e45b70ed064b8b6125/T1QYit8CQsIs2_tu3nD5ZTwjMEPVrXAhJDDng2-Dn3LIN6s3FBjqvWwnhWzV1icCdwkFgDjO5P11DiM8Yw-E_shCDJ_gUQRh3YcDUUAwkSiTtdsLcISkNbi5pFkzCgLSCM3TopQA?expires=1788635700&signature=8a532b6a63c6028c832be99c3e8b2055f82ab3e9d352004e789153ff9d30504f&req=cCQhFc98lIdXFb4f3HP0gDt7pb7egUuV0wahXeCsggteCUU0XYSxMGcIfNCN%0AouAV6Pq6mlHoO%2BBleQ%3D%3D%0A)

Les stocks sont alors activés pour toutes les déclinaisons avec les réglages choisis par défaut.

Vous pouvez alors gérer vos stocks par déclinaison, comme vous le feriez pour un article standard.

Rendez vous sur la fiche de la déclinaison en cliquant sur le nom de la déclinaison dans l’onglet “Déclinaisons”. Ensuite, cliquez sur l’onglet “*Infos stocks”*
