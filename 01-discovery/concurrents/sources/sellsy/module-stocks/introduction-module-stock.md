# Introduction : module Stock

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1333981746/79127749fce5ffc39c27f09dc81a/FAQ-Bannie%CC%80reAcademy-2.png?expires=1788635700&signature=8f65245f61c007b0e464c9840f5eeb0c7045903e1a8d5335de52570a5e72e1b4&req=dSMkFcB2nIZbX%2FMW1HO4zR7boU06cUdeyZWSmNkWxNUT3TwgdMvL322fRrpT%0ATCtnAko%2B1Bv5RMsPPt0%3D%0A)

Le module gestion de stock vous permet de **gérer votre stock** directement à partir de Sellsy.

Avec la possibilité de gérer **plusieurs entrepôts** et de calculer la valeur moyenne de votre inventaire, c'est un outil puissant pour vérifier la disponibilité de vos articles.

Le module est également conçu pour vous alerter en cas de rupture de stock et **générer des bons de commande** à vos fournisseurs en conséquence.

L'utilisation de ce module nécessite toutefois le respect de certaines règles pour être pleinement efficace. Il est important de lire cette section avant de débuter son utilisation.
