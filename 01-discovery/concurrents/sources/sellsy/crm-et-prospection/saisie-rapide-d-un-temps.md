# Saisie rapide d'un temps

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1925580031/d1ae1b0aa2ebaf4903d0a25844fc/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=d3304ef5fc5983f56241950bcc7fa4ccca0da74587e91b9af5bb58ef8f769806&req=dSklE8x2nYFcWPMW1HO4zXpmyvRJqjyL1%2BAkBXo7WvsiEujFI1IH6LpMDmyV%0AnrAx2imeUOZ8Ygt9ONA%3D%0A)

Ce type de saisie vous permet d'entrer très rapidement une entrée de timetracking.

Pour ce faire, cliquez sur le menu “Timetracking” puis sur “Saisie rapide”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446335142/3ffd8ebe42a6d6475f3b9ccd/xxzs37086FYcbJj2oeBVZwcLk0XYpg1pqGipFgDJ5f-1XTljra6XkY3SotKA7hezRULgVZeRpLD7eFsck5C70GWh9IIfh3jHq733uoPekNFvX_AjO0X2M7t5nzGJM5LZGXE7GISW?expires=1788635700&signature=a9ba8b6306d6906a046f95e38d264d08262b7b2aa1a3fc2b41049e228eabd1a4&req=cCQhFcp7nIVdFb4f3HP0gEYfqYxSzQvwccLu7npmvWrhKN0mUp87e9Q6Kik8%0A4IAxPKtE1Q2tDTtBNA%3D%3D%0A)

Vous pouvez alors saisir toutes les informations de votre entrée : temps passé, client concerné, etc.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446335151/43fc2fef9929c6de5457d16e/jHzD0MyYIaWheir-NLxnyvyIHjn7QsgWBLAgKwQ5JqnQuhcMEbow0Xq37Lxn9sHNW91_9uCI0LDqcE0Zv1L5eRpd-YPtkO0Kos61uN0ZfpF8bquMpwydsw1BjpaGO2VcEnUdke7C?expires=1788635700&signature=ebbba42eaab66e0501d730d61e4581631f5de1c81d2bca3360c68f6bae5e5fc2&req=cCQhFcp7nIReFb4f3HP0gGnEd5fJI9akqz33evcz5UIsJlI%2B8giz6lzd4o4m%0AOPKLkZjDGVIyv300oA%3D%3D%0A)

Vous retrouverez votre entrée directement depuis la liste de vos entrées de time tracking.
