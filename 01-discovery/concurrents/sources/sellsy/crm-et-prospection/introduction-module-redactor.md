# Introduction : module Redactor

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1399665087/7b7992e03f3bb62b444c61935d6e/FAQ-Bannie%CC%80reAcademy-2.png?expires=1788635700&signature=8bd95a6474d7fc53b07a3e5fd7886ae79c1e5820d9c92479ffac5a82e5153a8b&req=dSMuH894mIFXXvMW1HO4zfW2R%2BUKG0DEaGggGthM6k36rvYT4wjTSNyjBOl1%0ANXBOAal190uoW8pndcM%3D%0A)

Le module Sellsy Redactor est un puissant générateur de documents dynamiques.

Il vous permet de créer des documents de tout type en utilisant les données de votre compte Sellsy.

Vous pouvez par exemple créer très facilement :

- des propositions commerciales complètes et détaillées,
- des contrats, attestations, conventions,
- des fiches produit,
- et bien d'autres possibilités.

Ces documents peuvent utiliser les variables Sellsy comme :

- les données de votre société
- les données de vos clients (y compris les champs personnalisés)
- les données d'opportunités, ou de produits

De plus, vous pouvez lier les objets Sellsy suivants :

- documents de vente (devis, factures...)
- opportunités (y compris les champs personnalisés)
- produits du catalogue (y compris les champs personnalisés)
