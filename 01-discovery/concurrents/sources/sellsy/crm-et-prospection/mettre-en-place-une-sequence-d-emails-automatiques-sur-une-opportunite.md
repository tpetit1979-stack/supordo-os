# Mettre en place une séquence d'emails automatiques sur une opportunité

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261829183/495f954c70acc713078b4f3537ba/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=9e114eb72b89cb443e49e9c6cc6eafa4699790ff27d8930d5251ee9cd98848a2&req=dSIhF8F8lIBXWvMW1HO4zaU17FKAdXm1qu47p2G7q%2FqTRtg4jSPWfSTblcV7%0AuTlBVtDvbfb1QemOrP0%3D%0A)

Dans une logique de prospection, il est intéressant de pouvoir envoyer des emails automatiquement pour relancer un prospect sur une proposition commerciale.

___________________________________________________________

### **Fonctionnement**

La fonctionnalité email automatique vous permet de configurer une séquence d’emails qui seront envoyés automatiquement au(x) contact(s) d’une opportunité **(uniquement pour les opportunités en statut ouvert, retard, gagnée)**.

Depuis la vue pipeline, vous avez la possibilité de voir chaque étape. Pour chacune d’entre elles, vous avez la possibilité d’activer ou non une séquence d'emails automatiques. 

> **Bon à savoir : **
> - Si un contact est lié à l’opportunité : l’email est envoyé au contact
> - Si aucun contact n'est lié à l’opportunité : l’email est envoyé sur l’adresse email de la société liée

___________________________________________________________

### **Configurer **une séquence d’emails automatiques

Pour **configurer une séquence d’emails automatiques** sur une étape de pipeline, vous pouvez cliquer sur les labels “Email automatique activé” ou “Email automatique désactivé”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444747407/02165e5adfa3c34448cbf5b4/3NZJJu8u4O8A3K6m3QBvig5gYNEAPucRne54jDTQsAcAytXBxrAXljLCIjYuiy26JW9Ip5XVfEjOtkk_WR_hIvBGtNnWPPGH0u4o8l7Le9o3Py-aCbfeSlEsjVCPV4_FMgLXO3UF?expires=1788635700&signature=7653d2c8c12ea8e2c6796f8c6743cf2fc70ce765af47197246f3fba530c6042f&req=cCQjEc15mYFYFb4f3HP0gKwThIx8O0zEnOyP24EuUX2mpWhrqDe5m6%2F1QvHA%0ATpbQVkOC5VhrHrkbfg%3D%3D%0A)

Entrez les informations suivantes sur votre paramétrage :

1. Définissez le collaborateur par défaut du pipeline,
2. Ensuite, cochez “Activer l’envoi d’email automatique”,
3. Définissez à quel moment vous souhaitez que l’email automatique soit envoyé,
4. Choisissez l’expéditeur de l’email,
5. Choisissez le modèle de l’email.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444747415/96aee6ec09b297bf876199f2/FMsFoFTvZ8_M86UOHpaxZdg42toqCIKocRRFH58mvCwtCiVMVviH6v_EG41BwLSFGIXZJ7g9cG3yDgJ__b9EUT0Mv0GG3eLiGw0EXorqB5f1e6XS3lOMwDALamhyUvXe6SjsHNcU?expires=1788635700&signature=66abc730cf9f3598f33eaacda0f83870a4fdde5f9bae0b147d82af6695d668a9&req=cCQjEc15mYBaFb4f3HP0gI%2Bkyeq6O1%2B%2BbQaSDhFjOpktTkehu37RkJNAmXrR%0AcEu1yO0jws98%2FW2cPQ%3D%3D%0A)

Vous pouvez choisir d’envoyer un premier email au moment où vous déplacez l’opportunité dans une nouvelle étape du pipeline. Ensuite, vous pouvez configurer autant d’email que vous le souhaitez pour chaque étape du pipeline.

> **Attention :** le délai minimal pour l’envoi d’un email est Jour +1 (hors envoi à l'entrée dans l'étape). Par exemple, si vous configurez une entrée d’envoi d’email au Jour 1 à 10h00 et si une opportunité est créée le 1 janvier 2016 à 21h00 alors le contact de l’opportunité recevra son email le 2 janvier à 10h00.

Si vous déplacez une opportunité dans une nouvelle étape d’un pipeline et qu’un email doit être envoyé, vous serez automatiquement alerté par un popup d’information.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444747420/e7f19900b2a590bba56f9b3c/a1eRo02HlwQvLTLkQXgjwOe_KWsk7WYrg20IDsY5tdHhkn3sAG9Q694uMwME9OMQZbpaXiK-x9XAsUtKWckqF6FsUJHip3iLmv6bhtIeXo-QtX2IGKcS_vzyI_aOHvotwZ3q60l-?expires=1788635700&signature=faabc1b2cd5c6d40aee93444143300f3e8b498008f22bf08a3344e896a1917f8&req=cCQjEc15mYNfFb4f3HP0gI5gCiBgA1F84eULCJqK0IQ4XqjgwIKWwDt7Ie2A%0ARNekBYmZfv0PU0WpFg%3D%3D%0A)

Si vous avez configuré un envoi d’email lors du déplacement d’une opportunité dans une nouvelle étape d’un pipeline, nous vous invitons à bien vérifier votre configuration avant d’effectuer des imports ou de créer de nouvelles opportunités.

___________________________________________________________

### **Retrouver les emails envoyés automatiquement**

Pour retrouver les emails envoyés automatiquement, rendez-vous sur l’activité de l’opportunité dans la liste des emails envoyés.

___________________________________________________________

### **Suivre les résultats d'un email automatique**

Pour suivre les résultats d'un email automatique, vous pouvez créer des événements trackés comme l'ouverture de l'email par exemple.

Sur Sellsy, vous pouvez suivre la performance d'une séquence d’emails automatiques dans vos étapes de pipeline.

Rendez-vous sur la rubrique “Scoring client/prospect” depuis votre menu “Réglages”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/650334126/009c2a7dda277ff83a4db631/tCucybhxLUOYAA1jWnxfD9KDsjWnHgDZA78vohpMlZMKRDq0LRR62QqDJifYOjCDt-_JsZUXSzSAiFGlLPAjgFTeAtSy1w-SeZ_wT6eVFtBnu56hshwN7yzqKel1cqcmVT8_328GYUQtQt8S-DyRzR1uyePb3QZ2IJZOoJ0PYXdHInUGFI4AnYXAOGY6Ww?expires=1788635700&signature=d09ad64daecac2bb6279d253ee8fd56ab0ee8f0284598a29beb015fb6e412b15&req=ciUnFcp6nINZFb4f3HP0gGWMP9xk8oaM8d%2BjDFAeDlk0EqojsetnBIjnc1s2%0AY0PYhIeKbamBA0%2Focg%3D%3D%0A)

Vous pouvez ajouter un nouvel événement en cliquant sur “Ajouter un événement”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/650334134/b236eecbc4743d0862e92f62/HUb103hiWErwD4qusTb1ISRRckSra-0AS5dMMmv2N8Uc7Ko5GNxmjofRA8QBSlbU4tdSbfa2p0W5pVVFvbJQ2_m2uSKNa9LV4nHoolksTfbsCxPlD-NCL4I5rWtwqN8vDee53Em0DpoGFoND-qD9yS-DlAKtB-JKaAG-tMSmEjAjAE0w80AKh5kqdkEBIA?expires=1788635700&signature=61dd6f4e0fe032521b604ff4781bf2c36a161bc97e12e72a7b6fc171798ec8dc&req=ciUnFcp6nIJbFb4f3HP0gGDxiP%2FzxQke%2B7h9ecxBwTx7hRfGKgGj8ySTyD4P%0AdF%2B98XItKdRFrxVhng%3D%3D%0A)

Deux types d'événements peuvent être trackés et scorés :

- La visite d’une page, la soumission d’un formulaire,
- Une activité mail : ouverture de l’email.

Ensuite, vous allez pouvoir ajouter des opportunités dans une étape de pipeline associée à une séquence d’emails automatiques.

Dès que la séquence commence à envoyer des mails, le système va tracker les actions d’ouverture d’email et mettre à jour le score lié à la société.

En utilisant le filtre sur les opportunités avec un score supérieur à 0 alors vous pouvez identifier les contacts ayant réagi à votre email.
