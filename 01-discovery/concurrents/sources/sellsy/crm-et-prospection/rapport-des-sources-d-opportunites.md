### Accéder au rapport

Rendez-vous sur “Rapport” puis cherchez “Rapport des sources d’opportunités”.

Afin de mieux comprendre d’où viennent vos meilleures opportunités, vous allez pouvoir utiliser la logique de source et de catégorie de source d’opportunité.

Les sources d’opportunités permettent d’identifier de façon précise la provenance de l’opportunité (campagne facebook / salon e-commerce etc..).

Vous pourrez également regrouper les sources du même type, par exemple : social media pour les sources : facebook / twitter / linkedin ou événement pour des salons.

Pour mettre en forme ces informations nous vous proposons un rapport de source d'opportunités.

Le rapport de source d’opportunité vous permet d’accéder à une vue simple et rapide du **nombre d'opportunités générées par source** ainsi que du** montant facturé des opportunités par source**.

### **Organiser mes sources d’opportunités**

Vous pouvez organiser vos sources et catégories de sources depuis les préférences du module opportunité.

Rendez-vous sur votre menu puis sur “Réglages”, “Modules Sellsy” puis “opportunités”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444739644/4dd67a58300d7acfe086cbde/yWqbsyHY49-V2ehJNflVsJxRANZf4j_OCWo5Do8bnIcx2kQh5cwNaIA9RjUHQs8Jim1SuZvIyDAr5iAzVb_a3RW--p14T07QmAXwOWWtlwye68snbgVHSOy0hCvtm0wKrFbmzkzY?expires=1788635700&signature=54d97a08aa14a476386c9fa96815c95dba5ef2fb1592ab2fe0c0a74290219fec&req=cCQjEcp3m4VbFb4f3HP0gJTA7Izq0x1kUht9T098k762iYIl5XSvOd3yhTDg%0Awcn%2BL7pGT4BwokluKQ%3D%3D%0A)

Cliquez sur l’onglet “Sources”. La catégorie de source vous permet de regrouper les sources du même type (salon événement ou emailing) ou issues des mêmes campagnes (social media pour facebook / twitter etc...).

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444739661/0c56bc6fba0da43f42765475/Yi0ALv3BNzuhyWQMO0IyjWL_sO914MMjRzws86E7NO64p21GAgWOQBSryoZhEVrXYNaubU3A2IRi8rtaYHqFZP26gDo4H68s9ZFT2ooSUGOBS7J8O1QQkYaX6PU_1wy53c0yX_hy?expires=1788635700&signature=22443a28b36243fa72127e22ca1c1066d4161b0f32992b77071f0db2945f584c&req=cCQjEcp3m4deFb4f3HP0gFZmoyhLzMIQDilKd8k%2Fd%2FHDRp9SYaVOcNa4XJAq%0AjB59MoMGAttFQz4zwA%3D%3D%0A)

Ces catégories de sources seront visibles sur le rapport de sources d’opportunité.

Vous pouvez déplacer chaque source dans une catégorie de source (en glissant / déposant via l'icône tout à droite de la ligne).

### **Définir une source d’opportunité par défaut**

En cliquant sur l’onglet à droite de votre source d’opportunité, Sellsy vous propose d’utiliser cette source par défaut en cliquant sur “Utiliser cette source par défaut”. Elle sera ainsi sélectionnée automatiquement lors de la création des points de contacts (formulaire, widget).

### **Générer dynamiquement des sources d’opportunité**

Par défaut, la source de votre opportunité sera celle définie sur le point de contact (formulaire, widget), mais nous prenons également en compte les UTM (utm_source) de vos campagnes pour générer automatiquement des sources d’opportunités.

Ainsi vous pouvez retrouver la provenance précise de vos opportunités, par exemple selon vos campagnes webmarketing.

Pour mettre en place ce suivi, vous devez avoir mis en place le suivi des prospects sur votre site web via le widget Sellsy.

Si vous effectuez une campagne de promotion “Nouvelle offre octobre 2016” via le canal : social media.

Vous pouvez créer une landing page pour votre offre avec un formulaire d’inscription disponible sur l’adresse : [http://www.monsiteweb.com/offre-octobre-2016](http://www.monsiteweb.com/offre-octobre-2016?utm_source=linkedin&utm_medium=socialmedia&utm_campaign=011016_projet1)

Vous pouvez mettre en place des paramètres UTM dans vos lien de redirection pour vos différents canaux de social media :

- Url de redirection depuis linkedin : [http://www.monsiteweb.com/offre-octobre-2016?utm_source=linkedin&utm_medium=socialmedia&utm_campaign=011016_projet1](http://www.monsiteweb.com/offre-octobre-2016?utm_source=linkedin&utm_medium=socialmedia&utm_campaign=011016_projet1)
- Url de redirection depuis facebook : [http://www.monsiteweb.com/offre-octobre-2016?utm_source=facebook&utm_medium=socialmedia&utm_campaign=011016_projet1](http://www.monsiteweb.com/offre-octobre-2016?utm_source=linkedin&utm_medium=socialmedia&utm_campaign=011016_projet1)

Lors de la soumission du formulaire d'inscription, la valeur du paramètre utm_source sera automatiquement définie comme source de l’opportunité générée. Vous retrouverez également cette nouvelle source disponible dans la liste des sources dans les préférences du module Opportunités.
