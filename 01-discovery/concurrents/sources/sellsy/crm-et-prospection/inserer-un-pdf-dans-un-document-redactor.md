# Insérer un PDF dans un document Redactor

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1925506934/0b544a5f271c4252f3e0e9092a1e/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=4eb596ba333158c685622007bc0ce993536af8917867bd1b7db8e1209923527d&req=dSklE8x%2Bm4hcXfMW1HO4zdIw609ljxl%2FIizyi2rqdhW7i4%2BaLBZ1uRG1hLN6%0AsjiNOLX%2BuXl00OuQ4vU%3D%0A)

Avec le module Redactor vous pouvez insérer un document PDF avant et/ou après votre document Redactor.

Ceci vous permet par exemple d'insérer :

- une couverture graphique au début de votre document,
- des pages ne nécessitant pas de personnalisation (présentation de la société...),
- vos conditions générales en fin de document.

Pour insérer un PDF, cliquez sur l’onglet “Mise en page” dans l'éditeur de documents. Vous avez la possibilité d’insérer un fichier PDF qui doit être au préalable stocké dans vos fichiers Sellsy.
