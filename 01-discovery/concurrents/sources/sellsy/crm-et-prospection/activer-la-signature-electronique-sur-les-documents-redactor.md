# Activer la signature électronique sur les documents Redactor

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1334014497/184971f7740d1e4b4d26eeea0f5a/FAQ-Bannie%CC%80reAcademy-2.png?expires=1788635700&signature=ea4f83520129d29660ff0b9d1ad32f106a95c36c229ea025331bd0bbafd923ea&req=dSMkEsl%2FmYVWXvMW1HO4zcqGldK5Qwh8MeOslpK4zJpfh5c9%2BG%2BOqMAZXrdC%0AFoJKxeMFQAZixoWjjv0%3D%0A)

Avec le module Redactor, vous pouvez faire signer électroniquement vos documents grâce à notre module de Signature Électronique, 100% légale.

___________________________________________________________

### **Étape 1 : activer le module Signature électronique **

Rendez-vous dans votre menu puis cliquez sur “Réglages” et sur l’onglet “Module Sellsy”. Cliquez ensuite sur “Ajouter des modules” en bas de votre écran.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444766975/ab3181baf4743b2fc28f8ef1/uXG3BPAY9B2rtln6kRC4_y7zhZYw_aHsN7wmePGdcgnc0cwUxl62AfHAvc-ygvgnKaNGicAtmHpoG6-dSchnyQwVYStpsvx_biSSqNtsJfrAT3Vx9XhOFHvIobQowMvoofUHf6OU?expires=1788635700&signature=bf2b66930a4638cd683abf945d6c110ce1219695b9bdf2918dfd2a46ffd3c7bb&req=cCQjEc94lIZaFb4f3HP0gEzUDxj6tmiorrQFoRhOFxv1akbBggziCOyYqacX%0AgcHA14AcmyH8GG3iGQ%3D%3D%0A)

Recherchez le module “Signature électronique”  dans la barre de recherche puis cliquez sur “Activer”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444766992/1de5b0442bc5d73cc44468a8/D3U5Ju3k6-dImj6yMxZ-mqHJKrShbOEHyiGfz6RGw33hM8wDC9abbwd9pv1rZUhgkoawotybrH8zMH33GWwMNwEPn072cKkNgCUB_eTfjEZJKxTdVie6cES_71xuq6hDaiZmTuXD?expires=1788635700&signature=19387de34148f2c6692793887a0859f6d534e17901aadc9f9955d5a3f28b3aeb&req=cCQjEc94lIhdFb4f3HP0gNxr5vz012X8btfi18LXmjOgQSqYGkiwnGd80T2t%0AQpQ1bJRoFT%2FP6gNosw%3D%3D%0A)

___________________________________________________________

### **Étape 2 : ajouter le widget signature électronique sur le document Redactor**

> **Bon à savoir : **avant d’activer la signature électronique, assurez vous d’avoir **ajouté le widget signature sur votre document**. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444767004/2f72d5f3c00e9f4fb3c9e9ac/bTUDnVDJaY_LJxjH9lQlFCZPZyf_5H5Tp11-qrMNhT-3jJ6T1-3CD4t6ABGMm1sr49th1ruPj9kHFJnn7QflCA2MWOFc5Ov1Kz-75j57116xCJiEXUM9rRXhgzWqn500GhxO3_k7?expires=1788635700&signature=3f4a7f53d7d44babd455bc817751da660d6ec603b64aa963902b8103c07e04c6&req=cCQjEc95nYFbFb4f3HP0gCAsjg6Z7xTnLb1O39B8jMayDzPs%2B96P1IIjSlwX%0AUdowgyM66rJApxQrwQ%3D%3D%0A)

Une fois le module “Signature électronique” activé, depuis l'aperçu de votre document, cliquez sur l'onglet “Signature électronique” puis sur “Cliquez ici pour activer la signature électronique”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444767020/d1b9d86d648c22c2cb2dadb5/PDBv55EO54sjR9-NUrOyA_jtagxhqoEtDdigJX_spcCj19fiTzZx5R3z5ytY-R1TXQ6MxhKNCxXDKAhbDo8CmcHh-q4wo-PYG6sv8qpaZwkHlGWL7a6mgYJ5AnxFO1FGIRVNsqY8?expires=1788635700&signature=5cffc18a705cf2617583534653f0bf132552609144d8f6867ca02c2d9de24b05&req=cCQjEc95nYNfFb4f3HP0gJ4tKpptXzqDApeyDlXlXnnpVfjPHXjBNEZcTnsa%0Abng0E9c4kBKa3YAM7w%3D%3D%0A)

___________________________________________________________

### **Étape 3 : envoyer le document pour signature**

Vous pouvez ensuite lancer la procédure de signature et choisir les destinataires. Ensuite, définissez les réglages de l’email de notification qui sera envoyé pour signature.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444767038/9b0ed5e3ee8cc032fab470e8/qsl2fzyARwT7GfqKJVV8iub0EdSz8E-ZajVuUHlA2hPx_C_lzJH6QhUh_lM7W6yhuTABwcYYnjxYPRGqwqHqGfuiPoEo5LfkIzY6mCeJNOTDf4SyKR252BGB3Y3Bv0gzDm3YgUwA?expires=1788635700&signature=ba6c6c6040d0429cd2579ecd1120b8f08833126ea82ad6ca191c39dfbf23ab05&req=cCQjEc95nYJXFb4f3HP0gBW4IEwAZa0B0lvecLAyZsNYejRRG1pbdOpwNaGw%0AY6UVXGd4A1NO9kByQQ%3D%3D%0A)

Une fois votre document envoyé, vous retrouvez un récapitulatif des actions de signature dans l’onglet “Signature électronique”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444767053/114ba7d5c22fe3207d6af58f/H1ElayW62J0jdskZ0DKaH-AKylku6K0rBXYCXz-vIPLEM_NPgxgouP0CPvjswqSAPMecMul5NZZgxpTj_d6rWKcaUE980dDncNguwUdYQBt3Hr7SfyGBZgFetSo_z9qjiJsZl8ka?expires=1788635700&signature=f996d8927998d16e0a68eb6f18e75ca26119c26cbb2adf4f7738b272fc0eb6e4&req=cCQjEc95nYRcFb4f3HP0gLkYJaEHqAvTsWb0HSSP39nk%2F8ubha94%2FYlXmQmI%0A2ISAHhbVaJeUcI3gwA%3D%3D%0A)

Vous trouverez également cette information dans votre liste de documents Redactor.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444767065/eecbbc17cd4a8e3f5d7d2ff3/gSeE0IBaqvAYvjtRPROTW9MrIA5fsfMLs4E9wjjud7KoYJBsJLtalKa_jjtKgOyGlK-821odXx4TayWuluT8M2ADA19r8Q0weTUERqIVoSFeZI-2TjjUs4J1tRsyY8TI1AuBUUXj?expires=1788635700&signature=512dc4970d57eb3bffa8f89b567c774db997c61dd8796cf41e506c302ea837c0&req=cCQjEc95nYdaFb4f3HP0gDoLgVZUaIPKnVXhM7zXTm%2BTgXN%2B8Us%2Bq4Lop0nk%0AETGbnWh9Kt3BFzHxmw%3D%3D%0A)

> **Bon à savoir : **une fois signé, le document passe automatiquement en statut “Accepté”.

___________________________________________________________

### **Étape 4 : consulter les statistiques du document**

L’onglet “Consultation” de votre document permet de consulter des données concernant :

- Le nombre de visites sur l’espace client et depuis le lien public,
- La durée de consultation depuis l’espace client et le lien public,
- Le téléchargement du document depuis l’espace client et le lien public,
- Le détail des visites : date, visiteur, durée.
