# Créer une proposition commerciale dynamique avec Redactor

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1333962598/0e16ae7e6bbc00a8d775e7543af6/FAQ-Bannie%CC%80reAcademy-2.png?expires=1788635700&signature=afd27ca4cb293359c2ed52f74b09e2de911c5bf37d318d5d3ed34b61ea11a7d2&req=dSMkFcB4n4RWUfMW1HO4zXijqoD8V9KtvSyUbQ5HD2Nl8SXdMzI%2FNDFW4RBo%0ADAeF%2B1Zb0%2B%2FVU7rv%2B1w%3D%0A)

L’un des grands avantages de l’utilisation de l’éditeur Redactor est de pouvoir créer des modèles de documents entièrement dynamiques. 

À l’aide de balises et de widgets, vous pouvez très facilement intégrer des variables comme les coordonnées du destinataire ou une référence de document. 

Les variables dynamiques **sont disponibles sur les widgets** : 

- Texte,
- Texte 2 colonnes,
- Image et texte,
- Signature.

___________________________________________________________

### **Créer un modèle de document dynamique **

Pour commencer, cliquez sur “Nouveau modèle Redactor” sur votre menu “Redactor”.

Une fenêtre destinée aux liaisons s’affiche. 

Vous avez la possibilité de créer un modèle dynamique en liant : 

- Un contact (client ou prospect ou fournisseur),
- Un document (document de vente ou opportunité ou produit).

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444758145/0ad5ef495419c01f21a5f765/89RNvKpJmBg22v8psbQvXc2HUb-6TdNszqwVGiAk2AWgAbkP5k33zddLCfV9ssIavT9SRGMbQ8kwBOsPQrCAHIsdJPD8eVBI9AbRrb3WPVkRyNtsg9T8NzY2a04_HOTpEa9QgUz-?expires=1788635700&signature=f0b95f9f1c2a0754db26ce7f67933cd92d9a13027a6192cf1088e5cba21b503b&req=cCQjEcx2nIVaFb4f3HP0gBA5XPg5BV7m%2BvX%2FBfvX2METjKSLm0M6VnmiQ5pr%0AymvRJ0gYBrbaWx7dDA%3D%3D%0A)

La page d’édition de votre modèle s’ouvre. En glissant-déposant un bloc de texte par exemple, votre éditeur de texte vous proposera 3 types de variables dynamiques : 

- La personnalisation des objets liés,
- La personnalisation du contact lié,
- La personnalisation des données du compte (votre compte).

Si vous souhaitez par exemple ajouter au document des variables concernant les coordonnées du destinataire du document, cliquez sur l’icône de personnalisation du contact lié. Une liste de variables vous sera proposée. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444758154/399f6419143aabc3268928c5/EpFP5pil8Uf4UmrDqbzkA-69KrOrMnJ6REARp_Xodw1TSnfhmcIwpVUwtBkMcCuAN0JvYWwNK5UKJc4hMArq0Ch7GRMtWF0T3AzPGvKXFuHPOpFRa0nqUzuAwe5N07nbg7mB52AM?expires=1788635700&signature=b9792dad2431179a0d0ddaafbdc515575a0a4750bfd4682921a785a1940843b5&req=cCQjEcx2nIRbFb4f3HP0gA25v%2Bt15bEs4zbLtnbAMjsZXY7XFQhLi8hQW%2BsR%0ALICvDpEGfXaHzqqmUw%3D%3D%0A)

Il vous suffit de cliquer dessus pour les ajouter instantanément à votre bloc de texte. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444758170/8c801d40dd357aa3b6bf5628/x4H3Sg84Kw1GaPVAupYEXw1ZvIZXHV6HjrGQw-Ir_Yzn-vc_7E6IAhi1UU9Gal1flbQ_WhHhP91nGOq1_uz_eHoJyhsd4jxiRnplkm3N2e3u_JLmOCO1NSFDK888PDCAke2KXx_J?expires=1788635700&signature=ada81a0233f8ef526f1a849d979a1c05e2c3b2734177b5f4cd37e7af40832ae0&req=cCQjEcx2nIZfFb4f3HP0gDxV3Gzw5I5FVDOcCxFR5ODtNIe8DPhnhiYH5OxO%0AUNH4r0keKCeQiHHNwg%3D%3D%0A)

Votre choix d’objet lié lors de la création du modèle va également vous permettre d'intégrer une partie ou la totalité d’un document dans votre modèle Redactor 

Cela peut notamment être utile lorsque vous souhaitez faire référence à un devis ou une commande dans votre document.

Par exemple, si vous glissez-déposez le widget “Lignes de document”, en choisissant le document à afficher “Document lié”, les lignes du document de vente qui sera lié seront automatiquement affichées.

### **Générer le document Redactor **

Une fois votre modèle terminé et enregistré, voyons maintenant le résultat final avec un client et un document lié.

Sur votre menu “Redactor”, cliquez sur “Nouveau document Redactor”. La page qui s’ouvre vous propose d’utiliser un modèle, puis de définir le client et le document de vente que vous souhaitez lier à votre document Redactor. 

Cette étape est indispensable pour générer un document contenant du contenu dynamique.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444758185/91e7e7368ae16f13ce92c8ab/3zekHny1A1DCknPT268WXLgFsWYDKmxqlOtOPKr6EABstxCwmX2TYFtDCW2qr4M16Y0-MZzWNWla_CTkoHhzfC1aEXuXzdOgtDNmKCte5OqN1MP9EQ943FFW4-FILSNJubeaJmiK?expires=1788635700&signature=2cd3d7711ef803d238d8b08afbec4e4bb990e7709369198fd576192ddffade0d&req=cCQjEcx2nIlaFb4f3HP0gBXzD4waMnvC39M1aGID%2B0L%2BHhT6sY%2F90jbNQLvC%0Ayno9rB4Ncmd944sn%2BA%3D%3D%0A)

Vous êtes ensuite redirigé vers une page d’édition de votre document. Si votre modèle vous convient, vous pouvez directement cliquer sur “Enregistrer”, sinon, il est tout à fait possible d’y apporter des modifications. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444758192/f8d845e6a6892efb6f0d970d/Hknn2NabEIeA1ugcZkiEBPh119IM-AakbWgU0zzaSzdUpxwr28FbI1HYGi7WmlFdPx4NzCYl65iHBl1X3dMq_yQ6tEnPKSM-Jc-0q5sGfQaMv6fZ0jwLgihFzc1GqAR1P8pVWMEs?expires=1788635700&signature=45eca9a3c775f4ca44a903d1aa8fb970dcdd5d233e6447d332961868041f5245&req=cCQjEcx2nIhdFb4f3HP0gD6UoA8eMmCpHBnHbAud%2BpMT1HwE4yfRjhNTAqA6%0AgLnvZqIz9FLoONgIYg%3D%3D%0A)

Une fois enregistré, votre document final apparaît, vos variables sont automatiquement mises à jour selon les informations dont Sellsy dispose.
