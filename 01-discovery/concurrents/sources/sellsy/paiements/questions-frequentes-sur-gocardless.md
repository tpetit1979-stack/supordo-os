# Questions fréquentes sur GoCardless

___________________________________________________________

### **Gratuité du connecteur GoCardless**

Le connecteur Sellsy <> GoCardless est gratuit.

Cependant, les tarifs standard GoCardless sont appliqués aux transactions de prélèvement. Consultez **[la page des tarifs GoCardless](https://gocardless.com/fr-fr/tarifs/)** pour connaître les conditions tarifaires.

___________________________________________________________

### **Création d'un compte GoCardless**

Vous pouvez créer votre compte GoCardless de deux manières :

- Directement depuis **[gocardless.com](http://gocardless.com/)**
- Lors du processus de configuration de compte dans Sellsy

Pour plus de détails sur la configuration, consultez **[ce guide sur l'activation du prélèvement bancaire avec GoCardless](https://help.sellsy.com/fr/articles/5876292-activer-le-prelevement-bancaire-avec-gocardless)**.

___________________________________________________________

### **Import des mandats existants**

Il est possible d'effectuer un import de mandat existant pour un client.

Consultez la rubrique "Importer un mandat client (côté marchand)" dans **[l'article de FAQ dédié](https://help.sellsy.com/fr/articles/5876303-importer-des-mandats-gocardless)**.

___________________________________________________________

### **Point d'attention**

Il n'existe pas de lien unique entre les mandats GoCardless et les fiches clients dans Sellsy. La migration des mandats doit donc être effectuée individuellement sur chaque fiche client.

___________________________________________________________

### **Délai d'un prélèvement**

Par défaut, un délai de 2 jours est appliqué pour calculer la première date de prélèvement sur le compte du client.

Vous pouvez également définir une date précise de prélèvement lors de la création du prélèvement.

> **Attention :** il faut prendre en compte un minimum de 48h entre la date de création du mandat pour le client et la première date disponible pour programmer le prélèvement.

___________________________________________________________

### **Prélèvements récurrents**

Vous pouvez utiliser le module abonnement de Sellsy pour programmer des prélèvements récurrents.

Consultez la rubrique "Programmer des prélèvements pour vos factures (côté marchand)" dans **[l'article de FAQ dédié](https://help.sellsy.com/fr/articles/5871067-activer-le-prelevement-automatique-pour-le-reglement-des-factures-d-abonnements-gocardless)**.

Cette fonctionnalité est particulièrement utile pour automatiser les paiements de vos clients ayant souscrit à des abonnements.

___________________________________________________________

### **Limite de montant d'un prélèvement**

GoCardless limite à **5 000 € TTC** le montant d'un prélèvement pour des raisons de sécurité.

Néanmoins, vous pouvez lever cette limite en contactant directement GoCardless via votre compte.

___________________________________________________________

### **Montant minimum de prélèvement**

Le montant minimum d'un prélèvement GoCardless est de **1 €**.

___________________________________________________________

### **Absence de suggestions dans le rapprochement bancaire**

Si vous n'avez pas de suggestions dans le rapprochement bancaire ou si les paiements ne sont pas remontés dans Sellsy, vérifiez que :

Les ordres de prélèvements doivent être générés **directement depuis Sellsy** et non depuis l'interface GoCardless pour assurer :

- Le bon suivi des suggestions dans le rapprochement bancaire
- La remontée automatique des paiements dans Sellsy

___________________________________________________________

### **Remboursement d'un client**

Le remboursement d'un prélèvement GoCardless ne peut pas être effectué depuis Sellsy.

Le remboursement doit être effectué **directement depuis votre compte GoCardless**.

___________________________________________________________

### **Changement de mandat en cours d'abonnement**

Lorsque votre client change de mandat ou met à jour un mandat existant alors que l'abonnement est en cours, vous devez mettre à jour l'abonnement.

___________________________________________________________

### **Procédure de mise à jour**

1. Rendez-vous sur l'abonnement du client (accessible depuis sa fiche client, onglet "*Abonnement*")
2. Cliquez sur les 3 points à droite de la ligne d'abonnement
3. Sélectionnez "*Modifier l'abonnement*"
4. Vérifiez que le nouveau mandat apparaît bien dans le champ "*Mandat*"
5. Si c'est le bon mandat, cliquez sur "*Enregistrer*"

Cette manipulation permettra de prendre le nouveau mandat en considération pour les prochaines factures de cet abonnement.

___________________________________________________________

### **Support GoCardless**

Pour tout changement de plan, de RIB ou toute demande relative à votre compte et réglages GoCardless, contactez **[les équipes support de GoCardless](https://support.gocardless.com/hc/fr/requests/new)**.

L'équipe GoCardless pourra vous accompagner sur toutes les questions spécifiques à votre compte et à la configuration de vos prélèvements.
