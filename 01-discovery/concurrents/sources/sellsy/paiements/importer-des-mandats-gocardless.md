### Importer un mandat GoCardless

Rendez-vous sur la fiche du client concerné, onglet *"Mandats"*. 

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1253389054/32db2595a762c193cd77e6953d19/onglet+mandats.png?expires=1788635700&signature=8e2f18b659cf01ef11d455b82cceb8845cdeb2151a4567b95211a83341f021d7&req=dSIiFcp2lIFaXfMW1HO4zdZaS2nPHT0eeQLyqNdF0yezCrFoYTC5ULvOwNZ5%0An%2BRsMCyOHKZDJ%2FKqE54%3D%0A)

 Cliquez sur le bouton *“Importer des mandats”*. 

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1253392834/738c1ae54a48f00f2282be32e8df/importer+des+mandats.png?expires=1788635700&signature=09ad379bc749ee760a3bc614cd80af7a3fa6344fe7542bbcd2770ea0a6fff38c&req=dSIiFcp3n4lcXfMW1HO4zWsEDTYJcHiOVRSQn%2BNNlA8w6nM6YtwthP62m3T%2B%0AYYGeVCriVvmcbKt1imA%3D%0A)

Indiquez un ID Client GoCardless, puis cliquez sur *“Chercher”*.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1253396387/3abd0bf98bfca71912adcdefa0df/chercher.png?expires=1788635700&signature=8ca73bb622a2836860d2b1e82e50a4b5206f1cc76030fe423dfe4cbc8c5c37dd&req=dSIiFcp3m4JXXvMW1HO4zU1ryKp6hVY4VciK7vwh7U2eyWt1UoPEay0fAiwx%0AGWLK%2BY6%2BqtJCUGN0664%3D%0A)

 Sélectionnez le(s) mandat(s) que vous souhaitez importer, puis cliquez sur le bouton *“Importer”*.

> **Bon à savoir :** l'ID Client se trouve sur l’interface GoCardless (en haut à gauche).

### Importer des mandats GoCardless en masse 

Si vous êtes déjà client GoCardless, vous avez la possibilité d’importer l’ensemble des mandats présents dans votre compte GoCardless directement sur votre compte Sellsy.

Pour cela, il vous suffit d'[activer le module GoCardless et connecter votre compte](https://help.sellsy.com/fr/articles/5876292-gerer-mes-prelevements-avec-le-module-gocardless#h_b4a81b26fd) puis vous rendre dans le menu "*Banque" > "Liste des mandats". *Depuis la liste des mandats, vous pourrez alors cliquer sur le bouton *"Importer des mandats"*. 

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1262221263/cc5e4d588ba0847ecbec26f39f97/importer+des+mandats.png?expires=1788635700&signature=0af1477f83dffd1ea931b3f6cc5a2f7de3df64843310cb6200fa2755ca3df1ff&req=dSIhFMt8nINZWvMW1HO4zUbfrOwgSAS8TEhvlbHEQpD2usjk0QEc3w6Z6J2K%0Az2hNWd40zgutVgp5mlE%3D%0A)

Un message d’alerte vous indique qu’une recherche de correspondance va être lancée entre les mandats présents dans votre compte GoCardless et les clients présents dans votre compte Sellsy.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1262221919/6cb977791c46bd88b8e6680f877f/Message+syste%CC%80me.png?expires=1788635700&signature=4dd5ffd8c9f9de9b7534c8a75b1b5fe30fea825999f8684342662d3ff5c00f14&req=dSIhFMt8nIheUPMW1HO4zXhuVr8THT%2B%2BE9CrReMDexaSrk4Sv0eRKTiTg%2Fim%0AaVIiSxNMZ8CBEPy0orc%3D%0A)

À la suite de la recherche, nous vous proposons deux tableaux :

- les mandats avec les correspondances identifiées,
- les mandats sans correspondance.

Les critères de correspondance sont les suivants :

- Nom du client,
- Email du client.

Vous pouvez ajuster ou compléter les correspondances des mandats et des clients en utilisant le champ *"Rechercher"* dans la colonne *"Clients Sellsy"* à droite de chaque tableau.
