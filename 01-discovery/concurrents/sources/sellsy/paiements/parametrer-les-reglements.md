# Paramétrer les règlements

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261858244/b6276eff90dc29f6268b941b4a2d/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=cf2e426fa7a01b02431334861ca447a91c7a291ecfb7cf4a9bebccf21822577d&req=dSIhF8F7lYNbXfMW1HO4zazzaEH6jXd5IHpOlh%2BlQcD2i5jqdHqAo0Zu69SG%0AFavQ9jatPDnmUEVcV9s%3D%0A)

Pour paramétrer vos règlements, rendez-vous dans le Menu, puis dans les réglages et cliquez sur *"Règlements".*

### Moyens de paiement 

Dans la partie *"moyens de paiement",* vous pouvez **sélectionner vos moyens de paiement par défaut** (en les cochant/décochant). 

Si vous souhaitez **éditer les moyens de paiement**, cliquez sur *"Modifier les moyens de paiement".*

![](https://downloads.intercomcdn.com/i/o/768359853/6cd8fce97aa0fada019809eb/Moyens_paiement.png?expires=1788635700&signature=c695c7295c215552db5dbce4798d5e67e4e8540e8af6d305f1b38c1c682c9b8d&req=cyYvFcx3lYRcFb4f3HP0gHGFA0Re5bURTR3ai0u40glcDaSGCHv6J0ZQ5P4U%0AmAvxonOpZbKvLh0JEQ%3D%3D%0A)

Depuis la page qui s'affiche, vous aurez la possibilité de **créer de nouveaux moyens de paiement**, de les activer/désactiver, de les modifier ou encore de les supprimer. 

![](https://downloads.intercomcdn.com/i/o/768361567/4cfee8ea22ccf60150c86170/Moyens_paiement_modifier.png?expires=1788635700&signature=2abc7a3fdef48ca531987f444e53097ec9fa7b4ca36806a8991e635ddfcabe2a&req=cyYvFc9%2FmIdYFb4f3HP0gMm%2Fow9wFOuuSPbO%2FnqVFAK2ZR1oWX9A6HM7NLAN%0AEckT6tg36Z19UtDxjA%3D%3D%0A)

### Libellé de règlement 

Dans la partie *"libellé de règlement",* vous pouvez **sélectionner votre libellé de chèque et votre compte bancaire par défaut**. 

Le **compte bancaire** définit à ce niveau correspond au compte bancaire qui sera utilisé par défaut pour toutes les nouvelles sociétés que vous créerez. Pour les sociétés déjà existantes dans votre base, il faudra mettre à jour leurs préférences. 

Cette mise à jour est possible depuis l'onglet *"Préférences"* d'une fiche société, en cliquant sur le bouton *"Éditer".* 

Si besoin, la mise à jour pourra être effectuée en masse depuis la liste des clients, prospects et fournisseurs. Pour ce faire, sélectionnez plusieurs sociétés puis choisissez *"Éditer les préférences"* dans le menu déroulant *"Choisissez une action à effectuer".* 

Si vous souhaitez **éditer les libellés de règlement**, cliquez sur *"Modifier".*

![](https://downloads.intercomcdn.com/i/o/768369420/898ebe3acfe23abfd7baa448/Libelle_re%CC%80glement.png?expires=1788635700&signature=8e3974d5aa40d84464fb46937a93a4706902983b781da4968d7db507dcfd0e84&req=cyYvFc93mYNfFb4f3HP0gOPyJ73A3dAsQorUv4bWf%2BL6OFK3JTPVd7RcSGSQ%0AZEFeumY4s%2BNr1qTDiA%3D%3D%0A)

Depuis la page qui s'affiche, vous aurez la possibilité de **créer de nouveaux libellés de règlement**, de les activer/désactiver, de les modifier ou encore de les supprimer.   

![](https://downloads.intercomcdn.com/i/o/768392425/60ba6b5f672d0eeca8db2c3f/Libelle_re%CC%80glement_modifier.png?expires=1788635700&signature=9b7405e262a1a1045e374b922e1403f31556db3d18aab6c50edee16e86661eea&req=cyYvFcB8mYNaFb4f3HP0gJnptGdEH6BHTKpU4djcK5pSlWW4byOzqL6AppF%2F%0AxtPGuDxvCEmH5hzpSw%3D%3D%0A)

### Conditions de règlement 

Dans la partie *"conditions de règlement",* vous pouvez **sélectionner votre délai de paiement par défaut** et **paramétrer une demande d'acompte par défaut** (un % ou un montant). 

Si vous souhaitez **éditer les délais de paiement**, cliquez sur *"Modifier".* 

![](https://downloads.intercomcdn.com/i/o/768441095/aed88e01a560901664871630/Delais_paiement.png?expires=1788635700&signature=c2c810c80c61c01eaf77e935c685e5a2cfc2d0c23babee769061a89b2b988079&req=cyYvEs1%2FnYhaFb4f3HP0gOS0U3YPRCu7nkHdUBIqWZyxcqT20kWpMRVAbV6u%0AQ%2BXi7hpR3e52B5k9Ug%3D%3D%0A)

Depuis la page qui s'affiche, vous aurez la possibilité de **créer de nouveaux délais de paiement personnalisés**, de les activer/désactiver, de modifier ou encore supprimer vos délais de paiement existants.

Vous pouvez également décider d'**afficher la date** et **paramétrer le nombre de jours** (fin de mois ou non). 

![](https://downloads.intercomcdn.com/i/o/768452931/865108b75881f6f8043bce8e/Delais_paiement_modifier.png?expires=1788635700&signature=61757c5962cca0252cc4af22af9f6be679b84bd872e112af3a48db827a95bf26&req=cyYvEsx8lIJeFb4f3HP0gMoguF7RQFbfqBW6sAUOb2wTph4zRhA8fQA3VzAN%0ATZyYyuKpC%2BxbmkN4NQ%3D%3D%0A)
