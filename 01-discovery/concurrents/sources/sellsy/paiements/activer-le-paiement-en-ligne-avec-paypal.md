# Activer le paiement en ligne avec PayPal

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2200442402/7ee2a3e1be7fa8dd1177ddc3a5ef/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=fe1a73f8be89fd724ea1da351a27be4e17617ef11ab46802fa10d49b0dd39889&req=diInFs16n4VfW%2FMW1HO4zeSCFXj1rV16KcNZc6EHnmZmDHliDYJj%2F1T0dcM4%0AGXm9eaUICiAcecCRzsA%3D%0A)

Une fois activé, vous pourrez envoyer des devis ou factures avec **un lien de paiement sécurisé PayPa**l. Le règlement sera automatiquement enregistré dans Sellsy et associé au document.

___________________________________________________________

### Avant de commencer

Pour connecter PayPal, vous devez :

- disposer d’un **compte PayPal actif**
- avoir un accès **administrateur** dans Sellsy
​

> **Bon à savoir** : vous pouvez aussi créer un compte PayPal depuis Sellsy, en suivant les instructions de connexion ci-dessous.

___________________________________________________________

### Étape 1 : Activer PayPal dans Sellsy

1. Ouvrez "**[Menu" > "Réglages" > "Paiements en ligne](https://www.sellsy.com/settings/quickpay)"**

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169156737/ce8dd504136c56d69737638a8f53/Screenshot+2026-03-16+at+14_35_02.png?expires=1788635700&signature=7f418b482601fb834e98fbf5aa0340e8551f5b575441e29ec9a0583afb8b5b74&req=diEhH8h7m4ZcXvMW1HO4zYWpJg%2BFjJt4nmEPcI3fgmGWWvYUZdv78eFtLSgK%0A9nnw%2FqCeeQPrf4HYUlI%3D%0A)

2. Cliquez sur le bouton ***"Connecter"* dans l'encadré PayPal**

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169152615/6b440eff8d0f846d47ee01875ba9/Screenshot+2026-03-16+at+16_42_33.png?expires=1788635700&signature=305edf8f12ff3aded6bc6afa0b357af50764779c6548b8050495bc5569f84837&req=diEhH8h7n4deXPMW1HO4zdOGtALS%2FOsqQszmRC42tvsNqslv3f1m2DRhXkF0%0AY9cUXol3F%2F0D52JyPnY%3D%0A)

3. Cliquez ensuite sur *"**Connecter mon compte PayPal**"* 

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169157736/efeb463354065257041c34a85f47/Screenshot+2026-03-16+at+16_43_02.png?expires=1788635700&signature=96803731b32f4616ac7d1052dea159c7a66881fc028e5dfa01557d01063160a5&req=diEhH8h7moZcX%2FMW1HO4zQdFeVY%2B8cWCd0%2BX9lzIhpvHWzl20w1KXH0%2Bj08d%0AXa0OoQvYck%2Fp4E2rrpk%3D%0A)

4. **Renseignez** **les informations nécessaires pour la configuration API** pour finaliser la connexion

- le nom d'utilisateur API
- le mot de passe API
- et la signature API

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169163819/589dace79108f1f62d54c545f38a/Screenshot+2026-03-16+at+16_59_33.png?expires=1788635700&signature=9ed1c570f47904e4696b1e0efcf3de29714f17b5e30cb9cc5ffc0b67b9c3f918&req=diEhH8h4noleUPMW1HO4zd4vWJNxeR4jJR%2FqiELITUptDetUM7UNlwRMxU3d%0A%2FL1ZW9Y148hJA4Z1%2Bwg%3D%0A)

Vous pouvez aussi décider le moyen de paiement que vous voulez assigner aux paiements provenant de PayPal. Vous pouvez aussi configurer un moyen de paiement nommé "PayPal", [en suivant ce guide.](https://help.sellsy.com/fr/articles/8034545-parametrer-les-reglements)

> **Bon à savoir :** Si vous n'avez pas encore de compte PayPal, vous pouvez en créer un depuis cette étape.

___________________________________________________________

### Étape 2 : Activer le paiement sur un devis / facture

Vous pouvez activer le paiement en ligne lors de la création ou modification d’un document (devis, facture, etc.).

1. Ouvrez **Modifier les préférences du document**
2. Activez le moyen de paiement **Carte bancaire **ou** PayPal**
3. Activez l’option **Paiement via PayPal**

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169204931/800fafa9fc48eff221d1b748479e/image.png?expires=1788635700&signature=e79696c96856dcf1174c63bd31ffd474348830c8982a99ab26789484ed77f059&req=diEhH8t%2BmYhcWPMW1HO4zaxg0TimLIQl02IAF9OtNdns06fLIGqmXoDBYlPQ%0A3aj7uHyQ%2FsV4L6nD3nI%3D%0A)

Vous pouvez également activer ou désactiver PayPal directement depuis votre document en cliquant sur l'onglet ***"Paiement en ligne"****.*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169219339/d8f80fa7ba01c3bc67d97f319259/image.png?expires=1788635700&signature=f320605f9a3c237046cc1e06120fae3a1590fabe53a478e145259692cbbb0fdf&req=diEhH8t%2FlIJcUPMW1HO4zbaFdnSL3o94kde5WjlMlOFOMogeGiElm7Zeg3%2BA%0A3X2jVKSFqhO3JiL%2Bkkg%3D%0A)

### Ce que verra votre client 

Une fois le devis ou la facture envoyée : 

1. Votre client ouvre le **lien public du document** dans son email et choisit l'option **"PayPal"**
![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169187767/cf31c6dac630b21860a9e62b07c2/Screenshot%2B2026-03-16%2Bat%2B17_05_46.png?expires=1788635700&signature=4834c5b8fc7145b071667d5cac2850fd00d5972582c38a85302a916f56fa7344&req=diEhH8h2moZZXvMW1HO4zaeGB3tla0b4ewSJMr4Jvf5LsxjAzXZldWf2Wyhs%0AyxrZ%0A)

2. Il saisit ses **informations de carte bancaire** ou se connecte à son **compte PayPal**

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169189515/5062c9e022554e94de33fe82c5f0/Screenshot%2B2026-03-16%2Bat%2B17_06_16.png?expires=1788635700&signature=5aaba230e1068c97d2332690eb4ab79bb8953e99603e5babb7d325debd21112d&req=diEhH8h2lIReXPMW1HO4zYNRLtJvWQtiPaVmOnPlsrbVjV9PlUFiurl4L3yT%0AUtmtStkM%2F6G%2BJLXC4Dc%3D%0A)

3. Il valide le paiement.
​

Le paiement est ensuite automatiquement enregistré dans Sellsy et la facture passe en statut **Payée**.

### Questions fréquentes

**Quels frais s'appliquent sur les paiements via PayPal ?**

Les frais varient selon que votre client paie par carte bancaire ou avec son compte PayPal. Les tarifs peuvent évoluer selon le pays du client ou des conditions spécifiques liées à votre activité.

Consultez la [page des tarifs PayPal](https://www.paypal.com/fr/business/paypal-business-fees).

**Mes clients doivent-ils avoir un compte PayPal pour payer ?**

Non. Vos clients peuvent payer avec leur compte PayPal ou directement par carte bancaire, selon les options activées.
