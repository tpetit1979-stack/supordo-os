# Activer le paiement en ligne avec Stripe

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2200457156/bae8a2c99236515e13e22e553e36/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=3ef4a7ef624663a02b8ac9a6ec4a86e6651369ca3226ead83878b4103947fc05&req=diInFs17moBaX%2FMW1HO4zct7VjvB%2BC9rMf7NvGAt%2BiOnIwzDQ1hvxCLWiLyR%0AOyDIq9QryWeP8ARXnDc%3D%0A)

Une fois activé, vous pourrez envoyer des devis ou factures avec un **lien de paiement sécurisé**. Le règlement sera automatiquement enregistré dans Sellsy et associé à la facture.

___________________________________________________________

### Avant de commencer

Pour connecter Stripe, vous devez :

- disposer d’un **compte Stripe actif**
- avoir un accès **administrateur** dans Sellsy
​

> **Bon à savoir** : vous pouvez aussi créer un compte Stripe depuis Sellsy, en suivant les instructions de connexion ci-dessous.

___________________________________________________________

### Étape 1 : Activer Stripe dans Sellsy

1. Ouvrez "**[Menu" > "Réglages" > "Paiements en ligne](https://www.sellsy.com/settings/quickpay)"**

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169025936/601cff50740716c2f495b35d816f/Screenshot+2026-03-16+at+14_35_02.png?expires=1788635700&signature=432d0bbf320d7a4e138f4c5ba24a4c7ee3e63545dca4f3b33e88227072ce9200&req=diEhH8l8mIhcX%2FMW1HO4zSAD9v6SwhoLc3Rllj9AGD%2Bsdx%2BSwd0zYwH%2Fo5NI%0Ai6NHSeVvKRib4SHAcYo%3D%0A)

2. Cliquez sur le bouton ***"Connecter"* dans l'encadré Stripe**

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169029240/06a1e196a81f77388a5625f7496f/Screenshot+2026-03-16+at+14_37_30.png?expires=1788635700&signature=5b782b8747a051ff4e55782bf39e5b01087e8456494f6cbedfaf0742ad121e19&req=diEhH8l8lINbWfMW1HO4zX2%2BHq2W9LuTqsXnVGWCdGAQMe8hNIBlDb6OdPUb%0A6msFztDe7phv%2Bu13qtg%3D%0A)

3. Cliquez ensuite sur *"**Connecter mon compte Stripe**"* 

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169030573/3d5efa1d6a6ef82dc53c64fb9c5b/Screenshot+2026-03-16+at+14_39_12.png?expires=1788635700&signature=77f4eed111a1dd3a1e42a24e266539080d466c6785955e863da66f0adb4c0efb&req=diEhH8l9nYRYWvMW1HO4zc%2BA8OrN%2B4aFSQAXUfdOj65Bpgy%2BR%2BaVxnMc0Qlj%0AAowczg1jWS0wf6Yq6cI%3D%0A)

4. **Renseignez** **votre adresse email** pour finaliser la connexion

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169038105/462032b7fd9c037687b8811b4644/Screenshot+2026-03-16+at+16_20_33.png?expires=1788635700&signature=fa40477c1e4618453466dae1e39e27691a5d0c0b84533ca6b42693cd47d85fd2&req=diEhH8l9lYBfXPMW1HO4zQMqbeVsJewSC2gPpYkKJI34ij8PrOVpvEK3imre%0AGAFVrl%2Fxpq5xkyUutG4%3D%0A)

> **Bon à savoir :** Si vous avez déjà un compte Stripe, vous serez amené à connecter votre compte Stripe à Sellsy. 
> ​
> Dans le cas contraire, vous serez invité à créer un compte Stripe pour démarrer.

___________________________________________________________

### Étape 2 : Activer le paiement sur un devis / facture

Vous pouvez activer le paiement en ligne lors de la création ou modification d’un document (devis, facture, etc.).

1. Ouvrez **Modifier les préférences du document**
2. Activez le moyen de paiement **Carte bancaire**
3. Activez l’option **Paiement via Stripe**

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169027328/9c268dc23dd016a5a1a849348c83/Screenshot-2B2026-03-16-2Bat-2B14_53_11.png?expires=1788635700&signature=01ae6e0c7e54044d244f17e24fc4dd5f3496f3413b1800129a6aa46eff536177&req=diEhH8l8moJdUfMW1HO4zSkBcCmRLANIKcNh%2BlUPOX6WypfvX1A%2Ft%2FcXY38G%0A%2FPUbfkqAnlcsLcSor%2Bs%3D%0A)

Vous pouvez également activer ou désactiver Stripe directement depuis votre document en cliquant sur l'onglet ***"Paiement en ligne"****.*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169059827/e86e7bf36598fd0fe009124218c6/Screenshot+2026-03-16+at+16_27_41.png?expires=1788635700&signature=cc0bf01d6970403ec25f8dbf9ee67cc03979ce19e6bfadc76969df96386d0eac&req=diEhH8l7lIldXvMW1HO4zaEL4q1f9Yrqpx4MayqjJKfauSnYWUlfGRXPoR%2Ba%0ADi8M%2Fv9MliwebgXA%2F7w%3D%0A)

## Ce que verra votre client (vidéo)

Une fois le devis ou la facture envoyée : 

1. votre client ouvre le **lien public du document** dans son email
2. il saisit ses informations de carte bancaire
3. le paiement est validé

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2169009500/ae8f2136e28ca44b660fada4ccf5/payment_flow%2850FPS%29.gif?expires=1788635700&signature=29a15e29cdc391b8ec2de46142e4e751e97ddd08eeb007ebd78f1deffabfcdfb&req=diEhH8l%2BlIRfWfMW1HO4zRcehTMuW8VGCy4rE1TGU%2FKzw%2F6oeeO7kZV7bRcy%0Ao%2Fzbj2hdeZhOYYZxq5Q%3D%0A)

Le paiement est ensuite automatiquement enregistré dans Sellsy et la facture passe en statut **Payée**.

### Questions fréquentes

**Quels frais s'appliquent sur les paiements via Stripe ?**

Les frais dépendent du type de carte et du pays d'émission. Les cartes européennes bénéficient généralement d'un taux plus faible, tandis que les cartes hors UE ou certaines cartes professionnelles peuvent entraîner des frais plus élevés. Consultez la [page des tarifs Stripe](https://stripe.com/fr/pricing).

**Puis-je utiliser Stripe pour les paiements récurrents ?** 

Oui. Vous pouvez activer Stripe sur les abonnements ou factures à plusieurs échéances. Consultez [le guide suivant](https://help.sellsy.com/fr/articles/5876314-gerer-vos-paiements-par-empreinte-de-cb-avec-le-module-stripe) pour l'activer.
