# Rembourser un client

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1932983434/b5942f65874faa54e8f1039fb4da/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=3892eb2c3b1aa366f167a34a6c6941d974169cc8e78776448d53b180041ff737&req=dSkkFMB2noVcXfMW1HO4zZDRt6KqISAmQMlUZhtUVgcjD4xSayftHJQu9fjv%0AofdDVQ%2FW4rbqv2oX9v4%3D%0A)

Dans certains cas, comme un retour par exemple, vous pouvez souhaiter rembourser directement le client.

___________________________________________________________

### Procédure pour rembourser un client 

Pour se faire, depuis l'aperçu de l'avoir, cliquez sur *“Enregistrer un remboursement”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445630920/80435eabd43a87e68a4894a1/AlIDD3ebfSmqVACSqIssPkwKMozgGA2uVJr-uaPNzbjrujpSi4QAY6ylB16IbOm5YYdgLuIuUSHXLGsFNgg1aGJdTxSSEQ_r-4aTd7TGyf4cMgLarxORs8otQTrTyJx8N3GjQbWg?expires=1788635700&signature=4cce41ec31e2327f72576f080f87f25cecb371983463e654406b55c9ba929dc2&req=cCQiEMp%2BlINfFb4f3HP0gDUx7mFS4MaPHKnkmvo3xwiLFmwamCV1T0B%2FHbYu%0AM2VMhwVAh%2FbDQ26Rsw%3D%3D%0A)

Enregistrez alors votre remboursement exactement comme vous le feriez pour un encaissement client.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445630928/d1938ba0e9e00aabc13d0474/POXCuX8fP_2sX2iPbEvvelH1tDDG9qfhJHAG877Y0Qb7ZvsAGt35SVZt2Wk1hpf9zLSI26BSPODe99lLwkDIR_5ULTLJC-ERKjtF31HByzvH6NZnF8ayvJ1jxzotCGo4o84RzEj-?expires=1788635700&signature=879b9824ab5e085beb734a533b9c21cbc63186b120f05ef2ca9fd77336b43481&req=cCQiEMp%2BlINXFb4f3HP0gOSulOlniO%2BA2vuq4GDkSCxjwz9POWVWcPVYGg37%0A7wc1WVLd%2Bl3I3xpQtQ%3D%3D%0A)

Vous pouvez ensuite accéder à la liste des remboursements depuis l'aperçu de l'avoir dans l’onglet *“Récapitulatif”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445630941/4f104caaad9f3e4326cba0a6/N1Nyswf4cdSf15jH16RbjhCos6fo_pict6TzQgciikm001FcwSiNisnoqYwAvqUjnD8UztHvgVmTy59J9oFI9C2dok5IAI-9Pr-SLzR_GuwADLC3Qe1fy3lhkcWtF4al_64C_65u?expires=1788635700&signature=f12505c46999812f98e04bbead8d4a6415d88c63c62542c0e4e88e8949a22025&req=cCQiEMp%2BlIVeFb4f3HP0gFpuJXVfTcQZd8fxpRDp5M8H8M9%2FA2rWYcYYwSW6%0ADKby8G2NBdQWwv1gOA%3D%3D%0A)
