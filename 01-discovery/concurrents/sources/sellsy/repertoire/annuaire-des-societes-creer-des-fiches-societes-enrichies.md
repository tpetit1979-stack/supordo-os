# Annuaire des sociétés : Créer des fiches sociétés enrichies

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261813559/7c2b81e270b80db62918656a5596/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=4419da3b4b9f1774657c6e959a15946da654494b553fca6e9e88e0b3a4d2a40c&req=dSIhF8F%2FnoRaUPMW1HO4zRN%2BnUribN4EIztrhHxSX1JLOOZMHHprEx5YCXoq%0AvEN12nWJ%2FCBDR4IQTC4%3D%0A)

La fonctionnalité "Annuaire des sociétés" vous permet d'enrichir très facilement vos fiches Sellsy de type prospects, clients ou fournisseurs.
​
Elle se repose, entre autres, sur la base SIRENE de l'INSEE. Les données fournies sont nécessaires notamment à la facturation électronique.

L'annuaire des sociétés Sellsy propose trois grandes fonctionnalités :

1. enrichir vos fiches clients existantes,
2. créer une fiche société basée sur l'annuaire,
3. filtrer l'ensemble de la base pour constituer des listes de sociétés prospects.

Pour chaque interrogation réussie, le module va retourner les informations suivantes (si disponibles) :

- le nom de l'entreprise et, éventuellement, le nom commercial,
- le siren, le n° de TVA intracommunautaire, le code NAF,
- la forme juridique,
- l'adresse, le code postal et la ville,
- la date de création.

Nous avons amélioré ce module pour qu'il fournisse d'autres informations pertinentes comme les réseaux sociaux, le site web, ou encore la description d'activité de l'entreprise. Ces dernières, qui ne sont pas d'ordre réglementaire, peuvent nécessiter une vérification de votre part.
​

### **Utiliser l'annuaire des sociétés Sellsy lors de la création d’une société**

Lorsque le [module est activé](https://help.sellsy.com/fr/articles/5865833-fonctionnement-de-l-annuaire-des-societes-sellsy), une barre de recherche apparaît en haut de la fenêtre de création d’une société.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2646719403/89fe5a1ba8e8d112426fec825361/Capture+d%E2%80%99e%CC%81cran+2026-09-02+a%CC%80+17_26_41.png?expires=1788635700&signature=1ae7626c60850905e4c6f83ed48b1e5d8c9b608c835c01b1580033b15cda2953&req=diYjEM5%2FlIVfWvMW1HO4zTKpmZmq%2BgcxsTdPkX1IZTf8nNHfJokRpgW0M%2Fl%2B%0A12%2BnyiyzCiv6Bmjkz%2B0%3D%0A)


Il vous suffit d'entrer le nom de la société et de lancer la recherche. Le résultat de la recherche s'affiche juste dessous. Pour en savoir plus sur un résultat, cliquez sur l'icône d'information pour la fiche concernée.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2646721471/38634b2fd7a906cfe36b6f5ff3c0/Capture+d%E2%80%99e%CC%81cran+2026-09-02+a%CC%80+17_27_34.png?expires=1788635700&signature=fd8d0f1486c4dc6d82033a86c3bd00c6c9765b914b89ad2699a533c606f4db2f&req=diYjEM58nIVYWPMW1HO4zZMyXkuhbtDMGu66eZRTYu2skbno3uh3Al2H0OST%0AeGhrREOgmDBUw1EE7Os%3D%0A)

Vous pouvez également rechercher par numéro Siren ou Siret.

En cliquant sur l’entreprise que vous souhaitez ajouter, le formulaire est alors automatiquement rempli avec les informations disponibles. Complétez avec vos éventuelles informations puis cliquez sur Enregistrer pour créer la société.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2646723332/543c2feb3282a1fd090d2799ae68/Capture+d%E2%80%99e%CC%81cran+2026-09-02+a%CC%80+17_28_25.png?expires=1788635700&signature=8c394252b116728d9c653e76f7bf2b50817c258f004806e70cdd8ce36ec8a5b8&req=diYjEM58noJcW%2FMW1HO4zX3dZw%2F21zOgwNRFAiwGrRQHrjcm5BhEjxS4v%2BPi%0AxAKaeIVsC878QrVkyio%3D%0A)

Si les informations financières sont disponibles, elles s'affichent directement sur la fiche société.

### **Ajouter un client depuis l'onglet "Annuaire des sociétés"**

Alternativement, vous pouvez cliquer sur *“Répertoire” *et *“Annuaire des sociétés”.*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2646742691/aae152e4dc8f2ab66e2d4d8ad07e/Capture+d%E2%80%99e%CC%81cran+2026-09-02+a%CC%80+17_23_56.png?expires=1788635700&signature=e056e29fa1e451ef4239529d9b545ef66ef877c7aa2bb879678ffd93c247c8c9&req=diYjEM56n4dWWPMW1HO4zayDEtctFteuipMPp2htMgpI%2FEDkeJpWrX0oPeN8%0AHS2mYCbcaS%2BgbkrHWZo%3D%0A)

La recherche s'effectue de la même façon que la méthode précédente : choisissez la bonne entreprise, le système vous propose alors de créer les entreprises sélectionnées.
