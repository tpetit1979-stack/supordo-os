### Le module Annuaire des sociétés

Le module Annuaire des sociétés vous permet de trouver les informations légales et financières d'une société à partir de son nom, département, numéro SIREN, numéro SIRET ou code NAF.

Pour la France, les données proviennent de diverses sources, dont la base SIREN de l'INSEE.

La recherche d'une société fonctionne pour les pays suivants :

- France
- Royaume-Uni

 Pour accéder à la configuration du module, cliquez sur votre menu puis sur * “Réglages”,  “Module externe” et “Annuaire des sociétés”.*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2646704942/81405e1fdf057b9bf8922611b7e2/Capture+d%E2%80%99e%CC%81cran+2026-09-02+a%CC%80+17_21_40.png?expires=1788635700&signature=ad838a6e56765ff0c9eb891066e8e5ed3b78bd07fefd531b063b506e8bbb94b3&req=diYjEM5%2BmYhbW%2FMW1HO4zZaJDnVvlBERbVjwDgduwbIvHWcYrqL1XO5sJ2MO%0AqVHZkwEv5vxzzMSWJ2s%3D%0A)

Vous avez la possibilité de configurer sur cette page le choix des pays disponibles ainsi que le pays de recherche par défaut.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2646706744/899d23233be717356db6a128b6d3/Capture+d%E2%80%99e%CC%81cran+2026-09-02+a%CC%80+17_22_27.png?expires=1788635700&signature=e1da5c8bcf7bf478b3f3e2563515596f22288509fccad07d71c7798c861a9eda&req=diYjEM5%2Bm4ZbXfMW1HO4zTg1TTYHfagNPn90TvaDSd7Y7owMCs50V0gZtbwO%0A6AF7BnGedbBFyHFHW3A%3D%0A)

> **Bon à savoir :** si vous souhaitez compléter des informations sur des pays autres que la France ou le Royaume-Uni, vous devrez renseigner les données des sociétés manuellement.
