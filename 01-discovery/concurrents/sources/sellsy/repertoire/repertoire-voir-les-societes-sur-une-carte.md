# Répertoire : voir les sociétés sur une carte

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261815147/2ff0651b76015ea9ea37635c88ac/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=8267e2e179f35846c25ffed399725f21da3a68b55c542a096f39ea300a990961&req=dSIhF8F%2FmIBbXvMW1HO4zdAXIk4BemVSqn5ZpZJ%2FaGqVgMaUAHnu1gn%2F4xTq%0AmQUVg5eljVeEZAtl5io%3D%0A)

Vous pouvez visualiser sur une carte l'ensemble de vos prospects ou de vos clients depuis la nouvelle version des listes prospect / client.

Rendez-vous dans les options de la liste (en haut à droite) et cliquez sur l'icône *"Vue carte".*


![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2646694275/ab04bd3dddcb9e5681dbc880f4b9/Capture+d%E2%80%99e%CC%81cran+2026-09-02+a%CC%80+17_17_44.png?expires=1788635700&signature=605b4addce66143be7915c7657f12403aaa4c1c2b0ea29f40a10e8bdfd192535&req=diYjEM93mYNYXPMW1HO4zXOjasAhpTBKovmAsSp21omsw%2B1qBF5WhU1wwbXA%0A46KVvyTyXJIJr2wB4VM%3D%0A)

Il suffira de cliquer sur l'icône *"vue liste"* pour revenir à la vue précédente.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2646696292/74edbb9ce993757f9b42438f2854/Capture+d%E2%80%99e%CC%81cran+2026-09-02+a%CC%80+17_18_37.png?expires=1788635700&signature=beee36e3867c50f0bc712e1db643c581b0a88c30b843538a179dbd7b14742b63&req=diYjEM93m4NWW%2FMW1HO4zThFqIRw6mOOaBUiefCubZul1ZAobcu7SIRHV9MF%0Ajqbclo0L03XW71%2Bc3lA%3D%0A)

> **Bon à savoir :** vous pouvez utiliser les filtres et les favoris comme sur la vue liste classique.
