# Commentaires : comment les utiliser

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1925541523/bbb9e88e6dd36d759110754ef9cb/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788674400&signature=a026e075e62ff19fd797b61d7854d1315e5a44fcc2fa5b50cf1049cdbab80fb1&req=dSklE8x6nIRdWvMW3nq%2BgTAW27iziYwRO%2FwVZ9aYZjL1hrjX4vkVeid63Ipr%0A%2FyAXP%2Bffk3zi5Z%2B3sNg%2BrNv6%2Big%3D%0A)

Sellsy dispose d'un système de commentaires vous permettant d'échanger facilement avec vos collaborateurs.

Ce système permet de créer facilement des conversations au sein de votre équipe et d’optimiser votre suivi commercial.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2646869954/a8c47feb74c66fbb3971bb49a345/Capture+d%E2%80%99e%CC%81cran+2026-09-02+a%CC%80+18_24_07.png?expires=1788674400&signature=8fddd75a610c6dd7372f397c8c777c90f1c437630fe1c342bd4c736933f646f5&req=diYjEMF4lIhaXfMW3nq%2BgT8FQrkOgb1GZJaMCx6cLRZxy%2Fcs%2BKjuGORAukYL%0AN56fu%2B%2F5E7cjHhBmjMqW8mufKFQ%3D%0A)

Les commentaires sont disponibles sur plusieurs fonctionnalités :

- sur le tableau de bord général,
- sur les fiches contacts (clients, prospects, fournisseurs),
- sur les documents (devis, factures...),
- sur les fiches de votre catalogue,
- sur les opportunités.

Pour saisir un commentaire, il suffit d'entrer votre texte dans la zone de saisie puis de valider.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2648169259/5646f3ad23090b1c1d478812d0a6/Capture+d%E2%80%99e%CC%81cran+2026-09-03+a%CC%80+10_11_21.png?expires=1788674400&signature=31664ddaaf45d50d531177d4e585060358adb5ca8950be9fbfb89ae44dbc5a3d&req=diYjHsh4lINaUPMW3nq%2BgVcW5zlnrC7hlor%2FSSjAWVbHAs1sa%2FYhk0sMY7rT%0A%2FTUXkAebbCWs9BD9g3korxPKHH0%3D%0A)

L'ensemble des commentaires postés sur Sellsy peuvent être disponibles en temps réel sur votre[ tableau de bord](https://help.sellsy.com/hc/personnalisation-et-utilisation-du-tableau-de-bord/tableau-de-bord-utilisation-des-commentaires?searched=true). Une fois l'affichage sélectionné, vous y retrouverez l'ensemble des commentaires  par catégorie.
