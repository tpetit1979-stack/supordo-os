# Sociétés : suivre les informations clés d'une fiche client

### **Chiffre d’affaires, règlements en retard**

Sur la fiche client, vous retrouvez les informations clés : Chiffre d’affaires, règlements en retard.

Chiffre d'affaires reprend l’ensemble de factures payées + avoirs liés à la fiche client.

Règlements en retard reprend le montant des factures en statut en retard.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2651000220/2e6da0980336e6d92b8aa0683019/Capture+d%E2%80%99e%CC%81cran+2026-09-04+a%CC%80+14_38_19.png?expires=1788674400&signature=eefcefc2d2dc78032b61c1a74000155261c2432fba6749f7fa05fa766ceb1aae&req=diYiF8l%2BnYNdWfMW3nq%2BgcJ34%2Bgy5NNkMK8YE2bGp5uKAMOC3j6hOvB%2FmuFO%0Ammrx4T82u59wF2zqdur4kPNEY1M%3D%0A)

En cliquant sur ces indicateurs, vous êtes automatiquement redirigés vers la rubrique Statistiques de la fiche client.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2651000437/0772f739c049e8a94cc2ec1b8594/Capture+d%E2%80%99e%CC%81cran+2026-09-04+a%CC%80+14_38_55.png?expires=1788674400&signature=3464c1d717b92f40a667f6ed7d7013a8e57d99eab54fda240819ecb4010237bd&req=diYiF8l%2BnYVcXvMW3nq%2BgeBwTvjiN3JwjeC8Mx3TrJM2N900NmNejzA9sevO%0AXHEhYe3PvhYM7Ln0Jj%2FdoWShzm0%3D%0A)

### **Smart tag**

Les smart tags sont mis en avant pour que votre équipe identifie rapidement les informations importantes sur le client.

Vous pouvez également ajouter, supprimer et mettre à jour les smart tags en cliquant dessus.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2651001387/9907a44312cf57ca8a750641b187/Capture+d%E2%80%99e%CC%81cran+2026-09-04+a%CC%80+14_41_48.png?expires=1788674400&signature=3e7da36406d2b5d085705fe532b9ea0535f786e1302114041764ec54368f15ce&req=diYiF8l%2BnIJXXvMW3nq%2BgQ%2FGHVzYdGzR290GniEmmWMDj1kXb4jT8yeHCKWM%0AGRi4KTFqH8FiI0KEnJgxJFvUjIQ%3D%0A)

### **Type de fiche**

Le type de fiche est rapidement identifiable avec le code couleur présent à côté du nom de la société, particulier ou du contact.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2651003284/31d29649980c19e92d74f6315d09/Capture+d%E2%80%99e%CC%81cran+2026-09-04+a%CC%80+14_42_23.png?expires=1788674400&signature=75d881b3a01eca80adf801021be10119757fa51401380696adeb0eb0b1155510&req=diYiF8l%2BnoNXXfMW3nq%2BgcrZM49Sk3A9mYqgbZ6pn6S%2FGSGfYj5Poi%2FuF1oD%0AUehWqQQKO77m1H9EA6X5G0dNlSE%3D%0A)

### **L'activité**

L’onglet activité permet de voir l’ensemble de l’activité liée au client : commentaires, tâches, emails, événements. Le travail collaboratif est alors facilité par le partage d’informations.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2651004532/539fc0047f8aa487cc5fa62ba648/Capture+d%E2%80%99e%CC%81cran+2026-09-04+a%CC%80+14_43_33.png?expires=1788674400&signature=810797caa6543204faf54fa19a4e628bc2e2cd4de8e095712d10f1fa84d7f55a&req=diYiF8l%2BmYRcW%2FMW3nq%2BgegjuCrpjqDzmsEONA0nYTOSAyZ1JQ6n1YeH0pir%0AHxqOudWhYl6inBLkdMTD%2Fl7PYbg%3D%0A)

Vous avez besoin d'épingler une activité afin de pouvoir la retrouver facilement parmi tout votre fil d'actualité  : 

Il vous suffit de suvoler à droite de votre carte, puis de cliquer sur *"Épingler".*
​

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2651007001/7ecb7492ef06b907534779912259/Capture+d%E2%80%99e%CC%81cran+2026-09-04+a%CC%80+14_44_08.png?expires=1788674400&signature=17beb4269ae5dd82a20087c26ac7885acd621e1ce8517d00c418901dc03a54c8&req=diYiF8l%2BmoFfWPMW3nq%2BgQxi2NXvhbYPwWPtODy6D3cS7qrTP7rqhOGUH0VZ%0AMD%2FsdlzMKXM5cwKOgM8jUmOzauY%3D%0A)


Vous pourrez ainsi facilement la retrouver depuis l'onglet* "Éléments épinglés".*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2651006585/afebb3e6b700c9901081b3bb5137/Capture+d%E2%80%99%C3%A9cran+2026-09-04+%C3%A0+14_44_36.png?expires=1788674400&signature=53469c8f136d5636fad06c9747cd4a7978dedff7813f4bfbe19a0a8cd0247324&req=diYiF8l%2Bm4RXXPMW3nq%2BgS6OPkrJB2dlIUhJFOwL%2BEStAQ0DHN9PWWtHE4l3%0AtBG%2BNcVv7VfzsfgpKvXUPkdn%2Fgs%3D%0A)

### ** Les préférences  **

Accédez facilement aux préférences sociétés à travers un onglet d'édition dédié.

Vous pourrez y modifier différents éléments : devis, transporteur, TVA, délai de règlement, compte bancaire, plan des devis, plan des factures, catégories tarifaires, moyen de règlement.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2651009053/8de5923f1795cb38c20094f55c57/Capture+d%E2%80%99e%CC%81cran+2026-09-04+a%CC%80+14_45_58.png?expires=1788674400&signature=9010caf93bf3ed70d63e43f21731aaa74db802c1b5a8de612c30a3e5882aef81&req=diYiF8l%2BlIFaWvMW3nq%2BgRuSvDQFCY1h7azo4%2B7AcnflJTRd3MaVynFwQm2T%0Ah%2FvpVlKDeoZSGIkLd4xxcwviIto%3D%0A)

### **Les notes **

Un bloc *“Note” *est disponible dans la colonne latérale et vous permet d'enregistrer rapidement des informations à savoir sur la société. De plus, si une Note est renseignée à la création des fiches, celle-ci est enregistrée dans le bloc prévu à cet effet.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2651010973/2cd6b69501bdb9e2130c73ecda09/Capture+d%E2%80%99e%CC%81cran+2026-09-04+a%CC%80+14_46_47.png?expires=1788674400&signature=f20d26d8900e25fec0c260e2336cc1d4017b81ccf23c6c93886dea9dd121baef&req=diYiF8l%2FnYhYWvMW3nq%2BgUdgeAqtMoI59Dl76mLCKT0C7%2FqEUur%2F4roVHZQO%0AYCue4KVxvdBPpw%2F%2BumGorcQfFvY%3D%0A)

### Résumé IA

Lorsque vous êtes sur une fiche client, cliquez sur l’onglet *“Résumé IA”* dans le menu à gauche pour générer un résumé client.


Puis cliquez sur *“Générer”* pour créer le premier résumé IA pour votre client. Une fois généré, le résumé sera disponible pour tous les collaborateurs avec accès à cette fiche.
​
Pour plus d'informations sur cette fonctionnalité, [cliquez ici](https://help.sellsy.com/fr/articles/10054342-resumes-client-ia-resumer-une-fiche-client-en-un-clic-avec-sellsy-ia).
