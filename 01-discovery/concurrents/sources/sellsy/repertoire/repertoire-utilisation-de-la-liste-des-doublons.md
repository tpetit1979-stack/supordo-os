# Répertoire : utilisation de la liste des doublons

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261809630/9561ff76126797360b7277b8b33b/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=eca0bb90dc3dfda25af058e38e8bf152a1a29921868bd9ac50194e1a9a0b7a2b&req=dSIhF8F%2BlIdcWfMW1HO4zWNaqTweqL6G%2F%2BocNZWkqKnT1LYS44PrhqRK58IX%0Av1ONH0XOuijLvODHuus%3D%0A)

Cette fonctionnalité est disponible depuis le menu *“Répertoire”,* *“Lister les doublons”. *


![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2646689649/7a048ff2ca069d82d62db6f0fa5b/Capture+d%E2%80%99e%CC%81cran+2026-09-02+a%CC%80+17_15_58.png?expires=1788635700&signature=643728bc95583c8c57c6b4321f9a64088167d5b65739fadc9196b35abd361b89&req=diYjEM92lIdbUPMW1HO4zRiS7M4vFTzBFwnCjGIAPqgPBf%2FXLPqTc3eICHbi%0Aadtb9%2F3m4GwfXVMsqOs%3D%0A)


Pour lancer une recherche de doublons, choisissez un type et des critères de recherche puis cliquez sur* “Valider”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/451594058/232278931fedbb2c0a3441ff/TacHjPmfEsnSBqtf8b_t9ka0Yj0VtcScumm0eSeCReERxSVneyeFU_zcbl58lvfLteWM1SYO5hPfXDQ3huj9UNxR1DGOSpqcGX7l3f_RyL47PPWvwNsO06bZwRHJt8sdTqYC-oMc?expires=1788635700&signature=b85ee1aba7e041ffa5e5016d66307bc23cc14361841819f7e6e9b22a6c969c31&req=cCUmE8B6nYRXFb4f3HP0gCC%2B02qi8G25IMzBo9KnzpAxN4tUXZCL4sZsT%2Blx%0AhulygF3V8OS2SS0tow%3D%3D%0A)

> **Bon à savoir :** lorsque vous ajoutez plusieurs critères, la recherche fonctionne en *"ET" (par opposition à un fonctionnement en "OU")*. 

Vous retrouverez ainsi la liste de vos contacts/prospects/fournisseurs qui existent en plusieurs fois dans votre base de données. Dans la colonne *“Détails des doublons”, *vous avez la possibilité de cliquer sur les flèches bleues pour voir plus de détails. 

> **Bon à savoir : **cette liste est uniquement consultative, vous ne pouvez pas réaliser d’action depuis cette page. 

Si vous souhaitez traiter les doublons, vous devez cliquer sur la flèche bleue puis sur le contact concerné.
​

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2646685125/9273a437f51ffe68853d97f1dc6d/Capture+d%E2%80%99e%CC%81cran+2026-09-02+a%CC%80+17_12_43.png?expires=1788635700&signature=260553cfcb122d3dbc56943b4b62b98adf85cda14be0640fa9931c3f1b21a560&req=diYjEM92mIBdXPMW1HO4zeEJg%2BZ7%2BnD3IVU0zVOZoJrMtFAvPtN%2B5THcOCiW%0AsBJQr4IqTI9eRbMSh3E%3D%0A)


Vous serez ensuite redirigé vers la fiche détail afin de réaliser une action comme une archive ou une suppression.
