# Enrichir les données d’une société existante

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261814309/a96142c3705836d41a1e629bdaea/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=26e47b390b4cbfeae6f40d5cb1a2c8959c22fc8f5d3ef9f8b8481c5fb5445a64&req=dSIhF8F%2FmYJfUPMW1HO4zQm6L54N3K4f22kXRhXqXH3oj004xr7IXAaW0sJ7%0Ajaka4iDDi93s8ljn3Tk%3D%0A)

Pour enrichir les données d’une société déjà créée sur Sellsy, rendez-vous sur la société que vous souhaitez modifier, puis cliquez sur le bouton “action” puis sur “Compléter via l’annuaire”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444595600/41a191231e1a1981a579a8c6/GPoZ1_hDfTVlKxN1Jkzo9LLdb8ago7k7bGqS7GkSXwMfc683DNskpMz1-DTH9qLL775zlVpsmTBNwnhsyilhCB5r1uVJ-_7Aj8RIZ4ppF3cyGzCwl5n1EKsJiwQi1yzL77GrrG-Q?expires=1788635700&signature=7cbf2ae7ad3f9dc75d39db105d304345142a038844580fe83b2b9abe3796e8a0&req=cCQjE8B7m4FfFb4f3HP0gLBGM4sajiu7NoBx73uWKpMLMH0YpYbklOmZ1bd6%0AHWx77ZaXrpvYuh5nvg%3D%3D%0A)

Les données suivantes sont récupérées et sont comparées à celles de la société : Nom de la société, SIREN, SIRET, Forme juridique, Code NAF, Numéro TVA, Adresse.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444595607/13f83573d430d5e9dc5ebabf/9EJLFRz6nVxTUybbvJteESjEGu71hACz80EbRa2j7IGN8EvVN2Lo55qzETi4l08dBHKdYLiR-WKWxx7pvJd4Rf3zCyPWj75j9xUTcYZl7dEYmIxks5PABWEc5Bv76X-mKi-s3dKX?expires=1788635700&signature=072e55a4ffe8e9b0a946e79a15fc733d6d5dfaffa95f9ba7bae6a0bda3ceccef&req=cCQjE8B7m4FYFb4f3HP0gKheWDJRnJ1nmCROZHrfUoAaZHUjtpunC02Mfr5q%0AmVDyIm6PkAOzWJnnyw%3D%3D%0A)

Vous avez la possibilité de choisir quelles données doivent être conservées en sélectionnant les éléments à mettre à jour.
