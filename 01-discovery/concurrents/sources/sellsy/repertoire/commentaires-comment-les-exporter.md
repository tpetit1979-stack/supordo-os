### Export (CSV ou PDF)

Pour réaliser l’export au format CSV des commentaires il faut vous diriger sur les listes :

- Liste des clients
- Liste des prospects
- Liste des fournisseur
- Liste des contacts
- Liste des opportunités

Prenons l’exemple d’une liste de clients, cliquer sur “*Actions*” puis sur *“Export CSV”*.


![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2649115092/a6a51925c82271ef6065527d11da/Capture+d%E2%80%99e%CC%81cran+2026-09-03+a%CC%80+17_27_05.png?expires=1788674400&signature=dec8d15ef1e3b1903e1615943f75a5572ba6234d7d0a939c26ce163b33bd9ff9&req=diYjH8h%2FmIFWW%2FMW3nq%2BgU%2FfrwM7zIeEMsoR33CrVXpLTR0aErFkdsj3JSJZ%0AcU4KGo7C1F8JOtAK%2Fw%2BNmdDLNpM%3D%0A)

La fenêtre suivante s’ouvre. Pour exporter les commentaires, cliquez sur “*exporter les commentaires liés*” puis enregistrez.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2649117048/0c02f0aad89bc22e8d36e15b0b2d/Capture+d%E2%80%99e%CC%81cran+2026-09-03+a%CC%80+17_28_02.png?expires=1788674400&signature=b4c3217ede29d773ba8b2fe156a2109e88fb535fbf18c234b8bfd2e23e595d78&req=diYjH8h%2FmoFbUfMW3nq%2Bgc6VLnrHAfineWLZO1u2bixUFuv8qNP%2Bf5a9RTgw%0AvDVw8igOZFK8T6erfmqoGoNRLFA%3D%0A)

Cette action va générer un fichier compressé (Zip) qui contiendra : 

- client.csv,
- commentaires.csv.

> **Attention : **si vous cochez* “exporter au format import”* les commentaires ne seront pas présents.

### Export avancé (JSON ou PARQUET)

L'option *"Export avancé"* est disponible sur tous les exports. Elle vous permet d'exporter vos données aux formats JSON ou PARQUET, plus facilement exploitables dans le cadre d'intégrations API sans nécessiter de retraitement.

Cliquez sur *"export avancé"*.

**Télécharger un export**

À la génération d'un export, un bandeau de notification s'affiche directement dans l'interface pour vous informer que votre export est prêt. Vous pouvez télécharger le fichier immédiatement depuis ce bandeau, sans attendre la réception d'un email.


![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2649125159/a5e9c4cd9572878a20738ece9bc8/Capture+d%E2%80%99e%CC%81cran+2026-09-03+a%CC%80+17_30_55.png?expires=1788674400&signature=e82895cad3a950ac349cbac4e8eae365567d7439b2ad4275946af1eadd510f69&req=diYjH8h8mIBaUPMW3nq%2BgeJEViU%2BJLirtCk08V7QswppJ6%2BBuxn3SikOR5KB%0AZzpsOhUG0gINfOZ7tQxu8nKGEO0%3D%0A)

Un email de notification vous est également envoyé pour vous informer de la disponibilité de l'export.

**Retrouver vos exports dans les notifications**

Une section *"Export"* est disponible dans votre centre de notifications. Elle vous permet de consulter vos exports récents et de les télécharger directement depuis cet espace.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2434423622/9e5b6b1cf36e7ee934d0686199cf/4.png?expires=1788674400&signature=41b017577fea5ec54ca67aea2528b9b67d4e4e87473c2e27f36eba82277afdb6&req=diQkEs18noddW%2FMW3nq%2BgeuZra6grUGNOZxgdUkq6r%2FV512lVgCeoHpYBuuQ%0AMw5xzXyFxxBKp8bCUTSM96qbhKc%3D%0A)

### **Gérer l'historique de vos exports**

L'ensemble de vos exports est accessible depuis *"Réglages"* > *"Données"* > *"Export de données"*. Depuis cette section, vous pouvez :

- Renommer un export.
- Relancer un export existant.
- Télécharger un export précédemment généré.
