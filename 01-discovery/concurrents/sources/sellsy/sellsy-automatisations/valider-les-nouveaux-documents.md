# Valider les nouveaux documents

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1829063011/2e1927e2cd8a5c70f452e2739a58/FAQ-Bannie-CC-80reAcademy-2-2B-282-29.png?expires=1788635700&signature=268910af128641bdf1c390af43ea138dbe0f0e02971953edd32ac12c181c4d67&req=dSglH8l4noFeWPMW1HO4zajyCMECZL5R7GSQj1Q%2FTaPBuNfep7c1BL8wPMCb%0AlWED1gcufczC344qvZU%3D%0A)

### **Explication de l’automatisation**

L’automatisation ***"Valider les nouveaux documents"**** *permet de générer une tâche de validation dès qu’un document (devis, factures, bons de livraison, bons de commande) est créé dans Sellsy.

Voici comment cela fonctionne étape par étape :


​**Déclencheur (le point de départ)**

L’automatisation se déclenche **dès qu’un docuement est créé** dans Sellsy, quel que soit son mode de création.

**Action automatique**

Dès que cette condition est remplie, Sellsy Automatisations crée automatiquement **une tâche de validation** associée au document.  

Par exemple :

- Tâche : *« Vérifier le devis avant envoi »*
- Tâche : *« Valider les tarifs et conditions »*
- Tâche : *« Contrôler les lignes et montants »*

En résumé, cette automatisation vous permet d’instaurer un processus de validation fiable et rapide pour tous vos documents. 

___________________________________________________________

### **Activation de l’automatisation :**

1- Accédez à la section *Automatisations* depuis le menu principal de Sellsy.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1829064801/502ef9d56f85087ebe227c005b39/menu.png?expires=1788635700&signature=006bef7e778c026fba9b84fbb45ba020d59c3b0eb102176433c4696af4d38e05&req=dSglH8l4mYlfWPMW1HO4zYQKtpvfEWZ%2FBz%2BBwoK%2F8HICZ2mFFCX4ItNsrjmZ%0AZh62uDdYzOudfyzFS8Y%3D%0A)

2- En cliquant sur *“Explorez les modèles"; *vous accédez à notre **bibliothèque de modèles préconfigurés**.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1829065274/3f56e7ccc7d6fc23e343a31a3d05/Menu+mode%CC%80les.png?expires=1788635700&signature=2b59b070060d6ae48c273f14e7da9df0c621b6aa748d35101264986639edc9c5&req=dSglH8l4mINYXfMW1HO4zY0HROZEG%2BS1CYAnmtSO42D7f56cgyGynuq9IPDx%0AEwvtnSEthA7EEpOE4N0%3D%0A)

3- Choisissez le modèle nommé **“Valider les nouveaux documents”** et cliquez sur *“Utiliser le modèle”.*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2401805229/5817338ec015f2f47b74bd32866f/1.png?expires=1788635700&signature=a23e50268a91928cf8d33cbd99284d75e41ede2ce5269b6eafd2eb5521ca6d30&req=diQnF8F%2BmINdUPMW1HO4zZPZZeTq5zjpXdHKZMn%2FQmlYIbPJcoMylcID3Yn%2F%0A%2FKyXf4VdPdyG4TFMi2Y%3D%0A)

Cliquez sur *“Suivant : Configurer 2 étapes”* pour personnaliser le modèle selon vos besoins.

### **Configuration du modèle**

**1- Sélectionnez le type de document sur lequel vous souhaitez activer l'automatisation:** 

- Devis
- Factures
- Bons de livraison
- Bons de commande

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2401823569/5ef6e97a04af8bd74221b3a696ff/3.png?expires=1788635700&signature=b882c71f577f27de9055ff310d0f1f4014bfc5f232b675f1dfbde6a97b56549e&req=diQnF8F8noRZUPMW1HO4zXg2zwFOhbSt31iWrwZJ0YtDiWVGbtTpZ2WQJBoA%0AEzybV0qGxn9ivByLL%2Fs%3D%0A)

**Ajouter une condition supplémentaire (optionnel)**

Vous pouvez affiner le déclenchement de cette automatisation en ajoutant une condition supplémentaire, notamment sur un champ personnalisé configuré dans votre compte Sellsy.

L’automatisation se déclenche lorsqu’un document correspondant aux types sélectionnés est créé dans Sellsy, et uniquement si la condition ajoutée est respectée.

Exemple : l’automatisation s’exécutera uniquement pour les documents dont la date est inférieure au 19/05/2026.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2401833892/71263d9b07c2a9a4f5f70e9f718a/config+condition.png?expires=1788635700&signature=fa07448210052abe4d1a188df25c4e3eb2df344b01240c70fdc351c5e2e1d18b&req=diQnF8F9nolWW%2FMW1HO4zRTWqe9OOK7zwGi84m6Y7ZX9XDwKcqKI%2F%2FuBUg%2Bt%0AB%2BSew1Lc3wIo%2BBhpMt0%3D%0A)

**2-Définissez les détails de la tâche à créer automatiquement** :

- Titre de la tâche
- Description de la tâche
- Label
- Date et heure
- Responsable
- Autres collaborateurs
- Priorité
- Notification de rappel
- Rappel par email

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2401822491/7f20bbd7bb26696ead6af9a647c5/last.png?expires=1788635700&signature=e48aca5b0f282e36f62d39bb05e1ebe6fcb05396fdb2f3edc832de54fada6254&req=diQnF8F8n4VWWPMW1HO4za9Lt2zuu72Vy1yTJs6gZ4hhEyK%2B2hN%2BHs2akKon%0Abw6QKXh3IKk%2FxRGaa9w%3D%0A)

> **Bon à savoir** **:** pour recevoir une notification (dans Sellsy ou par email) dès la création d'une tâche, il est nécessaire d'avoir correctement paramétré vos notifications dans Sellsy : 
> 1. Rendez-vous dans *"Réglages"* > *"Mon profil"* > *"Notifications emails"* > *"Tâches"*.
> 2. Dans le champ *"Objets"*, sélectionnez *"les miens + ceux partagés avec moi"*.
> 3. Cochez l'option *"création"*.
> Pour en savoir plus sur les notifications, vous pouvez consulter [cet article](https://help.sellsy.com/fr/articles/5913509-notifications-fonctionnement-et-reglages). 

___________________________________________________________

### **Finalisation**

Une fois la configuration terminée, cliquez sur ***“Activer l’automatisation”*** en bas à droite de l’écran.

Votre automatisation est maintenant opérationnelle : **à chaque création de document, Sellsy Automatisations créera une tâche de validation associée.**

Si vous souhaitez **renommer ou supprimer cette automatisation**, consultez l’article **[Configurer et activer une automatisation dans Sellsy](https://help.sellsy.com/fr/articles/12636991-configurer-et-activer-une-automatisation-dans-sellsy)** pour connaître la marche à suivre.
