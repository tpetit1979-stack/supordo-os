# Assurer un suivi continu de vos opportunités

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1822072950/6b1b9542c24756659090769c0f70/FAQ-Bannie-CC-80reAcademy-2-2B-282-29.png?expires=1788635700&signature=5f25df025d31efb562a52217bbcb00d581395529ed1bd53f81b7cff43a40c424&req=dSglFMl5n4haWfMW1HO4zXZUikbmKR6ZFaZE%2BaNjRtR77D8mbYC3OijOSnb3%0A2C65nvMbcYF7zcH7id8%3D%0A)

### Explication de l’automatisation

L’automatisation "Assurer un suivi continu de vos opportunités” permet de générer automatiquement une tâche de suivi dès qu’une opportunité arrive dans une étape précise du pipeline.

Cette automatisation garantit qu’aucune opportunité ne reste sans action, en facilitant la relance et le suivi régulier de vos prospects. 

Voici comment cela fonctionne étape par étape :

**Déclencheur (le point de départ)**

L’automatisation se déclenche dès qu’une opportunité atteint l’étape définie dans votre pipeline commercial ; par exemple :

- "Premier contact"
- “Devis envoyé”
- “Négociation en cours”

**Action automatique**

Dès que cette condition est remplie, Sellsy Automatisations crée automatiquement une tâche de suivi liée à cette opportunité.

Par exemple :

- Si une opportunité atteint l’étape "Devis envoyé", une tâche “Relancer le client dans 3 jours” peut être créée.
- Si elle passe à l’étape *Négociation en cours*, une tâche “Préparer l’appel de suivi” peut être générée.

En résumé, cette automatisation vous permet de **structurer efficacement votre suivi commercial**, tout en garantissant une réactivité optimale pour chaque opportunité tout au long du pipeline commercial.

### **Activation de l’automatisation :**

1- Accédez à la section *Automatisations* depuis le menu principal de Sellsy.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1822133526/cb290513c4506a4c0c1fc2d79930/menu.png?expires=1788635700&signature=90d6c8a2b41620bce353de21b45b7946e2ef32951a2ed6c6c7dea8b9afa26930&req=dSglFMh9noRdX%2FMW1HO4zfvpemZ9hoCTZOkS84NbTwnEP4jHEsvJLGKzwPqX%0AWjfBoecJn196vgMBsxI%3D%0A)

2- En cliquant sur *“Explorez les modèles"; *vous accédez à notre **bibliothèque de modèles préconfigurés**.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2057161119/c205f4893fe75320db5667a9e2e6/etape+0.png?expires=1788635700&signature=80b464544dd110031b3d0161e70ae86b4fc3174bf3e32b91055d2d4499ab7495&req=diAiEch4nIBeUPMW1HO4zdRqUWcDKtHn4Q%2FJND%2FneUoIXfp3RPXQ7794Ez8d%0AE7xZCF9ESGEUt34Ucsk%3D%0A)

3- Choisissez le modèle nommé “Assurer un suivi continu de vos opportunités” et cliquez sur *“Utiliser le modèle”.*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2057166350/2655537c4db8f9178d9562a8d10b/etape+0+copie.png?expires=1788635700&signature=3c9e0f0a085e5c16011fbadcb5b4e6220daed7e38a41ce00026658eb3f5da868&req=diAiEch4m4JaWfMW1HO4zfYBVU7P%2B438s7OFmuI1qjxObLKXr017txopXVh9%0AbpyntEDOjySpW3RyKZg%3D%0A)

Cliquez sur *“Suivant : Configurer 2 étapes”* pour personnaliser le modèle selon vos besoins.

### **Configuration du modèle**

**1- Choisissez le pipeline** sur lequel vous souhaitez activer l’automatisation.

Ensuite, sélectionnez **une étape d’opportunité** dans le pipeline choisi.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2401571160/8ed4dee206457e0cafa7a7f6f5e6/Capture+d%E2%80%99e%CC%81cran+2026-05-19+a%CC%80+14_55_52.png?expires=1788635700&signature=81ce63c7dc3915a3cda400ba500b318e4fa4803d5f767b61f3939f2569445d95&req=diQnF8x5nIBZWfMW1HO4zQNOkSS2Lnh4JIKPDClR7vmVVmOCnJGVP7j%2FpSEd%0AE0%2Fc6cf6cw5t80ogtDs%3D%0A)

**Ajouter une condition supplémentaire (optionnel) :**

Vous pouvez affiner le déclenchement de cette automatisation en ajoutant une condition supplémentaire, notamment sur un champ personnalisé configuré dans votre compte Sellsy.

L’automatisation se déclenche lorsqu’une opportunité correspondant aux statuts sélectionnés atteint l’étape définie dans votre pipeline commercial, et uniquement si la condition ajoutée est respectée.

Exemple : l’automatisation s’exécutera uniquement pour les opportunités dont la date est inférieure au 19/05/2026.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2401657836/8f9f3124ff0c778218b8d6b13d2b/Capture+d%E2%80%99e%CC%81cran+2026-05-19+a%CC%80+15_14_45.png?expires=1788635700&signature=05b91b55d9f8a54c352c6f64c2acc727230a093c34f6e33ac87708e8d15792c2&req=diQnF897molcX%2FMW1HO4zWLDcOBDfleDS1J8jD2kQJ6nYUsbZdsC3Ghs071N%0Agb7KjQYZpn%2BiU4A0IR0%3D%0A)


​**2- Définissez les détails de la tâche à créer automatiquement** :

- Titre de la tâche
- Description de la tâche
- Label
- Date et heure
- Responsable
- Autres collaborateurs
- Priorité
- Notification de rappel
- Rappel par email

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2204309097/bddba341ea36144d4985a8151661/notif.png?expires=1788635700&signature=93fa83418814ea15ed4385652ea934c97e8cba4d594231a37d4e4555d9f8a5c5&req=diInEsp%2BlIFWXvMW1HO4zXi5pxUP3JXm%2BjiW0lF0WzMYIQUWAawJQyXjfguH%0AwU7maCfbiMx%2BUfWnWBg%3D%0A)

> **Bon à savoir** **:** pour recevoir une notification (dans Sellsy ou par email) dès la création d'une tâche, il est nécessaire d'avoir correctement paramétré vos notifications dans Sellsy :
> 1. Rendez-vous dans *"Réglages"* > *"Mon profil"* > *"Notifications emails"* > *"Tâches"*.
> 2. Dans le champ *"Objets"*, sélectionnez *"les miens + ceux partagés avec moi"*.
> 3. Cochez l'option *"création"*.
> Pour en savoir plus sur les notifications, vous pouvez consulter [cet article](https://help.sellsy.com/fr/articles/5913509-notifications-fonctionnement-et-reglages).

### Finalisation

Une fois vos paramètres configurés, cliquez simplement sur **“Activer l’automatisation”** en bas à droite de l'écran.

Votre automatisation est maintenant opérationnelle :
chaque fois qu’une opportunité atteindra l’étape définie, **Sellsy créera automatiquement une tâche de suivi associée.**

Si vous souhaitez **renommer ou supprimer cette automatisation**, consultez l’article **[Configurer et activer une automatisation dans Sellsy](https://help.sellsy.com/fr/articles/12636991-configurer-et-activer-une-automatisation-dans-sellsy)** pour connaître la marche à suivre.
