# Modifier le nombre de décimales dans un document

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261845562/1aebcaf2bc3bf45f5a5274a1c409/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=b63ae491942798ed876fff74bac0b702d3de9c3525753a15ea630a243b33de8e&req=dSIhF8F6mIRZW%2FMW1HO4zUN740%2BHBypTS8UOcycXcxO6J3mycOjTkqJ7k9wo%0Adw52BJrq%2BzMKHxzP3UY%3D%0A)

3 choix pour les décimales dans Sellsy :

- Définir le nombre de décimales pour l'entièreté de l’application,
- Définir le nombre de décimales pour les quantités,
- Définir le nombre de décimales pour la colonne Coût unitaire.

> **Bon à savoir : **ces trois précisions sont indépendantes les unes des autres.

___________________________________________________________

### **Définir le nombre de décimales pour l'entièreté de l’application**

La précision à l'affichage va vous permettre de modifier le nombre de décimales sur l'ensemble de l'application, c'est essentiellement utile si vous utilisez une devise qui a 0 ou 3 décimales.

Pour modifier les décimales sur **l’ensemble de l’application**, rendez-vous dans *“Menu”, “Réglages”,* puis cliquez sur *“Format de données”.*

 Paramétrez vos décimales dans l’espace dédié aux devises et formats monétaires.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445891744/6ba846d1fe04f0e04b6132e6/5eoX89z9rIcrVIgSTdyntkSrucwewYrhIF5TBc-UUKR-jGbKplKmXU7kWerycqWe56CHRPEv_RsHn9ZmoWkW790Bia6dLin0eA7THTW0dour_3-8tZqdqE6WRv8GtQvxCBoha_NH?expires=1788635700&signature=2f8b517cc332d42774e58c09846985048660bc2beed349f6eb9a01fbcd69ae09&req=cCQiHsB%2FmoVbFb4f3HP0gCjWmWhP3GXYS70sV6xqXetaMu33VsoYYnN50ZN5%0AVwD53vcfcL3ocwCy4w%3D%3D%0A)

### **Définir le nombre de décimales pour les quantités**

Le nombre de décimales **pour les quantités **est important si vous parlez en Kg par exemple. Cela vous sera utile dans le catalogue lors de la saisie des produits et dans le formulaire de création de documents.

Pour modifier le nombre de décimales pour les quantités, rendez-vous sur *“Menu” > “Module Sellsy” > “Facturation”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445891754/7521d8924456ee56ccc43918/oktxgZl39iw249HUCVJiqgMPfB2J_XZPbnsZcD1B9JBsL09ddVDlH55JI1Za8kXwrlK7X33YE6y0_cKwCugEaLZp3GQT1ED2rFIoC205tCeGc8jR7iiRQEIRrsUCMQezjCEqqxto?expires=1788635700&signature=2d9674031c38935706096b687cf0f3842a52129c1001e9981d0ff839342ab336&req=cCQiHsB%2FmoRbFb4f3HP0gCnfZNFGf91ourTV%2BQHt67bl9n0%2F6mffeIcMI7%2Bt%0A3PGvWj1JpgXIt4NYTA%3D%3D%0A)

Cliquez sur l’onglet *“Affichage”* puis modifiez vos préférences dans la partie *“précision des colonnes de documents”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445891765/2d71f4ec56ed8f9a15ac47a4/88gyGDsS1UDPBWxHRAYCG5kSEiE1AlT0oMKaWWEeE6c2Jad-W9iSuNejkQ6P7XVCQwSUs_JyPTulRR0oOkTYcepXIEATC2yH6HehYaLi5O1-opBPURTmn56eG5VRS5lt1Fz22H5q?expires=1788635700&signature=7096f9840f6e38f7d3b6f5ca61a7a501617da372dc8740f2200ebbe8579f4c07&req=cCQiHsB%2FmodaFb4f3HP0gDO6d9PU9J%2F5IbTZtLjVLz0J5UvxHlVh0yG9IVzQ%0A7J6NSyZV5JuTukfcyA%3D%3D%0A)

### **Définir le nombre de décimales pour la colonne Coût unitaire**

Enfin, le nombre de décimales** pour le coût unitaire** peut être fortement utilisé dans votre entreprise. Comme les quantités, vous le retrouverez dans le catalogue et dans le formulaire de création des documents.

Pour modifier le nombre de décimales pour la colonne coût unitaire, rendez-vous dans *“Menu” > ”Réglages” > “Unités”.*

Modifiez vos préférences dans l’espace “Précision de la colonne coût unitaire”.
