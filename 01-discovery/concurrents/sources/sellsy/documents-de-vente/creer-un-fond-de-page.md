# Créer un fond de page

### **Principe du fond de page**

Sellsy vous donne la possibilité d'ajouter un fond de page en PDF sur vos documents de vente.

Cette option vous permet de personnaliser vos documents Sellsy aux couleurs de votre entreprise. Le principe est simple : les informations Sellsy (contenu du devis, de la facture, etc.) viennent se superposer à votre fond de page.

### **Créer un fond de page**

Vous pouvez créer un fond de page avec tout logiciel de mise en page, par exemple :

- Microsoft Word
- Adobe Illustrator
- Adobe Photoshop
- Ou tout autre logiciel de création graphique

 Pour garantir un rendu optimal, respectez les contraintes suivantes :

**Format du document :**

- Votre document doit être strictement au format **A4** ou **Letter** selon le réglage de l'apparence que vous modifiez

**Poids du fichier :**

- Le poids de votre fichier doit être le plus léger possible
- Pensez que ce poids s'ajoute sur toutes les pages de vos documents
- **Idéalement 1 Mo maximum** pour éviter de créer des documents trop lourds

**Qualité des visuels :**

- **Privilégiez les illustrations vectorielles** aux images bitmap (plus lourdes)
- Si vous choisissez un format bitmap (via Photoshop par exemple), enregistrez votre document à **150 dpi** pour un bon rapport poids/qualité d'impression

### **Ajouter le fond de page dans Sellsy**

Une fois votre fond de page créé, suivez ces étapes pour l'intégrer :

**Étape 1 : Accéder aux paramètres**

Rendez-vous dans "*Menu*" > "*Réglages*" > "*Module Sellsy*" > "*Facturation*"

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445887443/eecbce634affdd945cd6616b/EAr7QDr8fYwwYh165CGXghzkW_j4Uzp-ryxgpuXP0IjKYeNOD4t8cr9E8cjsqWNpan6428_GFI9SGNO9MsX4ncGdyYYeaZ6KUA7VRpKda3yv5TZ04FlHE8O81KKGp8qCcE-P-H6t?expires=1788635700&signature=c7e637314f21e5bdd9910ac2af064abcaff85327fc6da5f9a2e357567c79c936&req=cCQiHsF5mYVcFb4f3HP0gJV6xh4ynifkvxioEiBuL1nM1eEpTKSUyvkxkYOV%0A1qaEAblGUCWtWetuTQ%3D%3D%0A)

**Étape 2 : Modifier ou créer une apparence**

Cliquez sur l’onglet *“Apparence”* puis :

- Pour une nouvelle apparence : cliquez sur "*Ajouter une apparence*"
- Pour une apparence existante : cliquez sur "*Modifier*"

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445887452/bf040142d547a109e9252ccd/zkp_oVr-C-wNGkFKYJ1YfJIDHjuBGTD8mtPA7k2TNH3nFNL_sdaN9zZsy-i33aUyCuQxlzmolm0A6iVYGFeiF4OkNfo376AGTKzfg1IZ-6vu1zPCudoeNheSO5EEFeZlv0nDaChZ?expires=1788635700&signature=cf5d216444f12c97fc830f442a99aba9e7820199889ab6693e274933610168d4&req=cCQiHsF5mYRdFb4f3HP0gEQR2EfhNTocDEBVSQQq8vW9NiMmhRhfS2hSBrrY%0AY%2F2CibuDD3Fu6oEdIw%3D%3D%0A)

**Étape 3 : Télécharger le fond de page**

1. Cliquez sur l'onglet "*Fond de page*"
2. Téléchargez votre fichier de fond de page

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445887465/95d84a6777d872061452e540/PLaBWa-iECfve4DJi2qihf4dfnL3l0L3jZSXw4c57rE1pX4BIHHuuxVy4xk9wbUc4e0Aza6d-OPcd9qCknEQ82JjD-xP8f4tZuWNhWFRJqwJFPclHajspzeOeot1qdteixRt6N_p?expires=1788635700&signature=f4673705aa00d5156aaa218226232bf2aa2171ee288021721035e77e38a291bf&req=cCQiHsF5mYdaFb4f3HP0gGg3bOvubNeEGanvWoDM2qZLoeuAka9HBtBMUzVI%0AMA%2F9n6xVNRvZXETE4A%3D%3D%0A)

**Étape 4 : Enregistrer**

Enregistrez votre apparence en cliquant sur "*Enregistrer*" tout en bas de votre page.

En choisissant cette apparence lors de la création d'un document, votre fond de page sera automatiquement ajouté.

Toutes les informations du document (produits, montants, coordonnées, etc.) se superposeront à votre design personnalisé, créant ainsi un document professionnel et conforme à votre identité visuelle.
