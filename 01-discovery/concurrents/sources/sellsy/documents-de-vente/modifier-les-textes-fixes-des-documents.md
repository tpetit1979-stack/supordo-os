# Modifier les textes fixes des documents

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261846723/a82edaf7c6d814eafcd2412047ac/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=39e6c9b8fd2c687570324e3983a3d9d95b5090ef4b758c1f5e5c1aed4b010fb7&req=dSIhF8F6m4ZdWvMW1HO4zUOaPVdLLeb02QvjTurKCsOXanTAMxXWlI5cierR%0AhDETLXe7l7OY%2FhElUw8%3D%0A)

Les documents Sellsy comportent un certain nombre de données fixes comme :

- les intitulés de colonnes,
- les intitulés de diverses mentions du document.

Ces données sont modifiables grâce aux [apparences de documents](https://help.sellsy.com/hc/gestion-de-l-apparence-des-documents/how-do-i-customize-the-design-and-layout-of-a-document).

Cette fonctionnalité vous permet d'adapter les textes à votre activité ou encore de créer une traduction dans une langue non disponible dans Sellsy.

> **Attention : **la modification ne s'appliquera pas aux documents existants, sauf si vous les enregistrez à nouveau.

Dans l'aperçu du document qui s'affiche, les champs sont tous éditables :

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445888727/5dfa8c1abca8477fcbf9469f/g1M2BaibTetuPGy9-EreIjchWvFdb26Q5RgSjOQTTu-JHWsZ9MZh8yxvYy3m8Sqxtrmy_wb-mohpxlf7q_JBCD4P43AUKx0ud96cmEZTCkc9Lfenavx4yYrZzmByyOjV5adsa-pn?expires=1788635700&signature=cd3472b971cbc3e0972012aed82e5971bf6fa0b9e9b8d4cea186ef2454733da4&req=cCQiHsF2moNYFb4f3HP0gJ3jldZHAliFF%2F7PM3WKKWN4GYaRN8l3SLYIC9c3%0AW0FJpgL8Yq1FKs4SbA%3D%3D%0A)

> **Bon à savoir : **en mode apparence, toutes les mentions possibles sont affichées, même si vous ne les utilisez pas dans votre compte.
