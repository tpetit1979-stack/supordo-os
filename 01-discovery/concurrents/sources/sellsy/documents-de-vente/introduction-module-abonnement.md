# Introduction : module abonnement

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261909384/d4e0416ce9455f46e91d76049767/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=3a99f1e4e73f638a753facc3e630dbaa9e7d549c5637e60774da076185ab59dc&req=dSIhF8B%2BlIJXXfMW1HO4zZwUNPLwYcefGkFKjJUKn%2BAj8iyrA6kpt3b7%2FuHl%0AeIu0fiIN7M5BRAkkS6E%3D%0A)

Le module de gestion des abonnements vous permet de gérer facilement vos prestations d'abonnement.

Le principe est simple :

- Création d'un modèle de document,
- Paramétrage des données d'abonnement (durée, produits...),
- Choix du mode d'envoi et activation.

Le module vous apporte une grande souplesse dans la gestion de l'échéancier et vous permet de modifier en bloc vos factures d'abonnement, par exemple en cas de changement de tarifs.
