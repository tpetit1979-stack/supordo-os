# Changer l'intitulé d'un document

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261850902/bde2ce9e3a1edad65962a2fa7bc3/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=c867fe715e07e1a76061ae7b759ad4e1a1c341213e523f2ec88e9a4d98a2d714&req=dSIhF8F7nYhfW%2FMW1HO4zddDOdEiAN15BeARFKraOwCs%2BTNSSOYmqvzuBkgJ%0ARKSH4s8xyxExzH9T0Y8%3D%0A)

Selon votre pays, le titre des documents n’est pas toujours pertinents.

Par exemple, un Avoir en France s'appelle une Note de crédit en Belgique. De même dans les pays anglo-saxons, un devis peut s'appeler Estimate ou Quote selon les entreprises.

Pour changer l'intitulé d'un document, il vous faudra **créer ou modifier une apparence de document,** que vous pourrez choisir lors de l’édition d’un document. 

Voici[ notre guide ](https://help.sellsy.com/hc/gestion-de-l-apparence-des-documents/how-do-i-customize-the-design-and-layout-of-a-document)pour créer une apparence de document.

Dans la page de création de l'apparence, entrez la valeur souhaitée dans le champ *“Nom du document”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445811133/00e3a239d9463179e5373af2/dIZvBwkN5kRaK3kb0pcHv93PnWYVCpNPGFEWTWiSpOYtZBBmPF5OzLjgnruzmQpwxqZkZCMlRSR6fjrhA-u6uTAda9bHTNOydWhH8PDChMpO3vL_cSc4C2_WXMoLiWOJlGKjCI45?expires=1788635700&signature=03336dcfacc79f7a303f55ca53fdf32092119aae07718d263ebdb2f24c013e60&req=cCQiHsh%2FnIJcFb4f3HP0gJ3Uqr4It%2B7Zocp7C%2Fm5DSh%2FLPdk823IzFyGqlY0%0A35B35Y4OdUZ283xSiQ%3D%3D%0A)

Désormais, tous les documents utilisant cette apparence porteront l’intitulé que vous avez choisi.
