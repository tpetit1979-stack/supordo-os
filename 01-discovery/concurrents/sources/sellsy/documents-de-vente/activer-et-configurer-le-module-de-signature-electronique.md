# Activer et configurer le module de signature électronique

> **Bon à savoir :** seul un administrateur dispose des droits pour réaliser ces actions.

___________________________________________________________

### Activation du module

Pour activer le module de signature électronique, rendez-vous dans "*Menu" > "Réglages" > "Modules Sellsy"* et cliquez sur “Ajouter des modules”. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444870758/f7cecac60fe16d4b4a76f27e/PyTKaXHJAmEo4BWH0annhuEepCEvgjI2Ec8xWx8NxGh4TjndmZaxFUQJ4qeCkpLKcHhipyn6PEmYBSynPNUzFpgQ2U9G4CIhiw7X488pWV4mub1R17X9T3Ra__jkmK0V3mKvyqCs?expires=1788635700&signature=fe836a1789e11cef2f3b287fb7caabeb963bab0b86c04daa088f35610965f9c7&req=cCQjHs5%2BmoRXFb4f3HP0gPQFSg6BqQYcccn0nJwoX1Sq%2Bp6lp3GtjwwFdF5V%0Arv0NNkoK2dRajnFVoQ%3D%3D%0A)

Recherchez le module "Signature électronique" puis cliquez sur “Activer”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444870765/d2d8d36d799aeb3741a25afe/LY7Y-1XyHz8BPKX4UYOTkfwwGtV30DXUEju9v5MQNqxX9IGLiDCJogRctNxZ3ZPzgO9atraSoJQ0w1eQz3j8EjAp_2RvWheUQqatkGsbPF6LSuAHcmKhylE0d5biDei2FxxRPZer?expires=1788635700&signature=046ff6e197a48f322b42d3cf0d474bae8643448072df065a0dbc93c15ce1f5de&req=cCQjHs5%2BmodaFb4f3HP0gNgsZbwiOVuqzvur%2FCrkpuBAMH9akTeTT5g1iIQM%0AB0vkaGvYhrI6CHywIA%3D%3D%0A)

### Configuration du module

Votre module est maintenant disponible dans l’onglet *“Modules externes”* de vos réglages.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444870779/5a890e50453c884ae695e645/AXUa6TRou1NkGyvUsgXV_5zxJl558hCe3THJP4c7zE2giyUBHFWpmUW0KqikGhHPCKxj3SIghdkDTmK33AUU6aLvaBd2F55H1_58RZuMaJGDZmrGmhDeb97Kgj5RY9fQi-QrS2gX?expires=1788635700&signature=7f1b7e341cb9e00af5e9a27a3616543d8d03f20fa5151903426ce35ac1ad5a2a&req=cCQjHs5%2BmoZWFb4f3HP0gDBle%2BkJV2GjvsNMAVhYveJ%2BF3wCXwKidx%2FOVao6%0ApzBsDQ9qbvJxMf%2BB5Q%3D%3D%0A)

En cliquant sur le module, vous pouvez paramétrer les préférences de vos signatures électroniques. Lorsque vos contacts signent vos documents, un code de vérification est envoyé pour valider la signature. 

Vous pouvez choisir le mode de réception de ce code de validation : par email ou SMS.

De plus, Sellsy vous permet de créer un email de notification qui sera envoyé au client lorsque vous enverrez votre document pour signature électronique. 

Tout comme les modèles d’emails, le contenu est entièrement personnalisable.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444870785/2c8902f291ef7a1a03b277a2/EC5sYaRkXZBarL2hkFCWqoWNaylBrTAQi2rC44MhkPQG6KGPNan_tNQJhrkqDlTPFMas25LWXa_WpPj14arjp0KtQlNiwtvYZU-jldtAXJjn1aRwaoi8O2Co0W6-7vjKHN3N8OND?expires=1788635700&signature=91ce44304c5577bd5eb598ac97caa2ba8a30e05dd3b02d3b117a22fef313a3fa&req=cCQjHs5%2BmolaFb4f3HP0gDDwf8nbTMjOC0DY2AAw6XoLH8ZyqRMSEdeh%2BDgg%0Af5A%2FJlA3ns%2BZKacrkQ%3D%3D%0A)

Cliquez sur *"enregistrer"* pour sauvegarder vos personnalisations.
