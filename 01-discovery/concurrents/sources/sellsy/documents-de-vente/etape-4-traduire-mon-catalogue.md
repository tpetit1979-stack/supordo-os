# Étape 4 : traduire mon catalogue

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261854185/c03ab5515d5941e53d2e50cb31a5/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=2a79948ab6407ea4f0c6b039d0f78c8ea7ecc55fe7d99348f395d91aa6886515&req=dSIhF8F7mYBXXPMW1HO4zbFCoHEcQbY8BwZyxnLYU5ujydzSP6%2FrsF3%2F7bXQ%0AE0z8RK2GQ1z0kDI4fWQ%3D%0A)

Il est maintenant temps de traduire votre catalogue (en anglais dans notre exemple).

Cette étape est essentielle pour que vos produits, services et toutes les informations associées apparaissent dans la langue de vos clients sur les documents de vente.

___________________________________________________________

### **Traduire les produits et services**

Pour traduire le nom commercial et la description de vos produits ou services :

1. Rendez-vous sur la fiche d'un produit ou service
2. Accédez à l'onglet "*Infos*"
3. Cliquez sur l'onglet de votre langue cible (par exemple "*Anglais*")
4. Remplissez manuellement :
- La traduction du nom commercial
- La traduction de la description

Répétez cette opération pour chaque produit et service de votre catalogue.

### **Traduire les unités**

Pour traduire vos unités de mesure (heures, jours, mètres carrés, etc.) :

1. Rendez-vous dans "*Menu*" > "*Réglages*" > "*Catalogues*" > "*Unités*"
2. Dans "*Paramétrage des unités*", cliquez sur "*Modifier*"
3. Cliquez sur l'onglet de votre langue (par exemple "*Anglais*")
4. Remplissez manuellement la traduction de vos unités

Cette traduction garantit que les unités apparaissent correctement sur vos documents internationaux.

### **Traduire les tarifs et taxes**

Pour traduire vos taxes (TVA, taxes spécifiques, etc.) :

1. Rendez-vous dans "*Menu*" > "*Réglages*" > "*Catalogue*" > "*Tarifs et taxes*"
2. Dans "*Taxes*", cliquez sur "*Modifier*"
3. Cliquez sur l'onglet de votre langue (par exemple "*Anglais*")
4. Remplissez manuellement la traduction de vos taxes

Les libellés de taxes traduits apparaîtront clairement sur vos documents pour vos clients internationaux.

### **Traduire les règlements**

Pour traduire les informations de paiement :

Rendez-vous dans "*Menu*" > "*Réglages*" > "*Catalogue*" > "*Règlements*"

Vous avez la possibilité de modifier plusieurs champs :

- **Moyens de paiement : **traduisez les modes de règlement (chèque, virement, carte bancaire, etc.)
- **Libellés de chèque : **traduisez les instructions pour les paiements par chèque
- **Délais de paiement : **traduisez les conditions de paiement (immédiat, 30 jours, etc.)

Pour chacun de ces éléments :

1. Cliquez sur le bouton "*Modifier*" disponible en face du champ concerné
2. Cliquez sur l'onglet de votre langue (par exemple "*Anglais*")
3. Remplissez manuellement la traduction

- Pour** traduire vos transporteurs et livraisons** : rendez-vous dans *Menu > Réglages > Catalogue > Transporteurs et livraisons*. Vous avez la possibilité de modifier plusieurs champs : 
- les transporteurs par défaut,
- les emballages par défaut.
En cliquant sur l'un des 2 boutons "Modifier" disponible en face de chaque champ, puis sur l’onglet "Anglais", vous avez la possibilité de remplir manuellement la traduction de ces champs.

### **Traduire les transporteurs et livraisons**

Pour traduire les informations de livraison :

Rendez-vous dans "*Menu*" > "*Réglages*" > "*Catalogue*" > "*Transporteurs et livraisons*"

Vous avez la possibilité de modifier plusieurs champs : 

- **les transporteurs par défaut, **
- **les emballages par défaut.**

Pour chacun de ces éléments :

1. Cliquez sur le bouton "*Modifier*" disponible en face du champ concerné
2. Cliquez sur l'onglet de votre langue (par exemple "*Anglais*")
3. Remplissez manuellement la traduction
