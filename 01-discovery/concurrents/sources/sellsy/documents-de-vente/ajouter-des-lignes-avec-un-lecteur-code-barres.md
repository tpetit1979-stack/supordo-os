# Ajouter des lignes avec un lecteur code-barres

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261845008/b07012312180f533d0e5ee0bb43b/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=f0c7657f2e7390ecfae1101ff3a342e37a556d6de477b12bf34b5481f04fca81&req=dSIhF8F6mIFfUfMW1HO4zVZdxeQ2RZnzgjf7VwctPtEvXp6d6OQWIGC444we%0AIbHufuXFlXydfD94KZk%3D%0A)

Si vous avez renseigné les codes-barres de vos produits dans votre catalogue, vous pouvez facilement remplir vos documents directement avec une douchette (lecteur de codes-barres).

___________________________________________________________

### **Ajouter un code-barres à un produit**

Pour qu'un produit puisse être ajouté par scan, vous devez d'abord lui attribuer un code-barres.

Pour cela, rendez-vous dans *“Catalogue”* puis *“Liste des produits”.* 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445893884/d8a623bf16edf4d766a71f24/mZKtnk300xc_aOFJ9DTgS5Qk4rN7YZYsU4V3Nk-FaRB0yivZaFKvz5gF_ecLPWjxVG1CIX5SrRwDbCaZMwjz6ZCCBGAoeSfb4F-KHwEMfzsrvokBUvl6i4RmZEbjoV9aJKGg2nDM?expires=1788635700&signature=f4e5c43b86c5a7745a1666f7b23daf7a28d9ba078df8c7223bae55de5e36452a&req=cCQiHsB9lYlbFb4f3HP0gFIxj8EW8qWR4ijyhIWWhgFUuP%2FWNcr5GSefZRFq%0A%2FKvIVhbw4AfJF8ar7A%3D%3D%0A)

Cliquez sur le produit concerné puis sur l’onglet *“Code-barres”* et *“Ajouter un code-barres”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445893922/887dc6966ddac2f048b69940/vQoCiIDzW4LTp2R_v4uJJAkEnSW6J93SITqd0_ZPotEUvI7feRPp8mDeld1OtqNu9IzpmXEkfpO47O-hA5Xc6QdmvG3Z831DE06hKOqOyMs_9QRqAVToWKMSEkeiEVmLxYLn_hyi?expires=1788635700&signature=746165086e9a01ae4ff77f48eed2bbf984ae52af01f44c464bce58cd086f3b42&req=cCQiHsB9lINdFb4f3HP0gJ4t5bzBAeCO5UJLQpSeiHxGlTHm2S16lgVwxcTI%0AHU2ga6pDU5lHils98w%3D%3D%0A)

Une fois que vos produits possèdent un code-barres, il ne vous reste plus qu’à scanner les produits que vous souhaitez ajouter quand vous éditez votre document ou entrez votre code-barres puis appuyez sur "*Entrer*."

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445893939/c9bdb4e8ed6ca9f0a8aecdfd/44df3-lBM70BEA_qtUBAyS5gzVapkl6Wj07XoP9IMcwhqn0AUKPqwUxXroGN0WP4euRivEPMkmziQhA1u4JkKmv1C2XdOyGSLg67HTMpD452VdAjQeGm0DYZU2d7ajxnU7dWkgkQ?expires=1788635700&signature=cbcae5e1aa604ffd144ebbd41fe983484cbdc47c62d55c4b4d7592a1dd409d94&req=cCQiHsB9lIJWFb4f3HP0gGROG42pckWYJlZGEFuhqPSfFyNDG%2FQpMEW2rngK%0AVYhE3XJssPAdkEk5PQ%3D%3D%0A)

Si vous scannez plusieurs fois le même article, les quantités sont ajustées sur la ligne concernée.
