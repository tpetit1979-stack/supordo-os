# Activer le prélèvement automatique pour le règlement des factures d’abonnements (GoCardless)

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2196194215/bf4ec223d58530c3e784105aeacd/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=8f92f6fd33c316299bbb9a7f090d73f80a413e7bcfd59c118ff9c72b6f89d596&req=diEuEMh3mYNeXPMW1HO4zVtDiRDYh3%2BGooeYzF6iQ2DatyvU7FKcfvMXG%2BMH%0AhyrRQfrFY53goTm9p9Q%3D%0A)

Pour activer le module GoCardless, rendez-vous sur *["**Menu" > "Réglages" > "Paiements en ligne"**](https://www.sellsy.com/settings/quickpay)*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2204249659/2a985b18c36abfe7645d3e660fc1/Capture+d%E2%80%99e%CC%81cran+2026-03-26+a%CC%80+15_11_13.png?expires=1788635700&signature=5916699e7d585b5f07dc99ddb24f2a7303901939d7c90993accee893799dfd31&req=diInEst6lIdaUPMW1HO4zT6keCpbuo8rZYsmhpkwma02G7QGJlTd7E5n3hVB%0AdYUfJlnSdgmX36uGqXc%3D%0A)

Activez ensuite le [module GoCardless](https://help.sellsy.com/hc/gestion-des-paiements-client/gerer-vos-prelevements-avec-le-module-gocardless) en cliquant sur *"connecter".*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2204250415/27c1f72a023ce60f41adb6265037/Capture+d%E2%80%99e%CC%81cran+2026-03-26+a%CC%80+15_11_29.png?expires=1788635700&signature=5b500f0e9e3b448789deb0f14cf127e6f0704c1bee89644b9a744f564d3c02a1&req=diInEst7nYVeXPMW1HO4zYsOPr%2FkNZHkhEUJyCa0XkIfjeMa%2Bn0w7X%2BYOCgH%0AMn1VFgH4y8PCsIDkpg0%3D%0A)

> **Bon à savoir :** seul un administrateur dispose des droits pour activer le module. 

Si le module GoCardless est activé, vous retrouvez lors de la création d’un abonnement un encart “prélèvement automatique”.

Afin de pouvoir activer le prélèvement automatique sur les abonnements, vous devez :

- Avoir un client avec un mandat,
- Le modèle doit avoir le module de paiement GoCardless d’activé,
- Le modèle doit avoir le mode de paiement prélèvement d’activé,
- Avoir sélectionné le mode de génération automatique.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445704619/0ace7f25ac74ba3c005dae91/GNyGQYbaF5BuEJvav-6-om6SrI30jVkyyAHbSSpzvrKJIHzQQA1_1gg0YkXmluUcs23ogL_3BLqw5xhxBzyYTOIaTU85jt5ZlIJT71w2ip7EKKVPgI0GhSYZrZw5u7nyk9Tusr5A?expires=1788635700&signature=8e460da86904d690f4db3892dca684fa5dc56db7405abed97fa04b979842d91f&req=cCQiEcl6m4BWFb4f3HP0gOYJJibcV0%2FZPJKN9fXTBBlvtSS3xczIdwTL3GZt%0A4q8Tf4FhS5mcgLYa0g%3D%3D%0A)

Sur la visualisation de votre abonnement, vous pourrez voir si celui-ci utilise le prélèvement automatique et quel mandat est utilisé. Pour accéder à cette page, rendez-vous dans la liste de vos abonnements puis cliquez sur les trois points à droite de votre abonnement et sur *“Voir l’échéancier”.*
