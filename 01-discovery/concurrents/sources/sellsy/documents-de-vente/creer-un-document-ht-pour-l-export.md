### Créer un document HT

Si vous facturez à l'export, vous avez besoin de créer des documents hors taxes.

Pour ce faire, lors de la création de votre document, réglez les TVA à 0 ligne par ligne.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445898464/0f4dbd1c07e3c823a655323f/LXghIhlW8n64ykX--gZwtaDtByx16knQFhk350zlI7x_M7pSykJ9_C2_DmPWwRh24Rsv89gRJqTulqKtCLk5A-CyDXOKLU77smirEpBhnfmeDymH9Dtwvwh5VAPdnNzhw3VbknfL?expires=1788635700&signature=920488bba13f1fff8437fd01f843305d438eeb57399402abcc728bfd12873051&req=cCQiHsB2mYdbFb4f3HP0gDc4hzi3IviTCwrmURChmHKgwPcymY0nJX764E5W%0AOYuKOccjBB0Se0NsCw%3D%3D%0A)

Vous pouvez ensuite masquer la colonne TVA si vous le souhaitez en cliquant sur *“Modifier les préférences du document”* en bas de votre page d’édition. Cliquez sur l’onglet *“Paramètres d’affichage”* puis cochez *“Masquer la colonne TVA”.* 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445898471/122bf192931bcb9552f25524/VFT4m4Hbl7uP1M3Ho-tMyJZsjPSSKg2BA0_G2SlIaLfJA7RjO0L0kJm6Ej6WpaZqtXlHaDHOJ3n4ZYpBQnvCv8riqS3O82u8P7cb_emRpxO_1CtnlD35GdzZ1dIb2jZ-FDuzXnJH?expires=1788635700&signature=5f8e9222f1faaf102f7e8a2c82b5663578434ed614eb2e8f680f0d7b76e3c665&req=cCQiHsB2mYZeFb4f3HP0gNsiLqwaxf7TiHbNIjwZoB51p1b9gc2Oz%2Ba6XXRi%0AsODSvGP7mYAgVIcCyQ%3D%3D%0A)

Ceci fait, si vous utilisez les exports comptables, vous pourrez ajuster le code comptable à gauche de chaque ligne en cliquant sur la roue crantée.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445898486/b506188a3ae913987d4d4c00/5FOL4s7XSRbIQrhoAmCNoMI-Wm2_bMJ-Czr8lSLe__RZ3wCGwK_9k9DjzcU4PcR1Ioc9_RJFX0jVPMxHQ9wpCco-kErmkFTvIYpleC2_eCXJ-kL0MFkDcLLiB8anMSXryN053Rz6?expires=1788635700&signature=72b668751afcaad4d42ea97d75797904a0c4de52da939e88ccd5e5120e2b58a5&req=cCQiHsB2mYlZFb4f3HP0gKaSkYQLNIUH6nV%2FO79t31lYpZfwifYVF04O%2BXj2%0A6k20zec8aijz5SGtmA%3D%3D%0A)

Cela vous permet d'obtenir un document sans aucune mention relative à la TVA.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445898496/241ba90c46686e0529e98d58/3ydnlKjTdA3fZwdOLlmDecAjr8re7Us3Fm3PBj52b3OkMzn4iEynZ2TvZMPTXPuaBVOPHQ31TCA_yDNIwW23pqjB6OfWc2-rbARepWNr2LSiDF7yNybFeZa1xD8J-hkQVdfyRmoE?expires=1788635700&signature=754e218ddd15eae2674faecb802ab1e5d197ce4f903c7f17f8184d9e767b1e33&req=cCQiHsB2mYhZFb4f3HP0gNSxo6IUsDuyaa6WRhA6yQu%2BKYcGmOp6Rocpu2CI%0ASoNHzjXtsYIZiJLO7A%3D%3D%0A)

### **Automatiser ce processus**

Si vous effectuez fréquemment des factures de type export, vous pouvez simplifier et automatiser ce processus grâce aux [catégories tarifaires](https://help.sellsy.com/fr/articles/5866756-comment-utiliser-les-categories-tarifaires).

Les catégories tarifaires vous permettent en effet de définir pour chacun de vos produits :

- un tarif spécifique,
- un taux de TVA (ou non) spécifique,
- des codes comptables spécifiques,
- une apparence de document spécifique.

Une fois définie, vous pouvez associer votre catégorie tarifaire à des clients ou à des documents.
