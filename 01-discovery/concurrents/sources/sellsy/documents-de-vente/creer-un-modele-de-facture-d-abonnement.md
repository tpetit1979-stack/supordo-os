# Créer un modèle de facture d'abonnement

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261909902/af3794c7e8add5bebe28691bda5f/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=1ad40e774530462f18cca2e96c7e2dda7d08ec99fd29ed95bd4102a8e163813e&req=dSIhF8B%2BlIhfW%2FMW1HO4zWJDJawWqqGPKZwP2wbZJH7tu4aoiXfKX0Eq7zi8%0A73Dm1qRKTz%2FinCEXGPo%3D%0A)

Tout comme vos factures classiques, vous pouvez très facilement créer un modèle de factures d'abonnement sur Sellsy.

Les documents modèles vous permettent de créer des documents type que vous pourrez aisément réutiliser, garantissant cohérence et gain de temps dans votre facturation récurrente.

___________________________________________________________

### **Créer un modèle de facture d'abonnement**

**Étape 1 : Accéder à la création**

1. Cliquez sur le menu "*Facturation*"
2. Sélectionnez "*Créer un modèle*"

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2196150449/d393bea77eed2f8e99d9657018c4/elche5PXLOqg5En914aDK2sCIHkqBWoo82IuMx0IoR0T8ExMZ8Pj5zlJ33TFqCQcZMhmTaBD0yeqP4hr1bSskpJLPL2c72gKAK2aJXgRvHR4I7E7p_oh5dIzg1ei905zC0kK2i2q?expires=1788635700&signature=78cf513cdd0caeca36253c64d9c34908263dc5054312f711a4478e5f8bd6c3b6&req=diEuEMh7nYVbUPMW1HO4zTshiGJ30elOfrcyvbVKFXMFgHYUlpeK%2BrkLMNOr%0AzjJKldvKYNWq5NcKcSI%3D%0A)

**Étape 2 : Configurer le modèle**

Choisissez la catégorie tarifaire et l'apparence de votre document comme vous le feriez pour un document normal.

S'agissant d'un modèle, aucune information de client n'est affichée à ce stade.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2196150924/04da318470bec9c7a11b36913925/lzYlSuT_9wu0cxBWR-Y_FVuUunQ0eA4ZyEW729tXFHpehAYMoE91VxZuy73rWdwR8k5uoBihe7vfaNLN6-cPIJqkloLC7aB4XnIbgiEXXco8ts85tZFy7OjzvEZCZ53GpjfvyM29?expires=1788635700&signature=f6b0d6f018bff0bf7370277f1214483f79004bfb0cc263adea3d886b355b7da5&req=diEuEMh7nYhdXfMW1HO4zcSETCln%2Bc6yOXTdixDB22aBQol4xzlik0LC3Ykf%0Ad3elPr%2BCZyEgdUDloNc%3D%0A)

**Étape 3 : Éditer le modèle**

Vous serez ensuite dirigé vers la page d'édition du document, similaire à la création d'un devis ou d'une facture.

___________________________________________________________

### **Utiliser les variables pour les périodes d'abonnement**

Dans le cadre de l'édition d'un modèle de facture d'abonnement, l'utilisation des variables peut vous être fortement utile.

Vous pouvez appliquer des variables dans le champ "*Objet*" du modèle pour faire afficher automatiquement la période facturée sur les factures d'abonnement générées.

### **Cas n°2 : abonnement trimestriel (à terme échu)**

Pour afficher **les dates d’un abonnement trimestriel**, les variables à afficher sont les suivantes :

- Moment de création : 3 ; mois ; numéro du premier jour du mois,
- Moment de création : 3 ; mois ; nom du mois,
- Année du mois précédent,
- Moment de création : 1 ; mois ; numéro du dernier jour du mois,
- Moment de création : 1 ; mois : nom du mois.

Une fois vos variables mises en place, vous pouvez continuer l’édition de votre document comme habituellement.

Une fois votre modèle terminé, cliquez sur *“enregistrer et quitter”.*

Vous pourrez ensuite retrouver votre modèle dans votre menu *“Facturation”* sur *“Liste des modèles”.*
