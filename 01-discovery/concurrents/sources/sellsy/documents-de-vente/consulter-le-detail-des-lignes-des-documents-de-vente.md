### Consulter le détail des documents de vente

Pour consulter le détail des documents de vente, c’est-à-dire la liste des lignes qui composent vos documents de vente, vous pouvez vous rendre dans la rubrique *“Facturation”* et *“Détail des lignes de documents”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/529614920/1d75c695f0e31d0317a25ef7/FzFfVywuWi1e50poB_2qfRiK5GtAwbsesc4kXIuhFKaRyvGUtL6ytAdrK_5LFVUxEAMlf83ErW0V0qbafEmFNaysfkGlrQ0EyoXtR9n1pyVpfVndc5cfVB4YrLbnV2uYx1dSknb_QJpMGycIow?expires=1788635700&signature=7bf102398383f49a8c7c8c8e6b8078905d2b93c368a88c91a31ae41f3264d5fa&req=cSIuEMh6lINfFb4f3HP0gI0YhBrByvelHIng9G6rP52LSZEa3r6%2FhDdS0K96%0A6lce850pP%2BsMC2HfKw%3D%3D%0A)

Dans cette liste, vous trouverez de nombreuses colonnes que vous pouvez décider d’afficher ou non en cliquant sur la roue crantée puis sur *“Gestion des colonnes”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/529614928/2a09aaf9367872b70a50cb1f/hU7IdxNDO9p2bH9xQCXP1QwtcSBYiDmTHGe-cFshL6SZ_2jeObhL51k7-lgpSzHDf5BokcbYlonjbFGvfX7It5oVcOGFtGyDsZt8CAdpigdzVGYlyejam6VrsZ04KopRN7GZggVqup-9xhgdFQ?expires=1788635700&signature=a4acc2a767e9de309756a884cfbb2fe5ba400adefae0f3d77ac12ebb54919887&req=cSIuEMh6lINXFb4f3HP0gO4FdSbd2todEpJnPQxawsM0fOEYudsPGQeXege%2F%0A8HA1vW2ld553VD0lqA%3D%3D%0A)

Vous pouvez également filtrer les lignes de documents par :

- Catégories de produit
- Codes comptables
- Produits / services
- Date de création
- Date de début et de fin de service
- Date du document
- Devise
- Document
- Montant
- Client / prospect
- Propriétaire du document
- Remise
- Référent interne
- Smart tags produit / service / document
- Type de document
- Type de ligne
- Éco taxe
- Champs personnalisés

### Exporter les lignes des documents de vente

Nous vous proposons également d’exporter ces lignes au format CSV pour exploiter les informations dans Excel et générer des statistiques. Cliquez sur *“Actions”* puis sur *“Export CSV”*. Un export en PDF, JSON ou PARQUET est également disponible.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2434534966/99a9cdadb5a074a327580ade66e4/Capture+d%E2%80%99e%CC%81cran+2026-05-28+a%CC%80+17_46_30.png?expires=1788635700&signature=be9d400a3926f9282bd363a98b5d536ebe9c718774b11933a281ab4a4c54b0b5&req=diQkEsx9mYhZX%2FMW1HO4zXn1hcRGyuJu6Z4%2FW%2F1DeqyoQkWCQ4znFSoxc8BG%0APM26XC3zSdiZvovT%2FHw%3D%0A)

Cette fonctionnalité est particulièrement puissante pour générer vos propres statistiques et peut servir à l'élaboration de rapports. 

Exemple : connaitre la quantité de produits ou services présente dans un type de document en particulier (devis, facture, bon de livraison, bon de commande, avoir, proforma). 

> **Bon à savoir :** L'option *"Export avancé"* est disponible sur tous les exports. Elle vous permet d'exporter vos données aux formats JSON ou PARQUET, plus facilement exploitables dans le cadre d'intégrations API sans nécessiter de retraitement.

Pour ce faire, cliquez sur *"export avancé"*. À la génération d'un export, un bandeau de notification s'affiche directement dans l'interface pour vous informer que votre export est prêt. Vous pouvez télécharger le fichier immédiatement depuis ce bandeau, sans attendre la réception d'un email.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2434542453/738d5516d4ccd72d29433584110e/3.png?expires=1788635700&signature=b2947d8c9a8e8c0dbbf07f585a8455a3c9d59a73a4cde2920a37d7a824baa9d9&req=diQkEsx6n4VaWvMW1HO4zZc69xvP1vFrU8z49NQm%2FV%2FpekmVdfv1%2F7ee2zV6%0AbsRW4p2oebsFJiGU7g0%3D%0A)

Un email de notification vous est également envoyé pour vous informer de la disponibilité de l'export.

**Retrouver vos exports dans les notifications**

Une section *"Export"* est disponible dans votre centre de notifications. Elle vous permet de consulter vos exports récents et de les télécharger directement depuis cet espace.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2434542458/a8003dadb7928479466a94f41694/4.png?expires=1788635700&signature=3d416d15eae8b7fd59f5d0af845f12436d0a52572b0f1d7e2d15ae9b163e1667&req=diQkEsx6n4VaUfMW1HO4ze1parneyVmVcmPG4PsPmOsYMMaLo47MgMzWLmUk%0Anj5OZKrDX25WttOSRK0%3D%0A)

**Gérer l'historique de vos exports**

L'ensemble de vos exports est accessible depuis *"Réglages"* > *"Données"* > *"Export de données"*. Depuis cette section, vous pouvez :

- Renommer un export.
- Relancer un export existant.
- Télécharger un export précédemment généré.
