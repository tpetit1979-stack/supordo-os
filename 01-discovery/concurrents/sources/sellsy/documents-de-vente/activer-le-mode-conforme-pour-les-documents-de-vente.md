# Activer le mode conforme pour les documents de vente

### Le mode conforme

L'activation du mode conforme dans Sellsy garantit que vos factures respectent la réglementation française en vigueur. Cette obligation s'inscrit dans le cadre de l'article L.441-9 du Code de commerce, qui impose des règles strictes de transparence, d'intégrité et d'inaltérabilité des documents comptables.


**Garantir l'intégrité de la facturation**

Le mode conforme empêche toute modification ou suppression d'une facture finalisée. Vos documents restent intègres, tracés et infalsifiables, **conformément aux exigences légales en matière de preuve comptable et de lutte contre la fraude**.


**Assurer la traçabilité des opérations**

Toute correction d'une facture passe obligatoirement par la création d'un avoir, **comme l'exige la loi**. Ce fonctionnement évite la disparition de documents comptables et permet un suivi transparent de votre activité.


**Respecter la numérotation légale**

**La législation impose une numérotation continue**, chronologique et non modifiable. Le mode conforme garantit automatiquement cette continuité en empêchant :

- toute modification de numéro
- toute rupture dans la séquence
- toute datation incohérente


**Se protéger en cas de contrôle fiscal**

En cas de contrôle de l'administration, l'utilisation du mode conforme prouve que :

- votre facturation est fiable
- vos données n'ont pas été altérées
- votre logiciel respecte les normes légales


**Anticiper la facturation électronique**

La réforme de la facturation électronique exige que les Plateformes Agrées, comme Sellsy, ainsi que les entreprises, respectent des standards stricts d'inaltérabilité et de traçabilité. **L'activation du mode conforme est indispensable pour être prêt à cette obligation légale**, déjà en cours de déploiement.

___________________________________________________________

### **Mode conforme et facturation électronique (FE)**

> **Attention :** Le mode conforme n'active pas la facturation électronique.

Le mode conforme prépare votre compte et est nécessaire pour émettre des factures électroniques. Il ne remplace cependant pas :

- le mandat PA ;
- la configuration de la facturation électronique ;
- les obligations futures liées à la réforme.

___________________________________________________________

### **Ce que le mode conforme change**

Une fois activé, le mode conforme implique plusieurs restrictions nécessaires à la conformité légale.


​**Création automatique d'un avoir**

Toute modification ou annulation d'une facture finalisée entraîne la création d'un avoir.


​**Numérotation continue et verrouillée**

- Numérotation non modifiable
- Séquence continue sans interruption
- Chronologie obligatoire
- Impossibilité d'émettre une facture datée dans le futur ou avant la dernière facture émise


​**Blocage des modifications après finalisation**

Il devient impossible de :

- modifier, supprimer ou annuler une facture ou un avoir finalisé
- changer leur date ou leur numéro

### **Activer le mode conformité**

Le mode conforme est activé par défaut sur les nouveaux comptes Sellsy. Si votre compte est plus ancien, seul le créateur du compte peut activer cette fonctionnalité.

**Accéder aux réglages de facturation :**

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1873383303/175c4d5914efc06aa008ffedd3d5/d3bbf0cf-2bf5-46ff-b7d1-77455612e809?expires=1788635700&signature=8bf4c01cecdaaf5cdc68a8251e0f7db3d366bee72ffb63ae009bf3490f14f2a5&req=dSggFcp2noJfWvMW1HO4zaJ4hTKO2HodsCuslPUkiRl3YdjUKyug0CQxml5h%0Aq5%2BgjyI50skmBSN5iyw%3D%0A)

1. Ouvrez le menu Sellsy
2. Accédez à *"Réglages"*
3. Sélectionnez *"Modules Sellsy"*
4. Cliquez sur *"Facturation"*

**Ouvrir la section “Conformité”**

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2130584968/13be3f73f34349ab25a6d0d96b93/Re%CC%81glages+-+Compliance+newGold.jpg?expires=1788635700&signature=15ccee8a351c24e287f2352a16efd27764c9f9f14d6d35cfcacac4f6563f8f06&req=diEkFsx2mYhZUfMW1HO4zW1KpvH4qy4xeHgMNWq4LOxpg8yWDrfiU7KwYqAZ%0AisUsu6MwDScyjXlZBAY%3D%0A)

1. Cliquer sur “Activer le mode conforme”
2. Lisez les informations
3. Validez les conditions et enregistrez
​

### **Télécharger votre attestation de conformité**

Si vous facturez des clients particuliers, Sellsy vous permet de télécharger une attestation de conformité du logiciel de caisse, document exigé par l'administration fiscale.
​

**Accéder aux réglages de facturation :**

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1873383301/eaf409d6efce14f9c88fd62c4094/c8960483-bc9d-44c1-b057-e955dd19a345?expires=1788635700&signature=e0a34866eea30434ef2312bc0f26841154b0c9d93ce7e6db47d1f7af3ad5bb12&req=dSggFcp2noJfWPMW1HO4zWu8xs5wrsNvOeOGjcu1HdRb1oAnWnWpqtpRB3MD%0AZTzXZen4%2ByIEBa%2FDU7g%3D%0A)

1. Ouvrez le menu Sellsy
2. Cliquez sur *"Réglages"*
3. Rendez-vous dans *"Modules Sellsy"*
4. Sélectionnez *"Facturation"*

**Ouvrir la section “Conformité" :**

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2130590369/b0919ad0383ae98f4d3805a2f861/image+%2810%29.png?expires=1788635700&signature=50c0213f0f28cef1fdffd2fc72a8f3356235a5a953481bfd6ca588cff6311072&req=diEkFsx3nYJZUPMW1HO4zfG9eIorP26g2uT7D5mF%2BkJ1wJOHmTrgVUQnN3FG%0AZ2AnWieIFogGfa0Z09w%3D%0A)

Cliquez sur *"Télécharger l'attestation". *

Le document sera immédiatement généré et disponible en téléchargement.

> **Attention :** **L'activation du mode conforme est définitive avec la demande d’attestation.** Après sa validation, aucun retour en arrière n'est possible. Ni vous ni Sellsy ne pourrez désactiver cette fonctionnalité. **Cette irréversibilité est imposée par la réglementation** afin de garantir l'inaltérabilité des données.

> **Bon à savoir :** Vous pouvez consulter le [journal de facturation](https://help.sellsy.com/fr/articles/5904114-journal-de-facturation) pour comprendre l'origine d'une erreur ou identifier un blocage. Cette fonctionnalité vous permet de suivre l'historique complet de vos opérations de facturation.
