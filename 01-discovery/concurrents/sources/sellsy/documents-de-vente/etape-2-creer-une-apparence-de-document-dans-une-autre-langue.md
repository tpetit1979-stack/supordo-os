# Étape 2 : créer une apparence de document dans une autre langue

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261853227/8bda6e9c0166b8cb60104f068c7f/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=e0c7eebb880f871164538ccd309eb819b3ba456123a0a57ec4d914f7b2ce79c6&req=dSIhF8F7noNdXvMW1HO4zZtSPyMyeF9HwazTK1vjMMFibJuOCmpoqr2D9AJO%0A3TxbT9kdx36Fdb%2FdBNM%3D%0A)

Créer **une apparence en anglais **(ou dans une autre langue) vous permettra de gagner du temps lors de la création d’un nouveau document.

___________________________________________________________

### **Étape 1 : Accéder aux apparences**

Rendez-vous dans "*Menu*" > "*Réglages*" > "*Module Sellsy*" > "*Facturation*".

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445943296/fb19b93395396d65e228473d/_OT6Bg_UeGOLr571l0WVl5fD91iawxPk5o_7lOiid7BWPs-wMFBwAJh4d7UmOgpRM2PXA5xj9KXdRh3lGH8UA0XcaA_CJuyg8_OKidfWrWikiJgXMzqhuvcgyIZLyxLGIw6Tw3S9%3Ds1600?expires=1788635700&signature=cc8e02823e319123d4c33368ef97ddcdc1fee7ddbec0628c19681c37e28199e2&req=cCQiH819n4hZFb4f3HP0gAa5tBBIGMqhD2e9DR0KzgKmU4zxQ3%2BtdFatz4SQ%0AWObTWJpgEK70uBLSQQ%3D%3D%0A)

**Étape 2 : Créer une nouvelle apparence**

1. Cliquez sur "*Apparence*"
2. Cliquez sur "*Ajouter une apparence*"

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445943304/b2256217b4310b3bb690f852/9efUqqYr4yu72cRr7w-Q_gniD4yCFDoaPbrHHJV8W9u0_d8McO6slhkg5nR946-4qyXkwuI9tLODvQ-6O_K1r3NLB4fHg26mq7vmvvGMn_cV6ESRVwz6FHJ20Iv5ZWRLad2O4SKh%3Ds1600?expires=1788635700&signature=0ee5c5174499667ea8fe852a1e70d49814f76fd44d95da8c92972d0d88f253e9&req=cCQiH819noFbFb4f3HP0gHhsIXEfy4EcfmL8rGVkOPPjglg%2Btc4C3PLDt1Cz%0AnLEZwPvprVQHRbp1XA%3D%3D%0A)

**Étape 3 : Configurer la langue**

Dans la fenêtre qui s'affiche :

1. Choisissez la langue du modèle que vous êtes en train de créer dans le menu déroulant
2. **Important** : après avoir modifié la langue, pensez à cliquer sur le bouton "*Charger la langue*"

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2195753678/e92abb6b85539272ecb925831db7/GsAIKsCJWGN5GEuhhZtr9wF5y3VYtm1N7_XfAr-izApfdVw8-iX-9FIOiLpkOTLgSEa_i_1aQ5tSArrS4SN2t5rfLENPlLEmy4CN4HGbH4wzKJ-Okf6rh_AHoifZILRY99buXAab-3Ds1600?expires=1788635700&signature=85859cf7f9c2f484bb7d7a48945cd87b5456f19fd5b48e7c14bde10cfec8bcde&req=diEuE857nodYUfMW1HO4zQ9JmWP2x9EPPGiwQNec5rQCk%2B2KF8CXxwypU5E5%0A7jOjdv6oF%2B1WFA5H8H8%3D%0A)

L'ensemble des mentions "fixes" sera alors automatiquement traduit dans la langue choisie :

- En-têtes de colonnes
- Labels des champs
- Détails des factures
- Mentions légales standards
- Etc.

**Étape 4 : Prévisualiser et enregistrer**

En dessous de la configuration, vous trouverez un exemple de document traduit dans la langue de votre choix. Cet aperçu vous permet de vérifier le rendu avant validation.

Vous pouvez enregistrer ce réglage en bas de votre page en cliquant sur "*Enregistrer*".

> **Bon à savoir :** 
> - Votre langue n'est pas disponible ? Vous pouvez tout à fait traduire le modèle vous-même, tous les champs sont modifiables directement dans l'apparence du document.
> - Les modifications de traduction ne sont pas rétroactives sur les documents déjà générés.

___________________________________________________________

### **Passer à l'étape suivante**

Une fois votre apparence créée, vous pouvez passer à l'étape suivante du processus de traduction :

**[Étape 3 : Paramétrer la traduction de l'ensemble des champs de documents](https://help.sellsy.com/fr/articles/5871939-etape-3-parametrer-la-traduction-de-l-ensemble-des-champs-de-documents)**

Cette étape vous permettra de traduire les champs personnalisables de vos documents (moyens de paiement, conditions, notes, etc.).
