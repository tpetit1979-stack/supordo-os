# Partager mes documents de vente via un lien public

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1932993399/8f8c3d3d0513bde809874c26bc50/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=9045a658f2a7f23cff25a5595b581ee4e65adec6dc87e37c56b79807da682efa&req=dSkkFMB3noJWUPMW1HO4zR9Uz6OFP%2FQ3c5uQ0eWJp5%2Fwf4oFExdRxyd7N6ZI%0AmFQWt%2FSzv4dI0uMXYWc%3D%0A)

Sellsy vous permet de partager vos documents de vente à vos clients (devis / facture). L'objectif final est de proposer à vos clients une interface de paiement en ligne pour leur devis ou factures.

___________________________________________________________

### **Activer le lien public par défaut depuis les réglages**

Rendez-vous sur votre menu puis sur *“Réglages”,* sélectionnez l’onglet *“Modules Sellsy”* puis cliquez sur *“Facturation”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445638640/c16e7cf153c5841ded3ab519/cXjHiriji2LCs7ZRs4ggpz-SF-pmUibaBahs1vomdZGthgaugYg4U8wEozAPS4Nt5ysP47MjBYdxox0komvV1j0j5-WzpoIL605KpBZFxSnTcYYmW_djPr74FsjWg-KAG589hHit?expires=1788635700&signature=8e0de802bdf9f5ec4c48677d69ec46e0a74aafaed8caad23681f36b5042edb17&req=cCQiEMp2m4VfFb4f3HP0gHDbEExRjEz14gJLXpFfncad5a7CcRqWMQjjYuPp%0ATM9lqgM2tKBLY4u2yA%3D%3D%0A)

Sur l’onglet *“Général”*, vous avez la possibilité d'activer ou non le lien public par défaut sur l'ensemble de vos documents de vente.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445638646/d9cfec7229e0fc71b147ca4f/IIfyuFQ7_cyWPcd2MK1v2mWsAtnnT1uJGb3HJ_TrSmvhvOAGlYdC0x_RGQx57Ku1c1Y0bZStMyG26bPL48KmGA3tAtELTUq5KrU7_0y3XfKbuLvzDp2VZGvKfzV7ERoLsvFMlQWE?expires=1788635700&signature=201db36674cfe99d9051c99b490a2f623638155e95722a07096f356df1a9e901&req=cCQiEMp2m4VZFb4f3HP0gDawKNt%2BBSKJmTlsVNvu1W8LMxGlLiwV9aUfmp6K%0AgHPOI2ag%2F6xpnZ0dzA%3D%3D%0A)

___________________________________________________________

### **Activer le lien public par défaut depuis un document de vente**

Sur chaque document vous avez également la possibilité d'activer ou désactiver le lien public.

> **Attention :** vous devez cependant faire attention **au statut de votre document** lorsque vous effectuez un partage via le lien public, en effet un document de vente en statut brouillon par exemple ne sera pas accessible. Un devis en statut expiré ne pourra également plus être payé.

### **Insérer le lien public d'un document de vente dans un modèle d'email**

Vous pouvez insérer le lien public d’un document dans un modèle d’email. 
Ce modèle pourra ensuite être utilisé lors de l’envoi de votre document (ex. : devis, facture, bon de commande).

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1589181936/f07ebaf5f4dbfc69b48750d5841c/Capture+d%E2%80%99e%CC%81cran+2025-06-26+a%CC%80+10_16_51.png?expires=1788635700&signature=fe38cd76c100d69de865316def6b6805f017a17772b0890e6964beea3458995f&req=dSUvH8h2nIhcX%2FMW1HO4zdEcCAhFGtAKULmoX2I9MzZ5V1fJkK%2BaJa1WvwFu%0AJjuHixtOjGh9aR12n10%3D%0A)

 
Les modèles d’emails appliqués par défaut pour l’envoi des devis ou factures sont disponibles dans [Réglages > Module Sellsy > Facturation > Emails systèmes.](https://www.sellsy.com/?_f=invoicing_prefs&action=emailsSystem)

Le partage de documents via une page publique constitue une alternative efficace à l’envoi de fichiers PDF en pièce jointe, tout en offrant des informations de[ tracking supplémentaires.](https://help.sellsy.com/fr/articles/5876346-tracking-de-consultation-des-documents)
