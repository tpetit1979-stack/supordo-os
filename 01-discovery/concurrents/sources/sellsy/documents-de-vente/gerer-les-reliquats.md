# Gérer les reliquats

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261844522/08e81355c6fa641abe3afa842c1d/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=85b136c8d3e0fd76199d7d571fecdc1fd41e30bd8f308f842dc56c0d6c434644&req=dSIhF8F6mYRdW%2FMW1HO4zZbHBkh6wtbx7eQgIVYL7RcAU4RPg0tJsphb%2FNI3%0AzrAgg0O5SBzLfvAFTaI%3D%0A)

Sellsy vous permet de gérer efficacement vos commandes en plusieurs livraisons en gérant les reliquats de votre commande.

> **Attention :** cette fonctionnalité n'est disponible que pour les lignes provenant du catalogue.

___________________________________________________________

### **Activer les reliquats**

Rendez-vous sur *“Menu”, “Réglages”,* puis sur l’onglet *“Modules Sellsy”.* Enfin, cliquez sur *“Facturation”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445894779/2b480587a08bd8109d7d94e2/pAqFPDxfUP38FdvGC2dcR7QLQhCa3MPTBF-6yYMvEo3FCNk9hn6bnhAEhauejMIgJR-Ytm3APBVuvzztIeAOR416xP4a81JE5Cq36Wfr8lX6mGCnETT9NrKBC_wxx2RI0ZbwZ6J-?expires=1788635700&signature=4eebec4a79706988bf59072cae7ce5b98e6010b78e0f7c9ac012fd5f7b7ca4f6&req=cCQiHsB6moZWFb4f3HP0gB7n8kSXG7PiSTtC%2FiHRVNPAbOpQmoCH4BJRI9rE%0A3ny%2B8WiCKDKHT6yghw%3D%3D%0A)

Cochez ensuite la case *“Activer la gestion des reliquats”* en bas de votre écran.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445894787/79eafa756725a2275d486579/vQlAy9nMNC28gYsv9Jpnslso7_4BY3FTnPcBSjdmCR1FY1ONBAb9d8NI459nzH96evpczVoVkgGNO5LkXlYu2cHtdzvuJto0yIfeH229nRtCpHUtpGfCiB_AJYtIJpYhIiGQldMs?expires=1788635700&signature=1f896fae2d662b6718426749ab38fd060ddbaf46fb5d10d1f50c36fb84e46e54&req=cCQiHsB6molYFb4f3HP0gNh4tYJWYag0rquf0HTdPeIhxvqmPVbjpSfqO8Qz%0AFMrnnVeRvqhaCu6%2F8g%3D%3D%0A)
