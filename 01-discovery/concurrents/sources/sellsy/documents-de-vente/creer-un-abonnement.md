# Créer un abonnement

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261911339/ad34fe81d07c5a8ede39e7053798/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=c67e34f0e7e26f9b834849efa429a722dc7aded2b548ab0c28ab9838bb4b69d0&req=dSIhF8B%2FnIJcUPMW1HO4zWEv74vrfLdnXTZmTLS5r2E6BgohQZLGE92O3EZJ%0AxXxe1xdEogpifb9qmSs%3D%0A)

Pour créer un abonnement, vous devez d'abord créer un modèle de document qui servira de base à vos factures d'abonnement.

Pour en savoir plus sur ce sujet, veuillez consulter le tutoriel : **[Créer un modèle de facture d'abonnement](https://help.sellsy.com/fr/articles/5987955-creer-un-modele-de-facture-d-abonnement)**.

___________________________________________________________

### **Accéder à la création d'abonnement**

Une fois votre modèle créé :

1. Rendez-vous dans la liste des modèles depuis le menu "*Facturation*" disponible dans le bandeau latéral à gauche de l'interface
2. Cliquez sur votre modèle
3. Sélectionnez "*Créer un abonnement*"

### **Étape 1 : Informations client**

Dans la fenêtre qui s'affiche, commencez par définir les informations relatives au client pour les factures :

- **Client** : sélectionnez le client concerné
- **À l'attention de** : le contact destinataire
- **Adresse du client** : l'adresse de facturation
- **Adresse de livraison** : si différente de l'adresse de facturation
- **Numéro du bon de commande** : si applicable

Ces informations seront automatiquement reprises sur toutes les factures générées par l'abonnement.

### **Étape 2 : Prélèvement automatique (optionnel)**

Pour activer le prélèvement automatique sur votre abonnement, vous pouvez utiliser GoCardless ou Stripe.

**Solutions disponibles**

- **GoCardless** : pour les prélèvements bancaires SEPA
- **Stripe** : pour les paiements par carte bancaire

**Documentation détaillée**

- **[Tutoriel prélèvement automatique GoCardless](https://help.sellsy.com/fr/articles/5871067-activer-le-prelevement-automatique-pour-le-reglement-des-factures-d-abonnements-gocardless)**
- **[Tutoriel prélèvement automatique Stripe](https://help.sellsy.com/fr/articles/5876314-gerer-vos-paiements-par-empreinte-de-cb-avec-le-module-stripe#h_69de943c51)**

Le prélèvement automatique simplifie considérablement la gestion des paiements récurrents.

### **Étape 3 : Mode de génération et envoi**

**Choix du mode de génération**

Le mode de génération et d'envoi est un choix important. Deux possibilités s'offrent à vous :

**Mode automatique :**

- La facture sera générée et envoyée au client sans intervention de votre part
- Idéal pour les abonnements standardisés

**Mode "Après validation" :**

- La facture sera générée en brouillon
- Vous devrez valider et envoyer manuellement chaque facture
- Une alerte email vous est adressée pour vous prévenir
- Recommandé si vous souhaitez vérifier chaque facture avant envoi

**Configuration de l'envoi**

Dans cette section, vous pouvez également :

- **Choisir le ou les destinataires** pour l'envoi par email
- **Sélectionner le modèle d'email** utilisé pour l'envoi
- **Définir les préférences de paiement**

**Options avancées**

Plusieurs options supplémentaires sont disponibles :

**Mise à jour dynamique des prix :**

- Case "*Mettre à jour les prix en fonction des produits et services du catalogue*"
- Si cochée, les prix des fiches produits/services seront appliqués au jour de la génération de la facture
- Vos factures seront liées dynamiquement à votre catalogue

**Gestion des promotions :**

- Vous pouvez choisir de prendre en compte les promotions éventuelles sur vos produits
- Si la promotion est active à la date de la facture, elle sera appliquée automatiquement

**Affichage de la prochaine récurrence :**

- Option "*Afficher la date de prochaine récurrence sur la facture*"
- Permet d'informer le client de la date de sa prochaine facturation

**Dates de service :**

- Option "*Afficher les dates de service sur la facture*"
- Permet d'afficher une date de début et une date de fin de période facturée
- Ces dates seront les mêmes sur toutes les factures issues de l'abonnement

**Gestion des stocks :**

- Dernière option : "*Impacter le stock des produits avec stock simple*"
- Active la décrémentation automatique des stocks à chaque génération de facture

### **Étape 4 : Programmation des factures**

Définissez le planning de facturation de votre abonnement :

**Paramètres de récurrence**

- **Date de début** : la date de la première occurrence
- **Nombre de factures** : combien de factures seront générées (ou illimité)
- **Fréquence d'envoi** : mensuel, trimestriel, annuel, etc.
- **Jour du mois** : quel jour du mois vous souhaitez adresser vos factures

**Génération de l'échéancier**

Cliquez sur "*Générer l'échéancier*", l'échéancier complet s'affiche :

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445681137/3364dfd0eee62a3d126cf8e8/5F85wuCJ3XEgFGbXpHbzZhaRHK1Iju6g-Vy3Lg0H6OlktXSFdw9zdsegUw-yI19tvOFkJur45mxK50E-iZo-2jmakD0rdPwUgq-Eo8Vg7BTDEQc14cG3-R55y4PFN_1ygXNNRrZo?expires=1788635700&signature=7454e62f4e16ba6a0ad6828d21b5d2565cd73ba56de23c890a953bdeedb011f2&req=cCQiEMF%2FnIJYFb4f3HP0gC4nI5r9nSTRQxOPf1U18O4Mw7gkHellyShVPcxv%0AV1aqi%2BZ%2BmVfDFfYZMA%3D%3D%0A)

Vous pouvez ajuster les dates ou le mode d'envoi si nécessaire. Une fois validé, cliquez sur "*Enregistrer*"

Votre abonnement est maintenant créé et les factures seront générées automatiquement selon le planning défini.
