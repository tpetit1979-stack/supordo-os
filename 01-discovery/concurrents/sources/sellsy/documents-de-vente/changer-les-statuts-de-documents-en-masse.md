# Changer les statuts de documents en masse

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261824956/9b0e230dfd2e8e0f06c2a8f3a133/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=70112608cda4047ac5e2e20948ccaa9bbfe097e871ff56099b9310a67e3780ac&req=dSIhF8F8mYhaX%2FMW1HO4zUm4bOKOEfXBQ34QkKfe%2BLZP2Gfj8%2B910aco8hJt%0Aw%2B8RU9SZ%2BdaNHLLvIok%3D%0A)

> **Attention :** cette fonctionnalité ne concerne que les documents de vente. Les documents d'achat ne sont pas concernés. 

___________________________________________________________

### Changer les statuts 

Pour changer le statut de plusieurs documents en masse, il suffit de les sélectionner depuis le listing concerné, nous prendrons comme exemple une liste de devis.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445618980/a62d9e1ea025be04d08fe693/IvNUrGoGdtwfX6hv6uey04EH3sLCR90LGRXKLKGIMkBVXid15rWqOzNbd6g_GixzmeBxwUL8QQtV39pIt7Go3vzlauwxAV-DZRbhCI_WCDzvxpaje27rgy-BtVq8ZcJCBfzsiaH0?expires=1788635700&signature=911d1c80ab62fef2991f05915d50d544e7ca1b28c3173c2a045805ce3463ec6a&req=cCQiEMh2lIlfFb4f3HP0gEAZrlB5btOnW17Bv6TF4cyFRuibzy8jJBNxTZGU%0ATP8YaLMQ6c%2B%2FG5jdkw%3D%3D%0A)

Sélectionnez les devis que vous souhaitez modifier puis cliquez sur *“Choisissez une action à effectuer”,* puis sur l’action *“Forcer les statuts”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445618987/53c45dbbb2414b2333b0d81c/oZQeAhaRmBGtMt1JQAeR01wqYPxegDqwz7Mi48p5w2_t1d7tPVVzr4c7X5tyTOpaSnFPs8VuihKcEd-g2UZu3Q-mZWMbqoxHsYAydpjYO1cZIUdfAQn3x7hVkWRkIxShzy6V79TW?expires=1788635700&signature=c7863f938f6824542dfbf2fb7ff49b23444eef64bd744ef1368f5e8e80fae42d&req=cCQiEMh2lIlYFb4f3HP0gISsK9mn7HRP6pTjlxMTc8zSnQBFj5qPY9QYZhRt%0AvCNnm0Bmem6wBdKEOw%3D%3D%0A)

Si les documents sont dans un statut identique, vous pouvez les fusionner de manière groupée.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445618991/989d063fb3c6509dc0b2bb34/5S5aVJHSwnmS8UsVEv9i4c2FCrG1gdLlsM_DA051hQwdsWXwCL3v-H5GdSrJXtgz1M8oyPEtBplmJNzc-0bdFAoGCsiGWJkibsrzdnGtmMyhMNbifsT_cHmULvfGuVyGq0vi8Ds5?expires=1788635700&signature=67615e0119399e7ced77a8da2381ed8b35cb30796024f0effba536c7cad6daef&req=cCQiEMh2lIheFb4f3HP0gA3a49h1SQCm9M6RPl3NV9q23xyETpSGsygIcD6l%0AHwk9Q4XB8LIbnap3Yw%3D%3D%0A)

Si les statuts sont incompatibles, Sellsy vous propose de changer les statuts pour chaque document.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445619001/5192324871da1c68607ed389/ClX6IDOLVnR6V3iSCMmJwsrU5Luwwlm3hQibDI2qn2Aj-Z06XDak1pNj2ZL5qftp77mz_9XrkbhXJT39RHo3luBM1WP9jfhS6nFQyOb-qFW-hQsPuj0QpJ_bsH0yBEkWkQ5n_Gi5?expires=1788635700&signature=ce8f588442d6c2bd894811fe2c7467ef9909e075178ae00d3bbd4831d5782253&req=cCQiEMh3nYFeFb4f3HP0gMDr4Vp9g4es1jwIC8SkLqM0QCQhsBUE2ZKG7fJk%0A1V5e0fyMP72%2B3miMcA%3D%3D%0A)

Il ne vous reste plus qu'à valider en cliquant sur *“Forcer les statuts”.*
