# Fusionner des documents

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261851463/6d4baf7fc622e4bc46237f6b93e1/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=aaf929ff7cc5bcaeeda8b92b571030922285e34ca9816d44d489e9dba5db9ca1&req=dSIhF8F7nIVZWvMW1HO4zU1PDK%2F%2BmJe3c6UB%2FbFGRmIoiXuiD1qM7i9xk7Ho%0AiIskApAyzUr6pPof5Yw%3D%0A)

Sellsy vous permet de créer un unique document à partir de plusieurs documents existants.

Voici quelques exemples d'utilisation :

- Facturer plusieurs devis sur une même facture
- Facturer plusieurs bons de livraison sur une seule facture
- Créer un bon de commande à partir de plusieurs devis

Cette fonctionnalité vous permet de simplifier votre gestion commerciale et de regrouper plusieurs opérations pour un même client.

___________________________________________________________

### Procédure de fusion

**Étape 1 : Sélectionner les documents**

Commencez par sélectionner les documents que vous souhaitez fusionner depuis la liste concernée (par exemple, la liste des devis).

Cochez simplement les documents concernés avec la case située à gauche de chaque ligne.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445809676/0988570633c30b533ffa8deb/tAtXAIGAORvYC6fLKwtL5hygYt0q4VIM8pFDMbskpFWVLHtSKSmFR-K6_3v_04FHjD3bfumzEuRvYvSK_RdjOsa6IKfQria7Z19GAAahk_aq6__sN3OwRSislm1ESL1wPuSuOPPs?expires=1788635700&signature=399f136bb427b8ad8fc2348dc81548185ad6a24721f806619b1fcdee4d8b8c87&req=cCQiHsl3m4ZZFb4f3HP0gI7s%2BnRkjHb6o92I9Xse8zIqgjs4ACWNAdJtOaJL%0A1z03xOSKbDmd23npAg%3D%3D%0A)

**Étape 2 : Lancer la fusion**

1. Cliquez sur la liste déroulante "*Choisissez une action à effectuer*"
2. Sélectionnez l'action "*Fusionner*"

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445809683/7bcb5a9418c33af06f5db928/SoFDBRemY-x8u6-bKjqgcwl8kXgqIr9s9RmYeoBidzVIbGNpeKZcfbDrukffaXsGuFjrkGhK9shoCsS8mOECqfadZzf6q34g43oBI-egjlpxd0TrOHDelJEAh0zsMq7YZQY7FX9X?expires=1788635700&signature=337dd65eaa407a0cfd792f3ac9fb1214a0943a6964e70ede20bcb002ce06572a&req=cCQiHsl3m4lcFb4f3HP0gMPGmiTfDqjti94igHyvda3ry6aQauXYHRRBXvTN%0AEffpA3dQ9zdg0USo0w%3D%3D%0A)

**Étape 3 : Configurer le document fusionné**

Un aperçu des documents concernés vous est proposé. Vous pouvez alors :

- Choisir le type de document de destination (facture, bon de commande, etc.)
- Décider d'afficher ou non une séparation avec les informations des documents fusionnés

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445809696/6e8e5b135157d83bd8654d7b/vIsAP-HAfSEHST0czHpPr51ee4p9ShlECsPeZlBqGVDcPbdC6rZgSRoUetH9HwkB_tRBcAnSZVYRGP7RyVF6WUKvZPDEqtWDzkQHE4UgZ3VWksw_F11hl45jVAa0LAgLVJnEAC_I?expires=1788635700&signature=2c64437c0c7b5a144942238f060df58aacf57c9ca94a2878c2a3f33cdfc5da3c&req=cCQiHsl3m4hZFb4f3HP0gFoALkATfw9CFeCElDLMHFoVSQIiEQkfjGy8ZuYH%0AfJOgeRhee0u2347hdg%3D%3D%0A)

**Étape 4 : Finaliser**

Une fois votre choix validé, votre document fusionné apparaît. Il vous suffit alors de l'enregistrer normalement.

### **Conditions requises pour la fusion**

Pour que vos documents puissent être fusionnés ils doivent :

- Avoir la même devise,
- Être pour le même client,
- Ne pas avoir impacté les stocks,
- Les devis ne doivent pas avoir d’acompte,
- Les documents doivent être dans la même catégorie tarifaire.
