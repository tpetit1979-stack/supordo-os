# Imprimer des documents en masse (devis, factures, etc..)

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261824115/9412800dda250c5018d39c621809/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=a072b49ba4cb9740d95dfde4ae7ae1025bbd086832ca9c4279f6056115e6a8df&req=dSIhF8F8mYBeXPMW1HO4zYNkzEPFYLHIYNc3SA40S8ZWo4Ozx%2Bi4cE6u0jTN%0AV%2BFQ3kbFt1nCP9%2BV6Fk%3D%0A)

Si vous souhaitez imprimer des documents en masse, il convient d'abord de les télécharger sur votre ordinateur.

Pour ce faire, isolez les documents désirés en utilisant les filtres de votre listing, puis cochez les devis que vous souhaitez exporter. Cliquez sur l’action groupée *“Télécharger au format ZIP”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446477264/290e5571379d303a0676719f/b2PtCdd6hyTGOmYKkiUl__pL2tI4-9-temcGv0c0Np-GPJUUrnPKK2rgTRD8ZaacJ9fsG-JtZWu22gnNmUh6CFhqUqoPWOWbGLSk0-JDnfngeepxYbZQqpWcUbAroRc3ONbYPH6N?expires=1788635700&signature=3703c6c13dd69f0d3cbe8ed5fced4b0e6813d80c021aad187e05c0a8379df8b4&req=cCQhEs55n4dbFb4f3HP0gHFEuzkmG6XsoAgLUZJNn1W2XMuaBChHc%2FiTHGpu%0ATIgTEx74v1iPRnbhaw%3D%3D%0A)

Le fichier ZIP est téléchargé sur votre ordinateur (dans le dossier de téléchargement de votre navigateur). Double-cliquez sur le dossier pour afficher les fichiers.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446477270/556257ea6be5a2f36fbc34ae/kFMAFlCOsVHLAhWbtm2lOaMWDhVq22dV3IuOD9jcRcAv4BHPobEczllDhEtuex7K4wnfDsXmbFCJ41qPfewf8fYBj_gxJgD3Raoi5SqJsFLcqCCMWJZXx_6XodeWCnnv0icSk9iC?expires=1788635700&signature=a232553f4f09563e895b6b2560113acbc4170a3a518f8734150e671a357071db&req=cCQhEs55n4ZfFb4f3HP0gGt%2B8u2n%2FSHL3zRQ5AI0FAk%2Fjg3QZNbWYdp%2FoYTU%0AYYROAbZgCSxb8XWOaA%3D%3D%0A)

Pour les imprimer en masse, il suffit d'ouvrir le panneau de votre imprimante et de faire glisser les fichiers dans la file d'attente de l'imprimante.

> **Bon à savoir : **Mac OS est utilisé pour l'exemple, mais la manipulation est similaire pour les autres systèmes d'exploitation.
