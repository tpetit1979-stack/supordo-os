# Étape 6 : créer le document dans une autre langue

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261855417/19bd537f3b7c76a48f30539ccbdd/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=af83b6cc55313ae550cf7535cbe8760497c2da44494d2bc047ff70dfc66ffa34&req=dSIhF8F7mIVeXvMW1HO4zZmv0amTNTfHS7g5nMwC1nxI3osGEUEw8XF1V335%0Al7%2Fjn0tN9kfR%2B7xZMVw%3D%0A)

Une fois l'apparence de document créée et votre **paramétrage effectué**, vous avez la possibilité de choisir cette nouvelle apparence dès la création de votre document. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445946966/d17653a17b72c96d3f2a544d/Zb7CVpZztJ16Q5a22-BfDMIHjwZxMz7sPnhRjgsg_6eRXLiZuAFR8wR-10x2lXyk9uqVFZiWL49to2v76KATvKef4ZgNZMbK4DlXB-lo_zK4JTl_h74neA3d5uMzcH26H3QtVk8H%3Ds1600?expires=1788635700&signature=f54df93fcbeed7243d4fa99fd431c22d028164c004a65f93050b521139d2aac4&req=cCQiH814lIdZFb4f3HP0gGPJXEJhAsr2WmW5GC0PqAmLds2y%2FdXdM%2FYz8u3N%0AZ5%2BS81SrJmadqc5%2FxQ%3D%3D%0A)

Ainsi, tous les champs de votre document seront **automatiquement traduits**. Vous trouverez également à côté de vos champs et réglages de documents un **drapeau **correspondant à votre langue de traduction afin d’apporter des **modifications aux variables **de votre document. 

> **Bon à savoir :** 
> - La traduction du document sera visible sur la version PDF. Lors de l’édition du document, vos champs apparaitront toujours dans la langue par défaut de votre compte.
> - Les modifications de traduction ne sont pas rétroactives sur les documents déjà générés.
