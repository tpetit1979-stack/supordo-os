# Étape 3 : paramétrer la traduction de l’ensemble des champs de documents

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261853749/92bd7370a781fbb0f50fed7f15a3/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=a0653911f8cc08bc6652f6ca09d587c646610343988ae3e230262dbcfc66db8e&req=dSIhF8F7noZbUPMW1HO4zed0I0gC1YwnMa2rOOOaVFkQ5LWSMLKv%2FwOTs6rs%0AR22hRMMgNw8jNsHeweU%3D%0A)

Lorsque vous ajoutez une langue à votre compte (anglais dans notre exemple), vous avez également la possibilité de traduire les informations **fixes ou variables** de vos documents. 

___________________________________________________________

### Traduire le libellé de l’interlocuteur et le pied de page 

Rendez-vous dans "*Menu*" > "*Réglages*" > "*Module Sellsy*" > "*Facturation*"

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445944007/4c95920cc83aa9de60de26ff/_OT6Bg_UeGOLr571l0WVl5fD91iawxPk5o_7lOiid7BWPs-wMFBwAJh4d7UmOgpRM2PXA5xj9KXdRh3lGH8UA0XcaA_CJuyg8_OKidfWrWikiJgXMzqhuvcgyIZLyxLGIw6Tw3S9%3Ds1600?expires=1788635700&signature=071b5f7788e5969dfb61cad894c8cafe70c4f78e524a5a2e0acc29aea962ff54&req=cCQiH816nYFYFb4f3HP0gMnuld%2Bb%2BQuoXjAys%2FnCd5FXvpnEZWzZ4YWO8g61%0Aq4SjTntpcHMITD5MRg%3D%3D%0A)

Cliquez sur *"Affichage".*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445944015/354f10f5854742f15d8257f1/2b758d75-b0c9-4cf9-88f9-0b226e857843?expires=1788635700&signature=3833bd8c2887d047a4d2329052898140c94c769ae0fbe7f25c0442791aa3495b&req=cCQiH816nYBaFb4f3HP0gL7XUh0clBR7n3VZIPPv%2B1aAa3PIkNQ3%2B6W%2BWqVi%0AHNSWO40qxi%2F%2F1XXCQA%3D%3D%0A)

En bas de votre page, vous trouverez les zones dédiées au paramétrage :

- Du libellé de votre interlocuteur
- Du pied de page

Pour traduire ces éléments :

1. Cliquez sur "*Modifier*"
2. Sélectionnez l'onglet correspondant à votre langue (par exemple "*Anglais*")
3. Remplissez manuellement votre texte traduit
4. Enregistrez

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445944036/cf39fc957b7f4add1803c305/EeQnj57NYWEXZAE_tHARpYNl2p_ywVRXv35e0iX15yg-zF7PSeHC3lCZsHtWU-EtdQeDNB27-_CkBBApV5Cb0yp7C3Q1uvm8IuOFFvAAOlI9CylQlvvD4uGm4v-fSXNArDpxcm_c%3Ds1600?expires=1788635700&signature=1c5b476ff3c2f2a9818ea4d14bc44ca0594378b7105b5ee2386b572cf4b93320&req=cCQiH816nYJZFb4f3HP0gHN0TcyuRFvjm5PG2RT6%2FTUWDM2uQ1iUFBBL0dzg%0AxsmvovN2xUPLyL0Jfw%3D%3D%0A)

### Traduire les conditions et acceptations 

Rendez-vous dans "*Menu*" > "*Réglages*" > "*Module Sellsy*" > "*Facturation*" > "*Conditions et acceptations*".

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445944040/80b0354a785e5794a7b70d94/452b0093-7353-4923-a626-50036986a66c?expires=1788635700&signature=08fb0595cf1a318152783d389fc8db9b65c0e40a263c0ae6476891c0f8b38d05&req=cCQiH816nYVfFb4f3HP0gIPf7cKz13o1xxJBAjkSUcnDqE9UJ6GIB0TaMp2L%0Aopp6P2w%2FJQfh6Vx%2BiA%3D%3D%0A)

Dans la page qui s'affiche, vous avez la possibilité de traduire :

- **L'acceptation des conditions** avant signature ou paiement en ligne
- **Le texte de loi sur les intérêts de retard de paiement**
- **Le texte de loi dédié à la TVA intracommunautaire**
- **Le champ note** pour vos conditions générales de vente

Comme pour l’exemple précédent, il vous suffit de cliquer sur l’onglet *"Anglais"* puis de remplir manuellement votre champ de texte traduit. 

___________________________________________________________

### **Passer à l'étape suivante**

Une fois tous vos champs de documents traduits, vous pouvez passer à l'étape suivante :

**[Étape 4 : Traduire le catalogue](https://help.sellsy.com/fr/articles/5871948-etape-4-traduire-mon-catalogue)**

Cette étape vous permettra de traduire vos produits et services pour qu'ils apparaissent dans la langue de vos clients sur les documents.
