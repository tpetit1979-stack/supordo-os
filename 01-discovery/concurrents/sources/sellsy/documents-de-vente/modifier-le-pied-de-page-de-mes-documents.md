### **Accéder aux paramètres du pied de page**

Pour modifier le pied de page de vos documents :

Accédez à "*Menu*" > "*Réglages*" > "*Module Sellsy*" > "*Facturation*"

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445845458/d492c4cd448a81f051ce5723/bEzFjRrAIrf3_TuahFnzEcSytRiUwW_yuZ1H0LWX07McebpZROIOg2jOx16Kl3uTM6qYt3iQhA12tJr6nNDpsy5uzhx8l659MK1l2aiAPbkP3VcSxIlXU1s7mNATsPqa47wSjHxC?expires=1788635700&signature=d348b45584d551dd3c24c9dcf762f0b60075f86db39775c8ee4fe2955c924786&req=cCQiHs17mYRXFb4f3HP0gDQ9MRiAk%2Fk4YuoqixhzDxYGOQQtuxiwwRQ85uZa%0ASb3IrI17TmB0lV54mA%3D%3D%0A)

Ensuite, rendez-vous sur *“Affichage”*.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2302968619/fee9daa546b22d7b83382e8e6546/Capture+d%E2%80%99e%CC%81cran+2026-04-21+a%CC%80+12_19_00.png?expires=1788635700&signature=b5964b05c1b5bcfe987c827c191853e545b0bae239fcfe63b3e364a471eaa754&req=diMnFMB4lYdeUPMW1HO4zTaQXA811Buqcx1ISsZq7z4yUWlgLrOGHbmpJgH%2B%0AarWBlPUVnJ%2BjZAxgS7I%3D%0A)

En bas de votre page, vous trouverez un espace *“Gérer le pied de page de mes documents"*. 

___________________________________________________________

### **Gestion automatique du pied de page (par défaut)**

Par défaut, Sellsy génère automatiquement le pied de page selon les informations renseignées dans votre fiche société.

Ne s'afficheront dans votre pied de page que les champs que vous avez effectivement remplis dans la fiche de votre société.

> **Bon à savoir** : La fiche de votre société est modifiable depuis "*Menu*" > "*Réglages*" > "*Société*" > "*Informations société*".

Les champs disponibles sont les suivants : 

- Nom société
- Email
- Téléphone
- Fax
- Site Web
- Capital social
- Numéro TVA intracommunautaire
- Numéro SIRET
- Numéro SIREN
- Code NAF (APE)
- RCS
- Type de société
- Adresses

> **Bon à savoir :** les champs suivants sont désormais affichés obligatoirement sur les factures et avoirs, conformément à la législation française :
> - Adresse complète du vendeur
> - Numéro SIREN/SIRET ;
> - Forme juridique,
> - Capital social ;
> - Numéro RCS
> - Numéro TVA intracommunautaire

### **Gestion manuelle du pied de page**

Si vous préférez un contrôle total sur le contenu et la mise en forme de votre pied de page, vous pouvez opter pour la gestion manuelle.

**Activation**

1. Dans la section "*Gérer le pied de page de mes documents*", sélectionnez l'option de gestion manuelle
2. Saisissez directement le texte que vous souhaitez voir apparaître dans la zone de texte prévue à cet effet

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2302970717/ccabdae1ef43b636695bfd272701/Capture+d%E2%80%99e%CC%81cran+2026-04-21+a%CC%80+12_19_41.png?expires=1788635700&signature=3b8ba146fb2288a9ea8889fea05f6dc7ffa90340c0c5f2673f3c7efc72241571&req=diMnFMB5nYZeXvMW1HO4zaP7Iqp2u%2BbLxjCD7IakiyqsSb56OHGgoikgc9OR%0AOLUkNTrMOEaRXc1%2Bv4Q%3D%0A)

**Avantages de la gestion manuelle**

- **Personnalisation complète** : vous choisissez exactement ce qui apparaît et comment
- **Mise en forme libre** : vous organisez les informations selon vos préférences
- **Traduction** : vous pouvez créer des pieds de page dans différentes langues

> **Attention :** si vous modifiez ces informations manuellement, leur conformité avec la législation française ne peut plus être garantie.
