# Créer un modèle de document

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261837486/63f1e9fc4f4a769a280012953040/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=d36cb811fce0e4cbe139997e78a09722c0659ed84f8ce5f8a32e27595b17acb2&req=dSIhF8F9moVXX%2FMW1HO4zSDKjDwMbwg1lDTBllfG%2BkJlJZndijMW%2Fr3S9PMa%0A64h7mA6egAc9ZdyWdIg%3D%0A)

Les modèles de documents vous permettent de standardiser vos devis, factures ou avoirs afin de gagner du temps lors de la création de nouveaux documents.

Ils permettent notamment de préconfigurer :

- la mise en page ;
- les catégories tarifaires ;
- certaines mentions réglementaires ;
- les paramètres liés à la TVA.

Cette fonctionnalité est également utile en association avec le module Gestion des abonnements.

___________________________________________________________

### Créer un document modèle

Cliquez sur le menu *“Facturation”* puis sur *“Créer un modèle”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445807757/1590cf64d8173a9fd1c0040b/8UMIIkQ9b9qzM8zd4NXzVAGNwYhSbCxwm4FvEP1MXnNFibVUZSIceW_LwtNfKoW2a0SHVEGL2vsSVXxCbj9OM8Vr3atnSLLaZe-ORnWS4LI1EyB8Ww3aGKFHWJoTddXNJQb3487M?expires=1788635700&signature=b4af0fd023859dae797547f2bf2b5bc07506d7d2d7be378b62200ee5da5326ba&req=cCQiHsl5moRYFb4f3HP0gHNV6AUYkeH5YCJcYecTt1tqpRnQaZiK%2Fvxz8w7K%0AR6RHRqh%2B78YzLRbOvw%3D%3D%0A)

Si vous avez déjà créé un modèle de document, vous avez la possibilité de vous appuyer sur celui-ci pour créer votre nouveau modèle en le dupliquant.

Choisissez la catégorie tarifaire et l’apparence de votre document comme vous le feriez pour un document normal.

> **Bon à savoir :** Les paramètres définis dans un modèle sont réutilisés à chaque création de document.
> Si votre configuration TVA a évolué dans le cadre de la facturation électronique, pensez à vérifier :
> - le mode de TVA utilisé ;
> - les éventuelles mentions réglementaires ;
> - les anciens taux ou exemptions configurés dans le modèle.
> Un modèle ancien peut conserver des paramètres devenus non conformes.

S'agissant d'un modèle, aucune information de client n'est affichée.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445807766/eae8ad6d7674aaa5ff40733c/mT9g3kPV05ZduUk8vAa3mCANK5H5j19UDIz87VyCGEdxVMzriPymagjfTxogRtWnE6kurjXmoZqu34ygo4y8-DagqE0wnLKEpTtpxMWyVW-wADzqL_8h-yIUR8r6pGk7civ9j4Yd?expires=1788635700&signature=388c7f242f6c33985954290bee1a6ec5e1066ff75627b1e7025a07dc740a7c38&req=cCQiHsl5modZFb4f3HP0gN77qxH0d5ueJeWBNvr19M73b4uOtSnTBwG0A2XG%0Afj4jQ7Dvk5cWoR4GFw%3D%3D%0A)

Vous serez ensuite dirigé vers la page d’édition du document, similaire à la [création d’un devis ou d’une facture par exemple](https://help.sellsy.com/fr/articles/5866884-comment-creer-un-document-devis-facture). Une fois votre modèle terminé, cliquez sur *“enregistrer et quitter”.*

**Utilisation des variables dynamiques : **Dans le champ objet d'un modèle, un bouton *"baguette magique"* est disponible afin d'ajouter des variables dynamiques. Les variables sont de type date (types de jours, mois, années, semestres, trimestres..).  Une fois choisies, les variables sont insérées et seront remplacées automatiquement lors de la génération du document.

![](https://downloads.intercomcdn.com/i/o/625303608/461c631027ccacfba506d461/Capture+d%E2%80%99e%CC%81cran+2022-11-29+a%CC%80+09.33.56.png?expires=1788635700&signature=c23949f0e66eed9e4f9ae244bfdc6d2a9806e8796b0afec87c0cdb32d9237e3a&req=ciIiFcl9m4FXFb4f3HP0gHW5sETuLARfA8u7tFeBG19Lk94Qi96xxN33gvHc%0ABbVBE%2BScxtUtVpf4fw%3D%3D%0A)

Vous pourrez ensuite retrouver votre modèle dans votre menu *“Facturation”,* sur *“Liste des modèles”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445807782/fffe0849b3d3e993822c9ba1/eiTumkF1xQdaLBX6AZdTME0fBMZZIeOlGlAyvi8YBpihChzSz-1GuybJsJ7HOqo1a_yV___xCatGW-1cO-wQCzGUvHrC-9jfgC4YV3lImK0mfE_IBzsc-I-2678PlnU0l9ccZTjl?expires=1788635700&signature=c2c5d002393d245e242e406d14a87df19111535b3b6016ab98dc4bbd018c6808&req=cCQiHsl5moldFb4f3HP0gFTwav1MDPUcm4BWJB2BOey7vHUg%2Fs%2B4%2Bzbf9BSl%0AsCALmvxX37nmI9mmMA%3D%3D%0A)


Lorsque vous allez créer un nouveau document de vente, Sellsy vous proposera d’utiliser votre modèle de document. Pour ce faire, il suffira de sélectionner votre modèle dans le champ *"À partir du modèle".* 

Ce choix est bien entendu facultatif (en fonction des droits appliqués dans votre profil de privilèges par votre administrateur).

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/445807793/d96677bf7af901c6bb4fe1dc/PURaAMUIffZYqkjCXAsFEMJGrwUS9DnaJRpkQFgscYfnGud5_TURuqf19O9rHAjp_buUDyJHnUYHSnsAVs5_S4YoucP2YSK_M7aAjVauTEPrTvZgDaXB1r-wzIHsq5jGeN54v5oW?expires=1788635700&signature=901f7289851e1538f82579204a0b623ed93801a056bdda92de957050c8b8f43d&req=cCQiHsl5mohcFb4f3HP0gBFwe%2FsN1Z6HCFJtimfp57ZqNpMX3Yk11JKdlM4B%0AsVoKBZ6AZqwu%2FU1m%2BQ%3D%3D%0A)

> **Bon à savoir :** 
> - chaque modèle conserve ses propres paramètres ;
> - les réglages globaux du compte ne mettent pas automatiquement à jour les anciens modèles ;
> - les modifications d’un modèle s’appliquent uniquement aux futurs documents ;
> - les documents déjà émis restent inchangés.
