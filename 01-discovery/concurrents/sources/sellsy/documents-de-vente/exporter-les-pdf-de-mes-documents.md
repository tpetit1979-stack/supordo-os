# Exporter les PDF de mes documents

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1932988748/7aa30c8bbcea515d08da38cd3ae1/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=ac8d9c29b2d062f3149d74e1e510644eeb873d2eddde2ff1e77cd7edc3cfa65a&req=dSkkFMB2lYZbUfMW1HO4zZRhC%2B1O0qvaiPghSr%2F9YZSlHVpY1Zwq%2BD3qresl%0ANrNr5aYSYCABaLVWgKU%3D%0A)

Si vous souhaitez exporter les PDF de vos documents de vente ou d'achat (devis, factures, avoirs, bons de livraison, bons de commande, proformas), Sellsy vous offre **deux possibilités**. 

> **Attention :** si vous n'avez pas la possibilité d'exporter les PDF des documents, veuillez vous rapprocher de votre administrateur afin qu'il modifie vos droits dans votre profil de privilèges. Le droit nécessaire se nomme *"Accès aux fichiers"* et se trouve dans la section *"Fonctionnalités diverses"* des profils de privilèges. 

___________________________________________________________

### **1. Export archive ZIP (sélection)**

Pour télécharger une sélection de documents de vente ou d'achat dans un zip contenant les PDF :

- rendez-vous sur la liste des documents que vous souhaitez exporter, par exemple la liste de vos devis,
- sélectionnez les devis que vous souhaitez exporter,
- cliquez sur *“Choisissez une action à effectuer”* puis sur *“Télécharger au format ZIP”* et validez.

___________________________________________________________

### **2. Export archive ZIP (complet) **

Pour télécharger la totalité de vos documents de vente ou d'achat dans un zip contenant les PDF : 

- rendez-vous dans l'onglet *“Fichiers”* disponible dans le bandeau latéral à gauche de l'interface puis dans le dossier *"Documents Sellsy", *
- cochez le ou les dossiers de votre choix (devis, factures, avoirs, bons de livraison, bons de commande, proformas, etc.)
- cliquez sur *“Télécharger ZIP”* dans la liste déroulante *“Actions groupées”* en haut à droite de votre page.
