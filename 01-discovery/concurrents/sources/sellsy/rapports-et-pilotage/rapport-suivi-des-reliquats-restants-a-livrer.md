# Rapport - Suivi des reliquats restants à livrer

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2494679752/da8efe6c0a1a9b7bbc5cd19e102e/FAQ-Bannie%CC%80reAcademy-2+-2-.png?expires=1788635700&signature=2d1a42453b220f6779abe0302a81533cba01580c21bb207021ecaa089187c6f3&req=diQuEs95lIZaW%2FMW1HO4zYU8zIRmDohNbUe2rgQvJV57iHIpuzEe92uYPdbF%0ATouPeQ196k%2FvIrJo6r8%3D%0A)

### Objectif du rapport

Le rapport **"Suivi des reliquats restants à livrer"** a pour objectif de centraliser et visualiser l'ensemble des reliquats (quantités commandées mais non encore livrées) sur vos documents de vente.

Il vous aide à :

- Identifier rapidement quels clients et quels produits ont des livraisons en attente
- Croiser les données de stock et de commandes fournisseur pour anticiper les approvisionnements
- Piloter votre activité logistique et commerciale depuis une vue consolidée

> **Bon à savoir :** Les documents de vente et les commandes fournisseur au statut **Annulé** sont automatiquement exclus du rapport. Si un reliquat portait sur un document annulé, il n'apparaîtra pas dans les données.

___________________________________________________________

### **Filtres disponibles**

Les filtres s'appliquent en haut du rapport et affectent l'ensemble des indicateurs et tableaux affichés.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2494681548/695d31084733e6f62f85a0445578/1.png?expires=1788635700&signature=338e55a0d66ebfd0e4a7bf72c3c904e79c34c837377983c913f081a00706afa3&req=diQuEs92nIRbUfMW1HO4zfjZUCtp1m4agTtGkLIP%2Bx%2FjPCMdCU62eiIqJWTu%0ALHBz3ag8TOQ4imCSQik%3D%0A)

| **Filtre** | **Description** |
| --- | --- |
| **Type de document** | Sélectionne le type de document à analyser : **Bon de commande** (par défaut) ou **Devis** |
| **Date du document** | Filtre les documents selon leur date de création |
| **Date de livraison** | Filtre selon la date de livraison prévue sur le document de vente (Devis ou Bon de commandes) |
| **Statut du document** | Filtre selon le statut du document. Les statuts **Accepté, Acompte, Lu, Envoyé, Partiellement facturé** sont actifs par défaut |
| **Propriétaire du document** | Filtre selon le collaborateur associé au document de vente. **Options disponibles :** • **Propriétaire du document** : collaborateur responsable du bon de commande ou du devis • **Propriétaire du client** : collaborateur responsable du compte client |
| **Client** | Filtre les résultats sur un ou plusieurs clients spécifiques |
| **Type de ligne** | Filtre les lignes selon leur type (produit, service, ligne simple) |
| **Référence** | Filtre les lignes selon la référence produit |
| **N° du document** | Filtre sur un numéro de document précis |

### **Tableau de détail par document**

Ce tableau présente le détail ligne par ligne de chaque document de vente contenant un reliquat. Il permet d'identifier précisément, pour chaque document, les références concernées et les quantités en attente de livraison.

| Colonne | Description | Affichée par défaut |
| --- | --- | --- |
| Client | Client associé au document | ☐ |
| N° de document | Numéro du bon de commande ou du devis | ✅ |
| Référence | Référence de la ligne produit/service | ✅ |
| Type de ligne | Type de ligne dans le document (produit / service / ligne simple) | ☐ |
| Déclinaison | Déclinaison de la référence (variante produit) | ☐ |
| Date du document | Date de création du document | ☐ |
| Date de livraison | Date de livraison prévue sur le document | ☐ |
| BL | Numéro(s) du ou des bons de livraison associés | ☐ |
| Détails des BL | Informations détaillées sur les bons de livraison associées (Date + quantités) | ☐ |
| Qté commandée | Quantité totale commandée sur la ligne | ✅ |
| Qté livrée | Quantité déjà livrée | ✅ |
| Restant à livrer | Quantité restante à livrer *(mise en évidence en rouge si > 0)* | ✅ |
| Commande fournisseur en cours | Quantité en attente sur commande fournisseur liée (reliquat du restant à livrer côté fournisseur) | ✅ |
| BDC achat | Numéro des bons de commandes achat associés | ☐ |
| Livraison achat | Informations sur la livraison fournisseur (Date de livraison estimée du BDC achat + montant restant à réceptionner de la part du fournisseur) | ☐ |
| Fournisseur | Nom du fournisseur concerné | ☐ |

> **Bon à savoir :** des colonnes supplémentaires peuvent être affichées en cliquant sur *"6 colonnes"* en haut à gauche du tableau.
