# Rapport - "Statistiques" par abonnement

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1867525941/b4b78250879c99cfbaff91e90ecb/FAQ-Bannie-CC-80reAcademy-2.png?expires=1788635700&signature=26e96784b426f8ba2240ad9c7290183eb0dc4ef36a347985abf3fe96855e85df&req=dSghEcx8mIhbWPMW1HO4zX2yMmJWM4JB2BLffFDNAtHHqLucls8w1CnZ%2B4zL%0Aj8ofpfQm%2B2LKgFFt%2BJY%3D%0A)


Pour consulter le tableau de statistiques liées aux abonnements, rendez-vous dans votre menu “*Rapport*”, puis “*Statistiques*”.
​
En cliquant sur l’onglet abonnement, vous retrouverez l’évolution de :

- Le nombre d’abonnement actifs,
- Le nombre de factures générées,
- Le chiffre d’affaires généré,
- Le nombre de factures restantes,
- Le chiffre d’affaires prévisionnel,
- Le chiffre d’affaires consolidé.
