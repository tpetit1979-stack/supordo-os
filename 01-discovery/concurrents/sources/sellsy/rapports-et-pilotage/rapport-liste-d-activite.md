# Rapport - "Liste d'activité"

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1867531795/ca7ec7b54cbc95e3039e330bda9d/FAQ-Bannie-CC-80reAcademy-2.png?expires=1788635700&signature=645c0005b3e8e1cbbff60dc34ab98969e4ddad4a1f40cd1351aaa2ee87652b45&req=dSghEcx9nIZWXPMW1HO4zZe0CRcs1Bf4b3MiIIepj4%2BVbqVKujxP9xVKHdBF%0AGSY3LS8Oxn4f%2BtoUb6Y%3D%0A)

La liste d'activité est disponible sur le menu *"Rapport"* puis sur *“Liste d'activité”*.

___________________________________________________________

### **Données disponibles**

La liste d'activité affiche les types d'activités suivants :

- E-mails envoyés
- Appels passés
- Tâches terminées
- Événements passés

Pour chaque activité, vous pouvez également accéder à l'objet auquel elle est liée, par exemple une opportunité ou un document de vente. Cette fonctionnalité vous permet de contextualiser rapidement chaque action et d'accéder aux informations associées.

![](https://downloads.intercomcdn.com/i/o/714532716/d31ea41f49530f17e2b128b9/Capture+d%E2%80%99e%CC%81cran+2023-04-18+a%CC%80+16.16.25.png?expires=1788635700&signature=f1a64edf48eba9bdbc1c79a9204a0997dabdd130bce16a8c4b4d3a94e73c568c&req=cyEjE8p8moBZFb4f3HP0gMUYUSj6iZ6fLUbTcOg5Ir65sL2BXetgN0%2BcvCXh%0ANO1SGntC3RsWkkAWyg%3D%3D%0A)

Les filtres vous permettent d’isoler certaines activités par période, collaborateurs ou type d’activité.

![](https://downloads.intercomcdn.com/i/o/714534387/efbd8b32bb8e9124807024ec/Capture+d%E2%80%99e%CC%81cran+2023-04-18+a%CC%80+16.18.11.png?expires=1788635700&signature=cce9a38ef20f9f72ee1e75125933638b1296684d5c4270bfe3593300f6feeba5&req=cyEjE8p6nolYFb4f3HP0gDdaniJAo%2FmdSHZf36gmjjXORSlNdbmVixCiw%2FMK%0AWCT70a9LzJUAYT6eDA%3D%3D%0A)

Vous pouvez exporter la liste d’activité au format CSV pour créer des rapports dans un tableur ou au format PDF.
