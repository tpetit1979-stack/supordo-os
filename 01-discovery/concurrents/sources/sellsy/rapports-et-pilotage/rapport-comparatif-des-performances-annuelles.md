# Rapport - "Comparatif des performances annuelles"

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1867547231/359beb1b566f4db6701f9349a2f8/FAQ-Bannie-CC-80reAcademy-2.png?expires=1788635700&signature=f4781c6b7cd2495b4de1a2dcef96d14ff9fd6b9a30c5046c978dd27f506e3617&req=dSghEcx6moNcWPMW1HO4zY27Bpjtx8zMkr4f0RdtmT1qtbnD9MiurwQyDDlk%0ABrpdYmAMM4dag4CVQ%2FA%3D%0A)


Le rapport **comparaison des ventes annuelles** vous permet de **mesurer et d’analyser vos performances commerciales sur plusieurs années**. Accessible via le menu "*Rapports",  "Facturation", "Chiffre d’affaires"  et "Comparatif des performances annuelles",* ce rapport est un outil puissant pour évaluer la progression de vos ventes.

Le rapport est divisé en 4 parties :

- Critères de filtrage à sélectionner pour l'analyse
- Vue générale pour comparer le chiffre d’affaires d’une année à l’autre
- Détail des résultats dans un format tabulaire
- Comparatif des années

> **Attention : **Les analyses de ce rapport se basent sur des données différentes suivant les licences souscrites : 
> - Licences Vente : les calculs se font sur la base des devis acceptés
> - Licences Facturation : les calculs se font sur les avoirs et factures, c'est à dire ce qui entre dans votre chiffre d'affaires
> - Si vous avez des licences Vente et Facturation, vous aurez le choix de baser votre analyse sur les devis ou sur le chiffre d'affaires

___________________________________________________________

### **Critères de filtrage à sélectionner pour l’analyse**

Vous pouvez cibler précisément les données que vous souhaitez examiner grâce aux filtres suivants :

- **Année fiscale** : Sélectionnez une ou plusieurs années pour l'analyse.
- **Groupe du référent** : Choisissez l’équipe commerciale.
- **Période** : Affinez par trimestre, mois ou semaine.
- **Catégorie de produit** : Spécifiez selon les niveaux définis dans votre catalogue.
- **Client** : Filtrez par un ou plusieurs clients.
- **Référent interne** : Identifiez le collaborateur associé aux devis ou factures.
- **Produit spécifique** : Choisissez un nom commercial ou une référence.
- **Devise** : Utilisez la devise par défaut de votre compte ou sélectionnez une autre.

### **Vue générale**

Le premier graphique en barres illustre le chiffre d'affaires d'une année à l'autre, en fonction de votre sélection dans le filtre *Années fiscales.*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1399562087/f7061dd6066074cc47eefd3a74e3/comparatif+perfs+annuelles.png?expires=1788635700&signature=1d6ae4504d966d9a9debb489fadfbbd5be807615912725801877360b26ef1762&req=dSMuH8x4n4FXXvMW1HO4zQB2sANDkISszHT44rmvEogsyEbn1FJRKnLC13rz%0AqMX0J0Y1%2FKOlTOTcntQ%3D%0A)

Ce graphique peut être modifié pour illustrer un certain nombre de mesures alternatives, notamment :

- Quantité
- Marge brute
- Marge produit
- Nombre de documents
- Nombre de clients
- Panier moyen (CA / nombre de documents)
- Panier moyen (CA / nombre de lignes)

### Détail des résultats dans un format tabulaire

Le tableau, juste en dessous du premier graphique, vous permet de comparer les mêmes données. C’est le premier graphique qui pilote le contenu de ce tableau, mais vous pouvez ensuite modifier le tableau comme vous le souhaitez. Vous pouvez sélectionner la *mesure* sur laquelle vous souhaitez effectuer le rapport et la *variable* par laquelle vous souhaitez trier.

Par exemple, vous pouvez générer un tableau du *chiffre d'affaires par client* d'une année à l'autre, mais vous n'êtes pas limité à ces sélections.

Les données sont exportables en format csv, xls et png.

### **Conseils pour une analyse efficace**

Voici quelques conseils pour tirer le meilleur parti de ce rapport :

- **Choisir les années à comparer** : Sélectionnez les années et les semaines spécifiques à comparer.
- **Analyser les chiffres clés** : Visualisez les chiffres clés pour chaque période sélectionnée.
- **Analyse graphique** : Utilisez les graphiques pour comparer divers indicateurs tels que le chiffre d'affaires, les quantités vendues, la marge, le panier moyen, etc.
- **Exportation des données :** Exportez vos résultats dans différents formats pour une utilisation ultérieure ou une présentation.
