# Rapport - Suivi des reliquats restants à réceptionner

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2493222319/56cf51f84dfd3dda39899dc4beea/FAQ-Bannie%CC%80reAcademy-2+-2-.png?expires=1788635700&signature=85a827da991534971d28ea6cc9a6782f3e2f6104e9dfd90ade5f7bcb9edf32f0&req=diQuFct8n4JeUPMW1HO4zaRm1%2FKX7suO5GyYVvbQBjdl0Z8DBnKATtaUN0Fn%0AYXrYou2p4kkjYz8vFs0%3D%0A)

___________________________________________________________

### Objectif du rapport

Le rapport “**Suivi des reliquats restants à réceptionner”** a pour objectif de centraliser et visualiser l'ensemble des reliquats d'achat (quantités commandées mais non encore réceptionnées) sur vos bons de commande fournisseur.

Ce rapport vous aide à :

- Identifier les fournisseurs et les produits ayant des livraisons en attente
- Suivre l'état d'avancement des réceptions par bon de commande d'achat
- Anticiper les approvisionnements et les relances fournisseur
- Croiser vos besoins d'achat avec les commandes clients en attente

> **Bon à savoir :** Les bons de commande d'achat au statut **Annulé** sont automatiquement exclus du rapport et n'apparaissent pas dans les données affichées.

___________________________________________________________

### **Filtres disponibles**

Les filtres suivants sont disponibles en haut du rapport et s'appliquent à l'ensemble des indicateurs et tableaux.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2493224966/b021481813c020f71c73390b1a59/image1.png?expires=1788635700&signature=ca3559e0a39d595553596bd6e9b6e8114862b8fb5a785445b96c23edb6049ff8&req=diQuFct8mYhZX%2FMW1HO4zciNeSoFpLsZU2C93pml5TNP4JkssVYDKwIZRgoD%0ARBCvPEYupML%2FogNsZUY%3D%0A)

| **Filtre** | **Description** |
| --- | --- |
| Type de document | Le rapport est centré sur les **Bons de commande d'achat** uniquement. |
| **Date du document** | Filtre les bons de commande d'achat selon leur date de création |
| **Date de livraison** | Filtre les documents selon la date de livraison prévue par le fournisseur |
| **Statut de livraison** | Filtre les documents selon le statut de livraison. Le statut **En attente** est actif par défaut |
| **Propriétaire du document** | Filtre selon le collaborateur responsable du bon de commande |
| **Fournisseurs** | Filtre les résultats sur un ou plusieurs fournisseurs spécifiques |
| **Type de ligne** | Filtre les lignes selon leur type (produit, service, etc.) |
| **Référence** | Filtre les lignes selon la référence produit |
| **N° du document** | Filtre sur un numéro de bon de commande d'achat précis |

### **Tableau de détail par document**

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2493235897/5921425d02da1220658fe4a650de/image6.png?expires=1788635700&signature=d9e06b51fc5a613421e9fe01fef3a137aa9de705b276baa9802a769adcaad0f0&req=diQuFct9mIlWXvMW1HO4zepO4FNut3RuaVtM0rVM4dI%2FXmSM%2BqcpCsHgeptL%0A1ICOQB3vF5o5HvQAGqU%3D%0A)

| Colonne | Description | Affichée par défaut |
| --- | --- | --- |
| N° du document | Numéro du bon de commande d'achat | ✅ |
| Référence | Référence de la ligne produit/service | ✅ |
| Type de ligne | Type de la ligne (produit, prestation…) | ☐ |
| Déclinaison | Déclinaison de la référence (variante produit) | ☐ |
| Propriétaire du document | Collaborateur responsable du bon de commande | ☐ |
| Fournisseur | Nom du fournisseur | ☐ |
| BDL achat | Numéro(s) du ou des bons de livraison achat associés | ☐ |
| Detail BDL achat | Informations détaillées sur les bons de livraison achat (Date du BDL + Quantité) | ☐ |
| Qte commandée | Quantité totale commandée sur la ligne | ✅ |
| Qte réceptionnée | Quantité déjà réceptionnée | ✅ |
| À réceptionner | Quantité restante à réceptionner | ✅ |
| Restant à livrer des BDC clients | Quantité restant à livrer sur les bons de commande clients liés | ☐ |
| Restant à livrer des devis | Quantité restant à livrer sur les devis clients liés | ☐ |
| BDC clients | Numéros des bons de commande clients associés | ☐ |
| Detail BDC clients | Détail des bons de commande clients liés | ☐ |
| Devis clients | Numéros des devis clients associés | ☐ |
| Detail devis clients | Détail des devis clients liés | ☐ |

> **Bon à savoir :** Les colonnes **Restant à livrer des BDC clients** et **Restant à livrer des devis** permettent de croiser votre besoin d'approvisionnement avec la demande client en attente. Elles sont particulièrement utiles pour prioriser les relances fournisseur.
