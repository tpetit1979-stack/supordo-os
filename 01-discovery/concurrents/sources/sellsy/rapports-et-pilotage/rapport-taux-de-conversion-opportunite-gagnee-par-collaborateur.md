### **Accès au rapport**

Vous pouvez retrouver ce rapport dans le menu *"Rapports"* puis *"Taux de conversion opportunité gagnée par collaborateur"*.

Ce rapport vous permet de retrouver le nombre total d'opportunités, les opportunités gagnées ainsi que le taux de conversion par collaborateur. Il vous offre une synthèse sur les performances de vos équipes commerciales et vous aide à mesurer le taux de closing de chaque membre de votre équipe.

### **Filtres disponibles**

Le rapport propose plusieurs filtres pour affiner vos analyses :

**(1) Date de création** : Date de création dans Sellsy - filtrez selon la date de création de l'opportunité dans Sellsy

**(2) Date d'affectation** : Date d'affectation dans Sellsy - filtrez selon la date d'affectation de l'opportunité dans Sellsy

**(6) Groupes de collaborateur** : sélectionnez un ou plusieurs groupes

**(7) Collaborateur** : sélectionnez un ou plusieurs collaborateurs

**(8) Catégorie de la source de l'opportunité** : filtrez par catégorie de source

**(9) Source de l'opportunité** : filtrez par source spécifique

**(10) Pipeline** : sélectionnez un ou plusieurs pipelines

Ces filtres vous permettent de comparer les performances de vos collaborateurs selon différents critères et d'identifier les meilleures pratiques.

___________________________________________________________

### **Indicateurs clés**

Le rapport affiche les indicateurs suivants en fonction des filtres appliqués (1, 2, 6, 7, 8, 9, 10) :

**(3) Opportunités affectées** : Nombre d'opportunités affectées

**(4) Opportunités gagnées** : Nombre d'opportunités gagnées

**(5) Taux de conversion** : (Nombre d'opportunités gagnées / Nombre total d'opportunités) × 100

Ces indicateurs vous permettent d'évaluer l'efficacité de chaque collaborateur et d'identifier les axes d'amélioration.

___________________________________________________________

### **Graphique - Performance par collaborateur**

**(11) Graphique en colonnes** : Nombre d'opportunités gagnées par source et global

Ce graphique présente les performances commerciales selon différents axes d'analyse.

**a. Choix de l'indicateur :**

- Nombre d'opportunités gagnées
- Taux de conversion (statut *"Gagné"*)

**b. Choix du regroupement principal :**

- Collaborateur affecté
- Groupe de collaborateur
- Date d'affectation
- Date de création
- Source
- Catégorie de source

**c. Choix du regroupement secondaire :**

- Global
- Catégorie de source
- Source

Cette visualisation flexible vous permet de comparer les performances selon de multiples dimensions et d'identifier les collaborateurs les plus performants ainsi que les sources les plus efficaces.

___________________________________________________________

### **Liste détaillée des opportunités**

**(12) Tableau récapitulatif des opportunités** en fonction des filtres

**Colonnes disponibles :**

a. Identifiant de l'opportunité
 b. Nom de l'opportunité
 c. Date de création dans Sellsy
 d. Date de passage en statut *"Gagné"*
 e. Montant potentiel de l'opportunité
 f. Pipeline
 g. Étape du pipeline
 h. Société liée à l'opportunité
 i. Collaborateur affecté
 j. Lien vers l'opportunité sur Sellsy

Vous pouvez cliquer sur le lien de l'opportunité pour y accéder directement depuis le rapport et consulter tous les détails associés.
