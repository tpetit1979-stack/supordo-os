# Rapport - "Rapport d'activité CRM" par collaborateur

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2155917769/13d8fe33fdd285df53a289d7cbd2/FAQ-Bannie-CC-80reAcademy-2%2B-282-29.png?expires=1788635700&signature=fdf00486148598dd47f151876224c8ee05d1475647b9bd78f657180b2289369f&req=diEiE8B%2FmoZZUPMW1HO4zZfjnWO5D9c%2B32XVERjW8XLn%2F1lZbQXWH%2BdTxCQp%0A7MnkFbsksowZsymI1Ac%3D%0A)

Rendez-vous sur le menu *"Rapports"* puis sur *“Rapport d'activité CRM”*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/482005617/076ae94624e4c418d2e75928/541a318e-1612-4a84-a55c-5f1a9ed1720a?expires=1788635700&signature=fdf4a7789970befa94bcf9ccf772b6696a8aa90e34d77ccba2ce987401184249&req=cCglFsl7m4BYFb4f3HP0gKWepxzaXpcrGvGDe%2FKlGpa0TzX0iHmbs6CzAvJU%0AF0NPO0h2z%2F5d0yMlgQ%3D%3D%0A)


Sur l’onglet *“Collaborateur”*, vous aurez la possibilité de comparer l’activité de vos collaborateurs en fonction des différentes activités que vous pouvez choisir de cocher ou non.
​

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446340358/e1a988679a4a6a8411c77bcb/XA84bK7Pr2tFu6BohAou858Oshzled4rCfRk_ehBEe2DFyRx97ShcWb4K6cb0jzV8lD5CWdDh4ZAqow_47cZBYCQFivScAiYGL2cR8hY7BrW_bBsUVHmaE3hJO_Rfi547c92bLFL?expires=1788635700&signature=ce82ff6aa76c29b19d0ad38f62d49bd91b95865d735841994f5c2041c09ea37a&req=cCQhFc1%2BnoRXFb4f3HP0gBHulS46hx0K0j8BhVqf%2FYdDypAM7x2qgDNNjEMw%0ATBJY%2BD19A5raA0Islg%3D%3D%0A)

Vous pouvez décider d’afficher tous les collaborateurs ou de comparer uniquement les collaborateurs d’un groupe.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446340369/0bfff6a2a822f4d36e8fa878/Ldd5teUcBEbkmqE_CFZSeX79dLcHLexw_8F7KY055lpPbN8aS6J3sWM3_wBA9Gdnu1jPGs5dgjRIFZ22jz4VqbcD3KrzS9bQ7lWMsf4Fw9suxMQMZMSpoUUioHhCaFAKcYHE5J1Q?expires=1788635700&signature=2cfd1c883962291bacd6909f7f508e4f65f02fa5db15748992e5a2a52962a5eb&req=cCQhFc1%2BnodWFb4f3HP0gN%2FihZ4M6r3C0OgVQ%2FDAy%2BO3uf3wh1fRGOG5YdBA%0AXsjkDgbJ71zTzsOY3g%3D%3D%0A)

De plus, l’affichage peut aussi être personnalisé selon une période donnée.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446340380/6a3594054fbd322a3994ab44/ohgiu3Fkh9E2O1uz4Lj2dvyIXYHbbuHtzXFvw2kUbD2k4oIQz2GnbThgEmTNbXIuPrdh2BNKjNCUWJqSr9bnK_BLn_SuIeHjFhm4MdD5J9A2Df3RVjxHK0titN1BY94vYU1GIMk1?expires=1788635700&signature=a65b06fe12cb69f1e65ab2dd94c3fa6dfd9e988a97802f8b31b8e574d1ae988c&req=cCQhFc1%2BnolfFb4f3HP0gKpe%2B2bb87Y7Ac1lDoM3sFi3uwfcGWUJMqXkr6lq%0AvePEKAvNSsbVg0irWg%3D%3D%0A)

Cette vue est également disponible en vue liste.
