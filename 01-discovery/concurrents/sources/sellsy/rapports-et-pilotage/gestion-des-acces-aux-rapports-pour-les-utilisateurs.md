# Gestion des accès aux rapports pour les utilisateurs

### **Modifier les privilèges d'un profil**

En tant qu'administrateur, vous pouvez donner accès aux rapports à l'ensemble de vos collaborateurs en configurant leurs profils de privilèges.

Pour accéder aux profils de privilèges, rendez-vous dans *"Menu"* > *"Réglages"* > *"Profils de privilèges"*.

![](https://downloads.intercomcdn.com/i/o/759926602/882f14e06a7f43a93dc50456/65ef9d46-b824-40f4-99be-241e44451fa8?expires=1788635700&signature=042d631415251340c73efa0e62597f9342ecc2c5a08c61b59d744e7d59d68b88&req=cyUuH8t4m4FdFb4f3HP0gIrNDAoONMBtx2oLaSZLRK6bKH4%2BQp%2FWvqde3711%0AXCotgfxmi4ohRjoyKA%3D%3D%0A)

Dans le tableau des profils de privilèges :

1. Identifiez le profil pour lequel vous souhaitez donner accès aux rapports et au tableau de bord.
2. Cliquez sur les 3 points situés à droite de la ligne concernée.
3. Sélectionnez *"Modifier"*.

![](https://downloads.intercomcdn.com/i/o/759926608/07b87024ac67e528b7c39bc8/1fe21071-fd5f-4f2b-a2f4-de86afc326ea?expires=1788635700&signature=f3d418d330ae8bb18c88787c7632f5e8c61fffe6cf46c31ed813b6b2a7185918&req=cyUuH8t4m4FXFb4f3HP0gK64gFqHHMV0GfrREPcaGD%2FlIrd9hJKDzL8VKZ3g%0AnX6lGHBUeJi56dUZxg%3D%3D%0A)

___________________________________________________________

### **Configurer l'accès aux rapports**

Une fois dans la modification du profil :

1. Affichez la section des privilèges liés aux rapports.
2. Cochez la case *"Pour tous les autres rapports"*.
3. Choisissez le niveau de visualisation des données adapté aux besoins du collaborateur :
- **Uniquement les données issues du collaborateur** : le collaborateur visualise uniquement ses propres données.
- **Toutes les données** : le collaborateur a accès à l'ensemble des données de l'entreprise.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2154962948/23b3eaf82431112e769bd3918008/7292e23c-7e1e-4a50-b9c0-738f8d81df66?expires=1788635700&signature=5ccd3a6239aae115ff181eced1cd1abd8d390529b6cdb885fa9df9c569f5de4b&req=diEiEsB4n4hbUfMW1HO4zSLHkGeEK6DEHm63WnH8Fd8QhPShnFKLt0TUTBVi%0AiQJB81wefEnrDZjPTyM%3D%0A)

> **Bon à savoir :** Pour que les collaborateurs aient accès à leurs tuiles personnalisées avec leurs propres données sur le tableau de bord, il est essentiel de cocher *"Pour tous les autres rapports"* en sélectionnant *"Uniquement les données issues du collaborateur"*.

___________________________________________________________

### **Nouveaux collaborateurs et collaborateurs existants**

> **Attention :** Lors de la création d'un nouveau collaborateur, ses privilèges concernant l'accès aux rapports sont automatiquement attribués par défaut.

En revanche, pour que les tuiles soient accessibles aux collaborateurs déjà existants, vous devez sélectionner manuellement ces options pour chaque profil collaborateur.

___________________________________________________________

### **Accès global aux données**

Si vous souhaitez qu'un ou plusieurs collaborateurs aient un accès de visualisation aux données globales de tous les rapports, sélectionnez *"Toutes les données"* lors de la configuration des privilèges.

Le collaborateur aura alors accès à la globalité des données de l'entreprise dans les rapports et le tableau de bord.
