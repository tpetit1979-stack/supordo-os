# Personnaliser les labels de tâches

### Gérer vos labels

Rendez-vous sur la page “Réglages”, puis sur “Tâche/évènement”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446326877/85b997077c74bfa295b3ab2b/je1Kg0eb6N5eL8FownwayAmamGJnbJfPtLHRr2WjqQKYYYaoQu0BGBbkLr636IJCWV13NWi1BAQU_fTorcAxbRGetNxovzBaMfZH-zNrDIBDKkoANLNbPaILwZhBSBhlYc-ybh7W?expires=1788635700&signature=d43b23d18a45bc5938bcb4efa6114ff304d5123ba4167762b98d2ffa6e3d2d13&req=cCQhFct4lYZYFb4f3HP0gP4iEZyd1fmnWf3cLR4gAC4InCoinNHr8go8dhra%0ASe3g5%2FK7oqY8DdSsew%3D%3D%0A)

Pour chaque tâche et/ou événement disponible sur la liste déroulante, vous allez pouvoir créer ou éditer des labels correspondants en cliquant sur “Modifier”.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446326886/fc4d675740ff192b39976518/A5eWd8IaZfeJaym13f8_dqqfXA6lmiQmOcyFRFnDJIVjTNW1QD0kjUlBLqAQOg5WAxFXxfGklPwOGg4_QWOmcEu5URnPuhMvvilrI023-HQWFmABO5GcjWFlnMF8m8ir2RFzub9g?expires=1788635700&signature=75afff99fbfded22a3788827c327233ca92a9ec4be6649707c433de91b38da35&req=cCQhFct4lYlZFb4f3HP0gCadQQGacR6ff%2BM6kU1ODk8fhImaqhHRk1Fpfe%2Be%0AKsITZTs6zG47YoXiyA%3D%3D%0A)

Pour les tâches ou événements , vous pouvez par exemple créer un label “Relance devis”, “démo produit” ou “rdv externe par exemple”. Choisissez une couleur et le type d’activité lié (tâche ou évènement).

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446326893/f7ab6ee3dfa8760cbb2029a4/Bv8A5ATrZZgW-6_0n_befu1vFaYwYK7Fax2JgirBfiXA8Vl_lNAwM5G3d8FV-XueM3rzZnJKgb8aB_hgxJb28m7nJ3XlAti2fOtzDtOXbtUtqVpO1gbK9mdCvdaZX2zRDpGPp-fg?expires=1788635700&signature=af44a5c864368ecab3d6f644a5df7297562578a50881813678bcdfb75c683f0b&req=cCQhFct4lYhcFb4f3HP0gEoxuYiHCknsc1rS1Z6mb0IWT9xUZWgdxWt8rpph%0An%2Bl%2B%2FLOZShE5ozu9GA%3D%3D%0A)

Une fois créés, ces labels seront disponibles lors de la création d’une tâche ou d’un événement.
