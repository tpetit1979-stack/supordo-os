# Personnaliser les labels des évènements

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1925530176/1da86fc9c10a32d3cf861d4133f1/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=c47fe1af8fc2090fe399725513bd4a4bd39cd5057bd8d4dc9c7813304406e01d&req=dSklE8x9nYBYX%2FMW1HO4zWGf5%2FxBDJUOCvnk7d4Xd1iu42vIZg%2FQuTqADhFI%0AwXNKHvTc8ErMV34r3GQ%3D%0A)

Sellsy vous propose des labels pour classer vos événements dans l'agenda.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446324274/50d6cc47ecf72302e09d3cc8/Vw7r1mDzwlhAPW-yMSlgysYLvWOMMF3WxRD1gBXFjpdxXrrZiYhDdhwcWTUumRtGs90CBDteHuN2d1Q947eUKcvZV0HdzdkPZzrEbqDxgHiDCtnXEaB4o8WCErPBRx0liSh873Jq?expires=1788635700&signature=f36a6cd227611f882039da260fa7063b7f7281a0fe9b6d11cbd807e1d8bfa68b&req=cCQhFct6n4ZbFb4f3HP0gJmLfOVQft%2F3TmGK6lqbbyyrvTtrK56%2FYy%2FPVLa4%0A%2BmW8RUjIZHXsFeXiHQ%3D%3D%0A)

Chaque label peut être associé à une couleur, pour vous aider à rapidement visualiser vos différents types d'événements dans l'agenda. 

Ces labels peuvent être modifiés pour mieux s'adapter à votre façon de travailler.

Pour changer les labels, rendez-vous dans *Menu > Réglages > Tâche/évènement*. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446324284/22ddc4d677bc5ccbb42163da/jBWvPtrSOj9IXAj65gloKEaoroFk0t0dNOuZpwSg6nbdhQXHhHFiKMeIzZx8amgjDQdfgniMrQciVG_3OfiRCNNszds2-kGLaMwq2IImkCOTRr1Nso9e_RCsEM3xTpyk4ai9fNlN?expires=1788635700&signature=d5f5e905c0a9e2e2abf615e450c0a8cdcac73c58f7b67cd5630eff99de4dc5b4&req=cCQhFct6n4lbFb4f3HP0gIjM3Itq4MJEgaT8JN6LcDYBB4QMr0Avbfwe%2BoJS%0AGh8Ay5ZJOO2PYYQvhQ%3D%3D%0A)

Cliquez ensuite sur *"Modifier"* à côté de *"Label des tâches et événements"*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446324289/dcaf6c487cbe925a73b7ac74/hXAiYbcpuelNWVuvUHHpSp1JQW8qdqSuvmTVfdCp4mJu0exdRIYUeXWOYA7omjftYQi1MjldtUgiSNSYe4xSo-D06y8QPqM4PpBKD6zO_GrRAoA_wzGMF7I8dG45769Jkgiuecw-?expires=1788635700&signature=3861b0181eed463b7d0a1b085eb2b8db6878d6a22b80ca497a96a9066abb287b&req=cCQhFct6n4lWFb4f3HP0gPzB3A1ZZhk%2Fpqq13j1jIQZTCQ%2BZPykpX7GLFJWo%0AcssFLfm2eW0hdSH1Aw%3D%3D%0A)

Vous pouvez alors définir vos labels et en changer l'ordre et les couleurs.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446324296/65898cfa9fa40b275470fdeb/v05SBVzDbc-JgvyV6O82whkrU_Iovb0_qNwbx7pUD7loOMsWMWeCM9a0XJ_ms8gD_OmzKKKsjOsxwUHTW0S08cPK0WFL8HNbobroVCom1BgNuNxqhAVOdB62jCJx-9LvsH4RUuvZ?expires=1788635700&signature=a8e4db48ea7ed530971c88ed69c7611a74514defbc053ab3eb8070848c4b512f&req=cCQhFct6n4hZFb4f3HP0gD7LoLRunWB%2BRPKcuI%2FKX4sLXwOXgoDwNC00xFui%0An8qEFGwSY9%2Fg2dGGJA%3D%3D%0A)
