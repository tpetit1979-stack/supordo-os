# Créer des modèles d'emails personnalisés

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261779510/91fd7169804fe2da2bdc75909551/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=589eae1b8306a5970facf093957a23f877dd785897f21f9d694f9cec2efd670a&req=dSIhF855lIReWfMW1HO4zeZFqh2fusmOBhyN2TxaLGB5%2BOhYEzVgraAH2QRl%0AtBSZFIOqW%2BuBErk0Gk4%3D%0A)

Sellsy vous permet de définir des modèles d'emails personnalisés. Cette fonctionnalité est très utile si vous souhaitez par exemple :

- programmer des relances par email
- utiliser des modèles d'emails différents selon le type de client
- définir des modèles dans plusieurs langues

> **Bon à savoir :** visionnez la [vidéo](https://www.sellsy.com/sellsy-academy?ms_url=%2Fcourses%2F6b51f1a9-6ba4-4fd6-90bb-645dbe1e6ca4%2Fstep%2Fbbf7b8b6-3229-41ab-b99a-a11b3632249c) suivante pour en savoir plus

___________________________________________________________

### **Créer un modèle d'email**

Pour créer un modèle d'email personnalisé, rendez-vous dans "*Menu" > "Réglages" > "Mes emails personnalisés"*.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1231755480/0ab075dfb30cbde9464f54dea5d7/image.png?expires=1788635700&signature=f95b860e3c6c6d5aab930aae0e533712af9090cac67159ea3665879aad311818&req=dSIkF857mIVXWfMW1HO4zbtAKADBZMVs9uWhGaBL0%2BBLN4Y9X9fmkCuWN6dc%0AeML31LfNCetbtL%2Bm%2Frc%3D%0A)

Dans la page qui s'affiche, cliquez sur *“Ajouter un modèle”*.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1231754590/c92ec9f26a7feea5decb9a60d88d/image.png?expires=1788635700&signature=c0e1deb157854187250e3f7810edad84d6bc5e28f3b523c2bf8ef373f2c09f80&req=dSIkF857mYRWWfMW1HO4zUwM9LGDObfgkiJOEDbcZf8ay0wLVJzw%2F%2BvL%2FaDR%0AElK5qT0LsMFl1r9GeRs%3D%0A)

Entrez le nom du modèle, l'objet et le message de l'email.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1269603768/8476ca79d905241006f1778e39e2/image.png?expires=1788635700&signature=2848d75e22228a8461190a2d35d945c81ab32dccd9011cc5b138101ce13584e5&req=dSIhH89%2BnoZZUfMW1HO4zXF5vZhk%2BH8DB%2Fg0Ee2JiueiBEIm7k1GKKYZDscZ%0AAGwoBYfPgcoCO18GmLw%3D%0A)

Dans l'objet et le message de l'email, vous pouvez ajouter une variable afin de personnaliser chaque email avec des données liées au client ou des données de votre compte. Dans le menu déroulant *"Insérer un champ"*, sélectionnez le champ natif ou le champ personnalisé à insérer. Par exemple le nom de votre client, le nom de votre société ou le montant d'une facture. 
​
Vous pouvez aussi ajouter des champs intelligents, pour que l'IA rédige votre email ou une partie de votre email suivant des instructions adaptées à vos besoins. Pour en savoir plus, consultez l'article [Modèles intelligents avec IA](https://intercom.help/sellsyprod/fr/articles/10211697-modeles-intelligents-generez-des-messages-cibles-avec-sellsy-ia).

> **Bon à savoir **: 
> - Pour créer ou modifier des champs personnalisés, suivez les étapes de cet article : [Créer des champs personnalisés](https://help.sellsy.com/fr/articles/5876490-creer-des-champs-personnalises)
> - Pour ajouter une image dans un modèle d'email personnalisé, suivez les étapes de cet article : [Ajouter une image dans un email](https://help.sellsy.com/fr/articles/9329578-envoyer-un-email-depuis-sellsy#h_2922151cee)

### **Utiliser les modèles d'emails au quotidien**

Lorsque vous envoyez un email, cliquez sur le bouton *"Utiliser un modèle"* en bas à gauche de l'éditeur de texte.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1231787015/a6b0dce23024a13c4f87fd517834/image.png?expires=1788635700&signature=28babe130c846e46d35ab31b22bc8cce0e00aa23befeca19dc6ccb57f022a42d&req=dSIkF852moFeXPMW1HO4zQor0i5mRwkk%2FKx7t%2Fd%2BzsKsUNKFYIw4rJ%2Bl4agx%0A48cMN7NXDLPoaSdj3hw%3D%0A)

Sélectionnez le modèle que vous souhaitez utiliser, puis cliquez sur *"Insérer"* pour l'insérer dans votre email actuel. 

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1231788631/9e8e6b68af87ca882539c1acb1ec/image.png?expires=1788635700&signature=6353b3cdc864cc41c57a5553acb2b207c16ceb09302b86307332d781d577e58b&req=dSIkF852lYdcWPMW1HO4zQJSsqmW3VYCDZeluK0K%2BOz2shmEZncEX%2FvFGCgO%0A9us0zKIuuNXHt4B9f5w%3D%0A)

Les variables choisies seront automatiquement remplacées par leur valeur dans l'email final. 
​
Si le champ utilisé est vide (aucune valeur n'a été renseignée), le nom du champ sera ajouté entre crochets dans votre email. Ceci vous permettra de renseigner au bon endroit la valeur dans l'email final.

> **Attention : **les variables utilisables dépendent de la fiche depuis laquelle vous envoyez l'email. 
> ​
> Par exemple, si vous envoyez un email depuis une fiche client, seules les variables utilisant des champs société/particulier pourront être remplies. Les variables utilisant d'autres champs, comme contact, document ou opportunité apparaîtront vides.
