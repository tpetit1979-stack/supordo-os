# Utiliser l'agenda Sellsy

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1925514523/b65f17129d62f610762a4130e0aa/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=00581b48f4428f9d066524fc06e78d748c19f2a6ff6f9a524e49226b2c85f24a&req=dSklE8x%2FmYRdWvMW1HO4zVJP%2BbaCIMrDH0GWioRqmTGn%2FEScwXuMoAmZCWjm%0AJyrwX1mlnG%2F%2Bg8b4q0U%3D%0A)

Le module agenda Sellsy va vous permettre d’organiser votre emploi du temps de manière collaborative avec l’ensemble de votre équipe.

___________________________________________________________

### ​**Accéder à mon agenda **

Vous pouvez accéder à votre agenda depuis le menu en haut de l'interface, en cliquant sur l'icône agenda. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446322346/86bb62b7eecd102f29bec468/5tJLcoyHYp5W_WCrDDqQhBimRfFPJ76TB5W_45OhQ4_LpkwSHrIo3_jKHkmBs78L5j4dly1Kh0QxeItkj_JrNm1tLO_OKvf-GxE3I7YbT7zW5GrMYFIRX7isSpDfmV2iRsFMjLoz?expires=1788635700&signature=ae5f59333db21e2de965433d8ebe2fab1f21538c332f6c3ceb13ab421dab4421&req=cCQhFct8noVZFb4f3HP0gGZf0TDkPstolJ9fmeEMzHStpgmNClXiKdHx5kS9%0AWGE4j7y8hPRncbQzfQ%3D%3D%0A)

___________________________________________________________

### **Ajouter un événement sur mon agenda **

Pour ajouter un événement sur l’agenda, vous pouvez cliquer directement sur une zone précise : un jour ou une plage horaire, en fonction de votre mode d’affichage (Mois / Semaine / Jour).

Vous pouvez également cliquer sur le bouton "*Nouvel événement*" en haut à droite du module Agenda.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446322360/35b93b23283867a72f021872/BjewMYz1TDp6B7ko-I1B3l9uEIUU8V8-Ugkf_cAqEbKbGw8qBzwGQzG5ldEc9Fb2MvfpeRR3Psc2VuO3qXHdJSPaYrhrWS5UQU88r_8-JGzKsPgSKGse2BSYLHlYhzQJ9LY6JwpQ?expires=1788635700&signature=a2d96562cc0a5dcb409437b8f1829726a722e20b26781955d6a6525d6ff6af28&req=cCQhFct8nodfFb4f3HP0gMjqNnNA21YvwzoytZSJ2C6pZKb5S9EWPmkYFWPF%0AA9yjfjhA%2B9IqeA%2BETg%3D%3D%0A)

Une fenêtre de création d’événement s’ouvre, vous permettant de configurer votre événement. En choisissant des collaborateurs, vous leur donnez également accès à cet événement.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446322368/ccfa5f3d5bc6b3afdcda3cd1/zs1Ym-QlYcAjEAHNYLi79wz5MfIJsOdTsaYq1FOjdlZ92CThLM7083A3FdlIlcZfi_gyHeAPEqNy3WCjBzEnlbcoear8cKc0TbPgQ-uJ4w8sbLWLNT1XXYhw4kJgV3L9Zozmsdr_?expires=1788635700&signature=9afff333528a371f0fb0981b8a38a30551334c8e4ac437aea86c39980b77dd2d&req=cCQhFct8nodXFb4f3HP0gDusVXidsN6lOgDXsVzpv3oLr16v79FWX4DY7k4Q%0AMPxIVQP2YTaYq5eayw%3D%3D%0A)

Une fois enregistré, votre événement est disponible sur votre agenda.

___________________________________________________________

### **Consulter un événement / modifier ou supprimer un événement**

Pour accéder au détail d’un événement présent dans votre agenda, vous pouvez cliquer sur l'événement. Le détail de l'événement s'affiche dans le panel de droite.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446322382/465700daf3bd93d1fe26c82e/ii0Sz7m_-mbw2ji74wLoOyCMw1l939gCriDtF2PAgJxuhrZ1-XUia_AwcwITEEU7uqOr953o22Y80siruPY9cTadjDHLK2BWInJN4TQhX4JU5yAqnpFhH3XvqOEEKbWdRqtiHvyg?expires=1788635700&signature=c60c1c731a392bb7edf2ebe26e2ebc626620ef2e38f8c9477d2593fb37c0db15&req=cCQhFct8noldFb4f3HP0gOjD9ysKw0OdT78PDgRK5%2BY5%2Fq68f85xBwq9HD1j%0AJ77g4VohfCoylZx79A%3D%3D%0A)

Pour modifier l’événement, cliquez sur le bouton bleu "*Modifier"* en bas à droite du panel de détail de l'événement. Pour le supprimer, cliquez sur “*Supprimer”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446322399/cb084baf7f1a1b06c2c015a4/1jkRTv5pEObWxFUHJ7sBii0UR2z9W6UZUhRsMPDHgaqO7rOYpdZ6e7miU_yaCEI70PjeIJcqDEJqmiE40SmMF9zxlL5atNwLN_4gqCIrzuLowDU4RcUSwymN4tWQNivOwt5BfgFq?expires=1788635700&signature=fb210095e3514ce420c79462fec7f5f57288f68a362e97cdfdd8d843ce6fa039&req=cCQhFct8nohWFb4f3HP0gGpKf0QMwdKDtibtjpTvxInvU7HavAiCTktEHSZb%0AnJJnfeUY7S6kMMEodw%3D%3D%0A)

Bien entendu, vous ne pouvez modifier ou supprimer que les événements dont vous êtes le propriétaire ou les événements sur lesquels l'autorisation de modification vous a été accordée. 

___________________________________________________________

### **Connaître les noms des participants à un événement **

Pour connaître les différents participants d’un évènement, vous pouvez passer votre souris sur l’icône à droite de l'évènement : 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446322402/8f8f729b289b240cc8f34e97/Zs5V4Y9DAh00C3dhagZnkCu68I6u-xMYr896R5RIqB8HwvL6xn8ze2RyweqUpU2ivN7xhvjnRzAhog5lxIINfzBFGcw6gPicMFRHhZ9AQ7RgTnieIXsKNuTN43RP6TYO5rE8kNhe?expires=1788635700&signature=e44f7d3379682b5d23aa8a62cc5f43417927ce76593ff28dc288c2ff672d255e&req=cCQhFct8mYFdFb4f3HP0gIF5ozB6AluM3ya%2FcAIy%2F6lm9jzpEQLTcoV7TARU%0AqkXb6bNrbNqMeU0yKg%3D%3D%0A)

Si l'icône apparaît, alors il y a plusieurs collaborateurs qui participent à l’évènement, sinon vous êtes le seul participant.

Les différents participants sont également mentionnés sur le détail d’un événement (sur le panel de droite).
