# Créer une signature email

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261778485/8909e8f698b42406f9ae15c4a4da/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=ee9b096e01b442a995c2b148e0eb97d1d73dcb2ba2068b92cc41c59a86863fc1&req=dSIhF855lYVXXPMW1HO4zbIpr9LjgV%2BCaDibhjSiV8FQscMUGoy9AP7JYhJ0%0A2df1DE10iw5RkO7hWQE%3D%0A)

Créer une signature email personnalisée permet de rendre votre entreprise plus dynamique et attractive. Une signature bien conçue peut également générer du trafic vers votre site web ou promouvoir un événement spécifique.

Sellsy vous propose plusieurs options pour créer et gérer vos signatures emails, afin de répondre à vos besoins spécifiques et à votre niveau de personnalisation souhaité.

> **Bon à savoir :** visionnez la [vidéo](https://www.sellsy.com/sellsy-academy?ms_url=%2Fcourses%2F6b51f1a9-6ba4-4fd6-90bb-645dbe1e6ca4%2Fstep%2Fbbf7b8b6-3229-41ab-b99a-a11b3632249c) suivante pour en savoir plus

### **Option 1 : signature email au format HTML **

Pour paramétrer votre signature HTML, rendez-vous dans *"Menu" > "Réglages" > "Mes signatures".*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/477966855/16ecd3661b4bb59b9b00ef13/o-qBP5k6KXjjL84KHrzh4Pexz0I9SP5l5oFdepBwbRTTwWr5MrMYfZ9oUshvBo77zHWUfq3NIPuaik-SCh6F6rUGX_zAYYQ_OLmFGkE4qTvjopA6162CNKFAYOxjjHygTtxt4kQc?expires=1788635700&signature=a9234c1fb7118b13d83ccf72707c3fe1c6276160772760920a228dc6f1011784&req=cCcgH894lYRaFb4f3HP0gB6L1XCpEB79WK2k2W4bXUZKx45BqtKYDILzfWnt%0AZhpVW1KqvLNHZKcOhA%3D%3D%0A)

Cochez l’option “*Gérer manuellement la signature” *et cliquez sur le bouton code. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/477966862/4036e1db89c8c2bbae534599/kiityutwa2gVxWhvaP5TK3zJunOe4lTKxilUQkwMx0yqUle1wFOyJXP3DnfS0n60uHfgCQ7D1sHr2LC_56iSzfAiBsdmw1qoHilUMM1TyHuVpyDUoBQEu-MO4N422Jb7Dni9ZHBW?expires=1788635700&signature=a063f751408c527de2ac08832a086a2ea6605187c17850c604fee61dcb94b2b8&req=cCcgH894lYddFb4f3HP0gCaCPSkAVo5a0h1H1OPjbw%2FysVRnuWpuXCmnzX0I%0AGQG3E5s4zOYMyddPUQ%3D%3D%0A)

 
Ensuite, collez votre code html puis cliquez sur *“enregistrer” *en bas de page. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/477966872/8525379c7f3fd80c3b0444d5/kDbh-EHDgi76OWecscZ28KkFt60qeJsLQWpK5dBz2YuJXl8I2g0xJBJw_gQ6HBMEW96MyCW4vn7tTOoz6TwbKRuI8q4xw0J1FkZgoIAPpFpEBNxR1eL77U9BT17cO9n1OEvFOyBb?expires=1788635700&signature=8c79acaf0e78239eed1fef9b59d68ddbf1146c668f45b4d8b25ba82aaa7abb96&req=cCcgH894lYZdFb4f3HP0gGr5sNr4JrMYg0MkWmKH%2FOyRbZXuc%2B34XDfkl7Xl%0AnmWCO9jzXadlLg%2F16Q%3D%3D%0A)

Votre signature HTML est maintenant configurée et sera utilisée dans vos emails envoyés depuis Sellsy.

> **Bon à savoir :** cette option est idéale si vous avez déjà une signature créée par un graphiste ou générée par un outil externe. Elle vous permet un contrôle total sur le design et la mise en forme.

### **Option 2 : insérer une image**

Si vous souhaitez directement intégrer une image en tant que signature email, rendez-vous dans vos fichiers.

![](https://downloads.intercomcdn.com/i/o/499828642/dfeaa00b60ae7be0ea97603d/Capture+d%E2%80%99e%CC%81cran+2022-04-20+a%CC%80+09.28.37.png?expires=1788635700&signature=ab7a86fc295b0a3e65d2e512a4747516b07ce5d6456c4a7cf38f8be0b8907a3f&req=cCkuHst2m4VdFb4f3HP0gI5ueYNxmn2qRQUTyHFoH9S8xXVBGorFvzSqL0ey%0A2ydQCWBPfAmS6fJk1g%3D%3D%0A)

Déposez tout d’abord votre image dans vos fichiers Sellsy en cliquant sur “*Ajouter un fichie*r”. Ensuite, cliquez sur le bouton de partage à droite de votre écran.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/477966885/0882f585a74a7c456a3660f7/D7xUhbAmFHX182vtrbIdvq01vaD5wKMg34BT9BRvSNUzyFEH9JdnyYKEb5Q_ENxF8sq_GpRiimtSNm9yumgmgLcL1zb_hDHNJOIeuVHfGQEjR_eTt6J86fpokjHEngazEWFPC7MN?expires=1788635700&signature=6d5a894e24ad78afd1bf832690af0e863bfc229a39d9f60fb181d8d567539a1f&req=cCcgH894lYlaFb4f3HP0gL2KhKdpc%2F5%2Bi4uZANSQokHHD0Dpenw68dEj8fGV%0AVY3Se6PN8%2B8on5Cu2w%3D%3D%0A)

Une fenêtre s’ouvre avec un lien. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/477966893/9b1ce55592de125b647ecb09/UlQ06kE3yJ4YgRg8wtBdCV5UAZm32rLJKhAzosZLe-pXEhwrOGOtpm0RQIfxcf6xwLCyFCE_bbtWYIbXqV0qPeVzS35QwG0DF1L5Py4YCFMVeoIFY5dWICqsF-LVywSNrIstRIcW?expires=1788635700&signature=cdbf6cd710aa4b74f2235ea2cc36f8829040a116dec11825e4a8428821e88f95&req=cCcgH894lYhcFb4f3HP0gPlUFwHOjZFZ8FjMh0e1Ss2QNkeqONgAAeeUG1sH%0A%2B%2FFboXWI7Ub6%2BO7qOg%3D%3D%0A)

Copiez ce lien puis rendez-vous dans "*Menu" > "Réglages" > "Mes signatures".* Cochez *“gérer manuellement mes signatures”*. Ensuite, cliquez sur le bouton image et collez votre lien. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/477966896/ba53b3062994934a2be3f940/xtcAjVx_xxye2corraMWKxLGJddi2zU-eZkM8R0-LNg5aI2Pji-bwf86FblKpOSWcUU56dxNiFN1GhKPO27J351vOamVTgUKwKmAkroKzYyWd2Us-uACzfvAKAKc_CzOeGq21cZC?expires=1788635700&signature=ab38761c84e301d8cccb7fc62b44aa6b4404f06c116c69ef186a112fa14f1298&req=cCcgH894lYhZFb4f3HP0gDx2zL4o7Zds2YMQDvv7oKEdVAmtof1M1ikWv2QL%0A7NhD2VuUq29ZBOvP8A%3D%3D%0A)


Il ne vous reste plus qu’à enregistrer. 

> **Bon à savoir :** assurez-vous que votre image est optimisée pour l'email (poids réduit et dimensions adaptées) afin de garantir un affichage rapide et correct chez vos destinataires.

### **Option 3 : créer une signature automatique à l’aide des variables dynamiques**

Toujours dans "*Menu" > "Réglages" > "Mes signatures"*, vous avez la possibilité d’utiliser les variables dynamiques pour créer une signature email. 

Sélectionnez *“gérer manuellement mes signatures”.* Choisissez les variables de votre choix puis cliquez sur* “Ajouter”* pour construire votre signature. Sellsy utilisera alors les éléments à sa disposition pour remplir automatiquement les champs. 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/477966903/79aff0e2186591ebde7043b2/XRVDpYhG-hw5m7WBoPUiguK7iw6nkKS0TyeVM-bbKz0Yg1wwEyQZSREpACFQpgV6aaOwLgMjZKkCTvdiZ98jCJnEPsI49XPf_uyJevel-93Py4IC6YWdbM7g0mXVcVfDk-lAGwxx?expires=1788635700&signature=2ee86ac1684b1bb2e313dcff1f916a903309fc1bda5a3cd70be9f451e2240552&req=cCcgH894lIFcFb4f3HP0gD1f13XPx2BKYXMom%2FQb2JlfRky2Ov4m3bfLNpID%0AsehuuXhn4rRbew4pNA%3D%3D%0A)

Une fois terminée, cliquez sur *“enregistrer” *en bas de page. 

___________________________________________________________

### **Option 4 : gestion automatique de la signature **

Dans "*Menu" > "Réglages" > "Mes signatures"*, vous avez aussi la possibilité de créer automatiquement une signature selon les informations dont dispose votre compte Sellsy. 

Pour cela, sélectionnez *“gérer automatiquement ma signature selon les informations renseignées”* puis enregistrez.

Une signature sera alors créée automatiquement en utilisant le nom de votre entreprise et votre nom et prénom.
