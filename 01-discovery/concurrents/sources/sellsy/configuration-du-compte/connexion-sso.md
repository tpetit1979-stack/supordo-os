# Connexion SSO

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2219505781/2d6bd30c4804eea925723239f371/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=4b8b0b62bbb12af1632abc48b9c74beba1841265068fb79ba836c66ec9074935&req=diImH8x%2BmIZXWPMW1HO4zVjjGzKf%2Fx1jQ8358uoHYREH%2FGA9KGyddgdTPjP6%0A%2FAVig77aafwgRFGG4hI%3D%0A)

Le SSO est une fonctionnalité de connexion unique qui simplifie et sécurise l'accès à Sellsy, que ce soit depuis un ordinateur ou un appareil mobile.

___________________________________________________________

### **Activation du SSO**

Le **SSO** est une option payante disponible à partir du plan **Evolution.** Après l'achat de cette option via votre commercial, l'équipe technique de Sellsy se charge de l'activer sur un domaine spécifique (par exemple : [sellsy.com](http://sellsy.com)).

La configuration technique doit ensuite être effectuée par un référent IT au sein de votre entreprise.

> **Bon à savoir : **L'activation du SSO nécessite une collaboration entre votre équipe IT et l'équipe technique de Sellsy pour assurer une mise en place correcte.

___________________________________________________________

### **Limitations avec SSO activé**

**Connexion via Google ou Microsoft**

Si le SSO est activé sur un domaine alors la seule façon de se connecter sur Sellsy sera le SSO. Si vous tentez de vous connecter via Google ou Microsoft alors que le SSO est activé, vous recevrez le message d'erreur suivant : *“Ce type d’authentification n’est pas autorisé pour ce domaine”.* 

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1219007038/e103a3b515cf10657e3cd7cd716a/image+%2821%29.png?expires=1788635700&signature=f3cf0bed9e161290c4eb8007402e33f8f50c54751d70f63a71595ccfa7ffe8c3&req=dSImH8l%2BmoFcUfMW1HO4zdY2btEVFg9Yn56QPGqARDTRtzFHJVuvumzeMHv9%0ABeW7%2BI2v8WtxaU7QG4M%3D%0A)

**Connexion avec email et mot de passe**

La connexion directe avec email et mot de passe n'est plus possible lorsque le SSO est activé. Vous verrez le même message d'erreur que pour la connexion Google/Microsoft.

___________________________________________________________

### **Demande de nouveau mot de passe**

Avec le SSO activé, il n'est pas possible de demander un nouveau mot de passe via Sellsy. Vous verrez le message suivant : *“La demande de mot de passe oublié n’est pas autorisée pour ce domaine”.*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1219008656/f12873f2cf9c0baede93dd4d1bb6/Screenshot+2024-10-09+at+18_03_41.png?expires=1788635700&signature=78801b832c1e7acd594c8fb161efd2022b4940f0afb1166954284eeec9e3e87b&req=dSImH8l%2BlYdaX%2FMW1HO4zXP7IaSQMT41CKeKzH5gJYprps2ZVUr9S4SfWlU5%0A6i1s6GX8GMJ4oRjuiC0%3D%0A)

> **Attention :** Pour toute réinitialisation de mot de passe, vous devez suivre la procédure de votre entreprise pour les comptes SSO.

___________________________________________________________

### **Modification de l'adresse email**

La modification de l'adresse email est soumise à des restrictions avec le SSO activé :

- Il n'est pas possible de définir une adresse email avec un domaine différent de celui configuré pour le SSO.
- Toute modification d'email doit correspondre au domaine sur lequel le SSO est activé.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1219015353/27fdd6cbad7fe771b9ddf5f93a72/Screenshot+2024-10-10+at+16_19_12+%282%29.png?expires=1788635700&signature=bb91cdb3c9a47313481fabab9430c1cb8791a302ad9a33fd8296cf374ac4266f&req=dSImH8l%2FmIJaWvMW1HO4zWCMHiUmFFK3RRVFztp7hC%2FgnOs8a8TY9DE49eSN%0Al5%2BviakYuGxt38fzzZ4%3D%0A)

> **Bon à savoir :** Cette restriction garantit que tous les utilisateurs d'un domaine utilisent la même méthode d'authentification.
