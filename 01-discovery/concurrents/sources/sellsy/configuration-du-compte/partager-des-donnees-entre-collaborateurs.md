# Partager des données entre collaborateurs

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261769239/994d5a4347d2b6dd85a0452760cf/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=8be867ca93e21282fa655aafed46ad206ef10f422b12a9d1293e5af356930c28&req=dSIhF854lINcUPMW1HO4ze7tjwYGERnpZNjbginFBNaVj8nLe%2BJ6lL0rmjAc%0AGGwChwfHiVGcpKWB1SE%3D%0A)

Sur Sellsy, il est possible de** partager différents objets** comme vos contacts, vos opportunités ou vos documents par exemple.

Chaque objet dispose d'un propriétaire, qui est modifiable et permet donc d'attribuer facilement le propriétaire de l'objet concerné.

Par défaut, lors de la création, ce sont les **réglages du créateur qui s'appliquent**. Si par exemple l'utilisateur est membre du groupe Webdesign, tout objet créé sera directement partagé avec son groupe.

> **Bon à savoir :** les réglages de partage interviennent après les réglages individuels du collaborateur concerné (privilèges). Si par exemple, l'utilisateur n'a pas accès aux devis, vous ne pourrez pas partager un devis avec lui.

Prenons l’exemple du partage d’un de vos clients. Accédez à la fiche de votre client. Vous trouverez dans l’onglet *“informations générales” *le propriétaire de ce client. 

![](https://downloads.intercomcdn.com/i/o/838122675/9159c9486141ca132a23d1a7/partager.png?expires=1788635700&signature=9fab22448907a0e8ad627007cdaba6ba35728fd3a521ac122ec3a4cd5d3bda5e&req=fCMvF8t8m4ZaFb4f3HP0gFta1d%2F%2Fyy7jM3BvqtYjJQZKrW6pSEhhELJt7BXz%0APtU%2BjVQDMxFUp8iIVg%3D%3D%0A)

En cliquant sur *“Partager”*, vous aurez la possibilité de modifier le partage en choisissant le propriétaire, les collaborateurs et les groupes qui peuvent voir et modifier l’élément.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444302091/f0939935496b8a4ce5f4460e/hgO73r83TxX0sMZBPJZSDj4K46W2z8jjebiXPRfGgvAxdJisOGBQ1y5vsERIP428CiMnm3gJ3zNjTUogEuCqsev2WR12LJAdieab8KDrHdE0JRAq0JDAaMhvdDzrHtGgu5iRK0vX?expires=1788635700&signature=3a07162c19f3acc886cc031d5706af693e025ee5c30347c31d7ce26981a8e957&req=cCQjFcl8nYheFb4f3HP0gMG5yTW0zCThbLRoYX4A0A4WZGiaku5pVE%2BSbdqM%0AyxYLr914Zbg9noULJQ%3D%3D%0A)

### **Changer le partage de mes données en masse **

Vous changez votre organisation et souhaitez rapidement redéfinir les droits d'une série de clients (ou autre) ? Voici comment changer le partage des données en masse :

- Rendez-vous sur la liste concernée,
- Filtrez les éléments que vous souhaitez modifier,
- Cochez-les à gauche de la liste,
- Dans le menu déroulant nommé *"Choisissez une action à effectuer"*, sélectionnez *"Modifier les options de partage" *puis *“Valider”, *

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444302099/9f12f0fcf5f59fdcf6992762/6SzysgLYR67frJu1WTJ4rsVB3rJXSj6o3ReSjUFPQVGeOs19be-E1X0rou2-X53KqltY8Ym0gRSPBSSbvBJ0jhFC1vdAFShZl6wGH4I-QoM4bs-cqO2kpVknx1OnrUtkIR2rzh4y?expires=1788635700&signature=dd4f29e49409105488346f7a399ac18be0ca429bbc3d62b0a591eee64440fdc6&req=cCQjFcl8nYhWFb4f3HP0gKmE9M%2Bi%2FzcgmWqHmgdCvsP7PHRXEfrB%2FYUc6zux%0AsO9EmVO8ChfGFXXDrQ%3D%3D%0A)

- Vous aurez ainsi la possibilité de choisir de nouvelles options de partage.

### **Autoriser le partage pour un collaborateur **

Pour autoriser le partage pour un collaborateur, vous devez vous rendre sur vos réglages puis sur *“Profils de privilèges”.*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444302114/7f7d5a182d0d5fdc3bd3c29e/SlpnQinGW0R0hYNjpBuz_KdyjNmVnre8Veem5vnsTDgAiPi0ZHYaaWIXj3aNPwKLy4vR_R0wnFiW6eDV2saWRmj4UK97nKhSQDaGkwchEIMGm6Wv1ITfgi1rlIPgZkXVwWbXxkXG?expires=1788635700&signature=ede82d35e3fab53039ca71cabb1daec34e4c8da8b8773b47c7587abce28510f3&req=cCQjFcl8nIBbFb4f3HP0gPhCLzIM9k9D1DPH3s2d0RgrdzWncFDO8pkhPn%2F7%0A64L2iUzvXT6XGYvgVA%3D%3D%0A)

Ensuite, cliquez sur les trois points à droite du profil du collaborateur puis sur *“Modifier”.* 

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/444302122/24ba2ce16bb08dceb49ea8e3/TvA_s09_SRXJadDpwZxMHj3oQcdCrnWhAewntqZJcd5ljSDOHcVVpymyfMlrKd57WFx1vln4XDL1wfrshPwCAcETYfPASMBIERR0s_hO5uS2qM49yKLRC2OGg8-vjlwZm4ri8CFA?expires=1788635700&signature=1d3c018d9d8247d0e6f771e9b2a11039098186c898d84222ada1a34f4d96c9bc&req=cCQjFcl8nINdFb4f3HP0gH7%2BnY4hUasDFDSv8ECXrEhniTSxvdVNMrzBL5hS%0AxU67R7GTR2CFt90A6A%3D%3D%0A)

Dans la section *"Fonctionnalités diverses"*, cochez l'option *"Autoriser l’édition du partage sur les fiches"*.
