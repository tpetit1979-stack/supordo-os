# Utiliser les groupes de collaborateurs

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261769680/fd1eaa90d07015fe558b7e991b2f/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=85095b208247b742698678fb461d5c888148e26877da2dd098f998044cc1ee9d&req=dSIhF854lIdXWfMW1HO4zbAbcJoT7bGZIN7gl67Qn2TBM%2FjS8oI7BkEONcUd%0ApkwbA73yDOVb2PD%2FJJc%3D%0A)

Sellsy vous permet de créer des **groupes de collaborateurs**, une fonctionnalité particulièrement utile pour les équipes de taille importante. Elle permet notamment de **restreindre l'accès aux données** (contacts, documents, statistiques) à un groupe spécifique, facilitant ainsi la gestion des droits et la confidentialité des informations.

### 

___________________________________________________________

### Les avantages des groupes de collaborateurs

Au-delà de la simple organisation interne, les groupes de travail offrent plusieurs fonctionnalités clés dans Sellsy :

- **Partage de données par groupe**
Les éléments (documents, opportunités, fiches clients, etc.) peuvent être partagés avec un ou plusieurs groupes, assurant un contrôle précis de la visibilité des données.
- **Filtrage par groupe**
Les groupes peuvent être utilisés comme critère de filtre dans différents modules (pipeline commercial, tâches, documents, etc.), ce qui facilite le suivi de l'activité par équipe.
- **Rapports segmentés par groupe**
Certains rapports peuvent être segmentés selon les groupes, permettant une analyse détaillée des performances par service ou département.

> **Bon à savoir**
> - Un collaborateur peut appartenir à plusieurs groupes.
> - Lorsqu’un utilisateur crée un document, celui-ci est automatiquement partagé avec le(s) groupe(s) auquel il appartient.

### Comment créer un groupe de travail

Pour créer un groupe de travail, cliquez sur votre menu puis sur *“Réglages”* et *“groupes”.*
