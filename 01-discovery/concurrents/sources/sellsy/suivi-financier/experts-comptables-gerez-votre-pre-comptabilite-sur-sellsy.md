### Consulter et exporter les factures et avoirs 

Rendez-vous dans le menu *"Facturation" *(pour les documents de vente) ou dans le menu* "Achats" *(pour les documents d'achat) disponible dans le bandeau latéral à gauche de l'interface puis cliquez sur *"Liste des factures"* ou *"Liste des avoirs"*. 

Vous pourrez ainsi : 

- Consulter le document et ses données
- [Exporter la version PDF](https://help.sellsy.com/fr/articles/5870719-exporter-les-pdf-de-mes-documents)
- [Exporter la liste](https://help.sellsy.com/fr/articles/5877082-export-des-donnees)

___________________________________________________________

### Le menu comptabilité 

> **Bon à savoir :** L’accès à certaines fonctionnalités est contrôlé par l’administrateur du compte principal. Pour modifier vos autorisations possibles, contactez l’administrateur du compte qui pourra les gérer depuis les profils de privilèges.

Le menu comptabilité disponible dans le bandeau latéral à gauche de l'interface regroupe l’ensemble des **journaux comptables** (vente, achat, trésorerie, opérations diverses), que vous allez pouvoir facilement [exporter au format FEC ou CSV](https://help.sellsy.com/fr/articles/5875031-comment-exporter-mes-ecritures-comptables-format-csv-fec).

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/630164429/fd5d7ec4e6048a03e246680c/NwKEY5NqoqJYIzTBmrXckH_1Uyqb8oJ8YaLsSr9M_xTIbLzM3q3z1uZ5X7Ok7E4R0czA6-gKosGp4N2nsKHz6Uxbwj5KjKQObkuuHZkpYC4IdZndhgyAY9oejl6wT5J5joqTDlr9l2ou4SvBijqahTZaQhUEtJ8x2alVhav7dfVBs6rQoEZhomV5xoFjcw?expires=1788635700&signature=d385ceb80208cbcf34af3c8af753b77a57835c35b00a0aa5fa9a4c0da6208fec&req=ciMnF896mYNWFb4f3HP0gH1AhbXVNM%2F%2F1WG2xJX9ZzHS%2BMykGaecHedrIHgA%0AyO23XLdk1HxFUISJaA%3D%3D%0A)

> **Bon à savoir** : Si vous ne voyez pas les écritures dans vos journaux, alors il est possible que tous les documents n'aient pas été [comptabilisés](https://help.sellsy.com/fr/articles/5875018-comment-comptabiliser-une-facture-d-achat-de-vente). Sinon, c'est que les lignes ont déjà été exportées. Dans ce cas, il faudra donc ajouter le filtre *"Inclure les lignes déjà exportées : oui". *

Dans ce menu comptabilité, vous trouverez également le réglage des codes comptables de TVA, le réglage des codes comptables de paiements, le réglage des codes comptables des emballages, le réglage des codes comptables des frais de port, le [plan comptable](https://help.sellsy.com/fr/articles/5875019-ajouter-des-codes-comptables-au-plan-comptable) et les balances âgées.
