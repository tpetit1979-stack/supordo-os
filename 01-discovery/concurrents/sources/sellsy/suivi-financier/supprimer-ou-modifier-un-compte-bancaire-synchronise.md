# Supprimer ou modifier un compte bancaire synchronisé

### **Actions possibles sur vos comptes bancaires**

Depuis le module Rapprochement bancaire, vous pouvez effectuer deux actions principales sur vos comptes bancaires synchronisés :

- **Modifier vos identifiants de connexion** : pour mettre à jour votre mot de passe ou vos codes d'accès
- **Supprimer un compte bancaire** : pour retirer définitivement un compte de la synchronisation

> **Attention : **Il ne sera pas possible de resynchroniser un compte bancaire après suppression. Si vous souhaitez le voir à nouveau dans le module Rapprochement bancaire, il faudra repasser par *"Connecter un compte bancaire"* et reconfigurer entièrement la connexion.

___________________________________________________________

### **Modifier vos identifiants de connexion ou supprimer un compte bancaire**

1. Rendez-vous sur les informations bancaires de votre société depuis les réglages
2. Cliquez sur *“Voir plus”* en face du compte concerné

> **Bon à savoir :** Pour supprimer un compte bancaire, il faut d'abord supprimer tous les rapprochements qui lui ont été effectués.
