# Modifier le moyen de paiement pour un rapprochement bancaire

### **Pourquoi modifier le moyen de paiement **

Il peut arriver qu'une transaction bancaire soit importée avec un moyen de paiement *"Inconnu"* ou qu'il y ait une erreur dans le moyen de paiement détecté.

Dans ce cas, avant d'effectuer le rapprochement, il est nécessaire de modifier le moyen de paiement pour assurer la cohérence de vos données comptables.

Vous disposez de deux méthodes pour modifier le moyen de paiement d'une ou plusieurs transactions.

___________________________________________________________

### **Directement dans la ligne**

Pour modifier rapidement le moyen de paiement d'une seule transaction :

1. Depuis le module *"Rapprochement bancaire"*, repérez la transaction concernée
2. Dans la colonne *"Moyen de paiement"*, cliquez sur *"Inconnu"* (ou sur le moyen de paiement à corriger)
3. Sélectionnez le nouveau moyen de paiement dans la liste déroulante
4. La modification est enregistrée automatiquement

### **Modification par action en masse**

Pour modifier le moyen de paiement de plusieurs transactions en une seule opération :

1. Depuis le module *"Rapprochement bancaire"*, sélectionnez les transactions concernées (cochez les cases)
2. Cliquez sur *"Actions en masse"* (ou bouton similaire)
3. Sélectionnez l'action *"Moyen de paiement"*
4. Choisissez le nouveau moyen de paiement à appliquer
5. Validez
