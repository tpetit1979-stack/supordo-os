### **Accéder au plan comptable**

Pour gérer vos codes comptables, cliquez sur "*Comptabilité*" dans le menu principal, puis sélectionnez "*Plan comptable*".

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446289256/57b3aaa11159e2929729a85a/LaKS1YOdoHoD3mENaWhYJiLQSevWBysItwm6G6gpA1nw8adOxMNYvFbOAYRwYpftOZEWCunt9viGw2WfRnBxzOtbQANAkWK9n21w2MKz06o1Km8bmor6k8y5R0UfgGb-iqtFiMIe?expires=1788635700&signature=c8822f0fbc900e3a4f329ecd513502d7b785bc52fded34f440bc2203927cbc3e&req=cCQhFMF3n4RZFb4f3HP0gDMW8%2B9Rm%2Fnr%2FcrnXRr%2BKsv%2F%2BPxaGLfBTL2t5a6x%0AQ5fULuQErXskj29FwQ%3D%3D%0A)

Vous accédez ainsi au plan comptable général de votre entreprise.

___________________________________________________________

### **Ajouter un code comptable**

Pour créer un nouveau code comptable, cliquez sur le bouton "*Nouveau code comptable*" situé en haut de la page.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2194998738/c3cb189c7c1239fae39b408d7d00/D6u8FkLiMj01dAtBW_enw8ugqoDoTxfrHISfdQtmFNGf5CHZwC3cCePuXfmfzA66NjwbMjpDlMTIx7i0u7peQdDCn-NT8cEpntqET37Wxt_yMmpmgzB7nOXV9ZmcDB7TfxG9w2kg?expires=1788635700&signature=84197d54ca4d1591ecbea24512e429124ba724cf200b0e53f718f3dbe6211441&req=diEuEsB3lYZcUfMW1HO4zURsy2NgqEbnw6xz9QjHk%2BdHxmNDtPcDXWV9yQQd%0AYDSInSb5WKCtWWGaIsQ%3D%0A)

Une fenêtre s'ouvre et vous permet de saisir les informations suivantes :

- Le numéro du code comptable
- Le libellé du compte
- Le type de compte (produit, charge, TVA, etc.)
- Les autres paramètres spécifiques selon vos besoins

Une fois les informations renseignées, validez pour enregistrer votre nouveau code comptable.

### **Modifier un code comptable existant**

Pour modifier un code comptable déjà créé, localisez-le dans la liste du plan comptable et cliquez dessus. Vous pouvez alors actualiser les informations nécessaires et enregistrer les modifications.

___________________________________________________________

### **Association des codes comptables aux produits**

> **Bon à savoir :** Il n'est pas possible d'attribuer plusieurs codes comptables à un même produit. Chaque produit ne peut être associé qu'à un seul code comptable de vente. Cependant, une alternative existe : il est possible de définir un code comptable par catégorie tarifaire. Concrètement, cela signifie que si un produit est associé à une catégorie tarifaire spécifique, le code comptable défini pour cette catégorie tarifaire prendra automatiquement le dessus sur celui du produit.

Cette fonctionnalité vous permet de gérer des exceptions comptables pour certains types de ventes sans modifier le code comptable principal du produit.
