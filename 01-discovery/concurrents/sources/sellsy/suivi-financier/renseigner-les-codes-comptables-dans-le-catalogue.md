# Renseigner les codes comptables dans le catalogue

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261880844/2dd5d081a49ac337549f730c6be4/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=652128281282680848c37378990b739cfc70a9eaf13ecaf2303af7e07f0e6e09&req=dSIhF8F2nYlbXfMW1HO4zai3WvpO%2Fml9HA%2BPRyLcLQ3L9xJDXpA1lQWxiAqP%0AKiITw2pxE9mIHERakug%3D%0A)

En renseignant les codes comptables de vos produits dans votre catalogue, vous gagnez un temps considérable sur votre saisie comptable.

Chaque fois que vous enregistrez une facture contenant ces produits, celle-ci est automatiquement prête à être comptabilisée avec les bons codes.

___________________________________________________________

### **Définir les codes comptables d'un produit existant**

Pour associer des codes comptables à un produit déjà créé :

Accédez à "*Catalogue*" > "*Liste des produits*"


![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2195052405/860bdb5bf2defa0960947838fbd7/gl6GNpN6GE92VAJ6infE2fAxgfAqt0Nh4JXYRkgqxJ8ca0407Rs6z6x5DlayfcKw2sHo9bZKyNNaenEpylJsiaTJqrPhqtx0QvB27DPQZ3dQpgZpCmJwJBSTREEODwzyVBkiT-Bi?expires=1788635700&signature=4afa9551c1c80b052059d67907098a0539a1b6cfa87389fac0da7e973e8f1382&req=diEuE8l7n4VfXPMW1HO4zZhYiJYANYnJUNw8FnEM9QdP3qStn0LkfbME%2FJbU%0AqYcaJKXNp0I9dv6wjic%3D%0A)

1. Cliquez sur le produit concerné
2. Cliquez sur l'action "*Modifier*"
3. En bas de la page, sélectionnez le code comptable correspondant au produit :
- Pour les achats
- Pour les ventes
4. Enregistrez vos modifications

### **Définir les codes comptables lors de la création d'un produit**

> **Bon à savoir : **vous pouvez également définir un code comptable directement lors de la création de votre produit dans le catalogue.

Cette fonctionnalité vous permet d'organiser votre comptabilité dès la création de vos fiches produits, pour une gestion optimale.

___________________________________________________________

### **Impact sur vos factures**

Les codes comptables définis sur vos produits s'appliquent automatiquement lors de l'ajout de ces produits dans vos documents de vente ou d'achat, garantissant une comptabilisation cohérente et sans erreur.
