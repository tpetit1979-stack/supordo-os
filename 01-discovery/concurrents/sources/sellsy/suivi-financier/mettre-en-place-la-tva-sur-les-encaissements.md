### **Paramétrage de la TVA sur les encaissements**

Pour définir le mode de TVA appliqué par défaut sur l'ensemble de vos documents, accédez à *"Menu"* > *"Réglages"* > *"Tarifs et taxes"*.

Vous pourrez ainsi choisir entre deux modes de TVA :

- La TVA sur les débits
- La TVA sur les encaissements

Il sera applicable sur tous vos nouveaux documents sauf sur les acomptes où la TVA est toujours exigible à l'encaissement. 

> Bon à savoir : Sur les factures d'acompte, la TVA est exigible sur les encaissements depuis le 1er janvier 2023 (Article 269 du CGI, 2-a). Vous ne pouvez donc pas modifier le mode de TVA pour ce type de document.

### **Paramétrage des codes comptables**

Pour configurer vos codes comptables de TVA sur les encaissements (vente et achat), accédez à *"Menu"* > *"Réglages"* > *"Module Sellsy"* > *"Comptabilité"*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/631577382/ed91ce65be049251bcb9c786/2ht0xpB0ZhLbS4UUgFaYV1c9kBMF3J8LAeiDktd84OSMfFN5-E9i8cFP1aLLTQSUeyKwlYldPaP6tE2NjdH0mzhnXo9NrUkhOciYxAzVbzCNRjLGqKDqlt1Wtouk--6-pXrhCZDwG7qh_OsotpN5ZHO07F2HiEk7VNY36e_MaQhKe5hwniYVlyQeF2PGUg?expires=1788635700&signature=2309137feeafd84314d4fbe0ef234f155631d1a46f53edb3f0b193a74a8d0a5b&req=ciMmE855noldFb4f3HP0gLXew3TRkSvYO7QISqpEKTKAOBIu7BoGwUHqnRF8%0A78T3uS9m4rK86TAPTw%3D%3D%0A)

Cliquez ensuite sur *"Paramètres du plan comptable"*.

Vous pouvez alors définir vos codes comptables pour :

- Code comptable TVA sur les encaissements
- Code comptable TVA sur les décaissements

### **Affichage de la TVA sur les factures de vente**

L'affichage du mode de TVA sur vos documents répond à plusieurs exigences liées à la facturation électronique :

- **Conformité à la facturation électronique** : la réglementation en vigueur impose l'indication du régime de TVA applicable sur les factures et avoirs.
- **Obligations réglementaires** : les entreprises assujetties à la TVA doivent préciser sur leurs documents si la TVA est exigible sur les débits ou sur les encaissements.

Consultez [les informations obligatoires d’une facture](https://help.sellsy.com/fr/articles/14756178-les-informations-obligatoires-d-une-facture) pour en savoir plus. 
​
Consultez cet article dédié pour comprendre pourquoi [les mentions de mode TVA apparaissent sur vos documents](https://help.sellsy.com/fr/articles/15231913-affichage-du-mode-de-tva-sur-les-documents) et comment les gérer dans Sellsy. 

> **Bon à savoir :** 
> - votre historique de documents est conservé ;
> - les anciens taux restent visibles sur vos documents déjà émis ;
> - vos documents passés ne sont pas modifiés.

### **Le journal des opérations diverses** 

Le journal des opérations diverses vous permet (ou permet à votre expert-comptable) de retrouver les écritures comptables de la TVA sur les encaissements. 

Il se trouve dans le module *“Comptabilité”* accessible via la barre latérale à gauche de l'interface.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/631577439/7354a8cb3614a2dc602824a5/eM0b9LJ2z_0eCEI3eS6fOuT9aCskhfM2GgOWlzzpoBzhMZTJ7NhFyHax0LR36yIBXkmp_gSg6hZq_gVlCM0Z4dXigV_JgafvwppaMtDMzkX-6y8Lbq34z8WY6S0K0Gi7ICojQlgfWkDujJWYsJrzNb45_L4S-4x6oUuM4WigRIYx1rx14ScY8AYEZO5DPQ?expires=1788635700&signature=bc90d1f5aa764c78b0db987c383c2178e3b47b43e6b43637a8b6cc8566a297a4&req=ciMmE855mYJWFb4f3HP0gK1GWXoTn39ByI%2FvBY75KtjEFmMMzsKMiU6RYebt%0AT7ZEEHVteLce4Z9lKQ%3D%3D%0A)

Voici les éléments répertoriés sur ce journal : 

**Colonnes visibles par défaut :**

- Code journal
- Date
- Compte
- Label code comptable
- Libellé
- Client
- Débit
- Crédit
- Devise
- Document
- Exporté

**Colonnes non visibles par défaut :**

- Compte auxiliaire
- Code analytique
- Lien public
- N° Facture
- Objet
- Référence client
- Référence externe (only achat)
- Sens (Débit/Crédit)
- Type écriture

Vous pourrez exporter l’ensemble de vos éléments en format CSV ou FEC.
