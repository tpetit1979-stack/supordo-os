# Gérer les codes comptables des remises

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261879344/ef3d31dce7b9f0439b5b90724395/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=ed428f2bc69c3b6da808b352512ee206e8d3bfd97d5aba2aa81067722c456cd3&req=dSIhF8F5lIJbXfMW1HO4zeCxT1sixVIT5eN6xPJpdNfbNIPOgqvsX5oWmx4r%0Al9RUi%2BtS7XBt7g7fjMc%3D%0A)

Par défaut, les remises sont comptabilisées sur des codes spécifiques :

- **Code 709** pour les remises sur ventes
- **Code 609** pour les remises sur achats

Lors de l'envoi en comptabilité d'un document comportant une remise, une ligne spécifique apparaît avec l'un de ces codes.

___________________________________________________________

### **Désactiver l'utilisation d'un code spécifique**

Vous pouvez désactiver l'application d'un code comptable spécifique pour les remises. Dans ce cas, les montants remisés seront directement déduits du montant crédité ou débité sur le code comptable du produit.

Pour désactiver cette fonctionnalité :

Accédez à "*Menu*" > "*Réglages*" > "*Module Sellsy*" > "*Comptabilité*".

 Rendez-vous dans la rubrique "*Paramètres du plan comptable*", puis décochez la case "*Utiliser des codes comptables spécifiques pour les remises*"

### **Personnaliser les codes comptables de remise**

Il est possible de choisir des codes comptables différents de ceux configurés par défaut.

La première étape est la [création d'un code dans le plan comptable.](https://help.sellsy.com/hc/export-des-journaux-comptables/how-to-add-accounting-codes)

Une fois le code créé, Rendez-vous dans "*Menu*" > "*Réglages*" > "*Module Sellsy*" > "*Comptabilité*", puis sélectionnez le code créé dans le menu déroulant des codes de remise

Le code créé apparaît dans le menu déroulant des codes de remise.

___________________________________________________________

### **Gérer plusieurs codes comptables pour les remises de vente**

Il est possible de distinguer plusieurs codes comptables pour les remises de vente en s’appuyant sur les catégories tarifaires.

Voici les étapes à suivre : 

1. Créer un code dans le plan comptable,
2. [Créer ou éditer une catégorie tarifaire](https://help.sellsy.com/hc/catalogue-a60c2672-1684-4298-9005-4203a5610b03/how-to-use-price-categories), et choisir le code comptable à utiliser pour les remises.

Lors de la création d’un document avec cette catégorie tarifaire, le code de remise précisé à l’étape précédente sera utilisé pour l’envoi en comptabilité.
