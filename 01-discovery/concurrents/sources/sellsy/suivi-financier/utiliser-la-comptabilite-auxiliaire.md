# Utiliser la comptabilité auxiliaire

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261878989/c3fd17a70376884a8a0b08773435/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=303db79757d09c07622e40ffe4ab34aade5e6e837751c2a47a2f7be53e00919b&req=dSIhF8F5lYhXUPMW1HO4zdvL7fB2h4hnic%2F%2FQygldvdlQHkS4zABzNer7yVL%0Acst5O8zC5HV%2BCoWJWQY%3D%0A)

Le module Comptabilité vous permet de gérer une comptabilité auxiliaire.

La génération des comptes auxiliaires sur les fiches client et sur les fiches fournisseur est automatique dans Sellsy.

___________________________________________________________

### **Réglages de la comptabilité auxiliaire**

Pour activer et paramétrer la comptabilité auxiliaire, suivez ces étapes :

1. Accédez à "*Menu*" > "*Réglages*" > "*Module Sellsy*" > "*Comptabilité*"
2. Cliquez sur l'onglet "*Comptabilité auxiliaire*"
3. Cochez "*Utilisation des comptes auxiliaires*"

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446292359/19dbbea3e29a43ceea28b9d0/Fyprj9Mvw6M-aNcQ6rcM7FbtiVvODOaJO9u4HKeQq-Ttrs6cbZoU_i11c2YfAvsGg8v1GxTwKUN6SAjNEOj9KX-rGU57tyQrkYi7InNAD8OGe8eXH3rOwDZ5ABRmhZ6vL-efxvRH?expires=1788635700&signature=15b1f9e12e92cb6a35d7121c0262c9e242c03f7e11a48d803600c71a568eeb02&req=cCQhFMB8noRWFb4f3HP0gO%2BbFm%2F23sMIsPWQStEfLvMDMb73jdnfMU3Zz4uo%0AbCeifePFEiuZjfs5fg%3D%3D%0A)

Une fois la comptabilité auxiliaire activée, vous pouvez personnaliser le format de vos comptes :

- **Code :** la racine du compte pour les clients et pour les fournisseurs
- **Format :** le nombre de caractères du nom du client / fournisseur
- **Compteur :** il se génère automatiquement pour éviter les doublons

L'option "*Appliquer sur tous les contacts (clients, fournisseurs)*" vous permet d'écraser tous vos comptes auxiliaires actuels. Cette option est particulièrement utile si vous souhaitez remettre vos clients / fournisseurs dans le nouveau format choisi.

### **Utilisation des comptes auxiliaires**

**Génération automatique**

Lorsque vous créez un nouveau client ou fournisseur, le compte auxiliaire se génère automatiquement après avoir saisi son nom.

Le système vérifie automatiquement qu'aucun doublon n'est créé lors de la génération initiale.

**Modification d'un compte auxiliaire**

Si vous souhaitez regrouper certains clients ou fournisseurs sous le même compte auxiliaire, vous pouvez modifier manuellement les comptes. Le système n'empêche pas les doublons lors de la modification.

> **Bon à savoir :** Pour modifier un compte auxiliaire, rendez-vous sur la fiche du client ou du fournisseur, cliquez sur le bouton "*Actions*" en haut à droite puis sur "*Modifier la société*". Vous trouverez le champ "*Compte auxiliaire*" dans la section "*Données comptables*".
