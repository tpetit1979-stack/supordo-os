# Transférer des transactions entre comptes bancaires

___________________________________________________________

### **Pourquoi transférer des transactions**

Dans certains cas, vous pouvez avoir la nécessité de transférer des transactions bancaires d'un compte à un autre.

Vous avez, par exemple, commencé l'utilisation du module Rapprochement bancaire avec le système d'import de relevés. Mais maintenant, vous souhaitez profiter d'une synchronisation automatique en connectant votre compte bancaire dans Sellsy. Vous avez donc 2 comptes bancaires disponibles.

> **Bon à savoir :** Le transfert des transactions peut également s'avérer utile dans le cadre d'une suppression de compte en doublon.

___________________________________________________________

### **Transférer des transactions**

**Accéder à la fonction de transfert**

1. Depuis le menu *"Banque"*, accédez à *"Rapprochement bancaire"*
2. Cliquez sur *"Actions"*
3. Sélectionnez *"Transférer des transactions"*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2160525664/312bdd6bd494b86b19276a535ad1/U8TXY8dEbJiV_00MYioNwWot4N-gKUlN31j8Jsah0GgVjG5K0P-luUAwRAaackyaBvrI3SVJxo_p9t7675R3oP9Txmnfw2S9htUha1KC6XHQAMWo4I8lnMyFUMGI8KF7UV-XG91f?expires=1788635700&signature=3e5acfee08a3767e7356e1dc1e090474239599e36fc8d7fb68305aa9f3b7ec16&req=diEhFsx8mIdZXfMW1HO4zT7FRAZmHLC1SDPg0Kaghm9q%2FEvtw7pJ%2BAcd9Vpn%0AyP3Fz5DJCisT4ZhpsCE%3D%0A)

**Configurer le transfert**

Dans la fenêtre qui s'ouvre, saisissez les informations nécessaires :

- **Le compte de départ** : compte bancaire source
- **Le compte d'arrivée** : compte bancaire de destination
- **La plage de dates** : période des transactions à transférer (dates incluses)

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2160526192/6d8423a91034ed1186672fc67ffa/7wkgmKKX1v0hKZRsO-r71vm-fw-uP9-AMbbpAy6gz0YJMvCBxZ9vOpxYdUfcLNjvkqB6sBn01PC7fct0A5TVgqMPg0hksOKOuO5yLgH4-uzdWBz6wZrsl_V1JKyetrQVk3wpFQpk?expires=1788635700&signature=d76ecc3bd0dd5bcee2568b7a2ad8ee7d67f405ba68f40d0a2901cdcad9b5bea4&req=diEhFsx8m4BWW%2FMW1HO4zSNveAax3RCzHosLyWvb4ZslRQBpcijptVQmd8rH%0Aq9oMjUJKhXrSNh0ETLA%3D%0A)

**Option d'écrasement**

Vous avez aussi la possibilité d'écraser (de remplacer la plage de dates) les transactions dans le compte d'arrivée.

> **Important :** Le transfert se fait avec les éventuels rapprochements déjà faits. Vos factures restent rapprochées aux transactions transférées.
