# Utiliser les codes comptables analytiques

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261879726/7d331d8f28bd7b98f706c25a36be/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=950e4632bca01fe0e0ce7acf90de544f3524c24cfe298b9f9e471e1cb42224e8&req=dSIhF8F5lIZdX%2FMW1HO4zfgxY%2BPKomFSFXQdQop1TpcFoA3XTJntm3dB1uvj%0ABcPZXsD8A%2FbIN%2BqvSWE%3D%0A)

Le module d'exports comptables vous permet de gérer une **comptabilité analytique par produits ou par affaires**.

___________________________________________________________

### **Activation et configuration de la comptabilité analytique**

Pour activer la comptabilité analytique, suivez ces étapes :

1. Accédez à *Menu* > *Réglages* > *Module Sellsy* > *Comptabilité* > *Comptabilité analytique*
2. Cochez la case "*Utilisation de la comptabilité analytique*"

Depuis cette interface, vous pouvez également configurer :

- Le type de comptabilité analytique (par produits ou par affaires)
- Le code analytique par défaut
- L'affichage de la comptabilité analytique (séparée ou non)

![](https://downloads.intercomcdn.com/i/o/1123246284/f945cd16688273e345944de9/Comptabilite%CC%81+analytique.png?expires=1788635700&signature=516c63082ecfc3342ffddd0ab76170dd41d010d8a82aa72aec4e771b8e047cc0&req=dSElFct6m4NXXfMW1HO4zQa0m9HXH8N2eiTwwPYRKDSXcnWlNkB%2FIB4v81b8%0A2quD1IB7v994vkzesv8%3D%0A)

> **Bon à savoir : **Lorsque la comptabilité analytique séparée est activée, cela génère une ligne supplémentaire dans vos journaux comptables.

### Comptabilité analytique par produits

La comptabilité analytique par produits vous permet d'associer des codes analytiques directement aux produits. Elle permet donc de ventiler une facture sur plusieurs codes analytiques. 

Dans ce mode, vous aurez deux possibilités pour gérer vos codes analytiques : 


Gestion des codes analytiques depuis la fiche produit

Les codes analytiques peuvent être définis ou modifiés directement au niveau de la fiche produit :

1. Ouvrez la fiche du produit concerné
2. Cliquez sur l'action "*Modifier*"
3. Renseignez le code analytique

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/499111767/9d26b09a36340af3409ef908/3b6d813d-7bf4-4720-81a2-094ccc126885?expires=1788635700&signature=dacd90bb4a89dda56a391d778bcdb512dc5bdeaf7497be0bba8cc31e165ea923&req=cCkuF8h%2FmodYFb4f3HP0gHgWuPlQ3NAiRcucRBP%2B0Kh6bVHb8tXB%2F71C0xFK%0Am7c3zjtMrayGQR7KrQ%3D%3D%0A)

Une fois enregistrés, les codes analytiques sont consultables en haut à gauche de chaque fiche produit ou service.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/499111779/e35ec85fca9fe6c909acc54c/27ff078e-503a-48ff-8033-ff8dd5cb9c5d?expires=1788635700&signature=c0bdbd00fc4e26a54bbb12e5903ac6ef4bb19c1336435a7473451e2dcd8d8ed9&req=cCkuF8h%2FmoZWFb4f3HP0gH2XYUO1Ssg2Ts6MsJTfyh5DLilgs1QtXNeoaELw%0Am64TaS80UwbU5qB7Xg%3D%3D%0A)

Gestion des codes analytiques depuis les documents

Vous pouvez également ajouter ou modifier les codes analytiques lors de l'édition d'un document :

1. Ajoutez un produit à votre document
2. Cliquez sur la roue crantée située à gauche du produit
3. Définissez ou modifiez le code analytique

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/499111786/fc2d79e7f97ed74cdd2b449e/576e3172-19d6-47b0-8ca9-ab2458f18d6b?expires=1788635700&signature=fb931db23f54586be88e78c3924295296e016771d66b4e153eeb35afeef377f9&req=cCkuF8h%2FmolZFb4f3HP0gApp8KNVknXtPv4sr%2BhjWwJJVRXZKCrpNX%2F0tYZV%0AiOcxQmdpfhX2lBlIWg%3D%3D%0A)

> **Bon à savoir :** Si aucun code n'est renseigné, c'est le code par défaut défini dans les préférences qui sera appliqué *(Menu > Réglages > Module Sellsy > Comptabilité > Comptabilité analytique)*.

### Comptabilité analytique par affaires

La comptabilité analytique par affaires vous permet d'associer des codes analytiques directement aux factures. Elle permet donc de ventiler une facture sur un unique code analytique. 

Le code analytique se définit lors de la création de votre facture, dans le bandeau situé tout en haut de la facture.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446289831/81c9ec2654fbcca67a8f528a/6JCVbJrmve8rh_eSZAO86X9F7PvocJPVPxV8JkH12DF68wbAtktgPEb4tXzxCFZAt6K5IHix8TIdWhcS76naN7KvO-nbYLHw3feXBhL0OSTg7qsdEL_8LaRAt3MXL_OnvS0kEKc3?expires=1788635700&signature=d41e1ffe76c28b74271b020777860504c6751ec99b7136dc6c63b00f3739954f&req=cCQhFMF3lYJeFb4f3HP0gF7ovypoAwQKjxxGlSnEgqGCwyVVkhBFtSQSNjzm%0A1wFJReG3QlzRgbeaTw%3D%3D%0A)

> **Bon à savoir :** Les factures d'acompte ne proposent pas de renseigner un code analytique car il s'agit d'avances de paiement n'impactant pas le chiffre d'affaires. C'est lors de la génération de la facture de solde que le code analytique pourra être renseigné.
