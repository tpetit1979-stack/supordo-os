# Exporter le journal de banque

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261863709/04e1c66a5db8eb25b13086b66df5/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=0ca3b55f15d61e09032189185e23d0a4d3f5d9fece198b53c1e50594c680f90b&req=dSIhF8F4noZfUPMW1HO4zV6MnGBCUDAbUK5Tak5PANHRWM7%2BHCk66iUQ87vK%0ARdliDoKnh5R0pdUtxIQ%3D%0A)

Pour exporter les écritures du journal de banque, rendez-vous dans le module *“Rapprochement bancaire”,* puis cliquez sur *“Actions”*. Pour finir, cliquez sur *“Exporter journal de banque”*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446305792/8324e086074555494a1d7452/PmyYhiM3qElysrCg6R3eu0ni-8hg3PdmZVNFYFKTXoJHzxJ7O_jL25xUBN2DzbrxcKAuBzBcc_i_dnMBw0q4xU5eeA-F9OooBkn5qKIoNphdUTuovdlgBsV4o0d81IWHNt2oPb17?expires=1788635700&signature=d1b929a0a9fd56877ed0964e6661526a49809bff34fbcc376167ab99908dd1d4&req=cCQhFcl7mohdFb4f3HP0gD954BK%2BwsK%2FKFyxGOMW9w6flV%2F5FP%2Bmpiyvf%2BA0%0AXyephC4YSqSmJfTkmw%3D%3D%0A)

Par la suite, vous recevrez un mail avec un lien de téléchargement.

> **Bon à savoir :** L'export du journal de banque s'effectue par compte bancaire. Positionnez-vous sur le compte bancaire souhaité avant de faire la demande d'export.
