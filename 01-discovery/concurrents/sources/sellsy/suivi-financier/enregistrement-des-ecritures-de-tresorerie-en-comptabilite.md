# Enregistrement des écritures de trésorerie en comptabilité

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261878223/e142fd1ca689ca88c335266d0ccb/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=d8d61f0bbe39d3d7407dc8d671a15b840fe0b8f96c03e4f2ac6397578ad6440c&req=dSIhF8F5lYNdWvMW1HO4zYn1bPdTSfVe%2BA%2B5Lyhp40%2BdJTRTUs9bnJig1zS4%0ACAN%2BgGRVRH6Be1B6lMY%3D%0A)

Les écritures du journal de trésorerie sont générées automatiquement lorsque vous enregistrez une remise en banque dans Sellsy.

Ces écritures peuvent ensuite être directement exportées vers votre logiciel de comptabilité pour une synchronisation parfaite de votre trésorerie.

___________________________________________________________

### **Enregistrer une remise en banque**

La remise en banque peut être effectuée de 2 façons :

**Méthode 1 : Action en masse depuis la liste des règlements**

1. Rendez-vous sur le menu "*Banque*" > "*Liste des règlements*"
2. Cochez le ou les règlements que vous souhaitez remettre en banque
3. Choisissez "*Remise en banque*" dans la liste déroulante des actions
4. Cliquez sur "*Valider*"

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2195069580/4b0c4fecf0469dc3ef8737427dc6/30053919-7f01-4293-999c-a1f11865836a?expires=1788635700&signature=d6d6156a550c8dfbe7639cc3c20b19ff229e920a10f815cc9e66b03a55b2a47b&req=diEuE8l4lIRXWfMW1HO4zTpeCLy9Ed5dcLAg4Xsqa72fS9Zm1gDyFJOanIqB%0AlFmndGHI6izw4bOpOzo%3D%0A)

Cette méthode est idéale pour traiter plusieurs règlements simultanément.

**Méthode 2 : Lors de l'enregistrement du règlement**

1. Depuis la page d'une facture, cliquez sur "*Enregistrer un paiement*"

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2195074150/e21c03fc4909a66b2327ea30823f/3402fe48-155e-4e54-b142-53701304b24e?expires=1788635700&signature=63c7c195ce49bb0a9fadb5e99953d7f7bfe6e2f7325f6883cedc6ee742d872af&req=diEuE8l5mYBaWfMW1HO4zUwkLx4Dk8OsO9wcJTYGKTbqEkSNllum1BXzXb4b%0AxI4v%0A)
![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2195072583/c2188ec2d1a12fda9f853b3b6e4a/428dd4d1-4f30-4a8e-a30f-f57718a13714?expires=1788635700&signature=09c5ef51ffbd1147c87d2ff445ddb101234176137820a5b32e1d36add1be3d4d&req=diEuE8l5n4RXWvMW1HO4zYiREbyNhyTn14lt%2BXra%2BIW9h2g1HEb%2BfJFROm20%0A46In%0A)
2. Saisissez les informations du paiement
3. Cochez l'option "*Ce règlement a été mis en banque*"
4. Validez

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446294141/268521040e0f2c1b6be1e897/b94e5ff3-992b-4b0e-9f26-cfa2c156d747?expires=1788635700&signature=5cc52552b66c722f09ac0574f915cca4c4dad7e1dfd020f94bee6995e3f046f1&req=cCQhFMB6nIVeFb4f3HP0gJBdo%2Fh0ltxmOnYYAu8DhS3PassOrryEoCILRAFx%0AwcPA6e7mrBNk96G6qg%3D%3D%0A)

### **Accéder au journal de trésorerie**

Pour consulter et exporter les écritures du journal de trésorerie :

1. Cliquez sur le menu "*Comptabilité*"
2. Sélectionnez "*Journal de trésorerie*"

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2195076949/5823bcc55caebe443a05b12c1856/85120dd8-3c23-43c1-ae57-04ceff04f7b6?expires=1788635700&signature=5a8b162c5a63c29f7fabfee4eb203d27d584f5145177587586ad36d5eed00255&req=diEuE8l5m4hbUPMW1HO4zQxbkSeZpjnny%2BNM1uw2YaOx%2FHUGrx95czWdEu0N%0Ac3mXR%2B96nMRoX3QkDrM%3D%0A)

Vous accédez ainsi à la liste de toutes les écritures de trésorerie prêtes à être exportées.

___________________________________________________________

### **Visualiser les écritures déjà exportées**

Une fois les écritures exportées, elles disparaissent automatiquement de la liste pour éviter les doublons.

Vous pouvez cependant les afficher à nouveau en utilisant le filtre "*Inclure les lignes déjà exportées*". Cette option est utile pour vérifier les exports passés ou pour effectuer des contrôles.
