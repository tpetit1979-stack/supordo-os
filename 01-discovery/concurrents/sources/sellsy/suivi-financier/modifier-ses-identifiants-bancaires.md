# Modifier ses identifiants bancaires

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261863001/40647c40a1cc43093c9ef8604fd6/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=a3ad76a134dd4fa7e945df8d6c1cc84923b63848e1bad7a1f203b3a77633ffc4&req=dSIhF8F4noFfWPMW1HO4zW24VZbpwr7hH7JkNFt%2BMsH6W9malxuiXP1%2BIyqN%0AbAfT0bW%2BQLckUcrCtwY%3D%0A)

Les identifiants de connexion de votre compte bancaire ont été modifiés, donc votre compte bancaire dans Sellsy ne se synchronise plus.

Il est essentiel de mettre à jour vos identifiants dans Sellsy plutôt que de supprimer et recréer la connexion, afin de conserver l'historique de vos rapprochements bancaires.

___________________________________________________________

### **Procédure de modification des identifiants**

Suivez ces étapes pour mettre à jour vos identifiants bancaires dans Sellsy.

**Étape 1 : Accéder à la liste des banques**

1. Depuis le menu principal, cliquez sur *"Banque"*
2. Sélectionnez *"Liste des banques"*

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446296712/1e40b42d5b81f06ca952682d/bcwVMsQ80YqJ_G4cj5ol2tsqoHVcTu1pP27LRCoe5G7Xs9Lrmm9I8ZLWVohCOPIQexrhFWv4JsceuB_G92SRx1nZN6JDAFpUko4kMI0-SbJsgp2oWzDJOCZjXLNgazCWd2PHttqy?expires=1788635700&signature=8e65460e0fed9da255b67e83abdbd8d6ac9d0766141ebd65a1972837009e77e9&req=cCQhFMB4moBdFb4f3HP0gNdFwTy92wPbc%2B54bwhWvEFnDeNGOQxJ8Z9MPGn8%0As7mBKAqL8%2FHr7xJPiQ%3D%3D%0A)

La liste de toutes vos connexions bancaires s'affiche.

**Étape 2 : Sélectionner la banque concernée**

1. Identifiez la banque dont vous souhaitez modifier les identifiants
2. Cliquez sur *"Voir plus"* sur la ligne de cette banque

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446296723/08dac0b0323e499692dbd7a7/PLSW_dEjcPI9LBJPKN1_xDlvmcNJFC18b_TW1hKG6arQd3deQBrCdjrbNwoLZNmmDEWr0GNCgGh_GnafjT0X9v1Eaj-y6JPNk6EYEEpZ356FabG61V4TtznSODzWT4MqdMkjrgl8?expires=1788635700&signature=34ac4c705def919551dd844bfa36e4ed2baa30c4ea80d7e419688fd870ac965a&req=cCQhFMB4moNcFb4f3HP0gAFqKkj7KuB%2BtoItB7bDwdsSlFa4wjZZYbMaKE4f%0AeIspo0M34h%2B7zbAFKQ%3D%3D%0A)

**Étape 3 : Accéder à la gestion des connexions**

1. Dans le menu *"Options"*, choisissez *"Gérer mes connexions"*

Vous accédez à la page de gestion de vos connexions bancaires.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/446296730/bd4bf1eb293beb7ee7194cef/7LuMZvePYur4II8AoEzcwBaUngIMTar5h87KE1PrJHha2bhj74jqEfdl6VR6DChsjDRfIQrDYvBvHzasUgfsHRkAYQa7j_UWACcdLf0dEt6rjwHEFMsqPJNgHAwkpzdXX3TxBlBh?expires=1788635700&signature=7818cbf989e0d86262b63a76b7c36ae0a27b0bae3f436df68101294e20e7d023&req=cCQhFMB4moJfFb4f3HP0gBe8xQWNw4DZkn%2B59shADIF8vsgJnziQYZfl2Sid%0AXZlbpaepMe5lorOYmg%3D%3D%0A)

**Étape 4 : Modifier les identifiants**

1. Sur la ligne de votre compte bancaire, cliquez sur les **trois points** à droite
2. Cliquez sur *"Modifier mes identifiants"*
3. Saisissez vos nouveaux identifiants bancaires
4. Validez

> **Attention : **Ne supprimez pas la connexion, vous perdriez sinon tous vos rapprochements bancaires et l'historique de vos transactions.

Saisissez vos nouveaux identifiants et validez.
