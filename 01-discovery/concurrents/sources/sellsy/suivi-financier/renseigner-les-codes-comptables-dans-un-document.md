# Renseigner les codes comptables dans un document

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2195055098/ab5292a09468949c91ce634c5f09/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=41c20d1811fadc8187aa2c096247e52dce969598e74c9a16a363821c1c58df17&req=diEuE8l7mIFWUfMW1HO4zRFrJPyF61cQsPUL%2Bp5XzmSF%2B4daUQCBqodSKQ2J%0AWJ6kEZvAqAKlTEQ4yEA%3D%0A)

Si vous n'utilisez pas le catalogue, par exemple si vous faites des prestations de service uniquement sur mesure, vous pouvez renseigner les codes comptables directement depuis les lignes de votre document.

Cette méthode vous offre une grande flexibilité pour adapter la comptabilisation à chaque situation spécifique.

___________________________________________________________

### **Définir un code comptable sur une ligne de document**

Pour renseigner un code comptable directement sur votre document de vente :

1. Lors de la création de votre document de vente, ajoutez une ligne
2. Cliquez sur la roue crantée au début de la ligne de vente
3. Sélectionnez le code comptable approprié dans le menu qui s'affiche
4. Validez votre choix

Le code comptable sera alors associé à cette ligne spécifique lors de l'envoi en comptabilité.

### **Définir un code comptable par défaut**

Pour simplifier la saisie, vous pouvez définir un code comptable par défaut qui s'appliquera automatiquement aux lignes vierges.

Cette configuration s'effectue dans vos préférences et vous permet de gagner du temps lors de la création de vos documents, tout en gardant la possibilité de modifier le code au cas par cas si nécessaire.
