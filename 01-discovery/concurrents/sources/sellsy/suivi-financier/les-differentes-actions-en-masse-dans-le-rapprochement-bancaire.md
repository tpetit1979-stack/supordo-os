# Les différentes actions en masse dans le rapprochement bancaire

### Réaliser une action en masse

Pour faire une action en masse, sélectionnez votre liste d’opérations.    

Il faut cliquer sur la flèche bleue à côté du nombre de transactions.

Ensuite, vous avez 4 possibilités d'action en masse :

- Valider les suggestions rapides,
- Transférer les actions,
- Modifier les moyens de paiement,
- Rapprocher au plan comptable.

### **Transférer les actions**

C'est une action particulière qui permet de transférer les rapprochement d'une transaction vers une autre. Le cas peut être nécessaire principalement dans 3 situations :

- Suite à une erreur de rapprochement, au lieu de supprimer le ou les rapprochements, il suffit de les transférer.
- Dans le cas des cartes à débit différé, vous pouvez faire le rapprochement sur les transactions fournies par la banque. Mais ces transactions seront supprimées en fin de mois pour être remplacées par une seule transaction du montant total. Vous pourrez donc sélectionner toutes ces transactions pour transférer leur rapprochement vers la transaction définitive (qui peut être dans un autre compte bancaire).
- Dans de rares cas, la banque peut nous renvoyer l'information d'une transaction supprimée ou modifiée, qui génère donc un doublon. Dans ce cas, la transaction passera dans le statut *"A corriger",* jusqu'à ce que vous transfériez son rapprochement.

___________________________________________________________

### **Modifier les moyens de paiement**

Vous avez la possibilité, avant de faire un rapprochement, de modifier le moyen de paiement utilisé. Vous pouvez le faire directement dans la ligne de la transaction mais aussi par la sélection en masse.

___________________________________________________________

### **Rapprocher au plan comptable**

Si l’opération ne peut être rapprochée à un document dans Sellsy, comme le paiement de la TVA ou le paiement des salaires par exemple, vous avez la possibilité de la rapprocher à un compte de votre plan comptable.
