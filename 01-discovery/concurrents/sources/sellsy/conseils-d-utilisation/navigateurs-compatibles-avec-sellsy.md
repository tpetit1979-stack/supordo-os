### Navigateurs pris en charge

Sellsy est compatible avec les navigateurs suivants :

- Google Chrome
- Mozilla Firefox
- Safari
- Microsoft Edge

___________________________________________________________

### Versions de navigateurs compatibles

Sellsy est conçu pour fonctionner avec :

- la version actuelle de chaque navigateur pris en charge
- les deux versions précédentes (N-2)

Cette compatibilité permet d’assurer un niveau optimal de sécurité et de performance.

Il est recommandé de maintenir le navigateur à jour afin de bénéficier de la meilleure expérience possible.

___________________________________________________________

### Recommandations d’utilisation

L’utilisation d’un navigateur non listé ou d’une version plus ancienne peut limiter l’accès à certaines fonctionnalités ou affecter l’affichage.

Pour une utilisation optimale de Sellsy, il est conseillé de :

- utiliser l’un des navigateurs pris en charge,
- maintenir le navigateur à jour,
- vérifier régulièrement les mises à jour du système.
