### **Conseil n°1 : videz le cache de votre navigateur**

Vider votre cache régulièrement permettra de faciliter le fonctionnement des applications présentes sur votre ordinateur et de fluidifier votre navigation sur internet.

**Comment procéder : **

- **Google Chrome :** [tutoriel](https://support.google.com/chrome/answer/2392709?hl=fr)
- **Firefox :** [tutoriel](https://support.mozilla.org/fr/kb/comment-vider-le-cache-de-firefox)
- **Edge :** [tutoriel](https://support.microsoft.com/fr-fr/microsoft-edge/afficher-et-supprimer-l-historique-du-navigateur-dans-microsoft-edge-00cf7943-a9e1-975a-a33d-ac10ce454ca4)
- **Safari :** [tutoriel](https://assistance.orange.fr/ordinateurs-peripheriques/installer-et-utiliser/la-recherche-et-navigation-sur-le-web-cookies/un-navigateur/safari-mac/usages-avances/safari-mac-vider-le-cache_166844-715466#onglet2)

### **Conseil n°2 : vérifiez vos extensions**

Les extensions installées sur votre navigateur peuvent provoquer un ralentissement ou des erreurs inhabituelles : les bloqueurs de publicité, Google Docs, des gestionnaires de mots de passe (Dashlane par exemple), les bloqueurs de pop-up, etc. Nous vous conseillons de les désactiver une à une afin d’identifier celle qui en est à l’origine. 

Utilisez-vous l’extension Dashlane sur Google Chrome ? Nous avons identifié que cette extension pouvait être à l’origine d’un ralentissement lors de l’utilisation de Sellsy, voici comment la désactiver : 

 - Rendez-vous sur l’extension Dashlane présent en haut de votre page de navigation ou disponible en cliquant sur la pièce de Puzzle.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/479879092/f9f383c5a468be13745cff81/d382dc25-341b-4966-b4d0-d6681e8ec0b9?expires=1788635700&signature=102bf68fe5ee376d07732afd778e21921c5285f80347bea4121778159ef58c78&req=cCcuHs53nYhdFb4f3HP0gBX%2FkBecbuqkYgjxYmVilq1tQmBlbauaRfOsftjY%0A8PQ54nAFWKVXaF6kLA%3D%3D%0A)

- Cliquez sur l'onglet "Saisie". Ensuite, cochez "Ne rien saisir sur ce site web".

- Pour finir, redémarrez votre navigateur.

### **Conseil n°3 : contrôlez votre VPN**

L'utilisation d'un VPN peut bloquer certaines actions réalisées sur votre compte Sellsy par exemple lors de votre connexion ou lors de la génération de documents.

Si un message d'erreur s'affiche lors de ces actions, nous vous conseillons de désactiver temporairement votre VPN.

> **Bon à savoir :** la connexion à votre compte Sellsy est sécurisée et chiffrée, l'utilisation d'un VPN n'augmentera pas la sécurisation de vos données.

___________________________________________________________

### **Conseil n°4 : vérifiez la version de votre OS ainsi que les navigateurs incompatibles**

Letsencrypt a mis à jour ses certificats SSL le 30 septembre 2021. Par conséquent, certaines plateformes ne sont plus compatibles.

Voici les pré-requis en terme de configuration pour une utilisation optimale de Sellsy :

- version Mac OS minimum >= 10.12.1
- version Windows minimum >= XP SP3
- version Firefox >= 50

Vous pourrez retrouver la liste complète des plateformes compatibles et incompatibles à l’adresse suivante : [https://letsencrypt.org/docs/certificate-compatibility/](https://letsencrypt.org/docs/certificate-compatibility/) 

**Si votre ordinateur n’est plus compatible :** faites une mise à jour du système ou utilisez le navigateur Firefox dans une version supérieure à 50.
