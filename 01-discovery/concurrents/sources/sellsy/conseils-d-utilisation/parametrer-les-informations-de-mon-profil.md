# Paramétrer les informations de mon profil

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261774903/fb5cc7eec05995c4bfd354d02524/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=4f37c7365140a3478459ff09575955304480bce62a62fd28d0b142b2e84063b4&req=dSIhF855mYhfWvMW1HO4zanM187vOecJNyoTN1Nwm407nUqXdjuNs471pKrN%0AkKHZ%2B20OHWKEJZ7fMaY%3D%0A)

Sur votre compte Sellsy, vous avez la possibilité de mettre à jour les informations de votre profil collaborateur (nom, prénom, email, fonction, numéro de téléphone, fuseau horaire et langue). 
​

Rendez-vous sur votre profil.

Cliquez sur *“options”* et *“modifier”*
