### **Activer la double authentification**

**1. Si la double authentification n'a pas été rendue obligatoire par l'administrateur de votre compte Sellsy,** vous pouvez l'activer volontairement pour renforcer la sécurité de votre compte.

Suivez ces instructions pour configurer la double authentification sur Sellsy :

Rendez-vous dans *Menu > Réglages > Ma double authentification*.

La double authentification est désactivée par défaut. Pour l’activer, vous devez choisir votre méthode d’authentification principale.

Vous serez alors déconnecté de votre compte afin de finaliser la configuration.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2144138366/989277cb2c9ca1787ad4a809c22b/-3C103U_lYBhfB2gswRyTKayDgmEa4aSSpHIpd0nR_J26ZpJFeuzdr8BzaBOCfbAcgQpTKHm3eWjU2O4x5CCnVDWNumY-vpscXvBmhpzhPwIT6Fi6EBnUZlxJMu8AhNe1klRhjdQRBILJ4sn7g?expires=1788635700&signature=663be16d3c8bbb3030d6f8549cb6e794a001662fec347cd6522a219a2d9314db&req=diEjEsh9lYJZX%2FMW1HO4zd0GEovGPewfSUMNV2FVbSs0w%2BWPHG42%2BgdraYDh%0AOx4TFl0QsOk8co%2FR4Po%3D%0A)

Voici votre écran de paramétrage une fois votre double authentification configurée.

**2. Si la double authentification a été rendue obligatoire par l’administrateur du compte Sellsy. **Lorsqu’un administrateur rend obligatoire l’activation de la double authentification à ses collaborateurs, il vous sera demandé dès votre prochaine connexion de configurer la double authentification afin de pouvoir accéder à votre compte en toute sécurité.

Lors de votre connexion, entrez votre adresse mail et votre mot de passe de façon habituelle. Puis, suivez les étapes suivantes :

1. Appuyez sur *“continuer”*

2. Selon votre situation, téléchargez/ utilisez l’application d’authentification souhaitée

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2144138380/f6f1a15c91fb42083e0da88a14c7/Step-2B2.png?expires=1788635700&signature=79ab0eef7f0b94dec3cc6d368fbe83936a24e54ce98f0aa4bacd6f1333474090&req=diEjEsh9lYJXWfMW1HO4zTFQGOH3kob4VqJnTdglH%2F2P6pqn6onV8eD93PHG%0A0JO%2BZCUJt4nxLApgFIc%3D%0A)

3. Scannez le QR code depuis l’application ou saisissez le code manuel

4. Saisissez le code généré par votre application d’authentification

Bon à savoir : Si vous vous **connectez à Sellsy depuis votre appareil habituel**, vous pouvez choisir de cocher la case ***“Faire confiance à cet appareil”*** afin de ne plus avoir à renseigner de code de vérification pendant 30 jours.

Une fois le code renseigné, vous pouvez vous connecter.

### **Choisir son application d'authentification**

**Utiliser une application sur téléphone**

L'utilisation d'un téléphone n'est pas obligatoire pour configurer la double authentification. Si vous souhaitez tout de même utiliser votre téléphone, plusieurs applications permettent de générer des codes de vérification. Vous n'êtes pas limité à Google Authenticator.

Les applications les plus courantes :

- **Authy** : **[https://www.authy.com/](https://www.authy.com/)**
- **Microsoft Authenticator** : disponible sur l'App Store et le Google Play Store

**Utiliser une application sur ordinateur**

Il est également possible de configurer la double authentification directement depuis votre ordinateur, sans utiliser de téléphone.

Deux options sont disponibles :

- **Proton Pass** (application bureau)

### **Gérer vos codes de secours**

En cas de perte de votre appareil ou si vous ne l'avez pas avec vous, vous pouvez utiliser un des 10 codes de secours à usage unique fournis lors de la configuration de la double authentification.

Pour retrouver vos codes de secours :

1. Rendez-vous dans *Menu > Réglages > Ma double authentification*
2. Cliquez sur *"Voir les codes"*

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2144153815/a2b725c1fafcacf3f8e2b04c08d0/RxPSD8DqPoE1N2GbdpPut4ZKCKWuKkLK9C8Zx7VUmInxMOwRG9awH_1fg1epHqdbbWGkD9VAusuguaDeCuJ0PwFww3H_5fG5TFbsCsJK9FOHwCi0IvBYoUzyVdcdvU9Q9U8WqPMY-0iFVY67UA?expires=1788635700&signature=6e6ad93aa0efac77e98aa6cb5983a528eb8ddded099fbb5270a79cc151805966&req=diEjEsh7noleXPMW1HO4zRVBieH%2F9gJ7t8hhiZZlarBnZ4TlEcvnPgz8%2BYge%0AjrsEeay36Bu6W%2F%2FTRTk%3D%0A)

> **Bon à savoir :** si vous avez utilisé tous vos codes de secours, vous pouvez en générer de nouveaux en cliquant sur *"Voir les codes"* puis *"Générer de nouveaux codes"*.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2144154661/c981189df8159705479f05ed2030/5J5bhTKE_3PzPkyZiLAZXKat3Y9ue3s8a420IvkxE7bvlWFiNFOZPceqVrGyuR1Q44nISHglGrTWdtiCdzQblW0D4tYD1zjkQhSHOyFXSZY3FwHKr7KCcSWFPMNtOBMg-juJ_t-5pV7gg2MW8g?expires=1788635700&signature=ba81feb021aad74e118033a98d049baacad2d2ae85578570982b65497de0c112&req=diEjEsh7mYdZWPMW1HO4zZjVMVkAkXF8AjvOJp8GQ%2BISTv31mupra7CKWgzF%0AtqGld2cbTJ5xtnHfVFo%3D%0A)


Si vous n’êtes pas en mesure de recevoir un code de vérification, vous pouvez utiliser un code de secours en cliquant sur *“J’ai un code de secours”*. Les codes de secours vous ont été fournis lors de la configuration de la double authentification, mais ils restent disponibles à tout moment depuis *Menu > Réglages > Ma double authentification*.

### **Gérer vos appareils de confiance**

Sur la page *Ma double authentification*, vous retrouvez la liste de vos appareils de confiance qui vous permettent d'éviter de saisir un code de sécurité pendant 30 jours lors de chaque connexion.

Vous pouvez choisir de ne plus faire confiance à un appareil s'il vous semble suspect ou qu'il n'est plus en votre possession.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2144206284/d8c49c4181b93db87afc04ada78b/cdTEUESYjEYDZAi4EhvpEk5osEwxQk7DHiyYwB44-FE58vi4qowm8to6R06cJAY9zMZLhFlHnf0co1gTIu08ecAHUr1_RMo8mij_fTsZpuzP4DM7L3xL3bne6t3zcBtdMsIcK49qCBazbogMuw?expires=1788635700&signature=ad87a706bcc48adf89a76826d4669fd0f93f49a58a750c4a5cd43410fe08f10b&req=diEjEst%2Bm4NXXfMW1HO4zQQIs%2FvIWEIZl9SZg%2Fms4F%2BTijRux6S4Q5S%2Bt1su%0AldXKnq7LTaShDWEg13Q%3D%0A)

> Bon à savoir : Si vous changez d'appareil (téléphone perdu, volé, remplacé), vous devez **reconfigurer la double authentification (2FA)** sur votre nouveau téléphone pour continuer à accéder à votre compte Sellsy en toute sécurité.
> La procédure varie selon que vous disposez encore de vos codes de secours ou non.
