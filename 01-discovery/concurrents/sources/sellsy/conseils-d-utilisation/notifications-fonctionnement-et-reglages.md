# Notifications : fonctionnement et réglages

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/1261772995/b186fd11cab70dd611b6d1701ae7/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=fc351b6abb67fe61d97868eea68517bb901b069fc9d29199c66fd519d916a6ff&req=dSIhF855n4hWXPMW1HO4zdYuO3wc4sdKaiO%2FjoNBMVZRrE6nvziHmE6%2BYZAv%0Aw1kiD3Dp8FuEnqTMFdg%3D%0A)

Sellsy vous permet d'être alerté lorsque des actions sont accomplies sur votre compte mais aussi lorsqu'un de vos collaborateurs vous mentionne dans un commentaire par exemple.

Il existe deux types de notifications :

- Les notifications dans le **centre de notifications** (directement sur Sellsy)
- Les **notifications emails**

___________________________________________________________

### **Centre de notifications**

Lorsqu'une nouvelle notification est disponible, une alerte s'affiche sur votre bouton *"Notifications"* en haut de votre page Sellsy. En cliquant sur ce bouton, vous accéderez à la fois à :

- **Vos notifications** : mentions, traitement des imports
- **Vos alertes** : support, stocks, timers, etc.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/477299781/296f7cc472035cde493ae884/beIVXZbFsUpIHZdEZH2XR0KQF7SVABZVVlZ79hr4Io6VnDuipTAl5lrZBc4jFSvTHLRAEwSWzY8CqE_IFDX_7ghEHQSEcuS7zf6_u2LE5A1DCyT5y0V9ah7J_ruUM2qnMp8V5R2j?expires=1788635700&signature=f57c3b082f204058d24b3039717c5e2556ed828a33bc5954e3dea3abaa57b0ea&req=cCcgFMB3moleFb4f3HP0gH2w%2Fh2z8N1tWf9EhyT9MAZIduc6EfgHHpYcNUzm%0AWhFjcdwHL4HGx9Ij7A%3D%3D%0A)

**Onglet "Notifications"**

Vous retrouverez notamment vos mentions. Vos nouvelles mentions se distinguent par la pastille bleue à droite de la notification.

En effet, vos collaborateurs peuvent facilement vous mentionner dans les commentaires des fiches de votre répertoire ou des opportunités en utilisant un @ devant votre nom.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/477299721/7fe1b79cba69e6f0ea65fa58/kUCvSO-nddT65pKdMtBMmg6TdW9od9LrHa62ZnbOYpZ1PUO0zm7TZhPFitjCPziUr8U4P2S0e_TJsUqxGc8NT6ZR1k3Dpw0dVAWqsicBjGbEK_kDpSLLCXHy-FkCk5GJvJU-sH4y?expires=1788635700&signature=51bd9e69f44c7bf428a56eb9f941a644ce93772178d25253df60612cc392b2c7&req=cCcgFMB3moNeFb4f3HP0gFJU2rs1gWPB3lzJDxEyayucn491kNZHhc0jd8on%0AzGpJiDIn3aMGlobolQ%3D%3D%0A)

> **Attention :** Si vous ne parvenez pas à taguer l'un de vos collaborateurs, cela peut être lié à son profil de privilèges défini par l'administrateur du compte.

En cliquant sur la notification, vous serez automatiquement redirigé vers la mention en question. Vous pouvez également marquer vos notifications comme lues en cliquant sur *"Tout marquer comme lu"*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/477299792/7d83d38a1d5e0e6c66435bcc/GM4ya9Uahwk2J0YZ-iH_JLE2vMBO-i0j0wHZQ_5pyRsi2Mhd-8QArYivrMKZa3NBEtBs-jSpdwOooply1_qNqKbeoJHgpKyF73I3mJa45UPdrqsbPO84CAs_Hv4iboXD9vYW8AMo?expires=1788635700&signature=ce001b62dd9cbca80b0d7e5663f83080afb0b1a84bd0af415ae4f974feebbaf9&req=cCcgFMB3mohdFb4f3HP0gPbxXbsd%2FVDQnMXV2625YuoxcwMDrsOVI0RF1Ek2%0AVZ0331fbV03zPKIWbA%3D%3D%0A)

**Onglet "Alertes"**

Vous retrouverez :

- Vos alertes support : vos tickets et tickets non assignés
- Vos abonnements du jour
- Vos alertes stocks
- Vos alertes timers

En cliquant sur l'alerte, vous retrouverez davantage d'informations.

![](https://downloads.intercomcdn.com/i/o/919916484/4869de18b708c39e10f9f94f/Alertes.png?expires=1788635700&signature=5e55198fbe24113496d9c69a856b0533c12c4d63d140b7eb2e1fd122f8f5190d&req=fSEuH8h4mYlbFb4f3HP0gBgazY7Y9RPqmw4iCHxtpRJ4muSHuqvpfpan6iWj%0AfcXv4OSHkoY6NoH4jA%3D%3D%0A)

> **Bon à savoir :** Vous pouvez, lors de la consultation de vos notifications, accéder directement aux réglages en cliquant sur la roue crantée en haut à droite de la fenêtre.

Réglages 

Pour accéder aux réglages de vos notifications, cliquez sur *"Menu"* puis *"Réglages"*.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/477299746/5e2f04276401f2f3a2b3f876/4j4j0qKmOTQyLytjrlbhLF2v4BzX-R_okhLDikxBvjCDmfFAgiDRLTFGPJzeQK2RCD88NWiBeXrQ_e_IdXRr2UnyxzN9u4BtNzj94v26MncjbCSr2j5D7f7gtuBgqGz1rJ_-nVnq?expires=1788635700&signature=8eaf2e498da2d085a347331e7cdc89694ee762435883782d356dde4fa2e0b5e0&req=cCcgFMB3moVZFb4f3HP0gHXoPTtPTi6b6GAfKpG2wXG56n6ms7EvdZIjM45%2B%0Anz6kGEA93xaN%2BbLP%2BQ%3D%3D%0A)

Ensuite, rendez-vous dans *"Mon profil"* puis *"Mes notifications"*.

Vous avez la possibilité d'**activer le mode ne pas déranger** afin de désactiver l'ensemble des notifications.

Vous pouvez également décider d'activer les notifications lorsque vous êtes mentionné dans un commentaire ou un objet par exemple.

Si vous désactivez cette option, vous recevrez uniquement des notifications pour vos objets et ceux partagés avec vous : les objets dont vous êtes propriétaires ainsi que les objets que les collaborateurs ont partagé avec vous.

![](https://sellsy-a9cc78fb6d3a.intercom-attachments-7.com/i/o/477299755/036249279bed2cd7c7242454/7DuysYcsk9ZVGZT5NN5tJYf0qV4eX2lvXlisSyGdFXT3ypzb_4n1aQdl8Tlj83pcV3dk_bSRW4SLbRfMzZALFXVyqQ8jmi2ZMz_LWKAHUZsm4aRmn6qdQjK_WI7WBQsHb48MImWk?expires=1788635700&signature=2287a10c3c178d8e9ef466f8e2557fdcb130e4bdb69f1a286e9feaf05b3eb9e8&req=cCcgFMB3moRaFb4f3HP0gCpAkD94oaG1ZwarCKSUYhlyLDu8OW7MF0taFW4l%0AzBv1Y0GyvVeUmAL2NA%3D%3D%0A)

> **Bon à savoir :** Si malgré le bon paramétrage de vos notifications, certaines ne vous parviennent pas, cela peut être dû à votre profil de privilège. Dans ce cas, il est nécessaire de contacter votre administrateur afin qu'il paramètre vos accès depuis son espace personnel.

### Les notifications emails

Il est également possible de recevoir des **notifications par email**. Pour les paramétrer, rendez-vous dans *"Menu > Réglages > Mon profil > Mes notifications emails"*.

![](https://downloads.intercomcdn.com/i/o/919894042/7916186430438d45a6964539/Notifications+emails.png?expires=1788635700&signature=9825ba3b972fbf8c5e8a7a954e01192e44e1e154a829f8ec1677a182f441323d&req=fSEuHsB6nYVdFb4f3HP0gM7%2BgYclyfIFYz6OhwGMhSH%2BduR2pZ1mZzuavN%2FJ%0AU%2BwCkuCXI85waBMW1g%3D%3D%0A)

Vous pourrez activer les notifications et choisir pour quels types d'objets vous souhaitez être notifié. Vous pouvez être alerté de toutes les actions du compte (en fonction de vos droits d'accès) ou seulement des actions sur les objets dont vous êtes le propriétaire. Vous pouvez par exemple être notifié quand un devis est signé, quand une facture est payée, quand un commentaire est ajouté, et bien plus encore.

Pour recevoir une notification lorsqu’une tâche est créée via les automatisations, il est nécessaire d’avoir correctement paramétré vos notifications :

- Sélectionnez l’onglet **« Tâches »**
- Dans le champ **« Objets »**, sélectionnez **« les miens + ceux partagés avec moi »**
- Cochez l’option **« création »**

Le paramétrage effectué directement dans l’automatisation permet ensuite d’ajouter des notifications complémentaires, soit **via une notification dans Sellsy**, soit **par email**, selon vos besoins.

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2405420728/38ef17bd3b4aa6c9e664cc26bcea/image.png?expires=1788635700&signature=695437934a759b0056bbf318114379806f17ec5092ccbb0f682fc46ee7327392&req=diQnE818nYZdUfMW1HO4zWdfozHB53DIQiARvQ6qieL%2FOdD294%2Bl6PCSAE6v%0A0zmjfpeUC2aIuRx2KDw%3D%0A)

> **Bon à savoir : **Ces réglages sont individuels, un commercial pourra définir des alertes très différentes de celles d'un opérateur logistique par exemple.
