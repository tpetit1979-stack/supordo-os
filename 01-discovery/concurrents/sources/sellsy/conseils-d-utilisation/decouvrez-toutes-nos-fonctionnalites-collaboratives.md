# Découvrez toutes nos fonctionnalités collaboratives

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2252271746/2aef8b16d5bac71a890d912a2763/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=b4294a5029c0e2bad823e72f34e491d24257e7a4814a1a634191e3147dfb86b8&req=diIiFMt5nIZbX%2FMW1HO4zXyMAExD2cWTLvRMaEJVs%2BQV0h9RiQSpyGA1fELO%0A2PP8maWkITfZyKX9LCY%3D%0A)

Sellsy propose différentes fonctionnalités pour optimiser la collaboration entre les équipes.

___________________________________________________________

### **Mentionner un collaborateur**

Vous avez la possibilité de mentionner un collaborateur dans un commentaire, sur les différentes fiches Sellsy (clients, prospects, sociétés, documents de vente, opportunités…).

Une notification est transmise à votre collaborateur directement sur l'interface Sellsy.

![](https://downloads.intercomcdn.com/i/o/781533376/53b99d7a4b66120b6e7d5b2d/Capture+d%E2%80%99e%CC%81cran+2023-07-07+a%CC%80+15.05.30.png?expires=1788635700&signature=4f39dc3156f4b5dab9f2100fd824ce5a6efb3ed2c90648024bddc898de24c6f4&req=cygmE8p9noZZFb4f3HP0gG9YUMcBrYMQGy2QirZ1MtYIcrwCsy4RnK2EHcmI%0A2oQNEAz9EnFIyGv8jw%3D%3D%0A)

___________________________________________________________

### **Épingler un élément**

Sur toutes les fiches, vous avez également la possibilité d'épingler un commentaire, une tâche, un email, un événement ou un appel.

Cette fonctionnalité d'épinglement permettra à tous vos collaborateurs de retrouver facilement un élément important dans les différentes fiches.

![](https://downloads.intercomcdn.com/i/o/781533597/d747437ecd0aec98d4069e33/Capture+d%E2%80%99e%CC%81cran+2023-07-10+a%CC%80+09.25.13.png?expires=1788635700&signature=a13951235e7eba075486328fe6910b22580688da50b16b201380c9fc7a6574c5&req=cygmE8p9mIhYFb4f3HP0gPMmEPtESoSHoE3%2BbOFCnW%2F7LVChZB8keM5VKoX1%0AsijWL6sy2plpjeL%2FYQ%3D%3D%0A)

___________________________________________________________

### **Intégration avec Slack**

Si vous avez besoin d'une alternative pour continuer à échanger directement avec vos collaborateurs, nous vous recommandons l'utilisation de la messagerie interne **[Slack version gratuite](https://slack.com/pricing/free)**.

Nous proposons un connecteur natif disponible depuis Sellsy. Il vous permet d'automatiser la remontée d'information en recevant un message Slack. Vous pouvez ainsi être alerté en temps réel des mises à jour sur Sellsy.

Par exemple, vous pourrez recevoir un message lorsqu'un client a été créé et ainsi échanger sur ce sujet avec vos collaborateurs.

Pour installer ce connecteur, n'hésitez pas à consulter notre guide : **[Webhooks](https://help.sellsy.com/fr/articles/5876622-webhooks)**
