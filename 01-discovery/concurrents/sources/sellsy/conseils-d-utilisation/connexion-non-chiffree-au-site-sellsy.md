# Connexion non chiffrée au site Sellsy

![](https://downloads.intercomcdn.com/i/o/p6qpddj1/2248990954/457c9b2c9d45bbd51e803b0a998d/FAQ-Bannie%CC%80reAcademy-2+%282%29.png?expires=1788635700&signature=55b494bdc2628602fe2521e386c6c5ca54565080803a643ff3682d7297833996&req=diIjHsB3nYhaXfMW1HO4zevzbPzoMaV4BODX2rKjctnLrf52MTSiax5wd%2B9i%0AJcoXJr9SVDApqA7wPdc%3D%0A)

Lors de votre connexion à Sellsy, un message mentionnant un problème de connexion à un site non sécurisé peut apparaître.

Letsencrypt a mis à jour ses certificats SSL le 30 septembre 2021. Par conséquent, certaines plateformes ne sont plus compatibles.

### 

___________________________________________________________

### **Vérifier la compatibilité de votre système**

Voici les pré-requis en termes de configuration pour une utilisation optimale de Sellsy :

- Version Mac OS minimum >= 10.12.1
- Version Windows minimum >= XP SP3
- Version Firefox >= 50

Vous pourrez retrouver la liste complète des plateformes compatibles et incompatibles suite à cette mise à jour à l'adresse suivante : **[https://letsencrypt.org/docs/certificate-compatibility/](https://letsencrypt.org/docs/certificate-compatibility/)**

**Si votre ordinateur n’est plus compatible :** si votre version de OS est trop ancienne, vérifiez via Google quelle est la dernière version de firefox compatible avec votre version de Mac os. Si une version de firefox supérieure à 50 est compatible, nous vous recommandons de la télécharger [via ce lien](https://ftp.mozilla.org/pub/firefox/releases/).

> **Bon à savoir :** Pour connaître la version de votre ordinateur :
> - **Mac :** Cliquez sur la pomme en haut à gauche de votre écran puis sur *"À propos de ce Mac"*
> - **Windows :** Rendez-vous dans *"Démarrer > Paramètres > Système > À propos de"* puis sous *"Spécifications de l'appareil"*, consultez le *"Type du système"*

**Afficher le certificat de votre navigateur**

Pour afficher le certificat de votre navigateur, cliquez sur la zone sécurisée (ou en rouge, si une erreur est présente) dans la barre d'adresse.

### **Vérifier vos antivirus et adblocker**

Certains antivirus ou adblocker empêchent l'accès à certains sites web. Désinstallez-les de façon temporaire afin de retrouver l'accès sécurisé à votre compte Sellsy.
