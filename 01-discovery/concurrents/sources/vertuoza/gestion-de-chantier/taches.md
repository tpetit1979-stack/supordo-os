# Tâches

La gestion des tâches, via le menu prévu ou via la première section de la partie "Suivi de Chantier", simplifie la création, l'attribution et le suivi des activités spécifiques à chaque chantier. 
Cette fonctionnalité favorise une coordination efficace entre les gestionnaires, assurant ainsi un suivi précis de l'avancement des chantiers.
​

### **Navigation dans l'écran des tâches:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une zone de recherche.
2. Le tableau reprenant les informations.
3. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
4. Le bouton "Nouveau" pour créer un nouvel élément.

### **Créer et assigner une tâche**

1. **Accéder à l'Onglet "Chantier" :**
- Cliquez sur l'cône **"Voir"**.
- Cliquer sur l'onglet Tâche.
2. **Ajouter une Tâche :**
- Pour créer une nouvelle tâche, cliquez sur le symbole "**+ Nouveau**".
- Remplissez les champs: tels que le "Responsable" de la tâche, le "Type de Tâche" (par exemple, tâche administrative), la "Description" de la tâche, et la "Date d'Échéance".
- Utilisez le champ "Remarque" pour ajouter des informations supplémentaires si nécessaire.
3. **Soumettre la Tâche :**
- Une fois les détails de la tâche saisis, cliquez sur "Soumettre" pour enregistrer la tâche dans le système.
4. **Visualiser dans le Tableau Récapitulatif :**
- La tâche nouvellement créée sera maintenant visible dans le tableau récapitulatif du suivi de chantier.
- Un code couleur indique le statut de la tâche : rouge pour "en retard", bleu pour "en cours", et vert pour "tâche clôturée".
5. **Actions sur les Tâches :**
- Chaque tâche dans le tableau récapitulatif dispose de boutons d'actions.
- "Rééditer" permet de modifier les détails de la tâche.
- "Clôturer" marque la tâche comme terminée.
- "Supprimer" permet de retirer la tâche si nécessaire.
