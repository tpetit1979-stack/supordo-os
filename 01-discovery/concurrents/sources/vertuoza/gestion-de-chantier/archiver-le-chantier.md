# Archiver le chantier

Archiver un chantier a pour objectif principal d'optimiser l'organisation en retirant le chantier des modules "Gestion de Chantier" et "Planning".
​

### **Attention:**

Cette action ne supprime pas le chantier, mais le place dans l'historique des chantiers, accessible depuis la section "Statistiques".
​

### **Comment archiver un chantier?**

1. **Accéder aux Informations Générales :**
- Dans la gestion du chantier, allez dans la section "Informations Générales"
2. **Cliquer sur les 3 points à droite**
- Cliquer sur archiver

Ou bien  si vous ne souhaitez pas rentrer devoir rentrer dans le chantier :

1. Allez dans l'onglets **"Chantiers"**

2. Cliquez directement sur les 3 petits points
3. Cliquez sur **"Archiver"**


Comment r**etrouver et Réactiver un Chantier Archivé.**

1. **Accéder à l'historique des Chantiers :**
- Pour retrouver les chantiers archivés: Statistiques < Historique < Historique de chantier
2. **Gestion des Chantiers Archivés :**
- Vous trouverez tous les chantiers archivés.
- Pour chaque chantier, vous avez la possibilité de visualiser ses détails en cliquant sur “l’œil”
3. **Réactiver un Chantier :**
- Si nécessaire, réactivez un chantier en cliquant sur l'icône "marteau".
