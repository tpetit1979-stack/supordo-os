# Comment se connecter à plusieurs environnements en même temps?

Pour vous connecter simultanément à plusieurs environnements Vertuoza, vous devez créer des profils distincts dans votre navigateur (Google Chrome, Mozilla Firefox, …). 

⚠️ Si vous tentez de vous connecter sur différents environnements via le même profil de votre navigateur, seule la connexion au dernier environnement sera prise en compte. 

Suivez les liens ci-dessous pour créer ces profils, en fonction du navigateur que vous utilisez :

- **[Google Chrome](https://support.google.com/chrome/answer/2364824?hl=fr&co=GENIE.Platform%3DDesktop)**
- **[Mozilla Firefox](https://support.mozilla.org/fr/kb/gestionnaire-profils-creer-supprimer-changer-profils-firefox#:~:text=dans%20la%20fen%C3%AAtre%20Firefox%20%E2%80%93%20Choisissez,votre%20pr%C3%A9nom%20ou%20votre%20nom.)**
- **[Microsoft Edge](https://support.microsoft.com/fr-fr/topic/se-connecter-et-cr%C3%A9er-plusieurs-profils-dans-microsoft-edge-df94e622-2061-49ae-ad1d-6f0e43ce6435)**
