# Comment retrouver un mot de passe qui est enregistré sur votre navigateur ?

[Vidéo]()

### 
Chrome :

1. Cliquez sur les trois points verticaux en haut à droite pour ouvrir le menu, puis sélectionnez **Paramètres**.
2. Accédez à la section **mots de passe et saisie automatique**.
3. Cliquez sur **Gestionnaire de mots de passe**.
4. Vous verrez alors tous vos mots de passe enregistrés. Veuillez chercher "**Vertuoza.com**" afin de retrouver votre ancien mot de passe enregistrer.

### 
Edge :

1. Ouvrez le menu Edge en cliquant sur l'icône « ... » située en haut à droite.
2. Allez dans **« Paramètres »**, puis accédez directement à la rubrique « Profils ».
3. Cliquez sur **« Mots de passe »** pour voir la liste des mots de passe enregistrés.
4. Sélectionnez le compte dont vous souhaitez consulter le mot de passe et cliquez sur l'icône en forme d'œil à droite du mot de passe. Pour des raisons de sécurité, le mot de passe est d'abord caché sous forme de points.

### Safari :

1. Ouvrez Safari et allez dans **Réglages (ou Préférences)** depuis le menu Safari.
2. Sélectionnez l'onglet **Mots de passe**.
3. Après vous être authentifié, une liste de sites web avec les mots de passe enregistrés s'affichera.
4. Sélectionnez un site pour afficher son mot de passe, que vous pouvez également modifier ou supprimer si nécessaire.
