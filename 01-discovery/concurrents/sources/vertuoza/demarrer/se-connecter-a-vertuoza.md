# Se connecter à Vertuoza

Pour vous connecter à votre environnement Vertuoza, rendez-vous dans votre boîte mail dans la quelle vous avez reçu un mail avec toutes les informations nécessaires pour vous connecter à Vertuoza.

1. Copiez le lien de votre environnement avec votre tenantID 
( [https://vertuoza.app/?tenant_id=tenantid](https://vertuoza.app/?tenant_id=tenantid)) et collez-le dans une nouvelle page Internet.
2. Sélectionnez le type de compte "Gestion".
3. Entrez votre nom d'utilisateur et le mot de passe reçu dans le mail de connexion.

### Comment modifier le mot de passe de mon profil?

Vous avez toujours la possibilité de **changer le mot de passe** de votre profil via les paramètres de votre profil.

**Attention :** Après avoir cliqué sur votre lien de connexion, vérifiez que celui-ci se termine bien par votre numéro de société après le signe « = » et non par le chiffre 1. 

Cela garantit que votre identifiant et votre mot de passe seront correctement reconnus. N’hésitez pas à cliquer sur l’URL pour vérifier ce point si vous ne parvenez pas à vous connecter.
