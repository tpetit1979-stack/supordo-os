# Réinitialiser le mot de passe

Réinitialiser le mot de passe
​
Vous pouvez réinitialiser votre mot de passe en cliquant sur le lien sous le champ "Mot de passe" sur l'écran de connexion. 

![](https://downloads.intercomcdn.eu/i/o/yr18hzl2/70268187/d5bc2d9eedf8f71a90fb2a319af4/f060b78b-2c0a-48fd-8c06-909c845e8e05?expires=1788620400&signature=67a58a1c79c9b6d191f15acc42f722e55e2d60cea5ec5acbc5e83d9c707d77b7&req=19Vtw1D7pDBk2hL085ZhoZKp6L73pSrd9VaQBBkddnyGET3Jhv6H2%2BrOVK1r%0AL44KRdYubg4JPylw%0A)

Vous avez impérativement besoin de votre identifiant et de l'adresse mail liée à cette identifiant. Si vous n'avez pas un des deux, vous pouvez :

- Soit demander à un collègue de vous les communiquer (accessible via Paramètres > Utilisateurs)
- Soit contacter notre équipe via [support@vertuoza.com](mailto:support@vertuoza.com)

Note : Vérifiez que l’URL de connexion se termine correctement par votre numéro de société, afin que votre identifiant et votre mot de passe soient correctement reconnus.
