# L'application est-elle disponible sur les tablettes Windows ?

Non, notre application est uniquement disponible sur le Playstore pour les appareils Android et sur l'Applestore pour les appareils iOS. Les tablettes Windows ne sont pas compatibles. Vous avez simplement besoin d'un accès WiFi ou 4G pour utiliser notre application sur les appareils compatibles.
