# Planning par homme

## 🔑 **Fonctionnalités principales**

- Création et planification d’interventions directement depuis l’interface du planning
- Édition complète des interventions : ajustez les détails à tout moment
- Fonctionnalité **drag & drop** pour planifier et replanifier intuitivement
- Outil de planning entièrement opérationnel, conçu pour remplacer l’ancien système
- Aucune limite d’ouvriers : gérez facilement des équipes de toute taille
- Possibilité de personnaliser la vue du planning avec :
- **Affichage sélectif** : choisissez quels ouvriers afficher ou masquer. Utile pour cacher les ouvriers rarement planifiés et réduire l’encombrement visuel. Filtrez, par exemple, pour n’afficher que les chefs d’équipe afin d’avoir une vue stratégique.
- **Ordre personnalisé** : réorganisez les ouvriers dans l’ordre souhaité, regroupez par compétences, organisez en équipes ou selon votre flux de travail opérationnel.
- **Indicateurs visuels d’assignation** : les cartes indiquent quels ouvriers sont assignés à chaque intervention. Lorsque seuls les chefs d’équipe sont affichés, les membres accompagnants apparaissent également.

## 🧭 Découverte de l’interface

### 1. Panneau gauche – File d’attente des interventions

Retrouvez ici toutes les interventions en attente de planification, avec leur date maximale de réalisation. Vous pouvez :

- Faire glisser une intervention dans le planning hebdomadaire pour la planifier
- Cliquer dessus pour ouvrir le formulaire d’édition avant de la placer

### 2. Panneau droit – Planning hebdomadaire

Visualisez toutes les interventions planifiées sur la semaine. Deux options pour ajouter une nouvelle intervention :

- Cliquer sur un créneau horaire : la date et l’ouvrier sont automatiquement préremplis
- Utiliser le bouton « Nouveau » pour ouvrir un formulaire vierge

## 🧠 Formulaire de planification intelligent

Le formulaire vous guide à chaque étape :

- Planification immédiate ou définition d’une date maximum pour une planification ultérieure
- Sélection du client, de l’installation et du type d’intervention
- Ajout de descriptions, documents et commentaires internes
- Assignation d’un responsable et d’éventuels accompagnants

___________________________________________________________

## 🎨 Indicateurs visuels

Pour une lecture rapide du planning :

- Les logos identifient les ouvriers responsables, facilitant le glisser-déposer des interventions vers la bonne personne
- Le code couleur indique le statut de chaque intervention :
- 🟦 Planifiée
- 🟧 À facturer
- 🟩 Facturée

___________________________________________________________

## 🧩 Drag & Drop intelligent

Le déplacement d’interventions est simplifié et automatiquement optimisé :

- La première intervention de la journée commence à l’heure du contrat de l’ouvrier
- Les interventions suivantes s’enchaînent à partir de l’heure de fin de la précédente
