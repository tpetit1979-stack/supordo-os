# Publier une nouvelle annonce  sur VertuoWork

Pour publier une annonce sur VertuoWork, suivez ces étapes simples :

1. **Accédez à VertuoWork** : Depuis votre tableau de bord Vertuoza, cliquez sur le bouton "Accéder à VertuoWork" visible dans la bannière en haut de la page.
2. **Cliquez sur "Publier une annonce"** : Une fois sur VertuoWork, localisez le bouton "Publier une annonce" situé en haut à droite de l'écran.
3. **Remplissez les informations requises** : Complétez tous les champs du formulaire de création d'annonce, en veillant à fournir les détails nécessaires.
4. **Validez la création** : Cliquez sur le bouton "Créer" pour publier votre annonce.

> Votre annonce sera alors visible sur la plateforme **VertuoWork** jusqu'à la date max pour postuler. Une fois qu'un candidat aura postulé, vous serez averti par email.
