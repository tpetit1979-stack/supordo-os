# Modifier une annonce  sur VertuoWork

Pour modifier une annonce déjà publiée sur VertuoWork, suivez ces étapes :

1. **Accédez au menu** : Cliquez sur l'icône de menu en haut à gauche de l'écran (les trois barres horizontales).
2. **Sélectionnez "Mes annonces"** : Dans le menu déroulant, cliquez sur "Mes annonces" pour afficher la liste de toutes vos annonces.
3. **Ouvrez le menu de l'annonce** : À côté de l'annonce que vous souhaitez modifier, cliquez sur les trois petits points pour ouvrir le menu des options.
4. **Sélectionnez "Éditer l'annonce"** : Choisissez l'option "Éditer l'annonce" pour accéder au formulaire de modification et apporter les changements nécessaires.

N'oubliez pas de sauvegarder vos modifications pour qu'elles soient prises en compte.
