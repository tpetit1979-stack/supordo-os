# Postulez à une annonce sur Vertuowork

Pour postuler à une annonce sur VertuoWork, suivez ces étapes simples :

1. **Accédez à VertuoWork** : Depuis votre tableau de bord Vertuoza, cliquez sur le bouton "Accéder à VertuoWork" visible dans la bannière en haut de la page.
2. **Parcourez les annonces** : Utilisez les filtres ou parcourez les annonces disponibles pour trouver celle qui vous intéresse.
3. **Consultez les détails** : Cliquez sur l'annonce de votre choix pour voir les détails du poste proposé.
4. **Postulez** : Cliquez sur le bouton "Postuler" pour soumettre votre candidature.

Le responsable du projet recevra directement un email avec votre candidature. Vous serez informé par email en cas d'acceptation ou de refus de votre candidature.

Retirer une candidature? Découvrez comment [ici](https://intercom-help.eu/vertuoza/fr/articles/225139-retirer-une-candidature-sur-vertuowork).
