# Comment consulter et gérer les candidatures à mon annonce sur VertuoWork ?

Si vous avez reçu un email indiquant qu'un candidat a postulé à votre annonce, voici comment consulter les candidatures et accepter ou refuser les candidats :

1. **Accédez au menu** : Cliquez sur l'icône de menu en haut à gauche de l'écran (les trois barres horizontales).
2. **Sélectionnez "Mes annonces"** : Dans le menu déroulant, cliquez sur "Mes annonces".
3. **Voir les candidats** : À côté de l'annonce concernée, cliquez sur les trois petits points, puis sélectionnez "Voir les candidats".

Sur la page des candidats, vous verrez trois icônes à côté de chaque candidature :

- **L'œil** : Cliquez sur cette icône pour voir les informations du candidat.
- **Le "V"** : Cliquez sur cette icône pour accepter la candidature.
- **La croix** : Cliquez sur cette icône pour refuser la candidature.

Lorsqu’un candidat est accepté ou refusé, un email lui est automatiquement envoyé pour le prévenir. En cas d'acceptation, il est recommandé de contacter le candidat directement pour lui fournir les informations pratiques nécessaires.
