# Supprimer une annonce sur VertuoWork

Pour supprimer une annonce publiée sur VertuoWork, suivez ces étapes :

1. **Accédez au menu** : Cliquez sur l'icône de menu en haut à gauche de l'écran (représentée par trois barres horizontales).
2. **Sélectionnez "Mes annonces"** : Dans le menu déroulant, cliquez sur "Mes annonces" pour afficher la liste de vos annonces.
3. **Ouvrez le menu de l'annonce** : Cliquez sur les trois petits points situés à côté de l'annonce que vous souhaitez supprimer pour ouvrir le menu des options.
4. **Sélectionnez "Supprimer l'annonce"** : Choisissez l'option "Supprimer l'annonce" pour retirer définitivement l'annonce de la plateforme.

Attention, la suppression est irréversible.
