# Type d’absences

Pour pouvoir compléter les différentes absences des ouvriers, vous allez devoir au préalable créer les différents types d’absences possibles.

### **Navigation dans l’écran "Types d’absences":**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une zone de recherche.
2. Le tableau reprenant les informations.
3. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
4. Le bouton "Nouveau" pour créer un nouvel élément.

### **Pour ajouter un type d’absence :**

1. Accédez à la section "**Types d’absences**" dans les paramètres du planning.
2. Cliquez sur "**Nouveau**"
3. Entrez la description.
4. Ajoutez un nom abrégé
5. Ajoutez un code EAN si vous le souhaitez
6. Cliquez sur **“Enregistrer”** pour l'ajouter à la liste de vos types d’installation.
