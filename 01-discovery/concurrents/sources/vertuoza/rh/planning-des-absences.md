# Planning des absences

Avant toute chose, n’oubliez pas de paramétrer les types d’absences dans **Paramètres > Planning > Types d’absences.**

Ensuite, rendez-vous dans  **RH > Planning absences**
​

### **Navigation dans l'écran des absences:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Un ensemble de filtres qui peuvent être appliqués sur le tableau de données
2. Le tableau reprenant les informations.
3. Des flèches permettant de passer de mois en mois dans le coin supérieur droit de l’écran.
4. Le bouton "Nouveau" pour créer un nouvel élément.

### Comment utiliser le planning des absences ?

- Filtrez sur :
- Vos ouvriers et/ou indépendants
- Le mois à afficher
- Le type d’absence à afficher
- Un affichage par mois ou par semaine

### Comment encoder une absence ?

- Cliquez sur “+ Nouveau”
- Encodez le ou les ouvriers concernés par l’absence, la période d’absence et le motif.

⇒ Lorsque vous allez dans le planning des chantiers, si un ouvrier est signalé comme absent, il apparaitra en gris dans le planning. Vous pouvez quand même le sélectionner, mais vous serez prévenu qu’il ne travaille pas ce jour là.
