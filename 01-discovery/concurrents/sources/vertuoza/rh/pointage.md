# Pointage

Dans Vertuoza, vos ouvriers peuvent pointer directement depuis le chantier sur la tablette.
Cela permet d’avoir un coût de main-d’œuvre précis pour votre rentabilité de chantier.

___________________________________________________________

### Vos paramétrages

### 1️⃣ Préférences de pointage

Rendez-vous dans **Paramètres > Propriétés > Pointage > Préférences** :

- Activez la gestion des pointages pour activer le module pointage dans les comptes chantiers et la validation des pointages dans les comptes gestion.
- Activez la gestion de la mobilité pour permettre à l’utilisateur d’encoder les kilomètres parcourus et renseigner le chauffeur si nécessaire.

### 2️⃣ Types d’absences

Dans **Paramètres > Propriétés > Planning > Types d’absences**, configurez les motifs d’absence de vos ouvriers : maladie, intempéries, congé, etc.

### 3️⃣ Véhicules

Dans **Paramètres > Propriétés > Général > Véhicules**, vérifiez que tous les véhicules disponibles dans la société sont correctement encodés (modèle et numéro de plaque).

### 4️⃣ Paramétrage des trajets (France)

Pour les sociétés françaises, vous pouvez activer des champs supplémentaires pour vos ouvriers :

- **Lieu de départ et d’arrivée** (domicile, entreprise, hôtel)
- **Type de véhicule** (véhicule personnel ou de société)
- **Durée de trajet** (utile pour les grands déplacements)
- **Distance parcourue** (kilomètres, non utilisée pour la France)
- **Rôles de transport** (chauffeur, passager…)

💡 Ces options facilitent le suivi des déplacements et l’encodage automatique des indemnités.

### 5️⃣ Gestion des paniers repas et hébergement (France)

- Attribuez automatiquement les **paniers repas** si un ouvrier travaille plus de 5 heures.
- Activez le calcul des **indemnités d’hébergement** pour les ouvriers en grand déplacement.
- Les informations apparaissent dans l’export comptable pour simplifier le calcul des fiches de paie.

### 6️⃣ Zones de déplacement (France)

- Activez les **zones de petits déplacements** selon la localisation du chantier.
- Base de calcul : **Entreprise** ou **Domicile**.
- Définissez vos zones (1A, 1B, 2, 3, 4, 5).
- Les montants sont calculés à partir de l’export comptable.

### 7️⃣ Heures supplémentaires et heures de nuit (France)

- **Heures supplémentaires** : calcul automatique selon la législation (25 % pour 35–43h, 50 % à partir de 43h).
- **Heures de nuit** : période paramétrable (20h00 à 06h00 par défaut), intégrées dans les exports.

### Le pointage par le chef d’équipe (depuis un compte chantier)

Votre chef d’équipe peut pointer les ouvriers directement sur la tablette depuis le chantier :

1. Dans l’onglet **Pointage**, cliquer sur **Ouvriers** et sélectionner ceux à encoder.
2. Pour chaque ouvrier, renseigner :
- Présence ou absence
- Chantier travaillé
- Heures d’arrivée et de départ
- Temps de pause
3. Ajouter plusieurs éléments si l’ouvrier a travaillé sur différents chantiers.
4. Si la mobilité est activée : encoder les **kilomètres aller/retour** et le **statut** (chauffeur, passagers…).
5. **Action groupée** : permet de reporter le temps de prestation sur plusieurs ouvriers simultanément.

Le pointage est ensuite à valider depuis un compte gestion dans Vertuoza.

### Navigation dans l’écran des pointages (gestion)

- Filtres pour trier et rechercher dans le tableau
- Détail par chantier (bouton Oui/Non)
- Bouton **Nouveau** pour créer un pointage

___________________________________________________________

### Gestion des pointages (depuis un compte gestion)

Rendez-vous dans **Planning > Pointage** :

- Tous les pointages des ouvriers depuis la tablette sont listés dans un tableau.
- Filtres disponibles pour affiner la recherche.
- Bouton **+** pour ajouter un pointage manuellement.
- Boutons d’action par ligne : valider, éditer, supprimer, voir l’historique.
- Statuts possibles :
- **En cours** : en cours sur tablette
- **À clôturer** : validé par le chef d’équipe mais à clôturer
- **Clôturé** : validé dans gestion
- **En retard** : non finalisé
- **Non planifié** : travail effectué sans planification

Vous pouvez sélectionner plusieurs lignes pour les **clôturer**, **revenir au statut précédent** ou **supprimer**.

### Nouveautés France intégrées

- **Encodage des trajets** (départ/arrivée, type de véhicule, durée)
- **Zones de déplacement** et calcul automatique pour petits déplacements
- **Paniers repas** et indemnités d’hébergement pour grands déplacements
- **Heures supplémentaires** et **heures de nuit** calculées automatiquement
- Tous ces champs apparaissent dans l’**export Excel France**, prêt à transmettre au comptable.
