# Fiches techniques

Les fiches techniques servent de référence précise pour chaque produit, facilitant une compréhension claire de ses composants, de son utilisation recommandée, de ses dimensions, et d'autres détails techniques.

Vertuoza vous permet de centraliser vos fiches techniques relatives aux produits et fournitures.

Vous pouvez les télécharger dans différents groupes et les relier aux chantiers que vous souhaitez.

### **Navigation dans le paramétrage des Groupes :**

Avant d'insérer vos fiches techniques dans Vertuoza, il faut d'abord créer les différents groupes dans lesquels vous pourrez les classer.

- Une zone de recherche.
- Le tableau reprenant les informations.
- La corbeille à l'extrême droite du tableau.
- Le bouton "**Nouveau**" pour créer un nouvel élément.
- Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
- Des filtres peuvent être appliqués.

### **Créer un nouveau groupe :**

1. Cliquer sur le “**+ Nouveau**”.
2. Nommer le groupe.
3. “**Enregistrer**”.
4. Le nom de votre groupe est affiché dans la première colonne.

### **Navigation dans le paramétrage des Fiches Techniques :**

Maintenant que vous avez ajouté vos groupes, importez vos fiches techniques et classez-les dans le groupe souhaité.

- Le tableau reprenant les informations.
- Une zone de recherche.
- Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
- Ajoutez une nouvelle fiche en cliquant sur le “**+ Nouveau**”.
- Sélectionnez le groupe souhaité.
- Donnez-lui un titre / une description.
- Insérez la marque du produit / fourniture.
- Importez la fiche technique.
- Vos fiches techniques s'affichent ensuite dans la liste de la première colonne.
- Vous pouvez à tout moment télécharger, éditer ou supprimer la fiche technique à l’aide des boutons d’action à droite.

### **Lier vos fiches techniques à vos chantiers à partir du Dossier FT :**

- Faire une recherche de dossier FT.
- Créer un nouveau dossier en cliquant en haut à droite sur +.
- Insérez une fiche technique (nommez-la, ajoutez une remarque et enregistrez).
- Une fois créé, vous pouvez cliquer à droite sur le bouton d’action qui vous permet de l’attribuer à un chantier.
- Sélectionnez le chantier.

### **Gestion chantier**

En allant dans la gestion de votre chantier, vous pouvez retrouver en bas, sous informations générales, vos fiches techniques liées.
