# Historique

### **Historique**

L’historique est source d’information pratique lorsque vous devez retrouver des informations qui ont été envoyées ou encore afin de voir les différentes modifications qui ont été apportées. Chaque élément dans les tableau de données dans Vertuoza dispose d’un historique.

### **Afficher l’historique:**

1. Dans les différents tableaux reprenant les documents, par exemple: Offre ⇒ Devis
2. Via les “…” en bout de ligne
3. Cliquez sur sur le bouton d’action “Afficher l’historique”
4. Dans un tableau, retrouvez les informations suivantes:
- La date et l’heure
- L’utilisateur
- L’action effectuée
- Les destinataires si un envoi est concerné
- Le contenu de l’e-mail envoyé
- Les pièces jointes qui ont été envoyées

**Attention ;** *Si vous avez configuré l’envoi avec votre propre adresse email, comme expliqué dans [cet article,](https://intercom-help.eu/vertuoza/fr/articles/411728-envoi-des-emails-avec-ta-propre-adresse) il est normal que vous ne retrouviez plus les statuts dans notre interface. En effet, l’envoi ne passe plus par notre serveur. Vous pouvez donc vous fier aux informations que vous retrouvez directement dans votre boîte mail (dans vos messages envoyés, etc.).*
