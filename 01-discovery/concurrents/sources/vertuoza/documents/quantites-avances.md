# Quantités avancés

Il se peut que dans certaines situations vous deviez calculer encore des quantités. Dans ce cas, vous pouvez utiliser les quantités avancées. Cela vous permettra de rentrer vos mesures et que la quantités soit ajoutée et appliquée sur la ligne.

Exemple: 5 (longueur) X 5 (Largeur) = 25

### **Appliquer une quantité avancée ; **

1. Rendez-vous dans l’édition d’une offre.
2. Au niveau du tableau d’encodage des devis ⇒ cliquez à l’extrême droite d’une ligne sur “…” ⇒ Cliquez sur “Détail de la quantité”
3. Vous visualisez ensuite: La description ⇒ La quantité ⇒ Longueur ⇒ Largeur ⇒ Hauteur ⇒ Total Il vous est aussi possible d’ajouter plusieurs lignes de mesures afin de créer une quantités globale
4. Après avoir complété les quantités, il vous suffit de confirmer.
5. A tout moment vous avez la possibilité de supprimer les quantités avancées via le bouton rouge.
