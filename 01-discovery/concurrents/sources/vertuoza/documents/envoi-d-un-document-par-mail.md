# Envoi d’un document par mail

### **Envoi de documents par e-mail**

Que ça soit pour vos offres, vos factures, … Vous pourrez les faire parvenir à vos clients et contacts par e-mail.

### **Envoyer des documents par e-mail:**

1. Dans les différents tableaux reprenant les documents, par exemple: Offre ⇒ Devis
2. Via les “…” en bout de ligne
3. Cliquez sur sur le bouton d’action “envoyer par mail”
4. Complétez ensuite les informations suivantes:
- (Uniquement pour les devis) Cochez oui si vous désirez envoyer le document avec signature électronique
- Définir le modèle d’e-mail utilisé (Modèles créés à l’avance dans les paramètres)
- Sélectionner les destinataires et autres personnes en CC ou CCI
- Définir l’objet de l’e-mail.
- Adapter le texte de l’e-mail si nécessaire.
- Modèle PDF: il vous est possible d’adapter le document envoyé via le bouton d’action à la droite du champ
- Pièces jointes supplémentaires
- Ajouter d’autres pièces jointes si nécessaire.
5. Cliquer sur “Envoyer”
