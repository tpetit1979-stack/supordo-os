# Retenue

Sur une offre, il est possible d’appliquer une retenue sur le sous-total.

### **Appliquer une retenue:**

1. Rendez-vous dans l’édition d’une offre.
2. Cliquez sur l'onglet "Totaux"  ⇒ Tableau des totaux ⇒ Total TTC à payer ⇒ +
3. Cliquez sur “Ajouter une retenue”.
4. Complétez ensuite les informations suivantes:
- Le total TTC
- La retenue en % à appliquer
- Le montant de la retenue
- Confirmer
5. Le prorata sera visible sur le PDF mais ne pas hérité dans la gestion de chantier. Si vous souhaitez voir la retenue sur vos factures, vous devrez l’ajouter manuellement de la même façon.
