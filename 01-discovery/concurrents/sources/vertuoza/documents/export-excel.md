# Export Excel

Que ça soit pour vos offres, vos factures, … Vous pouvez les exporter en Excel

## Exporter un document en Excel:

1. Dans les différents tableaux reprenant les documents, par exemple: Offre ⇒ Devis
2. Via les “…” en bout de ligne
3. Cliquez sur sur le bouton d’action “Exporter en Excel”
4. Choisissez votre type d’export en Excel
5. Cliquer sur l’icône en forme de fichier Excel
6. Le fichier est automatiquement téléchargé et se trouve dans vos téléchargements.
