# Export PDF

Que ça soit pour vos offres, vos factures, … Vous pouvez les exporter en PDF

## Exporter un document en PDF:

1. Dans les différents tableaux reprenant les documents, par exemple: Offre ⇒ Devis
2. Via les “…” en bout de ligne
3. Cliquez sur sur le bouton d’action “Exporter en PDF”
4. Choisissez votre mise en page PDF
- Parmi les les mises en pages standards
- Parmi les mises en pages personnalisées (créées depuis les paramètres de mise en page)
5. Cliquer sur l’icône en forme de fichier PDF
6. Le fichier s’ouvre dans une fenêtre de votre navigateur et il vous est alors possible de le télécharger
