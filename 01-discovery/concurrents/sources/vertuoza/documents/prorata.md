# Prorata

Sur une offre, il est possible d’appliquer un prorata sur sous-total.

### **Appliquer un prorata:**

1. Rendez-vous dans l’édition d’une offre.
2. Cliquez sur l'onglets "Totaux" ⇒ Tableau des totaux ⇒ Sous-total n° HT ⇒ +
3. Cliquez sur “Ajouter un prorata”.
4. Complétez ensuite les informations suivantes:
- La référence
- Le sous-total HT
- Le prorata en %, HT, TTC
- Le montant du prorata HT
- Le montant HT revu après prorata
5. Le prorata sera visible sur le PDF mais ne pas hérité dans la gestion de chantier. Si vous souhaitez voir le prorata sur vos factures, vous devrez l’ajouter manuellement de la même façon.
