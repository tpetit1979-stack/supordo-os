# Commentaires

Dans les commentaires, il est possible de laisser un mot, des notes, des fichiers, logger des appels,…

## Laisser un commentaire:

1. Dans les différents tableaux reprenant les documents, par exemple: Offre ⇒ Devis
2. Cliquez sur la bulle de commentaire à droite
3. Une fenêtre avec plusieurs option s’ouvre
4. Vous pouvez complétez les informations suivantes:
- Le type de commentaire: Notes, E-mail, Appel, RDV
- Ecrivez un commentaire
- Ajoutez des fichiers à lier au commentaire si nécessaire
- Retrouvez la listes des commentaires avec un historique de ce qui a été fait.
