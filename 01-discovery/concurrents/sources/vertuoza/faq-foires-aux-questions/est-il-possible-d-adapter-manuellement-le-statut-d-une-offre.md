# Est-il possible d’adapter manuellement le statut d’une offre ?

Non, il n’est pas possible de modifier manuellement le statut d’une offre. Vous pouvez cependant vous l’envoyer à vous-même au lieu d’utiliser l’étiquette "Envoyé"/non envoyé. Vous pouvez également utiliser la section des commentaires pour indiquer l’état de l’offre.
