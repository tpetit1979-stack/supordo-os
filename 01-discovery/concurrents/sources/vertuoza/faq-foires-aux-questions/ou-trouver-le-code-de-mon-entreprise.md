# Où trouver le code de mon entreprise ?

Vous pouvez retrouver le code de votre entreprise dans l’URL de votre environnement. Ce sont les derniers chiffres de cette URL.

Avec ce code, vous pourrez vous connecter à l’application mobile.

**Exemple :**

Si l’URL de votre environnement est https://mon-environnement.com/12345, le code de votre entreprise est **12345**.
