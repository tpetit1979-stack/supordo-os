# Pourquoi le prix dans le détail d’ouvrages peut-il différer du prix dans le devis ?

Il est courant que le prix affiché dans les détails d'un ouvrage soit différent de celui indiqué dans le devis. Cela est dû aux différences dans les arrondis utilisés. 

Le prix dans les détails est calculé en fonction de tous les composants de l'ouvrage, en prenant en compte les quantités et les prix unitaires, ce qui peut entraîner des variations dues aux arrondis de chaque composant. 


En revanche, le prix dans le devis est basé sur le prix unitaire arrondi multiplié par la quantité, puis arrondi à nouveau pour donner le total final affiché au client. 


Cette méthode assure une précision pour la facturation au client, tandis que le prix dans les détails, influencé par les arrondis de chaque composant, est principalement utilisé pour les calculs internes comme la marge. Les différences entre ces deux prix sont donc normales et résultent des différentes méthodes d'arrondi.
