# Comment créer une facture proforma sur Vertuoza ?

Pour faire une facture proforma sur Vertuoza, suivez ces étapes :

1. Créez une mise en page personnalisée avec le titre approprié pour votre pro forma.
2. Générez une facture dans Vertuoza sans la comptabiliser, ce qui signifie qu'elle ne sera pas numérotée.
3. Téléchargez le PDF de la facture avec la mise en page personnalisée.
4. Envoyez le PDF depuis votre boîte mail habituelle, en dehors de Vertuoza.

En suivant ces étapes simples, vous pourrez créer facilement un pro forma conforme à vos besoins spécifiques.
