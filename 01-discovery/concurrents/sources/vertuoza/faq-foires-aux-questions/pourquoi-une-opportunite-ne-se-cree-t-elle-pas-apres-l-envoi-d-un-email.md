# Pourquoi une opportunité ne se crée-t-elle pas après l’envoi d’un email ?

Si une opportunité ne se crée pas automatiquement après l’envoi d’un email, c’est généralement parce que **l’adresse e-mail du prospect n’est pas renseignée** dans le message reçu. Sans cette information, il est impossible de relier l’opportunité à un contact dans Vertuoza.

Pour que l’opportunité soit correctement créée, assurez-vous que l’email du prospect est bien présent dans le contenu du message. Exemple :

- Nom : Jean Dupont
- Email : [jean.dupont@gmail.com](mailto:jean.dupont@gmail.com)
- Adresse : Rue Louis Braille 16, 1400 Nivelles
- Téléphone : 0479 36 00 00
- Message : Je fais une demande d’information pour …
