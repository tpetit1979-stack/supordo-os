# Comment le système génère-t-il le numéro d'un nouveau devis ?

1. **Identification de l'année fiscale** : Le système prend en compte l'année fiscale actuelle.
2. **Recherche du numéro de devis le plus élevé** : Il identifie le numéro de devis le plus élevé déjà existant dans le système.
3. **Génération du nouveau numéro** : Le système ajoute +1 à ce numéro le plus élevé pour créer le nouveau numéro de devis.

Il est donc possible que certains devis aient des numéros plus élevés, car le système ne se contente pas de prendre le dernier devis créé, mais utilise le numéro le plus élevé pour garantir une numérotation cohérente et séquentielle.
