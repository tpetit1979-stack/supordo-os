# Je n'arrive pas à me connecter sur mobile

Pour vous connecter à notre application mobile, veuillez suivre ces étapes :

1. **Insérer votre numéro de société** : Dans le champ prévu à cet effet, entrez votre nom numéro de société qui se retrouve en fin de votre lien URL de connexion.
2. **Entrer votre identifiant** : Saisissez votre identifiant utilisateur dans le champ approprié.
3. **Entrer votre mot de passe** : Saisissez votre mot de passe dans le champ correspondant.
