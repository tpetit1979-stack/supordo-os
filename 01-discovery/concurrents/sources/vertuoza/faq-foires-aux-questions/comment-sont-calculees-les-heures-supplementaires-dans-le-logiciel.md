# Comment sont calculées les heures supplémentaires dans le logiciel ?

Le calcul des heures supplémentaires repose sur les règles suivantes :

1. **Heures normales** : Le logiciel prend en compte l'horaire standard défini pour chaque employé (par jour ou semaine).
2. **Heures planifiées** : Si des heures sont prévues dans le planning, elles servent de base initiale
3. **Heures pointées** : Les heures réellement travaillées, une fois clôturées, remplacent les heures planifiées pour le calcul.
4. **Excédent** : Toute heure au-delà de l'horaire normal est considérée comme une heure supplémentaire, selon la configuration du logiciel.

Si une anomalie est détectée (exemple : un affichage d'heures supplémentaires incorrect malgré un temps de travail dans les horaires normaux), vérifiez les paramètres du planning, les règles de calcul des heures supplémentaires, ou contactez le support technique pour une assistance.
