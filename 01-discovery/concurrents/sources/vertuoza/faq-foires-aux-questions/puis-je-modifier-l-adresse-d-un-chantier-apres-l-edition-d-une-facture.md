# Puis-je modifier l'adresse d'un chantier après l'édition d'une facture ?

Une fois la facture éditée, il n'est pas possible de modifier directement l'adresse du chantier. Pour effectuer ce changement, vous devrez d'abord modifier l'adresse dans la gestion de chantier, puis recréer la facture avec les nouvelles informations.
