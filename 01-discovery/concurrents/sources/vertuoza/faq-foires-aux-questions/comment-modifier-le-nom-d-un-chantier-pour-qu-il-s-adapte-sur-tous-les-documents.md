# Comment modifier le nom d'un chantier pour qu'il s’adapte sur tous les documents ?

### 

1. Accédez à la section **Chantier**
2. Ouvrez le chantier concerné.
3. Sous **Informations générales,** cliquez sur l'icône crayon à droite du nom du chantier.
4. Modifiez le champ **Nom de chantier**.

Le nom du chantier sera alors mis à jour dans tous vos documents.
