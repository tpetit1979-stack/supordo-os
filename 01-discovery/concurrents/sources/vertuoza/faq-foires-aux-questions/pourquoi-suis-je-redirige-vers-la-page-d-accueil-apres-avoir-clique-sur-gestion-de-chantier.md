# Pourquoi suis-je redirigé vers la page d'accueil après avoir cliqué sur "Gestion de chantier" ?

Cette situation se produit généralement lorsque vous n'avez pas les autorisations nécessaires pour accéder à la fonctionnalité demandée. 

Par exemple, si vous êtes dans le groupe “Commercial”, vous pourriez être redirigé vers la page d'accueil car l'accès à la gestion des chantiers est réservé à d'autres groupes spécifiques.


Pour résoudre ce problème, veuillez contacter votre administrateur afin qu'il puisse vérifier que vous faites partie du groupe approprié avec les permissions requises. Votre administrateur pourra ajuster vos accès si nécessaire.
