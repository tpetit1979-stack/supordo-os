# Pourquoi certaines factures ne remplissent pas automatiquement le champ “fournisseur” ?

Vertuoza utilise l’OCR pour remplir automatiquement le fournisseur. Cela ne fonctionne que si :

- Le fournisseur existe dans Vertuoza.
- Le numéro de TVA sur la facture correspond exactement à celui enregistré dans Vertuoza.

Si ce n’est pas le cas, créez manuellement le fournisseur avec son numéro de TVA pour que le lien se fasse correctement.
