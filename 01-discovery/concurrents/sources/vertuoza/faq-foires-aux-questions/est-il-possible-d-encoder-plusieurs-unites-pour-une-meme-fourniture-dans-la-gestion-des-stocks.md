# Est-il possible d'encoder plusieurs unités pour une même fourniture dans la gestion des stocks ?

Actuellement, il n’est pas possible d’encoder plusieurs unités pour une même fourniture dans la gestion des stocks. Chaque fourniture est limitée à une seule unité de mesure, ce qui signifie que vous devrez choisir entre "BTE" (boîte) ou "PCS" (pièce) pour un article donné, comme une boîte de vis contenant 200 pièces.
