# Comment les avenants impactent-ils le chiffre d’affaires dans Vertuoza ?

Le chiffre d’affaires dans Vertuoza se base sur les factures réellement émises, et non sur les devis ou avenants non facturés.

- **Avenant positif** : une fois facturé, il augmente le chiffre d’affaires du chantier et donc celui du commercial.
- **Avenant négatif ou note de crédit** : une fois enregistré et facturé, il diminue le chiffre d’affaires, afin que le CA final reflète le montant réellement réalisé (devis initial + avenants facturés).

En résumé : **seules les factures et notes de crédit affectent le chiffre d’affaires**. Les avenants en attente de facturation n’ont aucun impact jusqu’à leur comptabilisation.
