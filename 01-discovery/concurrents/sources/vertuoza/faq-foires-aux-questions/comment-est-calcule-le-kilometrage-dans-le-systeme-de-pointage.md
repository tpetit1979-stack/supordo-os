# Comment est calculé le kilométrage dans le système de pointage ?

Le calcul des kilomètres est basé sur l'adresse définie dans les paramètres de l'entreprise. Si les distances semblent incorrectes, cela peut être dû au fait que l'adresse prise en compte n'est pas celle du dépôt ou du point de départ réel des ouvriers. N’hésitez pas à vérifier et de mettre à jour cette adresse dans les paramètres afin de vous assurer que les kilomètres soient correctement calculés.
