# Comment est calculée la rentabilité main-d’œuvre d’un chantier ?

La rentabilité liée à la main-d’œuvre dans un chantier repose sur la comparaison entre le prévisionnel établi dans le devis et le temps réellement pointé par les ouvriers.

Voici comment cela fonctionne :

1. **Dans le devis**
Lorsque vous ajoutez des lignes de type **"main-d’œuvre"** (dans des ouvrages simples ou composés), vous indiquez le **nombre d’heures prévues** pour chaque tâche. Ce sont ces heures qui sont reprises dans la rentabilité du chantier, sous la section **“Main-d’œuvre disponible”**.
2. **Dans le pointage**
Côté RH / pointage, les ouvriers enregistrent les **heures réellement prestées** sur le chantier. Ce total est affiché **à gauche** dans la rentabilité du chantier.
3. **Comparaison et analyse**
En bas de la fiche chantier, dans l’onglet **Rentabilité**, la section **Main-d’œuvre** permet de comparer :
- **Main-d’œuvre disponible** = heures prévues dans le devis.
- **Main-d’œuvre prestée** = heures réellement pointées.

👉 Cela vous permet d’évaluer rapidement si le chantier est dans les temps ou si des écarts apparaissent
