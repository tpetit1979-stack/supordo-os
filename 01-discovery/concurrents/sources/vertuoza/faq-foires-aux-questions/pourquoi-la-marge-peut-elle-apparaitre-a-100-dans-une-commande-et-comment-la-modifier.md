# Pourquoi la marge peut-elle apparaître à -100 % dans une commande et comment la modifier ?

La marge affichée à -100 % est calculée automatiquement à partir du prix d’achat et du prix de vente que vous saisissez. Ces deux valeurs ne sont pas modifiables directement dans le champ marge.

- Si le **prix de vente** n’a pas encore été défini dans le chantier, la marge apparaît **négative par défaut**.
- Pour ajuster la marge ou le prix final, modifiez le **prix d’achat ou le prix de vente** dans le détail de l’article via les options situées en bout de ligne.
- La marge affichée est **purement informative** et n’empêche pas l’enregistrement de votre commande.

**En résumé :** ce champ **n’est pas modifiable directement** ; il reflète seulement le calcul automatique basé sur les montants renseignés.
