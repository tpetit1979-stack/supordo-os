# Quand un ouvrage est mis à jour dans la Biblio de prix, les prix sont-ils automatiquement mis à jour dans les devis existants ?

Non, lorsque vous mettez à jour un ouvrage dans la bibliothèque de prix, les nouveaux tarifs ne s’appliquent qu’aux futurs devis.
Les prix des ouvrages déjà présents dans les devis existants ne sont pas modifiés automatiquement.

Si vous souhaitez refléter les nouveaux prix dans un devis existant, vous devez le mettre à jour manuellement :


sélectionnez toutes les lignes concernées dans le devis, puis cliquez en haut à gauche sur **« Actualiser les prix »**.
