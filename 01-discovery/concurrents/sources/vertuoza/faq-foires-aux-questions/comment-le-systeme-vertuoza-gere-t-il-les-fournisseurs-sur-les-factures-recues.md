# Comment le système Vertuoza gère-t-il les fournisseurs sur les factures reçues ?

- Vertuoza associe automatiquement le fournisseur via le numéro de TVA et l’ID PEPPOL.

- Si les informations ne correspondent pas exactement (TVA, SIREN, ID PEPPOL), le champ reste vide.
- Créez ou corrigez le fournisseur dans Vertuoza pour que les prochaines factures soient automatiquement rattachées.
