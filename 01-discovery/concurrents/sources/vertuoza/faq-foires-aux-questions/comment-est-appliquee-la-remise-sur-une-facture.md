# Comment est appliquée la remise sur une facture ?

La remise peut être affichée soit sur une ligne séparée en tant que poste libre, soit répartie sur toutes les lignes. 

Lorsqu'une remise est ajoutée sur le total d’un devis, elle est automatiquement répartie sur l'ensemble des lignes, ce qui réduit déjà le montant total. 

Si une remise supplémentaire de X euros est ensuite appliquée sur la facture, cela peut entraîner un double effet. 

Pour corriger cela, il suffit de supprimer cette remise supplémentaire via l'option dédiée dans les factures.
