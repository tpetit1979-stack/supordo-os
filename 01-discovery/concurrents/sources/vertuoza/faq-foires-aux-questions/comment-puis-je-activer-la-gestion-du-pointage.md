# Comment puis-je activer la gestion du pointage ?

Pour activer la gestion du pointage, suivez ces étapes :

1. **Accéder aux Paramètres :**
- Allez dans le menu des **Paramètres**.
​
2. **Activer le Pointage :**
- Sous l'onglet **Pointage**, cliquez sur Préférences
- Vous trouverez une option intitulée **"Activer le pointage"**.
​
3. **Sauvegarder les Modifications :**
- Assurez-vous d'enregistrer les modifications apportées aux paramètres en cliquant sur "**Soumettre**".

Une fois ces étapes complètes, la gestion du pointage sera activée.
