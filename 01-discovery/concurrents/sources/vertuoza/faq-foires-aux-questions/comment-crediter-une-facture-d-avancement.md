# Comment créditer une facture d'avancement ?

**Créditer une facture d'avancement : **

Pour créditer une facture d'avancement, suivez ces étapes :

1. Allez dans le menu **Finance**
2. Sélectionnez **Note de crédit**
3. Cliquez sur **Nouveau**
4. Saisissez le montant de la note de crédit en utilisant un montant négatif correspondant à celui de la facture d'avancement.
5. Assurez-vous de lier la note de crédit au chantier approprié.
​

**Lier une note de crédit à un chantier :**

1. Dans la section **Finance**
2. Sélectionnez** Note de crédit**
3. Cliquez sur **Nouveau**
4. Sélectionnez le chantier à lier depuis le champ **Chantier**

**Important :** Les notes de crédits doivent obligatoirement être lié au chantier.

Cette liaison est indispensable pour assurer le bon calcul de la rentabilité du chantier.
