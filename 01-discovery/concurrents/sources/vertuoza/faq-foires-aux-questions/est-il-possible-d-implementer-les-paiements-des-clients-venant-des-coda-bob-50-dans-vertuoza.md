# Est-il possible d'implémenter les paiements des clients venant des coda Bob 50 dans Vertuoza ?

Non, il n'est pas possible de faire remonter les paiements depuis BOB50 vers Vertuoza. Toutefois, cela peut se faire via Codabox ou Ponto.
