# Comment sont calculées les dépenses dans la rentabilité d'un chantier ?

**Pour calculer la rentabilité d'un chantier, nous suivons ces trois points :**

1. **Planning chantier sans pointage lié** : Toutes les heures prévues dans le planning sont comptabilisées. Ces heures servent de base initiale pour l'évaluation de la rentabilité.
2. **Pointages clôturés liés à un planning chantier** : Les heures réellement pointées et clôturées prennent le dessus sur les heures prévues dans le planning. Ces heures pointées deviennent les valeurs définitives pour le calcul de la rentabilité. Ainsi, si des heures planifiées diffèrent des heures réellement travaillées, ce sont les heures réelles qui sont utilisées dans le calcul.
3. **Pointages clôturés non liés à un planning mais liés à un chantier** : Ces heures sont également prises en compte dans le calcul de la rentabilité. Même si elles ne sont pas liées à une planification initiale, elles sont ajoutées comme des heures réelles travaillées pour le chantier.

**Synthèse** : 
En résumé, la rentabilité est d'abord estimée sur la base des heures planifiées, mais elle est recalculée de manière définitive à partir des heures effectivement pointées et clôturées. Les heures planifiées fournissent une estimation temporaire, tandis que les pointages clôturés fournissent les données réelles pour le calcul final de la rentabilité du chantier.
