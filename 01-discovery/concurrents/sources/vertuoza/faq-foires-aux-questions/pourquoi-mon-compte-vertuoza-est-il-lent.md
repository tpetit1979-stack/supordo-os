# Pourquoi mon compte Vertuoza est-il lent ?

Si vous rencontrez des lenteurs ou des problèmes de chargement sur Vertuoza, cela peut être dû à plusieurs facteurs liés au navigateur que vous utilisez. Voici quelques conseils pour résoudre ce type de problème.

**Explication :**

Vertuoza est conçu pour fonctionner de manière optimale sur **Google Chrome**, qui est le navigateur recommandé pour une performance fluide et rapide. Si vous utilisez des navigateurs comme **Safari**, **Mozilla Firefox** ou **Microsoft Edge**, il peut y avoir des problèmes de lenteur, souvent dus à des configurations spécifiques de ces navigateurs ou des données mises en cache.

**Solutions :**

1. **Passez à Google Chrome pour une meilleure expérience :**
Nous recommandons vivement l'utilisation de **Google Chrome** pour accéder à Vertuoza. Chrome est le navigateur qui garantit la meilleure compatibilité avec notre plateforme et offre des performances maximales. Il est constamment mis à jour pour prendre en charge les dernières fonctionnalités de sécurité et de vitesse, offrant ainsi une expérience utilisateur fluide et rapide.
Si vous êtes déjà sur **Google Chrome**, mais rencontrez une lenteur, cela peut être dû à des données mises en cache ou à une version obsolète de votre navigateur.
2. **Videz le cache de votre navigateur :**
Les données en cache et les cookies peuvent parfois ralentir le chargement des pages. Voici comment vider le cache et supprimer les cookies dans **Google Chrome** :
- Cliquez sur les **trois petits points** dans le coin supérieur droit de Chrome.
- Sélectionnez **"Plus d'outils"**, puis **"Effacer les données de navigation"**.
- Cochez les cases **"Cookies"** et **"Cache"**.
- Cliquez sur **"Effacer les données"**.
Pour **Safari**, vous pouvez également supprimer le cache via **Préférences > Confidentialité** et **Gérer les données de site web**.
3. **Mettez à jour votre navigateur :**

Une version obsolète de **Google Chrome** peut causer des lenteurs. Assurez-vous de toujours utiliser la dernière version disponible :

- Pour **Google Chrome**, cliquez sur les **trois points** en haut à droite, puis allez dans **"Aide"** et sélectionnez **"À propos de Google Chrome"**. Si une mise à jour est disponible, elle sera installée automatiquement.
- Pour **Safari**, assurez-vous que votre système d'exploitation macOS est à jour, car Safari se met à jour via les mises à jour système.

1. **Testez un autre appareil ou un autre réseau :**
Si vous continuez à rencontrer des lenteurs sur votre appareil actuel, essayez d'accéder à Vertuoza depuis un autre appareil (ordinateur, tablette, smartphone) ou à partir d'une autre connexion réseau (Wi-Fi, réseau mobile). Parfois, des problèmes de connexion réseau peuvent également causer des lenteurs.
2. **Désactivez les extensions de votre navigateur :**
Certaines extensions ou plugins installés sur votre navigateur peuvent interférer avec le bon fonctionnement de Vertuoza. Désactivez temporairement vos extensions pour vérifier si cela améliore les performances. Vous pouvez réactiver les extensions une par une pour identifier celle qui pourrait poser problème.
