# Est-ce qu’un pointage est créé lorsqu’un ouvrier n’est pas censé travailler (par exemple le week-end) ?

Non, normalement, un pointage ne doit pas être créé pour un ouvrier qui n’a pas travaillé ce jour-là. 

Si un ouvrier est absent (par exemple le samedi), il ne devrait pas apparaître dans le pointage. Toutefois, cela peut se produire si l’ouvrier a été inscrit manuellement dans le planning avant d’être retiré. 

Il est donc important de vérifier que l’ouvrier a bien été supprimé du planning pour éviter cette situation.
