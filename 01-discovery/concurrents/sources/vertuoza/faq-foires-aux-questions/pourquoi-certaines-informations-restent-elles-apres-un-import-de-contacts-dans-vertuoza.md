# Pourquoi certaines informations restent-elles après un import de contacts dans Vertuoza ?

- Lorsqu’un contact ou une entreprise est supprimé puis réimporté, il est en réalité réactivé en base.
- Seules les informations présentes dans votre fichier Excel sont mises à jour. Si un champ existait auparavant mais est vide dans le fichier, l’ancienne valeur reste inchangée.
- Pour les contacts ou entreprises non complètement supprimables (liés à devis, installations, etc.), il faut mettre à jour directement la fiche dans Vertuoza.
- Les imports par lots fonctionnent normalement pour toutes les nouvelles données.
