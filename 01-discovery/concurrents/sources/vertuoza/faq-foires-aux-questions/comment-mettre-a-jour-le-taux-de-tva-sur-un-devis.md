# Comment mettre à jour le taux de TVA sur un devis

Pour modifier le taux de TVA dans l’état d’avancement, suivez ces étapes :

1. Allez dans la section « **Gestion de chantiers** ».
2. Accédez aux « **Informations générales** ».
3. Sélectionnez « **Devis** ».
4. Cliquez sur le bouton « **Éditer** ».
