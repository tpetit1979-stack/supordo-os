# Que se passe-t-il si un client n’est pas connecté au réseau PEPPOL ?

- Si un client n’est pas sur le réseau, il est impossible d’envoyer la facture électroniquement.
- La facture n’est jamais perdue, elle peut simplement être envoyée par un autre moyen.
- L’historique dans le logiciel enregistrera l’envoi tenté.

- Pour vérifier rapidement si une société est enregistrée sur Peppol, vous pouvez utiliser le site [Peppol Directory](https://directory.peppol.eu/public/locale-en_US/menuitem-search?q=) - Search et rechercher le numéro de TVA (sans espaces, sans points et sans le préfixe BE).
