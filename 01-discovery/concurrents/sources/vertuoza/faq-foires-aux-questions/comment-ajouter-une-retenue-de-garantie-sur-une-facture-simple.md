# Comment ajouter une retenue de garantie sur une facture simple ?

Il n'est pas possible d'ajouter une retenue sur une facture de type simple. Nous devons avoir un endroit pour stocker les documents de libération de retenue. Il est donc impératif d'avoir un chantier à disposition. Sans chantier, vous ne pourrez pas le faire.
