# Est-il possible de lier une installation à un numéro de série et à une date d’installation dans Vertuoza, afin de recevoir un rappel de maintenance un an plus tard ?

Oui, vous pouvez organiser le suivi de vos installations et prévoir des rappels de maintenance dans Vertuoza en suivant ces étapes :

1. **Décrivez l'installation** : Pour chaque installation, ajoutez les informations nécessaires comme le numéro de série et la date d'installation directement dans la description de l'élément. Cela permet de garder un suivi détaillé de chaque équipement installé.
2. **Planifiez les entretiens avec des interventions récurrentes** : Pour mettre en place des rappels de maintenance, utilisez la fonctionnalité des **interventions récurrentes**.
- Créez d’abord une intervention pour le premier entretien prévu.
- Une fois cette intervention enregistrée, accédez au planning et cliquez sur l’intervention. Vous verrez alors une option permettant de répéter l’intervention de façon récurrente.

De cette façon, Vertuoza vous rappellera de planifier les maintenances annuelles, en créant automatiquement un rappel pour les interventions futures.
