# Comment utiliser l'application mobile Vertuoza sur son ordinateur ?

Depuis le mois de Février 2025, les accès de type chantier peuvent se connecter exclusivement sur l'application mobile.
La partie chantier desktop n'est plus active.

Les personnes disposant d'un accès chantier peuvent évidemment se connecter depuis leur smartphone ou leur tablette.

En ce qui concerne les personnes désirant de pouvoir l'utiliser sur ordianteur:

1°) Sur MAC, vous pouvez tout à fait télécharger l'application depuis l'appstore Apple.

2°) Pour les personnes travaillant sur PC, vous pouvez alors télécharger un émulateur d'application Android.
Voici celui que nous recommandons:
[https://www.bluestacks.com/fr](https://www.bluestacks.com/fr)

L'expérience d'utilisation restera inchangée et vous pourrez alors utiliser l'application tout à fait normalement.
