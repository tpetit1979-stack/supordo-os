# Qu'est-ce que l'analytique dans la synchronisation comptable ?

L'analytique est une fonctionnalité optionnelle disponible dans certains logiciels comptables, mais qui n'est pas toujours intégrée par défaut. Elle permet d'analyser la rentabilité des chantiers en associant un identifiant comptable à chaque projet. Si le logiciel comptable du client propose cette fonctionnalité, il pourra créer des chantiers dans le système et les associer à un code analytique. Lors de l'importation des factures d'achat dans Vertuoza, le système synchronise automatiquement ces informations avec l'identifiant comptable correspondant. Cela permet d'affecter les dépenses au bon chantier, garantissant ainsi une gestion financière précise et optimisée du projet.
