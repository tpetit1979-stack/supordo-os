# Comment retrouver un devis signé ?

Depuis les "..." à droite du document dans votre chantier dans Vertuoza, vous avez accès à l'historique. De là, vous pouvez cliquer sur le trombone et sélectionner les pièces jointes pour visualiser le devis signé.
