# Pourquoi ma session a-t-elle été interrompue ?

Il est possible que votre session ait été interrompue parce que vous aviez une facture ouverte dans votre compte. Si tel est le cas, veuillez nous fournir la preuve de votre dernier paiement afin que nous puissions réactiver votre compte.
