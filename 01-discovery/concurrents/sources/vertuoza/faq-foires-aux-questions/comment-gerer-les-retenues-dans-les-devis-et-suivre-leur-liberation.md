# Comment gérer les retenues dans les devis et suivre leur libération ?

Vous pouvez inclure une retenue sur garantie directement dans vos devis depuis le “+” sous le sous-total TTC. 

Cette retenue sera visible dans votre gestion de chantier, à la fois pour les chantiers en cours et les chantiers archivés, dans une colonne dédiée. Pour gérer la libération de cette retenue, vous pouvez créer des rappels personnalisés qui vous alerteront automatiquement lorsqu'il sera temps de libérer la garantie, après la période spécifiée. Cela vous aide à éviter tout oubli et à garantir une gestion efficace des retenues.
