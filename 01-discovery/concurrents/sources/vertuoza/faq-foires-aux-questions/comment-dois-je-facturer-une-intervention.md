# Comment dois-je facturer une intervention ?

Pour facturer une intervention, veuillez suivre ces étapes :

1. **Réaliser un rapport d'intervention** : Assurez-vous de créer un rapport détaillé de l'intervention.
2. **Valider le rapport d'intervention** : Après avoir complété le rapport, validez-le pour vous assurer que toutes les informations sont correctes et complètes.
3. **Transformer le rapport en facture** : Une fois le rapport validé, vous pourrez facturer l’intervention.

En suivant ces étapes, vous pourrez facilement générer une facture précise pour l'intervention effectuée.


NB: vous pouvez également toujours effectuer des modifications au niveau de la facture même si nécessaire.
