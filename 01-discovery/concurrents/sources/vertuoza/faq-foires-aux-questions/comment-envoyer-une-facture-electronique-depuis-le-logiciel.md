# Comment envoyer une facture électronique depuis le logiciel ?

- Créez la facture normalement dans le logiciel.
- Cliquez sur le bouton **“Envoyer électroniquement”** pour la transmettre via PEPPOL.
- L’envoi est sécurisé et enregistré dans l’historique du logiciel.
- Le bouton devient inactif après l’envoi pour éviter les doublons.
