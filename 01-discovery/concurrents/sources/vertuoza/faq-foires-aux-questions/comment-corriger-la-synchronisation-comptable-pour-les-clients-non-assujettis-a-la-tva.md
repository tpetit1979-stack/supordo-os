# Comment corriger la synchronisation comptable pour les clients non assujettis à la TVA ?

Pour résoudre ce problème, il faut aller dans les fiches contacts sous l'onglet "Entreprise" et renseigner le champ "Taux de TVA". Il suffit de sélectionner le taux à 0 % pour indiquer que le client n'est pas assujetti. Cela permettra à Vertuoza de faire le lien correctement et d’éviter que ces clients apparaissent dans le listing des clients assujettis dans Bob.
