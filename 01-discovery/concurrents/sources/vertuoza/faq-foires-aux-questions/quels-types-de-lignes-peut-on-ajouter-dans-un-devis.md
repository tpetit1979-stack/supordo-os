# Quels types de lignes peut-on ajouter dans un devis ?

Il est possible d’ajouter différents types de lignes : titres et sous-titres, texte, poste libre, ouvrages, composants (fournitures, équipements, sous-traitants, main-d’œuvre). Les ouvrages peuvent être modifiés depuis le devis sans impacter la bibliothèque.
