# Pourquoi seules certaines informations (comme la TVA) apparaissent dans mon PDF de devis ?

### 

Cela se produit souvent lorsque le **modèle du devis a été modifié manuellement** via l’onglet **“Visualisation”**.

➡️ En cliquant sur cet onglet, vous créez un modèle personnalisé spécifique à ce devis, qui peut **masquer ou altérer certains éléments affichés** (comme le détail des montants ou des totaux).

🔧 **Conseil** :

Évitez de modifier le modèle via l’onglet “Visualisation” si ce n’est pas nécessaire. Pour garantir un affichage cohérent, utilisez les modèles standard proposés par défaut dans votre interface.
