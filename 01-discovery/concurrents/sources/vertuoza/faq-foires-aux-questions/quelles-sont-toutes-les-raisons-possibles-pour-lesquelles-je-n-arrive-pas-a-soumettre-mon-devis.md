# Quelles sont toutes les raisons possibles pour lesquelles je n'arrive pas à soumettre mon devis ?

Plusieurs raisons peuvent empêcher la soumission de votre devis :

1. **Le montant total est peut-être à zéro.** Un devis ne peut pas être soumis s’il est à 0 EUR. Assurez-vous d’avoir indiqué un montant pour chaque élément de votre devis.
2. **Tous les champs obligatoires ne sont peut-être pas remplis.** Vérifiez que tous les champs requis sont bien renseignés, notamment :
- Les unités pour chaque article
- Les descriptions de chaque ligne du devis
3. **La description contient peut-être des caractères spéciaux non supportés.** Certains caractères spéciaux, comme le symbole “°”, ne sont pas pris en charge. Retirez ces caractères et essayez à nouveau de soumettre le devis.
