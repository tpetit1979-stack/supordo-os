# Pourquoi, lorsque je clique sur ma notification, suis-je redirigé vers la page d'accueil (tableau de bord) au lieu de la module indiquée ?

Ce comportement est lié à une restriction d'accès. Lorsqu'une notification concerne un commentaire provenant d’un module auquel vous n'avez pas les droits d'accès, le système ne peut pas vous rediriger directement vers cette rubrique. Il vous renvoie donc par défaut à la page d'accueil (tableau de bord).

Une demande d'amélioration a été soumise pour qu'un message clair s'affiche afin de vous informer de cette restriction d'accès et de vous recommander de contacter votre administrateur, si nécessaire.

**Recommandation** : Si l'accès au module mentionné dans la notification est essentiel pour vous, nous vous invitons donc à contacter votre administrateur pour obtenir les permissions requises.
