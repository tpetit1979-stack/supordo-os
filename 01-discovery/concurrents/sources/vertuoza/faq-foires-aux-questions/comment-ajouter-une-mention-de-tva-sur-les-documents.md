# Comment ajouter une mention de TVA sur les documents ?

Accédez aux paramètres en suivant ces étapes : **Paramètres** => **Propriétés** => **Taux de TVA** => **Description**. Ajoutez la mention souhaitée. La description sera automatiquement incluse dans les documents lorsque le taux sera sélectionné.
​

Attention, cette modification sera appliquée uniquement dans vos mises en pages personnalisées sur lesquelles vous l'avez ajoutée.
