# Comment définir un modèle de devis par défaut dans le logiciel ?

Pour simplifier la création de devis, vous pouvez définir un modèle de devis par défaut directement depuis les paramètres du logiciel.

Comment procéder :

1. Allez dans **Paramètres → Documents → Devis**.
2. Repérez le modèle souhaité et cliquez sur les **3 petits points** à droite du modèle.
3. Dans le menu déroulant, sélectionnez **“Défaut”** pour le définir comme modèle par défaut.

Tous les nouveaux devis utiliseront automatiquement ce modèle.
