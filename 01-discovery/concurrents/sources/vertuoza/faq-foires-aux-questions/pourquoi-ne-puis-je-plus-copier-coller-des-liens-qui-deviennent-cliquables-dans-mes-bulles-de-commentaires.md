# Pourquoi ne puis-je plus copier/coller des liens qui deviennent cliquables dans mes bulles de commentaires ?

**Explication :**

Cette fonctionnalité n'a jamais été prévue de notre côté. Il est possible que Microsoft ait apporté des modifications récentes dans leur code, ce qui pourrait expliquer pourquoi cette fonction ne semble plus fonctionner.

1. **Modification côté Microsoft :**
Il est fort probable que Microsoft ait modifié la manière dont ils gèrent la copie des données dans leurs logiciels, ce qui pourrait perturber la fonctionnalité de liens cliquables dans les bulles de commentaires.
2. **Ajustement dans notre code :**
Bien que nous n'ayons rien modifié dans notre code à cet égard, nos développeurs ont ajusté une partie de celui-ci pour permettre une certaine intégration des liens cliquables. Cela permet aux utilisateurs de copier/coller des liens avec une certaine fonctionnalité.
