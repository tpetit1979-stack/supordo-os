# Comment afficher le montant total HTVA sur ma facture ?

Pour afficher le montant total HTVA sur votre facture, vous devez ajuster votre modèle de mise en page pour inclure cette information.

1. Allez dans les **paramètres de mise en page** de votre facture.
2. Activez le **sous-total** (qui représente le montant HTVA).
3. Renommez le champ sous-total en "**Total**"
4. Sauvegardez vos modifications.

Une fois cette configuration effectuée, le montant total HTVA apparaîtra sous le nom "Total" sur votre facture.
