# Pourquoi mes lignes sont-elles définies comme options par défaut lorsque je les importe depuis Excel ?

Lorsque vous importez un devis via Excel, si le champ "Prix Total" n'est pas renseigné pour certaines lignes, celles-ci sont automatiquement définies comme des options. Pour éviter cela, veillez à toujours remplir le champ "Prix Total" dans le fichier Excel avant l'importation. (même si le montant est de 0)
