# Comment faire une facture acquittée partiellement dans Vertuoza ?

Dans Vertuoza, il n’est pas possible de marquer directement une facture comme acquittée partiellement. Cependant, vous pouvez gérer cette situation de la manière suivante :

1. **Effectuer un paiement partiel** : Lorsque vous recevez un paiement partiel pour une facture, vous pouvez enregistrer le montant payé dans le système. Cela ne marquera pas la facture comme acquittée à 100 %, mais vous pourrez suivre le paiement effectué.
2. **Créer un avoir/note de crédit pour le solde restant** : Si vous souhaitez réduire le montant à payer ou si une partie de la facture est annulée, vous pouvez créer un **avoir** pour le solde restant. Cela permet de soustraire une partie du montant initial de la facture.

Ainsi, bien que la fonction d'acquittement partiel ne soit pas directement disponible, ces étapes permettent de suivre et de gérer efficacement les paiements partiels et les ajustements nécessaires.
