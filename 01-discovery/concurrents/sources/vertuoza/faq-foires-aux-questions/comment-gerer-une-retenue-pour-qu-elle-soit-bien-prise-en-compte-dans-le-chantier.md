# Comment gérer une retenue pour qu’elle soit bien prise en compte dans le chantier ?

Pour que la retenue soit correctement héritée dans le chantier, **il ne faut pas l’ajouter via le “+” du devis**.

💡 Procédure recommandée :

1. Créez une **ligne en poste libre** dans votre devis.
2. Donnez-lui un nom, par exemple **“Retenue”**.
3. Saisissez le **montant négatif** en ajoutant un devant le chiffre.
4. En **acceptant le devis depuis la gestion de chantier**, le montant correct sera affiché et la facture d’acompte sera correcte.

⚠️ Astuce : cette méthode permet de garder la retenue visible et correctement calculée dans le chantier
