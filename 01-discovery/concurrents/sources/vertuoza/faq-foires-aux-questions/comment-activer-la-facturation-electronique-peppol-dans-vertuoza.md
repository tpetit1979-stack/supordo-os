# Comment activer la facturation électronique PEPPOL dans Vertuoza ?

1. Allez dans **Paramètres → Intégrations → Facturation électronique**.
2. Cliquez sur **Demander une connexion** et renseignez vos informations (nom, e-mail, numéro de TVA, etc.).
3. Votre accompagnant validera votre demande.
4. Une nouvelle colonne **Envoi électronique** apparaîtra dans vos factures et notes de crédit.
5. Après activation, vous pourrez envoyer vos factures via PEPPOL directement depuis Vertuoza.
