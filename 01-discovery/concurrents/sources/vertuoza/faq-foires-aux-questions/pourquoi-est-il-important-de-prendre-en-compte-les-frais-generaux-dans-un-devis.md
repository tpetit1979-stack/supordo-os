# Pourquoi est-il important de prendre en compte les frais généraux dans un devis ?

Un devis rentable doit inclure toutes les dépenses de l’entreprise, y compris les frais fixes (loyer, salaires administratifs, assurances, etc.).

À partir du pack Expert, un pourcentage de frais généraux peut être appliqué automatiquement sur le devis et les chantiers.
