# Comment ajouter un sous-traitant à un planning ?

Si vous avez des difficultés à ajouter un sous-traitant à votre planning, suivez ces étapes simples pour y parvenir :

1. **Accédez à la gestion de chantier** :
- Ouvrez votre interface de gestion des chantiers.
2. **Sélectionnez le chantier concerné** :
- Dans la liste des chantiers, sélectionnez celui pour lequel vous souhaitez ajouter un sous-traitant.
3. **Éditez les informations du chantier** :
- Dans la vue de gestion de chantier, vous devriez voir un bouton en forme de crayon (ou "Éditer") au niveau des informations générales du chantier. Ce bouton vous permet de modifier les détails du chantier.
4. **Ajoutez le sous-traitant** :
- Une fois dans la section d’édition, vous pourrez ajouter le sous-traitant dans la liste prévue à cet effet.
5. **Enregistrez les modifications** :
- N'oubliez pas de sauvegarder les modifications une fois que vous avez ajouté le sous-traitant à votre chantier.

Si vous ne voyez pas le bouton en forme de crayon, il se peut que l'affichage ne soit pas correctement configuré. Vérifiez que vous êtes bien sur le chantier en question et que vous avez les autorisations nécessaires pour effectuer des modifications.
