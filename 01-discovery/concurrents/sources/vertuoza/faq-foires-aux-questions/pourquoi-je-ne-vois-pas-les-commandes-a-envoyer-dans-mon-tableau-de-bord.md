# Pourquoi je ne vois pas les commandes à envoyer dans mon tableau de bord ?

Les commandes de matériel sont uniquement visibles par les gestionnaires du chantier auquel elles sont associées. Si vous n’êtes pas gestionnaire du chantier concerné, vous n’aurez pas accès à ces informations.

Pour résoudre ce problème, vérifiez si vous avez les droits de gestion sur le chantier en question. Si nécessaire, contactez un administrateur pour ajuster vos droits d’accès.
