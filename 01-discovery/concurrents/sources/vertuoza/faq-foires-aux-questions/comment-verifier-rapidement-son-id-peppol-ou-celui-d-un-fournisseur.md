# Comment vérifier rapidement son ID PEPPOL ou celui d’un fournisseur ?

En Belgique, l’ID PEPPOL se construit ainsi :

```
0208:NUMERO_DE_TVA
```

- Sans espaces, sans points et sans le préfixe “BE”.
- Vérifiez l’inscription sur [Peppol Directory](https://directory.peppol.eu/) pour confirmer que le fournisseur ou client est actif.
