# Comment utiliser un autre type d'unité (jour, forfait) pour la main-d'œuvre dans la bibliothèque ?

Actuellement, seules les heures sont disponibles. Pour contourner cela, vous pouvez créer un Ouvrage de type main-d'œuvre et choisir l'unité souhaitée (jour, forfait, etc.). Cette fonctionnalité a été remontée pour amélioration future.
