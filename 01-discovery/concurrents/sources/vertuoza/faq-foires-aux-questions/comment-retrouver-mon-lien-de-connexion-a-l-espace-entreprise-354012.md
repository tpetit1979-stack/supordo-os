# Comment retrouver mon lien de connexion à l'espace entreprise ?

Votre lien de connexion est une URL spécifique à votre entreprise, contenant un code unique appelé *tenant ID*. Voici comment procéder pour retrouver et vérifier l'URL correcte :

1. **Vérifiez votre boîte mail** :
Recherchez un email envoyé par notre service, contenant votre lien de connexion.
2. **Structure de l'URL** :
L'URL commence toujours par :
https://app.vertuoza.app/?tenant_id=
Elle se termine par le code de votre entreprise (*tenant ID*). Par exemple, si votre code d’entreprise est **1234**, le lien ressemblera à :
https://app.vertuoza.app/?tenant_id=1234
3. **Utilisation des identifiants** :
Une fois sur le lien correct, entrez votre identifiant et mot de passe pour accéder à votre espace.

### Note :

Si la connexion ne semble toujours pas fonctionner, malgré avoir bien vérifié votre code d'entreprise dans l'URL, n'hésitez pas à cliquer sur **"Réinitialiser mon mot de passe"** sur la page de connexion. Vous recevrez alors un email contenant un nouveau mot de passe. Vous pourrez ensuite le mettre à jour directement dans votre profil une fois connecté.

Si vous avez toujours des difficultés, contactez notre support pour obtenir de l’aide.
