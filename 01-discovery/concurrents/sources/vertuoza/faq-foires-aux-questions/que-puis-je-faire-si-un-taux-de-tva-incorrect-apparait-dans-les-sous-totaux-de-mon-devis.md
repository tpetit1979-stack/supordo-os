# Que puis-je faire si un taux de TVA incorrect apparaît dans les sous-totaux de mon devis ?

Si vous constatez que des taux de TVA inattendus (comme 21 %) apparaissent dans les sous-totaux de votre devis alors que vous avez sélectionné un autre taux de TVA (comme 0 %), cela peut être lié à l’activation précédente de l’option "TVA à la ligne" dans vos paramètres. Voici comment résoudre ce problème :

1. **Vérifiez si l'option "TVA à la ligne" est activée** : Cette option permet d’attribuer un taux de TVA différent à chaque ligne du devis. Si cette option a été activée à un moment donné, les lignes peuvent avoir conservé un taux spécifique même après sa désactivation.
2. **Activez temporairement l'option "TVA à la ligne"** :
- Allez dans vos **paramètres** et réactivez l'option **TVA à la ligne**.
- Retournez dans votre devis et vérifiez chaque ligne pour modifier le taux de TVA en fonction de vos besoins (par exemple, remettez chaque ligne à 0 % si nécessaire).
3. **Désactivez à nouveau l’option "TVA à la ligne"** :
- Après avoir mis à jour tous les taux de TVA dans le devis, désactivez à nouveau l'option "TVA à la ligne" dans vos paramètres.
4. **Vérifiez les sous-totaux** : Une fois ces étapes terminées, seuls les taux de TVA appliqués devraient apparaître dans les sous-totaux de votre devis.

En suivant ces étapes, vous ne verrez que le taux de TVA souhaité dans le sous-total du devis, sans affichage de taux de TVA non souhaité.
