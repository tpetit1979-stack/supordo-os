# Quels sont les codes couleur utilisés dans le planning d'intervention et que signifient-ils ?

- **Bleu neutre** : intervention de base
- **Bleu / mauve** : intervention modifiée (par exemple, changement de contact)
- **Bleu clair** : personne accompagnante (non principale)
- **Rouge** : autre type d’entrée
- **Gris** : chantier
- **Vert** : rapport d’intervention clôturé
