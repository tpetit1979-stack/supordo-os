# Comment appliquer un escompte correctement dans l'application ?

Actuellement, l’escompte est calculé automatiquement sur le **montant TTC**, alors qu’il devrait normalement s’appliquer sur le **montant HTVA**. Ce comportement ne peut pas encore être modifié dans l’application, mais une demande de développement a été transmise pour corriger cela.

**En attendant, vous avez deux options :**

1. **Ajouter une remarque** sur la facture pour indiquer le calcul correct de l’escompte.
2. **Enregistrer le paiement comme complet**, puis **faire une écriture comptable manuelle** pour gérer l’escompte.

Vous pouvez également saisir l’escompte manuellement en cliquant sur le **“+” bleu à côté du montant TTC**, en choisissant « Escompte » comme libellé et en précisant son montant.
