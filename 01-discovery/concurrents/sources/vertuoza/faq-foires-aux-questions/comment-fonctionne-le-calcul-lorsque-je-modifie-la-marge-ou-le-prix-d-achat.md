# Comment fonctionne le calcul lorsque je modifie la marge ou le prix d'achat ?

Le fonctionnement actuel de l'application est le suivant :

### **Modification du champ "Prix d'achat"**

Si vous modifiez le **prix d'achat** sans toucher à la **marge**, le **prix total** sera recalculé sur base du nouveau prix d'achat.

👉 La **marge reste inchangée**.

### **Modification du champ "Marge"**

Si vous modifiez la **marge** sans changer le **prix d'achat**, ce dernier reste tel quel.

👉 Dans ce cas, le **prix total** est recalculé sur base de la **nouvelle marge**.
