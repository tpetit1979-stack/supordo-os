# Comment fonctionne le suivi de chantier pour un chef d'équipe ?

Le suivi de chantier pour un chef d’équipe permet de planifier et suivre précisément l’avancement des travaux. Une explication détaillée est disponible via ce lien : [Suivi de chantier - Chef d'équipe](https://intercom-help.eu/vertuoza/fr/articles/133053-suivi-de-chantier-chef-d-equipe). Vous pouvez également consulter tous les articles d’aide ici : [Centre d’aide Vertuoza](https://intercom-help.eu/vertuoza/fr/).

Si vous souhaitez utiliser cette fonction avec un compte gestionnaire, il faudra se référer au suivi de chantier dédié aux gestionnaires.
