# Pourquoi le bouton pour modifier le statut d’une commande est-il désactivé ?

Le bouton est désactivé lorsque la commande est déjà liée à un ou plusieurs avenants.

- Un tooltip apparaît lorsque vous passez la souris sur le bouton pour expliquer cette limitation.
- Dans ce cas, il est impossible de modifier le statut d’une commande sous-traitant vers “En cours " afin de préserver la cohérence entre la commande et ses avenants.

En résumé : le bouton reste désactivé tant que la commande est associée à un ou plusieurs avenants, pour éviter toute modification conflictuelle.
