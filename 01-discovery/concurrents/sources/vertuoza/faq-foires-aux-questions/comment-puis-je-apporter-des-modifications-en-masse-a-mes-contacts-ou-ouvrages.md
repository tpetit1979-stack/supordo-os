# Comment puis-je apporter des modifications en masse à mes contacts ou ouvrages ?

Pour ce faire, exportez les données pour les éditer dans Excel, puis réimportez-les.

Attention, afin d'éviter des doublons lors de l'importation, il est important de tenir compte de ce point :

- Pour les contacts, on se base sur le nom + prénom.
- Pour les ouvrages, on se base sur la description.

Ainsi, ne modifiez pas ces informations, sinon de nouveaux doublons seront créés.
