# Pourquoi certaines lignes ne sont-elles pas reprises dans la facture groupée ?

Les lignes dont la quantité ou le prix unitaire est de 0 ne sont pas incluses dans la facture groupée. Par exemple, si une borne de recharge a un prix unitaire de 0 €, ou si le sol est facturé à 0 €, ces éléments ne seront pas repris dans la facture.

Pour inclure ces lignes dans la facture, vous devrez modifier les quantités ou les prix unitaires via l'intervention. 

Accédez à la section "rapport" de l'intervention pour revenir à l'état précédent et ajuster les prix ou les quantités manquants.

Nous avons également remonté cette situation au responsable produit comme suggestion d'amélioration.
