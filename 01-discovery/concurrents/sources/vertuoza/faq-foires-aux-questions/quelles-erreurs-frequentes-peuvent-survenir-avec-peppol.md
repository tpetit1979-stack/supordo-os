# Quelles erreurs fréquentes peuvent survenir avec PEPPOL ?

1. **Client ou fournisseur non enregistré** → Échec de l’envoi ou rattachement.
2. **TVA incorrecte ou différente** → Le système ne reconnaît pas le fournisseur automatiquement.
3. **Factures vers particuliers** → Non supporté par PEPPOL.

Vérifiez toujours les numéros de TVA et l’inscription sur Peppol Directory pour éviter ces erreurs.
