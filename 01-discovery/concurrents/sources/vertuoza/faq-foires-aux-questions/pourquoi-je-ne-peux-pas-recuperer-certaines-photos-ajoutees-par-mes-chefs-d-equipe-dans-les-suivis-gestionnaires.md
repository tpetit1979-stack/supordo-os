# Pourquoi je ne peux pas récupérer certaines photos ajoutées par mes chefs d'équipe dans les suivis gestionnaires ?

Si vous ne parvenez pas à récupérer certaines photos, cela peut être lié à vos paramètres de chantier. Dans vos préférences de chantier, vous devez vérifier le nombre de jours que vous avez configuré pour la récupération des photos. 

Si vous avez, par exemple, défini une période de 20 jours, seules les photos prises dans ce délai seront disponibles. Si les photos datent de plus de 20 jours, elles ne seront plus sélectionnables.

Il est donc essentiel de bien ajuster ce paramètre en fonction de vos besoins pour éviter toute perte de données.
