# Comment puis-je afficher l'option permettant de sélectionner "Régie" ou "Forfait" lors de la création d'une intervention via l’accès chantier?

Pour pouvoir sélectionner "Régie" ou "Forfait" lors de la création d'une intervention, vous devez activer l'affichage des prix pour le responsable d'intervention. Voici comment procéder :

1. **Accéder aux Paramètres :**
- Allez dans le menu des **Paramètres**.
2. **Configurer les Propriétés de l'Intervention :**
- Naviguez vers l'onglet **Propriétés**.
- Sélectionnez **Intervention** dans les options disponibles.
3. **Activer l'Affichage des Prix :**
- Sous **Responsable interventions**, cliquez sur éditer à droite d’un responsable d’intervention.
- Vous trouverez l'option **"Activer l'affichage des prix"**.
- Cochez cette option afin de pouvoir voir et sélectionner le champ “Régie” ou “Forfait” lors de la création d’une intervention.
4. **Sauvegarder les Modifications :**
- Assurez-vous d'enregistrer les modifications apportées aux paramètres en cliquant en sur “**Soumettre**”.
