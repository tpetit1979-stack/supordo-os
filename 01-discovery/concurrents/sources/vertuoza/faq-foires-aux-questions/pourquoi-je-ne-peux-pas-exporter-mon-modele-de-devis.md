# Pourquoi je ne peux pas exporter mon modèle de devis ?

Si vous ne parvenez pas à exporter un modèle de devis, c’est probablement parce qu’il a été créé en tant que type de modèle nommé “**Document personnel”**. Or, ce type de modèle ne peut pas être exporté directement.

💡 Pour pouvoir l’exporter, il faut d’abord l’**ajouter dans un modèle de devis** créé avec une ou deux colonnes depuis vos Paramètres - Documents - Devis. Seuls ces modèles peuvent être exportés.
