# Pourquoi je n'arrive pas à ajouter un compte chantier dans le planning d’intervention ?

Si vous ne parvenez pas à ajouter un compte chantier dans le planning, voici les étapes à suivre pour résoudre le problème :

1. **Vérifiez la fiche personnelle du responsable** :
- Allez dans la **fiche personnelle** du responsable de l’intervention.
- **Cochez** l'option **"Interventions"** pour permettre au responsable d’être associé aux interventions.
2. **Configurez le responsable dans les paramètres d’intervention** :
- Allez dans les **Paramètres** → **Intervention** → **Responsable intervention**.
- Ajoutez le responsable en le sélectionnant dans la liste des intervenants.

Une fois ces étapes terminées, vous pourrez ajouter le compte chantier au planning et assigner correctement l’intervention.
