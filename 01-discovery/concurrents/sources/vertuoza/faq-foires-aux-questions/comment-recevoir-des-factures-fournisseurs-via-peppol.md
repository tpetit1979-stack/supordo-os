# Comment recevoir des factures fournisseurs via PEPPOL ?

Vous pouvez choisir entre deux modes :

- **Directement dans Vertuoza** : les factures sont visibles dans l’onglet Factures fournisseurs et peuvent être liées à vos chantiers.
- **Dans votre logiciel comptable** : Vertuoza peut synchroniser uniquement les factures liées aux chantiers pour votre comptable.

Cette flexibilité permet de collaborer efficacement avec votre comptable tout en gardant une vision complète de vos projets.
