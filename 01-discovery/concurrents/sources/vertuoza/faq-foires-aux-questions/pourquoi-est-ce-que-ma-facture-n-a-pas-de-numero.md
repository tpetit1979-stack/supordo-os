# Pourquoi est-ce que ma facture n'a pas de numéro ?

Vous devez d'abord la comptabiliser ⇒ ensuite un numéro lui sera attribué. 
​
Pour comptabiliser une facture :

1. Allez dans **Finances > Factures**
2. Créez-la d'abord **Nouveau**
3. Cliquez sur **Soumettre**
4. Vous arrivez à nouveau dans la page contenant toutes le factures
5. Cliquez à droite de la facture sur les 3 "**...**" → sélectionnez **Comptabiliser**
