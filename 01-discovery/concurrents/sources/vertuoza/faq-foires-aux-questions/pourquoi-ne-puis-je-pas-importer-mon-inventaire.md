# Pourquoi ne puis-je pas importer mon inventaire ?

Cela peut arriver si la colonne **Identifiants fournitures** n'est pas remplie dans votre fichier CSV. Les identifiants (ID) sont indispensables pour associer les quantités aux bonnes fournitures lors de l'importation.


Voici comment retrouver les identifiants des fournitures :

1. **Filtrer les fournitures dans la bibliothèque :**
Accédez à votre bibliothèque de fournitures et appliquez des filtres pour afficher uniquement les fournitures en stock.
2. **Exporter la liste des fournitures :**
Utilisez l'option d'exportation pour télécharger un fichier Excel contenant toutes les informations sur vos fournitures. Ce fichier inclura les identifiants (ID) ainsi que l'emplacement de chaque fourniture.
3. **Préparer le fichier pour l'importation :**
- Supprimez les colonnes inutiles dans le fichier exporté.
- Ajoutez une colonne pour indiquer les quantités.
- Sauvegardez le fichier au format CSV.

Vous pourrez ensuite importer ce fichier correctement.
