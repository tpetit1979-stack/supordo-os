# Comment gérer un ouvrier qui est également son propre chef d'équipe ?

Pour un ouvrier qui est aussi son propre chef d'équipe, vous devez créer un compte gestion en plus de son compte chantier. Ensuite, vous pouvez demander la création d'un groupe "Chef d'équipe" pour définir les accès nécessaires. Notez que l'application mobile est uniquement conçue pour les comptes chantier, tandis que le compte gestion permet l'accès au planning via le web/ordinateur.
