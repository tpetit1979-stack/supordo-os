# Pourquoi la marge peut sembler incorrecte dans un devis ?

Le calcul de marge dans le logiciel est correct et fonctionne selon les informations saisies. Cependant, certains résultats peuvent sembler “incorrects” si les fournitures sont saisies avec un prix de vente de 0 € ou une quantité inadaptée.

**Ce qu’il faut savoir :**

- La marge est calculée en comparant le prix de vente au coût d’achat réel.
- Si un prix est saisi à 0 €, le logiciel considère qu’il y a une perte totale pour cette ligne, ce qui impacte la marge globale.
- Le logiciel ne peut pas deviner un futur prix de vente.

**Pour obtenir une marge réaliste :**

1. Saisir un prix de vente estimé, même provisoire, plutôt que 0 €.
2. Si le prix exact n’est pas encore connu, mettre la ligne en option ou la quantité à 0 pour qu’elle n’affecte pas la marge globale.

En suivant ces bonnes pratiques, la marge affichée reflétera correctement la réalité.
