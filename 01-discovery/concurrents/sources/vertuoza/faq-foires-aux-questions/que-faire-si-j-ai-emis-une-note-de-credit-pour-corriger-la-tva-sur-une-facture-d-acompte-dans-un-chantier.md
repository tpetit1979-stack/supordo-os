# Que faire si j’ai émis une note de crédit pour corriger la TVA sur une facture d’acompte dans un chantier ?

**Il est important de finaliser le chantier avec une facture finale pour que la note de crédit soit correctement prise en compte dans le solde total du chantier.**

**Voici les étapes à suivre pour une bonne comptabilisation :**

1. **Vérifiez que la note de crédit est bien finalisée :**
- Dans l’onglet *Notes de crédit*, ouvrez la note concernée.
- Si elle est en statut *à envoyer*, cliquez sur le "✓" pour la comptabiliser.
- Cela garantit que la note de crédit est prise en compte dans la balance du chantier.
2. **Créez une facture finale :**
- Rendez-vous dans *Gestion de chantier > Facturation > Nouveau > Facture finale*.
- Le système reprendra automatiquement :
• Les factures déjà émises (y compris les acomptes)
• La note de crédit enregistrée
- Le solde restant à facturer sera calculé automatiquement.

Cette procédure vous permet de :

- Ne pas dupliquer les acomptes,
- Clôturer correctement le chantier avec des montants exacts (TVA incluse).
