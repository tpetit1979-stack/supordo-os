# Que faire si le fournisseur ou client n’est pas encore enregistré sur PEPPOL ?

1. Vérifiez l’inscription via [Peppol Directory](https://directory.peppol.eu/) en entrant le numéro de TVA.
2. Si le fournisseur ou client n’est pas enregistré, l’envoi ou la réception échouera.
3. Une fois l’inscription effectuée, vous pourrez renvoyer la facture ou recevoir automatiquement les documents dans Vertuoza.
