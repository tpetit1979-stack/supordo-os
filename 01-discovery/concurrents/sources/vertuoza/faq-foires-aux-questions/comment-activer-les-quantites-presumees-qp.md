# Comment activer les quantités présumées (QP) ?

### Étapes pour activer les quantités présumées (QP) :

1. **Accéder aux Paramètres :**
- Allez dans le menu des **Paramètres**.
2. **Préférences d’affichage :**
- Sélectionnez l'option **Préférences d'affichage**.
3. **Type de marché :**
- Activez l'option **Type de marché (QP)**.
4. **Utilisation dans les devis :**
- Dans votre devis, une colonne "**Type de marché**" sera ajoutée.
- Vous pourrez sélectionner l'option **Quantité présumée** (QP).

### Information complémentaire :

Activer cette option vous permettra de mieux gérer les ressources et de communiquer clairement avec vos sous-traitants que les quantités indiquées sont susceptibles de changer une fois les mesures définitives obtenues.
