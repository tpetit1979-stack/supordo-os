# Pourquoi toutes les lignes ne sont-elles pas reprises dans une facture groupée d'intervention ?

Lorsqu'on génère une facture groupée dans ABS EDE, les lignes dont le montant est à 0 € ne sont pas reprises automatiquement dans la facture.

Cela peut donner l'impression qu'il manque des éléments, mais ce n’est pas un bug : seules les lignes facturables (avec un montant supérieur à 0) sont prises en compte dans ce type de facture.

👉 **Solution recommandée** :

Si vous souhaitez que toutes les lignes facturables soient bien présentes dans la facture, il faut facturer les interventions une par une, et non via une facture groupée.
