# Comment actualiser les prix depuis un devis en sélectionnant uniquement certaines lignes ?

Pour actualiser les prix à partir d’un devis tout en sélectionnant uniquement certaines lignes, suivez les étapes ci-dessous :

1. **Ouvrez le devis concerné**.
2. **Cochez les lignes** pour lesquelles vous souhaitez actualiser le prix.
3. Cliquez sur le bouton **"Actualiser le prix"** (généralement situé en haut ou dans le menu contextuel).
4. Les prix des lignes sélectionnées seront mis à jour en fonction des dernières données enregistrées (matériaux, fournitures, main-d'œuvre, etc.).
