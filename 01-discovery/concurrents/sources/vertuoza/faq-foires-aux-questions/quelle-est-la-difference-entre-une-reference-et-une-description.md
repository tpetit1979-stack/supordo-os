# Quelle est la différence entre une référence et une description ?

- **Référence** : il s’agit d’un **identifiant unique** attribué à chaque composant. Elle sert principalement en interne, par exemple pour retrouver ou importer un élément dans le logiciel. Exemple : MO-PG, MO-MOTEUR.
- **Description** : il s’agit du texte qui apparaît sur le **devis destiné au client**. Elle doit être claire et compréhensible afin d’expliquer le travail ou l’élément facturé. Exemple : *Placement PG*, *Placement moteur*, *Placement châssis*.
