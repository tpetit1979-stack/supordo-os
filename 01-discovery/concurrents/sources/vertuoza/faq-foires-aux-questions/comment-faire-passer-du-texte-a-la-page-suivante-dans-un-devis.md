# Comment faire passer du texte à la page suivante dans un devis ?

Pour faire en sorte qu’un texte apparaisse sur une nouvelle page dans un devis, vous pouvez ajouter une ligne de type "Texte" et y insérer des retours à la ligne.

Voici comment procéder :

1. Dans le devis, cliquez sur **Visualisation**.
2. Sélectionnez un modèle personnalisé, puis cliquez sur **Modifier**.
3. Vous pouvez ensuite ajouter les retours à la ligne à l’endroit souhaité afin de faire passer du texte sur la page suivante.
