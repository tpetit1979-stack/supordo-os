# Comment puis-je entrer les frais kilométriques pour mes interventions ?

Pour entrer les frais kilométriques dans le cadre des interventions, vous devez d'abord accéder à la section de paramétrage. Suivez ces étapes :

1. Allez dans **Paramétrage**.
2. Sélectionnez **Gestion**.
3. Cliquez sur **Interventions**.
4. Ouvrez l'onglet **Préférences**.
5. Assurez-vous de cocher l'option **Appliquer les frais de transport** sur "Oui".
