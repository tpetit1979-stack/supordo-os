# Ouvrier - Rapport d’intervention

## Création du rapport

Depuis le planning, l’ouvrier peut créer un rapport d’intervention. Dans ce rapport, il peut:

**1. Ajouter, supprimer et modifier la liste des accompagnants**

Dans cette section, l’ouvrier peut gérer la liste des accompagnants.

💡 Dans le cas d’une intervention en régie, chaque accompagnant est ajouté dans les coûts de l’intervention.

**Pour ajouter un accompagnant:**

![](https://downloads.intercomcdn.eu/i/o/15338281/a6e9543157a1a3aea0eaab4e/Frame+2608633.png?expires=1788634800&signature=412c72b95467c2163e25889306fd43e5787563bfb1abde3397489c2bd42610c1&req=0dBsxlD4pDZk2hL085ZhoZk73MC%2FyqZ0uPEgx8BXFypqfk77gnJVCzp4ZY%2FP%0ACV%2Bk6ChVb6I7RtlB%0A)

**2. Editer la période de l’intervention**

L’ouvrier a la possibilité de modifier le temps initialement prévu pour la réalisation de l’intervention en ajustant l’heure de début et l’heure de fin.

💡 Dans le cas d’une intervention en régie, la période indiquée sert à calculer le coût de l’intervention.

**3. Paramètres ajustable **

- **Intervention terminée**
L'ouvrier a la possibilité de marquer l'intervention comme terminée. Cela indiquera au gestionnaire que tout s'est déroulé comme prévu et qu'il peut clôturer cette intervention.

- **Intervention facturable**
L'ouvrier a la possibilité de marquer l'intervention comme non facturable (par exemple, une intervention de SAV gratuite pour le client). Dans ce cas, il peut entrer une raison.

- **Reprogrammer l'intervention**
Si nécessaire, l'ouvrier peut également reprogrammer l'intervention en entrant la nouvelle date et les actions à réaliser. Une nouvelle intervention "A programmer" sera alors créée sur le planning côté gestion.

![](https://downloads.intercomcdn.eu/i/o/15339046/da6e6f2370267581bf7e9a14/Frame+2608634.png?expires=1788634800&signature=2424160efa505938d7763a9e073125cb2f0db31749139d917a9cba6988cc80d2&req=0dBsxlH6qDFk2hL085ZhoaHPYwwQOe1gkUIbO9LrNeCMS7cKgb%2Fr08poZEjw%0ATg%3D%3D%0A)

**4. Intervention en régie/forfaitaire/sur base du devis**

- **Intervention forfaitaire**
L’ouvrier peut définir si l’intervention est facturable ou non, modifier le prix de l’intervention et ajouter une note.

💡 L'élément apparaîtra sur la facture si l'option "facturable" est activée.

![](https://downloads.intercomcdn.eu/i/o/15356312/bccea7d23e68d9754b8faf0c/Fofaitaire.png?expires=1788634800&signature=581432417d6364873e9c4dd86ee0ee386dff6837146cc9a38d3e741d20d78956&req=0dBswF75rTVk2hL085ZhoeJvureltqpPLN6SBkWzbhZ7MJk%2B0NdrUN0D850J%0AkQ%3D%3D%0A)
- **Intervention en régie**
L’ouvrier peut définir si la main-d’œuvre est facturable ou non, modifier le prix unitaire et ajouter une note.

💡 L'élément apparaîtra sur la facture si l'option "facturable" est activée.

![](https://downloads.intercomcdn.eu/i/o/15345235/1d366150212b9a7c1a6313c5/Frame+2608635.png?expires=1788634800&signature=b99844db805a89078849b5c6a91e09d815e0b9c30216786111edf57f82d63467&req=0dBswV34rzJk2hL085ZhoWsVWEU5Ai7W9Z493fKvgGOk%2B%2Fy9QjThEJeyVklV%0Aqg%3D%3D%0A)
- **Intervention sur base d’un devis**
L’ouvrier peut définir si une ligne est facturable ou non, modifier le prix unitaire et ajouter une note.

💡 L'élément apparaîtra sur la facture si l'option "facturable" est activée.

![](https://downloads.intercomcdn.eu/i/o/15356335/f0a299cfb850e1aa8c64122f/Devis.png?expires=1788634800&signature=92a35a9ffdecd53226a3778217e642a0d384451522c43c00d96527b1ab6f1a0a&req=0dBswF75rzJk2hL085ZhoTNzdlXKLLNlirCKTjElkEcQlglCubej17rl%2FeUD%0AiA%3D%3D%0A)

**5. Ajouter et modifier les coûts**

Dans cette section, l’ouvrier peut ajouter les différents coûts d’intervention. Il peut choisir parmi les options suivantes : frais, poste libre ou fourniture.

💡 Le coût apparaîtra sur la facture si l'option "facturable" est activée.

![](https://downloads.intercomcdn.eu/i/o/15357300/bf81642fb5ff33dede9a0e07/Cout.png?expires=1788634800&signature=5acb21b1cfdba73e25dc01fe0986d4c2d618efb431b6e4df875031c4cfbfc8a0&req=0dBswF%2F5rDdk2hL085ZhoWhoSmrNPi09Bm75jOYalNXnTcvh4mfEIs9K6U7Q%0AQxBwBkn4IJpjgb4Q%0A)

**6. Ajouter des certificats d’entretiens/ photos d'interventions**

L’ouvrier peut joindre les photos du certificat d’entretien et les photos de l'intervention à à son rapport

![](https://downloads.intercomcdn.eu/i/o/15357796/1ccea01e6d154d9ff4a7ac53/Certificat.png?expires=1788634800&signature=f0eb32da57f405dd4bd9bec3b0934827d9271250c80b526564a2e658bbaa19b0&req=0dBswF%2F9pTFk2hL085Zhoe20Fi%2FTjmzqyjJHCoLqvT89QfKa1uyxsSHDPsNL%0AWhpog0KRpu%2FDspdX%0A)

## **Finalisation du rapport**

Une fois le rapport terminé, l’ouvrier peut le **soumettre**. Il arrive alors sur une page en lecture seule qui lui permet de relire son rapport et de le faire signer par le client avant de l’accepter.

![](https://downloads.intercomcdn.eu/i/o/15357827/69e4c2ac0ff5520d7cc32e43/Signature.png?expires=1788634800&signature=ab15e2b8800fb39d45d62378d421716fd4c86c6884608f7e7ee84b32a715bff4&req=0dBswF%2FyrjBk2hL085ZhoSQL7E52C84Mm1v7V31b3V0FqBfqBy%2BmDeKpI1Xk%0A5Ks8lVwntI4%2BfZ0U%0A)

Une fois accepté, l’ouvrier ne peut plus modifier le rapport.

L’intervention deviendra verte sur le planning du gestionnaire et le rapport apparaîtra sous le statut “Clôturé” dans la gestion de l’intervention.
