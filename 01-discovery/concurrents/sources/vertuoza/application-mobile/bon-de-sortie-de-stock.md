# Bon de sortie de stock

⚠️ Ce module est uniquement disponible pour le pack **EXPERT + .**

### 1. Que permet les bons de sortie de stock?

Vous pouvez sortir les éléments de votre stock depuis une intervention ou un chantier. Ils diminueront les stocks. Les matériaux seront en statut réservé afin d’être traité par le/les magasinier(s).

### 2. Création d’un bon de sortie

1️⃣ Cliquez sur **information** du chantier ou de l’intervention.

2️⃣ Cliquez sur **bon de sortie de stock.**

3️⃣ Cliquez sur **Nouvelle demande**.

4️⃣ Introduisez les **informations générales**:

- Une **référence**.
- Un **demandeur** (votre ouvrier qui fait la demande).
- Une **intervention/chantier** (déja remplie qui se rapporte à votre chantier ou intervention).

![](https://downloads.intercomcdn.eu/i/o/yr18hzl2/34360052/88414155ba7df0459a4a13ab98b0/-4-New-page-01-21-2025_02_56_PM.png?expires=1788634800&signature=1db119013fd49348114d33f0b4e43a775bc76eebaa4f61c93679bb9e3355a6fc&req=09Fsw1j6qTVk2hL085ZhoYQCydp8Rzhs%2Bxt9b0wvP70E7JC7fqSCdYGlhyBu%0AZkm4zJw99XdbTD0z%0A)

5️⃣ Appuyez sur **encodage**.

Ensuite, il faut **encoder** la ou les fournitures demandées avec le **“+”.**

- Entrez la **fourniture** (il est impossible de voir les fournitures si il n’y en a pas dans le stock).
- Entrez la **quantité** souhaitée pour chaque emplacement (le maximum possible est la quantité dans le stock).
- Appuyez sur **sauvergarder**.

![](https://downloads.intercomcdn.eu/i/o/yr18hzl2/34359037/0c26b63c9f52ef6c28e4f8cc6b67/IMG_1152_PNG.png?expires=1788634800&signature=bb5b67780c67c1216465997366fe070d6b8ba3e0cdb588acad1af7fd7fb4bfe1&req=09FswFH6rzBk2hL085ZhoTHPMZGHCP3noNDx7d72P4REBLJHUv60eal%2FP%2Fkf%0AUZT0dOiuteCwB7Mx%0A)

6️⃣ Introduisez une **remarque interne** si besoin.

7️⃣ Cliquez sur **soumettre**.

C’est **fini,** le bon de stock placera les **fournitures en “réservées**”. Lorsque le magasinier validera celle-ci, elles diminueront le stock.

[Vidéo YouTube](https://www.youtube.com/watch?v=lTv7JJq67cI)

### **3. Modifier ou supprimer le bon de sortie de stock**

Les actions de modification/suppression dépendent du statut:

- **Brouillon** : Vous pouvez modifier ou supprimer le bon de sortie en cliquant sur "..." si le statut est brouillon.
- **Réservé** : Cliquez sur "..." puis sur "réouvrir le bon de sortie" pour revenir au statut brouillon.
- **Livré** : Impossible de modifier ou supprimer le bon une fois qu'il est livré (validé par le magasinier).
