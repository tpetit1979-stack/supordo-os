# Ouvrier - Planning de l’ouvrier

Une fois connecté, l’ouvrier arrive sur le planning de sa journée. 📆

Ce planning permet de visualiser facilement tous les

- Chantiers
- Interventions
- Assignations de type "autres"

 sur lesquels il est planifié.

![](https://downloads.intercomcdn.eu/i/o/18181516/92ec3b5bd8004391c1e61f79/Frame+43526.png?expires=1788634800&signature=f25113f5d61cd28f5d9a93a50220745a2a96fa46130c7adf6ac4eca50ca9e1e3&req=0d1uzVn%2FrTFk2hL085Zhoa%2BiYNR315ppPJSngzEoLYc9IeeZtE3RzEiw5ooY%0Ah46acZNV2kmmebjd%0A)

**Navigation entre les jours**

Pour consulter le planning des autres jours, il faut :

- Cliquer sur le jour concerné en haut de l’écran. Une fois sélectionné, celui-ci devient bleu.
- Cliquer sur le mois en haut à gauche de l'écran pour ouvrir un calendrier et cliquer sur le jour désiré.
- Glisser vers la gauche ou vers la droite pour voir le planning des semaines précédentes ou suivantes.
