# Ouvrier - Module Pointage sur l'app mobile

### 1) Comprendre le pointage chez Vertuoza

Le module pointage sur l'application mobile permet aux chefs d'équipe de modifier et valider facilement le pointage de leurs équipes directement depuis leur smartphone ou tablette. Adieu les informations envoyées sur Whatsapp ou écrite sur une feuille de papier.

**Prérequis :** Le module doit être activé par un admin sur ordinateur dans les paramètres Paramètres > Propriétés > Pointage > Préférences.

**Fonctionnement :** Un pointage est automatiquement généré chaque jour, pour chaque ouvrier en fonction du planning de chantier et d’intervention. Si les informations sont correctes dans les plannings, le chef d’équipe n’a qu’à les valider. Il peut également :

- Modifier les heures de départ, d’arrivée, et de pause en fonction des aléas de la journée.
- Ajouter ou modifier une prestation (chantier ou intervention).
- Modifier les informations de mobilité, telles que le nombre de kilomètres parcourus et le rôle de chauffeur ou passager.

Le pointage validé sera ensuite clôturé par le gestionnaire ou la secrétaire sur ordinateur, influençant ainsi la rentabilité des chantiers et pouvant être exporté pour le secrétariat social.

### 2) Accéder au module de pointage sur l'app

Après vous être connecté à l'application mobile, vous pouvez accéder au module de pointage en cliquant sur l'icône "Pointage" dans la barre de menu en bas de l'écran. Si vous ne le voyez pas, vérifier le prérequis expliqué dans la section précédente.

![](https://downloads.intercomcdn.eu/i/o/18609686/ac2b11ec9d1ead1ad7ff655b/image.png?expires=1788634800&signature=22e2c5789772f271261f8538ec6d71478eb02a07aa0440679e846494af61af5e&req=0d1pxVH8pDFk2hL085ZhoU%2BNxYD6i9WSaZvINQPc5o8Y2HD42gMpq1%2FGNYNo%0A8y9njfK9DH1R0%2Fes%0A)

Un chiffre dans une bulle rouge indique le nombre total de pointages restant à valider. 

> 💡ASTUCE : Motiver vos chefs d'équipe à arriver à 0 à la fin de chaque journée.

 Sur l’écran de pointage, vous verrez une carte de pointage pour chaque ouvrier de votre équipe, offrant un résumé de leur journée de travail: le nombre d'heure prestée et le nombre d'heure supplémentaire entre parenthèse. Les heures supp sont définies en fonction de l'horaire indiquée sur la fiche ouvrier.

![](https://downloads.intercomcdn.eu/i/o/18609936/7f4c086a9f6443b9b90a1672/WhatsApp+Image+2024-08-21+%C3%A0+12_08_41_484da2b5.jpg?expires=1788634800&signature=07770fdca9028c6408adeb270bad8f3b6e5264321db001476e5b570651e1ab0c&req=0d1pxVHzrzFk2hL085Zhob6gKaC3ycwkARdM1r9AGxOpp0uL2hFxw4czMhh%2B%0APVUESspIe%2BTaImy4%0A)

Sur la barre supérieure, vous pouvez naviger entre les jours en cliquant sur celui-ci. Un chiffre indique le nombre de pointages qu'il reste à valider pour chaque jour. Si vous cliquez sur le mois, vous ouvrez le calendrier afin de naviguer jusqu'à un jour précis. 

### 3) Valider un pointage

Pour valider un pointage, cliquez sur l'icone "V" bleu à droite de la carte de pointage de l'ouvrier. L’icône se transformera en flèche, permettant de rouvrir le pointage si nécessaire.

![](https://downloads.intercomcdn.eu/i/o/18610243/5008cec2957dd397b2cdfbaa/image.png?expires=1788634800&signature=335f39d0276481140207a4978d11dbfe904912caaf375aee9ab30aa9b9cfeacf&req=0d1pxFj4qDRk2hL085ZhobA%2FlNooaukEf9vLrvtcsII0iWSLgm0O5N9NKJqQ%0AnxPuI31CSFmywPnw%0A)

> 💡ASTUCE : Le bouton "Tout valider" permet de valider l'ensemble des pointages en une fois. 

### 4) Modifier un pointage

Pour modifier un pointage, cliquez simplement sur la carte de pointage de l’ouvrier concerné.

![](https://downloads.intercomcdn.eu/i/o/18610887/84b35affd838a4c6f0e162ae/image.png?expires=1788634800&signature=63f61f827b2f5c14fb8de9b2f9182b63d701ba2b526ee4edc7535e25c998b5c2&req=0d1pxFjypDBk2hL085ZhoTytZf%2BELRZ5cZjwy%2FXHpC4UQG6e3uSQOBU6coYJ%0AFrsZ15pNceo83bKC%0A)

**a) Indiquer un ouvrier comme absent :** Pour marquer un ouvrier comme absent, cliquez sur « Absent » en haut de l’écran. Sur l'écran suivant, vous pouvez cliquer sur la flèche afin de sélectionnez un motif ou ajouter un commentaire. Le commentaire est un complément d'information pour le gestionnaire ou la secrétaire qui devra clôturer le pointage. 

![](https://downloads.intercomcdn.eu/i/o/18610363/05d656179c9f369c13b54e14/image.png?expires=1788634800&signature=818c83dc3b7d6968e90f19f5457ffa209c1ea121275f7cb475798a32c06591cb&req=0d1pxFj5qjRk2hL085ZhoYiEi1YQpnnWT55%2BR2LI9bJIFN7bPuQ%2BLVOBzRMD%0A6OeFLywtQ3WsgPqQ%0A)


​

Les motifs d’absence sont définis par l’administrateur dans les paramètres sur ordinateur: Propriétés > Planning > Types d’absences.

**b) Ajouter une prestation ou modifier les heures :** Pour ajouter une prestation, cliquez sur « Ajouter un chantier / une intervention ». 

![](https://downloads.intercomcdn.eu/i/o/18610433/6fb39cc70fbefdb4eedf227b/image.png?expires=1788634800&signature=c5d0a6b9dcc39fdea582a526efeb85349b4b409b22e505123ca9322bc9926e3b&req=0d1pxFj%2BrzRk2hL085ZhofJcUiGZy6CRPLkr8WgFLom9wgNQtWhiwme8gSzI%0ARCYvypur6z9ELZ1a%0A)

Une liste s'affichera avec :

- Les chantiers et interventions planifiés pour l’utilisateur aujourd’hui.
- Les autres chantiers disponibles.
- Une entrée de type "AUTRE" pour des tâches non liées aux chantiers ou interventions, comme une visite au contrôle technique du véhicule.

Vous pouvez ensuite modifier les heures de début, de fin et les pauses en cliquant sur la flèche au niveau de chaque champ. Un commentaire peut également être ajouté pour apporter plus d'information au gestionnaire/secrétaire qui devra clôturer le pointage.

![](https://downloads.intercomcdn.eu/i/o/18610502/44f2ba515bb1fc012c14d1df/image.png?expires=1788634800&signature=22085a5cfa1b580c16724843a11cd99c7a3fa40f59f27588b86fad3283e2b6d3&req=0d1pxFj%2FrDVk2hL085ZhoQ8Rjcg71kU6xQiX2pZNl%2FfzsoQU7AL0w7xJx%2Ft2%0AQ3TuzZdAO1te58HD%0A)

Il est également possible de supprimer une prestation en cliquant sur la poubelle en haut à droite de la carte de cette prestation. 

> 💡ASTUCE : Le bouton "Action groupée" permet de modifier tous les ouvriers en une fois dans le cas où les ouvriers ont effectué les mêmes tâches sur la journée.

**c) Mobilité :** Si la fonctionnalité de mobilité est activée, vous pouvez saisir :

- Le nombre de kilomètres aller et retour.
- Si l’ouvrier était chauffeur, chauffeur avec passager ou passager.

![](https://downloads.intercomcdn.eu/i/o/18610617/77cb219ff4797be09548c61c/image.png?expires=1788634800&signature=a2cd75ab04aa16fe669dc6f6b01e37138942ac00e63d5153f53b828b2cf8701e&req=0d1pxFj8rTBk2hL085ZhoRMnvVyp3I1uUsGjaCKJJa9NPn1nPD1OuxcZzTIV%0AwunR7zHPrJhdKwjE%0A)

Ces informations sont importantes pour la paie en Belgique. Si cette fonctionnalité ne vous concerne pas, elle peut être désactivée par l’administrateur.

### 5) Modifier la liste des ouvriers

Par défaut, vous verrez les ouvriers planifiés sur les chantiers où vous êtes assigné. Vous pouvez modifier cette liste en cliquant sur « Modifier les ouvriers » sous les cartes de pointage.

Ajoutez un ouvrier en cliquant sur le "+" en haut à gauche et en le sélectionnant dans la liste. Pour retirer un ouvrier, cliquez sur la croix correspondante. Une fois les modifications effectuées, cliquez sur le bouton de confirmation en bas de l'écran.
