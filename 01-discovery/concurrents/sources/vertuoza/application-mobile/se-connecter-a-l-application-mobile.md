# Se connecter à l'application Mobile

Une fois l’application téléchargée, vous pouvez l’ouvrir pour vous connecter. 

Entrez le code de votre société ainsi que votre login et mot de passe habituel.

Le code de votre société est le numéro de votre société dans vertuoza. Vous pouvez le trouve rdans l'URL de la page de connexion sur votre navigateur web après le mot "tenant_id="
