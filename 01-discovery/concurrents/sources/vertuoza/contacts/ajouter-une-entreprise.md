# Ajouter une entreprise

### **Navigation dans l'écran contact/entreprise:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une zone de recherche.
2. Le tableau reprenant les informations.
3. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
4. Le bouton "Nouveau" pour créer un nouvel élément.
5. Le bouton Action permettant un import ou un export de la liste

### **Ajouter une entreprise**

1. Allez dans le menu et sélectionnez l’onglet “Contacts”
2. Vous voyez alors les deux onglets qui s’affichent : “Entreprises” et “Contacts”
3. Vous appuyez sur “+ Nouveau” pour créer une nouvelle entreprise.
4. Une fois dans la création de l’entreprise, vous pouvez compléter les différentes informations. Toute entreprise doit absolument être liée à un type de profil : Prospect, Client, Sous-traitant, Co-traitant, Fournisseur, Architecte, Propriétaire, Ex-client.
C’est important de bien encoder tout type de profil car ça va amener plus de fluidité dans l’utilisation de Vertuoza.
5. Dans la fiche entreprise vous pouvez également ajouter des informations qui seront directement reprises dans les devis et factures (conditions particulières, taux de TVA,…).
6. Une fois que vous avez complété toutes les informations, vous pouvez cliquer sur “Soumettre”
