# Importer des contacts

Il est possible d’importer vos contacts ou entreprises à partir d’un fichier Excel.

Pour cela, vous devez vous rendre dans l’onglet “Contacts” ou “Entreprises” et cliquer en haut à droite sur le bouton bleu “Actions” → “Import”

### **Navigation dans l'écran contact/entreprise:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une zone de recherche.
2. Le tableau reprenant les informations.
3. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
4. Le bouton "Nouveau" pour créer un nouvel élément.
5. Le bouton Action permettant un import ou un export de la liste

### **Template d’import**

La première chose à faire est de télécharger le template que vous pourrez obtenir en cliquant sur le bouton bleu “Template d’import”.

Attention à bien distinguer “Contacts” et “Entreprises” lorsque vous téléchargerez le document, il existe un template pour chacun que vous retrouverez dans chaque onglet.

Ouvrez votre dossier de téléchargements de votre ordinateur et cliquez sur le fichier Excel qui se nomme “contact_fr-FR” ou “entreprise_fr-FR” en fonction.

Vous découvrez alors les différentes colonnes qui font partie du fichier. Vous pourrez les compléter manuellement ou en faisant des copier/coller à partir de votre propre fichier clients. Les deux colonnes avec un astérisque doivent être obligatoirement complétées :

- Nom
- Profil

Pour les autres colonnes, c’est à vous de décider celles que vous voulez compléter ou non.

Attention : pour la colonne “Pays”, il faut bien écrire le nom en entier avec une majuscule à la première lettre. *Exemple : Belgique, France, Suisse*

Veillez à bien enregistrer les modifications apportées au document.

### **Import d’un contact à partir d’un fichier Excel**

Suivez les étapes suivantes pour importer votre fichier :

1. Lorsque le fichier est complété, vous pouvez retourner dans Vertuoza, appuyer sur l’onglet “Choisir un fichier” et rechercher le fichier Excel “contact_fr-FR” ou “entreprise_fr-FR” en fonction.
2. Indiquez le numéro de feuille Excel sur lequel les informations sont reprises (ce sera généralement sur la feuille 1).
3. Cliquez sur le bouton bleu “Importer” pour que l’import commence.
4. Les colonnes du fichier vont alors être vérifiées mais si vous avez bien utilisé notre template d’import, il n’y aura pas de souci. Il suffit donc de cliquer sur “Confirmer cette étape” pour passer à la dernière étape de l’import.
5. Vous vérifiez alors que toutes lignes sont correctes et vous pouvez cliquer sur “Confirmer et valider l’importation”
