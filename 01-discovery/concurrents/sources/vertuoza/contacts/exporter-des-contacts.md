# Exporter des contacts

Il est possible d’exporter vos contacts ou entreprises dans un fichier Excel.

Pour cela, vous devez vous rendre dans l’onglet “Contacts” ou “Entreprises” et cliquer en haut à droite sur le bouton bleu “Actions” → “Exporter la liste”

Cela vous permet alors d’avoir une liste avec tous vos clients si vous devez par exemple leur envoyer un mail.

Vous retrouverez le document dans votre dossier de téléchargements de votre ordinateur.

### **Navigation dans l'écran contact/entreprise:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une zone de recherche.
2. Le tableau reprenant les informations.
3. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
4. Le bouton "Nouveau" pour créer un nouvel élément.
5. Le bouton Action permettant un import ou un export de la liste
