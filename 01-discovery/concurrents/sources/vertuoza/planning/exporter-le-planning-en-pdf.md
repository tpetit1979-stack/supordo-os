# Exporter le planning en PDF

Vous avez la possibilité d’exporter l’ensemble du planning sur une ou deux semaines pour l’ensemble des chantiers ou uniquement pour ceux dont vous êtes responsable via le bouton d'exportation situé en haut à droite.

![](https://downloads.intercomcdn.eu/i/o/11013204/2f4f18decea9c92fd63f60a6/8.png?expires=1788620400&signature=f8f04a58acb1119b1fceb9f86b8f7ef9fb441e42826165e4d40e784058c15921&req=0dRvxFv4rDNk2hL085Zhof4gUVP51mYy3JV9S8Q3L5Z07pPT9b%2BcwA%2Bi3dtG%0AxC4FRVAnSxjAOTZj%0A)

Vous avez également la possibilité d’exporter le planning d’un chantier en particulier en cliquant sur l’icône PDF à côté du nom du chantier.

![](https://downloads.intercomcdn.eu/i/o/11013213/a01f182678f6325f493c7290/9.png?expires=1788620400&signature=4c0e8c26a014c3d5f69ff019793a8e25d22c07878456ff74dcc300a7fe412e0f&req=0dRvxFv4rTRk2hL085ZhocXk74aUdVXHNQdkxp44UwPCo0tllSzJnEH9E5J3%0AzBl4E%2B%2BcUWh8AV6z%0A)
