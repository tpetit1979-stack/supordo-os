# Planification des ressources dans le planning

### Planification journalière:

Pour planifier vos ressrouces de manière journalière, cliquez sur le bouton d’édition dans la section “Ressources” de votre planning. Ajoutez ensuite les ressources que vous souhaitez planifier pour ce jour. Vous pouvez éditer les heures de travail individuelles selon les besoins.

![](https://downloads.intercomcdn.eu/i/o/11009333/371fec6b7aa67187da148c82/3.png?expires=1788620400&signature=a9543a685d19f61401b3861b931dcf2dc21fc380dc4432bf9b5c5beeaf990d3f&req=0dRvxVH5rzRk2hL085ZhoWZjAJi16lKLj1BuZ93c2Cm4qud6xEuO%2F2cTaDPy%0AvJ15mwdOK9kiFL0h%0A)

### Planification par type de ressources: 

Cliquez sur le bouton “+” dans la case correspondant au jour et au type de ressource que vous souhaitez ajouter. Ajoutez ensuite les ressources que vous souhaitez planifier pour ce jour. Vous pouvez éditer les heures de travail individuelles selon les besoins.

![](https://downloads.intercomcdn.eu/i/o/11009379/34caf68f79138f1f359ad85c/4.png?expires=1788620400&signature=15820071641bb8dcd2b02fc67b4e8cfc58a76049634dc063a5a98d7a1fa1e734&req=0dRvxVH5qz5k2hL085ZhoaeGXbzJ%2FBm2bd5jP%2Fvipp4PIzTMWhN%2BeFAbCEzc%0AArMnb2dM7XeN9j%2BD%0A)

### Planification individuelle: 

Vous pouvez également éditer l’assignation de vos ouvriers et indépendants individuellement en appuyant directement sur la carte de la ressource que vous souhaitez modifier.

### Copier-coller les ressources:

Vous avez également la possibilité de copier-coller vos ressources, soit d’un jour à un autre, soit sur une période. Pour ce faire, cliquez sur le bouton “…” dans la case du type de ressource que vous souhaitez copier, puis sur “Copier les ressources”.

![](https://downloads.intercomcdn.eu/i/o/11009408/469c214383af96ab571941d5/5.png?expires=1788620400&signature=14ff11ccd19707b8e6d37ac0587cfd24fb50854c19aa6efa5c42d169586219f1&req=0dRvxVH%2BrD9k2hL085ZhoXiMAV5w6f%2BjmzyFV2RngOIUqn3ogJ0OrW8USQkD%0AUWYdsQMEi%2BSasesr%0A)

Ensuite effectuez la même démarche sur la case où vous souhaitez coller vos ressources, vous aurez alors deux options “Coller une fois” et “coller jusqu’à”.

![](https://downloads.intercomcdn.eu/i/o/11009768/04e27860772a82a011c1f707/6.png?expires=1788620400&signature=3294fe3384572f3b0d273b5c6804f149eb982f8c06a9119649739f0b4abb8a9e&req=0dRvxVH9qj9k2hL085ZhoReABsFHIIgB1oaEomNSUWMWpXtQj6YKSZRIJKDS%0ArNfRG2QgIB9rxy02%0A)

### Impact sur la Rentabilité

Lorsque vous affectez vos employés sur le planning, l’horaire défini dans leur fiche “ouvrier” est ajouté par défaut.

Dans le cas où vous avez défini un taux horaire dans la fiche de votre ouvrier, la rentabilité de votre chantier se met à jour en ajoutant le nombre d’heures prestées par votre ouvrier lors de son assignation sur le planning.

Si vous disposez du module de pointage, le nombre d’heures indiqué par l’ouvrier dans le pointage mettra à jour la rentabilité une fois que vous aurez validé les pointages de vos ouvriers.

### 💡 Bon à savoir:

Si un cadenas est affiché à côté du nom de votre ouvrier, cela signifie que son pointage a déjà été clôturé et que vous ne pouvez plus éditer son assignation.
