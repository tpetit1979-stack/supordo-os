# Comment retirer un chantier du planning?

Rendez-vous dans la gestion du chantier, dans la section “Informations Générales”, et cliquez sur l’icône “crayon” pour éditer le Chantier.

Ensuite, décochez l’option “Affichage sur le planning”.
