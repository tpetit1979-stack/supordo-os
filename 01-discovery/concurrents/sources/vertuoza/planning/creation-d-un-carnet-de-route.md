# Création d'un carnet de route

Lorsque vous établissez un carnet de route pour une journée sur un chantier, les ouvriers assignés à ce chantier auront accès aux informations que vous avez saisies via leur planning personnel.

### Editer le carnet de route d'une journée

Pour accéder à l'édition du carnet de route, cliquez sur le bouton d’édition suivant:

![](https://downloads.intercomcdn.eu/i/o/11011123/2ab96417ceb711c6527dd1d4/image.png?expires=1788620400&signature=1e2d4a4b7d99e9b720a8966f3e9c0931b4de0fde7edf61bf69ebaa5442ae8134&req=0dRvxFn7rjRk2hL085ZhoZDu72IqbztNMt0iEcTHA1F9TaOw2WcxE6pp8WLk%0AOeuuHTsd0ifyhG41%0A)

Dans ce carnet de route, vous pouvez :

- Ajouter des [tâches de chantier](https://intercom-help.eu/vertuoza/fr/articles/133043-taches-de-chantier). Les tâches de chantier vous permettent de répertorier les tâches que vous effectuez de manière récurrente sur vos chantiers afin de vérifier la qualité de chaque tâche grâce à une check-list. Vous pouvez les définir dans **Paramètres > Propriétés > Chantier > Tâches de chantier**.
- Écrire un commentaire pour les tâches générales.
- Écrire un commentaire pour chaque ressource planifiée ce jour-là.
- Écrire un commentaire pour la préparation de l’atelier.

Vous pourrez ensuite visualiser les tâches et les pièces jointes sur le planning.
