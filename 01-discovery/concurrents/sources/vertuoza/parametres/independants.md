# Indépendants

La création d'indépendant sur Vertuoza vous offre la possibilité de regrouper les informations générales de chaque indépendant travaillant dans votre société (coordonnées, horaire de travail, etc).

### Ajouter un ouvrier

1. Rendez-vous la page **Paramètres > Général > Personnel > Indépendants.**
2. Cliquez sur “**Nouveau**”.
3. Compléter les informations relatives à ce nouveau indépendant.
4. Assurez-vous d’enregistrer les modifications apportées en cliquant sur **”Enregistrer”** en bas de la page.
