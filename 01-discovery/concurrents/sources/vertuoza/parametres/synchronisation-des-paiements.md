# Synchronisation des paiements

La synchronisation des paiement vous permet d’automatiser l’actualisation des statuts de vos factures. Une fois un paiement effectué sur votre compte bancaire, il vous suffit de lancer la synchronisation pour que le statut soit actualisé et passé en “Payé”.

### **Paramétrer la synchronisation:**

Rendez-vous dans les **paramètres** > **Avancé** > **Sync. paiement**

Vous avez alors le choix entre **Ponto** ou **Codabox:**

### **Ponto:**

1. Choix du logiciel > Ponto
2. Cliquer sur lier mon compte
3. Vous arrivez sur une autre plateforme
4. Suivez les différentes étapes affichées.
5. Choisir votre banque
![](https://downloads.intercomcdn.eu/i/o/10015527/77d5a7c10dd96c3b6f6d9de3/Untitled+%2810%29.png?expires=1788620400&signature=b9dbba5aea0af1f6fc52f3c0edf30e89005c7f24b7dc47f31566aac515e35ef1&req=0dVvxF3%2FrjBk2hL085ZhoaAlEuwx6r0OxC8bDhiYuNOpIyuz255isnznJe2p%0AEQ%3D%3D%0A)
6. Cliquez sur suivant et finalisez le paramétrage

### **Codabox (exclusivement belge)**

1. Choix du logiciel > Codabox
2. Indiquez votre adresse e-mail
3. Indiquez votre numéro de TVA
4. Indiquer votre Token (Si vous n’avez pas encore de TOKEN, vous pouvez cliquer sur le bouton “demander un Token)
5. Cliquer sur “Sauvegarder les changements” pour finaliser le paramétrage

### **Lancer la synchronisation:**

La synchronisation se lance directement via **Finance** > **Fact. clients**

1. Cliquez sur les … à gauche du bouton “ + Nouveau”
2. Cliquez ensuite sur Synchroniser les paiements:
![](https://downloads.intercomcdn.eu/i/o/10015538/41b1bcf087acd3e7466ef2f5/Untitled+%2811%29.png?expires=1788620400&signature=7b11e6377f00757c63bb56a5df6f8018247c7f4ab69d8c3d904582c4b75e04f2&req=0dVvxF3%2Frz9k2hL085ZhoZvCq0bjNDi5%2Bg2hlQh9jCzPHEMe1DXXtjQCtXbo%0AeQ%3D%3D%0A)
3. Choisissez la période à synchroniser en y mettant une date de début et une date de fin.
4. La synchronisation se lance et vous informe que vous serez averti lorsque celle-ci sera terminée
5. Il se peut que certains paiements ne soient pas validés dû à un manque d’informations. Pour faire le rapprochement dans Vertuoza, il vous sera alors demandé de réconcilier les paiement manuellement via ce bouton:
![](https://downloads.intercomcdn.eu/i/o/10015573/4167b2200be06dc2ace7b544/Untitled+%2812%29.png?expires=1788620400&signature=9654d517272fc5f599e97d9a672ef1d885ca9685c1db34129e2102ebfbf59fda&req=0dVvxF3%2FqzRk2hL085ZhoUy73J%2FjlEua19pLsmm1At3sFCmQvMkMteJ5Yfja%0Aew%3D%3D%0A)
6. Une liste sera alors proposée et vous pourrez sélectionner la facture à lier au paiement affiché.
