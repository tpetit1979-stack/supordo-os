# Employés

La création d'employés sur Vertuoza vous offre la possibilité de regrouper les informations générales de chaque employé travaillant dans votre société (coordonnées, gestion des accès). Vous pouvez ensuite leur attribuer un compte de gestion dans la section "Utilisateurs".

### Ajouter un employé

1. Rendez-vous la page **Paramètres > Général > Personnel > Employés.**
2. Cliquez sur “**Nouveau**”.
3. Compléter les informations relatives à ce nouveau employé.
4. Assurez-vous d’enregistrer les modifications apportées en cliquant sur **”Enregistrer”** en bas de la page.
