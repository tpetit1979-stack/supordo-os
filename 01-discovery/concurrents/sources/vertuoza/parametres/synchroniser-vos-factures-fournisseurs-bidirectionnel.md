# Synchroniser vos factures fournisseurs (bidirectionnel)

Si vous n'avez pas encore fait le paramètrage, [rendez-vous ici](https://intercom-help.eu/vertuoza/fr/articles/522539-guide-de-configuration-de-la-synchronisation-comptable) 


Vous pouvez choisir le sens de synchronisation le plus adapté à votre situation :

Envoi : Vertuoza → Logiciel comptable
**Quand l'utiliser** : Vous ajoutez vos factures d'achat directement dans Vertuoza.

**Avantage** : Vous pouvez activer la réception des **factures électroniques** dans Vertuoza gratuitement et simplement. Vos factures d'achat arrivent automatiquement dans votre comptabilité.

➡️ Consultez l'article [Synchroniser vos factures clients vers votre logiciel comptable](https://intercom-help.eu/vertuoza/fr/articles/522564-envoyer-les-factures-vers-le-logiciel-comptable) pour la procédure d'envoi (le fonctionnement est identique).

Réception : Logiciel comptable → Vertuoza
**Quand l'utiliser** : Vos factures d'achat sont déjà dans votre logiciel comptable et vous voulez les avoir dans Vertuoza pour analyser la rentabilité de vos chantiers.

**Avantage** : Vous centralisez toutes les données dans Vertuoza pour un suivi précis des coûts par chantier.



Étape 1 : Accéder à l'import
1. Allez dans la liste des **Factures fournisseurs**
2. À côté du bouton "Nouveau", cliquez sur le bouton avec **3 points**
3. Sélectionnez **"Importer depuis la comptabilité"**
Étape 2 : Définir la période
Une fenêtre s'ouvre vous permettant de saisir une période de dates. Indiquez la plage de dates des factures que vous souhaitez importer.

Étape 3 : Lancer l'import
Validez l'import. Le processus démarre automatiquement et vous recevrez une notification dès que l'opération est terminée.

Résultat de l'import
La notification finale vous indiquera :
- Le nombre de factures correctement synchronisées
- Le nombre de factures en erreur
Si vous avez des erreurs, consultez les détails dans l'historique des factures concernées.

➡️ Pour comprendre et résoudre les erreurs, consultez notre article [Comprendre et résoudre les erreurs de synchronisation](https://intercom-help.eu/vertuoza/fr/articles/148196-resoudre-les-erreurs-de-synchronisation).



La réception des factures fournisseurs depuis le logiciel comptable n'est pas disponible sur tous les logiciels. Consultez l'article [Vue d'ensemble de la synchronisation comptable](https://intercom-help.eu/vertuoza/fr/articles/522531-synchronisation-comptable-vue-d-ensemble#) pour vérifier la compatibilité de votre logiciel.
