# Testo

### 1. **Que permet l'intégration Testo ?**

Vous utilisez l'outil Testo pour vos entretiens ? L'intégration avec Vertuoza vous permet désormais d'importer directement les rapports d'entretien générés par Testo dans vos rapports d'intervention créés sur l'application mobile Vertuoza.

### 

### **2. Paramétrage**

Pour configurer l'intégration Testo, suivez ces étapes indispensables :

1. Allez dans vos **paramètres**.
2. Accédez à la section **Avancé** > **Intégration**.
3. Identifiez le logiciel **Testo** et cliquez sur **Se connecter**.
4. Ajoutez la **clé API** obtenue depuis Testo. Cette clé se trouve dans l'application web Testo, dans le menu **Administratif** > **Clé de sécurité**. Il s'agit d'une longue suite de caractères.
5. Cliquez sur **Enregistrer**.

Une fois le paramètrage réalisé, le bouton d'import **Testo** sera disponible dans l'application mobile Vertuoza.

### 3. **Ajouter un rapport Testo dans vos rapports d'intervention**

Voici la procédure à suivre pour importer un rapport Testo dans un rapport d'intervention sur Vertuoza :

1. **Réalisez votre entretien** dans l'outil Testo pour générer un rapport d'entretien.
2. **Créez votre rapport d'intervention** à l'aide de l'application mobile Vertuoza.

Ensuite, pour ajouter votre rapport d'entretien Testo :

1. Cliquez sur **"Certificats d'entretien"** pour accéder à la liste des certificats.
2. Cliquez sur le **"+"** en haut à gauche de cette liste.
3. Cliquez sur **"Téléchargement de Testo"**. Si cette option n'est pas affichée, cela signifie que le paramétrage n'a pas été effectué correctement. Reportez-vous à l'étape 1 pour configurer l'intégration.
4. La liste affichera tous les certificats créés pour la journée. Si le certificat a été créé à une autre date, vous pouvez cliquer sur le calendrier pour modifier la date.
5. Recherchez le certificat via le **nom du client** et **l'installation**.
6. Cliquez sur **Sélectionner**.

Le **PDF du certificat** sera alors joint au rapport d'intervention de Vertuoza.
