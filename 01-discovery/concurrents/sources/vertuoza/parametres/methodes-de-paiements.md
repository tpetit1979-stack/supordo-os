# Méthodes de paiements

Vous allez pouvoir déterminer les différentes façon dont vous voulez être payé.

## **Navigation dans l'écran des méthodes de paiements:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une zone de recherche.
2. Le tableau reprenant les informations.
3. Les boutons d'actions à l'extrême droite du tableau.
4. Le bouton "Nouveau" pour créer un nouvel élément.

## Ajouter **une méthode de paiement:**

1. Rendez-vous la page **Paramètres > Propriété > Général > Méthodes de paiement.**
2. Cliquez sur “**Nouveau**”.
3. Compléter les informations relatives à cette nouvelle méthode de paiement: le nom de la méthode de paiement.
4. Assurez-vous d’enregistrer les modifications apportées en cliquant sur **”Enregistrer”** en bas de la page.
