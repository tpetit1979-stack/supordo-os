# Modèle d’email par défaut

## **Le modèle d'email par défaut.**

Le modèle d'email par défaut est celui que vous retrouverez en premier lorsque vous souhaitez envoyer un email.

### **Comment définir un modèle d’email par défaut ?**

1. Assurez-vous d'avoir créé un email par défaut **Paramétrage > Modèles > Email** .
2. Dans l'édition d'un modèle d'email, vous avez un bouton qui permet d'activer l'email par défaut.
3. Cliquez sur "**Enregistrer**" pour que ce changement soit actif.

### **Puis-je modifier un modèle d'email avant l'envoi ?**

Oui, il est possible de modifier le texte d'un email par défaut sur la page d'envoi.

### **Puis-je avoir plusieurs modèles d'email par défaut ?**

Non, il est possible d'avoir qu’un seul modèle d'email par type de document (Devis, facture, etc.). Cependant, il est possible de choisir parmi les autres modèles d'email via le menu déroulant sur la page d'envoi d'email.
