# Comment modifier le mot de passe d’un utilisateur?

Pour changer le mot de passe d'un utilisateur :

- Rendez-vous dans la liste de vos utilisateurs (gestion ou chantier).
- Trouvez l'utilisateur pour lequel vous souhaitez changer le mot de passe.
- Cliquez sur l'icône d'édition.
- Une fois la fiche de l'utilisateur ouverte, entrez l’ancien mot de passe ainsi que le nouveau.
- N'oubliez pas de cliquer sur "Enregistrer" avant de quitter.

**Astuce** : *si vous ne connaissez plus l’ancien mot de passe, vous pouvez supprimer le compte « chantier » ou « gestion » et le recréer avec le mot de passe souhaité. Aucune information ne sera perdue car les données sont liées à l’ouvrier/l’employé et non au compte « chantier » ou « gestion ».*
