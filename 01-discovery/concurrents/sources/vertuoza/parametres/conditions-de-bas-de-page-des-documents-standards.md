# Conditions de bas de page des documents standards

Les conditions de bas de page apparaitront automatiquement dans les modèles de documents standards.

**Exemple 1:**

- Type de document : Devis
- Description : “Si vous souhaitez accepter cette offre, merci de nous la renvoyer signée pour accord”.

**Exemple 2 :**

- Commande de matériaux
- Description : “Toutes les fiches techniques seront remises avant l'exécution du travail.”

### **Navigation et création des conditions des bas de pages :**

- Une zone de recherche.
- Le tableau reprenant vos conditions de bas de pages créés.
- Les boutons d’actions à droite (passer dessus avec votre curseur afin de retrouver leurs signification).
- Cliquer sur “**+ Nouveau”**.
- Sélectionner un type de complément: document (Ex: devis, facturations etc.)
- Ajouter une description.
- “**Enregistrer**”.
- Vous allez pouvoir sélectionner cette condition de bas de page dans les modèles de documents standards.
