# Les taux de TVA

En fonction du pays dans lequel vous travaillez et résidez, vous allez pouvoir créer plusieurs taux de TVA dans Vertuoza.

## **Navigation dans l'écran des taux de TVA:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une zone de recherche.
2. Le tableau reprenant les informations.
3. Les boutons d'actions à l'extrême droite du tableau.
4. Le bouton "Nouveau" pour créer un nouvel élément.

## Ajouter **un taux de TVA:**

1. Rendez-vous la page **Paramètres > Propriété > Général > Taux de TVA.**
2. Cliquez sur “**Nouveau**”.
3. Compléter les informations relatives à ce nouveau taux de TVA: le taux TVA (en %), un libellé, un code TVA (pour le logiciel comptable) et une description.
4. Assurez-vous d’enregistrer les modifications apportées en cliquant sur **”Enregistrer”** en bas de la page.
