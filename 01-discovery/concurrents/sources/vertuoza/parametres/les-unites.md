# Les unités

Les unités sont utilisées dans tous les formulaires de Vertuoza, tels que les devis, les factures, les commandes, etc. Vous avez la possibilité d'en créer plusieurs pour personnaliser au maximum selon vos besoins.

## **Navigation dans l'écran des unités:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une zone de recherche.
2. Le tableau reprenant les informations.
3. Les boutons d'actions à l'extrême droite du tableau.
4. Le bouton "Nouveau" pour créer un nouvel élément.

## **Ajouter une unité:**

1. Rendez-vous la page **Paramètres > Propriété > Général > Unités.**
2. Cliquez sur “**Nouveau**”.
3. Compléter les informations relatives à cette nouvelle unité: le nom de l’unité.
4. Assurez-vous d’enregistrer les modifications apportées en cliquant sur **”Enregistrer”** en bas de la page.
