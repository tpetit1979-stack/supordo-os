# Comment utiliser les variables dans vos modèles ?

Les variables vous permettent d'insérer automatiquement des informations dynamiques dans vos modèles, comme le nom du client, l'adresse, le numéro de devis ou toute autre donnée disponible. Ces éléments peuvent être placés n’importe où dans vos modèles en fonction de vos besoins.

### **Qu’est-ce qu’une variable ?**

Une variable est un champ dynamique qui est automatiquement remplacé par une donnée spécifique lorsque le document est généré. Par exemple :

- La variable [client.nom] sera remplacée par le nom du client : *"Jean Dupont"*.
- La variable [devis.no] affichera le numéro du devis : *"2025-001"*.

Cela vous permet de créer des modèles personnalisés et flexibles sans avoir à entrer manuellement les informations pour chaque document.

___________________________________________________________

### **Comment insérer une variable dans un modèle ?**

### **1. Accéder à l’éditeur de modèle :**

- Ouvrez un modèle existant ou créez-en un nouveau dans **Paramètres > Documents > Devis**.

### **2. Insérer une variable :**

- Cliquez sur le bouton **+ Variables** dans la barre d’outils.
- Une liste de catégories s’affiche (ex. : Société, Client, Devis, Chantier).
- Parcourez les catégories ou utilisez la barre de recherche pour trouver la variable souhaitée.
- Cliquez sur une variable pour l’insérer directement dans la zone sélectionnée.

___________________________________________________________

### **Types de variables disponibles :**

1. **Société :**
- Informations sur votre entreprise (nom, adresse, TVA, IBAN, etc.).
2. **Client :**
- Nom, adresse, contact principal, email, etc.
3. **Client de facturation :**
- Coordonnées spécifiques au client destinataire des factures.
4. **Devis :**
- Numéro de devis, date, échéance, responsable.
5. **Chantier :**
- Adresse et détails spécifiques liés au chantier concerné.
