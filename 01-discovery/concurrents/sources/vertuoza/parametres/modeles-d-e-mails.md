# Modèles d’e-mails

Définissez les modèles d'e-mails que vous utilisez le plus souvent pour éviter de réécrire vos e-mails à chaque envoi.

### **Comment définir un modèle d’email ?**

1. Assurez-vous d'avoir créé un email par défaut dans **Paramétrage > Modèles > Email**.
2. Cliquez sur “**nouveau**” pour créer un nouveau modèle d’email.
3. Choisissez le type d'email qui détermine à quel document correspond ce mail. Si vous choisissez “Devis”, le modèle d'email sera proposé lors de l'envoi du devis.
4. Encodez la référence qui est le nom que vous donnez à ce mail afin de le retrouver facilement dans le menu déroulant. Exemple: “ Devis chantier privée”. Le client ne verra pas cette référence, elle est utile uniquement aux utilisateurs Vertuoza
5. Définissez l'objectif du mail qui apparaîtra en tant qu'objet du mail pour le client. L'objet du mail est similaire à un titre que l'on trouve en premier dans une boîte de réception d'email.
6. Saisissez votre email dans le champ description.
7. Cliquez sur "**Enregistrer**".

### **Puis-je modifier un modèle d'email avant l'envoi ?**

Oui, il est possible de modifier le texte d'un email par défaut sur la page d'envoi.
