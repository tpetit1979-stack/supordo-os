# Configuration des nouvelles pages listes

**1. Quelles pages ont été modifiées avec les nouvelles listes ?** 

Les pages de contacts et d'entreprises ont été modifiées. L'objectif est de mettre à jour toutes les listes progressivement. Nous vous informerons dès que d'autres pages seront mises à jour avec les nouvelles fonctionnalités.

**2. Quelles sont les nouvelles fonctionnalités disponibles sur les pages de listes ?** 

Avec les nouvelles listes, vous pouvez :

- Modifier les colonnes affichées
- Modifier l'ordre des colonnes
- Modifier la largeur des colonnes ou auto-ajuster celle-ci
- Épingler des colonnes à gauche ou à droite
- Modifier l'ordre des éléments affichés
- Modifier le nombre d'éléments affichés

**3. Comment puis-je modifier les colonnes affichées ?** 

Vous pouvez personnaliser les colonnes en cliquant sur les trois petits points qui apparaissent lorsque vous mettez votre souris sur le nom d'une colonne, puis cohez/décocher des colonnes dans l'onglet de droite.

**4. Comment changer l'ordre des colonnes ?** 

Pour changer l'ordre des colonnes, cliquez et faites glisser l'en-tête de la colonne à la position souhaitée.

**5. Comment modifier la largeur des colonnes ?** 

Vous pouvez ajuster la largeur des colonnes en faisant glisser le bord de l'en-tête de colonne. Pour auto-ajuster la taille des colonnes, cliquez sur les trois petits points qui apparaissent lorsque vous mettez votre souris sur le nom d'une colonne, puis sélectionnez "Auto-ajuster toutes les colonnes".
​
​**6. Comment modifier l'ordre des éléments affichés ?** 

Vous pouvez modifier l'ordre des éléments affichés en cliquant sur le nom de la colonne. Vous verrez alors une flèche vers le haut ou vers le bas en fonction du tri ascendant/descendant.

**7. Comment épingler des colonnes ?** 

Pour épingler une colonne, cliquez sur les trois petits points qui apparaissent lorsque vous mettez votre souris sur le nom d'une colonne et sélectionnez l'option "Épingler à gauche" ou "Épingler à droite".

**8. Puis-je changer le nombre d'éléments affichés dans la liste ?** 

Oui, vous pouvez modifier le nombre d'éléments affichés en utilisant le sélecteur de nombre d'éléments situé en bas de la liste. Cette information est maintenant **sauvée **même si vous quittez la page.

![](https://downloads.intercomcdn.eu/i/o/17050119/a767caec650c04840791a8ef/image.png?expires=1788620400&signature=44ccad13678f4c2de445645b9ae819c9ccf14028b4572f489ab0afdb647f27a1&req=0dJvwFj7rT5k2hL085ZhocWmNPyDmrCPIPiziUbxmK6lH0XyhB8dxAKalE2o%0AahfEmo5OdWVzyl%2BV%0A)

**9. Quelles sont les améliorations du filtre ?** 

Le filtre a été remplacé pour une utilisation plus facile. Vous pouvez maintenant sélectionner plusieurs éléments dans plusieurs filtres simultanément.

![](https://downloads.intercomcdn.eu/i/o/17050138/f076d8ee60b0220112f59d2c/image.png?expires=1788620400&signature=442ee19ce484b060d347811e607c0480f4df3236ee5455f2633c358c84b8d6ac&req=0dJvwFj7rz9k2hL085ZhoRDn80RoGw3cN5XUgTh8lOe820NgEx7bIl%2BYMfz%2B%0AxhEh70mJdVVD0kYL%0A)

**10. Est-ce que mes paramètres seront sauvegardés si je quitte la page ?** 

Oui, si vous quittez la page et que vous revenez, les filtres, la configuration des colonnes et le nombre d'éléments affichés seront toujours sauvegardés.

Si vous quittez la page en effectuant une action de la liste (par exemple, l'édition d'un élément), votre recherche sera sauvegardée et vous reviendrez à la page où vous étiez.

**11. Puis-je revenir à la configuration d'origine des colonnes ?** 

Oui, vous pouvez revenir à la configuration d'origine en cliquant sur les trois petits points qui apparaissent lorsque vous mettez votre souris sur le nom d'une colonne, puis en sélectionnant "Réinitialiser les colonnes".
