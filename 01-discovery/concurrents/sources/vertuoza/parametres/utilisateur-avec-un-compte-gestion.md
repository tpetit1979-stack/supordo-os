# Utilisateur avec un compte gestion

Un utilisateur avec un compte gestion a un **accès complet** à tous les modules de l'application. Ce compte convient pour les employés de bureau: administrateur gestionnaire et secrétaire.

### **Ajouter un utilisateur avec compte gestion**

1. Assurez-vous d'avoir créé un membre du personnel de type "employé" dans **Paramètres > Général > Personnel > Employé**.
2. Vérifiez le nombre de comptes gestion encore disponibles dans votre abonnement. Cette information est disponible dans l'en-tête de votre liste d'utilisateurs - compte gestion. (Si vous avez atteint le nombre limite, contactez le service client pour modifier votre abonnement.)
3. Cliquez sur "Nouveau" pour ajouter un nouvel utilisateur.
4. Sélectionnez l'employé auquel vous souhaitez donner accès à l'application.
5. Choisissez un login et un mot de passe. Veillez à ne pas perdre ce mot de passe et communiquez-le à votre employé.

### **Permission et accès d’un compte gestion**

Vous pouvez configurer les accès pour votre utilisateur avec un compte gestion dans la fiche de votre employé.

### **Accès à la gestion de chantier**

Pour donner l’accès à votre utilisateur avec un compte gestion à la gestion de chantier suivez les étapes suivantes:

- Accédez à **Paramètres > Général > Personnel > Employés > Fiche de l’employé** et activez l’option "Gestionnaire de chantier".
- Si vous souhaitez que cet utilisateur ait un accès à tous les chantiers, activez l’option "Vue sur tous les chantiers".
