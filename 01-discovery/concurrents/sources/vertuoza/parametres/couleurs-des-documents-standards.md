# Couleurs des documents standards

Choisissez les 2 couleurs qui apparaîtront dans les modèles des documents standards.

Vous pouvez sélectionner la couleur ou insérer directement le code couleur.

Les codes couleurs, également connus sous le nom de codes hexadécimaux, sont des codes alphanumériques utilisés pour définir spécifiquement une couleur sur un site web.

Chaque couleur est représentée par une combinaison de six caractères alphanumériques, par exemple, "#FF0000" pour le rouge. Ces codes sont utilisés dans le balisage HTML et le CSS pour définir la couleur de texte, de fond, de bordure, etc. sur une page web.

### **Navigation et sélection des couleurs des documents standards :**

- Sélection de la couleurs des titres (PDF)
- Sélection de la couleurs des sous-titres (PDF)
- “**Enregistrer”**.
