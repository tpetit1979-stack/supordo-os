# Ouvriers

La création d'ouvriers sur Vertuoza vous offre la possibilité de regrouper les informations générales de chaque ouvrier travaillant dans votre société (coordonnées, horaire de travail, etc). Vous pouvez ensuite leur attribuer un compte de chantier dans la section "Utilisateurs".

### Ajouter un ouvrier

1. Rendez-vous la page **Paramètres > Général > Personnel > Ouvriers.**
2. Cliquez sur “**Nouveau**”.
3. Compléter les informations relatives à ce nouveau ouvrier.
4. Assurez-vous d’enregistrer les modifications apportées en cliquant sur **”Enregistrer”** en bas de la page.
