# Commande de stock

Rendez-vous dans l’onglet **Stock > Commandes.**

### **Navigation dans l'écran des commandes de stock:**

Depuis cet écran, vous avez une vue sur toutes les commandes de stock. Vous pouvez:

Filtrer vos recherches par fournitures, fournisseurs, responsables, dates et statuts.

Les statuts donnent plus d’informations sur la progression d’une commande :

- Brouillon (nouvelle commande en cours)
- Réassort automatique (si vous aviez activé ce champ dans vos composants)
- A envoyer (brouillon soumis - prêt à être envoyé chez le fournisseur)
- En confirmation (chez le fournisseur)
- En livraison (confirmation reçue)
- Réservé
- Livré / partiellement livré
- Annulé

💡 Lorsque vous passez une commande de réapprovisionnement de stock, Vertuoza dispatche la commande entre les fournisseurs des fournitures. C’est-à-dire que vous pouvez commander vos matériaux provenant de différents fournisseurs dans la même commande, et Vertuoza se charge de créer différents bons de commande pour chaque fournisseur !

### **Comment réaliser une commande de stock ?**

Pour passer une nouvelle commande, cliquez sur le bouton “+ Nouveau” :

- Sélectionnez un responsable
- Choisissez une adresse de livraison (parmi vos emplacements de stock de Niveau 1)
- Encodez la commande
- Vous sélectionnez une fourniture et sa quantité à commander
- Vous pouvez ajouter une remarque (à la ligne)
*Comme déjà précisé, même s’il y a différents fournisseurs, Vertuoza dispatchera les postes selon les fournisseurs par après*
- Vous avez sur le stock actuel :
- “Réel” : quantité réellement en stock à l’instant T
- “Théorique” : reprend le stock réel + les différentes commandes en cours qui n’ont pas encore été livrées
- “Min et Max” : pour aider à commander les bonnes quantités
- En dessous de l’encodage, vous retrouvez les détails du franco
⇒ Intéressant : si vous approchez les 80/90% du franco à atteindre, vous pouvez augmenter un peu la quantité à commander pour ne pas subir les frais de livraison !

### **Et ensuite ?**

⇒ Lorsque la commande est au statut “en confirmation” :

- Vous pouvez indiquer une date de livraison donnée par le fournisseur
- Vous pouvez encore modifier (remplacer si alternative / modifier la quantité) ou supprimer une fourniture (si plus de stock chez le fournisseur,…)
- Vous pouvez modifier le prix unitaire si par exemple il y a une hausse de prix
- Vous pouvez modifier des frais de livraison

⇒ Une fois confirmée, la commande passe au statut “en livraison”

⇒ Pour réceptionner une marchandise, cliquez sur le petit bouton d’action “camion”

- Vous pouvez joindre le bon de livraison
- Indiquez la quantité reçue (commande livrée complètement ou partiellement)
- S’il s’agit d’une livraison partielle, vous pouvez indiquer une prochaine date de livraison
- Si pas d’emplacement de stock pour la fourniture, n’oubliez pas de l’indiquer
- Si vous n’avez pas réceptionné l’entièreté d’une commande lorsque vous soumettez, vous avez le choix :
- De clôturer la commande si le reste n’arrivera pas (→ Statut livré)
- D’attendre le reste de la commande pour la clôturer (→ Statut partiellement livré)
