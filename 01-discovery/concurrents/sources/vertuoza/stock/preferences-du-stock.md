# Préférences du stock

Dans l’onglet **Paramètres > Propriétés > Stock > Préférences**, vous pouvez déterminer :

- Le nombre de niveaux d’emplacements pour votre stock
- Le nom de chaque niveau :
- Niveau 1 : pour l’emplacement géographique de votre stock (ex: Entrepôt)
- Niveau 2 : pour la localisation dans cet emplacement géographique (ex: Allée)
- Niveau 3 : pour l’emplacement exact où se trouve la fourniture (ex: Box)
- Si vous souhaitez recevoir un bon de commande automatique lorsqu’une fourniture atteint sa quantité minimale dans votre stock

💡 Depuis l’onglet **Bibliothèque > Composants**, vous pouvez définir les composants qui se trouvent dans votre stock.

⇒ Lorsque vous créez ou éditez un composant, vous pouvez activer la fonction permettant qu’une fourniture soit gérée dans votre stock :

- Si vous activez cette fonction, vous devez choisir un emplacement de stock pour votre composant, ainsi qu’une quantité minimum et maximum.
- L’encodage d’emplacement de stock sera expliqué par après;
- L’encodage d’une quantité min et max permettra à Vertuoza de vous proposer des bon de commande automatique pour la fourniture une fois la quantité minimum atteinte.
