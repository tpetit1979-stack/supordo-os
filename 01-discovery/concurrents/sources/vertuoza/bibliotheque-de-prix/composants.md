# Composants

Les composants vont êtres les éléments qui vont constituer les ouvrages. Ils sont en quelque sorte les ingrédients nécessaires pour que l’ouvrage (recette de cuisine) soit complet.

Exemple: *”Bloc de 19”, “Main d’œuvre”,…*

### **Navigation dans l'écran des ouvrages:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza :

1. Des onglets permettent de passer des ouvrages aux composants.
2. Différents filtres peuvent être appliqués sur le tableau de données.
3. Une zone de recherche.
4. Le tableau reprenant les informations.
5. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
6. Le bouton "Nouveau" pour créer un nouvel élément.
7. Le bouton 3 points

### **Création de composants:**

Les composants seront principalement caractérisés dans Vertuoza par plusieurs éléments importants : la catégorie, la référence, la description, le fournisseur, l'unité, le prix d'achat, la marge, et enfin le prix de vente.

### **Ajouter un nouveau composant**

1. Assurez-vous d'avoir créé les catégories nécessaires si vous souhaitez catégoriser tous vos composants de manière plus précise.
2. Cliquez sur "**Nouveau**" pour ajouter un nouveau composant.
3. Déterminez le type de composant que vous voulez créer : fourniture, équipement, main d’œuvre, sous-traitant.
4. Ajoutez une référence obligatoire (c’est une référence unique).
5. Ajoutez une description, celle-ci sera visible par le client dans les différents documents.
6. Ajoutez une catégorie si nécessaire (optionnel).
7. Attribuez un fournisseur (comment créer un fournisseur : LIEN).
8. Définissez une unité pour ce composant (comment créer une unité via ce lien:……..).
9. Sélectionnez un compte général auquel le composant se rapporte.
10. Définissez un prix d’achat et une marge pour calculer le prix de vente.
11. Ajoutez une photo si vous le souhaitez.
12. Définissez si la fourniture sera gérée en stock ou non via le bouton à cocher.

### **Importer des composants**

Si vous commencez avec Vertuoza et que vous disposez d'une bibliothèque d'ouvrages existante, vous pouvez importer une liste de composants :

1. Cliquez sur les **3 points** dans le coin supérieur droit de l'écran.
2. Cliquez sur "**Importer**".
3. Sélectionnez le type de composant que vous voulez importer.
4. Un fichier modèle d'import est disponible via le bouton "**Template d'import"**.
5. Une fois le fichier complété, vous pouvez l'ajouter via le bouton "**Choisir un fichier**".
6. Vous pouvez également importer des photos si nécessaire.
7. Définissez le numéro de la feuille dans laquelle se trouvent les informations dans le fichier Excel.
8. Cliquez sur "**Importer**".
9. Assurez-vous de faire correspondre les colonnes du fichier Excel avec celles de Vertuoza.

### **Exporter la liste de fournitures**

1. Cliquez sur les **3 points** dans le coin supérieur droit de l'écran.
2. Cliquez sur "**Exporter la liste**".
3. Un fichier Excel sera téléchargé avec les données.
