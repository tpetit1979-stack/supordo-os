# Ouvrages

Les ouvrages sont les éléments que vous allez afficher dans vos devis, dans vos factures et autres documents. Chez Vertuoza, nous appelons ça **“la recette de cuisine”.

Exemple d’ouvrage en gros œuvre: *”Fourniture et pose de blocs de 19”*

Les ingrédients pour cette recette sont les composants : [LIEN](https://intercom-help.eu/vertuoza/fr/articles/132328-composants) vers les composants

### **Navigation dans l'écran des ouvrages:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Des onglets permettent de passer des ouvrages aux composants.
2. Un filtre peut être appliqué sur les catégories.
3. Une zone de recherche.
4. Le tableau reprenant les informations.
5. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
6. Le bouton "Nouveau" pour créer un nouvel élément.
1. Le bouton "**Action(s)**".

### **Création d'ouvrages:**

Les ouvrages sont principalement caractérisés dans Vertuoza par plusieurs éléments importants : la catégorie, la description, l'unité, le prix d'achat, la marge, et enfin le prix de vente.

### **Ajouter un nouvel ouvrage**

1. Assurez-vous d'avoir créé les catégories nécessaires si vous souhaitez catégoriser tous vos ouvrages de manière plus précise.
2. Cliquez sur "**Nouveau**" pour ajouter un nouvel ouvrage.
3. Ajoutez une description de l'ouvrage (cette description sera visible sur les différents documents).
4. Ajoutez une catégorie si nécessaire (optionnel).
5. Définissez une unité pour cet ouvrage (consultez comment créer une unité via ce lien :……..).
6. Définissez un prix de vente si vous ne paramétrez pas cela en fonction du prix d'achat et de la marge.
7. Définissez un prix d'achat et une marge pour calculer le prix de vente si vous avez coché "OUI" sur "Prix d’achat et marge".
8. Activez ou non l'utilisation des composants dans l'ouvrage (LIEN vers la gestion des composants).
9. Ajoutez une photo si vous le souhaitez.

### **Importer les ouvrages simples**

Si vous commencez avec Vertuoza et que vous disposez d'une bibliothèque d'ouvrages existante, vous pouvez importer une liste d'ouvrages simples :

1. Cliquez sur les 3 points dans le coin supérieur droit de l'écran.
2. Cliquez sur "Importer les ouvrages simples".
3. Un fichier modèle d'import est disponible via le bouton "Template d'import".
4. Une fois le fichier complété, vous pouvez l'ajouter via le bouton "Choisir un fichier".
5. Vous pouvez également importer des photos si nécessaire.
6. Définissez le numéro de la feuille dans laquelle se trouvent les informations dans le fichier Excel.
7. Cliquez sur "Importer".
8. Assurez-vous de faire correspondre les colonnes du fichier Excel avec celles de Vertuoza.

### **Exporter les ouvrages simples**

1. Cliquez sur les 3 points dans le coin supérieur droit de l'écran.
2. Cliquez sur "Exporter les ouvrages simples".
3. Un fichier Excel sera téléchargé avec tous les ouvrages simples.

### **Bibliothèque de prix achetée**

Si vous avez souscrit à la bibliothèque Vertuoza dans votre abonnement, il est possible qu'une bibliothèque complète soit importée en quelques clics.

1. Cliquez sur les 3 points dans le coin supérieur droit de l'écran.
2. Cliquez sur "**Bibliothèque de prix**".
3. Définissez quels sont les modules qui doivent être importés.
4. Par module, définissez quelle marge doit être appliquée sur les prix d'achat.
5. Cliquez sur "**Importer les chapitres**".
