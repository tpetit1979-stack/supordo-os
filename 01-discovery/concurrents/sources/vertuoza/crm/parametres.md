# Paramètres

### 🔧 Comment créer un **statut** pour une opportunité ?

1. Va dans **Paramètres > Opportunités > Statuts**.
2. Clique sur **Ajouter un statut**.
3. Donne :
1. un **nom**,
2. une **probabilité de gain** (en %),
3. un **état** à ce statut (en cours, accepté, refusé) et
4. un **ordre** (l’ordre correspond à l’ordre dans lequel les statuts vont s’afficher dans les opportunités)
4. Enregistre !

### 🔐 Qui peut accéder aux opportunités ?

Tous les utilisateurs ayant accès au module **Devis** peuvent voir les opportunités.

Les accès sont gérables via **Paramètres > Utilisateurs > Rôles**.
