# Créez vos opportunités automatiquement via votre formulaire de contact

### **Comment créer automatiquement une opportunité via un email ?**

Si vous recevez un email avec les informations d'un prospect, vous pouvez nous le transférer pour que l'opportunité soit automatiquement créée dans votre système. L'email doit contenir au minimum l'adresse email du contact. Si le contact existe déjà, il sera lié à l'opportunité en fonction de l'email.

### **Quelles informations doivent être présentes dans l'email ?**

L'email que vous transférez peut contenir les informations suivantes :

1. **Information sur le contact** :
- Nom et prénom
- Email (obligatoire)
- Téléphone
- Adresse
- Numéro de TVA
2. **Information sur le projet** :
- Budget
- Remarque

> **Note :** Toutes les informations de l'email seront ajoutées dans le champ **remarque** de l'opportunité afin de ne rien perdre.

### **Quelles informations sont obligatoires ?**

L'**email du prospect** est obligatoire. Sans cette information, l'opportunité ne pourra pas être liée correctement. Si aucun email n'est dans la demande, veuillez en ajouter un avant de nous transférer l'email.

### **Où trouver l'email à qui envoyer les informations ?**

Pour trouver l'email nécessaire pour envoyer ces informations, suivez ces étapes:

1. Cliquez sur "Opportunité" dans le menu.
2. Cliquez sur les 3 petits points en haut à droite.
3. Sélectionnez l'option **Importer par email**.

Cela vous fournira l'adresse email à laquelle envoyer les informations du prospect. L'email est spécifique à votre société.
