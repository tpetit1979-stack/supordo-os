# Informations générales du devis

Les informations générales sont la première étape dans la création d’un devis. Elles consistent en les informations sur le client, les différents intervenants, les conditions de facturations, le cadre du chantier.

Tous les champs ne sont pas affichés par défaut dans Vertuoza, vous pouvez aller les activer dans **Paramètres > Général > Préférences d’affichage** (Ex: le champ Architecte)

Cela va vous permettre de personnaliser les options qui seront disponible lorsque vous créerez un devis par exemple.

Vous y retrouvez trois catégories distinctes:

- Affichage des champs dans le formulaire
- Affichage des champs dans l’encodage des lignes
- Affichages des décimales

### **Appliquer une modification d’affichage**

Cochez le bouton en fonction de ce que vous désirez voir affiché ou pas.
