# Sources

## **Sources commerciales :**

Une source commerciale, également appelée source de clientèle ou source de prospects, fait référence à l'origine d'où proviennent les clients ou les prospects d'une entreprise. C'est le canal ou le moyen par lequel une entreprise attire l'attention de nouveaux clients ou génère des prospects potentiels. Comprendre les différentes sources commerciales permet aux entreprises d'optimiser leurs stratégies marketing et de concentrer leurs efforts là où elles sont les plus efficaces.

Les sources commerciales que vous allez paramétrer et donc ajouter pourront être liées par la suite aux opportunités associées à vos devis. Elles seront également incluses dans les statistiques, ce qui vous permettra d’analyser les différentes sources utilisées.

### **Navigation Sources commerciales :**

- Le tableau reprenant les informations.
- Zone de recherche.
- Éditer ou supprimer le libellé d’une source commerciale en utilisant les boutons d’actions à droite.
- Ajouter une source en cliquant sur + Nouveau.

### **Créer une Source commerciale :**

1. Aller dans **propriétés - Opportunité**
2. Cliquer sur le “**+ Nouveau**”
3. Insérer un libellé.
4. “**Enregistrer**”
5. Votre libellé est ajouté au tableau.

### **Devis - Comment utiliser vos sources commerciales :**

Une fois que vous avez ajouté vos sources, vous pourrez les lier aux opportunités de vos devis en passant par l'onglet **Opportunités.**
