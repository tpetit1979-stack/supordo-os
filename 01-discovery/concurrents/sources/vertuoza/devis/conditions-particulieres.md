# Conditions particulières

Les conditions particulières correspondent aux différentes tranches de paiement que vous appliquez selon vos clients ou types de chantier. Elles sont enregistrés en amont dans vos paramètres et peuvent ensuite être ajoutées au devis. Les conditions particulières peuvent également être liés aux contacts/entreprises afin qu’elles s’ajoutent automatiquement dans le devis.

### **Navigation dans l'écran devis:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une zone de recherche.
2. Le tableau reprenant les informations.
3. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
4. Le bouton "Nouveau" pour créer un nouvel élément.

### **Créer des conditions particulières**

Pour créer vos conditions particulières, rendez-vous dans Paramètres > Propriétés > Devis et avenants > Cond. particulières.

Cliquez sur Nouveau pour ajouter une nouvelle condition particulière. Vous devez lui donner un nom et une description qui s’affichera dans le devis. Par exemple :

Nom : **Paiement en 4 tranches**

Description :

**Nos paiements suivent le schéma suivant:**

*20% à la signature*

*30% en début de chantier*

*50% dès le chantier terminé*

Ou bien

Nom : **Photovoltaique**

Description :

**Conditions de paiement PV:**

Acompte 30%

Validation de la commande

Paiement 2e tranche

Paiement 3e tranche

### **Utiliser ses conditions particulières dans ses devis et avenants**

Une fois les conditions particulières crées, elles peuvent s’insérer à plusieurs niveaux.

- Dans un nouveau devis ou avenant, elles se retrouvent dans les Informations générales. Il vous suffit de sélectionner le nom de la condition souhaitée pour que la description s’affiche. Elle est encore modifiable.
- Lors de la création d’un *contact ou d’une entreprise (link)*, vous pouvez choisir de lui lier une condition particulière. Lorsque vous sélectionnerez ce contact comme client dans un devis, la condition liée sera automatiquement reprise.

### **Mes conditions particulières existent dans mon devis mais ne s’affichent pas sur le pdf, que faire ?**

Vérifier que l’affichage des conditions particulières est bien actif dans le template choisi.

- Récupérer le nom du template de pdf (Ex : Mise en page perso détaillées)
- Aller dans Paramètres > Modèles d’email > Documents > Devis
- Cliquer sur le crayon en bout de ligne du template en question pour rentrer dans l’édition (Voir *Créer une mise en page personnalisée (link)*)

- Assurez vous que la variable "Condition particulière" a bien été ajouté dans votre modèle de devis  :
