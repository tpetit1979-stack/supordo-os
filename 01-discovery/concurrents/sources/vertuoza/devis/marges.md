# Marges

### **Gérer ses marges dans Vertuoza**

Une bonne gestion de ses marges est la clé d’entreprise prospère. Bien renseigner ses marges dans Vertuoza permet d’avoir une vision précise de la rentabilité d’un chantier. Chaque ligne d’un devis, qu’il s’agisse d’un poste libre ou d’un composant ou ouvrage issu de la *bibliothèque de prix (link)* peut-être calculé en fonction du prix d’achat et de la marge souhaitée.

### **Ajuster la marge d’un poste libre**

Lors de la création d’un poste libre, vous pouvez saisir par défaut le prix unitaire et la quantité pour avoir le prix total. Mais il est également possible de faire le calcul à partir du prix d’achat et de la marge souhaitée :

- Créer le poste libre
- Cliquer sur les 3 petits points des options en bout de ligne
- Choisir “Editer le détail du poste libre”
- Cocher “Prix d’achat et marge”
- Renseigner le prix d’achat total HTVA et la marge souhaitée pour obtenir le prix de vente

**Astuce** : vous pouvez également construire un poste libre à partir de composants de la bibliothèque (à partir du Pack EXPERT) pour calculer le prix exacte d’un ouvrage (fourniture + main d’oeuvre). L’ouvrage ainsi créé pourra être enregistré dans la *Bibliothèque de prix (link)* pour être réutilisé dans d’autres devis.

### 

### **Ajuster la marge d’un composant**

Lors de la création d’un composant, la saisie du prix d’achat est obligatoire. Ces éléments sont donc par défaut construits sous la forme Prix d’achat HTVA + marge = Prix de vente HTVA. Vous pouvez adapter la marge d’un composant pour un devis en particulier sans impacter le composant dans la bibliothèque :

- Ajouter une ligne dans le devis et choisir le composant souhaité (Ex : Fourniture > Bloc béton 14)
- Cliquer sur les 3 petits points des options en bout de ligne
- Choisir “Editer la fourniture” (ou la main d’oeuvre, l’équipement…)
- Modifier la marge
- Enregistrer

### **Ajuster la marge d’un ouvrage simple**

Il n’est pas possible de modifier un ouvrage simple qui a uniquement un prix de vente directement depuis le devis. Il est nécessaire de repasser par la *bibliothèque de prix (link)* pour activer l’option **Prix d’achat et marge**.

Si l’ouvrage est déjà construit sous la forme Prix d’achat et marge, il est possible de modifier la marge directement depuis le devis :

- Ajouter une ligne dans le devis et choisir l’ouvrage souhaité
- Cliquer sur les 3 petits points des options en bout de ligne
- Choisir “Editer l’ouvrage”
- Modifier la marge
- Enregistrer

### **Ajuster la marge d’un ouvrage composé (à partir du Pack EXPERT)**

Un ouvrage composé est construit à partir de composants de la bibliothèque qui mis ensemble, permettent un calcul au plus juste d’un tarif (Voir *bibliothèque de prix (link)*)

**Ex :**

⇒ Composant bloc porte 1: 150€

⇒ Composant huisserie 1: 23€

⇒ Composant poignée 1: 20€

⇒ Composant main d’oeuvre 1,5h : 60€

⇒ Composant finition peinture satinée 300cl : 15€

Fourniture et pose d’une porte simple : 268€

Il est possible d’ajuster la marge de chaque composant de l’ouvrage directement depuis le devis, mais pas la marge globale.

- Ajouter une ligne dans le devis et choisir l’ouvrage souhaité
- Cliquer sur les 3 petits points des options en bout de ligne
- Choisir “Editer l’ouvrage”
- Modifier la marge des composants
- Enregistrer

### **Majorer les prix de vente ou le rendement pour augmenter sa marge**

Vertuoza permet également de majorer globalement tous les prix d’un devis, ou uniquement les composants main d’oeuvre.

### **Dans quels cas majorer les prix de vente ?**

Dans le cas où vous reprenez un devis après plusieurs mois et que les prix d’achats des fournitures ont augmentée, ou si les travaux doivent se faire plus rapidement ou à une période plus tendue, vous pouvez être amené à vouloir globalement majorer les prix du devis.

### **Comment majorer les prix ou le rendement ?**

- En cliquant sur "**Encodage**"
- Pour ensuite cliquer en bas à droite sur le total
- Vous permettant de cliquer sur "**+ Ajouter un ajustement"**
- Vous pouvez ensuite choisir entre "**Majoration des prix de vente**" ou bien "**Majoration du rendement**"

Cette majoration n’est pas visible dans le document final, au contraire des *remises (link)*

### **Le tableau de résumé des marges (à partir du Pack EXPERT)**

A partir du Pack Expert, un tableau de résumé des marges par type de ligne (Fourniture, Main d’oeuvre, Sous-traitance, Equipement, Poste libre) est disponible. Si tous les éléments ont bien été construits sous le format prix d’achat + marge, ce tableau donne un aperçu détaillée de la rentabilité estimée du futur chantier.
