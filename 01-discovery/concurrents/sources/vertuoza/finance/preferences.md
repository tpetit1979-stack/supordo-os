# Préférences

### **Préférences:**

Gérez les préférences et propriétés liées à vos factures.

### **Paramétrage des préférences:**

1. Définissez le type de facturation : annuelle ou mensuelle.
2. Activer les paiements par QR code
3. Définissez si les factures et les notes de crédit/avoirs partagent une numérotation continue.
4. Pour la Belgique uniquement : cochez si vous désirez utiliser les communications structurées.
5. Permettre ou non la suppression de factures.
6. Cliquez sur le bouton "Enregistrer".
