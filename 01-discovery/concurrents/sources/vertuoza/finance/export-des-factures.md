# Export des factures

### **Export de factures PDF/UBL:**

Il est fréquent qu'à plusieurs moments de l'année, vous vouliez exporter toutes les factures se trouvant dans Vertuoza, que ce soit pour vous ou même pour votre comptable.

### **Navigation dans l'écran des ouvrages:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une zone de recherche.
2. Le tableau reprenant les informations.
3. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
4. Le bouton "Nouveau" pour créer un nouvel élément.

### **Création d’un export de factures:**

**Créer un nouvel export**

1. Cliquez sur "Nouveau" pour créer un nouvel export de facture.
2. Ajoutez une référence pour différencier cet export d’un autre.
3. Définissez la période de cet export "de…. à …."
4. Cochez "Oui" si vous voulez exporter les factures clients.
5. Cochez "Oui" si vous voulez exporter les factures fournisseurs.
6. Cochez "Oui" si vous voulez exporter toutes les factures, y compris celles qui ont déjà été exportées pour cette période.
7. Définissez le format de fichier voulu : PDF ou UBL (format de facture électronique).
8. Cliquez sur "Enregistrer".
9. De retour dans le tableau, cliquez sur le bouton d’action "Fichier ZIP".
