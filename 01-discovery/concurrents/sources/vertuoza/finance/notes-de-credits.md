# Notes de crédits

Les notes de crédit/avoirs sont des documents établis dans le but d’annuler le montant d’une facture émise afin que cela soit rééquilibré.

### **Navigation dans l'écran des notes de crédit:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une période peut être déterminée en rentrant des dates.
2. Un filtre peut être appliqué sur le client.
3. Une zone de recherche.
4. Le tableau reprenant les informations.
5. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
6. Le bouton "Nouveau" pour créer un nouvel élément.

### **Création d’une nouvelle note de crédit:**

**Ajouter une note de crédit depuis le menu notes de crédit**

1. Cliquez sur "Nouveau" pour ajouter une nouvelle note de crédit.
2. Complétez les informations générales en rapport avec le client, le chantier et les conditions.
3. Complétez les coordonnées de facturation (qui seront visibles sur le NC).
4. Encodez les éléments à créditer.
5. Faites attention au fait que tout doit être complété et que les montants soient négatifs.
6. Cliquez sur “Enregistrer”.

**Ajouter une note de crédit depuis une facture existante**

1. Cliquez sur "…" au niveau des boutons d’actions de la facture.
2. Cliquez sur “Créditer la facture”.
3. Dans le pop-up affiché, déterminez le montant à créditer sur cette facture.
4. Cliquez sur “Confirmer”.
5. Certaines informations peuvent déjà être complétées (complétez les informations restantes si nécessaires).
6. Vérifiez que les informations et les montants crédités soient corrects.
7. Cliquez sur "Enregistrer".
8. Vous êtes redirigé dans l’écran des Notes de crédit. Il ne vous reste plus qu’à cliquer sur le “V” > “Comptabiliser”.
