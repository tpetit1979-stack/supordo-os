# Utiliser l’IA pour importer ses factures fournisseurs [BETA]

**Envoyez vos factures par mail**

Via les “…” visibles au-dessus de la liste, vous pouvez retrouver facilement vos adresses emails personnelles auxquelles envoyer vos factures fournisseurs:

Pour chaque type de facture fournisseur, vous disposez d’une adresse mail. Envoyez simplement vos factures à l’adresse correspondant, et notre IA la créera automatiquement.


![](https://downloads.intercomcdn.eu/i/o/yr18hzl2/76381059/2b41895ead839aafc68b5f3eb9e2/b28b2683-4ce3-4c80-86ff-8170f4cc991f?expires=1788620400&signature=1ddecee10e2fe1b3a33e3ae225a36fc66f7eb2af19942c8b69e28ec600d28baa&req=19NszVn6qT5k2hL085ZhoenlyPqUphRi1Er3qAkVIcoKP%2FtoKcTPbDdgcnQH%0AhizBxLLWy%2BPVVmA8%0A)

**Importez vos factures depuis Vertuoza**

Cliquez sur le bouton nouveau et choisissez le type de facture fournisseur que vous souhaitez importer.

Choisissez et/ou faites glisser vos fichiers dans la modale d’import et confirmez afin que notre IA crée et analyse vos factures. Cette opération peut prendre quelques minutes, vous pouvez continuer à utiliser Vertuoza en attendant. Vos factures apparaîtront ensuite dans la liste.

![](https://downloads.intercomcdn.eu/i/o/yr18hzl2/42739762/0bb6c508411802cfd6fdf1a860ff/Capture+d%E2%80%99e%CC%81cran+2025-03-21+a%CC%80+16_25_34.png?expires=1788620400&signature=b639473eda9516c00deb1c30b3565dab7efc0b33435abb9c1ee4d12493ff058e&req=1NdoxlH9qjVk2hL085ZhockIjO%2FI4Rixd3jmW0Q%2BbSkF%2Bl4ZCtYgU%2BvXuPvA%0Av8amkG9pNZMPa1kJ%0A)

**Scannez vos factures depuis l’application mobile Vertuoza**

Consultez notre page concernant l’import de factures fournisseurs depuis l’app mobile (+ lien)

Peu importe la façon dont vous importez vos factures fournisseurs (mail/web/app), notre IA scannera votre document et pré-remplira automatiquement les champs qu’elle détecte:

1. Fournisseur
2. Date
3. Taux de TVA
4. Montant
5. Référence
