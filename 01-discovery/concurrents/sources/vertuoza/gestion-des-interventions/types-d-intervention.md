# Types d’intervention

Chaque intervention que vous allez planifier dans Vertuoza sera associée à un type d'intervention. 
Cette classification permet de préétablir la durée moyenne, les montants et d'autres frais associés à chaque type d'intervention. 
Une bonne configuration de vos types d'intervention vous donnera une gestion et planification plus efficace de vos interventions.


### **Navigation dans l’écran "Types d’intervention":**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une zone de recherche.
2. Le tableau reprenant les informations.
3. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
4. Le bouton "Nouveau" pour créer un nouvel élément.

### **Comment ajouter un type d'intervention ?**

Pour ajouter un nouveau type d'intervention, cliquez simplement sur le bouton “**Nouveau**” à droite de l’écran. Indiquez ensuite les informations suivantes :

1. **Nom de l'intervention**: Indiquez un nom descriptif pour le type d'intervention, reflétant clairement la nature de la tâche ou de l'activité.
2. **Durée moyenne**: Définissez la durée moyenne estimée pour l'achèvement de cette intervention. Cette information est cruciale pour la planification de vos interventions.
3. **Nombre d'ouvriers requis**: Spécifiez le nombre d'ouvriers nécessaires pour réaliser ce type d’intervention.
4. **Forfait ou en régie**: Choisissez si l'intervention sera facturée en forfait (coût fixe) et/ou en régie (coût basé sur les heures travaillées). Cette distinction impacte la gestion financière de l’intervention.
5. **Frais généraux**: Encodez les frais généraux associés à ce type d'intervention. Ces frais incluent les coûts systématiquement liés au type d’intervention que vous êtes en train de créer. Le responsable d’intervention retrouvera cette liste dans son rapport et pourra encore ajouter d’autres frais manuellement si nécessaire.

Après avoir rempli toutes les informations ci-dessus, cliquez sur “**Enregistrer**” pour sauvegarder le type d’intervention que vous venez de créer. Celui-ci apparaîtra à présent dans le tableau reprenant tous vos types d’intervention déjà créés.
