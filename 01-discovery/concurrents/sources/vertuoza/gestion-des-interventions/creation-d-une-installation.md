# Création d’une installation

### **Installations**

L’installation correspond à la machine (ex: chaudière) ou à l’endroit (ex: jardin) sur lequel vous allez effectuer votre intervention. Il est indispensable que les installations de vos clients soient créées dans Vertuoza si vous souhaitez ajouter des interventions dans votre planning. Vertuoza vous permet de créer et répertorier celles-ci très rapidement. De plus, la fiche d’installation représente une aide précieuse pour vos ouvriers lorsqu'ils interviennent chez le client. Ils pourront y retrouver toutes les informations essentielles de l’installation (type, adresse, photos, etc.) ainsi que tout l’historique des interventions déjà réalisées sur l’installation.


### **Navigation dans l'écran Installations:**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Un ensemble de filtres qui peuvent être appliqués sur le tableau de données
2. Une zone de recherche.
3. Le tableau reprenant les informations.
4. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
5. Le bouton "Nouveau" pour créer un nouvel élément.

### **Créer une installation**

Pour ajouter une installation, cliquez simplement sur le bouton “**Nouveau**” à la droite de l’écran. Vous pouvez alors créer une nouvelle installation ou créer une installation à partir de l’un de vos chantiers. Entrez ensuite les informations suivantes :

1. **Informations:**
- **Client**: Associez l'installation au client correspondant.
- **Nom de l'installation**: Donnez un nom descriptif à l'installation pour une identification aisée.
- **Type d'installation**: Précisez le type d'installation à partir de la liste que vous aurez créé au préalable.
- **Remarques**: Ajoutez des remarques spécifiques liées à l'installation qui pourront donner des compléments d’informations à vos ouvriers.
- **Adresse**: Indiquez l'adresse précise de l'installation. Celle-ci sera reprise automatiquement lorsque vous planifierez une intervention sur l’installation.
- **Lien externe**: Comme sur les chantiers, vous pouvez intégrer un lien externe si vous souhaitez stocker des informations complémentaires sur Dropbox ou iCloud par exemple.
2. **Attestation TVA**:
- Sélectionnez quel type d’attestation vous souhaitez lier à l’installation et télécharger ensuite votre document au format .pdf, .png ou .jpeg.
3. **Photos de l'installation**:
- Vous pouvez également téléchargez des photos de l'installation pour fournir une visualisation claire de l'état actuel de l’installation.
4. **Fichiers complémentaires**:
- Attachez tout fichier supplémentaire pertinent, tels que des plans, manuels, ou documents techniques.
