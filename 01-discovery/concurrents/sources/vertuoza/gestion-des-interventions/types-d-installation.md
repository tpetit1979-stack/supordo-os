# Types d’installation

Chaque intervention que vous allez créer sera liée à une installation. Lorsque vous ajoutez ou modifier les installations de vos clients, vous pouvez ranger celles-ci par type d’installation.


### **Navigation dans l’écran "Types d’installation":**

Le fonctionnement général et la navigation sont similaires aux autres écrans de Vertuoza:

1. Une zone de recherche.
2. Le tableau reprenant les informations.
3. Les boutons d'actions à l'extrême droite du tableau (placez votre curseur sur chaque bouton pour en connaître la signification).
4. Le bouton "Nouveau" pour créer un nouvel élément.

### **Pour ajouter un type d’installation :**

1. Accédez à la section "**Types d’installations**" dans les paramètres de vos interventions.
2. Cliquez sur "**Nouveau**"
3. Entrez le nom du type d’installation.
4. Cliquez sur **“Enregistrer”** pour l'ajouter à la liste de vos types d’installation.
