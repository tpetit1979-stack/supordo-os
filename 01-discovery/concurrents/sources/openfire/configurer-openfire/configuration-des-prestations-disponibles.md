# Configuration des prestations disponibles

Vous avez la possibilité de définir les types de prestation que vous proposez à la réservation en ligne. Cet article vous guide pour configurer les modèles d'intervention en adéquation avec ce que vous souhaitez proposer à vos clients sur votre page de réservation en ligne.

Cet article contient les sections suivantes :

- [Définir les prestations disponibles à la prise de rendez-vous en ligne](#h_01K6ZA4Y5H81YKGJ6414300RNS)
- [Paramétrer des rendez-vous à adresse fixe](#h_01K6ZAEGFRF2W0HGP04RA9BY5B)

# Définir les prestations disponibles à la prise de rendez-vous en ligne

Pour définir les prestations que vous souhaitez rendre disponibles à la prise de rendez-vous en ligne, le paramétrage s’effectue dans les modèles d’intervention. Ce sont les prestations que vos clients pourront sélectionner en ligne :

![](https://support.openfire.fr/hc/article_attachments/22802043322908)

Chemin d’accès :

- **Pour les plans basiques** : OpenFire > Configuration > Modèles d’intervention
- **Pour les autres plans** : Interventions > Configuration > Modèles d’intervention

Pour activer le modèle d’intervention à la prise de rendez-vous en ligne, il faut que le smart button **Web** soit activé (en vert).

![](https://support.openfire.fr/hc/article_attachments/22819921492892)

Vous avez aussi la possibilité de changer le libellé de la prestation dans "**Libellé site web"** ce qui modifiera ce qui s’affiche en ligne.

![](https://support.openfire.fr/hc/article_attachments/22819921494300)

| 💡**Note **: Si vous souhaitez tester la prise de rendez-vous en ligne, pensez à vous déconnecter ou à vous mettre en navigation privée. |
| --- |

# Paramétrer des rendez-vous à adresse fixe

Il est possible de paramétrer certains modèles d’intervention pour des typologies de rendez-vous à adresse fixe. Par exemple, dans le cadre d’un rendez-vous pour découvrir un poêle, le rendez-vous se fera en magasin.

Chemin d’accès :

- **Pour les plans basiques **: OpenFire > Configuration > Modèles d’intervention
- **Pour les autres plans **: Interventions > Configuration > Modèles d’intervention

Dans l’onglet **Prise de rendez-vous en ligne** du modèle d’intervention, cochez "**RDV fixe"** et sélectionnez l’adresse associée pour ce type de rendez-vous.

![](https://support.openfire.fr/hc/article_attachments/22819921497372)

  **📓**Pour aller plus loin → Modèles d'intervention (à venir).
