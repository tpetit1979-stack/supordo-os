# Techniciens et horaires

La configuration des employés et de leurs horaires vous permet de paramétrer la prise de rendez-vous en ligne en adéquation avec ce que vous souhaitez proposer à vos clients.

Cet article contient les sections suivantes :

- [Configurer les horaires de réservation en ligne](#h_01K6Z3BF84CD8A7VVH5E9MN6E1)
- [Configurer l'adresse de départ de l'adresse de retour](#h_01K6Z4J9BXWM9VSA1CA1PV6D8G)

# Configurer les horaires de réservation en ligne

Pour définir les horaires de prise de rendez-vous en ligne, vous devez définir les horaires web de l’employé ou des employés.

Chemin d’accès :

- **Pour les plans basiques** : OpenFire > Configuration > Employés
- **Pour les autres plans** : Interventions > Configuration > Employés

Cliquez sur l’employé pour renseigner les horaires dans l’onglet Informations professionnelles > Horaire.

Si les horaires de prise de rendez-vous en ligne sont les mêmes que les horaires classiques de l’employé, vous pouvez uniquement renseigner le champ** Horaire** et laisser le champ **Horaire Web** vide.

*Exemple : l’employé travaille de 8h à 12h puis de 13h à 17h et ce sont également ces créneaux que vous voulez proposer à la prise de rendez-vous en ligne : *

![](https://support.openfire.fr/hc/article_attachments/22798872346012)

Si les horaires de prise de rendez-vous en ligne ne sont pas les mêmes que les horaires de travail de l’employé, vous pouvez sélectionner un temps de travail différent dans le champ **Horaire** et le champ **Horaire web**.

*Exemple : l’employé travaille de 8h à 12h puis de 13h à 17h mais vous souhaitez proposer la prise de rendez-vous en ligne uniquement sur la matinée :*

![](https://support.openfire.fr/hc/article_attachments/22798847087260)

Vous pouvez créer et configurer plusieurs temps de travail.

# Configurer l'adresse de départ et l'adresse de retour

Pour avoir une visibilité réelle des temps de trajet du technicien, il est possible de configurer son adresse de départ et son adresse de retour directement dans l’employé.

Chemin d’accès :

- **Pour les plans basiques** : OpenFire > Configuration > Employés
- **Pour les autres plans** : Interventions > Configuration > Employés

Vous pouvez cliquer sur l’employé pour pouvoir renseigner son adresse de départ et son adresse de retour dans l’onglet Informations privées > Déplacement.

Si vous laissez ces deux champs vides, l’adresse de la société est reprise par défaut pour le calcul des temps de trajet.

![](https://support.openfire.fr/hc/article_attachments/22799025125532)

Si vous souhaitez définir une adresse de départ et une adresse de retour différentes de celle de la société, vous pouvez sélectionner le contact associé dans votre base contacts, par exemple si le technicien part de chez lui le matin et rentre directement chez lui le soir.

![](https://support.openfire.fr/hc/article_attachments/22799033543964)

# Configurer l'aptitude aux tâches de techniciens

Il est possible d’indiquer quelle(s) tâche(s) un employé peut ou ne peut pas réaliser.

Chemin d’accès :

- **Pour les plans basiques** : OpenFire > Configuration > Employés
- **Pour les autres plans** : Interventions > Configuration > Employés

Pour définir sur quel type de prestation le technicien pourra intervenir, cliquez sur son employé, et dans l’onglet Interventions > Tâches, vous pourrez sélectionner les tâches.

Si le technicien réalise toutes les prestations, il est possible de cocher "Apte à réaliser toutes les tâches".

![](https://support.openfire.fr/hc/article_attachments/22799247996316)

Si le technicien ne réalise que certains types d’interventions, vous pourrez les sélectionner.

Dans cet exemple, le technicien ne réalise que du ramonage de poêle à bois.![](https://support.openfire.fr/hc/article_attachments/22799247999004)

Ceci vous permettra, en fonction de la prestation demandée par le client lors de la réservation en ligne, de positionner le rendez-vous avec un technicien qui a les compétences ou le matériel pour la réaliser.
