# Configurer les jours fériés

![All_tick_V2.png](https://support.openfire.fr/hc/article_attachments/20233280438684)

OpenFire vous permet d'accéder à la gestion des jours fériés configurés dans votre entreprise. Vous pouvez ainsi définir quels jours sont chômés.

# Créer un jour férié

Pour accéder aux jours fériés dans OpenFire, rendez-vous dans :

- **Pour tous les plans :** OpenFire > Congés > Configuration > Jours fériés

Cliquez sur le bouton **Créer** pour créer un nouveau jour férié chômé dans votre entreprise et remplissez les champs suivants :

**Nom : **nom du jour férié ;

**Date de début : **date de début du jour férié ;

**Date de fin : **date de fin du jour férié.

Puis enregistrez.

🧑‍🏫Exemple : le jour du 1er mai est obligatoirement chômé en France (sauf exceptions légales).

Dans la colonne Nom, renseignez Fête du Travail.
Dans la colonne Date de début et Date de fin, renseignez 01/05/2025, de 00h à 23h59 par exemple.

# Application des jours fériés

## Sur le planning

Lorsqu'un jour est déclaré férié, le planning en vue Jour et Semaine est grisé sur les jours en question, et lors de la planification d'une intervention via la recherche de créneau, ce jour n'est pas proposé.

💡Note : il est toujours possible pour un utilisateur de placer des rendez-vous d'intervention sur les jours grisés, manuellement.

## Sur la prise de rendez-vous en ligne

Lorsqu’un jour est déclaré férié, les créneaux disponibles de ce jour sont supprimés pour les interventions classiques et web.

Étant donné qu’il n’y a pas de créneaux disponibles ces jours, la recherche de créneaux (intervention et web pour la prise de rendez-vous en ligne) de cette journée n’apparaît pas.

💡Note : si un jour férié est supprimé, alors les créneaux disponibles sont recréés.
