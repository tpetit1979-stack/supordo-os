# Evènement ou Intervention ?

Dois-je créer un **Événement **où une **Intervention **sur mon planning ? Cet article vous aide à distinguer les deux types de rendez-vous disponibles dans votre outil afin de choisir le format le plus adapté à votre activité quotidienne

# L’Événement : pour vos rendez-vous classiques

L'**Événement** est conçu pour une gestion simple et rapide de votre emploi du temps, avec une ergonomie épurée proche de celle d'un agenda classique comme Google Calendar.

Il est idéal pour :

- Les rendez-vous commerciaux ou en magasin.
- Les réunions d'équipe ou rituels d'entreprise.
- Vos rendez-vous personnels ou tâches administratives.

Caractéristiques principales

- **Focus sur l'essentiel** : participants, lieu, horaires et confidentialité.
- **Rapidité** : une saisie simplifiée pour bloquer un créneau en quelques secondes.

  💡**Note :** Utilisez l'Événement pour tout ce qui ne nécessite pas de rapport technique
  ou de facturation immédiate sur place.

# L’Intervention : pour vos prestations techniques

L'**Intervention** est un rendez-vous structuré, spécifiquement dédié aux métiers de l'intervention (maintenance, SAV, chauffage, CVC, photovoltaïque, ramonage). Elle permet de suivre précisément une mission chez un client, de la préparation à la facturation.

Elle est indispensable pour :

- Les visites techniques et poses de matériel.
- Les entretiens annuels et le SAV.
- Les dépannages urgents.

### Ce que permet l'Intervention :

- **Suivi de protocole** : respecter des étapes précises durant la mission.
- **Preuves visuelles** : prise de photos directement depuis l'application mobile.
- **Rapport d'activité** : rédaction d'un compte rendu détaillé pour le client.
- **Gestion financière** : émission de devis, de factures et collecte du paiement.

# Tableau comparatif des fonctionnalités

| **Fonctionnalité** | **Événement** | **Intervention** |
| --- | --- | --- |
| **Usage** | Commercial / Interne / Perso | Technique / Maintenance / Pose |
| **Prise de photos** | Non | Oui |
| **Compte rendu** | Notes simples | Rapports structurés |
| **Questionnaire** | Non | Oui |
| **Suivi des équipements** | Non | Oui |
| **Facturation sur place** | Non | Oui |
| **Visibilité Planning** | Oui | Oui |

    🧑‍🏫**Exemple:** Si vous avez une réunion d'équipe à 9h, tous les lundi matin, créez un Événement. Si vous devez ramoner un poêle chez M. Martin à 10h, créez une Intervention.
