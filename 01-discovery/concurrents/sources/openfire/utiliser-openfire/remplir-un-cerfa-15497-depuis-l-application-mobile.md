# Remplir un Cerfa 15497 depuis l'application mobile

Cet article vous explique comment documenter vos interventions sur des équipements thermodynamiques (PAC, clim) directement depuis votre application mobile. La validation de ces étapes génère automatiquement votre rapport d'intervention et votre Cerfa réglementaire.

Cet article contient les sections suivantes :

- [Accéder au Cerfa dans l'intervention](#h_01KP3QK6FRT40HR3TV7CKHX449)

- [Enregistrer une manipulation de fluide (Chargement/Récupération)](#h_01KP3QK6G2PSSXSV3ZA1MMBKWX)

## Accéder au Cerfa dans l'intervention

Pour générer un Cerfa, vous devez travailler sur un équipement identifié comme relevant du secteur **Climaticien**.

- Ouvrez votre intervention depuis votre planning mobile.
- Deux situations possibles :

  - **L'équipement est déjà listé** : Cliquez directement sur le rapport d'équipement **CERFA 15497** associé.
  - **L'équipement n'est pas présent** : Cliquez sur **Ajouter un équipement**, sélectionnez l'appareil concerné, puis choisissez le rapport **CERFA 15497**.

| 💡**Note **: Pour que le formulaire Cerfa soit accessible, le secteur d'activité **Climaticien**, la **Nature de fluide** et la **Charge totale** sont des champs **obligatoires** dans la fiche technique de l'équipement. |
| --- |

| 📓**Pour aller plus loin** → [Configurer les secteurs d'activité et les fiches équipements]. |
| --- |

## Saisie des fuites et contrôles d'étanchéité

Avant toute manipulation, vous devez déclarer le résultat de votre contrôle d'étanchéité.

- Dans la section **Fuites constatées**, indiquer si une fuite a été détectée.
- Sélectionner votre **Matériel de détection** dans la liste déroulante.
- Si une fuite est trouvée, précisez sa localisation (ex: Raccord unité intérieure).

| 💡**Note **: Si votre appareil n'apparaît pas dans la liste, il doit être enregistré et vous être assigné par votre administrateur. |
| --- |

| 📓**Pour aller plus loin** → [Configurer la gestion des fluides et le matériel de détection]. |
| --- |

## Enregistrer une manipulation de fluide

Si vous devez ajouter ou retirer du gaz, utilisez les boutons spécifiques situés en bas de votre écran.

- Cliquer sur le bouton correspondant à votre action :

  - **Ajouter une manipulation de chargement** (pour un ajout de fluide).
  - **Ajouter une manipulation de récupération** (pour un retrait de fluide).
- Sélectionner la **Bouteille** utilisée.

  - OpenFire trie intelligemment la liste pour vous faire gagner du temps : les bouteilles qui vous sont **assignées** apparaissent en premier, filtrées par le **fluide correspondant** à l'équipement.
  - **Pour un chargement** : le logiciel vous propose d'abord la bouteille de fluide neuf la plus pleine.
- Saisir la **Quantité (kg)** manipulée.

## Signature et finalisation du document

Une fois toutes les données saisies, vous devez faire valider l'intervention par le client.

- Se rendre dans l'onglet **Signature**.
- Faire signer le client directement sur l'écran.
- Cliquer sur **Terminer l'intervention**.

| 🚨**Avertissement** : La signature du client sur l'intervention globale est celle qui sera apposée sur le Cerfa 15497. Assurez-vous que toutes les manipulations de fluides sont bien saisies **avant** de faire signer, car le document PDF final sera généré avec ces données. |
| --- |

## Bonnes pratiques

- **Précision** : Soyez vigilant lors de la saisie des poids. Ces données mettent à jour automatiquement la **Quantité contenue** de vos bouteilles.
- **Photos** : Utilisez l'onglet **Photos** pour prendre un cliché de la plaque signalétique de l'unité extérieure ou de la fuite réparée.
