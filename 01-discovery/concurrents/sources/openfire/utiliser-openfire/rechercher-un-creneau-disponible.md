# Rechercher un créneau disponible

La fonctionnalité **Rechercher un créneau disponible** vous permet de planifier vos interventions au moment le plus opportun. Elle prend en compte la disponibilité de vos techniciens, la position géographique de vos clients et vos préférences horaires pour optimiser votre charge de travail.

Cet article vous guide dans l'utilisation de cette fonctionnalité.

# Accéder à la planification des interventions

Vous pouvez accéder facilement à la recherche de créneau depuis une opportunité, un contact ou une demande d’intervention.

- Ouvrir la fiche concernée (Contact, Opportunité ou Demande d'intervention).
- Cliquer sur le bouton **PLANIFIER INTERVENTION** situé en haut de la fiche

  ![](https://support.openfire.fr/hc/article_attachments/20235949777052)

  💡Note : Vous pouvez également réaliser une planification rapide depuis la vue liste de vos contacts en cliquant sur l'action Planifier disponible au bout de la ligne de contact.

![](https://support.openfire.fr/hc/article_attachments/24304097511836)

# Comprendre l'écran de planification

L'écran de recherche est divisé en quatre zones interactives pour vous aider à prendre la meilleure décision :

1. La carte de la tournée ;
2. Le récapitulatifs des données de l'intervention à planifier ;
3. Les critères de recherche ;
4. Les résultats proposés selon vos critères de recherche.

![Capture d’écran 2025-12-17 113844.png](https://support.openfire.fr/hc/article_attachments/24305500439708)

## Consulter la carte de la tournée (zone 1)

La carte affiche visuellement l'organisation de la journée sélectionnée :

- **Le curseur noir** : Point de départ du technicien.
- **Le curseur vert** : Adresse du client pour l'intervention à planifier.
- **Les curseurs bleus** : Interventions déjà prévues dans cette tournée.

![](https://support.openfire.fr/hc/article_attachments/24305515776796)

# Vérifier les données de l'intervention à planifier (zone 2)

Avant de valider, vérifiez les informations essentielles importées dans le volet **INTERVENTION** :

![](https://support.openfire.fr/hc/article_attachments/24305515779100)

- Le **nom **et les **coordonnées **du client.
- L'**adresse d'intervention.**

🚨**Avertissement **: Si l'adresse n'est pas géolocalisée, la recherche de créneau sera impossible.

- Si l'intervention est liée à une d**emande d'intervention**, cette dernière est affichée. Le lien vers la demande d'intervention est essentielle pour garantir le bon suivi des interventions à réaliser, notamment dans le contexte des interventions récurrentes.
- Le **modèle d'intervention ; **il définit notamment la tâche et la durée prévue, hors temps de trajet. Dans le cadre d'une planification directe, un modèle d'intervention par défaut peut-être défini.
- Le ou les **équipements** du client sur lequel porte l'intervention.

# Ajuster vos critères de recherche (zone 3)

Utilisez le volet **CRITÈRES DE RECHERCHE** pour affiner les résultats :

![](https://support.openfire.fr/hc/article_attachments/24306066196636)

**Modèle de recherche : **les modèles de recherche vous permettent de définir des valeurs par défaut, tels que les techniciens, le modèles d'intervention, le type et le mode de recherche, les utilisateurs concernés et/ou les jours de recherche.

**📓**Pour aller plus loin → Paramétrer vos modèles de recherche de créneaux (à venir)
- ***Depuis***** **: Date de début de votre recherche.
- ***Période de la journée*** : matin, après-midi ou indifférent.
- ***Jours disponibles***** **: exclure les indisponibilités connues du client.
- ***Techniciens*** : sélectionnez un ou plusieurs intervenants spécifiques. Si aucun n'est choisi, le système cherche parmi tous les techniciens compétents.

Cliquez sur **Rechercher** pour afficher les créneaux.

# Choisir le meilleur créneau (zone 4)

Une fois la recherche lancée, le système vous propose deux listes de résultats pour sélectionner le rendez-vous idéal :

- **Par distance** : ce mode trie les résultats en optimisant les kilomètres à parcourir par le technicien. Il est particulièrement utile pour minimiser les temps de trajet entre deux interventions consécutives.
- **Par date** : ce mode privilégie la rapidité de prise en charge en affichant les disponibilités les plus proches dans le temps. C'est le choix recommandé pour planifier des interventions d'urgence ou de dépannage immédiat.

Pour chaque créneau proposé, vous visualisez trois indicateurs clés de distance:

- **Aller** : distance entre l'intervention précédente et celle à planifier.
- **Retour** : distance entre l'intervention à planifier et la suivante.
- **Min. journée** : distance la plus courte entre l’intervention à planifier et n'importe quelle intervention de la journée / demi-journée (suivant le mode d’optimisation par défaut sélectionné).

Si vous **AFFICHER** le créneau, vous visualisez sur la carte la tournée du technicien et la position de ce créneau dans la tournée (voir ci-dessus).

Cliquez sur **CONFIRMER CE CRENEAU** pour valider la planification.

![](https://support.openfire.fr/hc/article_attachments/24313172224796)
💡**Note** : Si vous avez activé l'option d'optimisation, un nouveau bouton **Par optimisation** apparaît pour trier les résultats selon la distance "Min. journée", vous offrant ainsi la meilleure organisation globale possible. Cette option d'optimisation est présentée ci-dessous.

# Effectuer une recherche par Optimisation

Lors de la planification d’une intervention, le système propose des créneaux disponibles. Avec l'option de recherche par **Optimisation, **le système ne se contente plus de regarder uniquement les interventions qui entourent le créneau, mais analyse **toute la journée du technicien** pour afficher la distance la plus proche.

## Pourquoi utiliser l'optimisation de recherche ?

L'optimisation transforme la manière dont le système analyse votre planning pour réduire vos trajets.

**Exemple concret :**

- **Sans optimisation :** Le système regarde uniquement les créneaux vides qui "entourent" vos rendez-vous existants. Il vous propose le mercredi, car l'intervention s'insère entre deux RDV avec seulement 8 km de trajet. Vous planifiez donc le mercredi.
- **Avec optimisation :** Le système analyse la **globalité de la journée** du technicien, et pas seulement les trous dans l'agenda. Il détecte qu'une intervention déjà prévue le jeudi se situe à seulement 1 km de votre nouveau client. Même si le planning du jeudi semble plus "rempli", l'outil vous propose ce créneau comme étant le meilleur choix géographique.
- **Le résultat :** En choisissant le jeudi, vous réduisez considérablement le nombre de kilomètres parcourus. Le logiciel se chargera ensuite de réorganiser (décaler) intelligemment les autres RDV de la journée pour faire de la place à cette nouvelle intervention.

**Bénéfice :** Une tournée plus dense, moins de temps sur la route et une meilleure rentabilité pour vos équipes.

## Activer et configurer l'option

L'option et les paramètres associés sont accessibles en suivant le chemin d'accès :

`Configuration > Interventions > Planification d'intervention` :

**![](https://support.openfire.fr/hc/article_attachments/24313218481692)**

L'activation de cette option d'optimisation modifie la gestion de votre planning. Comme elle permet au système d'insérer un rendez-vous au meilleur moment de la journée (quitte à décaler légèrement des interventions déjà prévues), vous devez définir comment le logiciel doit réorganiser la tournée ensuite.

![](https://support.openfire.fr/hc/article_attachments/24313172230172)

Trois options possibles :

| **Option** | **Description** | **Quand l'utiliser** |
| --- | --- | --- |
| **Toujours demander** | Une fenêtre vous demande si vous voulez optimiser après chaque planification | Vous préférez décider au cas par cas |
| **Toujours optimiser automatiquement** | La tournée s'optimise automatiquement sans vous demander | Vous voulez gagner du temps et optimiser systématiquement |
| **Ne jamais optimiser automatiquement** | Aucune optimisation après planification | Vous préférez optimiser manuellement plus tard |

  💡Conseil : Commencez par "Toujours demander" pour vous familiariser avec la fonctionnalité.

## Utiliser l'option

Une fois l'option activée, et dans le contexte de votre recherche de créneau, vous pouvez maintenant choisir comment trier les créneaux :

**Par distance / durée** (tri classique) ;

**Par optimisation** (nouveau) : trie selon la distance "Min. journée".

![](https://support.openfire.fr/hc/article_attachments/24313172224796)

## Optimiser après planification

![](https://support.openfire.fr/hc/article_attachments/24313218486940)

### Si vous avez choisi "Toujours demander"

Après avoir sélectionné un créneau, une fenêtre apparaît :

**"Souhaitez-vous optimiser la tournée du technicien après avoir ajouté cette intervention ?"**

Deux boutons :

- **Optimiser** : Optimise la tournée ;
- **Ne pas optimiser** : Planifier l’intervention sur le créneau sélectionné. On retrouvera la tournée dans le filtre “Besoin de mise à jour de l’optimisation”.

### Si vous avez choisi "Toujours optimiser automatiquement"

La tournée s'optimise automatiquement dès que vous confirmez le créneau. Aucune action supplémentaire n'est nécessaire.

### Si vous avez choisi "Ne jamais optimiser automatiquement"

Aucune optimisation n'est effectuée. La tournée du créneau sélectionné sera taggée comme nécessitant une optimisation (vous la retrouverez dans le filtre “Besoin de mise à jour de l’optimisation”). Vous pourrez optimiser manuellement depuis la liste des tournées.

# Gérer les tournées à optimiser

![](https://support.openfire.fr/hc/article_attachments/24313218488092)

Lorsqu'une intervention est planifiée sans optimisation, la tournée est automatiquement marquée comme "ayant besoin d'optimisation".

- Dans la liste des tournées, vous pouvez facilement identifier celles qui ont besoin d’optimisation grâce au filtre “**Besoin de mise à jour de l’optimisation**”.
- La tournée apparaît avec un ⚠️ sur sa ligne

# Bonnes pratiques

- Utiliser des critères de recherche précis et enregistrer des modèles récurrents vous fait gagner du temps et garantit des propositions plus pertinentes.
- Pensez à tenir à jour les plages de travail des techniciens pour éviter les créneaux irréalisables.

  💡Note : Vous pouvez planifier une intervention sur plusieurs créneaux. OpenFire prend en compte la pause déjeuner automatiquement.

    🧑‍🏫Exemple: une intervention de 4h démarrant à 11h inclura une pause déjeuner de 12h à 13h. Elle se terminera donc à 16h.

    🚨Avertissement : OpenFire n'affichera pas de créneau si le temps de trajet et la tâche dépassent le temps de travail disponible de l’intervenant.

    🧑‍🏫Exemple: Si un technicien travaille 4h le matin, il ne pourra pas être planifié pour une intervention de 1h située à 3h30 de route.
