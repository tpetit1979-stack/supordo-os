# OpenFire Version Odoo 14.0-20231205

                    Informations sur le OpenFire instance d'Odoo, le [ERP Open Source](https://www.odoo.com).
                

## Applications installées

- 
                        
                            [Site web](https://www.odoo.com/page/website-builder)
                        
- Constructeur de sites web d'entreprise

- 
                        
                            [Email Marketing](https://www.odoo.com/page/mailing)
                        
- Concevoir, envoyer et suivre des e-mails

- 
                        
                            [Custom Fields: Core](https://faotools.com/apps/14.0/custom-fields-core-484)
                        
- The technical core to add new fields for Odoo documents without any special knowledge

- 
                        
                            [KnowSystem: Knowledge Base System](https://faotools.com/apps/14.0/knowsystem-knowledge-base-system-506)
                        
- The tool to build deep and structured knowledge base for internal and external use. Knowledge System. KMS

- 
                        
                            [KnowSystem: Custom Fields](https://faotools.com/apps/14.0/knowsystem-custom-fields-508)
                        
- The extension to KnowSystem to create custom fields

- 
                        
                            [KnowSystem: Website and Portal](https://faotools.com/apps/14.0/knowsystem-website-and-portal-510)
                        
- The extension to KnowSystem to publish articles to portal and public users

- 
                        
                            [eLearning](https://www.odoo.com/page/slides)
                        
- Gérer et publier une plateforme eLearning

- 
                        
                            [Discussion](https://www.odoo.com/page/discuss)
                        
- Chat, passerelle d'email et canaux privés

- Contacts
- Centralisez votre carnet d'adresses
