Pour analyser le chiffre d'affaires par activité dans OpenFire, vous pouvez utiliser les fonctionnalités de rapports et d'analyse disponibles dans le menu Comptabilité > Rapports.

Le rapport nommé Analyse CA facturé permet d'analyser le chiffre d'affaires facturé sur une période donnée. Ce rapport affiche le chiffre d'affaires total, ainsi que le chiffre d'affaires par client et par produit. Pour utiliser ce rapport, vous devez suivre les étapes suivantes

## Fonctionnement

Rendez-vous dans le menu **Comptabilité > Rapports > Analyse CA facturé.**

Vous arrivez alors sur un tableau en vue croisée dynamique:

Ce tableau croisé dynamique est un tableau interactif qui permet de combiner et de comparer rapidement de grandes quantités de données.
