OpenFire enregistre des pièces jointes dès lors que vous imprimez un devis, un bon de commande ou une facture. Cela peut être utile dans certains cas puisqu'il permet de retrouver la dernière version imprimée d'un document.

Par exemple, si vous imprimez un bon de commande le 01/01/2022, une pièce jointe est automatiquement enregistrée et accessible via le bouton Pièces jointes.

Ainsi, si vous demandez la réimpression de ce même bon de commande le 01/03/2022, le document reprendra les données telles qu’elles étaient au 01/01/2022.
