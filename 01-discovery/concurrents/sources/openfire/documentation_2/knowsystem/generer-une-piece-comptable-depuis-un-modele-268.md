Les modèles de pièces comptables permettent de gagner du temps en évitant de saisir manuellement les mêmes informations à chaque fois que vous créez une nouvelle pièce comptable. En utilisant des modèles, les informations de base telles que les comptes, les montants, les taxes, les références, etc. peuvent être préremplies automatiquement.

Vous pouvez ainsi minimiser les risques d'erreur dans la saisie des données et vous n'avez qu'à vérifier et modifier les champs pertinents.

  *Plus d'information sur* *les écritures et les pièces comptables* 


## Création du Modèle

Les modèles de pièces comptables peuvent être créés depuis le menu **Comptabilité > Configuration > Modèles de pièce comptable**

Après avoir donné un nom à votre modèle, vous pouvez ajouter des écritures en cliquant sur Ajouter un élément:

Une séquence doit être donnée pour chaque ligne. Ensuite, vous pouvez vous référer aux autres lignes en utilisant leur numéro de séquence (par exemple L(1)*0.2).

 **Attention:** Veillez à utiliser des points dans les montants du modèle de pièce comptable et non pas des virgules.

## Utilisation du modèle

Vous pouvez utilisez un modèle préalablement créé en vous rendant dans le menu **Conseiller > Générer une pièce depuis un modèle** :


Sélectionnez ensuite le modèle de votre choix dans le menu déroulant dédié ainsi que le client ou le fournisseur concerné:

Si vous n'avez pas encore créé de modèle, vous pouvez le faire en cliquant sur le bouton "Créer" à côté du champ "Modèle".

Une fois que vous avez sélectionné votre modèle, OpenFire va automatiquement remplir les champs requis pour la pièce comptable en fonction du modèle sélectionné. Vous pouvez apporter des modifications à ces champs si nécessaire.

Vérifiez tous les détails de la pièce comptable, y compris les montants, les dates et les informations de compte, pour vous assurer qu'ils sont corrects.

Si tout est en ordre, cliquez sur le bouton "Charger" en bas de l'écran pour générer la pièce comptable.

La pièce comptable est alors enregistrée dans votre comptabilité et est prête à être utilisée.
