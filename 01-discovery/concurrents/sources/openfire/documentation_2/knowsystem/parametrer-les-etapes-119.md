OpenFire permet la création d'étapes de ventes que vous pouvez utilisez pour gérer des opportunités de vente et créer des rapports. Vous pouvez ajouter vos propres étapes et modifier certains aspects des étapes par défaut directement depuis le pipeline, ou depuis un menu dédié.

## Gérer les étapes

Par défaut, votre base contient 5 étapes simples:

- Nouveau : Il s’agit de l’état initial de l’opportunité ; cet état se rapproche de la notion de “Première ODV”.
- Estimation : opportunité pour lesquelles un pré-chiffrage de type estimation a été généré, alors qu’aucune VT n’a été réalisée. Cette étape est facultative.
- Visite Technique : Opportunité dont la Visite Technique a été planifiée ou réalisée.
- Devis : opportunités pour lesquelles un chiffrage de type devis a été édité
- Gagné / Perdu : Etat final de l’opportunité de vente

Ces tâches suivent un parcours logique vers la conclusion, mais vous n’êtes pas obligé de les suivre dans un ordre strict. Vous pouvez déplacer vos opportunités de vente entre les étapes pour refléter votre processus de vente.

Les étapes peuvent être créées et modifiées depuis le pipeline.

En cliquant sur le signe , vous accéder à la configuration des étapes.

Ces étapes peuvent être modifiées en leur affectant d'autres noms.

Elles peuvent également être replier, afin d'alléger l'affichage, ou encore supprimer.

Attention: l'étape ne pourra pas être supprimée si elle contient des opportunités. Si vous ne pouvez pas supprimer une étape, pensez à vérifier qu'il n'y a pas d'opportunités inactives dans cette étape.

## Automatisation des étapes

Il est possible d'automatiser le changement d'étape en fonction de certaines actions (génération d'un devis, envoi d'un mail, etc...).

Néanmoins, la configuration de ces changements automatiques étant complexe, nous vous invitons a vous rapprocher du service technique OpenFire à l'adresse support@openfire.fr ou par téléphone au 02.30.96.02.65 pour ce type de demande.
