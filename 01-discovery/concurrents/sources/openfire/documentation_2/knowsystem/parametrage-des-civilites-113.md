Les civilités peuvent être ajoutées, modifiées ou créés directement depuis les fiches contact. Néanmoins, un menu dédié est également disponible.

## Gestion des civilités

Pour accéder au menu des civilités, il faut dans un
premier temps activer le mode développeur.

Pour cela, rendez-vous dans l’onglet
**Configuration** puis cliquez sur l’option Activer le mode développeur à droite :

Une fois fait, rendez-vous dans le menu **Ventes > Configuration > Civilités** :


Vous trouverez alors la liste des civilités créés.

Lors de la création / Modification d'une civilité, vous pouvez alors choisir de la rendre disponible pour les numéros de téléphone ou non:

## Affichage dans les devis & commandes

Vous avez la possibilité de choisir d'afficher ou non les civilités en vous rendant dans **Ventes > Configuration > Configuration**

Ensuite cliquez sur l'option Définir les champs à afficher.

Cette option vous permettra de paramétrer certains éléments de l'impression de vos devis, comme l'affichage des civilités:

  Plus d'information sur [l'impression des devis](https://documentation.openfire.fr/knowsystem/parametrer-l-impression-du-devis-129)

## Affichage dans les factures

Vous avez la possibilité de faire apparaitre les civilités dans les factures en vous rendant dans le menu **Comptabilité > Configuration > Configuration**
