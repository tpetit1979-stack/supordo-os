L'application OpenFire est accessible sans installation préalable sur votre poste via un navigateur Web. L'ensemble des navigateurs peut être utilisés (Chrome, Firefox, Edge, Safari, ...).

## Connexion à la base de production

Saisissez votre identifiant ainsi que votre mot de passe dans les champs de texte indiqués :

A savoir : chaque utilisateur est identifié par un nom d'utilisateur, un mot de passe et un profil unique. Le profil détermine les données qu'un utilisateur peut afficher et les tâches qu'il peut effectuer. Il est donc important que chacun se connecte via son propre profil !

## Connexion à la base de test

En parallèle de votre environnement de production, une base de test appelée “bac à sable” est mise à votre disposition afin de réaliser l’ensemble de vos tests et exercices.

Cet environnement de test est une copie de l’environnement de travail mais n'a aucun autre lien avec ce dernier : ce que vous faites sur le bac à sable ne se répercute pas sur votre base de travail, et inversement.

Accès au bac à sable : https://bas-mabase.openfire.fr

Identifiant et mot de passe : identique à ceux de l’environnement de travail

Ce bac à sable est régénéré régulièrement et à la demande afin de réactualiser les données.

   Attention : votre bac à sable n’est pas sauvegardé et les données sont « jetables ».
