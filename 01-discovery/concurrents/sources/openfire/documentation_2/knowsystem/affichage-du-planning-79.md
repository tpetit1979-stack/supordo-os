Le menu interventions regroupe l'ensemble des éléments nécessaires à la gestion de l’activité technique de l’entreprise. On va ainsi pouvoir y retrouver le Planning, les Visites techniques, les SAV, les poses, les contrats d’entretien, etc…

Le planning d'intervention  est le premier menu du module Interventions, disponible en cliquant sur l’icône   (1)  , mais il est également consultable depuis le menu Interventions > Interventions > Planning

Plusieurs vues sont alors disponibles via les boutons disponibles en haut à droite de l'écran (2):

## Vue Planning

La vue planning est une vue destinée à visualiser facilement la charge de rendez-vous par intervenant.

Elle est disponible en cliquant sur l'icone ci-dessous:

Cette vue embarque des fonctions de planification destinées à aider les opérateurs à trouver la meilleure intervention à programmer pour un créneau donné :

- Nom du technicien ;
- Numéro de semaine affichée ;
- Détail de l’intervention affichée ;
- Fonction de planification indiquant les intervalles de temps disponibles ( *Plus d'information sur la __planification directe) ;__*
- Fonction d’assignation d’un secteur d’intervention pour le jour et le technicien donné ( *Plus d'information sur les __secteurs d'interventions).__*

Le volet de navigation sur la droite de l’écran vous permet de sélectionner vous-même les informations à afficher dans la vignette de l’intervention.

Il est possible de filtrer les techniciens pour la prise de rendez-vous, et de sélectionner une date par simple clic via le calendrier de droite :

OpenFire retiendra alors vos préférences d’affichage d’une connexion à l’autre.

## Vue calendrier

La vue Calendrier est disponible via l'icone ci-dessous :

Fonction de la vue Calendrier :

- Affichage en Jour / Semaine / Mois
- Sélection du mois à afficher
- Choix du technicien à afficher
- Numéro de semaine
- Légende sur l’état du RDV
- Fonctions de recherche et de filtre (voir détail ci-dessous)

## Vue Carte

La vue Carte est disponible via l'icone ci-dessous :

Cette vue permet d'afficher sur une carte les différents lieux de rendez-vous en fonction des filtres de recherche sélectionnés :

Chaque lieu de rendez-vous est caractérisé par un point et un code couleur. La légende des codes est disponible en bas a droite de la vue carte :

L'affichage des points nécessite que les lieux d'intervention soient correctement géolocalisés.

  Plus d'information sur la [géolocalisation](https://documentation.openfire.fr/knowsystem/geolocalisation-180)

## Filtres de recherche

Les Filtres de recherche vous permettent de filtrer les interventions en fonction de différentes données :

L’état de l’intervention : Brouillon, Confirmé, En cours, Réalisé, Inachevé, Annulé, Reporté

La temporalité de l’intervention :

          - Hier, Aujourd’hui, Demain
          - Semaine en cours ou semaine prochaine
          - Mois en cours ou mois prochain

  *Les filtres de temporalité sont utiles principalement depuis la vue planning pour ne conserver à l’écran que les interventions liées à une période de temps.*
