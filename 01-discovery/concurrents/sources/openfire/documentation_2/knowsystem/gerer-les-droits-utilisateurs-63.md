## Intervention



La gestion des droits web et mobile est gérée par le même groupe OF Interventions.

Nous avons uniformisé pour que les fonctionnalités soient les mêmes qu'on soit connecté depuis l'application ou depuis le web.

Les niveaux *Responsable* et *Gestionnaire* permettent, dans l'application mobile, l'accès au planning de tous les techniciens.

Pour les utilisateurs Mobile uniquement, le pilotage des droits se fait donc entre *Accéder à mes interventions* et *Gérer mes interventions*.

Selon le niveau de droits, vous pourrez :

*Accéder à mes interventions :*

- Voir et compléter vos interventions.
- Répondre à un questionnaire, ajouter des lignes de facturation et de livraison, modifier un parc installé.

*Gérer mes interventions :*  

- Accéder à toutes les interventions sans pouvoir les modifier (web uniquement)
- Créer et modifier la configuration de l'intervention
- Créer un contact
- Créer un parc installé.

*Responsable (droits web uniquement):*

- Créer et modifier des interventions pour tous les intervenants.
- Configurer les questionnaires, employés, modèles d'intervention, etc.
- Supprimer une intervention, une demande d'intervention
- (Mobile) Permet de voir le planning de tous les techniciens sur l'application mobile

*Gestionnaire (droits web uniquement) :* 

- Supprimer : parc installé, contact, questionnaire, modèle, etc.

## Paiement



Pour enregistrer un paiement, l'intervenant doit avoir au minimum le niveau de droit Facturation sur l'application Comptabilité et finance.
