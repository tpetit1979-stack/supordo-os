OpenFire a développé un module permettant de gérer les parrainages dans votre base clients. Des récompenses de parrainage peuvent être crées et associées à une fiche client s'il a parrainé un ami avec succès.

 Ce module n'est pas installé par défaut sur toutes les bases OpenFire. Si vous le souhaitez, vous pouvez demander l'installation de ce module au support OpenFire par mail à l'adresse support@openfire.fr, ou par téléphone au 02.30.96.02.65.

## Création des récompenses

Une fois le module présent dans votre base, vous pouvez définir des récompenses a attribuer aux parrains et aux filleuls qui remplissent les conditions du programme de parrainage, depuis le menu **Ventes > Configuration > Récompenses de parrainages**

Vous pouvez ainsi créer des récompenses de parrainage. Les récompenses peuvent être des points de fidélité, des bons de réduction, des produits gratuits, etc :

## Gestion des Parrains/Filleuls

Pour gérer les parrainages sur OpenFire, vous pouvez dans un premier temps créer une catégorie de produit spécifique pour les parrainages, si vous n'en avez pas déjà une.

Ensuite, les éléments de parrainage sont gérables depuis les fiches contacts via l'onglet Marketting:

Dans la partie Données Filleul , vous pouvez renseigner le parrain, la date de parrainage et une note concernant le parrainage:

En complément, il est possible d'envoyer d'effectuer des campagnes marketting sur OpenFire afin de  communiquer efficacement sur vos offre de parrainage, via le module de Publipostage.
