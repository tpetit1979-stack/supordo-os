Dans OpenFire, des modèles de Projets peuvent être associés aux opportunités. Ces modèles permettent d'organiser la prise d'informations, et de lier un certain nombre d'attributs à une opportunité.

[les opportunités](https://documentation.openfire.fr/knowsystem/creer-une-opportunite-106)


## Les modèles de projets

Les modèles de projets sont configurables depuis le menu Ventes > Configuration > Modèles de projets

Sur chaque modèle il est possible d'associer des attributs.

Par exemple, il est possible de créer un modèle de projet *Cheminée et Poêle* dans lequel on viendra définir différentes valeurs à remplir: 

- Le Type de projet (Cheminée, Poêle bois, Poêle Granulés, etc...)
- Habitat de + de 2ans
- Résidence principale Oui/Non, etc...

## Les Attributs

Les attributs sont paramétrables depuis le menu Ventes > Configuration > Attributs de Projets :

Les attributs d'un projet peuvent être de différents types: texte libre, réponses Oui/Non, réponses parmi plusieurs choix, etc...

Les réponses peuvent ensuite être sélectionnées depuis l'opportunité via un menu déroulant:

Dans le cas où l'on souhaite proposer de choisir un réponse parmi une liste, il faut tout d'abord créer les différentes réponses possibles.

Dans l'exemple ci-dessous, pour la question *Type de projet*, la réponse *Poêle bois* sera renseignée par défaut, mais d'autres choix de réponses sont possibles.

Ces réponses sont configurables depuis le menu Ventes > Configuration > Valeurs d'attributs de projets

Attention: Toute modification d’un modèle de projet ne sera répercutée que sur les interventions créées à posteriori.
