OpenFire vous permet de générer des factures boutiques. Si vous gérez les stocks et que vous souhaitez créer des factures directement au comptoir magasin, vous pouvez créer une facture boutique. Les factures de ventes au comptoir sont aussi dissociés de vos autres factures tout en restant dans le même journal de vente comptablement.

*__Accès__* : Comptabilité > Ventes > Factures Boutiques

Si vous n'avez pas le menu dans votre base, merci de contacter le support à support@openfire.fr.

## Créer une facture boutique

Pour générer directement une facture, vous allez dans **Comptabilité > Ventes > Factures Boutique**, puis cliquez sur Créer.

**1** - Notez le nom du client

**2** - Notez la position fiscale afin que la taxe se mette directement sur les lignes de facture.

**3** - Modifier l'adresse de livraison si elle est différente

**4** - Ajouter les articles dans les lignes de facture

**5** - Sauvegarder la facture brouillon. 

La facture est à l'état brouillon. Vous vérifiez les informations avant de valider la facture. Lorsque la facture est validée, la facture passe à l'état ouverte, un numéro de facture apparaît et une pièce comptable est générée.

La validation de la facture génère aussitôt un bon de livraison client en état fait. Il y a donc une sortie de stock. Vous avez accès au bon de livraison en cliquant sur Livraison en haut à droite.

Il faudra ensuite enregistrer le paiement en cliquant sur ENREGISTER UN REGLEMENT.

  Plus d'information sur [Enregistrer un paiement](https://documentation.openfire.fr/knowsystem/enregistrer-un-paiement-161)

Vous retrouvez toutes vos factures boutiques isolées dans le menu dédié et vous les retrouvez aussi dans le menu Factures clients avec les autres factures.
