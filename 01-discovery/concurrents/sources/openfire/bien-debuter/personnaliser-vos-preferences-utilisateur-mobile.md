# Personnaliser vos préférences utilisateur mobile

Dans votre application mobile, vous pouvez compléter ou modifier vos informations personnelles ainsi que personnaliser la vue de votre planning, en sélectionnant notamment les informations que vous souhaitez masquer ou afficher.

Cet article contient les sections suivantes :

- [Modifier les informations personnelles](#h_01JPAPK8DFCEDZB6ESVB100MRF)
- [Modifier les préférences utilisateurs](#h_01JPAPK8DFGXKQ056W1P8Q7H70)

# Modifier vos informations personnelles

Depuis l’application mobile OpenFire, vous pouvez modifier vos informations personnelles. Pour cela :

- Une fois connecté à l’application mobile OpenFire, cliquez sur le **menu principal** en haut à gauche
- Cliquez sur **Mon compte**.

| ![](https://support.openfire.fr/hc/article_attachments/19007349388956) |
| --- |

Modifiez vos informations personnelles et cliquez sur Enregistrer.

# Modifier vos préférences utilisateurs

Depuis l’application mobile OpenFire, vous pouvez afficher ou masquer certaines informations de vos interventions.

Pour cela :

- Cliquez sur le **menu principal** en haut à gauche  ;
- Cliquez ensuite sur **Configuration**.
- Choisissez ensuite les informations à afficher ou à masquer.
