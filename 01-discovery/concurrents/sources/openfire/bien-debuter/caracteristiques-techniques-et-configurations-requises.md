# Caractéristiques techniques et configurations requises

OpenFire est un logiciel SAAS. Il est donc accessible via un navigateur internet, mais également une application mobile.

Nous décrivons ici les limites du support de l’application en fonction du navigateur utilisé ou de la version du système d’exploitation de votre mobile.

Cet article contient les sections suivantes :

- [Navigateurs web supportés](#h_01JP80W3R9752WN2W5M2NNS9AZ)
- [Systèmes d’exploitation mobiles supportés](#h_01JP80W3R9N9RKPYMZ5YYSTX6N)

# Navigateurs web supportés

Le logiciel OpenFire est utilisable globalement sur tous les navigateurs du marché.

Cependant, pour des motifs techniques, de performance, et de compatibilité nous ne pouvons garantir le fonctionnement de notre logiciel que sur les navigateurs internet suivants :

- [Google Chrome](https://www.google.com/chrome/)
- [Mozilla Firefox](https://www.mozilla.org/fr/firefox/new/)
- [Safari](https://www.apple.com/fr/safari/)
- [Edge](https://www.microsoft.com/fr-fr/edge/)

Dans le cas où vous utiliseriez un navigateur différent, et rencontreriez un dysfonctionnement. Nous vous invitons à vous assurer que le problème se produise également sur les navigateurs cités ci-dessus.

# Systèmes d’exploitation mobiles supportés

L’application mobile OpenFire est disponible sur les boutiques d’application suivantes :

- [App Store](https://apps.apple.com/fr/app/openfire/id1641533331)
- [Play Store](https://play.google.com/store/apps/details?id=com.openfire.mobile.androidApp&hl=fr)

Les systèmes d’exploitation supportés sont :

- iOS, version 12 ou supérieure
- Android, version 10 ou supérieure

Nous ne supportons pas l’utilisation de l’application mobile via un émulateur.
