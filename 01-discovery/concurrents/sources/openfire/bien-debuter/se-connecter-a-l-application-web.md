# Se connecter à l'application web

![All_tick_V2.png](https://support.openfire.fr/hc/article_attachments/19563152522780)

Retrouvez dans cet article, toutes les informations pour vous connecter à vos environnements de travail OpenFire.

Cet article contient les sections suivantes :

- [Connexion à la base de production](#h_01JP5GPKXYGTZYPMDE7VECKQCG)
- [Connexion à la base de test](#h_01JP5GPKXYMPWC9YX776DM5AX3)
- [Déconnexion](#h_01JP5GPKXY0PGB49BZJD52RCXQ)

## **Connexion à la base de production**

OpenFire est accessible sans installation d'application préalable sur votre poste via un navigateur Web. L'ensemble des navigateurs peuvent être utilisés (Chrome, Firefox, Edge, Safari, ...).
Pour vous connecter à votre base OpenFire de production, rendez-vous sur l'URL reçu à la création de votre environnement de travail OpenFire.

Cette URL a la forme suivante : https://mabase.openfire.fr

![](https://support.openfire.fr/hc/article_attachments/18965586140444)

Saisissez votre identifiant ainsi que votre mot de passe dans les champs de texte indiqués, puis cliquez sur "Se connecter".

💡Note : Chaque utilisateur est identifié par un nom d'utilisateur, un mot de passe et un profil unique. Le profil détermine les données qu'un utilisateur peut afficher et les tâches qu'il peut effectuer. Il est donc important que chacun se connecte via son propre profil.

## **Connexion à la base de test**

En parallèle de votre environnement de production, une base de test est mise à votre disposition afin de réaliser l’ensemble de vos tests et exercices.

Cet environnement est une copie de votre base de travail mais n'a aucun autre lien avec ce dernier : ce que vous faites sur votre base test ne se répercute pas sur votre base de travail, et inversement.

L'URL de votre base test est la suivante : https://test-mabase.openfire.fr

Votre identifiant et mot de passe sont identiques à ceux de votre base de travail.

Ce bac à sable est régénéré régulièrement et à votre demande afin de réactualiser les données avec celles de votre base de production.

💡Note : Votre base test n’est pas sauvegardée et ses données sont « jetables ».

## **Déconnexion**

Pour vous déconnecter en toute sécurité, cliquez sur votre nom de profil en haut à droite, puis sur le bouton "Se déconnecter".
