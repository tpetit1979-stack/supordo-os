# Se connecter à l'application mobile

Cet article vous guide pas à pas pour télécharger l'application mobile OpenFire sur votre smartphone ou tablette et pour y établir votre première connexion. Cette étape est indispensable pour accéder à votre solution OpenFire en mobilité.

L’application mobile OpenFire est votre compagnon idéal pour piloter votre activité terrain ! Grâce à elle, vous pourrez notamment consulter votre planning, planifier vos prochains RDV, réaliser vos interventions du jour (compte rendu, photo, paiement, facturation, signature)...

L'application est disponible pour Android et iOS.

Découvrez ci-après comment télécharger et vous connecter à votre application !

# **Installation de l’application mobile**

Téléchargez l’application mobile à partir de votre boutique d’applications :

- Utilisateurs iOS : téléchargez-la à partir de l’[App Store](https://apps.apple.com/fr/app/openfire/id1641533331).
- Utilisateurs Android : téléchargez-la à partir du[ Google Play](https://play.google.com/store/apps/details?id=com.openfire.mobile.androidApp&hl=fr).

# **Se connecter à l'application mobile**

| ![page de connexion mobile](https://support.openfire.fr/hc/article_attachments/19097270939932) |
| --- |

Pour se connecter, trois champs sont à saisir :

- Serveur : Saisir ici l’adresse web de votre base OpenFire
  **Exemple **: https://mabase.openfire.fr
- Utilisateur et Mot de passe : Renseigner ici les identifiants de connexion qui vous ont été adressés par votre administrateur.
💡Note : Note : Vos identifiants de connexion sont identiques entre votre base web OpenFire et votre application mobile.💡Note : L’option **Rester connecté** vous permet de ne pas avoir à rentrer vos identifiants à chaque ouverture de l’app. En clair, si vous vous connectez sur votre téléphone n’hésitez pas à laisser la case cochée. Si par contre vous vous connectez sur le téléphone d’un tiers ou que vous estimez l’appareil non sécurisé, décochez la case. 
# **Se déconnecter de l'application mobile**

Pour vous déconnecter :

- Cliquer sur le **menu principal**, situé en haut à gauche de votre écran.
- Cliquer sur **Mon compte**.
- Cliquer sur l'icône **déconnexion** située en haut à droite.

# **Mettre à jour l'application mobile**

Les mises à jour de l’app sont proposées automatiquement et gratuitement par OpenFire.
Pour mettre à jour ou vérifier qu’une mise à jour est disponible ouvrez la page OpenFire dans votre boutique d’applications :

- Utilisateurs iOS :[ OpenFire sur l'App Store](https://apps.apple.com/fr/app/openfire/id1641533331)
- Utilisateurs Android :[ OpenFire sur le Google Play](https://play.google.com/store/apps/details?id=com.openfire.mobile.androidApp&hl=fr)

Si une mise à jour est disponible, le bouton ouvrir sera indisponible au profit d’un bouton mettre à jour.
