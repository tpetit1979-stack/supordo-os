# Factur-X : le format hybride de la facture électronique explique simplement

Factur-X est le format de facture électronique retenu par la France et l'Allemagne. Il combine un PDF lisible par l'humain et un fichier XML lisible par les machines. Pour les artisans du bâtiment, c'est la façon la plus simple de se conformer à la réforme sans changer radicalement ses habitudes.

A retenir

- Factur-X est un PDF qui embarque un fichier XML structure à l'intérieur.
- Il est lisible par l'humain (le PDF) et par les machines (le XML).
- C'est l'un des trois formats acceptes pour la facturation électronique en France (avec UBL et CII).
- Votre logiciel de facturation doit pouvoir générer ce format automatiquement.

## Qu'est-ce que Factur-X exactement ?

Factur-X est un standard franco-allemand de facture électronique hybride. Concrètement, c'est un fichier PDF/A-3 qui contient en pièce jointe un fichier XML structure au format CII (Cross Industry Invoice). Le PDF permet à n'importe qui de lire la facture visuellement. Le XML permet aux logiciels de traiter les données automatiquement sans ressaisie.

## Les differents profils de Factur-X

Factur-X propose plusieurs niveaux de détail dans le XML embarque, appeles profils. Le profil Minimum contient les informations essentielles (emetteur, destinataire, montant). Le profil Basic ajoute les lignes de détail. Le profil EN16931 (Comfort) est le plus complet et correspond à la norme européenne. Pour un artisan, le profil Basic ou EN16931 couvre les besoins courants.

- Minimum : informations de base (identites, montant total).
- Basic : ajout des lignes de facture detaillees.
- EN16931 (Comfort) : conformité complete à la norme européenne.
- Extended : champs supplémentaires pour des cas métier spécifiques.

## Pourquoi Factur-X est adapte aux artisans

Le gros avantage de Factur-X pour un artisan, c'est qu'il garde l'aspect visuel du PDF auquel tout le monde est habitue. Vos clients voient une facture normale. En parallèle, les données structurées permettent le traitement automatique par les plateformes de dématérialisation et l'administration fiscale. Pas besoin de changer vos habitudes : votre logiciel genere le bon format en arriere-plan.

## En resume

Factur-X est le format le plus accessible pour les artisans du bâtiment : il garde l'aspect visuel du PDF tout en embarquant les données structurées exigees par la réforme. Vous n'avez pas a le créer manuellement : votre logiciel de facturation s'en charge. L'important est de vérifier que votre outil genere bien ce format avant l'échéance de 2026.

## Questions fréquentes

### Quelle est la différence entre Factur-X et un PDF classique ?

Un PDF classique est juste une image de la facture. Factur-X est un PDF qui contient en plus un fichier XML avec toutes les données structurées, lisibles par les logiciels.

### Mon client peut-il lire une facture Factur-X comme un PDF normal ?

Oui. Visuellement, une facture Factur-X s'ouvre et se lit exactement comme un PDF classique. Le fichier XML est embarque en pièce jointe invisible pour l'utilisateur.

### Factur-X est-il le seul format accepte en France ?

Non. Trois formats sont acceptes : Factur-X (PDF + XML embarque), UBL 2.1 (XML pur) et CII (XML pur). Factur-X est le plus repandu en France car il conserve l'aspect visuel du PDF.

### Faut-il payer pour générer des factures au format Factur-X ?

Le format Factur-X est un standard ouvert et gratuit. Le coût reside dans le logiciel de facturation qui genere ce format. De nombreuses solutions l'incluent dans leur abonnement standard.

### Un comptable peut-il traiter une facture Factur-X automatiquement ?

Oui, c'est l'un des principaux avantages. Le XML embarque permet aux logiciels comptables d'importer les données sans ressaisie manuelle, ce qui réduit les erreurs et le temps de traitement.

## Comment générer des factures Factur-X

Vous n'avez pas à créer les fichiers XML manuellement. Un logiciel de facturation compatible genere automatiquement le PDF avec le XML embarque. Vérifiez simplement que votre outil mentionne la compatibilité Factur-X ou la norme EN16931. Lors de l'envoi via une PDP, le format est verifie automatiquement.
