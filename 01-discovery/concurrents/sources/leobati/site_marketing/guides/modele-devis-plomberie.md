# Modèle devis plomberie: une structure simple pour chiffrer plus vite

Un bon devis plomberie doit être rapide à préparer, clair pour le client et suffisamment détaillé pour protéger votre marge.

À retenir

- Structurez toujours prestation, quantités, prix et conditions.
- Gardez une base de postes récurrents.
- Un devis lisible réduit les échanges improductifs.

## Les rubriques indispensables

Identifiez clairement le client, le chantier, la description des travaux, les quantités, le prix unitaire, la TVA et les conditions.

## Construire une bibliothèque de postes

Les artisans les plus rapides s'appuient sur une bibliothèque de lignes déjà relues et cohérentes.

- Dépose et pose
- Fournitures récurrentes
- Déplacements
