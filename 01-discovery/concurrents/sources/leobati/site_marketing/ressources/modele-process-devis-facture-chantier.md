# Modèle de process devis facture chantier: une base simple pour aligner bureau et terrain

Cette ressource sert de trame simple pour les équipes qui veulent poser un process clair avant de le mettre dans un outil.

À retenir

- Le process doit rester assez court pour être applique.
- Chaque étape doit produire un statut visible.
- Le lien avec le paiement doit être pense dès le début.

## Les étapes minimales

Le process type couvre la qualification, le devis, la validation, l'acompte ou la situation, la facture finale et le règlement.

- Qualification
- Devis
- Validation
- Facturation
- Paiement

## Les points de rupture fréquents

Les ruptures viennent souvent d'un manque de statut, d'un document absent ou d'une information non rattachée au bon dossier.

- Document introuvable
- Statut flou
- Relance oubliée
