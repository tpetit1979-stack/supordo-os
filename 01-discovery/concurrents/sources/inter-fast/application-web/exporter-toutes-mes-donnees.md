# Exporter toutes mes Données

InterFast propose aux utilisateurs plusieurs types d'export depuis l'application web :

- Export des [Clients / Prospects / Fournisseurs](https://help.inter-fast.co/fr/articles/10253956-exporter-mon-fichier-clients) (CRM)
- Export des [Devis](https://help.inter-fast.co/fr/articles/10253855-comprendre-le-tableau-des-devis) / [Factures](https://help.inter-fast.co/fr/articles/12746923-exporter-ses-factures-client) / [Avoirs clients](https://help.inter-fast.co/fr/articles/10937993-comprendre-le-tableau-des-avoirs-clients) / [Paiements](https://help.inter-fast.co/fr/articles/12702500-exporter-ses-paiements) (Ventes)
- Export des [Commandes](https://help.inter-fast.co/fr/articles/11560415-utiliser-les-commandes-v2-app-web#h_903fdce205) / [Factures fournisseurs](https://help.inter-fast.co/fr/articles/12752458-exporter-ses-factures-fournisseur) (Dépenses)
- Export des [Articles](https://help.inter-fast.co/fr/articles/10253907-exporter-ma-base-d-articles) (Bibliothèque)
- Export des [Produits](https://help.inter-fast.co/fr/articles/10254009-gerer-les-stocks-app-web#h_379643b8c2) (Stock)
- Export des [Feuilles de temps](https://help.inter-fast.co/fr/articles/10253906-utiliser-les-feuilles-de-temps-app-web#h_60150d8d66) (Équipe)

Toutefois, à l'occasion d'un audit annuel ou d'une migration vers un autre logiciel, vous pouvez [contacter notre équipe Care](https://help.inter-fast.co/fr/articles/12701326-contacter-l-equipe-care) pour obtenir l'export complet de vos données.
​

L'export complet des données requiert **une procédure sécurisée** et **une maîtrise des tableurs** pour en assurer l'exploitation.

> *❌   Il n'est pas recommandé de recourir à l'export complet pour conserver une archive sur son ordinateur personnel. Vos données sont plus en sécurité sur nos serveurs AWS qui en assurent une double copie et une actualisation constante.*
> ​
> ​*Pour plus d'informations, consultez notre page dédiée à la [Sécurité de vos données](https://inter-fast.fr/interfast/securite-donnees).*
> *InterFast ne saurait être tenue pour responsable de l'utilisation effectuée des données exportées, ni de leur compromission auprès d'un tiers non autorisé.*


​*NB. Notre assistance se limite à la fourniture de l'export et notre équipe Care ne  pourra pas réaliser l'analyse de données à votre place. Nous restons toutefois disponibles pour répondre à vos questions, sur la base des fichiers et captures d'écran transmis par vos soins.*

## I. Demander l'export sécurisé

L'export complet contient des données très sensibles sur l'entreprise.
Il n'est donc pas accessible en libre-service pour les utilisateurs.

**     1. Initier la demande via le Tchat**

- Connectez-vous à votre compte InterFast.
- Ouvrez le tchat en ligne (*"Support en ligne"* en bas à droite) et demandez un **export complet des données**.
- **Indiquez l'email** sur lequel vous souhaitez recevoir le lien de téléchargement

> **⚠️ Condition impérative :** vous devez certifier être le **Propriétaire** du compte entreprise. Seul ce rôle est habilité à recevoir l'export complet des données *(cf. notre [tableau des rôles utilisateur](https://help.inter-fast.co/fr/articles/10253779-comprendre-les-roles-utilisateurs))*.
> ​
> ​*Assurez-vous que l'adresse email valide et confidentielle.*

## II. Réception de l'archive

Une fois l'export généré par nos serveurs, le processus de récupération est strictement encadré pour garantir la sécurité des données.

**     1. L'email de notification**

- Vous recevrez un email automatique contenant un lien de téléchargement valable pour une durée limitée.

![](https://downloads.intercomcdn.com/i/o/tarury57/1846490144/b2c9ca14567dccbaeba39f5dcb12/image.png?expires=1788618600&signature=22bdfeae4b32bf36fcbbfb43dd870d0f1497001e8236fc039149f8ded9859479&req=dSgjEM13nYBbXfMW1HO4zSet1aLWQ09GN1P1Uu6G1l2HD7c9oMCFGcpNlf%2Bk%0AfoiV%0A)

**     2. Le téléchargement sécurisé**

- Cliquez sur le bouton "**Télécharger l'archive"**.

> ⚠️ Vous devez impérativement être connecté à InterFast sur votre navigateur avec **le même compte utilisateur** que celui qui a fait la demande *(dans notre exemple [victor@kitchy.fr](mailto:victor@kitchy.fr))*.
> Si vous essayez de télécharger le lien avec un autre compte *(ou sans être connecté)*, le système bloquera l'accès par sécurité avec une Erreur 404 lorsque vous cliquerez sur le bouton "**Télécharger l'archive"**.
> 
> ​*Le lien de téléchargement ne peut donc pas être partagé.*

**     3. L'archive ZIP**

- Si le serveur accepte la requête de téléchargement, vous obtiendrez un dossier compressé .zip.

![](https://downloads.intercomcdn.com/i/o/tarury57/1846514155/8f0c622da66e033af50579632eaf/image.png?expires=1788618600&signature=900cee83177d3569bbc391bf6ba75482d33e4edea04165c4286360287aaef94e&req=dSgjEMx%2FmYBaXPMW1HO4zTWlPRcRtGPJ7H8LBuTDNVTq%2BF2nHC4MaTWLfHDQ%0AiYPV%0A)

> ✅ Pour les utilisateurs Windows, utilisez un logiciel comme [7-Zip](https://www.7-zip.org/) pour ouvrir l'archive sans erreur et extraire ses composants. Les utilisateurs Mac OS peuvent utiliser l'outil par défaut de leur ordinateur.

## III. Structure et Exploitation des données 

L'archive contient toutes vos données "brutes" au format CSV.

Les fichiers reprennent la structure réelle de votre base de données, laquelle est plus complexe que l'affichage utilisateur sur l'application web ou mobile.

1. **Le contenu de l'archive**
- Vous trouverez une multitude de fichiers CSV (CRM-Clients.csv, Interventions.csv, Ventes-Factures.csv, etc.).

![](https://downloads.intercomcdn.com/i/o/tarury57/1846525330/6e7ff16672f6259ab2164ced8c69/image.png?expires=1788618600&signature=9985370770e12b1e39ee7200d82c3e606e9a8b80cb14d8b59a41e87fd44049f5&req=dSgjEMx8mIJcWfMW1HO4zRdxedPyrIpKVxwFXzOPW%2FNGyWr6QtVPJjKFPgxA%0AN1Zs%0A)

Chaque fichier correspond à une table de données différente :
![](https://downloads.intercomcdn.com/i/o/tarury57/1846525177/999cb6730ac639a1603b604a5f51/image.png?expires=1788618600&signature=2f9b4dce98c64a356b5e5485027ca09d3d70ee691c97b35e7e0bf31427e65dc8&req=dSgjEMx8mIBYXvMW1HO4zfLvfON71yOaUeb7yAQpTW4sgeq863dlct%2BmDDXv%0AiA%2Bz%0A)
*Exemple - Interventions.csv*
2. **Comprendre la structure relationnelle**
- Ces fichiers fonctionnent comme une base de données relationnelle. Ils sont liés entre eux par des **identifiants uniques (ID)**.
- *Exemple :* Dans le fichier des **Interventions** (Interventions.csv), vous ne verrez pas directement le nom du technicien, mais son primaryTechnicianId (ex: 2828).
​
![](https://downloads.intercomcdn.com/i/o/tarury57/1846525810/c183e78cfd8112d2f59674ebb11c/image.png?expires=1788618600&signature=88c5d5a7579f18613f7eb4218b146c3f8ca88cfd067151b1b45b3bee4b9810fd&req=dSgjEMx8mIleWfMW1HO4zXniS5MlAANRlqJujeHLOl%2BuMX586Gy2vtPhS4ZM%0AO0%2FO%0A)
*Exemple - Interventions.csv*
3. **Croiser les données (RechercheV / VLOOKUP)**
- Pour rendre les données lisibles, vous devrez utiliser Excel ou Google Sheets.
- Ouvrez dans chaque sous-feuille les fichiers nécessaires au croisement des données (ex: Interventions.csv et Config-Utilisateurs.csv)

En effet, dans le présent exemple, le fichier Config-Utilisateurs.csv contient toutes les informations sur l'ID technicien 2828 (ici, "Victor Vivès").

![](https://downloads.intercomcdn.com/i/o/tarury57/1846528687/25e7ac69e8647d9c0b3f29a241b2/image.png?expires=1788618600&signature=cf75b0bfd20ce50237a81e3afba8d07f79e88e7c277d0d0c66d1519fd5d31871&req=dSgjEMx8lYdXXvMW1HO4zVK6NuVMUP5%2Fd%2BL2OzOKioHpPnN0L6R2rAIvOqeq%0ACaey%0A)
- Utilisez la fonction **RECHERCHEV** (ou VLOOKUP) pour remplacer automatiquement les IDs par les noms / informations correspondants dans vos tableaux d'analyse.

> ✅ Vous trouverez ci-joint les tutoriels d'utilisation de la fonction **RECHERCHEV**
