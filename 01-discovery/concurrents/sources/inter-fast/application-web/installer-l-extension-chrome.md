# Installer l'extension Chrome

> 💡 Notre extension Chrome est là pour vous simplifier la vie ! Imaginez une bibliothèque avec plus de 5 millions d'articles à votre disposition. Elle vous permet d'ajouter des articles directement depuis les sites de vos fournisseurs. En un seul clic, vous intégrez ces données dans vos devis et factures, vous faisant ainsi gagner un temps précieux.

## III. Installer l'extension

Afin de bénéficier l'extension Chrome : 

1. Ouvrez la page de l'extension depuis [le magasin d'extensions Chrome](https://chromewebstore.google.com/detail/interfast/jgbfamafechiafmoljlcbhnbhhcmbmkb?hl=fr)
2. Cliquez sur **Ajouter à Google Chrome**
3. Validez en cliquant **Ajouter l'extension**

## IV. Comment ça fonctionne ?

### A. Sélectionnez un article sur le site fournisseur

Rendez-vous sur le site d'un [des fournisseurs supportés](#h_9919f30b49) et cliquez sur le bouton Ajouter à InterFast. L'article sélectionné est ainsi ajouté à votre panier InterFast que vous pouvez consultez en cliquant sur l'icône de extension. 

![](https://downloads.intercomcdn.com/i/o/tarury57/1319701279/bf1068a213d6c0cd04edd477c507/Capture-2025-01-03+at+08_17_35.gif?expires=1788618600&signature=69a7b639227be9cd37d3af69f6aaa163065de503b9b50b4dc2498e14d6d78d22&req=dSMmH85%2BnINYUPMW1HO4zVz9NHRCxEtx2f4jEEW6AnMVA%2FKKs%2BupdHK1t2Ux%0AI4VMNa6Xf2gF69AfMSo%3D%0A)

 
Si vous voyez apparaître un message d’erreur comme « impossible d’importer la sélection » ou si l’article ne s’ajoute pas à l’extension, vous pouvez :

- Rafraîchir la page de votre navigateur
- Vider les articles présents en cliquant sur ce bouton :
​

![](https://downloads.intercomcdn.com/i/o/tarury57/1875082156/86024218c0ab4e6b60ed06f50522/Google+Chrome+2025-12-10+09_38_22.png?expires=1788618600&signature=5c17bbda088586827e160477a8c5bf05c17dba62e22df365890840b5badaa2cf&req=dSggE8l2n4BaX%2FMW1HO4zbyV4OSqDYlV8VWhnpuMi%2Fo0QQSKzj1vOfF4a8Bl%0A5XTFkMECAZ2D0tOvVVw%3D%0A)


Après un certain temps, il est possible que certains articles du panier « périment ». Cela pourrait expliquer l’erreur lors de certains ajouts.

> 💡 Vous pouvez sélectionner plusieurs articles depuis les sites de vos fournisseurs et retourner sur InterFast une fois que vous avez terminé votre sélection d'articles.

### B. Importez les articles sélectionnés sur votre devis

Une fois votre sélection d'articles terminée, c'est le moment de les intégrer dans votre devis !

Pour cela, ouvrez l'éditeur d'un devis puis cliquez sur le bouton  pour importer les sélectionnés à la fin de votre devis.

![](https://downloads.intercomcdn.com/i/o/tarury57/1319706101/4745843f9b4d4a06b0fde843eea2/Capture-2025-01-03+at+08_25_23.gif?expires=1788618600&signature=b505a60ec4b59a7bfb102799dfefadc1e5e7c338118c4cf003c55bb219e16d12&req=dSMmH85%2Bm4BfWPMW1HO4zR2rTvOs1w0uCCvUXDgu2t%2BoZjmUD%2BS29aY7Th6V%0ApFVOcP7YpEIuApI3Xmw%3D%0A)

> ✅ Vos articles sélectionnés sont importés dans votre devis avec leur désignation, une photo, des prix d'achat et de vente ! Pour configurer, le taux de marge appliqué par défaut, rendez-vous dans la section suivante !

### **C. Importez les articles directement dans votre Bibliothèque**

Vous n'avez pas de devis en cours mais vous souhaitez tout de même enrichir votre base de données ? Il est désormais possible d'envoyer vos trouvailles directement dans votre Bibliothèque InterFast !

1. Rendez-vous sur le site de votre fournisseur partenaire et constituez votre panier en cliquant sur **Ajouter à InterFast** pour chaque article.
2. Ouvrez l'application web InterFast, et naviguez dans **Outils > Bibliothèque**.
3. En haut à droite de votre écran, un nouveau bouton **Importer la sélection** est apparu. Cliquez dessus !
​
![](https://downloads.intercomcdn.com/i/o/tarury57/2192317094/630356bd709155cd11091dfab9b6/Extension+bibliotheque.png?expires=1788618600&signature=bf8280195fff2f3341b283c3a8a37caa3fe43efe216d274ffba4482eb1b8423a&req=diEuFMp%2FmoFWXfMW1HO4zcu7yoi36I3eHivvF9M%2FqAVmf0Z0LuNGlQFuXGhX%0ArFfL%0A)

​
4. Vos articles sont instantanément créés dans votre bibliothèque, complets avec leur désignation, leur photo, ainsi que leurs prix d'achat et de vente.

![](https://downloads.intercomcdn.com/i/o/tarury57/2192318465/3e101f9b25986206628ebcad2d02/Extension+bibliotheque+2.png?expires=1788618600&signature=06673c881ced97d60f5ca76f3fd6eab2607f7113333094dc5fa6ea5efcb676e0&req=diEuFMp%2FlYVZXPMW1HO4zRodmetmsuJ%2FnVgozvW%2Br4U6pZp7jn9ck997Fg0Q%0An1qIBINiwO8O000b1ys%3D%0A)

## V. Personnalisez les options de l'extension

Les options de l'extension vous permettent de configurer la manière dont vos articles sont importés dans votre devis : 

- Marge par défaut : le taux de marge à appliquer sur le prix de votre fournisseur lors de l'import de l'article pour déterminer le prix de vente
- Le prix des articles à importer est TTC : par défaut les prix identifiés sur les sites de vos fournisseurs sont considérés comme étant des prix HT. Pour changer ce comportement, cochez la case

![](https://downloads.intercomcdn.com/i/o/tarury57/1319708770/d532fac8bb58be17fc5c41d3571f/Capture-2025-01-03+at+08_29_41.gif?expires=1788618600&signature=c5211c12c2c973d3f15f86f5c5c8fc17ce5b8fc8a9412a531ae1f0ab9590c6e6&req=dSMmH85%2BlYZYWfMW1HO4zTFVV4LNG03ZcAZqYtlfFbfbux7WWarrlXnsN12J%0A6eGoEUO%2BRG3gj76UtKk%3D%0A)

## VII. **Questions Fréquentes (FAQ)**


Lors de la première installation de l’extension Chrome, il est possible que le bouton **« Ajouter à InterFast »** ne s’affiche pas immédiatement sur le site du fournisseur.

Rechargez simplement la page du site fournisseur après l’installation de l’extension.
Dans la majorité des cas, le bouton apparaît après ce rafraîchissement.


Il peut arriver qu’un article ne soit pas visible ou ne s’ajoute pas correctement dans l’extension Chrome, notamment si des articles sont déjà présents dans le panier depuis un certain temps.
1. Ouvrez l’extension InterFast
2. Videz le panier de l’extension
3. Rechargez la page du site fournisseur
4. Essayez à nouveau d’ajouter l’article

Cette manipulation permet de résoudre la majorité des problèmes d’ajout d’articles.


Si le site du fournisseur que vous souhaitez utiliser n’apparaît pas dans la liste des fournisseurs compatibles avec l’extension Chrome InterFast, il n’est pas possible de l’ajouter manuellement.

Dans ce cas, vous pouvez **contacter l’équipe InterFast** depuis le tchat en ligne afin de demander le référencement d'un nouveau site marchand. 

Une fois la demande transmise, nous pourrons analyser la compatibilité du site avec l'extension Chrome l’ajouter à la liste des fournisseurs supportés.

Après l’ajout du site marchand, pensez à recharger la page de votre navigateur pour faire apparaître le bouton **« Ajouter à InterFast »** aux côtés des articles.
