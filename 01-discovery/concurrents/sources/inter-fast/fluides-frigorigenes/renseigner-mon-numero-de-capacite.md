# Renseigner mon numéro de capacité

## Qu'est-ce que le numéro de capacité

Le numéro de capacité est un numéro qui est attribué à chaque entreprise qui obtient l'attestation de capacité pour les fluides frigorigènes. Ce numéro est obligatoire pour toute entreprise qui souhaite acheter, manipuler, utiliser ou vendre des fluides frigorigènes. 

Le numéro de capacité est délivré par un organisme agréé par le Ministère de la Transition Écologique et Solidaire. Il est valable pour une durée de 5 ans et doit être renouvelé à l'expiration de cette période.

## Comment remplir le numéro de capacité automatiquement

Il vous faut aller dans le module **Mon entreprise** puis cliquer sur l'onglet **Description**. : 

- Descendez dans la page jusqu'à l'encadré *Informations* de votre entreprise
- Éditez les informations en cliquant sur l'icône d'édition
- Remplissez le numéro de capacité dans le champ correspondant.
