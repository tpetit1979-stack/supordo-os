# Exporter mes Interventions

> 🔔 Besoin d'extraire votre historique d'interventions pour une analyse sur Excel ou pour archiver vos rapports en masse ? InterFast vous permet d'exporter vos données directement depuis votre calendrier.

## I. Accéder à la liste des interventions

Pour retrouver les options d'export, vous devez vous placer sur la vue en liste de vos opérations :

- Rendez-vous dans le menu **Calendrier** (ou **Opérations**).
- Cliquez sur l'onglet **Liste** en haut de l'écran.
- En bas de cette page, à côté du bouton "Personnaliser", vous trouverez désormais deux options : **Exporter CSV** et **Exporter PDF**.

## II. Exporter les données (Format CSV)

L'export CSV est idéal pour suivre vos statistiques, filtrer vos données sur Excel ou analyser les temps passés.

- Cliquez sur **Exporter CSV**.
- Une fenêtre surgissante apparaît : sélectionnez la **plage de dates** souhaitée (ex: "Mois dernier" ou une période personnalisée).
- Cliquez sur le bouton bleu **Exporter**.

![](https://downloads.intercomcdn.com/i/o/tarury57/2126329423/e65b3d3bcf007f50ee45fd99c4da/CleanShot+2026-03-04+at+08_48_48%402x.png?expires=1788618600&signature=797f952f9ef0fbfaacc7b446e3963f886399beeee591bd6aaa0d3308bf1ccdf3&req=diElEMp8lIVdWvMW1HO4zWlKbH9xM6gFKJmJ4iJllGOF58K4obkjcasXpVz6%0AhsJtiTg70nwDOafEGW8%3D%0A)

## III. Exporter les rapports (Format PDF)

Si vous souhaitez récupérer les documents PDF complets de vos interventions (comptes-rendus signés, photos, etc.) en une seule fois :

- Cliquez sur **Exporter PDF**.
- Choisissez votre période.
- Cliquez sur **Exporter**. Le système va générer une archive compressée (ZIP) contenant tous vos rapports.

![](https://downloads.intercomcdn.com/i/o/tarury57/2126331508/e4daf461b57c180e01116576e522/CleanShot+2026-03-04+at+08_40_56%402x.png?expires=1788618600&signature=9feeec4c65ddabe4ec34ac9e0f575acb8af60012b6c00a4ce5e847101a71f856&req=diElEMp9nIRfUfMW1HO4zZeQIeIVC7F8yuhWeS0DSxG4IXRPeMwMXxXAy4zD%0A09Yd%2BgzwDEoqSN21S7g%3D%0A)

## IV. Récupérer vos fichiers

Une fois l'export lancé, le traitement s'effectue en arrière-plan pour ne pas bloquer votre travail.

- Une notification apparaît dans l'icône de téléchargement (en haut de l'écran).
- Cliquez sur **Télécharger** pour enregistrer le fichier sur votre ordinateur.

## VI. Télécharger tous les rapports d'une intervention en un seul PDF

💡 Si votre intervention comporte plusieurs documents (rapport principal, sous-rapports, CERFA, documents complémentaires…), vous pouvez désormais les regrouper dans un seul fichier PDF. 

Cette fonctionnalité est particulièrement pratique pour transmettre un dossier complet à un client, un partenaire. 

### Comment télécharger un PDF unique

1. Ouvrez l'intervention concernée.
2. Rendez-vous dans l'onglet **Documents**.
3. Cliquez sur le bouton **Télécharger en un seul PDF**.

![](https://downloads.intercomcdn.com/i/o/tarury57/2511007152/41182d40412d13e9e203ffc1fc6f/CleanShot+2026-06-30+at+09_52_54%402x.png?expires=1788618600&signature=0000c1dcfe7a8d9ee5ba043d6d398515fb8807d5e591101c00c66a2942ce280a&req=diUmF8l%2BmoBaW%2FMW1HO4zeXpSt4TXaUQIaSHzvsIoaGyBETYZqUZStM86%2FPy%0A8E%2FhSrW79EErxUT3Pz8%3D%0A)

InterFast génère automatiquement un document PDF unique regroupant tous les documents associés à l'intervention.

> ℹ️ **À noter :** Lors de cet export, InterFast fusionne automatiquement tous les documents générés depuis l'application (rapport d'intervention, sous-rapports, CERFA, etc.) dans un seul fichier PDF. En revanche, les fichiers ajoutés manuellement dans la section **Autres documents** ne sont pas intégrés à cet export et devront être téléchargés séparément si vous souhaitez les transmettre.

## En résumé : Une donnée exploitable en toute liberté

L’exportation de vos interventions est le meilleur moyen de garder la main sur votre activité. Que ce soit pour effectuer des statistiques poussées sur Excel via le **CSV** ou pour transmettre un dossier complet de rapports d'interventions en **PDF** à un client, vous disposez de toute la souplesse nécessaire pour traiter vos informations hors du logiciel.
