# Utiliser les Formulaires de demande

> Les artisans n'ont pas toujours le temps de répondre immédiatement aux demandes de leurs clients. Le formulaire de demandes leur permet de récolter les informations nécessaires à leurs prochaines interventions.
> *Exemple : *
> *[https://app.inter-fast.fr/public/company/0612FA/request](https://app.inter-fast.fr/public/company/0612FA/request)*

[Vidéo YouTube](https://www.youtube.com/watch?v=D92lnwzup_4)

## I. Activer les Formulaires

A) Cliquez sur le module "Mon entreprise" > Paramètres > [Formulaire de demande. ](https://app.inter-fast.fr/dashboard/company?c=settings&settings=request-form&tab=config)

![](https://downloads.intercomcdn.com/i/o/tarury57/1850305603/dc9158cb95b16ef77ece089dbbab/CleanShot+2025-11-26+at+10_05_48%402x.png?expires=1788618600&signature=30b7be7ac026679f421777b77a2b2d7da06791d9bac29d9e9a6d66d80c103818&req=dSgiFsp%2BmIdfWvMW1HO4zaGFghgGZYHz%2ByrL4Cg5fV%2BrBl2nwojUse6ULqkh%0ArAR39CkLs1gjyHmRc6Y%3D%0A)

B) Cochez la case "Activer le formulaire de demande".

![](https://downloads.intercomcdn.com/i/o/tarury57/1422363866/874f8a5f6f38cfda9d91ce20b2a8/CleanShot+2025-03-14+at+11_34_34.png?expires=1788618600&signature=f2ce75f13fd26c2269f15d9ae4564751198915dadeb5ecf5dcaaf56f37082f2f&req=dSQlFMp4nolZX%2FMW1HO4zSatK6R1M1gwPdrOvTEgFiI0oTt31fFspvBZeOom%0AbO1TemAEyI0wF6r1GuE%3D%0A)

C) Cliquez sur le bouton "Sauvegarder"

## II. Utiliser le Formulaire par défaut

### 1) Auprès des Prospects


A) Sur l'application Web :

a) Cliquez sur le bouton "Ouvrir le formulaire"

c) Copiez le lien de la barre d'URL

![](https://downloads.intercomcdn.com/i/o/tarury57/1422372186/1e108ee3ad6b3d260d6eb43b5ae9/CleanShot+2025-03-14+at+11_40_07.png?expires=1788618600&signature=a93d4c18e85a67b0f7a76ff9be50999f8fdf38fad330e8a1b4147effde35eff0&req=dSQlFMp5n4BXX%2FMW1HO4zYvNPkr%2F0R78oh2FuO896r%2BcDRKdRCl2QZPOQmGv%0AlVKhcFx7IVZqXdLDvxM%3D%0A)

d) Partagez ce lien dans :

- vos [modèles d'email](https://app.inter-fast.fr/dashboard/company?settings=emails&tab=settings)
- vos modèles de SMS (selon votre smartphone)

Le formulaire est conçu pour que les prospects puissent renseigner toutes les informations nécessaires à la planification d'une intervention dans votre Calendrier :

![](https://downloads.intercomcdn.com/i/o/tarury57/1422382118/a8bc8684ed7db814168c858ca833/CleanShot+2025-03-14+at+11_46_09.png?expires=1788618600&signature=83ffbda34d25e2c35f4c3a3fdfb574b7ad5b604f5ff438f7bce7cd831293a552&req=dSQlFMp2n4BeUfMW1HO4zfh5vUdO0t2PxxYUYQvjLncXUKz2Xdgd0TW8s3wN%0A1WblCECU3JUga%2FI25Ic%3D%0A)

Une fois le formulaire rempli, les demandes apparaîtront dans la vue "[Timeline](https://app.inter-fast.fr/dashboard/interventions?events=%7B%22pageIndex%22%3A0%7D&tab=timeline)" de votre Calendrier :

![](https://downloads.intercomcdn.com/i/o/tarury57/1422389621/e5ba1920d87eafee162fd0b66e70/CleanShot%2B2025-03-14%2Bat%2B11_49_55.png?expires=1788618600&signature=55dcf65bb487e1f1f8c387b4b191d0491983519805322fb14c7e7e69ad799967&req=dSQlFMp2lIddWPMW1HO4zWkl9B3x9JWd%2Fi2rMjYw2nut31DBddIfqh9XeXSg%0AvdNGZo9eeXyNh2O96ds%3D%0A)


Vous pourrez ainsi :

- accepter la demande en planifiant l'intervention dans votre agenda

![](https://downloads.intercomcdn.com/i/o/tarury57/1422392017/88ef2f845865ee1515181a028983/CleanShot+2025-03-14+at+11_51_42.png?expires=1788618600&signature=aa254f47cf5724cfd8c51ea6a2b20379c39c84e9443ea49b2b23ed4e3a0a775d&req=dSQlFMp3n4FeXvMW1HO4zaljS6WhefyodwKpOYv7cr9oNZE6M0R%2BHDReNg%2Bs%0A%2B3A9%0A)

ou
- clôturer la demande en refusant la demande d'intervention
​
![](https://downloads.intercomcdn.com/i/o/tarury57/1422393885/7189e91d56a1e50274bb3241af6a/CleanShot+2025-03-14+at+11_52_19.png?expires=1788618600&signature=9f442ce1f699dad59346fa0bce1a9a0b92450c5aca80de9a63c18491f6b9d830&req=dSQlFMp3nolXXPMW1HO4zX31De9pRDDJXGmdyweFPWDJ22%2F8Bzw5CLX%2FWEHG%0AlDO9%0A)

Dans l'hypothèse où vous accepteriez la demande d'intervention, InterFast vous proposera :

- de créer un nouveau client dans le CRM
- d'associer la demande à un client existant dans le CRM
​
![](https://downloads.intercomcdn.com/i/o/tarury57/1422419536/d802619eacd11056d569f2751615/CleanShot%2B2025-03-14%2Bat%2B12_04_19.png?expires=1788618600&signature=43de00dc857dbc8bb3180c58e05dda4b116e830bb9f6ed7f7815802b9796190b&req=dSQlFM1%2FlIRcX%2FMW1HO4zQ9IqTpsoNA2%2Fe8t40GudasBQVUhl7%2BLtol%2FFzqH%0ATqKx%0A)

## III. Personnaliser les Formulaires

En complément du formulaire de demande par défaut, vous pouvez désormais créer un ou plusieurs formulaires personnalisés.

### 1) Créer un formulaire personnalisé 


- Cliquez sur le bouton bleu "Ajouter un formulaire"

![](https://downloads.intercomcdn.com/i/o/tarury57/1850312407/48eef506104dbe4563e354541101/CleanShot+2025-11-26+at+10_09_35%402x.png?expires=1788618600&signature=6930f55fb2466459e33b019640e69085842a67b1735610a1be86b3e4e2db7ada&req=dSgiFsp%2Fn4VfXvMW1HO4zUSo39iP74ZP2MK0YTV9%2BgmeFTRRZBOucWHJVL60%0A%2B9l7NS6KHZZYr33Z1MM%3D%0A)

- Nommez votre formulaire *(ex : Dépannage En urgence)* 
​

![](https://downloads.intercomcdn.com/i/o/tarury57/1850321122/c486973bb400f20447e778421de6/CleanShot+2025-11-26+at+10_14_15%402x.png?expires=1788618600&signature=4233fb6b6caa28475b1c296d0a5d4cf4dd78d1acb4af65939237a46202e1ba7e&req=dSgiFsp8nIBdW%2FMW1HO4zU9E1Gm25D59EyK8KqJ0ta%2Bk2za%2FTI6tCDelU%2F3O%0AnA0CrlPYbnpi4px1J30%3D%0A)

###  

- Ajoutez les composants de votre formulaire

Une fois votre formulaire créé et nommé, vous pouvez définir de nouveaux champs 

Les types de champ disponibles sont : 

- Texte court
- Texte long
- Email
- Téléphone
- Liste déroulante (sélection unique)
- Liste déroulante (sélections multiples)
- Case à cocher

## III. Questions Fréquentes

Vous pouvez récupérer le lien public dans *Paramètres > Général > Interventions > [Formulaires de demande](https://app.inter-fast.fr/dashboard/company?c=settings&settings=request-form)*. 

Pour l'intégrer visuellement sur votre site, vous pouvez utiliser une "iframe" avec le code suivant : <iframe src="VOTRE_LIEN_PUBLIC"></iframe>. Cela permettra à vos clients de saisir leurs demandes qui arriveront directement dans l'onglet "[Timeline](https://app.inter-fast.fr/dashboard/interventions?events=%7B%22pageIndex%22%3A0%7D&tab=timeline)" de votre Calendrier.



Voilà, vous maîtrisez désormais les formulaires de demandes.
Vous êtes prêt à récolter toutes les informations pour vos futures interventions ! 🥳
