# Consulter et utiliser le fil d'activité du chantier

> ℹ️ Disponible à partir de l’abonnement **Pro**.
> Le **fil du chantier est actuellement en bêta**.

Le **fil du chantier** permet de centraliser les échanges et les principales activités liées à un chantier.

Accessible directement depuis la fiche du chantier, il permet à toutes les personnes ayant accès au chantier de **communiquer, partager des fichiers et suivre en temps réel les interventions**.

Il est disponible sur **Web et sur l'application mobile**.

## 1. Accéder au fil du chantier

> ⚠️ **Activation préalable nécessaire**
> Bien que la fonctionnalité soit disponible à partir de l'abonnement Pro, l'accès au fil du chantier en version bêta nécessite une **activation préalable par l'équipe support**. Contactez votre [support client](https://help.inter-fast.co/fr/articles/12701326-contacter-l-equipe-care) pour demander son activation sur votre compte avant de pouvoir l'utiliser.

Depuis la fiche d'un chantier, le **Fil du chantier** est accessible directement sur la partie droite de l'écran sur la version Web.

Sur mobile, vous pouvez également accéder au fil depuis la fiche du chantier, via l'icône de conversation.

## 2. Suivre l'activité du chantier en temps réel

Le fil permet de retrouver les différentes activités liées au chantier, de la plus ancienne à la plus récente.

Les informations apparaissent **en temps réel**, sans avoir besoin de recharger la page.

Vous pouvez notamment retrouver :

- les **messages échangés**
- les **interventions créées** depuis le chantier
- les **interventions terminées**
- les informations liées aux **rapports d'intervention réalisés**
- les **photos et fichiers envoyés directement dans le fil**.

Par exemple, lorsqu'une intervention est créée depuis le chantier, une activité est automatiquement ajoutée :

**IN00251 · Intervention « Installation d'une pompe » créée · 15:18**

Puis, lorsque l'intervention est terminée :

**IN00251 · Intervention « Installation d'une pompe » terminée par Kevin Saint Fort · 15:37**

![](https://downloads.intercomcdn.com/i/o/tarury57/2639553824/323b10baa70b01c2ad1759dd14d0/CleanShot+2026-08-29+at+15_37_41%402x.png?expires=1788618600&signature=cefeeb1d84e9f79874a0fd58a652c31041e85432c277cfdacb8b7b7d76b41293&req=diYkH8x7noldXfMW1HO4zZVEa0zVB8gkZhcDmGreTU7b2sqee8X%2BacysoN2%2B%0AwW57TMZ1QB1NSrsCOVA%3D%0A)

> ℹ️ Le fil ne remonte pas automatiquement toutes les actions réalisées sur un chantier.
> La **création d'un devis ou d'une facture**, par exemple, n'apparaît pas automatiquement dans le fil.
> De même, lorsqu'une intervention existante est simplement **modifiée**, cette modification n'est pas ajoutée comme nouvel événement dans le fil.

## 3. Envoyer un message à l'équipe

Le fil permet d'échanger directement avec les personnes ayant accès au chantier.

Vous pouvez par exemple :

- transmettre une consigne
- poser une question à un technicien
- signaler un problème
- partager une information importante
- suivre les échanges liés aux travaux.

Saisissez votre message dans la zone prévue à cet effet, puis cliquez sur la **flèche d'envoi**.

![](https://downloads.intercomcdn.com/i/o/tarury57/2639559217/0d19e16280c6f35b3fbd126aa08a/CleanShot+2026-08-29+at+15_52_26%402x.png?expires=1788618600&signature=92c603ab6b1bdea9e5ace0b0f5f49df50644b7793d0a367798563f9697dd8ec0&req=diYkH8x7lINeXvMW1HO4zRr1h%2FS5%2Beab%2BNZJVQQV1PKh7IN5Perq1b8cC%2BbM%0AWFDd%2BFNv93xKp%2F5AytQ%3D%0A)

A) Modifier un message envoyé

Un message envoyé dans le fil du chantier **peut être modifié ou supprimé après son envoi**.

Vous pouvez donc corriger ou supprimer un message si nécessaire.

![](https://downloads.intercomcdn.com/i/o/tarury57/2639608261/13ab386af962833e196c912ea4fa/CleanShot+2026-08-29+at+16_31_58%402x.png?expires=1788618600&signature=1cdb1c0c818577821618361eaa78cf5aa433020100f9e753c0ec102e8362c65b&req=diYkH89%2BlYNZWPMW1HO4zfBj%2FVPQFGVqod4DILzLI1ThdlKuHZwQWSLNz2cw%0AD0yrCMLB7%2B3TJGI9MSY%3D%0A)

Avant d'envoyer votre message, pensez tout de même à vérifier :

- le contenu du message
- les personnes mentionnées
- la **visibilité du message** (interne ou visible par le client).** **

> Il n'est pas possible de supprimer un fichier envoyer ou une photo envoyer

## 4. Mentionner un membre de l'équipe avec @

Le bouton **@** permet de mentionner directement un utilisateur de votre entreprise dans un message.

Cela permet d'adresser clairement une demande à une personne précise.

Par exemple :

**@Jérôme Peux-tu vérifier que le matériel nécessaire est bien disponible pour demain ?**

![](https://downloads.intercomcdn.com/i/o/tarury57/2639566159/52fe2cdeb82c9d1f3e8065781573/CleanShot+2026-08-29+at+15_58_17%402x.png?expires=1788618600&signature=3a3139c514125ac1adfcd6de0f28c11df5dd9193ede1411e971b0503780a93ef&req=diYkH8x4m4BaUPMW1HO4zfY7QggpiNusBKN8eXY0LrPR2n%2FEQRuSxQvRXe%2B4%0AB1XWMVgaDfFv10YEgyQ%3D%0A)

La mention peut être utilisée dans vos échanges pour attirer l'attention d'un intervenant ou d'un membre de l'équipe.

## 5. Choisir la visibilité du message

Avant d'envoyer un message, vous pouvez choisir s'il s'agit d'un échange **interne à l'équipe** ou d'un message **visible par le client**.

Le choix se fait grâce à l'icône **cadenas** située dans la zone de saisie.

### Message interne

Lorsque l'icône représente un **cadenas**, le message est destiné aux échanges internes.

Il est visible par les personnes de l'équipe ayant accès au chantier, mais **pas par le client**.

![](https://downloads.intercomcdn.com/i/o/tarury57/2639568848/d642d64e75575076c217d88963cb/CleanShot+2026-08-29+at+16_00_09%402x.png?expires=1788618600&signature=132f9f853bf3fda84f16616ed47e2707e3a6061f0b960fbdb430ffbe1f50a067&req=diYkH8x4lYlbUfMW1HO4zYZyxc%2BUQZ5x6BqG6yZgeSix40pEjiN2ZEDGHUPw%0AchWVyWL2d3Hpdjat%2BDU%3D%0A)

### Message visible par le client

En cliquant sur le cadenas, l'icône devient une **planète**.

Le message est alors configuré pour être **visible par le client**.

![](https://downloads.intercomcdn.com/i/o/tarury57/2639570467/dae3f2f84899db50e029dbab91aa/CleanShot+2026-08-29+at+16_01_27%402x.png?expires=1788618600&signature=7b1154b631a0e7a3b1f7c50733a75fc8d8c4a6244bb973ed5268ef0673993a1f&req=diYkH8x5nYVZXvMW1HO4zTdwc97B4Dtzr2ZdqyaA45z3B7rxFkqDPyV4NieM%0AMZuD16OikUQQMWoau30%3D%0A)

## 6. Ajouter une photo ou un fichier

Le fil permet également de partager directement des éléments utiles au suivi du chantier.

Cliquez sur l'icône **trombone** 📎 pour sélectionner un fichier depuis votre ordinateur ou votre appareil.

Vous pouvez notamment partager :

- des photos de l'installation
- des photos avant / après
- un diagnostic
- un plan
- un document technique
- tout fichier utile au suivi des travaux..

![](https://downloads.intercomcdn.com/i/o/tarury57/2639573097/518aee31ad17214e27af45f37e9d/CleanShot+2026-08-29+at+16_03_18%402x.png?expires=1788618600&signature=6b301d67adb90c2b9c2e1be2938c09a4e1b9fe5a041e04d2ead6dea7949e47f5&req=diYkH8x5noFWXvMW1HO4zaq1IklTne%2F6sLjI964iH0BBz0APv4jvaqmEXW7w%0AwyZM%0A)

Les éléments envoyés apparaissent ensuite directement dans le fil.

> ℹ️ Un fichier ou une photo envoyé(e) dans le fil **n'est pas automatiquement ajouté(e) dans l'onglet Documents du chantier**.
> Le fil et l'onglet **Documents** restent donc deux espaces distincts.

## 7. Créer une intervention depuis le fil

Le fil propose également un raccourci **Créer une intervention**.

Cela permet de créer une nouvelle intervention directement depuis la fiche du chantier, sans avoir à passer par le module Interventions.

L'intervention créée est **automatiquement rattachée au chantier**.

![](https://downloads.intercomcdn.com/i/o/tarury57/2639576248/bada8309f17bc48a48412f512c91/CleanShot+2026-08-29+at+16_05_39.gif?expires=1788618600&signature=980ec37f0125eb6e334a8c78e5e6efbbe9edb332d9a69ba68723106348d7dd96&req=diYkH8x5m4NbUfMW1HO4zcjw4pZbHW0FtuhiWPG4ZJjxR2IEladR2FuDqMBu%0A3AbsC6%2FfctFNEi%2BHhzA%3D%0A)

Elle reste ensuite accessible dans le module **Interventions** et son événement apparaît dans le fil du chantier.

## 8. Les trois raccourcis disponibles

**Photo**
Ajoutez rapidement une photo au fil.

**Fichier**
Partagez un fichier depuis votre ordinateur ou votre appareil.

**Créer une intervention**
Créez une intervention directement liée au chantier.

![](https://downloads.intercomcdn.com/i/o/tarury57/2639578223/0c813fe57f28bc6b556dbb6ab276/CleanShot+2026-08-29+at+16_07_51%402x.png?expires=1788618600&signature=d358279fa5317376c1ce9de3897d3518eaa2097e40120131344a9792447f2380&req=diYkH8x5lYNdWvMW1HO4zfPo0PYP85J%2BGn0Z27olODjSfIRJawLp6UG9gvOl%0A8pG65NzPlviHkLRBAcM%3D%0A)

Ces boutons sont simplement des **raccourcis** : ils permettent d'accéder rapidement aux actions disponibles depuis le fil.

## 9. Un fil partagé avec les personnes ayant accès au chantier

Le fil est accessible aux **personnes ayant accès au chantier**.

Il permet ainsi de conserver un espace d'échange commun entre les différents intervenants concernés.
​

Par exemple, pour un chantier d'installation d'une pompe à chaleur, le responsable du chantier et les techniciens peuvent suivre les informations au même endroit :
​

**15:18** → Intervention « Installation d'une pompe » créée.

**15:33** → Intervention « Installation 2eme partie » créée.

**15:37** → Première intervention terminée.

**15:40** → Message envoyé à l'équipe.

**15:45** → Photo de l'installation ajoutée.
​

![](https://downloads.intercomcdn.com/i/o/tarury57/2639579734/218191af18f6d4dd37d98692bc9c/CleanShot+2026-08-29+at+16_09_43%402x.png?expires=1788618600&signature=ebf856d08405feb9b159d7add5ce85bb06b9f1a34fe9597a3e5dbac250279fc5&req=diYkH8x5lIZcXfMW1HO4zR24qL1c%2FXdmDnQYe8T99xAvGDIwcPRj0GKs3gLA%0AKjlTjIBnJREZ8qcg9nQ%3D%0A)

Le fil constitue ainsi un **historique chronologique des échanges et des événements importants du chantier**.

Les équipes présentes sur le terrain peuvent donc consulter les échanges et alimenter le fil directement depuis leur téléphone.

Vous pouvez notamment :

- consulter les messages
- envoyer un message
- mentionner un membre de l'équipe
- ajouter une photo ou un fichier
- créer une intervention

## 11. Questions et problèmes fréquents

Vérifiez que le message a bien été envoyé. Le fil se met à jour en temps réel : il n’est normalement pas nécessaire de recharger la pag



Les messages sont visibles par les personnes ayant accès au chantier. 

Vérifiez également l’icône de visibilité avant l’envoi : **cadenas pour un message interne** et **planète pour un message visible par le client**.


Seules les **interventions liées au chantier** remontent automatiquement dans le fil. 

Une intervention créée depuis le fil est automatiquement rattachée au chantier.


Le fil enregistre notamment la **création et la fin d’une intervention**, mais une simple modification d’une intervention existante ne génère pas automatiquement un nouvel événement dans le fil.
​
> A savoir, il ne prend pas en compte la planification de rendez-vous dans le style de chantier
