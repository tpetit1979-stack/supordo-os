# Comprendre la fiche d'Intervention (App Web)

## I. Les actions disponibles

Ce bouton d’actions permet par exemple :

- De lier l’intervention à un chantier
- De lier l’intervention à une maintenance
- De lier l’intervention à un équipement
- De créer un devis à partir de l’intervention sélectionnée
- De créer une facture à partir de l’intervention sélectionnée
- D’archiver l’intervention
- De supprimer l'intervention

![](https://downloads.intercomcdn.com/i/o/tarury57/1997668611/a40b8a7dd8154ba4152d96ebddbc/CleanShot+2026-01-28+at+10_47_17%402x.png?expires=1788618600&signature=d620cfb99c147f2b8a882e89969d778ec5b1e11501bb716fda4e2ac08cc6f1e6&req=dSkuEc94lYdeWPMW1HO4zTh49OVuqtFW7H%2FwcOAs%2BzoM4Nyta3D9EZQWIvBF%0AnvqNtAMO3ILuWDZS%2FeY%3D%0A)

## II. L'onglet "Description"

Ici, vous pouvez consulter la description de l'intervention ainsi que tous les fichiers importés, et vous avez la possibilité d'ajouter un fichier en cliquant sur le bouton "+"

## III. **Envoyer un rapport par email**

On a ici accès à l’historique des mails envoyés pour l'intervention sélectionnée

![](https://downloads.intercomcdn.com/i/o/tarury57/1997675071/fb2cc922890f0453c07aa0db5cca/CleanShot+2026-01-28+at+10_49_52%402x.png?expires=1788618600&signature=9b5c21841fdfca20a74212bb92126c93d8f7f278e3a8351c90fc4b2c90c4b505&req=dSkuEc95mIFYWPMW1HO4zenlQiKY6MDhc1iFDyBOUs92bOWUqkPhieb8fYeJ%0Au%2BvGU7VjUnJjKo1xwMI%3D%0A)

On pourra également actualiser la page et envoyer le rapport via le bouton “Envoyer le rapport”.

![](https://downloads.intercomcdn.com/i/o/tarury57/1997677427/ebb7e60e02a914ec061294df1001/CleanShot+2026-01-28+at+10_49_52%402x.png?expires=1788618600&signature=a72208fdcfba58b36877642a0caafe43470f8118cd00f4a9836f260c49553970&req=dSkuEc95moVdXvMW1HO4zQhPaRGDCVN586bPc9K0A0WMiHWnTns%2BcZLvsoVc%0AbQQ8nCJeQZYU%2FrA8wkw%3D%0A)

Lorsque vous cliquez sur "Envoyer le rapport" un formulaire s'affichera, comprenant les éléments à renseigner pour envoyer le rapport selon vos préférences.

Une fois l'intervention terminée, vous pouvez transmettre le rapport au client directement depuis sa fiche, sans passer par votre boite mail personnelle.

1. Rendez-vous dans l'onglet **Emails** de la fiche d'intervention.

2. Cliquez sur le bouton **"Envoyer le rapport"**.

![](https://interfast.intercom-attachments-7.com/i/o/tarury57/1997805093/73dc2fe85b4d49aa5d8e4423343c/edit-alt_e9942aace693e8a49697955478a4f74c.svg?expires=1788618600&signature=d42e5e47cf307eeb7169f777c8ed50ff34186088e651f980b29b9f2012a25cfa&req=dSkuEcF%2BmIFWWvMW1HO4zRbRbEswx819N%2Fia2WpVFwNd%2FUkOI5ePdGOok0Op%0AYdmTPTFFwcswM3i21Ao%3D%0A)

3. Une fenêtre s'ouvre : le rapport PDF est automatiquement joint. Vous pouvez vérifier le destinataire et choisir un modèle d'email avant de cliquer sur **Envoyer**.

![](https://downloads.intercomcdn.com/i/o/tarury57/1997683707/2c6b59e57fd5a3ebb055adee83eb/CleanShot+2026-01-28+at+10_53_15%402x.png?expires=1788618600&signature=3a5217c4764167e4b9e60db92bcfbf031dc34b6af7fc0f2cec84c8d664c6881f&req=dSkuEc92noZfXvMW1HO4zfiV4LdRJzFqVI%2BpHu9di59mXmHOpyMUnhb9GNS0%0A8TVe49TEM0N1YcqJhVo%3D%0A)

### VII. L'onglet "Dépense"

L’onglet Dépenses regroupe l’ensemble des achats liés à l’intervention (commandes et factures fournisseurs), afin de suivre facilement les coûts matériels engagés pour chaque mission.

![](https://downloads.intercomcdn.com/i/o/tarury57/1997749833/03cff438cb0373632e708967f632/Google+Chrome+2026-01-28+11_16_37.png?expires=1788618600&signature=e5aa1551f67532f6153acd489b060f7cd25b259e87e803de327f094e014137f0&req=dSkuEc56lIlcWvMW1HO4zYxQZmW%2FpJdpM%2FDqZAql0ft%2Fr4zy72maSgMhJq5l%0AKm3aDCRGxWG5vaiifZg%3D%0A)

## VIII. **Modifier un rapport existant**

Il est possible de corriger une erreur ou d’ajouter une précision sur un rapport déjà validé (statut **Terminé**).

1. Depuis la fiche de l’intervention, survolez la ligne du rapport (ou du sous-rapport concerné).
2. Cliquez sur le bouton **Éditer** (icône crayon) qui apparaît au survol.
![](https://interfast.intercom-attachments-7.com/i/o/tarury57/1997805102/f4e6a88cda31aaf9bb769e7fef46/edit-alt_e9942aace693e8a49697955478a4f74c.svg?expires=1788618600&signature=f3cecf5b2ad30fb27d5ae9f33720c6a5ba7d6c4f760bfc4eb934309ccfb8452c&req=dSkuEcF%2BmIBfW%2FMW1HO4zXSz9aFhtYbediOOKjq545C2V7AgQ%2BtOSkbPJqgr%0Axujb%0A)
3. Un volet latéral s’ouvre et vous permet de modifier les champs nécessaires.
4. Cliquez sur **Générer le rapport** pour enregistrer la nouvelle version.

![](https://downloads.intercomcdn.com/i/o/tarury57/1997798610/1015d529d68737a465dbab945f28/CleanShot+2026-01-28+at+11_32_53.gif?expires=1788618600&signature=4c3011c21acf979edfc566c9a04ad4a51f64bdaa52379cc91d2a185c6333302f&req=dSkuEc53lYdeWfMW1HO4zfJ5A78mmjAak%2Be84FagoP0KEd9KhdcyVesDlSiP%0APwQrXCy2VDvFjSysvNw%3D%0A)

**À noter – Traçabilité :**
Si vous modifiez le rapport d’un autre intervenant, InterFast vous demandera si vous souhaitez conserver la signature originale ou la remplacer par la vôtre afin de certifier la modification.

Se rendre sur le bouton “Action”.

![](https://downloads.intercomcdn.com/i/o/tarury57/1997718139/3845aecdf0f3844088ce0227408e/CleanShot+2026-01-28+at+11_03_04%402x.png?expires=1788618600&signature=668a0327e95a19c2e2f1e9c5a7c1c57b945acd5fbf7e9e5af016f2ca2a74285f&req=dSkuEc5%2FlYBcUPMW1HO4zQvYQ89bF4pxtbhtHqkgAze8ZJ0RfBtOlNibW50s%0A4dWxU5tA644ofwQlByw%3D%0A)
