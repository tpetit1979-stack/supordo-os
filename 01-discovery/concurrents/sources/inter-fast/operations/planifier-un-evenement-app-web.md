# Planifier un Évènement (App Web)

> 🔔 La planification d’un événement qu’il s’agisse d’une intervention, d’un rendez-vous ou d’une absence, est une étape clé dans InterFast pour assurer le bon déroulement des activités. Une organisation efficace de ces moments permet non seulement de mieux gérer votre emploi du temps, mais aussi de favoriser une bonne coordination entre les équipes.
> Dans cet article, nous vous partageons les meilleures pratiques pour une planification réussie, ainsi que quelques conseils utiles pour tirer le meilleur parti des fonctionnalités disponibles dans InterFast.

La planification via le calendrier est un outil essentiel pour organiser vos activités au quotidien. Que ce soit pour une **intervention**, un **rendez-vous**, ou une **absence**, le calendrier vous offre une vue d’ensemble claire de vos engagements et vous aide à optimiser votre gestion du temps.

Voici les étapes à suivre pour une planification réussie.

## II. Planifier une intervention

Une fois que vous avez cliqué sur le bouton **« Planifier »** , vous accédez au formulaire de planification d’un événement.

![](https://downloads.intercomcdn.com/i/o/tarury57/1470648784/54c5289327e253a37f11c14233fb/CleanShot+2025-04-11+at+13_42_56%402x.png?expires=1788618600&signature=98de39ce387f3ed3e8fc44ceb0088528e192186d1426aa95a32c21c533c25254&req=dSQgFs96lYZXXfMW1HO4zUsNHL8aI3WnStynbTf9MglD6M8XzyGiIQiMmXRS%0AJCQFj5gsKGkclD4X1qI%3D%0A)

Une fenêtre** **s’ouvre alors directement dans la page. Depuis cette pop-in, vous pouvez planifier trois types d’événements :

- une **intervention**,
- un **rendez-vous**,
- ou une **absence**.

👉 Dans cette partie, nous allons nous concentrer sur la **planification d’une intervention**.

Le formulaire se compose de plusieurs champs, dont certains sont **obligatoires** pour pouvoir créer l’intervention.

**Champs obligatoires :**

- Titre de l’événement
- Type d’intervention (choisissez parmi : *dépannage, intervention, visite avant-vente, contrat de chantier, endorsement de chantier*, etc.)
- Client : vous pouvez sélectionner un client existant dans votre base CRM ou en ajouter un nouveau.
- Adresse : si le client est déjà enregistré, l’adresse s’affiche automatiquement.

![](https://downloads.intercomcdn.com/i/o/tarury57/1470657963/89c143ee8bc9b5850856e0ccfe52/CleanShot+2025-04-11+at+13_36_48%402x.png?expires=1788618600&signature=3958820cf63ff7d3808a70fd4184819cf4c7ebe8d73daba5bc93e639aceb656b&req=dSQgFs97mohZWvMW1HO4zZW7F2MAT04DJzmbMAWeT%2Bhrj64lbGggvHWNIa9h%0A%2BDYWPQ8xB7%2B66buquyM%3D%0A)

**Champs facultatifs :**

- Description de l’intervention
- Référence côté client
- Afficher la description dans le rapport (option à cocher/décocher)
- Ajouter des pièces jointes : photos, fichiers PDF, etc.
- Ajouter un contact secondaire
- Lier à un chantier ou une maintenance (ou laisser non lié)
- Planifier maintenant ou décocher pour planifier ultérieurement
- Intervenant principal et intervenants secondaires (si besoin)
- Durée estimée de l’intervention

![](https://downloads.intercomcdn.com/i/o/tarury57/1470658313/74a348da4a520cfe0c31e513057b/CleanShot+2025-04-11+at+13_48_28%402x.png?expires=1788618600&signature=09c11d3ce94f2e04a55b42a941d908d86110d671fc63ba4be13eff15e17139e3&req=dSQgFs97lYJeWvMW1HO4zUo9RLCgsPt2gmz8IbzRTna9KRkJmwE9QHuzeu17%0AEfy9TJawZ9x4DzbaLCw%3D%0A)

Une fois tous les champs nécessaires remplis (du moins toutes les informations obligatoires), cliquez sur le bouton **« Créer »** pour enregistrer et planifier l’intervention.

## A. Planifier une intervention sur plusieurs jours

Lors de la création d'une intervention, vous avez la possibilité de la planifier sur plusieurs jours. Pour cela, cliquez sur le champ date de l’intervention, puis sélectionnez les dates souhaitées.


👉 Vous pouvez choisir autant de dates que nécessaire : chaque date sélectionnée s'affichera en bleu, indiquant qu’elle est bien prise en compte.

Une fois toutes les dates sélectionnées, cliquez sur « **Créer** ».
Le système générera alors autant d'interventions que de dates sélectionnées, chacune correspondant à un jour distinct.

## III. Planifier un rendez-vous

Après avoir cliqué sur le bouton **"Planifier"**, accédez à l’onglet **"Rendez-vous"**.

Vous y trouverez le formulaire dédié à la création d’un rendez-vous. Avant de cliquer sur **"Créer"** veillez à bien renseigner toutes les informations obligatoires, à savoir :

- le titre du rendez-vous
- la ou les dates concernées (possibilité de planifier sur **plusieurs jours** en une seule fois, en sélectionnant plusieurs dates)
- l’intervenant principal
- l’adresse du rendez-vous.

![](https://downloads.intercomcdn.com/i/o/tarury57/1471084862/a62d4352e3fd4057041c82ab040c/CleanShot+2025-04-11+at+17_42_13%402x.png?expires=1788618600&signature=c6bd4e80db7c91dbbe90cbece0c51893e4d71dd69a77c2b179802c19eb630015&req=dSQgF8l2mYlZW%2FMW1HO4zefbllg8gRbKCmhU2hqcZuhW7ybEg%2BKedMqe6Ou%2B%0A2YQsyLwIMXh7KxwQuCA%3D%0A)

Des champs optionnels sont également disponibles :

- une description du rendez-vous
- la possibilité d’ajouter un intervenant secondaire
- la liaison éventuelle avec un client ou un chantier
- l’ajout de fichiers (documents, photos, etc.)

![](https://downloads.intercomcdn.com/i/o/tarury57/1471078692/a30524f77172bd3496b049e71ef0/CleanShot+2025-04-11+at+17_44_25%402x.png?expires=1788618600&signature=78a21cc4f5aa1d036d23f6c8ae8b0d121b6bf2ca7852f4cfa452142a36bb8787&req=dSQgF8l5lYdWW%2FMW1HO4zQfnGE84kcJeKo8zW5dVjM7hoB1eEC60b8pW9fk8%0AJ0o245yd6KxMH3B1yR8%3D%0A)

Une fois tous les éléments renseignés, cliquez sur **« Créer »** pour enregistrer votre rendez-vous. 

## IV. Planifier une absence

Pour planifier une absence, commencez par cliquer sur le bouton **« Planifier »**, puis accédez à l’onglet **« Absence »**.

Dans le formulaire, renseignez les informations suivantes :

- la date de l’absence (possibilité de planifier sur **plusieurs jours** en une seule fois, en sélectionnant plusieurs dates)
- l’utilisateur concerné
- le motif de l’absence
- éventuellement, des commentaires (champ facultatif)

Une fois ces éléments saisis, cliquez sur le bouton **« Créer »** pour enregistrer l’absence. 

![](https://downloads.intercomcdn.com/i/o/tarury57/1470987222/6f2137668d731631e646588dff6c/CleanShot+2025-04-11+at+16_58_36%402x.png?expires=1788618600&signature=05838c97dedb9947ef4008daa8ae89a6d9fe66ea9e45993b3476026ee3afe0c9&req=dSQgFsB2moNdW%2FMW1HO4zd3m%2B8fagM3rVsaA0wkc%2BOMQCZU3TStNn3wH5U6x%0AfVh2R2W665VElvy%2Fo7Y%3D%0A)

- sur le client
- sur ses relations
