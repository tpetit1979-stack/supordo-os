# Consulter mon Profil (App Mobile)

> ℹ️ Sur le terrain, vous avez parfois besoin d'ajuster rapidement les paramètres de votre application, de contacter l'assistance, ou même de basculer vers une autre entreprise. L'écran **« Mon Profil »** de l'application mobile a été pensé pour vous offrir un accès rapide à toutes vos actions personnelles et outils d'aide, sans avoir besoin d'ouvrir votre ordinateur.

## I. **Accéder à votre profil **

Ouvrez l'application mobile InterFast et appuyez simplement sur votre photo de profil (ou vos initiales) située en haut à droite de votre écran d'accueil. 

![](https://downloads.intercomcdn.com/i/o/tarury57/2187140705/cf9c6fb6fc54c9f0669c4b604da9/CleanShot+2026-03-21+at+16_41_36%402x.png?expires=1788619500&signature=2e6f8916a4ab485cad00c0104bc9cfa2116bfb1dcba653199049425a6451978f&req=diEvEch6nYZfXPMW1HO4zX%2BTOn6tqpcycgFd2U2D9lsQ%2Ffo7Sr%2FsXg8ZyF4Q%0A80kL66DFKgmc1S03iyA%3D%0A)

## II. **Changer votre photo de profil**

Une fois sur la page, un simple clic sur votre photo actuelle vous donne la possibilité de la modifier. 

![](https://downloads.intercomcdn.com/i/o/tarury57/2187144740/604044d7e730ea114dbae8d148ba/CleanShot+2026-03-21+at+16_43_08%402x.png?expires=1788619500&signature=850473307f058d199c43c27743da4a8244391dd0f079419060c830d9c09188a7&req=diEvEch6mYZbWfMW1HO4zTYrwvWnRfnZ6yFN6WKNPQlZ9%2FPaeN6oObe2jCGb%0Ae3tBrZEY3X8pbXFlnfI%3D%0A)

## III. **Naviguer entre vos différentes entreprises**

Si vous travaillez pour plusieurs sociétés, descendez jusqu'à la section "Autres comptes". 

![](https://downloads.intercomcdn.com/i/o/tarury57/2187150332/95c725cf6070e814f03631fd329f/CleanShot+2026-03-21+at+16_45_43%402x.png?expires=1788619500&signature=39cb003b9e31f8825cdb7db2971d2c4660da49c128d83d3026d74ebc30320586&req=diEvEch7nYJcW%2FMW1HO4ze3C%2BXZE4IwiK72z3PXF2ISW7CbyDHON%2Bg1ZDzZj%0Agm7isgovH4VETLcAZlI%3D%0A)

> Appuyez simplement sur le compte souhaité pour basculer instantanément de l'un à l'autre.

## IV. **Partager votre formulaire de demande**

Envie d'envoyer votre formulaire à un client ? 

![](https://downloads.intercomcdn.com/i/o/tarury57/2187155197/a2f726854b5f11626afad39d1a1b/CleanShot+2026-03-21+at+16_45_43%402x.png?expires=1788619500&signature=ef2da6f0b7cb9a7f42fbb1819a72bf4c3b0d95b5d3813e2ce90e9485469fc698&req=diEvEch7mIBWXvMW1HO4zWRWBghY7p95J0AaIjRxRTu2ibzWt17%2Fz4uFjCP2%0AGo%2BxbfVzDpLjyUWxN64%3D%0A)

Cliquez sur le bouton "Formulaire de demande". 

L'application copiera automatiquement votre lien de partage, prêt à être collé et envoyé par SMS ou e-mail.

> 💡 **Conseil de pro :** Ce formulaire est l'outil parfait à envoyer à un client en fin d'intervention pour qu'il puisse vous signaler un autre problème en direct, qui arrivera directement dans votre calendrier de bureau

## V. **Se former avec l'Académie Vidéo**

Appuyez sur le bouton « Je veux découvrir » pour accéder à nos vidéos de formation de l'Académie Vidéo, afin de comprendre facilement une nouvelle fonctionnalité.

![](https://downloads.intercomcdn.com/i/o/tarury57/2187158995/b2652fc821cb0ef44c0bc4813515/Discord+2026-03-21+15_55_19.png?expires=1788619500&signature=c80be15d5b4a048f46e9e88845938e484a82ed471894954f204baaa9bf948ada&req=diEvEch7lYhWXPMW1HO4zem3k1U%2Fqe6lbEvOsLnyaeOdLBogKbpmFNjrQTZU%0AflzItkrJ8g%2BhozCyK1U%3D%0A)

Vous pouvez ensuite cliquer sur « Tous les cours » pour accéder à tous les cours de l’académie d’Interfast. 

## **VI. Contacter le Support client**

Défilez l'écran vers le bas et appuyez sur le bouton "Contacter le support". 

Cela ouvrira la fenêtre de discussion avec notre agent ou notre équipe Care pour nous envoyer un message. 

![](https://downloads.intercomcdn.com/i/o/tarury57/2187165297/626e891ab1c6527bf55a2a14966a/CleanShot+2026-03-21+at+16_52_03%402x.png?expires=1788619500&signature=95bb18f4adb9273959a1018a145e14bd69d4d32ef8c733a64290afca2cbc2873&req=diEvEch4mINWXvMW1HO4zeOadfa4JZh0BBz%2BGUQ%2BgcYjYy2APKoPMkjcJ4nM%0AMbkrASmf3UrjrU8gZdI%3D%0A)

## VII. **Vider les caches ou se déconnecter**

A) Si vous souhaitez vider le cache de votre application mobile, il faut aller tout en bas de l’onglet Profil et cliquer sur « Vider le cache de l’application ». 

![](https://downloads.intercomcdn.com/i/o/tarury57/2187184578/542e821bd6f17e4c86d096193df1/CleanShot+2026-03-21+at+16_52_03%402x.png?expires=1788619500&signature=9c5653b1c8165baf6a01034dfe44f7324d0abb60562bd80dafc14eb9aef581f4&req=diEvEch2mYRYUfMW1HO4zURVn6jx57yc0kgqMbiuup6NEMPky6g%2Bd4U%2F%2F4U%2F%0AwASx8W%2BVLkqCDse715M%3D%0A)

> Il est recommandé de cliquer deux fois dessus, de quitter l'application et de revenir pour être sûr que le cache est bien vide. 

> ℹ️ L'application "mouline" ou l'écran est figé (Erreur fréquente) : Si vous rencontrez un ralentissement ou si vous ne voyez pas les dernières mises à jour (ex: vos dernières interventions n'apparaissent pas), le premier réflexe est d'utiliser le bouton "Vider les caches" depuis votre profil, puis de fermer complètement et relancer l'application. Cela forcera la re-synchronisation de vos données avec le bureau. 

B) Pour se déconnecter de l'application mobile, vous pouvez cliquer sur le bouton bleu situé tout en haut. 

![](https://downloads.intercomcdn.com/i/o/tarury57/2187171932/568cf498474235397e2deeef4925/CleanShot+2026-03-21+at+16_54_26%402x.png?expires=1788619500&signature=59291043873e906a4031ed3756c8f95641d6a710256f9ecc683faeb08c972d4a&req=diEvEch5nIhcW%2FMW1HO4zRHhakO39SlIErpIJ0S1osS5Dn5iRnDj9MH2IA2E%0AFyJmj9ThhP%2B%2BTlNUdrs%3D%0A)


​

> **ℹ️ Limites de l'application terrain :** Les actions disponibles depuis ce profil mobile sont strictement liées à l'utilisateur qui est connecté. Pour modifier les informations globales de votre entreprise (les taux de TVA, les licences de l'équipe, la facturation), vous devez vous rendre sur l'application Web depuis votre ordinateur. 

## 
VII. Conclusion 

Votre profil mobile est désormais votre meilleur allié pour paramétrer votre compte personnel, forcer la synchronisation de vos données et obtenir de l'aide en quelques clics, directement depuis vos chantiers !

## VIII. Questions Fréquentes


C'est le fonctionnement tout à fait normal du logiciel. 

Les rôles **« Technicien »** et **« Technicien + »** sont configurés pour un usage exclusif sur le terrain et **n'ont pas d'accès web sur ordinateur**. Si un collaborateur a besoin de se connecter au bureau sur PC, un administrateur doit modifier son rôle pour lui attribuer un profil supérieur comme **« Assistant »** ou **« Manager**


Par défaut, le rôle **« Technicien »** simple est limité à la vue de son propre planning pour plus de clarté. Pour lui donner l'accès au planning complet de l'équipe sur le terrain, vous devez lui attribuer le rôle **« Technicien + »** depuis la gestion d'équipe sur l'ordinateur



Si vous constatez un ralentissement ou un retard de synchronisation avec le bureau, **videz le cache de votre application**. 

**La méthode :** Ouvrez votre profil mobile (icône en haut à droite), descendez tout en bas de l'écran et cliquez sur le bouton **« Vider le cache de l'application »**
