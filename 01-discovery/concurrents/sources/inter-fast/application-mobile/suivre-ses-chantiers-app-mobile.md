# Suivre ses Chantiers (App Mobile)

> En complément, consultez notre tutoriel dédié au [suivi des Chantiers depuis l'Application web](https://help.inter-fast.co/fr/articles/10253980-creer-un-chantier-app-web).

## I. Introduction

Le module **Chantiers** de l'application mobile est conçu pour offrir une vision à 360° de vos projets directement sur le terrain. Il centralise les informations, les interventions et la documentation disponible.
​
Les techniciens peuvent ainsi être autonomes sans avoir à solliciter le bureau.

## II. Accès aux Chantiers

### A. Technicien / Stagiaire-Alternant / Sous-Traitant

> ⚠️ Par défaut, l'accès aux chantiers est restreint pour ces profils d'utilisateurs.
> Vous devez leur accorder une autorisation depuis la page Mon entreprise > Paramètres > [Chantiers](https://app.inter-fast.fr/dashboard/company?c=settings&settings=worksite), dans la section "Accès aux documents".

Pour accéder au dossier d'un chantier, les profils Technicien / Stagiaire-Alternant / Sous-Traitant peuvent uniquement consulter la fiche d'une intervention reliée.

Le titre du Chantier est cliquable :

L'utilisateur accède alors aux informations disponibles :

### B. Propriétaire / Administrateur / Manager / Commercial / Assistant

Pour accéder au dossier d'un Chantier, les profils Propriétaire / Administrateur / Manager / Commercial / Assistant peuvent consulter la fiche d'une intervention reliée.

Ils peuvent également :

1. Cliquer sur le **« Menu »** de l'application.
2. Sélectionner l'onglet **« Chantiers »**.
​
![](https://downloads.intercomcdn.com/i/o/tarury57/1828892872/c58bab0964a534975e5c94059217/image.png?expires=1788619500&signature=0ab6c9fe6c892be1b29d19eeef21c9cfd2c7a171bc89e2ac8e7030f4c2dd5c28&req=dSglHsF3n4lYW%2FMW1HO4zbC5%2BrwhpbCgZiXBF%2Bic6sQwF9StVHfgjtB%2FD2ZN%0Afz9b%0A)
3. **Navigation par statut :** l'écran d'accueil trie vos chantiers en trois statuts pour faciliter votre recherche : **« Non commencé »**, **« En cours »** et **« Terminé »**.

![](https://downloads.intercomcdn.com/i/o/tarury57/1828895134/634eacb69f4d32ec587aab0f5ef0/image.png?expires=1788619500&signature=9f156ce242141a7f4f9774ac749dfdfea446e9c30da98d9ed5ab6e46a43392aa&req=dSglHsF3mIBcXfMW1HO4zY58UguqlfrO3k7cl98YUJ8QVqqKXVOE2pylbxSE%0Ahw%2B7%0A)
4. Sélectionnez le chantier souhaité dans la liste (ex: CH00030 - Projet Fenêtres) pour ouvrir sa fiche de synthèse.

## III. Fiche de Synthèse

### A. Onglet "Infos"

Dès l'ouverture d'un chantier, vous arrivez sur l'onglet **« Infos »**.

C'est la fiche d'informations qui regroupe les données principales :

- **Planning :** vous visualisez la date de **Début** et de **Fin prévue**.
- **Description** : vous prenez connaissance de la nature des travaux.
- **Mémo client :** vous pouvez ajouter des informations spécifiques ou des liens externes *(ex: lien vers un dossier Google Drive)*.
- **Contacts et Accès :** retrouvez le nom et le téléphone du Client, ainsi que l'adresse exacte du chantier. Le bouton bleu **« Appeler »** permet de joindre le client en un clic sans quitter l'application.

![](https://downloads.intercomcdn.com/i/o/tarury57/1828902444/25713c9c1cbc9db899a54148c23c/image.png?expires=1788619500&signature=f1d19f04caa36c37bf46fd11372837e2aa864c19b5c13759611101761bcc0df4&req=dSglHsB%2Bn4VbXfMW1HO4zc2aEkmVEZWONQ7lgND6ICYpcyJWdCffbPjmZxTN%0A%2B4kB0AQjahqYnri9aJY%3D%0A)

### B. Onglet "Interventions"

Pour piloter l'avancement du chantier, basculez sur l'onglet **« Interventions »**.

- **Historique complet :** vous y retrouvez la liste des interventions planifiées.

![](https://downloads.intercomcdn.com/i/o/tarury57/1828912687/48c82404053780bd1838786621c1/image.png?expires=1788619500&signature=6e1117e24f987baf174a88fb7df0e679608b90a84cf7a653127fc629068c0a0a&req=dSglHsB%2Fn4dXXvMW1HO4zdEBts577XhfeX%2Filt7ubOXPpZYlpsFPx8EGrVLJ%0ADu0u%0A)

Cliquez sur la case **« Afficher les interventions terminées »** pour visualiser l'historique des travaux déjà réalisés.

![](https://downloads.intercomcdn.com/i/o/tarury57/1828913794/5a9f714c7416a70d5ae07a30c480/image.png?expires=1788619500&signature=eade044499ebd4ccb14708407caaf33fbe31412fe4f73f69f8e31c018de78638&req=dSglHsB%2FnoZWXfMW1HO4zRVD5kZBB5DdN9Sin9zbqvWSZN8SDLldsgVa%2FDWI%0AVbT9%0A)
- **Navigation croisée :** si vous consultez la fiche d'une intervention spécifique, un lien bleu portant le nom du chantier (ex: "Projet - Fenêtres") vous permet de revenir instantanément à la fiche globale du chantier.

![](https://downloads.intercomcdn.com/i/o/tarury57/1828916676/10b197887f909af2ed84d3db3138/image.png?expires=1788619500&signature=fa098453eb71991ca888b852a25c83f4ea96d11f11d9c63f41fb051e811159ab&req=dSglHsB%2Fm4dYX%2FMW1HO4zRoquZI5wE0Hzd9HG7bTZe%2B8ilRBUR9zexvCaWEe%0A%2B%2F8d%0A)

### C. Onglet "Documents"

L'onglet **« Documents »** remplace le dossier papier traditionnel.

- **Types de fichiers :** vous y retrouvez le devis signé, les listes d'articles (matériel / fournitures) et tout autre document que vous aurez joint au chantier.
- **Actions :** en cliquant sur les trois petits points à côté d'un document, un menu s'ouvre vous permettant de :
- **« Voir le fichier »** : pour le visualiser sur l'écran de votre téléphone.
- **« Télécharger le fichier »** : pour l'enregistrer sur votre téléphone.

## IV. Collaboration et Commentaires 

### A. L'espace Commentaires classique

Pour faciliter la communication interne, une icône de bulle de discussion est accessible en haut à droite de la fiche chantier.

Elle ouvre un espace **« Commentaires »** où vous pouvez :

- Ajouter des notes de suivi
- Historiser les échanges concernant ce projet spécifique.

![](https://downloads.intercomcdn.com/i/o/tarury57/1828926402/122750390130b12482fecf13cdf5/image.png?expires=1788619500&signature=638500c3d6a5d5e2daa683df78677aeb6dbb19fc3c2c3b75c7a8f1e834266be5&req=dSglHsB8m4VfW%2FMW1HO4zaroQPJ%2FzZ9i4Pn02IaLe4iigxtR%2Bu57DzPtpBMV%0AFXDcI1EJ7VR5GW8bFuI%3D%0A)

### B. Le nouveau Fil de Chantier

L'espace commentaire évolue et devient le **Fil de Chantier**, pensé comme le véritable "WhatsApp" de vos projets !

Toujours accessible via la même icône de bulle de discussion, cet espace enrichi centralise toutes les informations en un seul endroit pour vous faire gagner en réactivité. Depuis le terrain, vos équipes peuvent désormais :

- 📸 **Partager vos photos en direct :** Montrez l'avancée des travaux ou un point de blocage technique instantanément.
- 🎙️ **Envoyer des messages vocaux :** Idéal pour communiquer plus vite quand on a les mains prises sur le chantier.

- 📋 **Retrouver l'historique complet :** Gardez une trace claire et chronologique de chaque intervention liée au projet.

*💡 **Prêt à le tester ?** Cette fonctionnalité est disponible sur demande. Contactez vite notre équipe support via la bulle de tchat en ligne pour l'activer sur votre compte !*

Le suivi de chantier sur mobile est un ainsi une fonctionnalité puissante pour diffuser l'information auprès des techniciens / sous-traitants sur le terrain ! 😄

En regroupant les contacts, l'historique des interventions et les documents administratifs dans une interface unique, le dossier chantier centralise les données nécessaires à l'avancement de vos projets.

## VI. Questions fréquentes (FAQ)


Par défaut, l'accès aux documents (plans, devis, photos) est restreint pour les techniciens afin de protéger vos données. Pour leur donner l'accès, vous devez vous rendre sur l'application web :
1. Allez dans **Mon entreprise > Paramètres > Chantiers**.
2. Dans la section **Accès aux documents**, séléctionnez les rôles que vous souhaitez autoriser (ex: Technicien et Sous-Traitant).
3. Demandez ensuite à vos techniciens d'actualiser leur application mobile en glissant l'écran vers le bas.
![](https://downloads.intercomcdn.com/i/o/tarury57/2464800626/3279d081cecb51ffa67b0da752de/CleanShot-2B2026-06-09-2Bat-2B11_18_47-402x.png?expires=1788619500&signature=7d06bfde72b9cf6c915d2afada75ad83d90aa5fe452d538c836edea18d522bb8&req=diQhEsF%2BnYddX%2FMW1HO4zYQyYMnE%2BPdLebr2pNmLTILhdMkpRc0qbPYfzxV0%0AwjFJvIvja%2BI1gU2eqoQ%3D%0A)


Oui, c'est un comportement tout à fait normal conçu pour sécuriser vos dossiers. Lorsqu'un accès aux documents est accordé, les collaborateurs sur le terrain peuvent les consulter et les télécharger pour mener à bien leur mission. En revanche, pour éviter toute erreur de manipulation, la modification ou la suppression de documents n'est pas permise depuis l'application mobile.

Sur l'application mobile, ouvrez le dossier du chantier concerné et rendez-vous dans l'onglet **Interventions**. Vous y retrouverez la liste exacte de toutes les interventions qui ont été correctement affectées à ce projet spécifique par vos salariés. Si une intervention n'y figure pas, c'est que le technicien a oublié de faire la liaison !
