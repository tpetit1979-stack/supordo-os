# Planifier un Évènement (App Mobile)

> 👉 En complément, consultez notre tutoriel dédié à [la planification d'évènement](https://help.inter-fast.co/fr/articles/10253860-planifier-un-evenement-app-web) depuis l'application web.

## Introduction

L'application mobile InterFast vous offre une autonomie totale pour gérer votre planning.

Avant d'aller plus loin, il est crucial de comprendre la distinction entre les deux types d'évènements :

- **L'Intervention :** cet évènement représente un déplacement technique qui implique la rédaction d'un rapport / compte-rendu à l'issue.
​*ex : dépannage, installation, visite technique*
- **Le Rendez-vous :** cet évènement représente un déplacement professionnel sans rapport à remplir.
​*ex : réunion à la banque, déjeuner d'affaires, journée BNI.*

Ce guide vous explique comment planifier une intervention ou un rendez-vous depuis l'application mobile.

## I. Planifier un évènement

Quelle que soit la nature de l'événement, tout commence au même endroit.

1. **Accéder aux actions rapides**
Depuis votre écran d'accueil, appuyez sur le **bouton bleu central « + ».**

![](https://downloads.intercomcdn.com/i/o/tarury57/1836360683/1d217dbdc000272f635f623ad752/image.png?expires=1788619500&signature=ea5d19894c20e7edf998782f12f6c0e926158e58f9ce6b0797d6446b2156638a&req=dSgkEMp4nYdXWvMW1HO4zfGiVCpCRA0U0bz1gy1qQZaK7SQ5%2FlESzOuHXb91%0AkmIA%0A)
2. **Faire le choix**
Le menu vous propose alors de choisir entre **« Planifier une intervention »** ou **« Organiser un rendez-vous »**.

![](https://downloads.intercomcdn.com/i/o/tarury57/1836362532/62b23a28c6fc02e1b60cd4bc4a5b/image.png?expires=1788619500&signature=65715c7681c969b1543529f418de0a43689ec64b007fd1c62a18d795a06e3004&req=dSgkEMp4n4RcW%2FMW1HO4zQMY5Q9Y25Qb69zmLYvHsOt0hzu%2BhoP7UILjMWL5%0ANY6W%0A)

## II. Cas d'une Intervention

***> avec rapport***

Si vous devez produire un compte-rendu / rapport d'intervention, sélectionnez **« Planifier une intervention ».**

![](https://downloads.intercomcdn.com/i/o/tarury57/1836432491/531cf8903e572490823fa1f417e1/Capture+d-e%CC%81cran+000035+-18-11-2025.png?expires=1788619500&signature=8c75cc8f01c3d594f2f54a480f8bc5b4aab15fe2315a19b526ec2cbbb4de70a7&req=dSgkEM19n4VWWPMW1HO4zaFK%2FXATuDgnwfgBNlZWYi7QWjf2CSjwvkv7yYSC%0AzWRy7LzCWOrS%2BTc%2FubM%3D%0A)

### **1. Onglet Général**

- **Type d'intervention :** le type d'intervention choisi *(ex: Visite avant devis PAC Air / Air)* déterminera le modèle de rapport associé à l'évènement.
​
​*👉 Pour plus d'informations, consultez notre tutoriel sur le [Constructeur de rapports](https://help.inter-fast.co/fr/articles/11183432-construire-les-modeles-de-rapports).*
​
- Sélectionnez ensuite :
-  le **Client** / le **Prospect**
​*Au besoin, vous pouvez [créer un client / un prospect](https://help.inter-fast.co/fr/articles/12645868-gerer-les-clients-app-mobile) grâce à notre tutoriel dédié.*
​
- l'**Adresse **qui** **sera géolocalisée sur Google Maps.
​*Au besoin, vous pouvez en ajouter une et elle sera enregistrée sur la fiche client.*

![](https://downloads.intercomcdn.com/i/o/tarury57/1836366052/de5d0f5aa2401d8a666e60e7fef0/image.png?expires=1788619500&signature=29eed747c135d4e12de3e78f03677302fb3160a745e5a773f6e119f59dc0d2ae&req=dSgkEMp4m4FaW%2FMW1HO4zcEBtSi%2FhLjhO1oC4CN9xoP%2BBHThu12ZWC8ecAHu%0A279N%0A)

### **2. Onglet Détails**

- Ajoutez un **titre**, une **référence client** éventuelle et une **description** *(ex: "Appartement 3 pièces")* pour compléter la fiche d'intervention.
​
![](https://downloads.intercomcdn.com/i/o/tarury57/1836379873/7b0247e9dc4119fab58a4aaa4a34/image.png?expires=1788619500&signature=9b7233f8e201f5f69dd3a4a91a914ed86ba491b492b316dd7c1bacdbdb06484b&req=dSgkEMp5lIlYWvMW1HO4zZLiAnFzQa%2BgUGMaHHkhWg6ILb9YB9T9%2BQ06xtsN%0A1bB5%0A)
- **Planifier dans le temps**
​
- **Option "Maintenant" :** cochez cette case pour fixer une date et une heure précise.

![](https://downloads.intercomcdn.com/i/o/tarury57/1836382147/d94d9cf25816068b09efdb780b11/image.png?expires=1788619500&signature=776f78d4f31e28b7a895dbb098c442cedd6ffe6e9faa2d31e132b47478436348&req=dSgkEMp2n4BbXvMW1HO4zZlko41H%2ByHnBLbqUrIQRPK12qiZlHdq6t7Laua5%0ACpVE%0A)

Vous pouvez cliquer sur la date pour la modifier.
Une pop-up s'ouvre alors pour choisir une nouvelle date dans le calendrier.
​
![](https://downloads.intercomcdn.com/i/o/tarury57/1836383733/8b326e714cce0d56c9e48c1a466c/image.png?expires=1788619500&signature=d760d0032e659b5913d51455f829ab8cf3b45447cf0a257709fdc5c1cd766a57&req=dSgkEMp2noZcWvMW1HO4zT2ghqmu%2FAj1dXz%2Bo%2FJ2NhzgvuIMPP7VmEX7hHM4%0Aouub%0A)

L'intervention sera créée et positionnée dans le Calendrier à la date choisie :

![](https://downloads.intercomcdn.com/i/o/tarury57/1836391295/ad361788eb759bd64c8642209118/image.png?expires=1788619500&signature=971a9bb8d7cea786f14be824f305a459f55bc19b2e4f7336e46b06b5122a1f1f&req=dSgkEMp3nINWXPMW1HO4zcUlV5a6nsdGIb8pXq9L8osi35x1ptHZZFvBV%2FbD%0AUHBi%0A)
- **Option "Plus tard" :** cochez cette case si la date d'intervention n'est pas encore connue.

![](https://downloads.intercomcdn.com/i/o/tarury57/1836385304/8e333f25fa0a91ef5711096446d5/image.png?expires=1788619500&signature=25addb39324e467c6ff002b10c13235a2ce2f3cdd2b4cce86b874923c9fb3131&req=dSgkEMp2mIJfXfMW1HO4zZPIgd9%2B%2FYAOz5P3IJt0Jixwqytau%2BoLv4WoLGQK%0AuRSx%0A)

L'intervention sera créée mais restera en attente d'une date dans votre liste **"À planifier"** du Calendrier :
​
![](https://downloads.intercomcdn.com/i/o/tarury57/1836388064/c95f4dddae4a728d952232c4e9b9/image.png?expires=1788619500&signature=2fab526586274b414d402bb3c66544731658a075ec61d2ce8b7c3b13ca6737d0&req=dSgkEMp2lYFZXfMW1HO4zXFVe3h2qtm%2B8tKe258QBIxEOpYfehODBUywB7mb%0AOvB8%0A)

### 3. Onglet Fichier

Vous pouvez compléter la fiche d'intervention avec des documents depuis l'onglet **"Fichiers"**.
​
Vous pouvez ainsi :

- prendre une photo
- prendre une vidéo
- ajouter une image de la galerie
- ajouter un fichier du téléphone

![](https://downloads.intercomcdn.com/i/o/tarury57/1836398561/01731c629813fcccfe85f877c108/image.png?expires=1788619500&signature=ae8dde0936e301521c40fddfd5b04f0f66b08b893844cfd7f6dd2af25393bbfc&req=dSgkEMp3lYRZWPMW1HO4zVJ614Wp0v2tXa8SiAVs23%2FTCYxpJ8HYd2l98Hn3%0AD3Oz32rwe857Z0%2Fwotw%3D%0A)

Le fichier ajouté rejoindra la fiche d'informations :

![](https://downloads.intercomcdn.com/i/o/tarury57/1836405206/08ae737af2d730620afc464c716b/image.png?expires=1788619500&signature=dcea34fc948bbd0cbf9462fcd944742bbf1ab3facb2b80564474a5525c9b2265&req=dSgkEM1%2BmINfX%2FMW1HO4zd5WkGZLR6iK8mX6aaeU4h2VKlvSh9CP0ZJIhfLb%0AdRVJOd5Jrg%2BPK3NhvvM%3D%0A)

### 4. Terminer la création

Une fois que les informations sont correctement remplies, deux options s'offrent à vous :

![](https://downloads.intercomcdn.com/i/o/tarury57/1836406744/d6dcac52a127288892ca222e05f8/image.png?expires=1788619500&signature=8c5e981c9e749b8af3e7e4f375292c80a77ada77e069aad08028b57b55c4531e&req=dSgkEM1%2Bm4ZbXfMW1HO4zUwVbO2eOVx8PExbS63oxnoNRyOY9R8Urm0tYQuJ%0AY624QGKkStwX0jxEO5w%3D%0A)

- vous pouvez cliquer sur **« Remplir le rapport d'intervention »** pour débuter le remplissage du compte-rendu technique :

![](https://downloads.intercomcdn.com/i/o/tarury57/1836396047/f9d0c4005b680b9f9022148daa1d/image.png?expires=1788619500&signature=12b74543faaa994fc837d0698c9fb9b0c7ad312c697ac05f2b15473e05823d38&req=dSgkEMp3m4FbXvMW1HO4zf3S092xU5oiBKgeuTIV5NDWN4qbPSVPmY1dYJ%2FA%0Aomo8%0A)
- vous pouvez **« Continuer sans remplir le rapport »** pour sauvegarder votre intervention et rejoindre le menu principal de l'application mobile.

## III. Cas d'un Rendez-vous

*> sans rapport d'intervention*

Si vous ne devez pas produire un compte-rendu / rapport d'intervention, sélectionnez **« Organiser un rendez-vous ».**

![](https://downloads.intercomcdn.com/i/o/tarury57/1836431837/d6a24ec292197ece0901eb6f616e/Capture+d-e%CC%81cran+000036+-18-11-2025.png?expires=1788619500&signature=b87d8438514a377036673d14272b3bf43ab49b72d445810c23f9bcc6a00f87b4&req=dSgkEM19nIlcXvMW1HO4zY2b9%2BlMcAB84DbryBZjF%2BsfaiIcpxgv%2FBvLG98%2F%0A75BR6RfrexqS9OxM26E%3D%0A)

### 
1. Configuration initiale

- Donnez un titre explicite *(ex : "Réunion BNI")* et une description de ce que vous projetez de faire.

*NB. Contrairement à la planification d'une intervention, il n'y a pas de modèle de rapport associé au rendez-vous.*

![](https://downloads.intercomcdn.com/i/o/tarury57/1836439404/8c2a4a45e68a155a9d56433751f1/image.png?expires=1788619500&signature=fa4870bd289a73f13b1539bc7722b821ebe083c71c79e64b59d99a460e5dfc63&req=dSgkEM19lIVfXfMW1HO4zau1C2g16knNG%2FchU%2FS5OFyXcB%2BOVl4aY77E6ZC9%0AjM3N%0A)

- Déterminez la date du rendez-vous et l'heure début / de fin

### **2. Choix du Client**

- Remplissez le formulaire simplifié :
- **Client** : pour lier le rendez-vous à son historique d'évènement
- **Chantier** éventuellement
- **Adresse** pour bénéficier de la géolocalisation Google Maps.

![](https://downloads.intercomcdn.com/i/o/tarury57/1836435859/2b4ead2bcabe67070ca5f3a0bc61/image.png?expires=1788619500&signature=8e5bb8b461be5b1c4d28409c9b329dae7f0f6664b133b8314d1c4132d04ff4cb&req=dSgkEM19mIlaUPMW1HO4zanIgmVxguvDcI7ljpgTUOBPISHSbUvye3M%2BiB9j%0AsAtP%0A)

### **3. Ajout de pièces jointes**

- Si nécessaire, cliquez sur **"Ajouter des fichiers"** pour compléter la fiche du rendez-vous.

![](https://downloads.intercomcdn.com/i/o/tarury57/1836445965/35d64dcb5ce397b0fa42a5ac2d57/image.png?expires=1788619500&signature=175d74528d881eaecd4bff3574656f12b8586bd4d64cfe5a15d35a86143ab8de&req=dSgkEM16mIhZXPMW1HO4ze8zaxNLcc8LUY96T2cqUSC9iPlhNHxSmyOR4LCL%0AyGCN%0A)
- Vous pouvez ajouter :
- des photos
- des images de la galerie
- des documents de votre téléphone

![](https://downloads.intercomcdn.com/i/o/tarury57/1836446860/7937494a82755fdd7674528b3224/image.png?expires=1788619500&signature=577152ae7c6f28314a6325d37b58ca3941b61986dac5e3c2ebbaa2135e09cef3&req=dSgkEM16m4lZWfMW1HO4zS7A1f6yUm6kNvB6ddZk6Sl0cNrXa1TCet1%2B0h7X%0A%2BgT%2F%0A)

### 4. Terminer la création

Une fois que les informations sont correctement remplies, cliquez sur le bouton **"Planifier le rendez-vous"** :

![](https://downloads.intercomcdn.com/i/o/tarury57/1836463167/dc44f77058bee896f462b137b2c3/image.png?expires=1788619500&signature=fbf92c1836b691b2f1c6b207a57a8a4c9b8802c45410adef3c9094da98b64605&req=dSgkEM14noBZXvMW1HO4zaN9o2FuGTZ63Mtujcn8JelwNIKiWed2ADdArPeI%0AjfTpElMrWEETEfOyR4U%3D%0A)

Votre rendez-vous sera sauvegardé dans le Calendrier et vous rejoindrez le menu principal de l'application mobile.

## IV. Suivi du Planning / Calendrier

Une fois créés, ces deux types d'événements apparaîtront dans votre calendrier pour vous donner une vue d'ensemble de votre journée.

*Exemple :*

![](https://downloads.intercomcdn.com/i/o/tarury57/1836448753/9df732462a0e98ab1bf0d7a80064/image.png?expires=1788619500&signature=254eefdb93bd228d314ae20363f6945c09329725c6261c2e58b7b03f62c5d639&req=dSgkEM16lYZaWvMW1HO4zeqBMrhqKQfxK%2BoWgwlSZCuumf%2FyhPs2zUvFipe7%0AAxYeqrC3%2FDE6XulO8GE%3D%0A)

- Gardez à l'esprit que :
- les **Interventions** *(ex: IN00911 - Visite avant devis)* nécessitent un rapport pour être terminées.

![](https://downloads.intercomcdn.com/i/o/tarury57/1836453672/3e36ea82757f8191e96d86e66aa8/image.png?expires=1788619500&signature=b1de4ca9f051b753944f14e437969914ab813d06e647851d77c98138f067d3fc&req=dSgkEM17nodYW%2FMW1HO4zaUL1YqzL7lkvamVDL8Zx7BvAmTxi8c6z808VeZY%0AqJWG%0A)
