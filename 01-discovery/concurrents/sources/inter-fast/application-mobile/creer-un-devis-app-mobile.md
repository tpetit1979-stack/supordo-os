# Créer un Devis (App Mobile)

> **💡 **Grâce à l’application mobile InterFast, vous pouvez consulter, modifier, créer et envoyer vos devis en toute simplicité. Où que vous soyez.
> En complément consultez notre tutoriel dédié à la [création de factures depuis l'Application mobile](https://help.inter-fast.co/fr/articles/12645881-creer-des-factures-app-mobile).

La **fonctionnalité « Devis »** depuis l'Application mobile permet utilisateurs de générer, éditer et transmettre des factures directement depuis le terrain, sans attendre le retour au bureau.

## I. Accéder aux Devis

Depuis l'interface mobile, cliquez sur le bouton **"Devis / Facture"**. Vous accédez alors à la liste de vos documents commerciaux, organisé en deux onglets :

- **Devis**
- **Factures**

![](https://downloads.intercomcdn.com/i/o/tarury57/1478728344/8ae703cc075f8443ca3fd11d92f9/IMG_2880.jpg?expires=1788619500&signature=8e3f4e1e7f424b735b00372d65f6fbbf44f33fbc4d8cdf856e4ae13819dd698f&req=dSQgHs58lYJbXfMW1HO4zUwYX0AvUS2cYMBiAerxTHO%2F9PL%2B699KA4E1SEhL%0AWsRVgN1DkGea%2FynRLIg%3D%0A)

Dans cet article, nous allons nous concentrer sur l'onglet **"Devis"**.

## II. Visualiser un Devis existant

Dans l'onglet **Devis**, vous retrouvez la liste de tous vos devis avec leurs statuts : *brouillon*, *envoyé*, *accepté*, *finalisé*, etc. Chaque statut est indiqué par une pastille de couleur à droite de chaque ligne.

![](https://downloads.intercomcdn.com/i/o/tarury57/1478729048/3123079f65903072aed007569bd8/IMG_2881.jpg?expires=1788619500&signature=4e09d3b3a88f3a612b7aa9861a1831310bba1d6bc8372efadc7dde3045661efe&req=dSQgHs58lIFbUfMW1HO4zXxttx9jZZpJLbJTMCU2ljYc9AWjlfn3A9T6PKNz%0A7m984Qz13becAKH2j%2F8%3D%0A)

Pour consulter un devis, cliquez simplement dessus. Deux onglets s'affichent :

- **Détail** : pour consulter ou modifier les informations du devis
- **Aperçu** : pour visualiser le rendu PDF du devis

Dans l'onglet **Détails**, vous trouverez trois encadrés :

1. **Client** : informations du client concerné
2. **Détails du devis** : auteur, date de création, statut
3. **Liens** : si le devis est lié à un chantier
4. **Récapitulatif** : montant total et acompte concerné (le cas échéant)

![](https://downloads.intercomcdn.com/i/o/tarury57/1478730557/9eab0eb224626935df0b35db98be/IMG_2882.jpg?expires=1788619500&signature=1572fccf1cccd559bc8c999ae8c6516e4fe799ceeb472ff10a64293bd1e19ba6&req=dSQgHs59nYRaXvMW1HO4zcw1qx0ffpxZbSsPQDUNYuv1mvVrtM0nGOY2jK1e%0AmoBL0wNiAi7TCOgyUHE%3D%0A)

Vous pouvez cliquer sur les boutons ci-dessous pour : 

- Modifier pour éditer le devis
- Envoyer par mail pour l'envoyer au client

L'envoi par mail permet :

- D'envoyer à un contact préexistant du client
- D'envoyer à une adresse email saisie manuellement
- D'envoyer pour signature électronique

![](https://downloads.intercomcdn.com/i/o/tarury57/1478748171/855b8d8e8eec7e7e5efc066192c2/WhatsApp%2BImage%2B2025-04-16%2Bat%2B1_21_00.jpeg?expires=1788619500&signature=a28ad7fed23c60e9ede4228cedc1aec1bcd5f6d94fab81b0d69b88e1e07428d5&req=dSQgHs56lYBYWPMW1HO4zeMKNZ2SyNbatnf1XJO6My8KpF5flaL%2F%2FJkjxgp7%0AJQrHNk4gWYXM7H%2FzqtY%3D%0A)

Dans l'encadré où figurent les informations relatives au client, cliquez sur l’icône en haut à droite pour ouvrir la fiche client dans une nouvelle page dédiée.

![](https://downloads.intercomcdn.com/i/o/tarury57/1478750144/91543edb52d66bc5a708cf9e00d8/WhatsApp+Image+2025-04-16+at+10_20_59.jpeg?expires=1788619500&signature=343ba01f86815e03dd740d675ff39d1fcd9a416da08f55a7da8ddea96b86c659&req=dSQgHs57nYBbXfMW1HO4zd5HNDIal7WbLOdVVuI3jjB2Kvp%2BT7caYAq85A3R%0ANWnbJVi5GDlml7SAc%2BY%3D%0A)

Dans cette nouvelle page, vous aurez toutes les informations relatives aux clients, divisées en quatre parties. 

- **Infos client** : coordonnées et informations générales
- **Historique** : interventions et rendez-vous passés
- **Documents** : tous les fichiers liés au client
- **Équipements** : les équipements rattachés au client (si renseignés)

![](https://downloads.intercomcdn.com/i/o/tarury57/1478736373/cb7bad9184f65b408231ad02a0e1/IMG_2884.jpg?expires=1788619500&signature=b22b8153f81ff12e0600b80c74bc91395a54659d642fc6cb7309a2d29146cd9d&req=dSQgHs59m4JYWvMW1HO4zW6r%2BAcJdokNlA6s%2F7YewIzCTpzwyEUE%2FI8fECpl%0AIBd66y6vRYXYi3ArKfc%3D%0A)

Dans l'onglet "**Aperçu**", vous avez le devis tel qu'il sera sur le fichier PDF.

![](https://downloads.intercomcdn.com/i/o/tarury57/1478732361/c21fe9b8a3c4b59dbedd5d206bcd/IMG_2883.jpg?expires=1788619500&signature=97dec1bc9636de1be39b237c616c6df302b0f819ba7eb655e3bc470b68cae5ad&req=dSQgHs59n4JZWPMW1HO4zbhK4%2F1qb9ahqtn5FuHaU%2BgdOTn9ZZoY5zJuxjb6%0AZSyweVJSLbnsftvCQaM%3D%0A)

## III. Créer un nouveau Devis

Pour ajouter un devis, cliquez sur le bouton **+** en bas de la page.

![](https://downloads.intercomcdn.com/i/o/tarury57/1478753629/4bb4f2816534d2428147a0c2d56c/IMG_2881.jpg?expires=1788619500&signature=270bf59851ce8a77e15a993b9092d8d10933af5185f5bcb070f45833d82a4fe5&req=dSQgHs57noddUPMW1HO4zXFkLSDMpTHMBWG8n66Ydpc0YgH3wnzKdD1y9jkf%0AbKKeL6hqeNJMp80PP4g%3D%0A)

Sur la page suivante, indiquez :

- le titre du Devis (obligatoire)
- le Client associé (obligatoire)

![](https://downloads.intercomcdn.com/i/o/tarury57/1864977669/552d11c306b831958ea3c4aa47de/image.png?expires=1788619500&signature=69fdbecc7cde6f4f482403711f48455c794ab63cb6b568e2aed8abf9391bd125&req=dSghEsB5modZUPMW1HO4zV0tKFxPCcbHdW0UFSI2hRByRqIv3mTuLKrPFGys%0Axipc8iCpZW8hBJFfJ7g%3D%0A)

### B. Modifier le corps du Devis

Pour éditer un devis existant, cliquez sur le bouton **Modifier**. Vous pourrez alors changer ou supprimer les lignes existantes.
​
​ 

![](https://downloads.intercomcdn.com/i/o/tarury57/1478835606/8fcede5f808ce77990683281c080/IMG_2894.jpg?expires=1788619500&signature=e1ffa7fa1a9ccb90b1420e68d66b31f3fee6505cfe952b4b131a8f11e6c4efa0&req=dSQgHsF9mIdfX%2FMW1HO4zRPiL4gNrwdUNjWqHt01ZcRrorHXnStv9NPuBoF2%0ApOoYHq9LOng4znAO9WI%3D%0A)

Dans l'onglet "**Général**", en cliquant sur les trois petits points à droite de chaque ligne, vous pouvez :

- Modifier la ligne (description, quantité, prix HT, prix TTC, taux de TVA)
- Supprimer la ligne

Dans l'onglet "**Détails"**, vous pouvez :
