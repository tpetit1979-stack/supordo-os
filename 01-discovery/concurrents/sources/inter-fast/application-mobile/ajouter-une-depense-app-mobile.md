# Ajouter une Dépense (App Mobile)

> 🔔 Les justificatifs de paiement peuvent être photographiés et analysés par notre OCR pour créer de nouvelles dépenses dans l'environnement web, dédié à la gestion administrative de l'entreprise.

## I. Vidéo tutoriel d'Hedi

[Vidéo YouTube](https://www.youtube.com/watch?v=SPDK13hD6hE)

## II. Détail des Étapes


Depuis l'application mobile d'InterFast :

1) Cliquez sur le bouton " + " :

![](https://downloads.intercomcdn.com/i/o/tarury57/1388773988/159ae68d807743ad8b53f86b19a8/IMG_1361.PNG?expires=1788619500&signature=734f513191a98a1aeaddb212235426acc04be5ea83e65b1e31518580d13abf8f&req=dSMvHs55nohXUfMW1HO4zaIw2v8X7s49UWHAg7%2BXXL4vwZxK009vxvAr%2Bdj%2F%0AY0TudCAynaHqWwmEXFk%3D%0A)


​

2) Choisissez "Une dépense" dans le panneau de sélection :

![](https://downloads.intercomcdn.com/i/o/tarury57/1388775540/e15a8cbffd64292e55f3c732fda5/IMG_1362.PNG?expires=1788619500&signature=633f097b2b007c28d3c91306ad0764f792a3d1b4a983f520519a12804ab6b6b0&req=dSMvHs55mIRbWfMW1HO4zeSsfTtkRvf6PzX9y6S%2F0ZtdKmMFyPtjaAfta2uf%0AtBT2QgR2mhf123f%2F54w%3D%0A)


3) Cliquez sur le bouton "Ajouter" :

> Vous pouvez ajouter **un ou plusieurs** justificatifs / reçus à la fois.

![](https://downloads.intercomcdn.com/i/o/tarury57/1388777483/c9df1ad4c60a634cb42ff933ebc9/IMG_1363.PNG?expires=1788619500&signature=52449f5a5c4d7c5eade2ca454880e8457408cb33d39744a0c5c5d24e53d6a697&req=dSMvHs55moVXWvMW1HO4zfz9BcQ1OAc%2Bm%2FAnE4pOb6KOa%2FDyNewoh8BG2LmK%0AIQvBheMU84aEheM8aZ8%3D%0A)

4) Cliquez sur le bouton "Enregistrer" :

![](https://downloads.intercomcdn.com/i/o/tarury57/1388781324/42e9f5f479344fd87b369e44e367/Screenshot+2025-02-20+at+13_15_32.jpeg?expires=1788619500&signature=6ff11a0913b8c97029854ff455f9d0a92f7d321fe965df18a7da07d2a94ea534&req=dSMvHs52nIJdXfMW1HO4zWqdZLtQPspQfr%2BX0E9tLMcAqZPFGZ9D1SQqJ6Q8%0AdSH%2B84G69hQYYBYFfHU%3D%0A)

5) Vos dépenses sont disponibles sur l'application web :

![](https://downloads.intercomcdn.com/i/o/tarury57/1405916783/b03aa4df7a48a7771dd97b8ef901/CleanShot%2B2025-02-20%2Bat%2B13_19_00.png?expires=1788619500&signature=f2bbf628b2e78425b82b5210a4577dce96ba45249d49ede7ee1f8844586d9fa8&req=dSQnE8B%2Fm4ZXWvMW1HO4zSbIZ1iJP68WdRO9VNd3l3uGCvoOUCUo4JJM312P%0Ac0oWzJ9ugyV76u5Hhao%3D%0A)

> ✅ Les justificatifs / reçus ont été analysés par l'intelligence artificielle pour pré-extraire toutes les informations du document et faciliter votre suivi administratif.
