# Gérer les Fournisseurs (App Mobile)

> 👉 En complément, consultez notre tutoriel dédié à [la compréhension de la fiche client](https://help.inter-fast.co/fr/articles/10253899-ajouter-des-clients-prospects-fournisseurs) depuis l'application web.

Le module CRM de l'application mobile vous permet d'accéder, y compris dans vos déplacements, à l'intégralité de votre base de Fournisseurs.

## I. Introduction

Le module Fournisseurs mobile vous permet de centraliser les coordonnées et l'historique de vos partenaires d'approvisionnement.

Il facilite la prise de contact rapide et le suivi de la relation fournisseurs directement depuis le terrain.

## II. Visualisation des Fournisseurs

Pour accéder à votre répertoire :

1. Cliquez sur l'icône **« Menu »** de l'application.
2. Sélectionnez l'onglet **« Fournisseurs »**.

![](https://downloads.intercomcdn.com/i/o/tarury57/1829591755/4481ceeec3f9b3733e28d7bfaa59/image.png?expires=1788619500&signature=9e049b15ec1af9c1515cf808952f2e254e31da83b0e0257551fdc93ddd2f2af2&req=dSglH8x3nIZaXPMW1HO4zR2RzR4NT%2BXD6q4BlryDGS3GNbMqFrKy3EbXItH9%0An0lN%0A)
3. **Recherche :** vous accédez à la liste complète de vos Fournisseurs. Utilisez la barre de recherche pour trouver rapidement une entreprise par son nom ou sa référence interne dans le CRM.

![](https://downloads.intercomcdn.com/i/o/tarury57/1829594682/c48a209a796f1c8c35519d5deb44/image.png?expires=1788619500&signature=d3ed87b852f550418918ed05bbd2cc3a944ca53d419b65c6f67d0a08a60150b1&req=dSglH8x3mYdXW%2FMW1HO4zYed%2BGuUp5gXToAvV1bje%2FMuQcJoINBnSHh1yO8G%0A41KRkjnu7ukgrYSf5uQ%3D%0A)

## III. Consultation d'une Fiche Fournisseur

En cliquant sur un nom d'entreprise dans la liste, vous ouvrez la fiche détaillée du Fournisseur :

### A. Onglet Informations

C'est la fiche d'identité du Fournisseur. Vous y retrouverez :

- L'adresse principale, le numéro de téléphone et les contacts associés.
- **Action rapide :** le bouton bleu **« Appeler »** permet de joindre le Fournisseur en un clic.

![](https://downloads.intercomcdn.com/i/o/tarury57/1829596185/f12e1aa1bc7af40826760b8eee5e/image.png?expires=1788619500&signature=757ed13540ea6344605d65454d1a9eaa0a1f2bde3bf84a24142b60fcdb384df9&req=dSglH8x3m4BXXPMW1HO4zRdfNSNT3RDvUn%2FiY%2Bo8SvTxjS8heLY0t%2FSZmfEi%0AXa60%0A)

### B. Onglet Historique

Cet onglet retrace l'ensemble des déplacements / interventions auprès du fournisseur.

> ❌ Les commandes ne sont pas encore affichées sur la fiche Fournisseur depuis l'application mobile. C'est une amélioration à venir.

![](https://downloads.intercomcdn.com/i/o/tarury57/1829600422/c55b60211dc554a69e129000873c/image.png?expires=1788619500&signature=bdc7b1cfc1f8e120c4d7b1eb975b99c2d4356fcc963c3389e88a317ae46de0e5&req=dSglH89%2BnYVdW%2FMW1HO4zZOBDacNpHPGO3z8cymfKk0XwI%2FeX5r5EP8Ye98N%0AX8wi%2BKvOL9zySqWnmoI%3D%0A)

### C. Onglet Documents

Il regroupe les fichiers administratifs ou techniques partagés avec ce Fournisseur (contrats, tarifs, etc.).

![](https://downloads.intercomcdn.com/i/o/tarury57/1829601150/a1140e131d36a29d511daa36632d/image.png?expires=1788619500&signature=8eda987da1746b12307ec591a3c8634acb31105f2c0e485ceacb70ea15f99321&req=dSglH89%2BnIBaWfMW1HO4zS3cKsAmjUisfsRlxZ9TJwtzVThhCtrasPwuv7Y%2B%0Ak9t%2FIlPqhHV5ws5Xeyk%3D%0A)

### D. Onglet Équipements

Il recense les équipements spécifiques rattachés à ce fournisseur.

Vous pouvez cliquer sur **« Ajouter un équipement »** pour enregistrer une nouvelle machine liée à ce partenaire.

![](https://downloads.intercomcdn.com/i/o/tarury57/1829601925/a9757d5fb614326f1cf6f124aa2a/image.png?expires=1788619500&signature=f015ac15d04d2ed78d5c76d1154162392528d030efba5952d23b07bcaf5dd6ea&req=dSglH89%2BnIhdXPMW1HO4zTX5LoxCjOqgMEs0xtnBwQUidn1%2FwjJcA5XIpp32%0AuOJue1K0YEU7%2BQFFqS0%3D%0A)

## IV. Actions et Modifications

Depuis la fiche d'un Fournisseur, vous disposez d'outils pour tenir vos données à jour :

- **Modifier les informations :** en cliquant sur le bouton **« Modifier »**, vous accédez au formulaire d'édition pour corriger le nom de l'entreprise, le SIRET ou les coordonnées du contact principal.

![](https://downloads.intercomcdn.com/i/o/tarury57/1829604026/a0fa24058767d0868bae92587e7e/image.png?expires=1788619500&signature=fa6d15c78d8ba0a07f6c625af4a107a1b272a9d4feb079371fedb20ea84b78d7&req=dSglH89%2BmYFdX%2FMW1HO4zTvTCt1vqpY7TT5QXnTKMnumvjRMkQGlQYSAeE%2BG%0ADjgR%0A)
- **Autres actions :** en appuyant sur le bouton **« Autres actions »**, un menu contextuel s'ouvre pour vous permettre de créer directement :
- un **Devis**
- une **Facture**
- une **Intervention**

![](https://downloads.intercomcdn.com/i/o/tarury57/1829605971/a37687995e9171ee21c23b709fd9/image.png?expires=1788619500&signature=ce802e9bf41c68ef847de2290c06673d9d80bc8e285d7a09d5e62f5d1afbfdd9&req=dSglH89%2BmIhYWPMW1HO4zaQ0IaWQh3IfVhVp0kLthvyId4yoBV%2B4pb2XoF0f%0A6%2BgJsajNfqfMwGB18hg%3D%0A)

## V. Conclusion

La gestion des fournisseurs sur l'application mobile permet à vos équipes de toujours disposer des bons contacts pour passer commande ou gérer un SAV. 

Simple et directe, cette fonctionnalité complète le CRM pour une vision globale de vos partenaires ! 😄
