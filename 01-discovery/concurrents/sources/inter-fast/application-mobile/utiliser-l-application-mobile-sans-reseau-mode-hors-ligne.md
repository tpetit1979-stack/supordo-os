# Utiliser l'application mobile sans réseau (Mode hors ligne)

> Il vous arrive d'intervenir dans des zones sans réseau (caves, sous-sols, zones blanches) ? 
> L'application mobile InterFast intègre un **mode hors ligne partiel** qui vous permet de réaliser certaines actions, dont nous allons parler dans cet article, avec leurs limites. 

## I. Remplir un rapport d'intervention

### A. Pré-charger l'intervention - avec réseau

Le logiciel a besoin d'internet pour récupérer les informations de votre client et de l'équipement avant que vous ne descendiez sur le terrain.

- **Avant de perdre le réseau** (par exemple, dans votre véhicule en arrivant devant le bâtiment), ouvrez l'application InterFast.
- Ouvrez la fiche de votre intervention du jour pour la "pré-charger" sur votre téléphone.
- Cliquez directement sur **Démarrer l'intervention**.

### B.Compléter votre rapport sur place - sans réseau

Vous êtes désormais dans la zone blanche.

Vous pouvez remplir votre rapport d'intervention normalement, cocher vos listes de contrôle et prendre vos photos.

Toutes ces informations sont sauvegardées localement et en toute sécurité sur la mémoire interne de votre téléphone.

### C. Finaliser votre rapport - retour du réseau

Une fois votre travail terminé, **ne cliquez pas tout de suite sur "Terminer l'intervention"** si vous n'avez toujours pas de réseau.

Attendez de retrouver une connexion stable (Wi-Fi ou 4G/5G) et terminez votre intervention :

Et voilà ! Vous avez généré votre rapport avec le mode hors ligne partiel. 🎉

## II. Questions fréquentes (FAQ)

Non, le mode hors ligne est *partiel*. Vous devez obligatoirement avoir chargé l'intervention au préalable lorsqu'une connexion internet était active pour que le téléphone connaisse le client et le travail à faire.


Comme toute application mobile, l'application InterFast est conçue pour fonctionner avec une synchronisation instantanée entre le terrain et le bureau. Sans réseau, le téléphone ne peut pas se connecter aux serveurs pour récupérer les informations du client ou de l'intervention à venir. Cependant, l'application possède bien un "mode hors ligne partiel" comme évoqué dans cet article.
