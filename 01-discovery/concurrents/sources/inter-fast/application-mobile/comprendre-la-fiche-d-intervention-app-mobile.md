# Comprendre la fiche d'Intervention (App Mobile)

> 🔔 La fiche d'intervention est principalement remplie par les techniciens sur le terrain via l'application mobile. Pour accéder à cette fiche **sur l'application terrain**, vous n’aurez qu’à cliquer sur une intervention déjà existante. 

## I. Contexte

Une intervention peut être : 

- Soit préalablement planifiée à l'avance, apparaissant dans les sections "**Aujourd'hui**", "**À venir**" ou "**En retard**".

- Soit créée directement depuis l'application web ou terrain en utilisant le bouton de création "**+ planifier**" sur l'application web ou "**+**" sur mobile.

## II. Type d'intervention 

Dans cette section, apparaîtra le type d’intervention (Dépannage, installation, visite avant devis, etc..).

![](https://downloads.intercomcdn.com/i/o/tarury57/1428218631/07e984f6c04e0ae04a2c5d566ec4/type-inter.jpeg?expires=1788619500&signature=b0d3d05b8f957fb6a571a885a4794df5becd83f78d4aadeac97a83a064d6a981&req=dSQlHst%2FlYdcWPMW1HO4za4TzZ1uUiOatsw%2F3jCh2n2D3Cgl4ltcYwksfvH1%0AcoCR%2Fx4y60%2FhkMs0LsY%3D%0A)

## III. Description

Cette section reprend la description saisie pour l’intervention. Elle peut être affichée ou non sur le rapport, selon votre choix. En effet, lors de la création de l’intervention, vous avez la possibilité d’activer ou de masquer la section "**Description**" dans le rapport final.

![](https://downloads.intercomcdn.com/i/o/tarury57/1428279186/61796d88ad7ce268d5ebc4f04d1e/inter.jpeg?expires=1788619500&signature=7233faa7315edb2276b234083337c23a33096742d2bcbdb7887ccc85d1baa703&req=dSQlHst5lIBXX%2FMW1HO4zQTfWik5aNea8Q5G5Mf0uUG%2FULRukt2V3dt0XCuH%0AcimTrYDzG9tFMzg%2BeYI%3D%0A)

## IV. Adresse

L’adresse principale du lieu de l’intervention s'affichera à cet emplacement.

![](https://downloads.intercomcdn.com/i/o/tarury57/1428367899/5863f99efa0d2365d79b1b380b24/adress-inter.jpeg?expires=1788619500&signature=2ed18fd0074d99801694147bbff80729b546f781f1e18599a128ac5283fabde4&req=dSQlHsp4molWUPMW1HO4zZ9MU9LeChbllA4AgrUVPzlvNo0h%2FtYNipuDY2tZ%0AuJvHTJSig%2BgSD293%2Bp4%3D%0A)

## VI. Remplir le rapport d'intervention

Vous pouvez remplir le rapport d'intervention en cliquant sur le bouton "**Remplir le rapport**".

![](https://downloads.intercomcdn.com/i/o/tarury57/1428413181/302760b9346cb3b5bf07dee7e8a4/rapp-inter.jpeg?expires=1788619500&signature=fea1b5b12cdeb9b5e8c4212a779df6947127f61c9524d76364bde87351fe1aa3&req=dSQlHs1%2FnoBXWPMW1HO4zRRg%2FaBvD%2BkWCtSeZTUMe%2B29rqlXtxfhxbpqFiqU%0Ay3%2BlrhC1ti8WcdI6KJo%3D%0A)

## VII. Réinitialiser le rapport d'intervention

En choisissant l'option "**Réinitialiser le rapport**", tous les éléments saisis seront remis à zéro.

![](https://downloads.intercomcdn.com/i/o/tarury57/1428419874/5670ba616bf07f80f05caa8f2e1e/reinit.jpeg?expires=1788619500&signature=9385bd16a720abed8b0b94d2d769565e9b53ddce256b8e377e3335acfc703d4c&req=dSQlHs1%2FlIlYXfMW1HO4zYYVq%2FfTe9oQ1QBQr44s9SsE1wO7n4g%2FhON43VyT%0A1HZqLQoTGLXZWqQc2xA%3D%0A)

## VIII. Supprimer l'intervention

En cliquant sur le bouton "**Supprimer l'intervention**", vous supprimerez de manière définitive l'intervention concernée.

![](https://downloads.intercomcdn.com/i/o/tarury57/1428434122/a9c5af2e451ad69aa1ad2d46ac09/supp-int.jpeg?expires=1788619500&signature=bc585bf31970804d5ab9e0798eec542e38cc5c12ff3f58d3f71d56e23b4ba295&req=dSQlHs19mYBdW%2FMW1HO4zZLpy%2FKHoSNV%2FgGtzq%2BkCEIlbycG6j7vS%2FmlN8kA%0A65MoJx0q0MpbSe17pjo%3D%0A)

## IX. Joindre un fichier à l'intervention

Dans les interventions, vous pouvez joindre des documents, que ce soit des photos, ou autres.

![](https://downloads.intercomcdn.com/i/o/tarury57/1428469156/aec65ee499b79584cec5bb5f89e6/fich-int.jpeg?expires=1788619500&signature=388d3f4a2f38330b96f142eef93697182a622fa1f906ae7f0c7d6751efaad9c0&req=dSQlHs14lIBaX%2FMW1HO4zSNGCuUcDWyWg0CbQ8sjlmDH3jJu4tToZrpcbkiI%0AkOYqYdayhJ1zm%2BZaHb0%3D%0A)

## X. Historique client

En cliquant sur "**Historique**", vous accéderez à l’ensemble des interventions réalisées pour le client associé à l’intervention en cours.

![](https://downloads.intercomcdn.com/i/o/tarury57/1428482175/33ca77a0ec8f42fe684a0d56ea4f/hist.jpeg?expires=1788619500&signature=9fc427fa576d118b67b242e0181b75922546d4ba43ecbd308cfd565e5e8b3dbd&req=dSQlHs12n4BYXPMW1HO4zebwXf7zDuC3nbB7ZTnbLf9ORME7JYO5AsYef15A%0AcGuhZWGhayZ8zhcHVVw%3D%0A)

## XI. Équipements

Il est possible d’associer des équipements à un client. Dans cet onglet, vous retrouverez la liste des équipements rattachés au client de l’intervention en cours.

De plus vous pouvez également ajouter un équipement directement depuis l'intervention en cliquant tout en bas sur "Ajouter un équipement". 

![](https://downloads.intercomcdn.com/i/o/tarury57/1428497286/39f69b90959947b9ede6c7f1525b/equipe.jpeg?expires=1788619500&signature=145d38f55a04073a7f04ea2189dcf8b5316733c8098c370e9773c6ad41acbd0f&req=dSQlHs13moNXX%2FMW1HO4zV9u74SXOqc6Y06I6EM1KY9%2FRiVtYQpnl8Mq8IA7%0AdBoNRtqS3GU73eN0pX0%3D%0A)
