# Enregistrer une vidéo d'intervention (App Mobile)

Voici un tutoriel pour maîtriser la fonctionnalité vidéo sur l'application mobile InterFast, une option puissante réservée [au plan d'abonnement Business](https://inter-fast.fr/ressources/page-pricing).

## I. Introduction 

Parfois, une photo ne suffit pas... 😅
La vidéo apporte une dimension visuelle et sonore à la documentation, que ce soit pour :

- diagnostiquer un bruit anormal sur une machine
- évaluer le volume d'une pièce pour un devis
- ou prouver le bon fonctionnement d'une installation complexe

Ce guide vous explique comment enregistrer vos vidéos directement depuis le terrain.

## II. Débuter l'enregistrement vidéo

L'ajout de vidéo se fait exclusivement sur :

- les interventions mais *pas* sur les rendez-vous
- les interventions en cours de planification *(*👉 *[consultez notre tutoriel](https://help.inter-fast.co/fr/articles/12645472-planifier-un-evenement-app-mobile))*
- les interventions déjà planifiées.

> *❌ Pour le moment, il n'est pas possible d'ajouter une vidéo sur une intervention terminée afin d'en compléter la documentation.*


Pour débuter l'enregistrement vidéo :

1. **Accédez à l'intervention**
Depuis votre Planning ou votre Calendrier, ouvrez la fiche de l'intervention concernée.

![](https://downloads.intercomcdn.com/i/o/tarury57/1836614137/d29935bd22e9223849b7e14b1c29/image.png?expires=1788619500&signature=c3c0b051f1536d2aeb33f0e297c2c2141cd90466af8370287e466a3a0837a421&req=dSgkEM9%2FmYBcXvMW1HO4zexgj5Hu6Gd48xZesoWzNSm7cOO7YKMcUXuqxN3O%0AQ3gl%0A)
2. **Ajoutez un fichier**
Faites défiler la fiche d'intervention vers le bas jusqu'à la section "Fichiers" et cliquez sur le bouton **« Ajouter un fichier »** tout en bas de l'écran.

![](https://downloads.intercomcdn.com/i/o/tarury57/1836618188/459ab8eb3ac9e23c1032f0029f3e/image.png?expires=1788619500&signature=ccf5f9ae2faf64fb693c9c68730e982bd63d7e68a9564c8721696711b9a27b79&req=dSgkEM9%2FlYBXUfMW1HO4zaRMHBj7N0S6jSWfF1blh0w9m%2BXddDC2MRci7jKB%0ARMtb%0A)
3. **Choisir l'ajout d'une vidéo**
Dans le menu qui s'ouvre, sélectionnez l'option **« Prendre une vidéo »**.

![](https://downloads.intercomcdn.com/i/o/tarury57/1836619829/bf18c4bdbe866b09c8b4a9a9a7cf/image.png?expires=1788619500&signature=3e49fccb1abddb44a470fb4b1260e3b04177036e9e28ef9244dee6c967cf5317&req=dSgkEM9%2FlIldUPMW1HO4zRgp1gfkX0NQmqBmWoOyu0nuW6b4UWmhOv2fnZks%0A5rc0%0A)

## III. Capturer et Valider la séquence

L'application mobile d'InterFast ouvre alors le mode caméra du téléphone.
Suivez ces étapes simples pour que l'enregistrement soit exploitable.

1. **Le Tournage**
- Cadrez l'équipement ou la zone concernée au centre de l'écran.

![](https://downloads.intercomcdn.com/i/o/tarury57/1836623832/c453ca2548b545dc80b805ff3ef7/image.png?expires=1788619500&signature=418b2f33b5a333a882624aee02cc92b3360bc8d6951876d257aad14b390e2a9a&req=dSgkEM98nolcW%2FMW1HO4zVcpswg1Iq6WIzKNJhVKb%2B2HGoBdxbWhQxNj%2B0tT%0Are4z%0A)
- Appuyez sur le **bouton rouge** pour lancer l'enregistrement. Le chronomètre se déclenche en haut de l'écran.

![](https://downloads.intercomcdn.com/i/o/tarury57/1836625102/d36cc18a796fe14d86fd349e09e8/image.png?expires=1788619500&signature=9c649c314faf24a06755c09816511d3ae126ad4137747db86774e283d69fcdfc&req=dSgkEM98mIBfW%2FMW1HO4zSivs33n0esArEBnDaWZQi3haT15M6Ha4YK5teBy%0A%2F9BT%0A)

*✅ Conseil de Pro : profitez de la vidéo pour capter le son (bruit de moteur, ventilation) ou pour commenter oralement ce que vous voyez.*
- Appuyez sur le **carré rouge** pour stopper l'enregistrement.
2. **La Validation**

- L'application vous présente un aperçu immédiat.

![](https://downloads.intercomcdn.com/i/o/tarury57/1836628608/7c4e5774ee20f4805300b8fd23d0/image.png?expires=1788619500&signature=eeebd0aa4aab422f5e1f670fc7a50fe09bf16a9faeb67c0fb3bdc1fec0f2ab0a&req=dSgkEM98lYdfUfMW1HO4zSsAQfar%2BoTgU7qFuynmJNPO4XWIQQSulxdxUMop%0AJ5DR%0A)
- Vous avez alors trois choix :
- **Retake** (Reprendre)** :** pour relancer un nouvel enregistrement, si la vidéo  initiale est floue ou incomplète.
- **Bouton Play** (Lecture)** :** pour vérifier le son et l'image.
- **Use Video** (Utiliser la vidéo)** :** pour confirmer l'enregistrement et joindre le fichier à l'intervention.

### **3. Limitations techniques**

Pour des raisons de performance de l'application mobile, les fichiers vidéo ne peuvent dépasser :

- une durée de 3 minutes ;
- un poids de 200 Mo.

Vous pouvez toutefois ajouter plusieurs fichiers vidéo à une même intervention. 😉
