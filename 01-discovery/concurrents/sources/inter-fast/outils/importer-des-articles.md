# Importer des Articles

[Vidéo YouTube](https://www.youtube.com/watch?v=Rm9OyBjvLi8)

## **I. Préparer vos données**

La clé d'un import réussi, c'est la qualité de votre fichier de départ. Nous vous recommandons d'utiliser **Google Sheets et notre fichier template pour réaliser votre import **👉 **[[Cliquez ici pour télécharger l'exemple de fichier articles]](https://docs.google.com/spreadsheets/d/1TwBORDvD-GCzJBoCrg3Od-HWRXdUEZAeAbIWJxfDlP0/edit?usp=sharing)**

> 💡 **L'alternative rapide : L'Extension Chrome** 
> Avant de vous lancer dans la création d'un fichier Excel (CSV) pour importer vos articles, sachez qu'il existe une méthode beaucoup plus rapide si vous souhaitez importer seulement quelques dizaines de références depuis vos fournisseurs habituels : **l'Extension Chrome InterFast**. 
> Il vous suffit de "faire vos courses" sur le site internet de votre fournisseur (ex: Cedeo, Rexel, Téréva...), de cliquer sur **Ajouter à InterFast**, puis de vous rendre dans votre Bibliothèque pour cliquer sur **Importer la sélection**. Les articles se créent automatiquement avec leurs images et leurs prix ! 
> ​
> 👉 *Si cette méthode vous correspond mieux, [découvrez notre tutoriel sur l'Extension Chrome](https://help.inter-fast.co/fr/articles/10253857-installer-l-extension-chrome#h_9919f30b49)*[.](https://help.inter-fast.co/fr/articles/10253857-installer-l-extension-chrome#h_9919f30b49)

### **Les colonnes à renseigner**

Ce modèle de base articles contient les colonnes suivantes qu'il vous faudra renseigner :

- **A. Catégorie** (Pour classer vos articles)
- **B. Nom de l'article / Libellé**
- **C. Code Fournisseur **
- **D. Description** (Texte long pour vos devis)
- **E. Prix d'achat HT**
- **F. Prix de vente HT**
- **G.TVA** (Taux applicable)
- **H. Fournisseur**
- **I.Unité**
- **J. Emplacement du stock** (Optionnel : si vous souhaitez spécifier un emplacement différent par ligne)
- **K.Quantité en stock**

**⚠️ Important : **

Pour faciliter vos filtres, notez que le moteur de recherche cible en priorité les champs **Catégorie** et **Code fournisseur**. Pensez à y renseigner vos mots-clés stratégiques lors de l'import.

**La colonne "Unité"** Il s'agit de l'unité de facturation (ex: m², heure, forfait, u) et **non** du stock disponible. *Exemple : Si vous vendez du carrelage, inscrivez "m²".*

### **Préparer le transfert de vos données - Méthode par colonne**

Cette méthode a un double objectif : Empêche de modifier accidentellement les en-têtes (titres) du modèle et vous permet de vérifier que chaque donnée atterrit bien dans la colonne prévue.

1. Ouvrez votre fichier **source  (csv)** et le fichier **Modèle Interfast** dans deux onglets distincts.
2. Dans votre fichier source, cliquez sur la lettre de la colonne à copier (tout en haut) pour la sélectionner entièrement, puis faites **Copier**.
3. Dans le **Modèle Interfast**, cliquez sur la lettre de la colonne correspondante (cible) et faites **Coller**.
4. Répétez l'opération pour chaque information.

![](https://downloads.intercomcdn.com/i/o/tarury57/1848182689/619f053986271f02cfc8aafebbe6/2025-11-19_14h31_14.gif?expires=1788674400&signature=c5113e8aeaf8c2d7ba197d2a2e4e923436208939966b81b6700098ae1c5a4816&req=dSgjHsh2n4dXUPMW3nq%2BgY3EvdkZdZWh9XSjAQawBiMaD2FTsy6pfP3Fov1y%0A%2BCjgQhKVsZZvJEYQgiOWCcvbetU%3D%0A)

**Important :** Ne modifiez jamais la première ligne (l'entête) du modèle Interfast. Le logiciel a besoin de ces titres exacts pour mapper les colonnes et éviter les erreurs.

## II. Importer sa Bibliothèque d'articles

### Sélection du fichier à importer

> 💡 Assurez-vous d'avoir votre base articles exportée au **format CSV** avant de poursuivre. 

Il est possible d’importer une bibliothèque d’articles via le bouton  en haut à droite, puis choisissez le fichier d'export de votre base articles depuis votre ordinateur : 

![](https://downloads.intercomcdn.com/i/o/tarury57/1997574035/8969c62bc35ed0d68daf27cd497b/CleanShot+2026-01-28+at+10_05_12.gif?expires=1788674400&signature=23b15fae1fdd6197967c9cc272ad25a715627e10f4105866baef27faa1d35870&req=dSkuEcx5mYFcXPMW3nq%2BgY2k7zHyYrCS7uMNJSYiWXs4Fr2eVwe67Yil4cHA%0A0sm0%2FIN%2F0cxAUWalAuA94Lw%2Bp4o%3D%0A)

### Matching ou correspondance des informations

> 💡 L'étape de **matching** consiste à faire correspondre les colonnes de votre fichier d'articles avec les informations attendues par InterFast. Si vous êtes parti du modèle InterFast, vous pouvez cliquer sur **Suivant** sinon il vous faudra faire correspondre les colonnes à importer.

Cette étape de correspondance présente deux colonnes : 

- La première (sur la gauche) liste les colonnes présentes dans votre fichier CSV
- La deuxième (sur la droite) liste les informations pouvant être importées dans InterFast

Pour faire importer des informations de votre fichier CSV, sélectionner pour chaque colonne à importer, la donnée InterFast qui correspond puis cliquez sur **Suivant** : 

![](https://downloads.intercomcdn.com/i/o/tarury57/1997577183/b57cebaa3bc1a300dddd17c4353d/CleanShot+2026-01-28+at+10_06_47%402x.png?expires=1788674400&signature=9edc996d46b254f4e3272178cab397ce07917b824bd80199b6195665ae4fb05a&req=dSkuEcx5moBXWvMW3nq%2BgXYf%2BFY%2FKOsyzB%2By5qDG6DGfwLf%2B%2FrzkzE3W5Sox%0AErQyEojd8p2KOr2LScr1lJKCwCk%3D%0A)

**Initialiser les stocks lors de l'import** Une fois vos colonnes d'articles configurées, une étape dédiée à la gestion des stocks vous sera proposée.

![](https://downloads.intercomcdn.com/i/o/tarury57/1997579982/972829d933ac1621c055c03aa03b/CleanShot+2026-01-28+at+10_08_13%402x.png?expires=1788674400&signature=02cb3007a8ad221c54ccb3fc87642ad4160c2f3afa2a225303ffb080be1bbe8f&req=dSkuEcx5lIhXW%2FMW3nq%2BgU3fRY%2Bi9IcCit4MBgABQsHzbuiMEV6KWIx8M4DX%0Asl8q6lFQjo9gSAAGQO5UV0RYI%2FI%3D%0A)

InterFast vous posera la question suivante : **"Votre fichier contient-il une colonne indiquant l'emplacement du stock ?"**

Deux options s'offrent à vous :

**Oui :** Si vous avez préparé une colonne "Emplacement" dans votre fichier CSV (utile si vous avez des stocks différents pour chaque article), vous pourrez sélectionner cette colonne pour faire la correspondance.

**Non :** Si vos articles vont tous au même endroit, vous pourrez sélectionner directement un emplacement de stock existant que vous aurez créé sur InterFast (ex: "Entrepôt principal" ou "Camion 1").

Avant de valider l'import des données, vérifiez que les articles à importer sont correctement reconnus par InterFast. Si ce n'est pas le cas, revenez en arrière avec le bouton **Retour** pour corriger le mapping.

![](https://downloads.intercomcdn.com/i/o/tarury57/1997582853/3a73d020814ea50041a64f25dd5b/CleanShot+2026-01-28+at+10_09_20%402x.png?expires=1788674400&signature=817e1dfb92c796549faf6ed7288f938399d5cebc97d85ed241ed891cc5e62ec9&req=dSkuEcx2n4laWvMW3nq%2BgWpZoxaO2mKhXlxJKA57VG%2F8%2BX5QavTgM1DBrBxr%0Ay8gxN5wFsKKXd43xvyndehXKLls%3D%0A)

> ✅ Vous savez désormais comment importer tous vos articles dans InterFast. Vous pouvez à présent les utiliser lors de l'[édition d'un devis](https://intercom.help/interfast/fr/articles/10245590-creer-un-devis).

## **III. Corriger une erreur en supprimant l'import**

Un mauvais mapping ou un fichier mal préparé a généré des erreurs dans votre Bibliothèque ? Pas de panique, la gestion de vos données est flexible.

Pour tout effacer et recommencer :

1. Allez dans **Mon entreprise > Paramètres**, puis descendez jusqu'à la section **Imports**.
2. Repérez votre import (grâce à la date) et cliquez sur l'icône **Corbeille**.

![](https://downloads.intercomcdn.com/i/o/tarury57/2450018564/e3e8a4cf64f1343872909d2edfa7/image.png?expires=1788674400&signature=10d27e26fbc0a9efc42b7d7a2241dbf3693d6edebab8380d8224375158197bfe&req=diQiFsl%2FlYRZXfMW3nq%2BgUALMf544xDmEPpvAYyaUKJ2IV0CX04MJJLEPHEE%0ADlz3og8trjBNe%2F48O4DwELhnF9Y%3D%0A)

Cela supprimera instantanément tous les articles et éventuels catalogues générés par ce fichier, vous laissant une base propre

## **IV. Questions fréquentes (FAQ)**

1) Malheureusement, InterFast ne permet pas encore d’emporter des sous-catalogues dans la bibliothèque.
​
Vos sous-catalogues seront donc importés... comme des catalogues.

2) Vous pourrez toutefois :
​
a) renommer spécifiquement vos sous-catalogues dans votre fichier csv
​
b) importer le fichier csv
​
c) recréez manuellement les sous-catalogues dans les catalogues principaux
​
d) supprimer les sous-catalogues importés pour déplacer les articles qu'ils contiennent dans le sous-catalogue de votre choix.

2. Utilisez la formule suivante : =CONCATENER(A2;" ";B2)
3. Étirez la formule sur toutes vos lignes.
