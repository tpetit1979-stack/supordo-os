## II. Étapes détaillées

### A. Ajouter des propriétés personnalisées à vos équipements

Vous souhaitez noter des informations spécifiques sur vos équipements, comme leur localisation ? C’est possible grâce aux propriétés personnalisées.

➡️ Rendez-vous dans **Mon entreprise > Paramètres > Propriétés personnalisées**

Vous pouvez y ajouter autant de champs que nécessaire (localisation, puissance, étage, etc.), en cliquant sur le bouton "créer une propriété". 

![](https://downloads.intercomcdn.com/i/o/tarury57/1510023343/bf8a82548495ba41adaa6d389810/CleanShot+2025-05-06+at+08_47_29%402x.png?expires=1788619500&signature=71879011d5922a902eaea3db8f273450901b49a0b95b6ea72dfd3afd454265e1&req=dSUmFsl8noJbWvMW1HO4zVbuLQMn8mkY131J7SEpGOgB9uXd5i3V0pSQ4dPF%0AuVJv6dsDTqs8uvJx5DU%3D%0A)

Chaque propriété peut être :

- Un texte (ex : "18e étage")
- Un nombre, une date, un choix multiple, etc.

*💡 Exemple d’usage :*
Si vous gérez un immeuble avec une climatisation par étage, vous pouvez créer une propriété “Localisation” pour préciser “Étage 1”, “Étage 2”...

![](https://downloads.intercomcdn.com/i/o/tarury57/1510021388/efedb5a6d324b3ff38700b608dcb/CleanShot+2025-05-06+at+08_45_05.png?expires=1788619500&signature=ba852d55f4662329634fa786e6fa6cab7a5c9ffe73a72a5ab50f3b306a53886c&req=dSUmFsl8nIJXUfMW1HO4zUv5BUNNInqX5Fhoruw9OulIcPhw3FJso6f%2F3IAu%0AI0ZqUWeKtrO40ZMDkJU%3D%0A)

> 🔎 **Besoin d’un coup de main pour créer vos propriétés personnalisées ?**
> Consultez notre article dédié ici 👉 [Créer des propriétés personnalisées](https://help.inter-fast.co/fr/articles/10253812-creer-des-proprietes-personnalisees).

### B. Créer vos propres types d’équipement

Pour aller plus loin, vous pouvez structurer vos équipements **par type**.

➡️ Rendez-vous dans **Équipements > Paramètres > Types d’équipements**
Cliquez sur **“Ajouter un type”** et définissez le nom du type.

*Exemple *: **Aérotherme Gaz**

Vous pouvez également associer une gamme de maintenance à ce type.


InterFast propose **plus de 200 gammes prêtes à l’emploi** !

Si vous ne trouvez pas celle qu’il vous faut, écrivez-nous dans le chat, nous l’ajouterons avec plaisir 😉.

### E. Remplir le rapport de maintenance

Depuis votre application mobile, vous pouvez intervenir chez le client et compléter le rapport d’intervention associé à la maintenance :

➡️ Ouvrez l’intervention planifiée
➡️ Vous retrouverez automatiquement :

- L’équipement concerné
- La gamme de maintenance associée
- Les points de contrôle à valider :
- Pressostat
- Fonctionnement sécurité gaz
- Nettoyage brûleur…

Il vous suffit de cocher ce que vous avez réalisé, valider, et le tour est joué 👌
Le rapport est prêt à être envoyé au client.

## III. Questions fréquentes (FAQ)

L’ordre d’affichage de vos propriétés personnalisées correspond strictement à l'ordre dans lequel vous les avez créées. Il n'est actuellement pas possible de modifier cet ordre a posteriori avec un glisser-déposer. Si vous souhaitez afficher la "Localisation" avant la "Puissance" par exemple, la seule solution consiste à supprimer les propriétés existantes pour les recréer une par une dans l'ordre désiré.



Pour que le pré-remplissage automatique fonctionne et évite la double saisie à votre technicien, trois conditions doivent être réunies :
1. L'équipement doit être rattaché à l'intervention lors de la planification.
2. L'équipement doit être associé à un *Type d'équipement* (lui-même lié à un sous-rapport).
3. Votre modèle de rapport d'intervention principal doit obligatoirement contenir le widget « Rapports non référencés ».

L'Intelligence Artificielle vous fait gagner du temps en pré-remplissant les champs, mais vous gardez toujours le contrôle final. Si la photo de la plaque est floue, effacée ou mal éclairée, il se peut que l'IA confonde un caractère. Vous pouvez tout à fait cliquer dans le champ concerné (comme le Numéro de série) pour corriger manuellement l'erreur avant d'enregistrer l'équipement.


L'analyse intelligente de l'image par l'IA nécessite une connexion internet. Si vous êtes dans une "zone blanche" sans réseau, prenez simplement la plaque en photo avec l'appareil de votre téléphone de manière classique. Une fois le réseau retrouvé, vous pourrez importer cette photo dans la fiche de création de l'équipement pour déclencher le pré-remplissage automatique !
