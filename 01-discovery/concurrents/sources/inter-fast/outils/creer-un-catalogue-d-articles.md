# Créer un catalogue d'articles

> 🔔 Le catalogue d'InterFast aura le même usage qu'un dossier dans lequel vous pourrez intégrer des articles et/ou ouvrages. Cela vous permettra de mieux vous organiser dans la gestion de votre bibliothèque en créant des catalogues et sous-catalogues par type de matériaux, métiers ou autres.

## I. Comment créer un catalogue ?

Pour créer un nouveau catalogue, il vous suffit d'aller dans "**Bibliothèque**" cliquer sur le bouton "**+ Nouveau catalogue**" puis de lui attribuer le nom de votre choix.

## II. Comment créer un sous-catalogue

Dans la continuité, vous pouvez également créer des sous-catalogues dans les catalogues. Rien de plus simple. Vous cliquez sur les 3 petits points à droite d'un catalogue, et vous aurez accès à un menu dans lequel vous pouvez choisir l'option "**Ajouter un sous-catalogue**". De la même manière vous nommez votre sous-catalogue et vous cliquez sur "**créer**".
