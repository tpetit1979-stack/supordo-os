# Archiver un Client

## Explications des étapes


Sur l'application web d'InterFast :
​

1) Cliquez sur le module "CRM"
​
2) Recherchez le client que vous souhaitez archiver.
​
3) Cliquez sur le nom du Client pour afficher sa fiche complète.
​
4) Cliquez sur le bouton "Actions".

![](https://downloads.intercomcdn.com/i/o/tarury57/1397637792/f1ed28609e61843b4601d258089d/CleanShot+2025-02-26+at+12_54_30.png?expires=1788619500&signature=6e8a35730d41030da5107857d47ad6c190a41b18796761c7b697ff4137465cd7&req=dSMuEc99moZWW%2FMW1HO4zX2fFuAM22MrJoWB2VW9kqNIkgWYNi0TcFgoVx8R%0AewrqHbKPzlAvMNdsAsM%3D%0A)


5) Cliquez sur l'action "Archiver"

![](https://downloads.intercomcdn.com/i/o/tarury57/1397638501/3157b2fea0bb6452cce5fe76c4da/CleanShot+2025-02-26+at+12_54_47.png?expires=1788619500&signature=4f8d8ab293140a3a642d22fe9bb29e6b4e1cb33e65d98ec44d41611ca7635c51&req=dSMuEc99lYRfWPMW1HO4zbBZIyzFlJcH3hE8Wg4%2BkqlDcaD8%2FDWYCb1wFf2L%0AultpFDRNZDFwqQ5Jj%2F4%3D%0A)
