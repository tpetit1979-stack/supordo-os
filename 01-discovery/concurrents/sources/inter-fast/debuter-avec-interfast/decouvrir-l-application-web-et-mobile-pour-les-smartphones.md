# Découvrir l'application Web et Mobile pour les smartphones

[Vidéo YouTube](https://www.youtube.com/watch?v=SQS7MX8P2Bc)

## I. Application de gestion

> 💡 L'application de gestion est une application WEB (ou site internet) qui permet aux utilisateurs d'accéder à l'ensemble des fonctionnalités de gestion de l'entreprise **en fonction des droits associés à son rôle** (tous exceptés les rôles *Technicien*, *Stagiaire / alternant* et *Sous-traitant*).

### Depuis un navigateur WEB

Les utilisateurs habilités peuvent accéder à l'application de gestion à travers un navigateur WEB (*Google Chrome*, *Safari*, *Firefox*…). Pour cela, il leur suffira de saisir l'adresse [https://app.inter-fast.fr](https://app.inter-fast.fr/).

### Depuis un smartphone ou tablette iOS

Si vous utilisez un smartphone ou une tablette Apple, vous pouvez accéder à l'application de gestion depuis un navigateur WEB ou en l'installant comme une application native (installée depuis l'AppStore).

Lorsque vous installez l'application de gestion, une icône InterFast est ajoutée à votre écran d'accueil et vous y accédez comme une application mobile. Pour cela, accéder à l'application WEB via Safari en saisissant l'adresse [https://app.inter-fast.fr](https://app.inter-fast.fr/) puis :

### Depuis un smartphone ou tablette Android

Si vous utilisez un smartphone ou une tablette Android, vous pouvez accéder à l'application de gestion depuis un navigateur WEB ou en l'installant comme une application native (installée depuis Google Play).

Lorsque vous installez l'application de gestion, une icône InterFast est ajoutée à votre écran d'accueil et vous y accédez comme une application mobile. Pour cela, accéder à l'application WEB via Google Chrome en saisissant l'adresse [https://app.inter-fast.fr](https://app.inter-fast.fr/) puis :

## II. Application Terrain

> 💡 L'application Terrain est une application mobile dédiée à l'utilisation d'InterFast sur le terrain en fournissant une expérience dédiée au remplissage de **rapports d'interventions** avec un smartphone ou une tablette.

Pour installer l'application Terrain, rendez-vous sur Google Play pour les terminaux Android ou sur l'AppStore pour les terminaux Apple.
