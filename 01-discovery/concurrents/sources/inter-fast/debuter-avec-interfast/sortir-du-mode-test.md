# Sortir du mode test

> 💡 Le **Mode test** est activé, par défaut, à la création d'un compte entreprise. Il vous permet de tester InterFast, durant votre période d'essai, puis de réinitialiser votre compte entreprise pour repartir à zéro *ou presque* !
> N'oubliez donc pas d'en sortir avant de commencer votre vraie utilisation de notre logiciel.

> ⚠️ **Avant de sortir du mode test : attention aux documents finalisés**
> Le Mode test est fait pour vos essais : créez-y de faux devis et factures, puis réinitialisez vos données à volonté.
> En **usage réel**, c'est différent : un devis ou une facture **finalisé et numéroté ne peut plus être supprimé**, conformément à la législation anti-fraude à la TVA (numérotation continue obligatoire). Avec l'arrivée de la **facturation électronique**, ces règles se durcissent encore. Seuls les documents au statut **Brouillon** peuvent être supprimés.
> - Pour tester sans risque en usage réel → gardez vos documents en **Brouillon**.
> - Pour corriger un document déjà numéroté → créez un **avoir** (facture) ou passez-le en **Annulé** (devis).

## **II. Sortir du mode test**

Vous avez fini vos tests et voulez passer à une utilisation réelle d'InterFast ? Nous vous laissons le choix :

- Conserver les données ajoutées durant vos tests
- Supprimer seulement certains types de données
- Supprimer toutes vos données

Pour ce faire, il vous faut cliquer sur l'option  dans le menu de navigation puis cliquez sur ''Je commence''

![](https://downloads.intercomcdn.com/i/o/tarury57/1295505569/888c80f8e1dfa5980ba5cefa6563/Capture-2024-12-12+at+23_56_11.png?expires=1788618600&signature=38b60a95a498e072e398c22b92db87631508a408599ac40e146c754e67203754&req=dSIuE8x%2BmIRZUPMW1HO4zRfW76NU2JFS8%2Fo8g1EutvaC0ADN1d7JfDQAAOme%0AeZ2FSUcYbu5YPZqtHSI%3D%0A)

Ensuite, vous aurez la possibilité de conserver vos données ou de supprimer tout ou partie de vos données.

Vous pouvez commencer à utiliser InterFast en mode réel à tout moment, même pendant la période d'essai, et supprimer les données de test que vous avez générées.

### A. Sortir du mode test en conservant toutes les données

Si vous souhaitez garder l'ensemble de vos données, vous pouvez cliquer sur Je conserve mes données.

> ⚠️ Si vous êtes sorti du mode test par erreur, écrivez nous dans le chat pour que nous puissions vous le réactiver. 
> De votre côté, vous ne pourrez pas revenir en arrière. 

### B. Sortir du mode test en sélectionnant les données à supprimer

Lorsque vous souhaitez passer à un usage réel en conservant une partie de vos données (par exemple : vos clients importés), il vous faut sélectionner l'option  puis . 

Vous serez ensuite invité à supprimer vos données type par type (dépenses, bibliothèque, devis...) :

![](https://downloads.intercomcdn.com/i/o/tarury57/1295511451/c8255447aa4525ebac120d6103c7/Capture-2024-12-13+at+00_01_20.gif?expires=1788618600&signature=394d02c8d42b80572d697b581721f03fd3ba9252f59ecf74680a2dfc7eea1710&req=dSIuE8x%2FnIVaWPMW1HO4zSBXh5PwyYhvJS6pi4O6nQgIhP0OfuzuHhiuSJ9K%0An%2F4H9F8LDTtfEzZkPrk%3D%0A)

> ✅ Lorsque vous avez terminé de supprimer vos données, vous pouvez sortir du mode test en cliquant sur le bouton . 
> Vous pouvez aussi choisir de continuer en mode test et passer à un usage réel plus tard.

### C. Sortir du mode test en supprimant toutes les données

Lorsque vous souhaitez passer à un usage réel en supprimant toutes vos données, il vous faut sélectionner l'option . 

Vous serez ensuite invité à confirmer l'opération.

## III. Questions Fréquentes (FAQ)

Une fois que vous avez quitté le mode test et validé votre passage en "Mode Réel", il n'est plus possible d'y retourner par vous-même depuis l'application. 

Cependant, pas de panique : contactez simplement notre équipe Support via le tchat en ligne. Un conseiller pourra réactiver manuellement le mode test sur votre compte pour vous permettre de finaliser la suppression de vos données



Rassurez-vous, sortir du mode test ne vous fera pas perdre votre travail de paramétrage. Les informations fondamentales de votre entreprise (votre logo, votre adresse, votre SIRET ou encore votre paramétrage de numérotation) ne sont jamais effacées lors de cette manipulation. 

Vous pouvez nettoyer vos données d'essai et passer en mode réel en toute sérénité.


En raison de la facturation électronique qui entre en vigueur, on a mis en place une petite alerte pour vous inviter à sortir du mode test si vous avez oublié de le faire.
