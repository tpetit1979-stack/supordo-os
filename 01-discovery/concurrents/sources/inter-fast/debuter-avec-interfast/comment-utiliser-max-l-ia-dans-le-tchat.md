# Comment utiliser Max (l’IA) dans le tchat ?

> 🔔 Max est disponible **24h/24 et 7j/7**. Il a été formé sur l'intégralité de notre Centre d'aide et de nos vidéos pour vous apporter une réponse immédiate. Si votre demande nécessite une expertise humaine, il saura passer le relais à notre équipe Care.

## I. Qui est Max et comment fonctionne-t-il ?


Max est l'intelligence artificielle native d'InterFast. Contrairement à un tchat classique, il ne se contente pas de vous orienter : il analyse votre question pour vous proposer une solution concrète et personnalisée.

### 
A. Comment contacter Max via le support InterFast ?

Pour échanger avec notre assistant Max, suivez ces étapes depuis votre interface :

1. **Menu latéral** : Dans votre espace InterFast, descendez tout en bas du menu situé à gauche.
2. **Support en ligne** : Cliquez sur le bouton pour ouvrir la fenêtre d'assistance.
3. **Lancer la discussion** : Une fois la fenêtre ouverte, deux chemins sont possibles :
- Cliquez directement sur **"Envoyez-nous un message"**.
- Ou rendez-vous dans l'onglet **"Conversations"**, puis cliquez sur **"Envoyez-nous un message"**.

### C. Exemple concret : Résoudre un problème de facture avec Max

**1. Votre question (Le Prompt) :**

*"Salut Max ! J'ai finalisé une facture par erreur pour le client Martin. Je me suis trompé sur le montant. Comment je peux faire pour corriger ça ?"*
​

**2. L'analyse de Max :** Max identifie immédiatement que la facture est "Finalisée". Il sait que la loi anti-fraude interdit la suppression simple.
​

**3. La solution immédiate :** Au lieu de vous laisser chercher, Max vous répond :

- *"Une facture finalisée ne peut plus être modifiée directement. La procédure légale est de créer un **Avoir**."*
- Il vous guide ensuite : *"Allez sur la facture concernée > Cliquez sur le bouton 'Créer un avoir' > Validez."*
- Etc.

**4. Le petit plus :** Max vous affiche simultanément un lien direct vers l'article de notre centre d'aide, associé à votre question  : Exemple : **"Créer une Facture d'avoir client"** au cas où vous auriez besoin de captures d'écran pour vous guider.

## 
III. Prompts prêts à l’usage : Comment parler à Max ?

Pour gagner du temps, n'hésitez pas à poser des questions directes. Voici quelques exemples de "prompts" (phrases types) que Max comprend parfaitement :

- **Pour la facturation :** *"Comment créer un avoir sur une facture déjà finalisée ?"*
- **Pour le paramétrage :** *"Je veux modifier le taux de TVA par défaut sur mes devis."*
- **Pour la mobilité :** *"Comment ajouter une photo à un rapport d'intervention sur l'application mobile ?"*
- **Pour les exports :** *"Génère-moi la procédure pour exporter mes factures vers mon comptable."*

## IV. Que se passe-t-il après un transfert ?

Si Max vous informe qu'il a passé le relais à l'équipe Care, voici ce qu'il faut savoir :

1. **Analyse du contexte :** Avant de donner la main à un humain, Max prépare une synthèse de votre échange pour que le conseiller ne vous fasse pas répéter.
​
2. **Nouvelle question ?** Si pendant l'attente d'un conseiller vous avez une autre question différente, vous pouvez demander à Max de reprendre la main temporairement.
​
