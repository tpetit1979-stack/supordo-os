# Créer un Modèle d'e-mail

> 💡 Les modèles d'email permettent de gagner du temps à chaque envoi et assurent l'efficacité des échanges grâce aux variables dynamiques.

[Vidéo]()

## II. Création d'un modèle d'email

A) Cliquez sur Mon entreprise > Paramètres > [Email](https://app.inter-fast.fr/dashboard/company?tab=settings&settings=emails)

![](https://downloads.intercomcdn.com/i/o/tarury57/1417491182/a51c88fbb0d7539230525a446fb6/CleanShot+2025-03-11+at+21_24_59.png?expires=1788619500&signature=d009d92088c7296818b4edb1e81575e7c508dbf5cdee5fb489668e718325b70f&req=dSQmEc13nIBXW%2FMW1HO4zRr%2BnlaekiDH46MCsS7XmB8rADqghRML5laSYPSF%0ASQpJ2DtLJopvCAzKLv8%3D%0A)


B) Cliquez sur le bouton bleu "+ Ajouter un modèle"


C) Une pop-up apparaît sur votre écran :

![](https://downloads.intercomcdn.com/i/o/tarury57/1417498450/7685df78cd5c530f6c37edb9df37/CleanShot+2025-03-11+at+21_28_57.png?expires=1788619500&signature=786e6e0c9d23f2a0987bb0f7d2546368c97ee42c3973df13be0dfd1a1e9a6054&req=dSQmEc13lYVaWfMW1HO4zbmed2ETlo9PE0l5eZrG16UnsS6buiv%2BmsStxp5y%0ASA0T72yZpBx55VSh74Q%3D%0A)


​**Indications :**

1. Utilisez nos modèles prédéfinis pour différents scénarios
2. Nommez votre modèle pour une identification facile lors de l'envoi
3. Choisissez la catégorie des documents associés au modèle
ex: Devis / Factures / Interventions / Signature de devis
4. Déterminez l'objet de l'email
> vous pouvez insérer des variables
5. Rédigez le corps de l'email
> vous pouvez insérer des variables
6. Définissez le modèle par défaut pour une sélection automatique lors des envois

D) Cliquez sur le bouton "Créer" lorsque votre modèle d'email est prêt à être publié.
​

> ✅ N'insérez pas votre signature dans le corps de l'email.
> La signature se définit à l'échelle de chaque profil Utilisateur.

Depuis le tableau de vos modèles d'email, vous pouvez cliquer sur le bouton "Actions" pour :

- Modifier le modèle
- Supprimer le modèle

A) Cliquez sur le bouton "Actions" > "Envoyer par email" ou "Envoyer pour signature"
