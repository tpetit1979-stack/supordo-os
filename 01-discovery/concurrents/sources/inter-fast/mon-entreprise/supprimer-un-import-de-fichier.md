# Supprimer un import de fichier

> 💡 Il peut arriver qu'un import de fichier (clients, articles, etc.) ne se passe pas comme prévu : erreurs de colonnes, doublons, ou mauvais fichier sélectionné. Rassurez-vous, sur InterFast, vous n'avez pas besoin d'effacer les fiches une par une à la main ! Vous pouvez annuler l'import complet en quelques clics pour nettoyer votre base et repartir de zéro

## I. La marche à suivre pour supprimer un import

Pour supprimer un import de fichier, la procédure est très simple :

1. Dans le panneau latéral gauche de votre écran, cliquez sur **Mon entreprise**, puis rendez-vous dans les **Paramètres**.
2. Descendez tout en bas de la page jusqu'à trouver la section **[Imports](https://app.inter-fast.fr/dashboard/company?tab=settings&settings=imports)**. Vous y verrez l'historique des fichiers importés.
3. Repérez le fichier que vous souhaitez annuler dans la liste, puis cliquez simplement sur l'icône en forme de **Corbeille** pour le supprimer

## Conclusion

La gestion de vos données reste flexible sur InterFast ! L'erreur est humaine, et cette fonctionnalité de suppression d'import est justement conçue pour vous permettre de nettoyer rapidement votre environnement en cas de mauvaise manipulation. Vous gardez ainsi une base de données propre et saine. En cas de doute avant de cliquer sur la corbeille, n'hésitez pas à solliciter notre équipe Care depuis le tchat en ligne !

## Questions Fréquentes


Il n'est pas nécessaire de supprimer les fiches une par une. Allez dans **"Mon entreprise" > "Paramètres"**, descendez jusqu'à la section **"[Imports](https://app.inter-fast.fr/dashboard/company?c=settings&settings=imports)"** (souvent tout en bas de la page).

Repérez votre fichier dans la liste et cliquez sur l'icône **Corbeille** pour le supprimer. Cela effacera automatiquement toutes les données créées par cet import spécifique. Vous pourrez ensuite réimporter votre fichier corrigé.



Tous les clients créés dans le CRM par ce fichier d'import seront supprimés.
​
⚠️ Une seule exception : les clients qui auraient entre-temps été associés à un devis ou une facture définitifs (avec un numéro officiel). En effet, la loi anti-fraude à la TVA impose de conserver toutes les informations en lien avec la facturation en cours. Ces clients-là ne seront donc pas supprimés de votre base.
