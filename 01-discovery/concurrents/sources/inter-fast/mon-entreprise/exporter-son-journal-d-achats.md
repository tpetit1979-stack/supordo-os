# Exporter son Journal d'achats

> 👉 Nous vous invitons à consulter notre tutoriel détaillé pour plus d'informations sur [le paramétrage comptable](https://help.inter-fast.co/fr/articles/10253840-parametrer-l-export-comptable) sur InterFast.

[Vidéo YouTube](https://www.youtube.com/watch?v=nq6_2H-XEhA)

InterFast vous offre la possibilité d'exporter votre journal d'achats, ainsi que toutes les factures associées. Ces données pourront être ensuite analysées et intégrer votre bilan d'entreprise.

## **I. Générer le Journal d'achats**

- Allez dans l'onglet Dépenses > [Factures](https://app.inter-fast.fr/dashboard/expenses)
​
- Filtrez sur la plage de dates souhaitée
- *Astuce : utilisez le filtre rapide "Exercice comptable actuel" ou "Mois dernier"*

![](https://downloads.intercomcdn.com/i/o/tarury57/1862557530/591122a589682280953f4c185f56/image.png?expires=1788619500&signature=ba81e8f91204a543206c43c80e8b0d6e4f0259499d33d556e6d5c9b652f73567&req=dSghFMx7moRcWfMW1HO4zfK1p34mqpiGTSPyJnAf6RN6xZUfyVsbHUk8PBnX%0Aov5blXaaIXWBQ6Qs8fQ%3D%0A)

- Cliquez sur le bouton "**Exporter**" en haut à droite et choisissez :
- **Export comptable :** pour le fichier CSV contenant les écritures comptables (débits/crédits) du journal d'achats
- **Export des justificatifs :** pour télécharger l'archive ZIP contenant les PDF de toutes les dépenses correspondantes.

![](https://downloads.intercomcdn.com/i/o/tarury57/1862557533/aaf067cff23aa2043d4db5f478a9/image.png?expires=1788619500&signature=6736aadd1f2e21b4cf0e7af2bb33bf7f04555e7e92ef95e8b1c04129ec75658e&req=dSghFMx7moRcWvMW1HO4zVnz6fKObSRcAylwHhSFL3bs5PMOB8YzTQhNhef2%0ANXOejadOl0gM1pgmbWc%3D%0A)

## **II. Exploiter le Journal d'achat**

- Ouvrez le fichier Journal-Achats.csv

![](https://downloads.intercomcdn.com/i/o/tarury57/1861801395/d893a2ded816df4d17f6324156c4/image.png?expires=1788619500&signature=7420a24b45e6b182c87f5efa0b63a9b9bebc35be9bba65e5a913ef03c155ffaa&req=dSghF8F%2BnIJWXPMW1HO4zfGys8%2B64uP%2BhsAz0gMfzMKdggK%2BOLoB0xfY1SB8%0Al1%2B7%0A)
- Conformément aux paramétrages, le Journal d'achats contient :
​
- les informations sur les dépenses *(ex: N° de référence - en rouge)*
- le Code journal *(en jaune)* ;
- les comptes de TVA *(ici au global - en violet) au débit*
- les comptes clients *(en vert)* au crédit

![](https://downloads.intercomcdn.com/i/o/tarury57/1862557537/21ef45bed31b9ef9c999a0c6ea5d/image.png?expires=1788619500&signature=010d0d678454bad9139939ad0f2e98dd8183d5dccd5441366eee4f516acb187d&req=dSghFMx7moRcXvMW1HO4zT%2FLSVZZ3WKHLSVBy73cmJccqmD7DqzMHhx3X%2B5F%0AdqqRh0o6CQ5ypajwEAw%3D%0A)

Ainsi, le Journal d'achat est prêt à l'emploi pour l'analyse de votre Expert-Comptable.
​

> ⚡ InterFast ne permet pas encore de personnaliser le libellé des colonnes de l'export comptable, afin qu'il respecte une nomenclature spécifique. Des améliorations techniques sont activement considérées par nos équipes.

## **III. Exploiter l'Export des factures**

- Ouvrez l'archive Export-justificatifs.zip
*NB. les utilisateurs Windows devront utiliser [7-Zip](https://www.7-zip.org/) pour ouvrir l'archive.*
![](https://downloads.intercomcdn.com/i/o/tarury57/1861813219/679bc05d38bf783f8f89a1bfbb68/image.png?expires=1788619500&signature=0db753ecb1a85aa2892cc51e8e6b679165fd7e5d2eea05e0fa00fceb2a6f132a&req=dSghF8F%2FnoNeUPMW1HO4zZJC3SZLJQKYsClVUbun3VAGSIi7g15XTEXy%2BIK8%0AOtXO%0A)
- Accédez aux factures fournisseurs *(format image ou PDF)* associées à votre export comptable
