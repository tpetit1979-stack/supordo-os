# Connecter Batiprix à InterFast

## I. Vidéo de présentation

> Dans cette vidéo, vous découvrirez comment connecter votre compte Batiprix à InterFast et importer facilement des ouvrages professionnels directement dans vos devis.
> Batiprix met à disposition **plusieurs milliers d’ouvrages actualisés**, classés par corps d’état. Grâce à l’intégration InterFast, vous pouvez les rechercher, les sélectionner et les insérer en un clic.

[Vidéo YouTube](https://www.youtube.com/watch?v=JrX9iZq4EvI)

## II. Installer et utiliser Batiprix dans InterFast

### A. Obtenir votre clé Batiprix

Pour activer Batiprix dans InterFast, il vous faut une **clé API personnelle**, fournie par Batiprix.

Comment l’obtenir :

1. Rendez-vous sur le site Batiprix.
2. Ouvrez la section **Partenaires** et cherchez InterFast.

![](https://downloads.intercomcdn.com/i/o/tarury57/1862979345/63f0f6e1e8572973bfc3bb3dc4ed/CleanShot+2025-12-03+at+14_14_42.gif?expires=1788619500&signature=b0aec7b745fa3fef8750c917d77050474fe437d717f822eba91356a7162690e4&req=dSghFMB5lIJbXPMW1HO4zdMXTYgP7EPVpv86FrMEH5NFZWTLg6LZWnVbDnj0%0AxQuy%0A)
3. Demandez :

- soit une **période d'essai** (généralement 24 à 48 h),
- soit votre **clé API définitive** après souscription.

![](https://downloads.intercomcdn.com/i/o/tarury57/1862980675/b75bc4fb3590c87199465009782b/CleanShot+2025-12-03+at+14_15_16%402x.png?expires=1788619500&signature=3ace69cce9f965317b420e5c7ee8424659a9838dd2928facfa74b867047c5283&req=dSghFMB2nYdYXPMW1HO4zR%2FTxoMEn5MmcWRad88pZum%2F8yb8jk7Bh0Jb2I5W%0AdHOj%0A)

Cette clé vous permettra de tester la bibliothèque directement depuis InterFast.

### B. Activer Batiprix dans InterFast

Une fois votre clé API obtenue :

1. Allez dans votre **Profil utilisateur**.
2. Ouvrez l’onglet **Intégrations**.
3. Collez votre **clé API Batiprix** dans le champ dédié.
4. Cliquez sur **Tester la connexion** pour vérifier que tout fonctionne.

![](https://downloads.intercomcdn.com/i/o/tarury57/1862953716/bcb246a4746698d120bd95a7e92b/CleanShot+2025-12-03+at+14_18_21%402x.png?expires=1788619500&signature=a29792a543ec3bccf3137fe2c109def5ddc5b31f0ffa5bc3690c02bf346ef072&req=dSghFMB7noZeX%2FMW1HO4zSEhTRMtjLJs3P%2BMtwdU6pZP0ho8NvkZRCs7UkM0%0AtTwxubKPR5I2y2BM2EA%3D%0A)

Si le test est validé, la connexion est opérationnelle : vous pouvez passer à la création de devis.

> ⚠️ Si le test n'est pas validé, vérifiez que vous avez copié / collé correctement la clé. Essayez également de la renseigner manuellement.
> Si cela ne fonctionne toujours pas, écrivez-nous dans le tchat pour que l'on regarde ensemble.

### C. Utiliser Batiprix dans vos devis

Accéder à la bibliothèque depuis un devis

1. Rendez-vous dans le module **Devis**.
2. Créez un nouveau devis ou ouvrez-en un existant.
3. Cliquez sur **Ajouter un élément**.
4. Un nouveau bouton apparaît : **Batiprix**.

![](https://downloads.intercomcdn.com/i/o/tarury57/1862991466/45ac8c1cddc84cb6d897733a8506/CleanShot+2025-12-03+at+14_36_32%402x.png?expires=1788619500&signature=114caaa60c4c4b9f67ddbcb52e084cd5a530b7b4d413e00e4c5aa0537a06e766&req=dSghFMB3nIVZX%2FMW1HO4zR%2FHKbDP%2BYOM4MZxRppGQ7dJ1jAjq9DM%2BZXNzYZO%0AFXSTDTOjvTgXeE8LMdE%3D%0A)

En cliquant dessus, la bibliothèque Batiprix se charge automatiquement.

## III. Questions / problèmes fréquents


Oui, l’accès à Batiprix est en supplément d’InterFast.
​
Cependant, nous proposons une **offre partenaire** avantageuse que vous pouvez retrouver directement [sur cette page](https://www.batiprix.com/content/177-interfast).
Vous avez également la possibilité de demander **une clé API de test** gratuit en remplissant [le formulaire](https://offre.batiprix.com/global/essai-gratuit) prévu à cet effet.

Une fois la clé obtenue, il suffira de la renseigner dans votre **profil Utilisateur** pour activer Batiprix dans InterFast.



Chaque utilisateur doit demander sa propre clé Batiprix : elle n’est pas valable pour les autres utilisateurs d'un même compte entreprise.
> une clé = un utilisateur.
