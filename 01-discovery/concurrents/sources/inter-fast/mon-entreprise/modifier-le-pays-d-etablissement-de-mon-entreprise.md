# Modifier le pays d'établissement de mon entreprise

Si votre société est située hors France métropolitaine (ex: Belgique ou Suisse), il est important de sélectionner le bon pays. 

Le logiciel ajustera alors automatiquement les champs d'adresse lors de l'enregistrement d'un nouveau client ou fournisseur, pour correspondre aux formats belges ou suisses, ce qui vous permettra de choisir la bonne adresse.

Pour le faire il faudra vous rendre dans mon "Entreprise" ensuite dans "Description" et enfin en bas à droite dans ''Informations'' vous cliquez sur le petit stylo et vous modifiez le pays.
