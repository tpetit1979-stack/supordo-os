# Parrainer un Artisan sur InterFast

> Le système de parrainage vous permet de faire découvrir InterFast à d’autres entreprises du bâtiment avec les avantages suivants pendant 12 mois :
> - **pour votre filleul :** -15% de réduction sur son abonnement
> - **pour vous :** rétrocommission de 10% des paiements HT de vos filleuls, en déduction de vos prochaines factures
> C'est gagnant-gagnant 🤝

## III. Expérience côté Filleul

Lorsqu’une nouvelle entreprise clique sur votre lien de parrainage, elle est redirigée vers la page de création de compte InterFast.

👉 Le **code promo est automatiquement appliqué** sur son compte dès l’inscription.

Aucune manipulation n’est nécessaire : tout se fait automatiquement.

Ainsi, elles pourront tester gratuitement InterFast pendant 7 jours ! 🎉

## IV. Cas d'un filleul avec un compte

Si la personne que vous parrainez possède déjà un compte InterFast, elle peut tout de même profiter du parrainage **à condition qu’elle n’ait pas encore d’abonnement payant.**

Dans ce cas :

- Le filleul doit **contacter le support** via le chat ou l’email de contact.
- Il lui suffit d’indiquer le **nom de l’entreprise de son parrain** pour que le lien soit fait manuellement par notre équipe.

> 💡 **Important :** le parrainage ne peut pas être appliqué rétroactivement sur un compte payant déjà actif.

## V. Questions fréquentes (FAQ)

- Exceptionnellement, il est possible d'appliquer un code de parrainage après votre abonnement*,* mais sans effet rétroactif.
- Pour que l'équipe puisse effectuer la vérification et l'ajustement, vous devez transmettre dans le support en ligne le nom de votre parrain ainsi que le nom de son entreprise enregistrée sur InterFast.
- Une fois ces informations validées, la remise sera appliquée manuellement sur votre compte entreprise par l'équipe Care ET les crédits de parrainage seront appliqués sur **votre prochaine facture**.

- L'équipe Support effectue une double vérification systématique après l'application d'un code de parrainage.
- Vous pouvez toujours demander à l'Équipe Care qu'un lien entre votre compte et celui de votre parrain est correctement établi et que les avantages sont effectifs pour les deux parties.


- La nature des remises peut varier selon la source du code.
- Certains codes sont à durée limitée, tandis que d'autres peuvent avoir des conditions d'utilisation différentes selon les accords commerciaux en vigueur.
- Vous pouvez tester votre code de réduction sur la page "[Mon Abonnement](https://app.inter-fast.fr/dashboard/company?c=billing)".

- Vous pouvez parfaitement parrainer plusieurs membres grâce à votre lien personnel, créé depuis la page "[Mon Abonnement](https://app.inter-fast.fr/dashboard/company?c=billing)".
​
- Vous pouvez également mettre InterFast en relation avec les responsables de votre réseau ou coopérative pour organiser une présentation commune du logiciel. Choisissez un créneau dans l'[agenda en ligne](https://meetings.hubspot.com/hedi7/demo-interfast?uuid=8e369f5a-5697-48a3-9867-e2b713640c66) de notre équipe commerciale pour en discuter directement.
