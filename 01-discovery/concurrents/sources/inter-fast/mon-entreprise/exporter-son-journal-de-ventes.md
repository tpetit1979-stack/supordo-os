# Exporter son Journal de ventes

> 👉 Nous vous invitons à consulter notre tutoriel détaillé pour plus d'informations sur [le paramétrage comptable](https://help.inter-fast.co/fr/articles/10253840-parametrer-l-export-comptable) sur InterFast.

[Vidéo YouTube](https://www.youtube.com/watch?v=ijslkkhWhX0)

InterFast vous offre la possibilité d'exporter votre journal de ventes, ainsi que toutes les factures associées. Ces données pourront être ensuite analysées et intégrer votre bilan d'entreprise.

## **I. Générer le Journal de ventes**


- Allez dans l'onglet Ventes > [Factures](https://app.inter-fast.fr/dashboard/billing/bills?bill=%7B%22pageIndex%22%3A0%7D)
- Filtrez sur la plage de dates souhaitée
- *Astuce : utilisez le filtre rapide "Exercice comptable actuel" ou "Mois dernier"*

![](https://downloads.intercomcdn.com/i/o/tarury57/1861644740/b372201584c192fcd21abf07ab46/image.png?expires=1788619500&signature=e8ef7f1d43b0422904ac1aa38c277367a8575e2e098d7ab0f0efd08d257a294c&req=dSghF896mYZbWfMW1HO4zcGEuniN5q6wnGrav0KwDobs8NAPrDI4oCDiCTje%0AO6yp%0A)
- Cliquez sur le bouton "**Actions"** et choisissez :
- **Journal des ventes :** pour le fichier CSV des écritures comptables *(débits/crédits)*.
- **Export des documents :** pour télécharger l'archive ZIP de tous les PDF correspondants *(pièces justificatives)*.

![](https://downloads.intercomcdn.com/i/o/tarury57/1861646470/ea75934f0dfe890c70a69a6aca4d/image.png?expires=1788619500&signature=4cd6997a26d6ca499d13470982378d7f42f08640d750b9078bf1d15beb0b59e7&req=dSghF896m4VYWfMW1HO4zeH%2BooIZIZOrXEjZfPDr%2F%2BStC2wbL%2Fq3yxcQlKA9%0A%2Fg9P%0A)

## **II. Exploiter le Journal de ventes**


- Ouvrez le fichier Journal-Ventes.csv

![](https://downloads.intercomcdn.com/i/o/tarury57/1861649584/35b46f05abdcafc4693bc8d3078c/image.png?expires=1788619500&signature=b67d048607b75ad080b4214f9b68dd8444e337d30251ff3b08a7da16e5774501&req=dSghF896lIRXXfMW1HO4zd7rM28LJREazj4sl8YZPz%2F0PgHlZCNUwWljgmeB%0A1gKv%0A)
- Conformément aux paramétrages, le Journal de ventes contient :
​
- les informations sur les factures finalisées *(ex: N° de référence - en rouge)*
​*NB. les factures au statut "**Brouillon**" n'intègrent pas l'export comptable*
​
- le Code journal *(en jaune)* ;
- les comptes de TVA *(ici au global - en violet) au crédit*
- les comptes clients *(en vert)* au débit
- l'analytique par agence *(en bleu)*.

![](https://downloads.intercomcdn.com/i/o/tarury57/1862531822/e96ecd8ef6e6e9baed128971ac30/image.png?expires=1788619500&signature=33e50e4f14799f8b06f36a5bcb33c2d6cffa0650b6d9a2151511b1b97b6907bb&req=dSghFMx9nIldW%2FMW1HO4zfFj9FdkG4aHePRygUmc1UJ9%2FMkizt9VOmHzLJgQ%0A4%2FKTnjQt1VlIxDofyhA%3D%0A)

- Ainsi, le Journal de ventes est prêt à l'emploi pour l'analyse de votre Expert-Comptable
​

> ⚡ InterFast ne permet pas encore de personnaliser le libellé des colonnes de l'export comptable, afin qu'il respecte une nomenclature spécifique. Des améliorations techniques sont activement considérées par nos équipes.

## **III. Exploiter l'Export des factures**


- Ouvrez l'archive Export-factures.zip
*NB. les utilisateurs Windows devront utiliser [7-Zip](https://www.7-zip.org/) pour ouvrir l'archive.*
![](https://downloads.intercomcdn.com/i/o/tarury57/1861666193/9dc502fd9f8892ed4eb7dda34aec/image.png?expires=1788619500&signature=e712ad91c078e8744eb527b3cc8aca1a8b08744788a22a64ef81a52099ab8b6d&req=dSghF894m4BWWvMW1HO4zRaeWCClL9P9b3lniMcmfUZj2O9jgPRx30rYovfQ%0AbMV8%0A)
- Accédez aux factures clients *(format PDF)* associées à votre export comptable
