# Paramétrer mes Chantiers

> ℹ️ Cet article vous guide pas à pas dans le paramétrage du module **Chantiers** *(selon le nom que vous avez défini)* dans Interfast. Ces paramètres vous permettent d’adapter l’outil à votre organisation, de gérer les accès aux documents et de répondre à certaines obligations réglementaires.

## I. Accéder aux paramètres


Pour configurer le module Chantiers, vous devez accéder aux paramètres de votre entreprise.

Étapes à suivre

1. Depuis le menu latéral gauche, cliquez sur **Mon entreprise**
2. Ouvrez l’onglet **Paramètres**
3. Dans la colonne de gauche, descendez jusqu’à la section **Modules**
4. Cliquez sur **Chantiers**

![](https://downloads.intercomcdn.com/i/o/tarury57/1891693129/f80f43a730cb2f904482cbd65578/CleanShot+2025-12-17+at+20_47_18%402x.png?expires=1788619500&signature=c7ab165368ad3b68cfeb895b58459f0c9feac4e97ac964380d750cef7d5ac8f8&req=dSguF893noBdUPMW1HO4za4n%2BQOP72bZey4m1OEjE74AvxSBmoEzEAfes9bQ%0AFzK6U9%2B7NdUmfKwSHek%3D%0A)

Vous arrivez alors sur la page de configuration du module.

## II. Paramétrer les Chantiers

### 1. Modifier le nom du module

Par défaut, le module s’appelle **Chantiers**. Il est possible de le renommer afin qu’il corresponde mieux à votre vocabulaire métier. 

Cette modification impacte uniquement l’affichage dans l’interface.

Étapes à suivre

1. Depuis les paramètres du module Chantiers
2. Renseignez le nouveau nom dans le champ **Renommer « Chantiers » par :**
3. Modifier le nom
4. Enregistrez vos modifications

![](https://downloads.intercomcdn.com/i/o/tarury57/1891697119/5751ebd2767a68ee8fa1afb91d06/CleanShot+2025-12-17+at+20_41_38.gif?expires=1788619500&signature=cfc20a466dd966f1ac71b67e82be3ef52abc0ccb6d27018dc470570ae0043c45&req=dSguF893moBeUPMW1HO4zbVmjw%2BxOq6smgnkzMAbEzBF7lNrYCGNwa83W9Fj%0AY92hgg3K%2FG9DytDROYk%3D%0A)


Le nouveau nom est immédiatement visible dans le menu et dans l’ensemble de l’interface.

Cette personnalisation permet d’adapter l’outil à votre vocabulaire métier, facilitant la compréhension et l’adoption par vos équipes.


Par exemple, renommer « Chantiers » en « Projets » ou « Affaires » rend la navigation plus intuitive et cohérente avec vos processus internes.

### 

### 2. Gérer l’accès aux documents

L’accès aux documents d’un chantier dépend du **rôle de l’utilisateur**.
​

Par défaut, certains rôles (comme **technicien**, **alternant**/**stagiaire**, **sous-traitant** ou **invité**) peuvent accéder aux autres informations du chantier (description, interventions, etc.).

En revanche, **ils n’ont pas accès aux documents** :

- L’onglet **Documents** est visible,
- Mais **aucun document n’est affiché**,
- Ils ne peuvent donc ni consulter ni télécharger les documents liés au chantier.
​

Il est possible d’autoriser l’accès aux documents pour certains rôles via les paramètres du module **Chantiers**
​

### 3. Configurer l’accès aux documents dans le module Chantier 

1. Depuis **Mon entreprise** > **Paramètres**
2. Ouvrez le module **Chantiers**
3. Dans la section **Accès aux documents**
4. Sélectionnez les rôles supplémentaires autorisés à consulter les documents
5. Enregistrez vos modifications

![](https://downloads.intercomcdn.com/i/o/tarury57/1901239771/fbc5b48689ec37803c6882269b1f/CleanShot+2025-12-24+at+09_42_30%402x.png?expires=1788619500&signature=6c82d5c8b998217fe8df81b826ca084e4ea64aaa814214f0ccae9810ae3ef15e&req=dSknF8t9lIZYWPMW1HO4zaX3jxo9Dq%2Fa40k%2FYHgx7GIHKGB9boQzLNUE3iry%0AZYWC0bDi8Cac%2BHfCDQE%3D%0A)

> ✅ Les changements sont appliqués immédiatement. Mais, sur l'application mobile, il peut être nécessaire de [vider le cache](https://drive.google.com/file/d/1kEBQyYdMYMyjAQ-RXvbqF4Cnge0dWsNI/view?usp=sharing) pour accéder aux documents.

- L’utilisateur ne peut ni consulter ni télécharger les documents

Cas 2 : accès autorisé

- L’utilisateur peut consulter et télécharger les documents

> 👉  *Depuis l'application mobile, les utilisateurs peuvent consulter et télécharger les documents du chantier, mais ne peuvent pas :*
> - *modifier un document*
> - *supprimer un document*

## III. Traitement des déchets sur les chantiers


Le paramétrage du **traitement des déchets** permet d’informer vos prospects et clients de la manière dont les déchets sont gérés lors de vos chantiers. 

Ces informations peuvent ensuite être reprises dans vos devis.

### 1. Accéder au paramétrage des traitements des déchets

1. Depuis **Mon entreprise** > **Paramètres**
2. Ouvrez le module **Chantiers**
3. Descendez jusqu’à la section **Traitement des déchets**
4. Cliquez sur le bouton **Ajouter **

![](https://downloads.intercomcdn.com/i/o/tarury57/1891724843/017be09a82ef382e185140422391/CleanShot+2025-12-18+at+08_49_29%402x.png?expires=1788619500&signature=8026549bc2a0a71561943c208f8970a24ba86731d00d0ad11bf7d31336af6256&req=dSguF858mYlbWvMW1HO4zUNrbagCP78bHK0y2YrA4Mxz5WQabolhJa%2B2gLnZ%0AcGP0%0A)

Le traitement des déchets est désormais disponible et réutilisable.

### 2. Renseigner un traitement des déchets

Lors de l’ajout, vous devez :

- Définir un **libellé**, utilisé pour retrouver facilement ce traitement lors de l’édition d’un devis ;
- Rédiger une **description** expliquant la gestion et le traitement des déchets.

![](https://downloads.intercomcdn.com/i/o/tarury57/1891738286/1770f6328873994024bcc83a6802/Google+Chrome+2025-12-18+08_57_48.png?expires=1788619500&signature=c2fa83395a49dd92945e849d3a6f8eca9f5d1fe755e0778d222a66bc462809b8&req=dSguF859lYNXX%2FMW1HO4zWG%2Bw7LRR7BLqpdXf6akT4IwdNJFrhwoP%2BnYRWxR%0AqHMOL5HLNvy2O15FiO8%3D%0A)

**Exemple :**

*Les déchets générés lors des travaux de chauffage, ventilation ou climatisation (anciens équipements, gaines, tuyauteries, isolants, gravats) sont triés et évacués par nos équipes.
​*

*Ils sont ensuite déposés dans des filières de traitement et de recyclage agréées, conformément à la réglementation en vigueur.
​*

*Cette prestation comprend l'enlèvement, le transport et le traitement des déchets issus du chantier.*
​
✅ Une fois les informations complétées, cliquez sur **Enregistrer**.
​

> 👉 ﻿Sur les recommandations de la FFB, vous pouvez aussi [créer un article](https://help.inter-fast.co/fr/articles/11172963-utiliser-les-articles#h_c547b9c239) dans votre Bibliothèque pour ajouter la prestation de traitement des déchets dans vos devis et factures :
> - Désignation : *"Traitement des déchets"*
> ​
> - Description : *"Gestion, évacuation et traitement des déchets de chantier comprenant la main-d’œuvre liée à la dépose et au tri, le transport des déchets de chantier vers un ou plusieurs points de collecte et les coûts de traitement"*
> ​
> - Unité : *"Forfait"*

### 3. Affichage du traitement des déchets dans le devis

Une fois un traitement des déchets configuré, celui-ci peut être sélectionné lors de la création ou de la modification d’un **devis lié à un chantier**.

Les informations renseignées dans le traitement des déchets :

- sont automatiquement intégrées aux nouveaux devis,
- sont visibles par le client,
- sont utiles pour expliquer clairement comment les déchets seront gérés.

![](https://downloads.intercomcdn.com/i/o/tarury57/1891748465/d1f9b1643f674e0a17fc2fe3aeb3/CleanShot+2025-12-17+at+21_46_39.gif?expires=1788619500&signature=fd54050ddef67782cd091b5be60a08223dac70ac358a0fe4ce7241eb9572aa7e&req=dSguF856lYVZXPMW1HO4zVGgZsIi%2BH05G%2Bt3vVeznqVoZTDLmXRCCCMx8R6e%0AFl5S%0A)

Cela vous permet de standardiser vos devis tout en répondant aux exigences réglementaires et aux attentes de vos Clients.

> Exemple 1 — Cas standard (exemple copiable / personnalisable selon votre activité)

Libellé : Gestion des déchets non dangereux du chantier

Contenu :

Les déchets générés lors du chantier sont collectés, triés et évacués vers des filières de traitement agréées.

Cette gestion concerne les déchets issus des travaux (matériels déposés, matériaux, consommables et résidus de chantier).


Le tri est effectué afin de favoriser la valorisation et le recyclage lorsque cela est possible.

Les déchets non valorisables sont traités conformément à la réglementation en vigueur, via des centres agréés (enfouissement ou incinération selon la nature des déchets).

### Conclusion 

Le module Chantiers vous permet de :

- Personnaliser le nom du module selon votre organisation
- Sécuriser l’accès aux documents selon les rôles
- Standardiser et valoriser le traitement des déchets dans vos devis

Tous ces paramètres sont accessibles à tout moment depuis les réglages de votre entreprise.

## IV. **Questions fréquentes (FAQ)**


Par défaut, pour protéger vos données, l'accès aux documents d'un chantier n'est pas activé pour les rôles "Technicien", "Alternant/Stagiaire" ou "Sous-traitant". Ils voient l'onglet "Documents", mais celui-ci reste vide.

Vous pouvez débloquer cet accès facilement depuis l'application web :
1. Allez dans **Mon entreprise** > **Paramètres**.
2. Dans la section "Modules" (à gauche), cliquez sur **Chantiers**.
3. Dans la partie **Accès aux documents**, sélectionnez les rôles que vous souhaitez autoriser.
4. Enregistrez vos modifications. *Astuce :* Si le collaborateur est sur le terrain, demandez-lui de vider le cache de son application mobile pour que les modifications s'appliquent immédiatement.


Chaque entreprise a son propre vocabulaire et le terme "Chantier" peut prêter à confusion en interne.

Oui, InterFast vous permet d'adapter l'interface à votre métier.
1. Rendez-vous dans **Mon entreprise** > **Paramètres** > module **Chantiers**.
2. Saisissez le terme souhaité (ex: "Projet" ou "Affaire") dans le champ **Renommer « Chantiers » par :**
3. Cliquez sur **Modifier le nom** et enregistrez. Le nouveau nom remplacera immédiatement le terme "Chantiers" dans tout votre environnement et vos menus.


Le technicien consulte le document mais le bouton de suppression/modification est absent sur l'application terrain.

C'est un comportement tout à fait normal conçu pour sécuriser vos dossiers. Lorsqu'un accès aux documents est accordé, les collaborateurs sur le terrain peuvent les consulter et les télécharger pour mener à bien leur mission. 

En revanche, pour éviter toute erreur de manipulation, la modification ou la suppression de documents n'est pas permise depuis l'application mobile.


Devoir retaper ou copier-coller les mentions réglementaires sur le traitement des déchets à chaque nouveau devis est une perte de temps.

Vous pouvez configurer et enregistrer ces mentions une bonne fois pour toutes pour standardiser vos devis.

1. Allez dans **Mon entreprise** > **Paramètres** > module **Chantiers**.
2. Descendez à la section **Traitement des déchets** et cliquez sur **Ajouter**.
3. Définissez un libellé clair et rédigez votre description expliquant comment vous collectez, triez et évacuez les déchets (vous pouvez utiliser l'exemple standard fourni par InterFast).
4. Enregistrez. Lors de la création ou modification d'un devis lié à un chantier, vous n'aurez plus qu'à sélectionner ce texte pré-enregistré pour qu'il soit visible par le client. 

 *> Cette action n'est pas rétroactive sur un devis déjà généré.*
