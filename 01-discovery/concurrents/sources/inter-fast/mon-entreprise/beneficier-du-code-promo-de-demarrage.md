# Bénéficier du Code promo de démarrage

> 💡 Dans cet article vous allez tout savoir sur l'application du code de réduction issu de la vidéo de présentation complète d'InterFast : éligibilité, méthode d'application avant ou après souscription et fonctionnement du crédit.
> ​
> Vous avez visionné la [vidéo de présentation complète](https://www.youtube.com/watch?v=fiM4HIrlJyA) et récupéré le code  ? Ce code vous permet de bénéficier d'**un mois d'abonnement offert** sur votre souscription. Voici comment l'appliquer selon votre situation actuelle.

## I. Conditions d'éligibilité

Pour que ce code soit valide, deux conditions doivent être réunies :

1. **Délai d'activation :** La demande doit être faite au maximum **1 mois après la date de création** de votre compte entreprise sur InterFast. Passé ce délai, l'offre n'est plus applicable.
​

2. **Type d'offre :** Le code s'applique sur les abonnements payants (Starter, Pro, Business) en mensuel ou annuel.

## II. Comment activer votre code ?

La procédure diffère selon que vous ayez déjà réglé votre abonnement ou non.
​

### Cas 1 : Vous n'avez pas encore souscrit à un abonnement

Si vous êtes en période d'essai et que vous souhaitez activer votre abonnement avec ce code :
​

1. Contactez-nous via le **Tchat en ligne**.
​

2. Indiquez à l'équipe Support les informations suivantes :

- Le **nom** du code en question
- Le nombre de licences souhaitées (combien de personnes ?)
- Le type d'abonnement visé (Starter, Pro ou Business)
- La durée d'engagement (Mensuel ou Annuel)

3. Notre équipe appliquera la réduction ou vous guidera pour qu'elle soit prise en compte lors de votre premier paiement.
​

*Note : Si vous prenez plusieurs licences, l'équipe vérifiera que les collaborateurs sont bien ajoutés pour ajuster l'offre.*
​

### Cas 2 : Vous avez déjà souscrit (Régularisation)

Si vous avez déjà payé votre abonnement (il y a moins d'un mois) et que vous avez oublié de saisir le code :

1. Contactez le support pour demander l'application rétroactive du code sans oublier de bien indiquer le **nom** du code en question.
​

2. **Important :** Aucun remboursement monétaire (virement bancaire) ne sera effectué.
​

3. Nous appliquerons la valeur d'un mois d'abonnement sous forme de **Crédit** directement sur votre compte InterFast (visible dans *Mon entreprise > Mon abonnement*).
​

4. Ce crédit sera automatiquement déduit de vos prochaines factures de renouvellement ou lors de l'ajout de nouveaux utilisateurs.
