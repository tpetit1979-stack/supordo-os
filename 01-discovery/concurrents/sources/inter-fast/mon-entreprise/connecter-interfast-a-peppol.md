# Connecter InterFast à Peppol

> 💡 Le réseau **Peppol** devient la norme pour la facturation électronique. 
> **Anticipez la facturation électronique !** En connectant InterFast au réseau **Peppol**, vous assurez la transmission automatique et sécurisée de vos factures vers vos clients publics et les grandes entreprises. C'est le moyen le plus simple de garantir la conformité de vos échanges et d'accélérer vos délais de paiement sans aucune saisie manuelle !

**⚠️ Important : Disponibilité géographique**

Cette fonctionnalité est exclusivement réservée aux entreprises domiciliées en Belgique 🇧🇪.

• **Pourquoi ?** Le réseau Peppol est le standard retenu par la Belgique pour l'obligation de facturation électronique au 1er janvier 2026.

• **Et pour la France 🇫🇷 ?** Si votre entreprise est française, vous ne devez pas demander de connexion Peppol sur InterFast.

- Pour la France, la réforme entrera en vigueur le 1er septembre 2026.
- InterFast assurera votre conformité via une interconnexion dédiée avec **Pennylane** (Plateforme de Dématérialisation Partenaire).
- Nous communiquerons spécifiquement sur l'activation de ce module en temps voulu.

## I. Activer votre compte

### A. Vous ne possédez pas d'identifiant Peppol

L'activation du réseau Peppol sur votre compte n'est pas automatique : elle nécessite une intervention de notre équipe technique.

1. Contactez l'équipe Care via le tchat pour demander votre raccordement,
​
2. Nos techniciens activent votre accès dès que vos informations d'entreprise (**SIRET** ou **BCE**) sont validées.

> 💡 L'enregistrement sur le réseau Peppol n’est pas instantané et peut prendre quelques heures. 

### B. Vous possédez déjà un identifiant Peppol

Si vous possédez déjà un identifiant Peppol obtenu via un autre logiciel, nous pouvons procéder à une configuration manuelle de notre côté.

Il vous suffit de nous contacter via le tchat et de nous communiquer vos ID Peppol générés depuis l’autre logiciel.

> ⚠️ Veuillez noter toutefois qu'un ID Peppol ne peut être actif que sur un seul logiciel à la fois, l'identifiant est à usage unique.
> Ainsi, vous pourrez **émettre** vos factures depuis InterFast, mais la **réception** de vos documents continuera de se faire sur votre ancien outil.

### C. Distinction : clients professionnels VS clients particuliers

La facturation électronique via Peppol fonctionne uniquement pour les clients professionnels.
Les clients **particuliers** ne sont donc **pas** concernés par Peppol.

La distinction se fait au niveau du client dans votre CRM InterFast.

## II. Maîtriser l'envoi via Peppol

### A. Utiliser notre Checklist de vérification

Le réseau Peppol est très strict : une simple erreur de format dans vos numéros d'identification peut bloquer l'envoi. 

Nous avons donc mis en place une liste de points à vérifier sur vos fiches clients, pour faciliter vos envois et éviter des erreurs qui peuvent vous faire perdre du temps au dernier moment.

Suivez les étapes suivantes pour valider les informations renseignées dans vos fiches clients et envoyer vos factures sans obstacles.

**1. Rendez-vous dans le bouton "Actions" sur une fiche client :**

2. Vérifiez la conformité de votre client :

Si votre fiche client n'est pas conforme, une alerte apparaîtra pour vous permettre de corriger les erreurs et de renseigner correctement les différentes informations indispensables pour envoyer vos factures.

C'est ici que les erreurs sont les plus fréquentes. 

Au moment de configurer la fiche de votre client, il vous faudra impérativement renseigner ces champs :

![](https://downloads.intercomcdn.com/i/o/tarury57/2030623128/a1310be2f8c996bb06f28f71f217/CleanShot+2026-02-05+at+12_47_30%402x.png?expires=1788619500&signature=db04d86bc00092ce0560ce31b99bd3095f222c0c83a975b38facdc6d2adf0d0e&req=diAkFs98noBdUfMW1HO4zaiEKnuYoT2xcS4Wu5Zg66A3qSlUlBsb2nb%2B53H%2F%0A18bM5ju1ua5nmG7Nd%2BY%3D%0A)

⚠️ **Attention à bien distinguer les deux champs dans la fiche client**

Ces deux informations, bien qu'elles partagent les mêmes chiffres pour une entreprise belge, doivent impérativement être renseignées dans les bons champs :

- Le champ **"Numéro d'entreprise"** attend **uniquement les chiffres**, sans préfixe (ex : 0123456789).
- Le champ **"Numéro de TVA intracommunautaire"** attend le **format complet avec le code pays** (ex : BE0123456789).

Renseigner le mauvais format dans l'un ou l'autre de ces champs est l'une des causes les plus fréquentes de blocage à l'envoi. En cas de doute, utilisez la checklist de vérification avant d'envoyer votre facture.

> 💡 Règle d'or à retenir pour nos utilisateurs belges :
> - **Champ "Numéro d'entreprise" :** Indiquez uniquement les chiffres (ex: 0123456789). **Ne mettez pas "BE" ici.**
> - **Champ "Numéro de TVA intra-communautaire" :** Indiquez le format complet avec le préfixe pays (ex: BE0123456789).

3. Facturer un client français

Vous facturez un client français ? Attention, ce n'est pas la même logique qu'en Belgique !

C'est un point qui prête souvent à confusion : contrairement à la Belgique, **le numéro SIRET et le numéro de TVA intracommunautaire **d'une entreprise française sont deux numéros distincts.

- Le **SIRET** est un identifiant à 14 chiffres qui correspond à l’établissement précis d’une entreprise
Exemple : 12345678900012. Il est à renseigner dans le champ **"Numéro d'entreprise"**.
- Le **numéro de TVA intracommunautaire français** commence par le préfixe **FR** suivi d'une clé (2 chiffres) et du numéro **SIREN** de l'entreprise (9 chiffres). Exemple : FR12345678901. 
Il est à renseigner dans le champ **"Numéro de TVA intracommunautaire"**.

Exemple concret :

- Entreprise : ELECTRICITE DE FRANCE (EDF)
- SIREN : 552081317
- Numéro de TVA intracommunautaire : FR 03 552081317

⚠️ **Ne confondez pas les deux** : renseigner le SIRET dans le champ TVA (ou inversement) entraînera un rejet de l'envoi via Peppol.  

> 💡 Pour vous y retrouver : 
> - Le SIREN est l’identifiant national unique d’une entreprise. Il lui est attribué à vie par les services de l’INSEE.
> - Le numéro SIRET correspond à l’établissement précis d’une entreprise : il change en cas de déménagement ou pour l’ouverture d’un nouveau local.

Soit, vous pouvez rafraîchir depuis le CRM directement.

3. Cas particulier : factures déjà finalisées

Si vous modifiez une fiche client, les changements ne se répercutent **pas** sur les factures déjà passées au statut "Finalisée".

Si une facture finalisée présente une erreur Peppol : contactez-nous via le **tchat en ligne** directement.

> ⚠️ Communiquez-nous bien le / les numéros de factures concernées et les noms de clients. 
> **Notre équipe s'occupera de mettre à jour le document manuellement pour vous.**

## III. Réceptionner ses factures fournisseurs

Une fois la réception Peppol activée, vous simplifiez et automatisez entièrement la gestion de vos factures fournisseurs. 

1. Lorsqu’un fournisseur vous envoie une facture via Peppol, celle-ci est reçue directement dans le module Dépenses d’InterFast.
2. De votre côté, lorsque vous envoyez une facture via Peppol, votre fournisseur / client la recevra directement dans son environnement également.

![](https://downloads.intercomcdn.com/i/o/tarury57/1911563094/3c3205525805dc1b9af29bae79ad/CleanShot%2B2026-01-02%2Bat%2B10_55_49-402x.png?expires=1788619500&signature=743e8f4f1df846c3bbd8f88573c5d009fc149ac6cb471ccf25b72ea87572585d&req=dSkmF8x4noFWXfMW1HO4za%2B9XbINOs5YHMz2SU9xfaKPj5a8VRJe4njUcVDb%0AY4l6Zrku8xbSttWd3U4%3D%0A)

Grâce à l’intelligence artificielle, les informations clés (montants, fournisseurs, etc.) sont reconnues et préremplies, vous évitant toute saisie manuelle et vous faisant gagner un temps précieux au quotidien.

> ⚠️ si vous avez été enregistré sur Peppol via un autre service, la réception de ces factures se fera sur l'autre service et non sur InterFast.
> Pour que tout soit centralisé sur InterFast, vous devez vous déconnecter de l'ancien service afin qu'on vous reconnecte totalement.
> N'hésitez pas à nous solliciter dans le tchat en ce sens.

## Conclusion

En activant Peppol dans InterFast, vous prenez une longueur d’avance sur la facturation électronique obligatoire et sécurisez vos échanges de factures, aussi bien en émission qu’en réception.

N'oubliez pas de vérifier toutes les informations capitales en amont afin de ne pas être bloqués dans l'envoi de vos factures.

InterFast vous accompagne dans cette transition pour vous permettre de rester conforme.
