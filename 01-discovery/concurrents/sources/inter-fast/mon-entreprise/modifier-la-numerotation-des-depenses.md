# Modifier la numérotation des dépenses

> ✅ La législation française n'impose pas d'obligations sur la numérotation des dépenses fournisseurs. InterFast vous permet toutefois de définir le format et le prochain numéro de vos documents afin de faciliter votre organisation.

## I. Modifier le format

Le format permet de distinguer d'un coup d'oeil la nature du document.

1) Accédez au module "Mon entreprise" > "Paramètres" > "[Général](https://app.inter-fast.fr/dashboard/company?c=settings&settings=sequence)"

![](https://downloads.intercomcdn.com/i/o/tarury57/1788303394/23648459703b4b789f38eeb1b259/Capture+d-e%CC%81cran+-21-10-2025.png?expires=1788619500&signature=fb5f9aa1406ce9e4c7938c7a2bbf638b9a5fb5a3249ee161dc3e518f910185b0&req=dScvHsp%2BnoJWXfMW1HO4zffFAwX4oDAcmecing%2F%2FTSNqF2eEDUGjsYOvoEkt%0APUMWCh63ABeMjXe3zFI%3D%0A)

2) Cliquez sur "Modifier le format"
​*[une pop-up s'ouvre]*


3) Choisissez les options de format :

- préfixe (texte)
- année / mois
- séparateur
- longueur du numéro

![](https://downloads.intercomcdn.com/i/o/tarury57/1788304045/03caeb556ad0512015cc9be48dc4/Capture+d-e%CC%81cran+-21-10-2025.png?expires=1788619500&signature=7bbde18e8391299313c695cc310eb65aee8fda9b6728744d4f06f31c48e973fe&req=dScvHsp%2BmYFbXPMW1HO4zYzm4A7LRs%2BboAwc9KtgfY8iYqSXtGGDOf79uRE4%0AbS0uvLP4A0rkdwoHinM%3D%0A)

4) Prévisualisez le résultat des options sélectionnées
​
5) Confirmez la modification de votre format

> ⚠️ Le format modifié ne sera appliqué qu'aux nouvelles dépenses.

## II. Modifier le prochain numéro

Par défaut, le prochain numéro est "1". Vous pouvez cependant poursuivre votre numérotation si vous avez débuté votre historique sur un précédent logiciel.

1) Cliquez sur "Modifier le prochain numéro"
​*[une pop-up s'ouvre]*


2) Incrivez le numéro de votre choix

![](https://downloads.intercomcdn.com/i/o/tarury57/1788305199/005db011ea5b38b039f507d3d14f/Capture+d-e%CC%81cran+-21-10-2025.png?expires=1788619500&signature=764b023424ad58cb31cedc07c7d47f29d8d549c366ed423374a9a7d55649928f&req=dScvHsp%2BmIBWUPMW1HO4zbd2OqQrCxnM%2Biw%2B07LCp1UDTZyaQ1GH9HXg1X%2F1%0AixFKGyt2K3hLXe2v5kw%3D%0A)


3) Confirmez la modification
​

> 👍 Votre prochaine dépense portera ce numéro.

## III. Questions fréquentes (QPF)

- Vous pouvez retrouver et gérer l'état de votre numérotation directement dans sur la page Paramètres > [Dépenses](https://app.inter-fast.fr/dashboard/company?c=settings&settings=expense).
- La section "Numérotation" vous permet de modifier la série en cours.

1. Vous pouvez définir un format spécifique incluant un préfixe (ex: "DEP-) l'**année** (ex: "2026"), un **séparateur** (comme un tiret) et la **longueur du numéro** (par exemple, 4 chiffres pour obtenir 26-0001).
2. Il est également possible d'ajouter des préfixes pour distinguer vos différents types de documents.

1. Oui, la remise à zéro est possible, notamment lors d'une migration ou d'un changement de structure juridique.
2. Cependant, vous devrez solliciter l'équipe Care dans le tchat pour effectuer un diagnostic rapide. La réinitialisation est volontairement bloquée côté utilisateur.
​
3. Communiquez dans le fil de discussion l'ancien et le nouveau Kbis
​
4. Notre équipe de Conseillers effectuera les vérifications nécessaires avant de procéder à la réinitialisation de la série.


Le numéro d'une dépense créée n'est plus modifiable.

1. La législation n'impose pas une continuité numérique et chronologique des dépenses. Vous pouvez donc supprimer les dépenses créées par erreur.
2. Toutefois, il est recommandé de conserver une numérotation continue sans rupture afin d'éviter des observations négatives lors d'un contrôle fiscal.
