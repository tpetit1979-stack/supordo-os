# Comprendre le tableau des Devis

> En tant qu'Artisan, les devis jouent un rôle central dans votre activité. Ils vous permettent de proposer vos services, la livraison de marchandises ou l'installation d'équipements auprès de vos clients potentiels.
> ​
> InterFast vous aidera à créer des devis clairs, élégants et efficaces !

## I. Vidéo tutoriel d'Hedi

[Vidéo YouTube](https://www.youtube.com/watch?v=0oFdhh89Zx0)

## II. Présentation détaillée

### 1. Les filtres des Devis

![](https://downloads.intercomcdn.com/i/o/tarury57/1422185331/4ef2007589fdbc21f83a1074ae10/CleanShot+2025-03-14+at+09_29_20.png?expires=1788618600&signature=794a5d04f9693b9fe11667873858cfd96de8e092e6b80e8ba8cb5e406711e660&req=dSQlFMh2mIJcWPMW1HO4zVhvICuxa7c7sop21C9CmSeKE8GHnNk0pWhq0Mu1%0ABM8Egu6P%2F9fPZwGDBAc%3D%0A)

Vous pouvez rechercher vos devis par :

- titre / nom du devis
- numéro de référence
- nom de chantier

Vous pouvez également filtrer vos devis par :

- Client (CRM)
- Dates
- de création
- d'émission
- de validité
- Expiration (date de validité dépassée)
- Activité
- SAV
- Chantier
- Maintenance
- Agence
- Utilisateur ayant créé le document
- Commercial auquel le client est rattaché
- Intervention à planifier
- Propriété personnalisée

### 2. Les statuts des Devis

![](https://downloads.intercomcdn.com/i/o/tarury57/1422166093/dc9105055dfa6a1e49816bd58d96/CleanShot+2025-03-14+at+09_14_06.png?expires=1788618600&signature=4acbea0be22fa45589aee9be3c85a6282bafca9631518d25bb79edc082a5e0d6&req=dSQlFMh4m4FWWvMW1HO4zWWSVGcMr7SpQ51EhhWVC0bMRLTicUX6O9uDNAWB%0AiuoEox45xl1TZ%2F9OqaU%3D%0A)

Vous pouvez filtrer les dépenses par statut :

- Brouillon (aucun numéro de référence)
- Finalisé (numéro de référence attribué)
- Envoyé (devis transmis au client)
- Accepté (signature manuelle ou électronique)
- Facturé (facturation du montant total)
- Refusé (rejet par le Client)
- Annulé (abandon à la discrétion de l'Artisan)
​

> ✅ Les résultats affichés dans les cartes tiennent compte des filtres appliqués.

### 3. Le bouton Nouveau Devis

![](https://downloads.intercomcdn.com/i/o/tarury57/1422170909/f7c83409634107b2176e0659c74c/CleanShot+2025-03-14+at+09_17_58.png?expires=1788618600&signature=c8be41a46914bbe56feaee29e0adab41cae49c9993e527e2a49a0a96d9505c17&req=dSQlFMh5nYhfUPMW1HO4zdsFU8%2Ffw425FUZcVzcuDgLtymDkbPbutkB5orRD%0ABW0sWGTM%2F%2FlMQmXfd2E%3D%0A)

Ce bouton vous permet de créer un nouveau devis en renseignant :

- un titre / nom
- le client associé ou à créer (CRM)
- le modèle de devis à utiliser (optionnel)

### 4. Le bouton Actions

![](https://downloads.intercomcdn.com/i/o/tarury57/1422176919/b0e23953993df1515187412d52d2/image.png?expires=1788618600&signature=26074161c18224b4be24f4e357bd4e1ed3920020ffebc55d27d9451993b3f76d&req=dSQlFMh5m4heUPMW1HO4zdbdykNvUPVGWzXL2EN%2Fs5ltjwb9UKcMfLIM1ige%0AcljCCZ4s9L7RzI7CWAs%3D%0A)

Ce bouton vous permet :

- d'importer vos anciens devis, issus de votre précédent logiciel
- d'exporter toutes les lignes du tableau des devis (format .csv)
- d'exporter tous les devis sous forme de document (format .pdf)

> ✅ Les exports tiennent compte des filtres appliqués.
> ​*Exemple : filtrez les devis du mois précédent avant de réaliser votre export simple et votre export des documents PDF.*

### 5. Les colonnes affichées

![](https://downloads.intercomcdn.com/i/o/tarury57/1422186472/4bc30f167855e9b31f2ee4f52a02/CleanShot+2025-03-14+at+09_27_01.png?expires=1788618600&signature=be0357f0011a2b2644288ce68d536c8caea55f1671361c387c65c4efb0fda5b4&req=dSQlFMh2m4VYW%2FMW1HO4zTwKmIiyBig0r%2FJldcUqdEasjOx8t9xziXqtWxlM%0A0tFxOldw2Abbnr2Wlvs%3D%0A)

Les colonnes disponibles pour les devis sont par défaut :

- le numéro (de référence)
- le titre / nom du devis
- le Client associé (CRM)
- le Chantier associé
- le Montant HT
- le Montant TTC
- le Reste à facturer TTC
- le Statut
- la Date de création
- l'Utilisateur ayant créé le document

 En cliquant sur le bouton "Personnaliser", en bas de la page, vous pouvez :

- afficher / masquer les colonnes
- déplacer l'ordre des colonnes

![](https://downloads.intercomcdn.com/i/o/tarury57/1422196406/5b35fe5e6e193a39d5bc20fb796e/CleanShot+2025-03-14+at+09_34_57.png?expires=1788618600&signature=05a19b093bef196884f0faea9c88e3613af45b5cdb1eaaf12d5fddfff7a753ce&req=dSQlFMh3m4VfX%2FMW1HO4zbKyT2oVxJrLIsCQ2zE42%2BeTy0iMqJcggr273duP%0AG%2BpnXp3td0t4ko4zvak%3D%0A)
