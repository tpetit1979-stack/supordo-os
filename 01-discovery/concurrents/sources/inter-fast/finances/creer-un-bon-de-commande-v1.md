## II. Détail des Étapes

Pour créer un bon de commande, il vous suffit de vous rendre sur le bouton “+ Ajouter” en haut à droite de votre écran puis “créer un bon de commande”.

![](https://interfast.intercom-attachments-1.com/i/o/tarury57/1285179911/903738f40103f32304212f1680ff/capture-decran-2024-01-19-a-12_1qqiuys.png?expires=1788674400&signature=6b9cea05a4c28b01e6b26189c2b41a405e2ed2ba63d9d94e60cb0d45dbc4fa47&req=dSIvE8h5lIheWPMW3nq%2BgRx5UiOBPQ7SA9MX6VIGY%2FrOg8xeGnDYkolReN%2Bt%0AzdiSIjdtyR5PshfasgAdSwNcwM0%3D%0A)

Une fois dessus, un petit formulaire s’ouvrira, vous n’aurez qu’à remplir les éléments demandés :

![](https://interfast.intercom-attachments-1.com/i/o/tarury57/1285179938/efad75741584a6a399b2b7092e1b/capture-decran-2024-01-19-a-12_jhv3u.png?expires=1788674400&signature=72fcf920c8c6a43e4b3044ca368eb518bbc095c7a67062fb4d8f6ef2837d0aba&req=dSIvE8h5lIhcUfMW3nq%2BgTajarH%2FCDVUOpoLB2UOtRtJ8ZEoxKXjyegY65Y9%0AnRPHeDUwneYR%2Bj0j%2Bhhjlk6jnbg%3D%0A)

1. Sélectionner le fournisseur concerné par ce bon de commande

2. S’il n’est pas présent, le créer via le bouton “ajouter un fournisseur”

3. Sélectionner le client concerné par ce bon de commande

4. S’il n’est pas présent, le créer via le bouton “ajouter un client”

5. Sélectionner le chantier concerné par ce bon de commande

6. Sélectionner les fichiers justificatifs reliés à ce bon de commande

![](https://interfast.intercom-attachments-1.com/i/o/tarury57/1285179966/c6051085ba19f8d640133e60fa42/capture-decran-2024-01-19-a-12_1ppdy90.png?expires=1788674400&signature=aac85e9dd35f9de8fcb3cb92547573ec652fbd03e3996d6b8b86d00cf08dec8b&req=dSIvE8h5lIhZX%2FMW3nq%2BganXa8MHLSa5XsaCSkLx3tbXKXGg5bQXf354oaFV%0AbE9DBh2t7XO9OUNQW8qT4A2ydqQ%3D%0A)

Vous pourrez ensuite ajouter un élément (tel qu’une ligne ou du texte libre).

![](https://interfast.intercom-attachments-1.com/i/o/tarury57/1285179995/cf13b35882fdcf60a8fedc0ac9bb/capture-decran-2024-01-19-a-12_559scy.png?expires=1788674400&signature=3b145d24ace8ff877532ff6a418a9944bda442309d579df31464a6c86560986c&req=dSIvE8h5lIhWXPMW3nq%2Bgcb87ogreBl1D9iOFnUcenHrwd9VenCc8sQuCGcV%0An9e%2BxRi%2Bnbtj6Zf2SfODeowTulU%3D%0A)

Ainsi qu’y ajouter un article parmi votre bibliothèque d’articles déjà existante ou de sélectionner un devis ou facture déjà existante pour les reporter sur le document.
