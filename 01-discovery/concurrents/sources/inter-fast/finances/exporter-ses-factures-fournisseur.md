# Exporter ses Factures fournisseur

[Vidéo YouTube](https://www.youtube.com/watch?v=nq6_2H-XEhA)

> ✅ Il est conseillé de poser la question à son comptable avant d'opérer toute modification.

L'objectif du module Dépenses est de permettre à votre comptable d'accéder automatiquement aux justificatifs et de réaliser les exports comptables, de la même manière que pour vos factures clients.

## **I. Configuration du Journal des achats**

### **1. Personnalisation des comptes de vente**

Il est possible de personnaliser les comptes comptables du [journal des achats](https://app.inter-fast.fr/dashboard/company?c=settings&settings=expenses).

Cela implique la création de catégories qui peuvent être affectées à des comptes comptables.

![](https://downloads.intercomcdn.com/i/o/tarury57/1814532324/ebcfbf484d2fd9e43c21cd240c69/Capture+d-e%CC%81cran+-05-11-2025.png?expires=1788619500&signature=25d6fa167f2aecfde003b47e1a8731224cced7a0c12016c8ec87f7f591594d7b&req=dSgmEsx9n4JdXfMW1HO4zTa1tqT1BvPZ7ERtJaoMCgBvbyGUrMeVWIdpMJdL%0AoTWFU0%2BOkA38Lf3M%2Ffc%3D%0A)

Pour chaque catégorie, on peut définir soit un compte comptable global, soit un compte comptable spécifique par taux de TVA.

![](https://downloads.intercomcdn.com/i/o/tarury57/1814533930/447ef2ac1803aece935fb2e8266d/Capture+d-e%CC%81cran+-05-11-2025.png?expires=1788619500&signature=581715c283379969d370814618a71f78cac205eec02728960ddc85683da6b1e7&req=dSgmEsx9nohcWfMW1HO4zc6oB7CBTDYcO8vmbJlUgEEQjOTxDKx%2B%2B7j20LT0%0A9nxH0dnz%2BZCsvjg91Zk%3D%0A)

L'objectif est de personnaliser les comptes comptables afin que, lors de l'export comptable, les ventes soient clairement ventilées par catégorie.

### **2. Définition d'une catégorie par défaut**

Dans votre [journal des achats](https://app.inter-fast.fr/dashboard/company?c=settings&settings=expenses), définissez une catégorie comptable par défaut l'essentiel de vos dépenses :

![](https://downloads.intercomcdn.com/i/o/tarury57/1814534739/38b9123f1b83f5dc05c83729dcfe/Capture+d-e%CC%81cran+-05-11-2025.png?expires=1788619500&signature=2400dfec5c33c18dbda253860334f30b7c41dbff4045334a80a8521d1f07040f&req=dSgmEsx9mYZcUPMW1HO4zdvwWENdEb0Avrp2UkK%2BoA4OwxXyNVKjMFIJdGki%0A8aNATiKWoN8BSOWL%2BpM%3D%0A)

### **3. Personnalisation du code journal**

L'utilisateur peut également personnaliser le code journal dans le [journal des achats](https://app.inter-fast.fr/dashboard/company?c=settings&settings=expenses), ce qui permettra de rajouter une colonne dans le fichier d'export.

![](https://downloads.intercomcdn.com/i/o/tarury57/1814525709/f4eb9c47deafbb0fbbf2d077c938/Capture%2Bd-e-CC-81cran%2B-04-11-2025.png?expires=1788619500&signature=f32408ecb713b72e1c2d7cef825985892b56b334aaf1601cdda07a2d99c160dc&req=dSgmEsx8mIZfUPMW1HO4zVtZv8Ca2Jmc8sRUZFfx3%2FDWnbL4X1l5E%2Fzhllq7%0AhyiSljjTPidiNvm7g8Y%3D%0A)

## II. Export des factures fournisseurs

### 1. Application des filtres

Une fois la configuration effectuée, l'utilisateur doit se rendre sur le tableau des factures fournisseurs pour réaliser l'export.

![](https://downloads.intercomcdn.com/i/o/tarury57/1814546359/fac371011c6c17d7a2e795196b83/Capture+d-e%CC%81cran+-05-11-2025.png?expires=1788619500&signature=6a55b63b4e4656117af3dfda3e71c05039435a85f849cb2d3201e9a8a145faad&req=dSgmEsx6m4JaUPMW1HO4zVNVW%2Fukf0XREvCLYyUH%2FL2cy%2F8IN4C8w3%2B6YFzJ%0Ao7W9guZpZjz3YJX8AXs%3D%0A)

En général, le comptable utilise un filtre de date pour exporter toutes les factures fournisseurs qui ont été payées sur un mois donné :

![](https://downloads.intercomcdn.com/i/o/tarury57/1814547132/5abdc8e9b9e39072c0acbb5dc497/Capture+d-e%CC%81cran+-05-11-2025.png?expires=1788619500&signature=8dee6ee011ee1289e5ac12ccbb9448d699b8d147e952d2c2728997383e871bef&req=dSgmEsx6moBcW%2FMW1HO4zcwpoPuYC9uNFwSKEjmHdiqp1J6w03%2FUPsazelW6%0Aak5D9jNdYoypQ%2Bsv7%2BM%3D%0A)

### 2. Les types d'export

Il existe trois possibilités d'exportation :

- un export simple : il permet d'exporter les valeurs du tableau des factures sur la base des filtres.
- un export comptable : il contient la ventilation des factures par catégorie comptable
- un export des documents : il génère un fichier .zip contenant l'ensemble des factures au format .pdf

> ✅ Pour ouvrir le fichier sous Windows, utilisez l'outil gratuit 7-Zip :
> [https://www.7-zip.org/](https://www.7-zip.org/)

![](https://downloads.intercomcdn.com/i/o/tarury57/1814552584/a6d9ed05b54bc2781e751cf85288/Google+Chrome+2025-11-05+14_15_37.png?expires=1788619500&signature=182bdd4114286de3fd3b6fab67f44f4a2110537a179dd3e85782a316fa610576&req=dSgmEsx7n4RXXfMW1HO4zX%2FOfDfQU00u1I7uV17B7aM79frIqVXfq8EYGbFC%0Ag7njy5S03n9YjQFl9QU%3D%0A)

### 3. Contenu de l'export comptable

Après que l'export comptable ait été téléchargé, il peut être ouvert dans Excel ou Google Sheets. L'export comptable contient différentes colonnes, notamment :

- la date de l'écriture
- la référence de la facture
- les numéros de comptes comptables
- les libellés et les comptes auxiliaires
- les montants ventilés par taux de TVA
