## II. Présentation détaillée

### 1. Les filtres des Commandes

![](https://downloads.intercomcdn.com/i/o/tarury57/1846677642/390a5c7c27ee4851118a0216db63/Capture+d-e%CC%81cran+000215+-24-11-2025.png?expires=1788619500&signature=c037f4538ecaa58ddb6370766b8f299d1735106b88daaf1fbd527786a0977c79&req=dSgjEM95modbW%2FMW1HO4zX2oY6%2BWuvFzahCcVtuMTMPTWAAfj8LpmTJ62sac%0Ae4oucORc7%2BjNFilboKA%3D%0A)

*Cliquez sur le bouton "Tous les filtres"*


Vous pouvez rechercher vos commandes par :

- libellé / nom
- numéro de référence

Vous pouvez filtrer les commandes par :

- Fournisseur
- Dates
- d'envoi
- de livraison prévue
- de réception
- Montant HT
- Montant TTC
- Reste à facturer TTC
- Facturation *(oui / non)*
- Propriété personnalisée

### 2. Les statuts des Commandes

![](https://downloads.intercomcdn.com/i/o/tarury57/1846728216/84a0d7e98fef6579cc1750c82748/Capture+d-e%CC%81cran+000221+-24-11-2025.png?expires=1788619500&signature=6fd6147d1ac85b849fd2558f3e3511c7a1b0a085fccd1c6394e3e4d962ef3d20&req=dSgjEM58lYNeX%2FMW1HO4zay%2FDH13eG%2ByzU%2B7l5376XuoWYfwBczmBemKerrG%0Aes6g%2BUwxHntV74hoQ0g%3D%0A)

Vous pouvez filtrer les Commandes par statut :

- Brouillon *(en attente de finalisation pour envoi au fournisseur)*
- En attente *(de réception des marchandises du fournisseur)*
- Partielle *(seule une partie des marchandises a été réceptionnée)*
- Reçue *(toutes les marchandises ont été réceptionnées)*

> ✅ Les résultats affichés dans les cartes tiennent compte des filtres appliqués :

### 3. Le bouton Ajouter

![](https://downloads.intercomcdn.com/i/o/tarury57/1846735292/a572893f9ad0cd1b93d2d81771f2/Capture+d-e%CC%81cran+000223+-24-11-2025.png?expires=1788619500&signature=7f928018e6e6025481059d65e5e9a84d7db630caf942ad76ff442e3e3a60007a&req=dSgjEM59mINWW%2FMW1HO4zTKNnN8gr5wJn%2FImyLZZC8gtY%2FmN2MpT5pvu8G5E%0A7T9SWMS3Ywa8wPxiBzo%3D%0A)

### 4. Les colonnes affichées

![](https://downloads.intercomcdn.com/i/o/tarury57/1846742055/3550867da27a5691f46d65e96a94/Capture+d-e%CC%81cran+000225+-24-11-2025.png?expires=1788619500&signature=8d26ebd707e137c59805b7ad5a5cecdfb2ecd1467d18e71239b944ad40f593fe&req=dSgjEM56n4FaXPMW1HO4zf7wQJw2fY2t%2B6urYir7GCSo3CHssbQ3OjQF88lb%0AENManfMiqcRT5DflA3g%3D%0A)

Les colonnes disponibles pour les Commandes sont par défaut :

- le numéro de référence
- le libellé / nom
- le statut
- la liaison
​*> à une intervention /un chantier / une maintenance / une facture fournisseur*
- la facturation complète
​*> oui / non*
- le montant HT
- le montant TTC
- le Fournisseur
- le Reste à facturer TTC
- les propriétés personnalisées

En cliquant sur le bouton "Personnaliser", en bas de la page, vous pouvez :

- afficher / masquer les colonnes
- déplacer l'ordre des colonnes

![](https://downloads.intercomcdn.com/i/o/tarury57/1846741319/29d3ba2c53431084572f1c5460e9/Capture+d-e%CC%81cran+000224+-24-11-2025.png?expires=1788619500&signature=7a620090ee75c90b62055f622fc193504ed855a5d0ce7657a968d4fb8ad4f267&req=dSgjEM56nIJeUPMW1HO4zYRAldygpuWq8Aj02qlFWfSNdqcqwaTfFI1y350K%0A2le5T4aRBkGby8KLR4M%3D%0A)

Vous pouvez naviguer de page en page grâce aux boutons de navigation :

![](https://downloads.intercomcdn.com/i/o/tarury57/1846613806/7563073c3c87aaab473bde23ce59/CleanShot%2B2025-03-12%2Bat%2B10_54_22.png?expires=1788619500&signature=a46e857049c65f71d53f1520b9071333ca332876eb0ed8d9c7d5400bda07c2d5&req=dSgjEM9%2FnolfX%2FMW1HO4zUQYCt9d0zvnjvwEA%2FXMLN3AITxMnMT9WNvRvd%2BE%0AKe5Ju7xkoWFedJohf3M%3D%0A)
