# Comprendre le tableau des Dépenses

> Le module Dépenses regroupe :
> - les Factures fournisseurs
> - les Avoirs fournisseurs
> - les Bons de commande V1
> InterFast vous aidera à suivre efficacement les dépenses de votre entreprise.
> ​
> ​*✅ les [Bons de commande V2](https://help.inter-fast.co/fr/articles/11560415-utiliser-les-commandes-v2-app-web) sont regroupés dans leur sous-module dédié.*

- Propriété personnalisée

## III. Questions Fréquentes

L'export comptable génère un fichier CSV contenant uniquement les écritures du journal d'achats. Pour récupérer vos documents numérisés, vous devez cliquer sur le bouton **"Exporter"** puis choisir **"Export des justificatifs"**. Vous téléchargerez alors une archive ZIP contenant tous les documents PDF associés à la période filtrée.

​


Les modules "Dépenses" (Achats) et "Ventes" (Factures client) sont distincts. Affecter une dépense à un chantier sert à **calculer votre rentabilité** et non à facturer le client. Pour refacturer du matériel, vous devez ajouter manuellement la ligne ou l'article correspondant dans votre devis ou facture de vente.



Il n'est pas possible de saisir un montant négatif sur une dépense classique. Vous devez cliquer sur le bouton **"+ Ajouter"** puis sélectionner **"Enregistrer un avoir fournisseur"**. Cela créera une écriture négative qui viendra se déduire de votre solde fournisseur.



Pas encore. Pour les prélèvements sans facture fournisseur (comme l'URSSAF ou les salaires), la procédure recommandée est de créer un "Fournisseur" spécifique, puis de créer une dépense manuelle chaque mois depuis le module Banque ou Dépenses. Il n'existe pas de récurrence automatique à ce jour.
