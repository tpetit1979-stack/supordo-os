### 2. Personnalisation des comptes de vente

Il est possible de personnaliser les comptes comptables du [journal des ventes](https://app.inter-fast.fr/dashboard/company?c=settings&settings=sales). Cela implique la création de catégories qui peuvent être affectées à des comptes comptables.

![](https://downloads.intercomcdn.com/i/o/tarury57/1813328877/4b1dcbf0010eea80ede217aa3232/Capture+d-e%CC%81cran+-04-11-2025.png?expires=1788619500&signature=b469f9d7a05c200a5067cceebec99e5f3471c33094cc9e8a85e442c6bbdd157d&req=dSgmFcp8lYlYXvMW1HO4zUoIO%2Fn41Hi8rxzeoG9fwHibqZ7YoQqCSOptfHIg%0AfJYoZjxIttDWxEYaF1E%3D%0A)

Pour chaque catégorie, on peut définir soit un compte comptable global, soit un compte comptable spécifique par taux de TVA.

![](https://downloads.intercomcdn.com/i/o/tarury57/1813329868/5fe9bed6bd84109bc56237a89357/Capture+d-e%CC%81cran+-04-11-2025.png?expires=1788619500&signature=e2b72bd9c2267dd136f65eddcc3584c03e3a8ba794389469f5193f1237729960&req=dSgmFcp8lIlZUfMW1HO4zZ%2F6V5rkGGaHiBy%2F9rSqKoNAeVrXEoreiPmWmRMq%0Amfypk0P8Gg0bZKKrw7M%3D%0A)

L'objectif est de personnaliser les comptes comptables afin que, lors de l'export comptable, les ventes soient clairement ventilées par catégorie.

### 3. Personnalisation du code journal

L'utilisateur peut également personnaliser le code journal dans le [journal des ventes](https://app.inter-fast.fr/dashboard/company?c=settings&settings=sales), ce qui permet de rajouter la colonne du code journal dans le fichier d'export.

## III. Export des factures client

### 1. Application des filtres 

Une fois la configuration effectuée, l'utilisateur doit se rendre sur le tableau des factures client pour réaliser l'export. En général, le comptable utilise un filtre de date pour exporter toutes les factures émises sur un mois donné.

![](https://downloads.intercomcdn.com/i/o/tarury57/1813333943/e797f79e7d3001c1110041630142/Capture+d-e%CC%81cran+-04-11-2025.png?expires=1788619500&signature=e4fd1ec38ede3892fde494c4650e1e22130a4b2ad25a46bbd9701ec555c0b9a5&req=dSgmFcp9nohbWvMW1HO4zcbQXOQlNNjnsA9fACiM40WJMMvgaBPJ%2BlW3mfZo%0A2gM%2Fp1Arw2xBOAclEI0%3D%0A)

### 2. Les types d'export

Il existe trois possibilités d'exportation :

- un export simple : il permet d'exporter les valeurs du tableau des factures sur la base des filtres.
- un export comptable : il contient la ventilation des factures par catégorie comptable
- un export des documents : il génère un fichier .zip contenant l'ensemble des factures au format pdf.

> ✅ Pour ouvrir le fichier sous Windows, utilisez l'outil gratuit 7-Zip :
> [https://www.7-zip.org/](https://www.7-zip.org/)

### 3. Contenu de l'export comptable

Après que l'export comptable ait été téléchargé, il peut être ouvert dans Excel ou Google Sheets. L'export comptable contient différentes colonnes, notamment :

- la date de l'écriture
- la référence de la facture
- les numéros de comptes comptables
- les libellés et les comptes auxiliaires.
- les montants ventilés par taux de TVA.

## IV.Questions Fréquentes (FAQ)


Si votre export ne se génère pas, il est possible que le volume de données soit trop important (période trop longue ou nombre élevé de documents).
Dans ce cas, le fichier peut être trop lourd à traiter en une seule fois.

**Solution recommandée**

Divisez votre export en plusieurs périodes plus courtes.
Par exemple :
- Au lieu d’exporter 12 mois en une seule fois,
faites 2 exports de 6 mois
- Ou 3 exports de 4 mois
Cette méthode permet de réduire la taille du fichier et d’éviter les blocages.
Si le problème persiste malgré le découpage, contactez le support en précisant :
- La période concernée
- Le type d’export (factures, achats, etc.)
- Le message d’erreur éventuel
Nous pourrons alors analyser la situation plus précisément.
