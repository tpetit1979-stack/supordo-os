# Enregistrer un Avoir fournisseur

> 💡 **Bon à savoir** : vous avez désormais la possibilité d’enregistrer des avoirs fournisseurs directement dans vos dépenses, avec un montant négatif. Pratique pour gérer les retours de matériel, les remises ou les rectifications d’erreurs de facturation !

## I. Étapes détaillées

### A. Enregistrer un avoir fournisseur

Pour créer un avoir fournisseur dans InterFast, la démarche est simple et rapide. Depuis le menu "**Dépenses > Factures**", cliquez  sur le bouton "** + Ajouter** "** **en haut à droite de l’écran.

![](https://downloads.intercomcdn.com/i/o/tarury57/1586217388/c8589abe7ce9e568464495db0e96/CleanShot+2025-06-24+at+18_11_57%402x.png?expires=1788619500&signature=66215b60ab434db9f9261787710feb0e761f59bf09a0a500030070c41cb30245&req=dSUvEMt%2FmoJXUfMW1HO4zc3NEdCZbKxe8x97mVck6pjE8%2BiFKX5bf3n2n1HO%0AY6JDidyc8QLOyH1fvLY%3D%0A)

Une fois le menu déroulant ouvert, sélectionnez l’option **"Enregistrer un avoir fournisseur"**. Cela vous permet de créer une dépense spéciale, au format d’un avoir, avec les champs adaptés. L’enregistrement se fait exactement comme pour une dépense classique, mais avec une particularité : le montant est saisi **en valeur négative**, automatiquement pris en compte dans vos calculs.

### B. Compléter les informations de l’avoir

Une fois la fiche ouverte, vous pouvez renseigner toutes les données nécessaires à l’enregistrement de l’avoir.

Commencez par sélectionner le fournisseur concerné, puis la date de l’avoir telle qu’indiquée sur le document reçu. Indiquez ensuite le montant TTC, qui sera affiché en négatif, ainsi que les informations complémentaires : numéro de l’avoir, motif, et lignes de dépense (avec catégories comptables, taux de TVA, etc.).

Cela vous permet de garder une traçabilité claire dans votre gestion fournisseurs. Par exemple, si vous avez retourné du matériel non utilisé, vous pouvez préciser la nature du retour et rattacher l’avoir à la bonne catégorie de dépense (ex. matériaux, sous-traitance…). Et enfin, cliquez sur le bouton "**Enregistrer**" pour valider votre avoir.

### C. Visualiser et suivre vos avoirs

Une fois l’avoir enregistré, il apparaît dans la liste de vos factures fournisseurs. Vous le reconnaîtrez facilement grâce au montant **en négatif**, qui permet de le distinguer visuellement des autres dépenses.

Vous pouvez utiliser les filtres habituels (par fournisseur, date, catégorie, etc.) pour le retrouver facilement. Comme les autres écritures, l’avoir sera inclus dans vos exports comptables et vos rapports, et viendra diminuer le total de vos dépenses.

Ainsi, tout est centralisé au même endroit, et votre comptabilité reste à jour.

## II. Questions Fréquentes


Il ne faut pas utiliser le formulaire de dépense classique. Allez dans le menu **"Dépenses > Factures"**, cliquez sur le bouton **"+ Ajouter"** en haut à droite, et sélectionnez spécifiquement **"Enregistrer un avoir fournisseur"**.

Le système créera alors un enregistrement adapté où le montant sera automatiquement considéré comme négatif pour se déduire de vos charges.



Le module Banque d’InterFast ne permet pas encore de rapprocher automatiquement les avoirs fournisseurs *(ni clients)*.

**La solution de contournement :**
1. Passez manuellement l'avoir fournisseur au statut **"Payée"** depuis le module Dépenses.
2. Dans le module Banque, cliquez sur la transaction de remboursement et marquez-la comme **"Rapprochée"** *(sans lier l'opération bancaire à la facture d'avoir)* pour valider votre pointage.
​
Pour rappel, seul le journal des achats dispose d'une valeur comptable.
Le module Banque sert simplement à pointer les opérations.



Dans le tableau des dépenses, les avoirs fournisseurs s'identifient facilement grâce à leur montant affiché en **négatif** (ex: -150,00 €). Ils viennent automatiquement diminuer le total de vos dépenses sur la période consultée.


## III. Conclusion

Créer un avoir fournisseur dans InterFast vous permet de gérer efficacement les régularisations, remboursements ou ajustements liés à vos achats.

Que ce soit pour un retour de matériel, une remise commerciale ou une erreur de facturation, vous pouvez l’enregistrer simplement comme une dépense négative, depuis l’onglet Dépenses.

Et voilà, vous savez désormais comment enregistrer facilement un avoir fournisseur dans InterFast !
