# Modifier le Client sur un Devis

> 🔔 Dans cet article, nous vous guidons à travers les différentes étapes pour modifier les informations d’un client sur un devis, qu’elle soit en statut **"brouillon"**, **"finalisée"** ou **"envoyée"**.

## 
​I. Explications des étapes

Sur l'application web d'InterFast :

### A. Si le devis est au statut "Brouillon"

1- Accédez au module **Devis**

2- Recherchez le devis que vous souhaitez modifier

3- Cliquez sur le **titre** du devis pour l’ouvrir

4- Cliquez sur le bouton **"Modifier"** en haut à droite de l’écran

### 
**B. Si le devis est au statut "Finalisé" ou "Envoyé"**

1- Cliquez sur le module **Devis**
​2- Recherchez le devis à modifier

3- Cliquez sur le titre du devis

4- Cliquez sur le statut du devis et passez-le en "**Annulé**"

> ℹ️ En effet, un devis avec numéro ne peut plus être modifiée.

![](https://downloads.intercomcdn.com/i/o/tarury57/1489570924/2a8e0ffb5507922fab69e62781b0/CleanShot+2025-04-23+at+10_25_22%402x.png?expires=1788618600&signature=f2fb3ac5ab47b9e358061e07cac81e001906114c67f88188f32092097da2c96e&req=dSQvH8x5nYhdXfMW1HO4zYW2V9vHx303r92DbCKJwhYMwu7jppZScEEhO4C9%0AsS%2BJtVzPpK9g0OGpp20%3D%0A)

5- Cliquez sur le bouton **"Actions" > "Dupliquer".**

![](https://downloads.intercomcdn.com/i/o/tarury57/1489573720/aaa3df6868578d57d0509ab2b05f/CleanShot+2025-04-23+at+10_27_15%402x.png?expires=1788618600&signature=5f57d17ec7f392f3de63fae1e393a00e7fbc3b723a0c5e3bd47d1cfa6b5842f1&req=dSQvH8x5noZdWfMW1HO4zXgQFQqZNUud6BrJMP%2B%2FsPeOaiYjL5xDrjapSAbC%0AA9l5O5PiFdF5MJ%2B2fDY%3D%0A)

6- Sélectionnez le Client à qui vous souhaitez adresser le devis et cliquez sur le bouton "**c'est parti !**".

![](https://downloads.intercomcdn.com/i/o/tarury57/1489575847/8062f5b47c9da5404577396390fd/CleanShot+2025-04-23+at+10_28_42%402x.png?expires=1788618600&signature=0135703ba3b70a38faf8bce278827e959bd8a307eafe3b3619ad6e3c3dd73622&req=dSQvH8x5mIlbXvMW1HO4zZpYs%2F69zgkYv4SmiWEdKvlVz552llPmUMsdZHOx%0AynUvT2C3u0Dillp2XjI%3D%0A)

7- Pour sélectionner un Contact précis, associé au Client, cliquez sur le bouton "**Configuer le Client**" depuis l'éditeur du nouveau devis.

![](https://downloads.intercomcdn.com/i/o/tarury57/1489582527/a24b49440749b835ffd651e94098/CleanShot+2025-04-23+at+10_33_35.gif?expires=1788618600&signature=87ef5b22daa6dec6c95f5bc9ec6b8513f1515a6e8874f22ac8359372d17c63de&req=dSQvH8x2n4RdXvMW1HO4zU28qf8qysjk2G3vLIJQJNtWNWS7brLHybsGpqa3%0AqOFD%2FRtmYBN9iBI7T%2BQ%3D%0A)

8- Sur le panneau déroulant, cliquez sur "**Sélectionner un contact**" et cliquez sur "**Appliquer sur le devis**" pour valider les modifications.

![](https://downloads.intercomcdn.com/i/o/tarury57/1489584629/3eb1146d94026de5ec2583a8cecb/CleanShot+2025-04-23+at+10_32_29%402x.png?expires=1788618600&signature=86f023d2b6fb0b2967ec2790e60f3d271cf37d5460b86af735e3854f868b1245&req=dSQvH8x2mYddUPMW1HO4zbmTg%2BAcDvTXARb5KMi4dgwmOvZsImSV9aF7OmEh%0A4%2Bu3rqC6agZrTPAsfuY%3D%0A)

​*> sinon, forcez la sauvegarde en appuyant sur le bouton bleu.*
