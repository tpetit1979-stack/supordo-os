# Comprendre le tableau des Factures

> En tant qu'Artisan, les factures jouent un rôle central dans votre activité. Elles vous permettent de justifier auprès de vos clients le paiement de vos services et prestations.
> ​
> InterFast vous aidera à créer des factures claires, élégantes et conformes ! 👍

## I. Vidéo tutoriel d'Hedi

[Vidéo YouTube](https://www.youtube.com/watch?v=Ngz1EoZO4iQ)

## II. Présentation détaillée

### 1. Les filtres des Factures

![](https://downloads.intercomcdn.com/i/o/tarury57/1429686879/551f8429c36d3d379aadf98f63b3/CleanShot+2025-03-19+at+09_01_27.png?expires=1788618600&signature=2813a5441287cab2932a94e7ca6bf8ff5e4e7c74072e26fc607851772fa3202c&req=dSQlH892m4lYUPMW1HO4zbMRLdr0bIb4H792CL5Ur715bcsykYJVkTzg3y0d%0AM9LtVz%2BYwh3U1Q8TPiA%3D%0A)

Vous pouvez rechercher vos factures par :

- titre / nom de la facture
- numéro de référence
- nom de chantier

Vous pouvez également filtrer vos factures par :

- Client (CRM)
- Dates
- de création
- d'émission
- d'échéance
- Expiration (date d'échéance dépassée)
- Activité
- SAV
- Chantier
- Maintenance
- Agence
- Utilisateur ayant créé le document
- Commercial auquel le client est rattaché
- Propriétés personnalisées

### 2. Les statuts des Factures

![](https://downloads.intercomcdn.com/i/o/tarury57/1429687667/3ce1cd7e16ec99bdc5a01176bb89/CleanShot+2025-03-19+at+09_04_21.png?expires=1788618600&signature=04851c4be90b07c0575ffa51ecbc082312ce05cbfdb6e903203e3e2cb87e56f8&req=dSQlH892modZXvMW1HO4zQ313vPAEIYAt6fZrR3d%2BRsQ31qeERzbrln%2FR6u3%0AF10wojIyAJ2NORrwUZc%3D%0A)

Vous pouvez filtrer les factures par statut :

- Brouillon (aucun numéro de référence)
- Finalisé (numéro de référence attribué)
- Envoyé (facture transmise au client)
- Payée (consignation de tous les encaissements)
- Annulé (abandon à la discrétion de l'Artisan)
​

> ✅ Les résultats affichés dans les cartes tiennent compte des filtres appliqués.

### 3. Le bouton Nouvelle Facture

![](https://downloads.intercomcdn.com/i/o/tarury57/1429694687/b3d241f63a2b987e84ba9d60f493/CleanShot+2025-03-19+at+09_08_57.png?expires=1788618600&signature=d015f440b688d90573d218b71b5cd81ef4e63d363081dd0794839eec344261c3&req=dSQlH893mYdXXvMW1HO4zY1hZy7Fg2%2B22JdZiMvCZgheNZmYfu%2Bu5jdEJexv%0AN7w34khj5eXAGa8%2FNSI%3D%0A)

Ce bouton vous permet de créer une nouvelle facture en renseignant :

- un titre / nom
- le client associé ou à créer (CRM)

### 4. Le bouton Actions

![](https://downloads.intercomcdn.com/i/o/tarury57/1429696743/fccc35fa380184d5fffb5e16955a/image.png?expires=1788618600&signature=c1c7cdbb8d5592fa7b40ec3877997944c2db340163116b60ac6709459f9a95e9&req=dSQlH893m4ZbWvMW1HO4ze2F4c6y%2BWa%2BNFHvR835sJsZrzkMrWdDV89Cy2mr%0Av%2BgKD2DGok9askbHFxQ%3D%0A)

Ce bouton vous permet :

- d'importer vos anciennes factures, issues de votre précédent logiciel
- d'exporter toutes les lignes du tableau des factures (format .csv)
- d'exporter les écritures comptables sur les factures (format .csv)
- d'exporter toutes les factures sous forme de document (format .pdf)

> ✅ Les exports tiennent compte des filtres appliqués.
> ​*Exemple : filtrez les factures du mois précédent avant de réaliser votre export comptable et votre export des documents PDF.*

### 5. Les colonnes affichées

![](https://downloads.intercomcdn.com/i/o/tarury57/1429699369/bc1e0d736f3b1d688f38a48c41e1/CleanShot+2025-03-19+at+09_13_32.png?expires=1788618600&signature=7ba144f1a2409753a682ffd8c50d8707745d73639bdd5e77f8e8948727903080&req=dSQlH893lIJZUPMW1HO4zYQfl7CHhyYVpe3PWH8lrajUP9WTZIEgzF7dSc8Z%0AQFoEco7A8VmMvi9vu6Q%3D%0A)

Les colonnes disponibles pour les factures sont par défaut :

- le numéro (de référence)
- le titre / nom de la facture
- le Client associé (CRM)
- le Chantier associé
- le Montant HT
- le Montant TTC
- le Reste à payer TTC
- le Statut
- la Date de création
- l'Utilisateur ayant créé le document

 En cliquant sur le bouton "Personnaliser", en bas de la page, vous pouvez :

- afficher / masquer les colonnes
- déplacer l'ordre des colonnes

![](https://downloads.intercomcdn.com/i/o/tarury57/1429678699/4660e092380a96f3bd14f3e93669/CleanShot%2B2025-03-14%2Bat%2B09_34_57.png?expires=1788618600&signature=984d4998883d144f44951969e07172e63dbcbe2606dc48f2ceb1bba86d7b5e9c&req=dSQlH895lYdWUPMW1HO4zZBYoB%2BUV2Bvvl6C1Xe26P0Evt%2BI3ZL7Omtxfrz8%0AY4wa%2B1gYaIBT5MRHaso%3D%0A)

Vous pouvez naviguer de page en page grâce aux boutons de navigation :

![](https://downloads.intercomcdn.com/i/o/tarury57/1429678696/05a29367208b2c17b323e345adb7/CleanShot%2B2025-03-14%2Bat%2B09_38_05.png?expires=1788618600&signature=8b58ba422b0792520a4d4114d1e71088a318858acd68200aae62b27968b0c05c&req=dSQlH895lYdWX%2FMW1HO4zV50soVYs00ubJevB8ug%2F25ax30tcCj2xC%2BN1Nic%0ADC6SLPgX%2F7HnIPQDffY%3D%0A)
