# Intégrer le calendrier InterFast dans une autre application

> 💡 En partageant votre calendrier InterFast, vous donnez la possibilité à d'autres applications d'accéder à **vos événements** *(dont vous êtes l'intervenant principal ou secondaire)*.
> Si au contraire, vous souhaitez intégrer votre calendrier personnel dans InterFast, c'est [par ici](https://intercom.help/interfast/fr/articles/10253803-integration-d-un-autre-calendrier-dans-interfast).

[Vidéo YouTube](https://www.youtube.com/watch?v=8tkKUBlK5UQ)

## Générer une adresse iCal InterFast

1. Rendez-vous dans votre profil
2. Dans la section **Synchronisation de calendriers**, cliquez sur le bouton **Créer un lien de partage du calendrier InterFast**

> ✅ Vous avez généré une adresse **iCal** pour ajouter **votre** **calendrier** **InterFast** à votre calendrier personnel ! Plus d'informations ci-dessous pour l'intégrer facilement à Google Calendar, Outlook ou iCloud.

## Intégrer le calendrier InterFast à...

### Google Calendar 

1. Ouvrir Google Calendar : Accédez à [Google Calendar](https://calendar.google.com/) sur votre navigateur et connectez-vous à votre compte Google si nécessaire
2. Ajouter un calendrier : Dans la colonne de gauche, sous **Autres calendriers**, cliquez sur le bouton **+** à côté de cette section
3. Sélectionner **À partir de l'URL** : Un menu déroulant apparaît, choisissez **À partir de l'URL**
4. Entrer l'adresse iCal : Collez l'adresse iCal du Calendrier InterFast dans le champ.
5. Ajouter le calendrier : Cliquez sur **Ajouter un calendrier**. Le Calendrier InterFast apparaîtra désormais dans votre liste de calendriers sous la section *Autres calendriers*

###  Outlook

1. Ouvrir Outlook : Accédez à [outlook.com](https://outlook.com) et connectez-vous à votre compte
2. Accéder au calendrier : Cliquer sur l'icône du calendrier dans la barre de gauche
3. Ajouter un calendrier : Dans le panneau de gauche, cliquez sur **Ajouter un calendrier**
4. Sélectionner **S'abonner à partir du Web** : Un menu s'affiche, choisissez **S'abonner à partir du Web**
5. Entrer l'adresse iCal : Collez l'adresse iCal du Calendrier InterFast dans le champ prévu à cet effet
6. Personnaliser : Vous pouvez choisir un nom et une couleur pour le calendrier
7. Enregistrer : Cliquez sur **Importer**. Le Calendrier InterFast sera désormais visible dans votre calendrier Outlook.

### Calendrier Apple depuis macOs

1. Ouvrir Calendrier : Ouvrir l'application *Calendrier* sur macOs
2. Ajouter un calendrier : Dans le menu **Fichier**, cliquer sur **Abonnement à un calendrier**
3. Entrer l'adresse iCal : Collez l'adresse iCal du Calendrier InterFast dans le champ et cliquez sur **S’abonner**
4. Personnaliser : Vous pouvez choisir un nom et une couleur pour le calendrier et décider de sa fréquence d'actualisation
5. Enregistrer : Cliquez sur **OK** pour finaliser l'ajout. Le Calendrier InterFast apparaîtra dans votre application *Calendrier* sur vos appareils Apple.

### Calendrier Apple depuis iPhone

1. Ouvrir Calendrier : Ouvrir l'application *Calendrier*
2. Appuyer sur **Calendriers** : bouton en bas au centre
3. Appuyer sur **Ajouter un calendrier** : bouton en bas à gauche, puis sur **Ajouter un calendrier avec abonnement**
4. Entrer l'adresse iCal : Collez l'adresse iCal du Calendrier InterFast dans le champ et cliquez sur **S’abonner**
5. Personnaliser : Vous pouvez choisir un nom et une couleur pour le calendrier et décider de sa fréquence d'actualisation
6. Enregistrer : Cliquez sur **Ajouter** en haut à droite pour finaliser l'ajout. Le Calendrier InterFast apparaîtra dans votre application *Calendrier* sur vos appareils Apple.
