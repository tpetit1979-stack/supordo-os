## Personnalisation

Toutes les options de personnalisation sont accessibles depuis vos paramètres Batikko. Les modifications sont appliquées à votre site automatiquement, sans intervention technique :

- Titre principal et sous-titre du hero
- Texte « À propos »
- Liste des services proposés (titre, description, icône)
- Coordonnées (téléphone, email, adresse)
- Liens vers vos réseaux sociaux
- Témoignages clients (selon votre plan)
- Galerie de réalisations photos (selon votre plan)
- Horaires d'ouverture
- Méta description SEO
- Couleur principale personnalisée

## Création du site (étape par étape)

1. 01### Choisissez votre offreDepuis vos paramètres, accédez à la section Site internet et sélectionnez l'offre qui correspond à vos besoins.
2. 02### Renseignez votre adresse webChoisissez votre sous-domaine ou, si votre plan le permet, votre nom de domaine personnalisé. Batikko vérifie automatiquement la disponibilité.
3. 03### Personnalisez le contenuHero, services, contact, couleurs, photos. Le formulaire vous guide étape par étape, sans aucune compétence technique.
4. 04### Validation et créationVotre site est généré automatiquement avec toutes vos personnalisations. La création prend généralement quelques minutes.
5. 05### Configuration DNS (si domaine personnalisé)Si vous avez choisi un nom de domaine personnalisé, Batikko vous envoie par email les paramètres à configurer chez votre fournisseur de domaine.
6. 06### Site en ligneUne fois prêt, votre site est accessible publiquement. Vous pouvez le modifier à tout moment depuis vos paramètres.

## Limitations actuelles

Soyons transparents sur ce qui sera amélioré prochainement :

Le formulaire de contact de votre site n'est pas encore intégré au CRM Batikko : les leads doivent être recopiés manuellement (intégration en cours de développement).

La configuration DNS pour les noms de domaine personnalisés est manuelle : vous recevez les paramètres par email mais devez les configurer vous-même chez votre fournisseur.

Ces limitations sont en cours de résolution. Si l'intégration directe des leads vers le CRM est critique pour vous, contactez-nous pour connaître la roadmap.
