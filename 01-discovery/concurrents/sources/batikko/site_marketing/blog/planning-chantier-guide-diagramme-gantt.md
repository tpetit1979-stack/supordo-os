Le diagramme de Gantt est l'outil de planification par excellence dans le BTP. Inventé au début du XXe siècle, il reste aujourd'hui indispensable pour visualiser et coordonner les travaux sur un chantier.

## Qu'est-ce qu'un diagramme de Gantt ?

C'est une représentation graphique qui affiche :

- Les tâches à réaliser sur l'axe vertical
- Le temps sur l'axe horizontal
- Des barres horizontales montrant la durée de chaque tâche
- Les liens de dépendance entre les tâches

## Pourquoi utiliser un Gantt pour vos chantiers ?

### Vision globale

D'un coup d'œil, vous voyez :

- L'ensemble des travaux à réaliser
- Les dates de début et fin prévisionnelles
- Les chevauchements et les temps morts
- Le chemin critique du projet

### Coordination des équipes

Chaque intervenant sait exactement :

- Quand il doit intervenir
- Qui intervient avant et après lui
- Les contraintes à respecter

### Anticipation des problèmes

Le Gantt permet d'identifier à l'avance :

- Les goulots d'étranglement
- Les risques de retard
- Les conflits de ressources

## Comment créer votre planning Gantt

### Étape 1 : Lister toutes les tâches

Décomposez votre chantier en tâches élémentaires :

- Préparation du terrain
- Gros œuvre
- Second œuvre
- Finitions
- Nettoyage et réception

### Étape 2 : Estimer les durées

Pour chaque tâche, estimez :

- La durée optimiste
- La durée pessimiste
- La durée probable

### Étape 3 : Identifier les dépendances

Quelles tâches doivent être terminées avant d'en commencer d'autres ?

- Les fondations avant les murs
- L'électricité avant le placo
- La peinture après le plâtre sec

### Étape 4 : Affecter les ressources

Attribuez à chaque tâche :

- L'équipe ou le sous-traitant responsable
- Le matériel nécessaire
- Le budget alloué

## Les erreurs à éviter

- **Sous-estimer les durées** : Prévoyez toujours une marge
- **Oublier les contraintes externes** : Livraisons, séchage, météo...
- **Ne pas mettre à jour** : Le planning doit vivre avec le chantier
- **Planning trop détaillé** : Restez à un niveau lisible

## Utiliser un logiciel de Gantt

Un bon logiciel comme Batikko vous permet de :

- Créer facilement des tâches par glisser-déposer
- Définir les dépendances visuellement
- Affecter les ressources
- Suivre l'avancement en temps réel
- Recalculer automatiquement les dates en cas de retard
- Partager le planning avec les intervenants

## Conclusion

Le diagramme de Gantt est un outil puissant qui, bien utilisé, vous permet d'optimiser vos chantiers, d'éviter les retards et d'améliorer la coordination entre vos équipes.
