# Comment créer des modèles de feuilles d'heures

#### Gagnez du temps sur vos chantiers grâce à des modèles de feuilles d'heures : capturez précisément les heures de main-d'œuvre chantier par chantier.

Vous avez la possibilité de créer des modèles de feuilles d'heures que vous pouvez reprendre pour le pointage des heures.

1. Rendez vous dans l'onglet **Feuilles d'heures.**
2. Cliquez sur **Modèles.**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_zsva5.jpg)

3. Cliquez sur N**ouveau Modèle**.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_ts5kx6.jpg)

4. Indiquez un nom pour le modèle

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1q57rj.jpg)

5. Vous pouvez maintenant créer votre modèle

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_67ijz5.jpg)

> Pour appliquer un modèle lors du pointage de la semaine, il faut cliquer sur les 3 points en bout de ligne et sélectionner le modèle à appliquer.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre-2_ekyavj.jpg)
