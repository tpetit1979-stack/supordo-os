# Comment inviter mon comptable ?

#### Invitez votre comptable pour un accès sécurisé aux exports de documents : simplifiez vos échanges comptables, gagnez du temps et assurez une synchronisation parfaite de vos données financières.

1. Dans le menu principal, rendez vous dans les [Réglages](https://app.costructor.co/account/company)
2. Dans la section *Réglages*, cliquez sur [Equipe](https://app.costructor.co/account/company/users)
3. Cliquez sur **Comptable**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre-2_bthojp.jpg)

4. Cliquez sur **Inviter mon comptable** :
5. Remplissez les champs

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/image_jud4e5.png)

6. Valider en cliquant sur **Continuer**
7. Vérifier les informations et cliquez sur **Envoyer l’invitation**

> Le comptable recevra une invitation par email et pourra accéder à votre compte pour récupérer vos documents et faire le paramétrage comptable.
