# Comment modifier son adresse mail de connexion / son mot de passe ?

Vous avez la possibilité de modifier à tout moment votre adresse mail de connexion ainsi que votre mot de passe.

1. Cliquez sur votre profil en haut à droite de votre espace.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1216tk.jpg)

2. Cliquez ensuite sur mon profil.
3. Modifiez vos informations de connexion.
4. Cliquez sur enregistrer.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_8zdujs.jpg)

> Si vous avez oublié votre mot de passe, vous pouvez cliquer sur "**mot de passe oublié"** lors de votre connexion, vous recevrez un lien de réinitialisation sur votre boite mail.
