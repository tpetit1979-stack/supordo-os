# Comment importer plus de 100 millions d'articles en 1 clic ?

#### Ne perdez plus de temps à copier-coller, importez directement vos produits depuis vos sites fournisseurs.

> L'extension est disponible sur le navigateur Google Chrome et le navigateur Firefox depuis un ordinateur.

1. **Téléchargez l'extension depuis vos réglages / votre bibliothèque ou via les liens suivants** : [Plugin Google Chrome](https://chromewebstore.google.com/detail/costructor/ccfhdffgckhdclpkhcgfgdackgiljldp) / [Plugin Mozilla Firefox](https://addons.mozilla.org/fr/firefox/addon/costructor/)

Depuis vos réglages :

Cliquez sur l'onglet "intégrations" et installez l'extension.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1vlz3vd.jpg)

Depuis votre bibliothèque :

Cliquez sur "découvrir" depuis le bandeau présent dans votre bibliothèque.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre-3_1cqc2ub.jpg)

2. **Une fois l'extension téléchargée, rendez-vous sur votre site fournisseur**
3. **Sélectionnez vos articles**
4. **Cliquez sur ajouter à Costructor**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_15tvwhj.jpg)

> Lorsque vous ajoutez un élément depuis le site fournisseur, la désignation complète et le prix d'achat sont repris automatiquement sur Costructor

5. **Une fois votre shopping effectué rendez vous sur costructor pour ajouter vos produits directement sur votre devis ou dans votre bibliothèque**

Ajout dans votre bibliothèque

1. **Cliquez sur le bouton chrome à droite de nouvel élément**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_uhejpw.jpg)

2. **Sélectionnez les produits que vous souhaitez ajouter**
3. **Sélectionnez le dossier dans lequel vous souhaitez l'importer**
4. **Cliquez sur importer les produits**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_g7nzr6.jpg)

Ajout dans votre devis

1. **Cliquez sur nouvelle ligne**
2. **Cliquez sur "Panier"**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_191mfg6.jpg)

3. **Cliquez sur le produit que vous souhaitez ajouter**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_hlfrus.jpg)

4. **Votre produit à été ajouté à votre devis**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_mj2mkl.jpg)

> Si vous avez activé le calcul des marges et que vous avez défini un taux de marge, le prix de vente de votre produit est calculé automatiquement.

> Si vous ne retrouvez pas votre site fournisseur dans la liste des fournisseurs disponibles, n'hésitez pas à nous en faire la demande via le chat afin de l'ajouter.
