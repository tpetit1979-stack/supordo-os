# Comment créer une clé API ?

## Développez les possibilités de Costructor en le connectant à vos outils préférés. Une clé API vous permet de mettre en place des intégrations sécurisées et d'automatiser vos workflows.

> Une clé API permet à une application externe de s'authentifier auprès de Costructor afin d'accéder aux fonctionnalités autorisées de l'API publique. Considérez cette clé comme un identifiant confidentiel : ne la partagez jamais publiquement et révoquez-la immédiatement en cas de compromission.

1. Rendez-vous dans Réglages/API.
2. Cliquez sur créer une clé API.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_14loq4i.jpg)

3. Définissez le nom de la clé et cliquez sur Créer la clé.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_in44xt.jpg)

4. Copiez la clé et fermez la page.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_nle3q3.jpg)

> Retrouvez la documentation de l'API en cliquant sur le lien suivant : [Documentation](https://costructor.readme.io/reference/introduction)

> L'API est disponible en option sur les abonnements pro et business+, elle est incluse dans l'abonnement premium.
