# Comment personnaliser le nom des documents PDF ?

## Adaptez le nom de vos documents PDF à votre façon de travailler pour plus de simplicité au quotidien.

> Vous pouvez personnaliser le nom de vos documents PDF sur tout type de documents.

1. Rendez-vous dans les réglages du logiciel.
2. Cliquez sur le type de documents souhaité (devis/factures/bons de commande…)
3. Cliquez sur modifier le nom des documents PDF.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1gjigek.jpg)

4. Selectionnez les informations que vous souhaitez faire apparaître et cliquez sur enregistrer

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_ejdm2.jpg)
