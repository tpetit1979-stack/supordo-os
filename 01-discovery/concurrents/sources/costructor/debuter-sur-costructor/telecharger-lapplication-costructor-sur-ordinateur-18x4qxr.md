# Télécharger l'application Costructor sur ordinateur

Vous pouvez enregistrer le logiciel [Costructor](https://app.costructor.co/) sur votre ordinateur!

Voici la marche à suivre sur les navigateurs les plus utilisés :

> Nous recommandons d'utiliser Google Chrome pour cette opération

# Google Chrome

1. Rendez-vous sur l'application [Costructor](https://app.costructor.co/)
2. Cliquez sur l'icône d'installation dans la barre d'URL

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/appchrome_1sbmgfj.png)

3. Cliquez sur **Installer**

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/appchrome2_1rltuhh.png)

> L'application est installé et serra disponible sur votre Bureau

# Mozilla Firefox

1. Rendez-vous sur l'application [Costructor](https://app.costructor.co/)
2. Cliquez sur le **cadenas** à gauche de la barre d'adresse (là où l'adresse web (URL) est affichée)
3. Maintenez le bouton de souris enfoncé, déplacez le pointeur vers le bureau, puis relâchez le bouton de la souris. Le raccourci est créé.

# Safari

1. Rendez-vous sur l'application [Costructor](https://app.costructor.co/)
2. Cliquez une fois dans le champs de la barre d'adresse (là où l'adresse web (URL) est affichée, le logo Costructor apparaîtra à gauche de cette même barre
3. Cliquez sur le **logo Costructor** à gauche de la barre d'adresse (là où l'adresse web (URL) est affichée)
4. Maintenez le bouton de souris enfoncé, déplacez le pointeur vers le bureau, puis relâchez le bouton de la souris. Le raccourci est créé.

> Une connexion internet reste requise afin de pouvoir vous connecter au logiciel Costructor et l'utiliser
