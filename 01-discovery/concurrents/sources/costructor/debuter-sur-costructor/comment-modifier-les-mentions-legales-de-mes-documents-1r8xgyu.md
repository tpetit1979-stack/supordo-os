# Comment modifier les mentions légales de mes documents ?

Pour modifier ou compléter les mentions légales sur vos documents, il vous suffit de vous rendre dans le menu : **Réglages** > **Informations** puis de remplir les différentes informations.

1. Nom de votre entreprise
2. Adresse
3. Pays d'enregistrement
4. Forme juridique
5. Capital social en €
6. Numéro SIREN
7. Numéro de TVA
8. Chambre des métiers
9. Ville du RCS
10. Code APE

> 💡 Ces informations seront automatiquement ajoutées sur tous vos documents
