# Comment configurer mon taux de marge par défaut ?

#### Modifiez votre taux de marge par défaut pour une rentabilité sur mesure : Adaptez-le à vos chantiers et optimisez automatiquement prix de vente, fournitures et main-d'œuvre.

Configurer le taux de marge global

1. Via le menu principal, cliquez sur **Réglages** > Rentabilité.
2. Changez le taux de marge par défaut avec les flèches ou saisissez-le manuellement.

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/rentabilite_5i0y99.png)

1. Enregistrez les modifications

Configurer le taux de marge global par type d'élément

1. Via le menu principal, cliquez sur **Réglages** > [Rentabilité](https://app.costructor.co/account/company/profit)
2. Cliquez sur l’option Taux de marge par défaut > **Ajustez par type d’éléments**
3. Changez les taux de marge avec les flèches ou saisissez-le manuellement

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/rentabilite-elements_5gaxo.png)

1. Enregistrez les modifications
