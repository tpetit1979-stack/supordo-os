# Comment connecter son compte bancaire ?

## Connecter votre compte bancaire

1. Dans le menu principal, rendez vous dans les [Réglages](https://app.costructor.co/account/company)
2. Dans la section *Réglages*, cliquez sur [Banques](https://app.costructor.co/account/company/banks)
3. Cliquez sur **+ Connecter mon compte bancaire**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1sxi78p.jpg)

4. Sélectionnez votre banque

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_dejp76.jpg)

5. Indiquez votre idenfitiant et mot de passe, puis cliquez sur **valider**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_9snsqu.jpg)

6. Cliquez sur **connecter**

> Dans le menu principal, rendez vous dans les [Transactions](https://app.costructor.co/transactions) pour retrouver vos transactions bancaires

> Vous pouvez visionner notre vidéo dédiée à la connexion bancaire
