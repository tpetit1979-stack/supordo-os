# Comment utiliser les Tags analytiques ?

#### **Les tags analytiques vous donnent une vision claire et instantanée de vos performances, pour mieux piloter vos actions, optimiser vos résultats et prendre des décisions plus stratégiques.**

Ajouter un tag analytique :

1. Rendez-vous dans les réglages de votre espace.
2. Cliquez sur Tags analytiques.
3. Ajouter vos tags.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1qq1092.jpg)

1. Renseignez le nom et choisissez une couleur.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_14e0lmm.jpg)

> Les tags analytiques peuvent être utilisés sur vos devis, vos factures ainsi que vos chantiers.

Ajouter un tag sur vos devis/factures :

1. Vous pouvez ajouter votre tag sur votre devis une fois qu'il est finalisé en cliquant sur tags analytiques sur la droite.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1vhp06i.jpg)

1. Vous pouvez l'ajouter également depuis les onglets devis/factures.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_uhy3x6.jpg)

> Vous avez la possibilité de filtrer par tag depuis l'onglet pilotage, ce qui vous permet de retrouver le chiffre d'affaires lié à ce tag et également la performance commerciale de vos devis

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_sb1n53.jpg)

Ajouter un tag analytique sur un chantier :

1. Vous avez la possibilité d'ajouter un tag analytique sur vos chantiers depuis le tableau de bord du chantier. Cela vous permet de filtrer vos chantiers par tag.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1vpytl3.jpg)

> Les tags analytiques sont disponibles avec l'abonnement Premium de votre logiciel.
