# Comment supprimer le logo Costructor de mes documents ?

Vous pouvez retirer le logo Costructor de vos devis et factures avec les abonnements **Pro** ou **Business**.

## Masquer le logo Costructor

1. Cliquez sur **Réglages** puis sur **Apparence.**
2. Cochez la case **Masquer le logo Costructor**
3. Cliquez sur **Enregistrer** en haut à droite
