# Télécharger l'application Costructor sur mobile

Vous pouvez enregistrer l'application mobile [Costructor](https://app.costructor.co/) sur tous les smartphones!

Pour cela, nul besoin de vous rendre dans le Play Store ou l'Apple Store. Voici la marche à suivre :

# Appareils Android (Samsung, Huawei, Xiaomi, Oppo....)

1. Rendez-vous sur l'application [Costructor](https://app.costructor.co/)
2. Cliquez sur les 3 petits points à droite de la barre d'outils

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/3-petits-points-android_12567bk.jpg)

3. Cliquez sur **Ajouter à l'écran d'accueil**

# Appareils iOS (Apple)

1. Rendez-vous sur l'application [Costructor](https://app.costructor.co/)
2. Cliquez sur le carré avec une flèche à l'intérieur

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/fleche-carre-ios_13yrwh3.jpg)

3. Cliquez sur **Ajouter à l'écran d'accueil**

> 💡 Costructor est le seul logiciel de devis et factures BTP à disposer d'une application mobile 100% fonctionnelle
