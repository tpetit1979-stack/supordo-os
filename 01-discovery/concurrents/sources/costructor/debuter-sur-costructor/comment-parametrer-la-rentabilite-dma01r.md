# Comment paramétrer la rentabilité ?

#### Optimisez la rentabilité de vos devis dès la conception : paramétrez vos marges et vos frais généraux pour sécuriser vos chantiers et booster votre performance économique.

1. Rendez-vous dans les réglages.
2. Cliquez sur **rentabilité.**

Définir un taux de marge :

> Vous pouvez définir un taux de marge par défaut. Ce taux de marge sera appliqué sur tous les types d'élèments. Si vous souhaitez définir des taux de marge plus précis, vous pouvez les définir par type d'élément.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_ztru5o.jpg)

Définir un coefficient de frais généraux :

1. Indiquez votre coefficient de frais généraux, qui sera repris sur l'ensemble de vos chantiers.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1x69f40.jpg)

> Pour une entreprise de BTP, le coefficient de frais généraux est calculé en utilisant la formule suivante : **frais généraux / (consommation + main-d'œuvre)**.
