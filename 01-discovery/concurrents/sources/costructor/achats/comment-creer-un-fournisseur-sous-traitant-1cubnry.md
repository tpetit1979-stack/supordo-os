# Comment créer un fournisseur / sous-traitant ?

Créez un fournisseur en quelques étapes seulement !

1. Rendez-vous dans la section [Fournisseurs](https://app.costructor.co/suppliers), depuis le menu principal
2. Cliquez sur **Nouveau contact** puis **Fournisseur**
3. Renseignez ses informations, puis cliquez sur **Créer le contact** !
