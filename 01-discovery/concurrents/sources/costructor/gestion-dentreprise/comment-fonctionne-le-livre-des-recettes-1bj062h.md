# Comment fonctionne le livre des recettes ?

**Le livre des recettes est un registre dans lequel un micro-entrepreneur enregistre de façon chronologique toutes les recettes encaissées au cours d'une année**

> Seuls les micro-entrepreneurs / Entrepreneur Individuel sont tenus de tenir un livre des recettes.

## Ajouter une classification à un élément

#### DANS LA BIBLIOTHÈQUE :

1. Via le menu principal, rendez-vous dans [Bibliothèque](https://app.costructor.co/products).
2. Sélectionnez un **élément existant** ou **créez un nouvel élément**.

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/ldr-3-1_5n8eh4.png)

3. Dans la fenêtre Informations, trouvez l’option **Compte de produit**.
4. Sélectionnez la classification que vous souhaitez.
5. Cliquez sur **Mettre à jour** ou **Créer l’élément** pour sauvegarder vos modifications.

#### DANS UN DEVIS OU UNE FACTURE :

1. Sélectionnez un **Devis** ou une **Facture** en cours d’édition.
2. Cliquez sur la **ligne** que vous souhaitez classifier.
3. Sélectionnez le bouton **Réglages du produit**.

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/ldr-1_yd8r9b.png)

4. Ajoutez ou modifiez la classification que vous souhaitez.

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/ldr-2_b6k9ch.png)

5. Cliquez sur **Enregistrer** pour sauvegarder vos modifications.

## Visualiser un règlement sur le Livre de recettes

1. **Facturez** votre devis avec les éléments classifiés.
2. [Enregistrez un règlement sur votre facture](https://support.costructor.co/fr/article/comment-enregistrer-un-reglement-sur-une-facture-j8zd6o/)
3. Via le menu principal, rendez-vous dans [Livre de recettes](https://app.costructor.co/accounting/incomes).

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/group-2_m8ykb9.png)

> Vous pouvez maintenant consulter vos recettes classifiées dans la liste.

> Vous pouvez modifier la classification des comptes par défaut via Réglages > Comptabilité
