# Comment justifier une transaction bancaire ?

#### Rapprochez vos transactions bancaires avec vos factures de vente et d’achat pour gagner du temps, sécuriser votre trésorerie et garder une vision claire de votre activité.

> Vous devez au préalable connecter votre compte bancaire pour pouvoir faire le rapprochement : [Comment connecter son compte bancaire ?](https://support.costructor.co/fr/article/comment-connecter-son-compte-bancaire-xupyjb/)

Dans le menu principal, rendez-vous dans les Transactions.

1. Sélectionnez la transaction à justifier

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_dtot6x.jpg)

2. Cliquez sur **Recherchez sur Costructor**
3. Sélectionnez la ou les factures à rapprocher

> Avec l'IA, des suggestions de factures vous seront proposées en fonction du montant, du nom du client/fournisseur.....

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/image_19pjbo.png)

4. Cliquez sur **Rapprocher la facture**

> Vous pouvez rapprocher plusieurs factures à une seule transaction ainsi que plusieurs transactions à une seule facture

> Si vous n'avez pas ajouté une facture d'achat avant de faire le rapprochement, vous pouvez directement l'ajouter en cliquant sur la transaction.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_2qudt0.jpg)

1. Déposez votre facture ou sélectionnez la depuis votre ordinateur
2. Vérifiez et/ou remplissez les champs
3. Cliquez sur **Enregistrer**

> Vous avez la possibilité de catégoriser vos transactions directement  par exemple dans le cas de prélevement URSAFF en cliquant sur + dans la colonne catégories et de les noter comme justifié manuellement en cliqaunt sur le 📎

> Vous pouvez consulter notre vidéo dédiée à la justification de vos transactions bancaires.
