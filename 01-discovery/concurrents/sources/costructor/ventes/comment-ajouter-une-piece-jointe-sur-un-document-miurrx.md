# Comment ajouter une pièce-jointe sur un document ?

#### Ajoutez vos pièces jointes (plans, photos, etc.) à vos devis et factures pour envoyer à vos clients des documents complets, clairs et professionnels en un seul envoi.

#### Dans un document en cours d'édition :

1. Créez ou ouvrez votre [Devis](https://app.costructor.co/quotes) / [Factures](https://app.costructor.co/invoices).
2. Cliquez sur le bouton **Pièce jointe** dans la barre latérale.

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/capture-decran-2024-06-12-a-22_7qtlgu.png)

3. Sélectionnez votre fichier via votre ordinateur ou les fichiers Costructor.

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/capture-decran-2024-06-12-a-22_16o68wb.png)

4. Indiquez si votre pièce jointe doit être Privée ou Partagée avec le client en cliquant directement dessus.

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/group-9_a2kri2.png)

#### Dans un document finalisé :

1. Ouvrez votre [Devis](https://app.costructor.co/quotes) / [Factures](https://app.costructor.co/invoices) finalisé.
2. Dans le menu de droite, dans l'onglet Pièce jointe, cliquez sur **+ Ajouter**.

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/capture-decran-2024-06-12-a-22_wx8ej.png)

3. Sélectionnez votre fichier via votre ordinateur ou les fichiers Costructor.

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/capture-decran-2024-06-12-a-22_1aizjlu.png)

4. Indiquez si votre pièce jointe doit être Privée ou Partagée avec le client en cliquant directement dessus.

> Vous pouvez supprimer la pièce jointe via l'icône "Poubelle".

> Lors de l'envoi de votre document, vous avez la possiblité de joindre les PDF à l'email directement en cliquant sur les options avancées.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_u24hl2.jpg)

> En joignant le PDF du document à l'email, vous ne profiterez pas des notifications en cas d'ouverture du document.
