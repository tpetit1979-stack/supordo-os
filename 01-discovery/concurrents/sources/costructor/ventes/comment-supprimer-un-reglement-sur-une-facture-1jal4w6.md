# Comment supprimer un règlement sur une facture ?

#### Supprimez le règlement associé en toute simplicité sur vos factures : ajustez les soldes, relancez efficacement et reprenez le contrôle de votre trésorerie sans contrainte.

1. Via le menu principal, cliquez sur **Factures**.
2. Sélectionnez la facture sur laquelle vous souhaitez annuler un règlement.
3. Dans le menu à droite de votre facture, vous pouvez supprimer le règlement en cliquant sur l’icône **Supprimer**  à droite de celui-ci.

![Supprimer un règlement](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/capture-decran-2024-09-03-a-16_fjmrkw.png)

4. Un pop-up s'affichera, vous demandant si vous souhaitez vraiment supprimer ce règlement ?

![Supprimer le règlement](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/capture-decran-2024-09-03-a-16_1ilmdrv.png)
