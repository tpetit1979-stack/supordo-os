# Comment afficher la référence d’un produit sur un devis ou d'une facture ?

#### Comment afficher la référence d'un produit ou d'une facture ?

1. Rendez-vous dans la section [Devis](https://app.costructor.co/quotes) ou [Factures](https://app.costructor.co/invoices).
2. Sélectionnez le devis ou la facture à éditer
3. Dans le menu à droite, cliquez sur **Options**
4. Activez l'option **Afficher les références des produits**

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/refproduit_1f9i4yj.png)

5. Validez en cliquant sur **Enregistrer**

> Les références sont maintenant indiquées sur votre document
