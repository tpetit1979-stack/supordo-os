# Comment signer un devis électroniquement ?

#### Convertissez vos prospects plus vite : laissez vos clients signer vos devis électroniquement en toute sécurité.

> Vous pouvez activer la signature électronique depuis Réglages/Abonnement.

1. Lorsque vous envoyez votre devis à votre client, il a la possibilité de le signer électroniquement en cliquant sur « Accepter le devis ».

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_7090tz.jpg)

1. Si vous avez ajouté des options dans le devis, il a la possibilité de les cocher et de cliquer sur continuer.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1xvz2gm.jpg)

1. Il faut qu'il renseigne son adresse mail puis cliquer sur "démarrer la signature"

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1gx5dqg.jpg)

1. Il pourr ensuite cliquer sur envoyer le code et le renseigner une fois reçu sur son adresse mail

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_iso1qb.jpg)

1. Dés que le code est renseigné, vous serez redirigé sur la page du devis, il faut cliquer sur accepter et continuer

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_139epzf.jpg)

1. Le devis pourra étre lu et il faudra cocher j'ai lu et j'accepte le document puis cliquer sur continuer

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1gsrvr2.jpg)

1. Il pourra ensuite renseigner ses informations pour obtenir un code par SMS

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1aaakao.jpg)

1. Il faut ensuite renseigner le code reçu par SMS et cliquer sur signer.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1k0zmbg.jpg)

1. Il faut en suite cliquer sur "j'ai terminé"

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_45cxus.jpg)

> La signature électronique est maintenant apposée sur le devis. Une fois signé, le devis se met automatiquement en accepté.

> La signature électronique est disponible sur tous nos abonnement. Elle est incluse dans les abonnement business+ et premium en illimitée et est facturée 0,90 centime HT sur l'abonnement pro par signature effective.
