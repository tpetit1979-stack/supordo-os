# Comment masquer le numéro de révision d'un devis ?

#### Par défaut, chaque devis modifié génère un numéro de révision (ex. v1, v2, v3) afin de suivre l’historique des modifications.

Cependant, vous pouvez choisir de ne pas afficher ce numéro dans le document transmis à votre client.

> Si vous modifiez un devis déjà signé, il faudra le refaire signer à votre client.

Masquer le numéro de révision d'un devis

1. Cliquez sur ⚙️ Options sur la droite lors de la modification du devis

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_jo2sn3.jpg)

2. Activez l'option "Masquer le numéro des révisions des devis"

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_cz34r4.jpg)

> Vous pouvez définir cette option par défaut avant d'enregistrer si vous souhaitez que cela soit masqué automatiquement sur vos prochains devis.

> Le numéro de la révision ne sera plus visible sur le document pour le client mais restera visible pour vous.
