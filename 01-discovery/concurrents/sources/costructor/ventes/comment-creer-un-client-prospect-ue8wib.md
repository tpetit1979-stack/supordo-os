# Comment créer un client / prospect ?

#### Créez un client en quelques étapes seulement !

Créer un client particulier

1. Rendez-vous dans la section **Contact**
2. Cliquez sur **Nouveau contact** puis **Client**
3. Sélectionnez "Particulier"
4. Renseignez ses informations, puis cliquez sur **Créer le contact** !

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1x4gs9x.jpg)

Créer un client professionnel

1. Rendez-vous dans la section **Contact**
2. Cliquez sur **Nouveau contact** puis **Client**
3. Sélectionnez "Professionnel"
4. Renseignez ses informations, puis cliquez sur **Créer le contact** !

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1fn1nqg.jpg)
