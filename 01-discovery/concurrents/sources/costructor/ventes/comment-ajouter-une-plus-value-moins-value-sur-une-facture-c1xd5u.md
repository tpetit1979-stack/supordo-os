# Comment ajouter une plus - value / moins - value sur une facture ?

#### Que ce soit des travaux supplémentaires ou des prestations qui n'ont pas été effectuées, ne perdez pas de temps et ajoutez-les directement sur vos factures.

> Il est possible de les ajouter sur votre devis initial si celui-ci n'est pas lié à une facture de situation ou finale.

> Si votre devis est déjà facturé, vous pouvez créer un avenant et importer ces lignes à la facturation initiale.

Ajouter une plus-value

1. Rendez-vous sur l'édition d'une facture
2. Cliquez sur le bouton + Nouvelle ligne.
3. Indiquez la désignation, le prix ainsi que la quantité souhaitée.

> Sur une facture de situation, il faudra indiquer le pourcentage d'avancement sur votre ligne de plus-value afin que celle-ci soit bien prise en compte.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/capture-decran-2025-08-06-a-15_1sq875q.png)

Ajouter une moins-value

1. Rendez vous sur l'édition d'une facture
2. Cliquez sur le bouton + Nouvelle ligne
3. Indiquez la désignation, le prix ainsi que la quantité souhaitée
4. Indiquez le signe **" - "** devant la quantité. Le prix unitaire doit étre positif

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/capture-decran-2025-08-06-a-15_pzprbz.png)

> Les plus - values / moins - values seront visibles sur le décompte général et seront automatiquement ajoutées sur le total de votre facture
