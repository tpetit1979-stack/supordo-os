# Comment importer des lignes d'un autre document ?

#### Importez instantanément les lignes d’un autre document dans vos devis ou factures BTP : gagnez du temps, évitez les ressaisies et construisez des offres ultra-personnalisées en quelques clics.

> L'import de lignes est valable pour les devis, bons d'intervention, bons de commande client, factures et bons de commande fournisseur.

Importer des lignes d'un document

1. Rendez-vous sur un **document en brouillon.**
2. Cliquez sur l'icône **boîte à outils** sur la droite de votre écran.

![Boite à outils](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/capture-decran-2025-08-05-a-15_efuy93.png)

3. Cliquez sur **Importer des lignes d'un document.**
4. Choisissez le document dont vous souhaitez importer les lignes.
5. Cochez les lignes que vous souhaitez importer.
6. Cliquez sur "Insérer dans le document".

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/capture-decran-2025-08-05-a-15_neuc8c.png)

> Une fois les lignes importées, vous les retrouverez à la fin de votre document, vous aurez la possibilité de les modifier / déplacer

Importer les lignes d'un document depuis une ligne précise

1. Cliquez sur les "..." à droite d'une ligne présente sur votre document.
2. Cliquez sur "Insérer une ligne avant / après".
3. Choisissez **Depuis un document.**

![Insérer des lignes depuis une ligne précise](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/capture-decran-2025-08-05-a-16_c7tfhi.png)
