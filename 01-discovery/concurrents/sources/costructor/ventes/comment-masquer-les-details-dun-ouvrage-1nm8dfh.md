# Comment masquer les détails d'un ouvrage

#### Masquez les détails d'un ouvrage en un clic sur vos devis : préservez vos marges et simplifiez la présentation client

Pour masquer les détails d’un ouvrage, rendez-vous dans l’édition de votre document ou dans un document en brouillon.

Cliquez sur la roue dentée **"Options"** située à droite de l’écran.

![Options](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/capture-decran-2025-02-21-a-13_1wix19k.png)

Dans le menu qui s’affiche, cochez l’option **Masquer les détails des ouvrages**, aussi bien sur l’éditeur que sur le document.

![Masquer les détails des ouvrages](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/capture-decran-2025-02-21-a-13_11wa0q6.png)
