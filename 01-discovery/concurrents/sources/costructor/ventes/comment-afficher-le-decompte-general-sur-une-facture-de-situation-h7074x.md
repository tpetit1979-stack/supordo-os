# Comment afficher le décompte général sur une facture de situation ?

## Afficher le décompte général (DGD) sur une facture de situation

> ⚠️ Le devis doit être **finalisé** et **accepté** pour être facturé

1. Rendez-vous dans la section [Devis](https://app.costructor.co/quotes)
2. Sélectionnez le devis à facturer
3. Cliquez sur le bouton **Facturer**
4. Cliquez sur **Créer une facture de situation**
5. Dans le Menu à droite, cliquez sur **Options**
6. Activez l'option **Afficher le décompte général**

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/decompte1-1_tkm0lv.png)

> Pour afficher le décompte général par défaut sur vos prochaines factures, cliquez sur le bouton **définir comme valeurs par défaut** avant d'enregistrer

7. Validez en cliquant sur **Enregistrer**

> Le décompte général est indiqué sur votre document, vous pouvez le finaliser

> Vous pouvez visionner notre vidéo dédiée à l'affichage du décompte général
