# Comment récupérer une version antérieure d'un devis ?

Il peut arriver que vous ayez besoin de revenir sur une version précédente d’un devis, par exemple pour comparer les montants, vérifier des modifications ou restaurer une version validée par le client.
Costructor conserve automatiquement l’historique de vos devis afin de vous permettre de consulter et restaurer facilement les versions antérieures.

> Cette fonctionnalité est disponible avec les abonnements Business+ et Enterprise.

Récupérer une révision d'un devis

1. Cliquez sur le devis concerné.
2. Cliquez sur l’icône "x Révisions" qui se trouve à côté du numéro du devis.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_uvkrdl.jpg)

3. Choisissez la révision que vous souhaitez récupérer.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_iv71je.jpg)

> Vous pouvez accéder jusqu'aux dix dernières révisions de votre devis.

4. Cliquez sur l'icone ⿻ pour dupliquer la révision choisie.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_y4h1e1.jpg)

> Le devis dupliqué, portera un numéro différent que votre devis actuel.

Vous avez également la possibilité de consulter, imprimer ou télécharger une révision via les différents icones.
