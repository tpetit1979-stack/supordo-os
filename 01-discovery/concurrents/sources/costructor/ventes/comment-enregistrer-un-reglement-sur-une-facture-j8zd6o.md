# Comment enregistrer un règlement sur une facture ?

#### Enregistrez vos règlements rapidement : associez-les aux factures et relancez sereinement les impayés.

1. Via le menu principal, cliquez sur **Factures**.
2. Sélectionnez la facture sur laquelle vous voulez enregistrer un règlement.
3. Dans le menu à droite de votre facture, cliquez sur **Enregistrer un règlement**.

![Enregistrer un règlement](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/regler1_sovriu.png)

4. Remplissez maintenant les informations du règlement :

1. **Date**
2. **Mode de paiement**
3. **Montant**
4. **Note (facultatif)**

5. Une fois les informations saisies, cliquez sur **Enregistrer le règlement**.

![Informations du règlement](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/regler2_nszul7.png)

> Le règlement apparaîtra à gauche de votre facture ainsi que sur la facture avec la mention **Facture acquittée**

![](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/group-1_1u0htec.png)

![Règlement à gauche de la facture](https://storage.crisp.chat/users/helpdesk/website/89d563729eac1000/regler3_b41aim.png)

> Vous pouvez supprimer le règlement en cliquant sur l’icône **Supprimer** à droite de celui-ci.
