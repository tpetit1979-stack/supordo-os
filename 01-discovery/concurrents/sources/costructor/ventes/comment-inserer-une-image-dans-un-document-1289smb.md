# Comment insérer une image dans un document ?

#### Costructor vous permet d'insérer facilement des images dans vos lignes de devis & factures.

Cette fonctionnalité vous permet d'améliorer votre image de marque, de vous démarquer de la concurrence et d'augmenter le nombre de devis acceptés 🏆

Insérer une image dans un devis / facture

1. Créez ou modifiez un document
2. Cliquez sur une ligne du document, puis sur l'icone *Image* 📷
3. Choisissez une image depuis votre PC ou smartphone.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_vh0r3d.jpg)

4. Sélectionnez l'image que vous souhaitez insérer.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_6eeo61.jpg)

5. Définissez l'emplacement et la taille de votre image

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_wj5cdv.jpg)

> 💡 Vous pouvez ajouter une image à un produit directement depuis votre bibliothèque
