# Comment s'abonner à Costructor ?

Costructor propose 3 forfaits, adaptés à toutes les tailles d'entreprises.

## Abonnement à Costructor

1. Rendez-vous dans la section [Réglages](https://app.costructor.co/account/company/subscription)
2. Cliquez sur **Abonnement** > **Découvrir les abonnements**
3. Choisissez le **Paiement mensuel** ou **Paiement annuel** puis le forfait adapté à vos besoins
4. Choisissez votre moyen de paiement préféré puis complétez le formulaire
5. Bienvenue parmi nous !

> 💡 Tous les abonnements Costructor sont sans engagement.
