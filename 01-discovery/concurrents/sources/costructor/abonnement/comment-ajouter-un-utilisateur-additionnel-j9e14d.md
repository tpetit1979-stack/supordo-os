# Comment ajouter un utilisateur additionnel ?

#### Centralisez l’accès de vos collaborateurs grâce à l’ajout d’utilisateurs additionnels.

1. Rendez-vous dans les réglages de votre espace.
2. Cliquez sur abonnements/services complémentaires.
3. Cliquez sur augmenter le nombre d'utilisateurs.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_fr0q1l.jpg)

1. Choisissez le nombre d'utilisateurs dont vous avez besoin.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1meay0d.jpg)

> Les utilisateurs supplémentaires vous sont facturés 10 euros HT par mois ou 100 euros HT par an. Il est possible d'ajouter des utilisateurs supplémentaires à partir de la formule business+

> Si vous n'avez besoin que d'accès salariés (visualisation du planning / chantier pour l'abonnement business+ et visualisation du planning / pointage des heures pour la version premium) les accès salariés sont inclus dans votre abonnement, 2 accès pour l'abonnement business+ et illimité pour l'abonnement premium.
