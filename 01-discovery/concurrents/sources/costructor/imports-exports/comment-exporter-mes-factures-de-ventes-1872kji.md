# Comment exporter mes factures de ventes ?

## Vous pouvez exporter vos factures en un clic via Costructor, dans de nombreux formats.

#### Comment exporter mes factures de ventes ?

1. Cliquez sur **Factures** dans le menu à gauche.
2. Appliquez les filtres que vous souhaitez.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_go8bvq.jpg)

3. Cliquez sur **Exporter**.

![Bouton d'export](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_zilpao.jpg)

4. Choisissez le format : *CSV*, *XLSX* ou FEC.
5. Vous pouvez inclure les fichiers PDF en cochant la case.
6. Sélectionnez la période de votre choix.
7. Cochez inclure les avoirs (facultatif).
8. Cliquez sur **Exporter.**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1qqe3nb.jpg)

> L'export des factures est disponible dans les versions Pro , Business + et Premium du logiciel.

> L'export **Fichier des Ecritures Comptables** (FEC)  est disponible dans les versions Business + et Premium du logiciel.
