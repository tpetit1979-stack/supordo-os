# Comment importer une facture d'achat ?

## Les factures d’achats regroupent l’ensemble des dépenses engagées auprès de vos fournisseurs et prestataires.

####

Elles constituent une base essentielle pour suivre vos coûts, gérer votre trésorerie et préparer votre comptabilité.

#### Importer une facture d'achat

1. Cliquez sur **Factures d'achats** dans le menu principal.
2. Cliquez sur **+ Ajouter une facture** en haut à droite.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1sunh5t.jpg)

3. Glissez-déposez votre facture ou choisissez un fichier depuis votre ordinateur.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1esk56r.jpg)

> 💡 Vous pouvez également prendre un photo depuis votre smartphone avec l'[application mobile](https://support.costructor.co/fr/article/telecharger-lapplication-costructor-sur-mobile-s25hdg/).

![Exemple d'import d'une facture d'achat](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1a30kp2.jpg)

4. Sélectionnez le ou les chantiers (facultatif)
5. Sélectionnez la ou les catégories d'achats (facultatif)
6. Cliquez sur **Enregistrer**

> 💡 Les factures d'achats permettent de calculer la rentabilité réelle de vos chantiers et d'avoir une vue sur les dépenses par catégories.

#### Import par transfert de mail

Vous avez également la possibilité de transférer vos factures d'achat reçues par mail par transfert de mail.

1. Rendez vous dans l'onglet **factures d'achats**.
2. Cliquez sur ajouter une facture et copier le lien.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1lg426t.jpg)

3. Allez sur votre boite mail et cliquez sur transférer sur le mail reçu par votre fournisseur.
4. Renseignez l'adresse ci dessus dans l'adresse du destinataire.
5. Votre facture sera importée dans Costructor.
