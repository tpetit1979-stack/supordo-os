# Comment exporter mes factures d'achats ?

## Vous pouvez exporter vos factures d'achat en un clic via Costructor, dans de nombreux formats.

#### Comment exporter mes factures d'achat ?

1. Cliquez sur **Factures d'achat** dans le menu à gauche.
2. Appliquez les filtres souhaités.

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_11jofmh.jpg)

3. Cliquez sur le bouton d'export, à droite de **Ajouter une facture**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_1ft7m3s.jpg)

4. Choisissez le format : *CSV*, *XLSX *ou FEC.
5. Vous pouvez inclure les fichiers PDF en cochant la case.
6. Sélectionnez la période de votre choix.
7. Cliquez sur la case inclure les avoirs fournisseurs (facultatif).
8. Cliquez sur **Exporter.**

![](https://storage.crisp.chat/users/helpdesk/website/-/8/9/d/5/89d563729eac1000/sans-titre_muzyik.jpg)

> L'export des factures d'achat est disponible dans les versions **Business + et Premium **du logiciel.
