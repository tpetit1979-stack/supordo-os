## **Qu’est-ce qu’une facture électronique dans le BTP ?**

Les **exemples de factures électroniques dans le BTP** désignent des modèles de factures numériques utilisées par les artisans et entreprises du bâtiment pour facturer leurs prestations (main-d’œuvre, matériaux, sous-traitance). Une facture électronique n’est pas un simple PDF : c’est un document émis dans un format structuré (Factur-X, XML ou UBL) permettant un traitement automatisé par les logiciels comptables et les plateformes agréées. Dans le BTP, elle doit intégrer toutes les mentions légales (TVA, SIRET, détail du chantier, etc.) et s’inscrit dans la réforme française de [la facturation électronique](https://www.tolteck.com/fr-fr/facturation-electronique-dans-le-batiment-guide-pratique-pour-les-artisans/), qui impose progressivement l’échange via des Plateformes Agréées (PA) et un contrôle via le Portail Public de Facturation (PPF).

## **Quels formats de facture électronique sont utilisés dans le BTP ?**

Dans le secteur du bâtiment, les formats de facturation évoluent selon les obligations réglementaires et le niveau de digitalisation des entreprises.

### Les principaux formats utilisés

- PDF simple : encore très répandu mais non structuré
- Factur-X (hybride) : PDF lisible + données XML intégrées
- XML / UBL : format entièrement structuré
- EDI / CII : utilisé principalement par les grands donneurs d’ordre

### Pourquoi le Factur-X est privilégié dans le BTP ?

Le **template Factur-X BTP** est aujourd’hui le format le plus adapté aux artisans car :

- Il reste lisible comme une facture classique
- Il permet l’automatisation comptable
- Il est compatible avec les Plateformes Agréées (PA)
- Il facilite la transition vers la réforme

### Exemple concret

Un électricien peut générer une facture Factur-X après une intervention :

- Une version PDF pour le client
- Des données structurées pour le logiciel comptable
- Une transmission via une PA vers les systèmes de facturation

## **Quels sont des exemples concrets de factures électroniques dans le BTP ?**

### Exemple 1 : facture chantier artisan (cas standard)

Une **exemple facture chantier** comprend généralement :

- Identité de l’artisan (nom, SIRET, adresse)
- Identité du client
- Adresse du chantier
- Détail des prestations
- Montants HT, TVA, TTC
- Conditions de paiement

Exemple simplifié :

- Pose de carrelage : 1 200 € HT
- Fournitures : 400 € HT
- TVA 10 % : 160 €
- Total TTC : 1 760 €

Exemple 2 : facture avec TVA dans le BTP

Une **facture avec TVA BTP** doit détailler précisément les taux appliqués :

- TVA 20 % : travaux standards
- TVA 10 % : rénovation de logement
- TVA 5,5 % : travaux de rénovation énergétique

Elle doit afficher :

- Base HT par taux
- Montant de TVA par taux
- Total TTC global

Cette distinction est essentielle pour la conformité fiscale et les contrôles.

Exemple 3 : facture sous-traitant bâtiment

La [**facture sous-traitant bâtiment**](https://www.tolteck.com/fr-fr/facturation-electronique-et-sous-traitance-dans-le-btp-comment-se-preparer/) est fréquente sur les chantiers multi-entreprises. Elle inclut :

- Référence du chantier principal
- Nom de l’entreprise principale
- Nature des travaux réalisés
- Montant HT

Cas fréquent :

- Autoliquidation de TVA (facture émise en HT uniquement)
- Mention obligatoire de sous-traitance

## **Quelles sont les obligations de la facture électronique dans le BTP ?**

### Calendrier officiel de la réforme

- **1er septembre 2026**  - Toutes les entreprises doivent être capables de recevoir des factures électroniques (e-invoicing)
  - Les grandes entreprises et ETI doivent être capables d’émettre des factures électroniques et transmettre les données (e-reporting)
- **1er septembre 2027**  - Obligation d’émettre des factures électroniques pour toutes les entreprises (PME, TPE, micro-entreprises incluses)
  - Généralisation de l’e-reporting pour toutes les entreprises

### Rôle des plateformes dans la réforme

- Les factures doivent être transmises via une Plateforme Agréée (PA) ou un logiciel connecté à une PA
- Le Portail Public de Facturation (PPF) ne sert pas à envoyer des factures aux clients
  - Il reçoit et centralise les données
  - Il transmet les informations à l’administration fiscale
  - Il reçoit les factures B2G (d’une entreprise à un acteur public). C’est l’évolution de Chorus Pro.

### Impact concret pour les artisans du BTP

- Fin progressive des échanges par email non structurés
- Obligation d’utiliser des formats standardisés
- Traçabilité complète des factures
- Automatisation des échanges comptables

## **Comment créer une facture électronique conforme dans le BTP ?**

### Étapes à suivre

1. Identifier le client et le chantier
2. Décrire précisément les prestations
3. Appliquer les bons taux de TVA
4. Ajouter les mentions légales obligatoires
5. Générer un format conforme (Factur-X recommandé)
6. Transmettre via une Plateforme Agréée (PA) ou un logiciel connecté

### Mentions obligatoires

- **Mention “Facture”** (doit apparaître clairement sur le document)
- **Numéro de la facture** (numéro unique basé sur une séquence chronologique et continue)
- **Date d’émission** de la facture
- **Date de la vente** ou de la prestation de services
- **Identité du vendeur :** Dénomination sociale, adresse du siège social, SIREN ou SIRET, numéro RCS,  forme juridique et capital social
- **Identité du client :** Dénomination sociale (ou nom pour un particulier) et adresse de facturation
- **Numéro SIREN du client** (**Nouveauté Réforme** )
- **Adresse de livraison** (**Nouveauté Réforme** ) : Uniquement si elle est différente de l’adresse de facturation
- **Nature de l’opération** (**Nouveauté Réforme** ) : Préciser s’il s’agit d’une “Livraison de biens”, d’une “Prestation de services” ou d’une “Opération mixte”
- **Numéro de TVA intracommunautaire du vendeur** (et celui du client pour les opérations de commerce intracommunautaire ou d’autoliquidation)
- **Désignation des produits ou services :** Nom, quantité, prix unitaire HT et taux de TVA appliqué pour chaque ligne
- **Réductions de prix :** Rabais, remises ou ristournes acquis à la date de la vente
- **Total HT et Total TVA** (ventilés par taux si plusieurs taux s’appliquent)
- **Total TTC** (Somme totale à payer)
- **Date ou délai de paiement :** Date limite à laquelle le règlement doit intervenir
- **Taux des pénalités de retard :** Exigibles en cas de non-paiement à la date d’échéance.
- **Indemnité forfaitaire:** Pour frais de recouvrement en cas de retard de paiement (concerne uniquement les professionnels)
- **Option pour le paiement de la TVA sur les débits** (**Nouveauté Réforme** ) : À mentionner si vous avez opté pour ce régime fiscal spécifique
- **Mentions d’exonération ou d’autoliquidation :** Si applicable (ex: “TVA non applicable, art. 293 B du CGI” pour les micro-entrepreneurs ou “Autoliquidation” si le client est redevable de la taxe)

Il est possible de retrouver toutes les mentions obligatoires sur le site gouvernemental : [https://entreprendre.service-public.gouv.fr/vosdroits/F31808](https://entreprendre.service-public.gouv.fr/vosdroits/F31808)

## **FAQ : exemples de factures électroniques dans le BTP**

### Qu’est-ce qu’un exemple de facture électronique dans le BTP ?

C’est un modèle de facture numérique structurée utilisé pour les travaux du bâtiment.

Elle contient les données du chantier, les montants et la TVA.

Elle peut être au format Factur-X ou XML.

### Un PDF est-il une facture électronique conforme ?

Non, un PDF seul n’est pas suffisant.

Il doit être enrichi de données structurées pour répondre aux exigences de la réforme.

Le Factur-X est le format recommandé.

### Comment fonctionne une facture de sous-traitance ?

Elle décrit les travaux réalisés pour une entreprise principale.

Elle peut être soumise à l’autoliquidation de TVA.

Elle doit mentionner clairement le chantier et le donneur d’ordre.

### Quand la facture électronique devient-elle obligatoire ?

- 1er septembre 2026 : réception obligatoire pour toutes les entreprises
- 1er septembre 2027 : émission obligatoire pour toutes les entreprises
Ces obligations concernent progressivement tous les artisans du BTP.

### Le PPF permet-il d’envoyer des factures ?

Non. Le PPF ne sert pas à émettre les factures.

Il centralise et transmet les données à l’administration fiscale.

L’émission passe par une Plateforme Agréée (PA) ou un logiciel connecté.
