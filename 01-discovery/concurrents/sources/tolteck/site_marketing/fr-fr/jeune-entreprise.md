# Offre exclusive pour les jeunes entreprises

######  Chez Tolteck, nous avons à coeur d’aider les artisans qui lancent leur entreprise.
C’est pourquoi nous proposons une offre promotionelle pour les entreprises ayant moins de 5 ans.


### Profiter de l’offre

Pour profiter de l’offre Jeune entreprise, veuillez télécharger votre Kbis (format pdf ou en photo) ci-dessous.


*Si ce n’est pas possible pour vous, envoyez votre K-Bis par mail à support@tolteck.com.*

- 35% de réduction sur la première année d’abonnement à Tolteck (149€ HT au lieu de 228€ HT), soit l’équivalent de 12,50€HT/mois pendant la première année.
- Offre valable uniquement pour les entreprises de moins de 5 ans, uniquement sur un abonnement annuel à Tolteck.
- Le programme de parrainage est également disponible avec cette offre (plus de détails sur le programme de parrainage [ici](https://www.tolteck.com/fr-fr/parrainage/) )

### Et après ?

Une fois votre Kbis envoyé et validé par nos équipes, vous recevez par mail un code unique et personnel à rentrer lors du paiement.

			
1/ Rendez-vous sur la page [https://tolteck.app/company/subscription/plans](https://tolteck.app/company/subscription/plans?gaClientId=249693469.1525250276)

2/ Cliquez sur “Je bénéficie d’un code de réduction ou de parrainage…”

3/ Inscrivez le code reçu par mail

Votre offre s’applique, suivez la procédure de paiement.
