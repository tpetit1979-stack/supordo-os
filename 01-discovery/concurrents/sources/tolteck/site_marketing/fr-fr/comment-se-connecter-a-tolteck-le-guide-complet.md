## **Où se connecter à Tolteck ?**

Tolteck est une application 100% en ligne (qui fonctionne avec ou sans connexion à Internet), accessible depuis :

- Un navigateur, à l’adresse **tolteck.app**
- Des raccourcis sur votre PC, Mac, téléphone et tablette
- L’application mobile Tolteck (Android), disponible sur le Playstore
- Le bouton “Connexion” présent sur toutes les pages du site tolteck.com

Aucune installation logicielle n’est nécessaire : vos devis, factures et données client sont accessibles depuis n’importe quel appareil.

## 
**Mot de passe oublié : comment le réinitialiser**

Mot de passe oublié : comment le réinitialiser

Si vous ne vous souvenez plus de votre mot de passe :

1. Sur la page de connexion, cliquez sur **“Mot de passe oublié”**
2. Saisissez l’adresse email associée à votre compte Tolteck
3. Vous recevez un email de réinitialisation sous quelques minutes (pensez à vérifier vos spams / courriers indésirables)
4. Cliquez sur le lien reçu et définissez un nouveau mot de passe

**Le lien n’arrive pas ?** Vérifiez que l’adresse saisie est bien celle utilisée à la création du compte. Si vous avez plusieurs adresses email professionnelles, essayez chacune d’elles. Si le problème persiste, contactez le support Tolteck au 01 76 44 05 14. 

## 
**Changer l’adresse email de connexion**

Changer l’adresse email de connexion

Vous avez changé d’adresse professionnelle ou souhaitez utiliser un autre email pour vous connecter :

1. Connectez-vous à votre compte Tolteck
2. Cliquez sur votre profil (en haut à droite) → **“Mes informations”**
3. Cliquez sur **“Ajouter”** dans la partie liée à l’email
4. Renseignez la nouvelle adresse email souhaitée
5. Un code de sécurité est envoyé à votre adresse email actuelle : renseignez-le pour valider le changement

Vous recevez ensuite un email vous invitant à rejoindre le compte de l’entreprise avec votre nouvelle adresse. **Vous conservez toujours la possibilité de vous connecter avec votre adresse email d’origine.**

💡 Si vous avez déjà créé un autre compte Tolteck avec votre nouvelle adresse email, continuez à utiliser ce compte ou contactez le support avant de modifier votre adresse de connexion.

👉 Le détail de la procédure est disponible dans notre [centre d’aide](http://help.tolteck.com/fr/articles/4100908-comment-modifier-mon-adresse-email-de-connexion).

## 
**Gérer plusieurs utilisateurs sur un même compte Tolteck**

Si votre entreprise compte plusieurs collaborateurs (conducteurs de travaux, commerciaux, comptable), chacun peut disposer de son propre accès avec ses propres identifiants et droits.

### Ajouter un utilisateur

1. Cliquez sur votre profil (en haut à droite) → **“Utilisateurs”**
2. Cliquez sur **“Ajouter un utilisateur”**
3. Renseignez ses informations et définissez son niveau d’accès
4. Validez : l’utilisateur reçoit un email d’invitation pour rejoindre votre compte

### Les niveaux d’accès disponibles :

- **Propriétaire du compte** : accès complet, y compris la gestion des utilisateurs
- **Lecture et modification** : accès complet aux fonctionnalités, sans gestion des utilisateurs
- **Lecture seule** : consultation des données, téléchargement des factures et export financier, sans création ni modification

### Supprimer un utilisateur

1. Cliquez sur votre profil → **“Utilisateurs”**
2. Cliquez sur les droits attribués à l’adresse email concernée
3. Sélectionnez **“Révoquer l’accès”**

👉 Le détail de la procédure est disponible dans notre [centre d’aide](http://help.tolteck.com/fr/articles/15773243-comment-ajouter-ou-supprimer-un-utilisateur-de-mon-compte).

## 
**Tolteck ne se connecte pas : les causes les plus fréquentes**

Si la page de connexion ne répond pas, voici les vérifications à effectuer dans l’ordre :

1.  **Vérifier votre connexion internet** Assurez-vous qu’elle fonctionne correctement en ouvrant un autre site internet, en particulier sur chantier avec une couverture réseau faible.
2.  **Vérifier votre navigateur** Certains paramètres du navigateur peuvent bloquer la connexion à Tolteck :

- Évitez la navigation privée
- Videz le cache de votre navigateur
- Essayez un autre navigateur (Google Chrome, Mozilla Firefox)

1.  **Le problème persiste ?** Contactez l’équipe support Tolteck pour identifier l’origine exacte du problème.

💡 Vous recevez un code d’authentification qui ne fonctionne pas, ou vous ne le recevez pas ? Consultez l’article dédié aux [problèmes de code d’authentification](http://help.tolteck.com/fr/articles/10651400-que-faire-en-cas-de-probleme-avec-mon-code-d-authentification).

👉 Le détail de ces vérifications est disponible dans notre [centre d’aide](http://help.tolteck.com/fr/articles/2266373-pourquoi-je-n-arrive-pas-a-me-connecter-a-tolteck).
