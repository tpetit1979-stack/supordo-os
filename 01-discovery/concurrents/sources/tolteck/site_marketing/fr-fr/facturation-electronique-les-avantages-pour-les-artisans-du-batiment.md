## **Qu’est-ce que la facturation électronique pour un artisan ?**

[La facturation électronique](https://www.tolteck.com/fr-fr/pourquoi-passer-a-la-facturation-electronique/) (e-invoicing) consiste à émettre, transmettre et recevoir des factures dans un format structuré, via une plateforme sécurisée reconnue par l’administration fiscale. À ne pas confondre avec :

- une facture PDF envoyée par email
- une facture papier numérisée

Une vraie facture électronique doit :

- être au format structuré (Factur-X, UBL, CII)
- transiter par une Plateforme Agréée (PA) ou un logiciel connecté
- permettre une lecture automatique

Objectifs :

1. Automatiser les échanges entre entreprises
2. Réduire la fraude à la TVA
3. Simplifier [les obligations administratives](https://www.tolteck.com/fr-fr/obligations-legales-de-facturation-dans-le-btp-le-guide-pratique-pour-les-artisans/)

## **Quel est le calendrier officiel à respecter ?**

Voici les dates clés à connaître :

### 1er septembre 2026

- Toutes les entreprises doivent être capables de recevoir des factures électroniques
- Les grandes entreprises et ETI doivent :
  - émettre leurs factures électroniques
  - transmettre leurs données (e-reporting)

### 1er septembre 2027

- Toutes les entreprises (PME, TPE, micro-entreprises) doivent :
  - émettre leurs factures électroniques
  - réaliser leur e-reporting

Concrètement pour les artisans : vous devrez être totalement opérationnel en 2027, avec une obligation de réception dès 2026. Point essentiel :

- Vous ne pouvez pas envoyer vos factures via le PPF
- Seules les Plateformes Agréées (PA) ou les logiciels connectés peuvent transmettre les factures
- Le PPF sert uniquement à transmettre les données à l’administration fiscale

## **FAQ**

### Une facture PDF est-elle conforme ?

Non. Une facture PDF simple n’est pas une facture électronique conforme.

### Est-ce obligatoire pour les artisans ?

Oui, à partir du 1er septembre 2027 pour l’émission.

### Peut-on envoyer des factures via le PPF ?

Non. Le PPF ne permet pas l’émission.

### Faut-il changer de logiciel ?

Non, si votre logiciel est compatible avec la réforme.

### Quand faut-il s’y mettre ?

Dès maintenant, avec une obligation de réception en 2026.
