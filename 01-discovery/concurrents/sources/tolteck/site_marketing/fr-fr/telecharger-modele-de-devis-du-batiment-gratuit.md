## **Quelles sont les informations de base à intégrer dans un devis bâtiment ?**

Les informations de base sont indispensables pour garantir la traçabilité et la conformité du devis.

1. Vos coordonnées complètes: Assurez-vous d’inclure votre nom ou le nom de votre entreprise tel qu’il apparaît légalement.
Entrez le nom de votre entreprise, votre adresse, votre adresse e-mail, numéro de téléphone ou site web.
2. Numéro de devis: Chaque devis doit avoir un numéro unique pour la référence et la traçabilité.
 La date d’émission du devis: Indispensable pour la traçabilité. Indiquez le numéro de devis. La date du devis se met automatiquement au jour où vous utilisez le modèle, mais vous pouvez la modifier.
Date d’échéance: La date à laquelle le devis est valable.
3. Informations sur le client: indiquez clairement les coordonnées du client pour lequel vous émettez le devis. Cela comprend:
  - Nom du client: Assurez-vous d’écrire correctement le nom complet du client.
  - Adresse de facturation: L’adresse où le client souhaite recevoir le devis.
  - Coordonnées de contact: Numéros de téléphone, adresse e-mail, etc.
4. Si l’adresse du projet est différente, vous pouvez la modifier ici.
5. Donnez un titre à votre devis.

Vous pouvez ajouter votre logo pour une présentation professionnelle et personnalisée.
