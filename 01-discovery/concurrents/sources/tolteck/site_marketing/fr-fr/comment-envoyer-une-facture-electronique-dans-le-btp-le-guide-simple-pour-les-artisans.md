Envoyer une facture électronique dans le BTP consiste à **créer une facture dans un format structuré (comme Factur-X), puis la transmettre via une Plateforme Agréée (PA)** ou un logiciel connecté. Contrairement à une idée reçue, **il ne s’agit pas d’un simple PDF envoyé par email**.

À partir du **1er septembre 2026**, toutes les entreprises devront être capables de **recevoir des factures électroniques**, et à partir du **1er septembre 2027**, toutes devront également **les émettre**.

Bonne nouvelle : avec les bons outils, cette transition est simple à mettre en place et permet même de **gagner du temps au quotidien**. Voici tout ce que vous devez savoir, étape par étape.

## **Qu’est-ce qu’une facture électronique dans le BTP (et ce que ce n’est pas) ?**

Une [facture électronique](https://www.tolteck.com/fr-fr/facturation-electronique-dans-le-batiment-guide-pratique-pour-les-artisans/) est une facture **émise, transmise et reçue dans un format structuré**, permettant un traitement automatique par les systèmes informatiques. Concrètement :

- Un PDF envoyé par email = **pas une facture électronique**
- Une facture au format structuré (ou mixte) envoyée via une plateforme agréée = **oui**

### Pourquoi cette réforme ?

Dans le secteur du bâtiment, cette évolution vise à :

- Lutter contre la fraude à la TVA
- Automatiser les contrôles fiscaux
- Simplifier les échanges entre professionnels

### Le rôle des plateformes (point essentiel)

- Les factures passent **obligatoirement par une Plateforme Agréée (PA)** ou un logiciel connecté
- Le **Portail Public de Facturation (PPF)** :
  - n’envoie pas directement les factures
  - reçoit et transmet les données à l’administration fiscale

## **Comment envoyer une facture électronique dans le BTP étape par étape ?**

La procédure est en réalité simple si elle est bien comprise.

### 1. Créer une facture conforme

Les mentions restent les mêmes qu’aujourd’hui :

- Coordonnées de l’entreprise et du client
- Description des travaux
- Montants HT / TVA / TTC
- Conditions de paiement

Spécificités BTP à ne pas oublier :

- TVA sur encaissement
- Acomptes
- Retenue de garantie
- Situations de travaux

### 2. Générer la facture au bon format

La facture doit être produite dans un format accepté :

- Format structuré (UBL, CII)
- Format mixte **Factur-X** (le plus simple)

Factur-X = un PDF lisible + des données intégrées invisibles

### 3. Transmettre via une Plateforme Agréée

- La facture est envoyée automatiquement via une **PA**
- Elle est ensuite :
  - transmise au client
  - et ses données envoyées à l’administration

L’artisan n’envoie plus directement la facture lui-même.

### 4. Suivre le statut de la facture

Vous pouvez suivre :

- Envoyée
- Reçue
- Rejetée
- Payée

## **Quand la facturation électronique devient-elle obligatoire ?**

Voici le calendrier officiel à connaître absolument :

### 1er septembre 2026

- Toutes les entreprises doivent **recevoir des factures électroniques**
- Les grandes entreprises et ETI doivent **émettre leurs factures électroniques**

### 1er septembre 2027

- Toutes les entreprises (TPE, PME, micro-entreprises) doivent :
  - **émettre des factures électroniques**
  - **transmettre leurs données (e-reporting)**

Pour les artisans : **mieux vaut anticiper dès maintenant.**
