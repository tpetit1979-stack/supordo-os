# Mot clé :pas d’impression

## [Si vous n’arrivez pas à imprimer](https://servicescompris.extrabat.com/si-vous-narrivez-pas-imprimer/)

	
Il vous faut ouvrir le Menu de Firefox (3 barres verticales à droites), puis dans ***Modules*** aller sur ***Préférences ou Extensions de « JS Print Setup »*** et Sélectionner: **Enable Access from all sites.**

Vous pouvez à ce moment là refaire une tentative d’impression.
