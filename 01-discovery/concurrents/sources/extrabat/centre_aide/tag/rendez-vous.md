# Mot clé :rendez-vous

## [Connaître les statistiques des rendez-vous](https://servicescompris.extrabat.com/connaitre-les-statistiques-des-rendez_vous/)

	
Pour connaître les statistiques de vos rendez-vous commerciaux, vous devez :

– Cliquer sur le [, puis sur le la bulle « Statistiques »](https://servicescompris.extrabat.com/content/uploads/sites/5/2022/06/3.jpg) [, et si vous cliquez sur « Statistiques RDV », apparaitra directement les graphiques puis le tableau récapitulatif de vos rendez-vous.](https://servicescompris.extrabat.com/content/uploads/sites/5/2013/05/2.jpg)

Vous pouvez faire une sélection :

– par utilisateurs,

– par type de rendez-vous

– par année.
