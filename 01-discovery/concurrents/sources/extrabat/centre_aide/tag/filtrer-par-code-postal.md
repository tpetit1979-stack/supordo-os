Sur la liste des sav ou des contrats de services (bulle téléphone rouge ou bulle camionnette), vous pouvez filtrer par code postal (par deux chiffres ou 5 chiffres)

Il vous suffit juste de rentrer le code postal (16 ou 16000 par exemple) et cela filtre automatiquement tous vos sav ou contrats de services
