Sur votre profil, en cliquant en haut à droite sur la roue crantée, vous pouvez :

- Activer le module ou non de « Saisie des temps »,
- Activer ou non le module C Fluide,
- Si vous avez cocher Oui pour le module C Fluide, il faudra demander à C Fluide votre API Token que vous renseignerez dans le champ dédié et nous vous recommandons de cocher « Document visible par le client » ainsi que de « conserver les cookies C Fluide », ce qui vous évitera de saisir systématiquement votre identifiant et mot de passe,
- Personnaliser votre signature pour le bouton « Je pars » si vous ne voulez pas signer en votre nom mais plutôt de celui de votre société,
- Activer par défaut pour les photos prises avec Today, Visible par le client, coordonnées GPS ainsi qu’une résolution type « basse résolution » pour une synchronisation plus rapide dans le porte doc du client,
- Activer par défaut ou non, les questions métiers de la fiche sanitaire pour le métier Piscine
