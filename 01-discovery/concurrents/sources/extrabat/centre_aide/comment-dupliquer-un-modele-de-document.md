Vous pouvez dupliquer les modèles d’impression personnalisés du générateur de document.

Pour cela, il vous faut aller sur le  [puis la bulle « paramètres »](https://servicescompris.extrabat.com/content/uploads/sites/5/2013/05/1-1.jpg)  [=> Module modèle de document => générateur modèle de document.](https://servicescompris.extrabat.com/content/uploads/sites/5/2022/06/4.jpg)


Cliquez sur l’icône « Dupliquer » pour dupliquer votre modèle.
