#### **Une fonctionnalité conçue pour nos réseaux.**

Pour satisfaire les besoins spécifiques des réseaux, il est possible de spécifier une adresse de facturation par défaut sur les pièces de type fournisseur (commandes fournisseur, bons de réception…).

#### **Répondre aux besoins spécifiques de nos clients.**

Pouvoir renseigner et définir une adresse de facturation qui sera ensuite reprise automatiquement par défaut à l’édition et impression de l’ensemble de vos pièces commerciales de type fournisseur (commande fournisseur, facture d’achat…).

 

#### **Comment attribuer une adresse par défaut pour les pièces type fournisseur ?**





1. Rendez-vous sur la page : [Coordonnées & Infos générales](https://www.myextrabat.com/parametres/coordonnees)
2. Aller à la section “Adresses”.
3. Définir, dans un premier temps, votre “adresse principale”, correspondant à l’adresse de référence de votre structure/entité. Celle-ci sera reprise à l’édition de vos pièces commerciales type client (devis, factures…).
4. Définir ensuite, une adresse par défaut pour vos pièces type fournisseur, en sélectionnant “Fournisseur” pour l’attribuer.
5. Vos adresses sont désormais définies !

## 💡 Astuce

Vous avez la possibilité de renseigner une adresse différente, directement depuis la page d’édition de votre pièce commerciale.
