# Proposez l’avance immédiate avec Axonaut

Vous êtes une société de prestation de service ? L’URSSAF propose un service en ligne gratuit qui permet aux particuliers de déduire le montant du crédit d’impôt lors de la facturation : c’est l’avance immédiate ou API tiers de prestation. Pour votre client, il n’aura plus besoin d’attendre pour bénéficier de son crédit d’impôt. Grâce à la connexion URSSAF/Axonaut, votre entreprise profite également de plusieurs avantages :

- Automatisez la gestion de votre facturation.
- Créez des factures conformes en quelques clics.
- Recevez les paiements plus rapidement et diminuez les risques d’impayés.

Découvrez comment activer la connexion en quelques étapes !

## Les premières étapes

![](https://blog.axonaut.com/support/wp-content/uploads/2024/05/image-19-1024x483.png)

1. Rendez-vous dans la clé à molette à haut à droite, Marketplace et avance immédiate.
2. Cliquez sur « c’est parti » dans paramétrez la connexion.
3. Renseignez ici : le client ID, Client Secret, le numéro SAP et le nom du tiers de facturation. Ces identifiants sont donnés par l’URSSAF lorsque vous en faites la demande pour utiliser l’API tiers de prestation.

## La fiche client

![](https://blog.axonaut.com/support/wp-content/uploads/2024/05/image-20.png)

Une fois que la configuration est validée, rendez-vous sur la [fiche d’un client](https://support.axonaut.com/optimisez-gestion-commerciale/la-fiche-client-axonaut/) **particulier**.

1. Vous pourrez modifier la fiche client et retrouver un champ « API tiers de prestation ».
2. Remplissez l’ensemble des informations pour avoir accès au service. Vous aurez ensuite un message de confirmation :

![](https://blog.axonaut.com/support/wp-content/uploads/2024/05/image-21.png)

💡 Vous verrez ces informations uniquement sur la fiche d’un client particulier !

## La facturation

1. [Créez la facture](https://support.axonaut.com/gerez-vos-factures/creer-une-facture-avec-axonaut/) et vous retrouverez une nouvelle option dans l’envoi de la facture :

![](https://blog.axonaut.com/support/wp-content/uploads/2024/05/image-22.png)

2. Vous devrez sélectionner un type pour les prestations ainsi que les dates d’emploi (**cette date devra être dans le futur**) :

![](https://blog.axonaut.com/support/wp-content/uploads/2024/05/image-23.png)

3. Vous pourrez visualiser le statut également en cliquant sur l’avion bleu :

![](https://blog.axonaut.com/support/wp-content/uploads/2024/05/image-24.png)

Dans un premier temps, vous verrez un statut « intégré », cela signifie que la demande a été transmise à l’URSSAF et qu’une confirmation est en cours.

Pour vérifier le statut, vous devrez cliquer sur les flèches. Vous serez ainsi prévenu si la demande est confirmée ou si des modifications doivent être effectuées.

Si vous avez des questions, n’hésitez pas à nous contacter sur votre compte via la bulle bleue en bas de votre écran !
