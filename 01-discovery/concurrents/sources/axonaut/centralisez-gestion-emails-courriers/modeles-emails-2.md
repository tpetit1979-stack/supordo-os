# Comment gérer les modèles dans Axonaut ?

Axonaut est votre outil pour gagner du temps dans la gestion de votre entreprise. Pour cela nous mettons en place des actions automatisées comme les modèles de documents, d’emails, de signature, de tâches. Voici comment gérer les modèles dans Axonaut !

Pour accéder à la configuration des modèles sur votre compte, il vous suffit de cliquer sur l’adresse suivante : [https://axonaut.com/account/config/templates](https://axonaut.com/account/config/templates)

## Les modèles possibles dans Axonaut

- La liste de tâches :

Pour créer vos listes de tâches, rendez-vous sur l’adresse suivante : [https://axonaut.com/account/taskList/list](https://axonaut.com/account/taskList/list)

Cela vous permettra de catégoriser chacun de vos projets et de vos tâches pour mieux les retrouver.

- Les commentaires :

Il est possible de configurer vos commentaires à partir de cette interface : [https://axonaut.com/account/comment/list](https://axonaut.com/account/comment/list)

Sur chaque fiche client, vous pouvez sélectionner en un clic un modèle de commentaire pour donner des indications sur vos prospects, clients ou fournisseurs.

- Les modèles d’emails et courriers :

Comment vous le savez, il est possible d’envoyer des emails et des courriers depuis votre compte Axonaut. Pour les configurer en amont, c’est via cette interface : [https://axonaut.com/account/emailTemplate/list](https://axonaut.com/account/emailTemplate/list)

Vous pouvez ainsi gagner du temps sur l’édition de vos emails et courriers au quotidien.

- Modèles d’envois/relances pour les factures :

Afin de gagner du temps dans l’envoi et la relance de vos factures, il est possible de configurer les emails/textes à partir de cette interface : [https://axonaut.com/manager/invoiceSendText](https://axonaut.com/manager/invoiceSendText)

Chaque relance est ainsi envoyée automatiquement avec le texte de votre choix.

- Texte d’envoi pour les devis :

Comme pour les factures, il est possible de configurer votre texte d’envoi via cette adresse : [https://axonaut.com/manager/quotationSendText](https://axonaut.com/manager/quotationSendText)

- Configurer votre signature mail :

Comme indiqué, vous pouvez envoyer des emails depuis Axonaut. Vous pouvez donc configurer votre signature et celles de collègues via l’interface de synchro emails.
