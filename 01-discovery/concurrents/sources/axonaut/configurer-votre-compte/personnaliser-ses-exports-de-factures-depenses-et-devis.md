# Personnaliser ses exports de factures, dépenses et devis

Dans la gestion quotidienne d’une entreprise, disposer d’exports de données bien structurés et configurés est essentiel. Que ce soit pour faire des analyses, des statistiques, les transmettre à un comptable, ou intégrer dans d’autres outils, le format et le contenu de vos exports comptent. Axonaut propose des options de personnalisation des exports de **factures**, **devis** et **dépenses**, pour vous permettre d’exporter uniquement les champs qui vous intéressent, dans un format exploitable (CSV). Découvrons comment personnaliser ces exports pas à pas ! 🙂

## L’export personnalisé

Contrairement à l’export “comptable pur” souvent réservé aux portails dédiés, Axonaut permet dans son interface utilisateur de **paramétrer les exports** pour vos besoins analytiques ou de reporting.

La logique est simple : vous choisissez, pour vos factures, devis ou dépenses, les champs (colonnes) que vous souhaitez voir dans votre fichier d’export. Ensuite, quand vous lancez l’export, le fichier généré (souvent un CSV) n’inclura que ces champs sélectionnés — ce qui rend les données plus lisibles et plus utiles pour les usages que vous visez.

## Personnaliser ses exports de factures

Tout d’abord, rendez vous dans Devis & Factures > Factures et le bouton exporter les recettes, Personnalisation des exports et le bouton “Factures” :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-72-7.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-72-7.png)

Vous pouvez choisir les champs que vous souhaitez voir apparaître parmi les choix disponibles dans le menu déroulant :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-66-5.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-66-5.png)

Une fois validé, il vous suffira de revenir dans le même onglet et de cliquer sur “Exporter les recettes” et Export des factures pour avoir votre fichier CSV.

## Personnaliser ses exports de lignes de facture**s**

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-72-7.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-72-7.png)

Vous pouvez choisir les champs que vous souhaitez voir apparaître parmi les choix disponibles dans le menu déroulant :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-66-5.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-66-5.png)

Une fois validé, il vous suffira de revenir dans Devis & Factures, Factures et de cliquer sur “Exporter les recettes” et Export des lignes de factures pour avoir votre fichier CSV.
