# Fabrications : comment ça marche ?

1- Rendez vous dans Gestion de stock, Etat des stocks :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-8-2.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-8-2.png)

2- Modifier un produit à l’aide du stylo bleu :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-66-3.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-66-3.png)

3- Dans le produit, déclarez que c’est un produit fini dans le type :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-79-2.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-79-2.png)

4- En bas de votre écran, vous verrez la partie “Produits qui composent ce produit”. Vous pourrez ajouter des matières premières qui composent ce produit. Lors de la vente du produit fini, cela va permettre de décrémenter également le stock de ces matières premières. Lorsque vous fabriquez un produit, le stock des matières premières baissera tandis que le stock du produit fini augmentera.

En revanche, pour information, seul le produit fini apparaîtra sur la facture :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-94-6.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-94-6.png)

5- Dans le menu “Fabrications” et dans le champ “Nom du produit”, sélectionnez le produit en question :

![](https://blog.axonaut.com/support/wp-content/uploads/2023/10/image-32-12.png)

6- Une fois fait, vous pouvez voir l’historique de vos fabrications dans le tableau en dessous :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-70-5.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-70-5.png)

Pour toutes questions supplémentaires, n’hésitez pas à revenir vers nous via l’Axobot en bas à droite 😉
