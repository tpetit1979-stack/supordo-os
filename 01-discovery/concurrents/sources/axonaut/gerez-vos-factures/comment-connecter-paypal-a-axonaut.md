# Comment connecter Paypal à Axonaut ?

Vous souhaitez être accompagné(e) dans la connexion de votre compte PayPal à Axonaut ? Nous sommes là pour ça !

Grâce à cette connexion, vous allez pouvoir autoriser le paiement des factures et devis par PayPal, directement depuis Axonaut.

Alors, comment tout ça fonctionne concrètement ? Nous vous proposons un accompagnement point par point, qui ne devrait pas vous prendre plus de 5 minutes.

## 1) Connexion à votre compte Paypal

Pour pouvoir utiliser PayPal au sein d’Axonaut, il vous faudra vous rendre sur le site suivant :

https://developer.paypal.com/developer/applications.

D’abord, connectez-vous sur le dashboard avec le compte PayPal que vous souhaitez associer :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/4KTyX1fBMMH9A-1SR7oUCQxqrX2RylWH2QK1cVTuFrOxFLUmIcHorNLCk8Ioa_uHOLinU3YhYOe1Fx_7y7ojsKFQmvfeDB7zd5bpEO3dycJTx2GqKhAfJkF3sbOIpFHJO5dyOxjZ-16.jpg)](https://support.axonaut.com/wp-content/uploads/2023/10/4KTyX1fBMMH9A-1SR7oUCQxqrX2RylWH2QK1cVTuFrOxFLUmIcHorNLCk8Ioa_uHOLinU3YhYOe1Fx_7y7ojsKFQmvfeDB7zd5bpEO3dycJTx2GqKhAfJkF3sbOIpFHJO5dyOxjZ-16.jpg)

Cliquez ensuite sur l’onglet “Live” en dessous de “My apps & credentials”.

Ensuite, cliquez sur “Create App”.

## 2. Configurer l’application à connecter à Paypal

Désormais, vous pouvez configurer l’application que vous venez de créer.

[![](https://support.axonaut.com/wp-content/uploads/2023/10/yMOZ2ej-rRRGHuCsh8EP9dUN6iLK3iAzjFatgWjuBr9mo66r2cpDZ_1DcUyjcAX2KYNLvuEi3WPlfGaSj3e2IipsE6pQXGJa-DG5B62WpMNhwC-cXhQa-ZkTayiwMLXr9vKdO3Ka-34.jpg)](https://support.axonaut.com/wp-content/uploads/2023/10/yMOZ2ej-rRRGHuCsh8EP9dUN6iLK3iAzjFatgWjuBr9mo66r2cpDZ_1DcUyjcAX2KYNLvuEi3WPlfGaSj3e2IipsE6pQXGJa-DG5B62WpMNhwC-cXhQa-ZkTayiwMLXr9vKdO3Ka-34.jpg)

Dans le champ “App name”, insérez le nom de votre société. C’est ce nom que verra le client lorsqu’il effectuera des paiements.

Une fois ce champ validé, vous allez voir les champs “Client ID” et “Secret” que vous devrez ensuite renseigner sur Axonaut.

[![](https://support.axonaut.com/wp-content/uploads/2023/10/9IDlcd0-FivDjk18mj2WUGhB_DeY922gOlyjyOQhNaJFIZJrBFmekyxYcc1s67Tkp0CbIpJUMknTy0rKIQGFot9Y_VX5k8i2qQyyP3v4dNdi1VC58cs5c7j9vbGTnQWFtZeCW0C7-42.jpg)](https://support.axonaut.com/wp-content/uploads/2023/10/9IDlcd0-FivDjk18mj2WUGhB_DeY922gOlyjyOQhNaJFIZJrBFmekyxYcc1s67Tkp0CbIpJUMknTy0rKIQGFot9Y_VX5k8i2qQyyP3v4dNdi1VC58cs5c7j9vbGTnQWFtZeCW0C7-42.jpg)

[![](https://support.axonaut.com/wp-content/uploads/2023/10/1Qd9XxcXqQvIggoRUzdCoHJ8cFSgzlhLxh1aVAzJAoIlq2NNz1Ug13dsuOyNvdBOQ8qnkRoua1Oqbny7xNBv3ME4bMbpUaSGQ3RJZriymB-nUClRonJMR7L9kz743-Pr1Wvyv18e-20.jpg)](https://support.axonaut.com/wp-content/uploads/2023/10/1Qd9XxcXqQvIggoRUzdCoHJ8cFSgzlhLxh1aVAzJAoIlq2NNz1Ug13dsuOyNvdBOQ8qnkRoua1Oqbny7xNBv3ME4bMbpUaSGQ3RJZriymB-nUClRonJMR7L9kz743-Pr1Wvyv18e-20.jpg)

## 3. Configurer les paramètres

Maintenant, vérifiez les paramètres (“settings”) de votre compte, et corrigez-les si nécessaire.

[![](https://support.axonaut.com/wp-content/uploads/2023/10/eFCT5NY6-luDn7mxDrBxxG_4gJzsc4H55_i8F4gMhokhkObnuM2AJjYCCUjHdTIY-eUnq7n8NjJAXlnsm0L_GeEKELitZQ2hB2gkuIVcIZRRTZ0Uta2KPagmeYxasDaV6BbZcOxZ-1.jpg)](https://support.axonaut.com/wp-content/uploads/2023/10/eFCT5NY6-luDn7mxDrBxxG_4gJzsc4H55_i8F4gMhokhkObnuM2AJjYCCUjHdTIY-eUnq7n8NjJAXlnsm0L_GeEKELitZQ2hB2gkuIVcIZRRTZ0Uta2KPagmeYxasDaV6BbZcOxZ-1.jpg)

## 4. Insérez les identifiants

- Récupérez votre client ID et votre code secret. Pour cela, rendez-vous dans la clé à molette, Devis & Factures et cliquez sur paiement Paypal ici :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-0-3.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-0-3.png)

- Cliquez ensuite sur « C’est parti » :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-16-2.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-16-2.png)

- Insérez vos identifiants dans le champ dédié ici :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-36-2.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-36-2.png)

Vous pouvez maintenant profiter de PayPal dans votre édition de devis et facturations 🙂

Si vous avez des questions, n’hésitez pas à cliquer sur la bulle bleue en bas de votre écran !
