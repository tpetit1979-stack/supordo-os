# QR code facture Suisse : comment configurer dans Axonaut ?

À partir d’octobre 2022, l’utilisation du QR code sur les factures est devenue obligatoire pour toutes les entreprises en Suisse. Cette mesure vise à moderniser et simplifier le processus de facturation et de paiement. Découvrez comment créer des factures QR code plus facilement avec Axonaut 👇

## Comment configurer le QR code sur mes factures dans Axonaut ?

### Accéder aux paramètres de facturation

- Cliquez sur l’icône de la clé à molette pour accéder aux paramètres.
- Sélectionnez la section « Devis & Factures ».
- Cliquez sur l’option « QR Facture Suisse ».

*Remarque : Si cette option n’est pas visible, assurez-vous que le pays renseigné dans « Mon abonnement et mes coordonnées de facturation » est bien la Suisse.*

[![](https://support.axonaut.com/wp-content/uploads/2023/10/CapturedE28099C3A9cran2022-08-31144714-95.png)](https://support.axonaut.com/wp-content/uploads/2023/10/CapturedE28099C3A9cran2022-08-31144714-95.png)

### Configurer les informations bancaires

- Vous avez la possibilité d’entrer soit votre IBAN standard, soit un QR IBAN accompagné de la référence correspondante.
- Ces informations sont généralement fournies par votre établissement bancaire.
- Après avoir saisi les données requises, cliquez sur « Valider » pour enregistrer les modifications.

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-31-3.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-31-3.png)

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-24-4.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-24-4.png)

### Créer une facture avec le QR Code

- Pour générer une nouvelle facture, cliquez sur le symbole « + » situé en haut à droite de l’interface.
- Renseignez toutes les informations nécessaires pour la facture.
- En bas de la facture, le QR code ainsi que le récépissé apparaîtront automatiquement, conformément aux normes suisses en vigueur.

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-73-2.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-73-2.png)

L’intégration du QR code sur vos factures présente plusieurs avantages :

- **Simplification des paiements :** Vos clients peuvent scanner le QR code pour effectuer le paiement, réduisant ainsi les erreurs de saisie et accélérant le processus.
- **Conformité légale :** En intégrant le QR code, vous vous conformez aux obligations légales suisses en matière de facturation.
- **Efficacité administrative :** La gestion des paiements est facilitée, ce qui permet de gagner du temps et de réduire les tâches administratives.
