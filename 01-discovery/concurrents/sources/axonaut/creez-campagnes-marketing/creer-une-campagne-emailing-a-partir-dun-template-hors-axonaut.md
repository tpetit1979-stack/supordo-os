# Créer une campagne emailing à partir d’un template hors Axonaut

Vous avez créé un template dans Mailjet, Mailchimp etc et vous souhaitez l’utiliser pour vos campagnes emailings ? Découvrez comment faire pas à pas dans cet article !

1) Tout d’abord, cliquez sur Emailing dans Marketing, Campagnes :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-76-2.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-76-2.png)

2) Ensuite, commençons par donner un nom à votre campagne.

Ensuite, vous pouvez définir le sujet de l’email, ajouter les documents déjà présents dans Axonaut qui seront en pièce jointe du mail et choisir “Template vide” dans la partie “Utiliser un template”:

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-37-5.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-37-5.png)

3) Lorsque vous passez à l’étape suivante, choisissez “Template simplifié” en haut à droite et continuer lorsque la pop-up apparaît :

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-78-7.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-78-7.png)

4) Pour créer la campagne de votre choix, vous avez trois tutoriels à votre disposition : le tuto Mailjet, Sendinblue/Brevo et Mailchimp. Cliquez sur le tuto de votre choix et suivez les étapes décrites dans chacun des articles :). Vous avez également les liens vers ces tutos pour Mailchimp, Sendinblue/Brevo et Mailjet dans ces articles ;).

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-22-3.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-22-3.png)

Retrouvez l’ensemble de vos campagnes mailings dans Marketing, Campagnes. Elles seront répertoriées dans un tableau indiquant leur date de création, le nom, le type de campagne (email, sms), le nombre de destinataires, le coût de la campagne, le statut c’est-à-dire quand cela va être envoyé ou quand cela a été envoyé.

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-59-5.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-59-5.png)

**Note :** Attention, une fois envoyé ou une date heure programmée, il n’est plus possible de supprimer ou modifier une campagne.

Pour permettre aux destinataires de se désinscrire de votre newsletter, élement obligatoire, vous pouvez ajouter un bouton opt out. Pour cela, ajouter un bouton dans la partie Bloc, cliquer sur le bouton sur le modèle de la campagne et sélectionner lien de désinscription dans le champ lien.
