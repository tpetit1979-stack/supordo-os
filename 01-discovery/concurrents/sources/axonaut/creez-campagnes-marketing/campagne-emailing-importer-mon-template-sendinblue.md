# Campagne Emailing : Importer mon template Sendinblue

Vous souhaitez utiliser vos templates d’emailing dans Axonaut ?

Rien de plus simple : Suivez le guide !

Tout d’abord, rendez-vous sur votre compte Sendinblue, menu « Campagnes » puis sélectionnez la rubrique « Templates » :

[![Campagne Sendinblue,](https://support.axonaut.com/wp-content/uploads/2023/10/Capture1-36.png)](https://support.axonaut.com/wp-content/uploads/2023/10/Capture1-36.png)

Une fois sur cette page, cliquez sur le nom du « Templates » de votre choix afin de le prévisualiser :

[![Aperçu campagne sendinblue,](https://support.axonaut.com/wp-content/uploads/2023/10/image-27-4.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-27-4.png)

Puis, rendez-vous dans le bouton « Aperçu » > « voir le code HTML » :

[![Voir le code HTML d'une campagne sendinblue,](https://support.axonaut.com/wp-content/uploads/2023/10/Capture3-32.png)](https://support.axonaut.com/wp-content/uploads/2023/10/Capture3-32.png)

Vous obtenez donc l’ouverture d’une nouvelle fenêtre avec un bloc de texte « spéciaux » : le code HTML de votre campagne.

C’est donc ces informations qui vont permettre à Axonaut de reproduire votre modèle à l’identique.

Ainsi, copiez les en partant du bas de la fenêtre, tel que ceci :

[![Code HTML campagne sendinblue,](https://support.axonaut.com/wp-content/uploads/2023/10/Capture4-34.png)](https://support.axonaut.com/wp-content/uploads/2023/10/Capture4-34.png)

Nous avons donc fini avec Sendinblue, passons à la partie Axonaut :

Ouvrez donc votre outil, sur la partie « Marketing » > « Campagnes ».

Une fois ici, deux options s’offrent à vous :

- Editer une campagne existante

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-88-6.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-88-6.png)

- Ou créer une nouvelle campagne

Vous pourrez donner un nom à votre campagne mailing, indiquer l’expéditeur, un sujet et cliquer sur « étape suivante en bas »:

[![](https://support.axonaut.com/wp-content/uploads/2023/10/image-14-6.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-14-6.png)

Vous êtes désormais sur la page où vous pouvez éditer des templates, cliquez désormais sur « Template simplifié » en haut et Continuer sur la pop up qui apparait:

[![](https://support.axonaut.com/wp-content/uploads/2023/10/CapturedE28099C3A9cran2021-11-16142529-32.png)](https://support.axonaut.com/wp-content/uploads/2023/10/CapturedE28099C3A9cran2021-11-16142529-32.png)

Vous pouvez ensuite coller le code HTML en cliquant sur le bouton ci-dessous:

[![](https://support.axonaut.com/wp-content/uploads/2023/10/CapturedE28099C3A9cran2021-11-16142805-11.png)](https://support.axonaut.com/wp-content/uploads/2023/10/CapturedE28099C3A9cran2021-11-16142805-11.png)

[![Source code Axonaut,](https://support.axonaut.com/wp-content/uploads/2023/10/image-39-2.png)](https://support.axonaut.com/wp-content/uploads/2023/10/image-39-2.png)

Enfin, validez avec le bouton « Ok » et admirez le rendu. 😀

N’hésitez pas à nous contacter via la bulle bleue en bas à droite de votre écran si vous avez des questions !
