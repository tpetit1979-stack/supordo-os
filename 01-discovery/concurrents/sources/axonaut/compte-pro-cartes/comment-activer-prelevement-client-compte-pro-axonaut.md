# Comment activer le prélèvement client avec le Compte Pro Axonaut ?

Il est possible de prélever vos clients directement depuis le Compte Pro Axonaut. De manière simple, vous pourrez créer vos factures et prélever vos clients de manière automatique, sécurisée et fiable ! On vous explique comment faire dans cet article !

Attention, cette option est disponible uniquement pour les clients ayant :

- Un abonnement Axonaut actif
- Un Compte Pro Axonaut actif

## Comment activer l’option du prélèvement automatique de vos clients sur Axonaut ?

Comme nous l’avons vu précédemment, le prélèvement client est disponible uniquement pour nos clients ayant un Compte Pro actif. Si vous ne l’avez pas encore ouvert, vous pouvez cliquer sur le lien suivant : [Ouvrir mon Compte Pro !](https://axonaut.com/axobank/activate/dashboard)

Ensuite pour activer l’option, il suffit de vous rendre dans la configuration de votre compte Axonaut : [ici](https://axonaut.com/account/accountInvoiceParameters/edit/64472)

Et de cocher l’option : Proposer le paiement par prélèvement

![](https://lh7-rt.googleusercontent.com/docsz/AD_4nXd29nLqXGUhNcmxynUAFMjoOn41nYRH3cdCASTaHNVYCbL_Zdf8--YAg1BkdZY7YDtL4ak38YhYVvFTJ6yzVWJpChP52Zr_b_wQ1lHTumC3HmeXCcqE3eL-37d8CgPxTJDWtJHDkQ?key=Itr5F3JjnlXG27nsx13TKA)

Attention, **si vous avez déjà l’option GoCardless**, il faudra en amont nous envoyer un email à [support@axonaut.com](mailto:support@axonaut.com) pour que nous puissions vous aider dans la migration de vos mandats existants.

## Comment créer un mandat Axonaut pour prélever vos clients ?

Afin de créer un nouveau mandat Axonaut pour prélever vos clients, il suffit de suivre les étapes suivantes :

- Créer une facture client

  - Ne pas oubliez de cocher la case : Autoriser le paiement par prélèvement

![](https://lh7-rt.googleusercontent.com/docsz/AD_4nXewcTUIgnIHBfhGeNAcj93AxAKqV3EovJ-0lODbvDeI_gvN_m6cKb_dmlUpU0TU_15ZISvRuP2Tk4sGGqKL7zhzKet43kfG9Cw6glKzYkeNCfSzyfX125fyrQn6pL0Jv5tR48iX?key=Itr5F3JjnlXG27nsx13TKA)

Important : par la suite, si vous ne souhaitez pas que la facture soit prélevée, il suffira de décocher cette option directement sur la facture.

## Comment faire signer le mandat Axonaut pour prélever vos clients ?

Avant de pouvoir prélever un client, il faut au en amont, lui faire signer un mandat d’autorisation de prélèvement. Voici comment faire :

### Via un lien dans la fiche du client

Tout simplement en se rendant dans la fiche de votre client et en cliquant sur : « Obtenir un lien à envoyer au client pour signer un mandat de prélèvement SEPA »

![](https://support.axonaut.com/wp-content/uploads/2025/07/image.png)

Une fois que vous avez cliqué vous arrivez sur une nouvelle page :

![](https://support.axonaut.com/wp-content/uploads/2025/07/image-1-1024x571.png)

Il vous faudra copier l’URL de cette page (lien unique par client) et lui envoyer par email pour qu’il signe le mandat.

Une fois que votre client aura signé le mandat, vous recevrez un email de la part de Axonaut vous signifiant que ce dernier est signé ! Ainsi toutes les prochaines factures pour ce client seront prélevées à la date d’échéance !

## Où retrouver vos mandats actifs ?

Vos clients ont déjà signé vos mandats et vous souhaitez savoir où ils sont ? Nous avons pensé à tout !

Pour les retrouver, rendez-vous sur votre Compte Axonaut dans :

- Compte Pro > Comptes > Mandats
- Ou directement sur ce lien : [ici](https://axonaut.com/axobank/receivedDirectDebitMandate/list)

![](https://lh7-rt.googleusercontent.com/docsz/AD_4nXfgHtGrbgsmfTKwCtpgXSF9OOym9LtYOVLp-OFMLBsPUwuDd9pn5l5PvNn6gSx8p47MGEhgjWgUVzYAzCc4TGygejc2P9H3Tb7PPfwZ5SIUieoWxhaAWr2jb3NkBabVGJuqXCM7?key=Itr5F3JjnlXG27nsx13TKA)

## Comment annuler un mandat actif ?

Si vous souhaitez annuler un mandat actif sur votre Compte Pro Axonaut, il faut vous rendre directement dans la fiche du client concerné.

Vous pourrez alors cliquer sur le bouton : Mandat d’autorisation de prélèvement

![](https://lh7-rt.googleusercontent.com/docsz/AD_4nXepU1DWddDyYw6iXxJ_-_RW8UNKtNSeHdypDIaUbburkmpfakcsWSx3_QFt3SzBqqr1ISsS0GTRf4GE1IZkA0UiX5yfuhIUAdTYiK8PKizDhidKhJbZAmb3jZ_ZEBYdkaxq8q2Usg?key=Itr5F3JjnlXG27nsx13TKA)

Ou vous rendre dans Compte Pro > Comptes > Mandats > Mandats clients.

Par la suite, cliquez dans la colonne “Statut” sur le mandat que vous souhaitez supprimer.
Vous aurez alors une icône de poubelle noire pour annuler le mandat et ainsi stopper les prélèvements pour ce dernier.

Si vous avez des questions ou besoin d’aide dans la mise en place de cette fonctionnalité, n’hésitez pas à contacter le support directement depuis le « ? » en bas à droite de votre écran.
