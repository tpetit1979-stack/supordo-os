# La gestion des droits utilisateurs pour le Compte Pro Axonaut

Afin de vous accompagner dans la gestion quotidienne de votre entreprise, Axonaut propose à l’ensemble de ses utilisateurs un Compte Pro gratuit. Pour gagner encore plus de temps sur l’administratif, vous pouvez donner des accès restreints à d’autres utilisateurs pour qu’ils s’occupent des tâches chronophages. On vous explique tout cela dans notre article.

## Comment fonctionne la gestion des droits utilisateurs pour le Compte Pro Axonaut ?

Si vous souhaitez donner un accès utilisateur au Compte Pro Axonaut, il faut au préalable lui donner un accès au Compte Axonaut de votre entreprise.

### Comment ajouter un utilisateur Axonaut ?

Pour ajouter un nouvel utilisateur sur votre compte Axonaut, rendez-vous dans la configuration de votre compte (en haut à droite de votre écran Axonaut) :

![](https://blog.axonaut.com/support/wp-content/uploads/2024/08/image.png)

- Cliquez sur « Utilisateurs »,
- Cliquez sur « Ajouter un utilisateur »,

![](https://blog.axonaut.com/support/wp-content/uploads/2024/08/image-1-1024x135.png)

- Remplissez tous les champs demandés :

![](https://blog.axonaut.com/support/wp-content/uploads/2024/08/image-2-1024x550.png)

Le nouvel utilisateur va recevoir une invitation à accéder à votre Compte Axonaut

### Comment ajouter un utilisateur du Compte Pro Axonaut ?

Afin d’ajouter un utilisateur sur le Compte Pro Axonaut, il faut vous rendre dans :

- Banques > Accès
- Cliquez sur « Inviter » dans l’utilisateur correspondant
- Remplir les champs demandés :

![](https://blog.axonaut.com/support/wp-content/uploads/2024/08/image-3-705x1024.png)

- Définir ses droits

  - *Pourra gérer les accès et les cartes* : cela revient à un statut administrateur où l’utilisateur verra toutes les informations du Compte Pro,
  - *Pourra faire des virements* : aura accès au sous menu « Virements »,
  - *Une carte pourra lui être attribué* : l’utilisateur pourra avoir une carte et la gérer.
- Cliquez sur « Inviter »

Une fois la procédure effectuée, votre utilisateur va recevoir un email sur l’adresse renseignée afin de compléter les informations de sécurité et vérifier son identité. Un passeport ou une carte d’identité sera nécessaire.
