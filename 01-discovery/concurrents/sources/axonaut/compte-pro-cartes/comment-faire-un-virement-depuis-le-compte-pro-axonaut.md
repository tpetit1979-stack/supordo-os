# Comment faire un virement depuis le Compte Pro Axonaut ?

Gérer vos finances professionnelles efficacement est essentiel pour le bon fonctionnement de votre entreprise. Axonaut propose une solution complète pour faciliter vos opérations bancaires, y compris les virements. Voici un guide détaillé pour vous aider à créer et gérer des virements depuis votre Compte Pro Axonaut.

## Étapes pour créer un nouveau virement

Pour initier un virement depuis votre Compte Pro Axonaut, suivez les étapes ci-dessous :

- **Accédez à votre compte Axonaut**

  - Commencez par vous connecter à votre compte Axonaut.
- **Allez dans la section Banques > Virements**

  - Une fois connecté, rendez-vous dans la section Banques. Cliquez ensuite sur l’onglet Virements. Cette section est dédiée à la gestion de vos transactions bancaires.

- **Créez un nouveau virement**

  - Pour créer un nouveau virement, cliquez sur le bouton “Nouveau virement”. Cette action ouvrira une nouvelle fenêtre où vous pourrez entrer les détails de votre virement.

![](https://blog.axonaut.com/support/wp-content/uploads/2024/07/image-19.png)

- **Sélectionnez les détails du virement**

  - **Le bénéficiaire** : Choisissez le bénéficiaire du virement. Si le bénéficiaire n’existe pas encore dans votre liste, vous pouvez le créer à ce moment-là en fournissant les informations nécessaires, telles que le nom, les coordonnées bancaires, et toute autre information requise.

![](https://blog.axonaut.com/support/wp-content/uploads/2024/07/image.png)

- **Le montant** : Indiquez le montant que vous souhaitez transférer. Assurez-vous que le montant ne dépasse pas le solde disponible de votre Compte Pro Axonaut.

![](https://blog.axonaut.com/support/wp-content/uploads/2024/07/image-1.png)

- **Les références et le libellé** : Fournissez les références et le libellé du virement. Ces informations permettent de suivre et de justifier la transaction.

![](https://blog.axonaut.com/support/wp-content/uploads/2024/07/image-2.png)

- **La date effective du virement** : Sélectionnez la date à laquelle vous souhaitez que le virement soit effectué. Vous pouvez choisir une date future si nécessaire.

![](https://blog.axonaut.com/support/wp-content/uploads/2024/07/image-3.png)

- **Validez le virement**

  - Après avoir rempli tous les détails nécessaires, passez à l’étape de récapitulatif. Vérifiez attentivement toutes les informations pour vous assurer qu’elles sont correctes. Une fois vérifiées, cliquez sur « Valider » pour confirmer le virement.

## Quels sont les délais pour recevoir un virement sur mon Compte Pro Axonaut ?

### Quels sont les délais pour recevoir un virement classique ?

Dans la majorité des cas, la réception des virements classiques va prendre entre **2 et 3 jours ouvrés** (c’est-à-dire du lundi au vendredi).

Les virements classiques ou SEPA sont la norme européenne pour les virements. Les délais peuvent varier selon la banque émettrice mais ne dépassent pas généralement les 3 jours ouvrés.

### Quels sont les délais pour recevoir un virement instantané ?

Comme son nom l’indique, les virements instantanés sont réceptionnés en seulement quelques secondes.

Cependant, dans certains cas indépendants de notre volonté, la réception peut être rallongée pour des raisons diverses. Généralement, quelques minutes. Mais ne vous inquiétez pas, nous vous tiendrons informés.

### Quels sont les délais pour recevoir un virement international ou virement SWIFT ?

Rappel : À l’heure actuelle, le Compte Pro Axonaut ne permet pas d’initier les virements SWIFT mais vous pouvez les recevoir. Nous vous tiendrons informés lorsque cette fonctionnalité sera présente sur Axonaut.

Concernant les délais de réception, il faut en moyenne entre 4 et 5 jours ouvrés pour recevoir ce type de virement. Encore une fois, les délais peuvent varier en fonction de la banque émettrice.

Pour rappel, les virements SWIFT sont des virements en devises étrangères uniquement et qui proviennent d’un pays hors SEPA).

## Comment créer un virement récurrent ?

Voici les étapes à suivre pour initier un virement récurrent depuis votre Compte Pro Axonaut :

- Rendez-vous sur votre compte Axonaut,
- Allez dans Banques > Virements,
- Cliquez sur “Nouveau virement”.

Lors de cette étape, il vous faudra choisir les éléments suivants :

- Le bénéficiaire (vous pouvez en créer à ce moment-là ou en choisir un existant),
- Le montant,
- Les références, le libellé,
- Cliquez sur « Récurrent » pour définir la fréquence

![](https://blog.axonaut.com/support/wp-content/uploads/2024/07/image-5.png)

- Ensuite la période de date,

![](https://blog.axonaut.com/support/wp-content/uploads/2024/07/image-4.png)

- Cliquez sur « Valider »

Attention, le virement ne sera pas possible si son montant est supérieur au solde actuel de votre Compte Pro Axonaut ! Dans le cas où votre solde est inférieur au moment du virement à venir, Axonaut vous enverra un email précisant qu’il faut recharger votre compte 48h avant.

## Comment modifier un virement récurrent ?

Voici les étapes à suivre pour modifier un virement récurrent depuis votre Compte Pro Axonaut :

- Rendez-vous sur votre compte Axonaut,
- Allez dans Banques > Virements > Onglet « Virements récurrent «

![](https://blog.axonaut.com/support/wp-content/uploads/2024/07/image-6.png)

- Cliquez sur la ligne du virement récurrent > Modifier.

Lors de cette étape, il vous faudra modifier les éléments souhaités :

- Le montant,
- La date à laquelle vous souhaitez qu’Axonaut fasse le virement,
- La fréquence,
- Cliquez sur Valider .

Attention, le virement ne sera pas possible si son montant est supérieur au solde actuel de votre Compte Pro Axonaut ! Dans le cas où votre solde est inférieur au moment du virement à venir, Axonaut vous enverra u,n email précisant qu’il faut recharger votre compte 48h avant.

## Comment supprimer un virement récurrent ?

Voici les étapes à suivre pour supprimer un virement récurrent depuis votre Compte Pro Axonaut :

- Rendez-vous sur votre compte Axonaut,
- Allez dans Banques > Virements > Onglet « Virements récurrents »,
- Cliquez sur la ligne du virement récurrent > Modifier > Annuler le virement récurrent.

## Comment gérer les bénéficiaires ?

Comme nous l’avons vu, il est tout à fait possible de créer un nouveau bénéficiaire lors de l’initiation d’un nouveau virement. Mais vous pouvez aussi gérer l’ensemble des bénéficiaires depuis l’interface dédiée de votre compte Axonaut :

- Banques > Virements > Onglet « Bénéficiaires »,

![](https://blog.axonaut.com/support/wp-content/uploads/2024/07/image-8-1024x360.png)

- Banques > Virements > Bénéficiaires > cliquez sur “Modifier” (petit stylo bleu) pour soit modifier ou supprimer un bénéficiaire existant.

Attention, dans tous les cas, Axonaut demandera une double authentification afin d’assurer la sécurité de votre compte.

## Points à retenir

Il est important de noter que le virement ne pourra pas être effectué si le montant dépasse le solde actuel de votre Compte Pro Axonaut. Pour éviter ce problème, veillez à vérifier régulièrement le solde de votre compte et à l’alimenter si nécessaire. Vous pouvez alimenter votre Compte Pro en effectuant un virement depuis votre banque traditionnelle vers votre compte Axonaut.

En suivant ces étapes simples, vous pouvez gérer efficacement vos virements et assurer une bonne gestion financière de votre entreprise grâce à Axonaut. Assurez-vous de toujours garder un œil sur votre solde et de vérifier les détails avant de valider un virement pour éviter toute erreur.

Avec Axonaut, la gestion de vos opérations bancaires n’a jamais été aussi facile. Profitez de cette fonctionnalité pour gagner du temps et vous concentrer sur le développement de votre entreprise.
