# Le prévisionnel de trésorerie : découvrez le module trésorerie !

Pour gérer son entreprise, il est essentiel d’avoir une vision claire sur sa trésorerie et plus précisément son prévisionnel de trésorerie. Découvrez notre module de trésorerie !

## Le module trésorerie ✨

Avec le module trésorerie, Axonaut devient encore davantage votre allié pour une trésorerie saine ! Créez des prévisions financières et anticipez différents scénarios pour votre entreprise.

 

### Création de votre module de trésorerie

Pour créer et personnaliser votre module de trésorerie :

- Rendez-vous dans Pilotage > Trésorerie
- Vous pourrez cliquer sur « créer votre prévisionnel de trésorerie » sur la fenêtre qui s’affiche.
- Nommez votre prévisionnel de trésorerie.
- Sélectionnez la date de fin de votre choix (fin de l’année civile ou l’exercice comptable). Chaque colonne du tableau se remplira avec les données disponibles sur Axonaut.
- Une fois ces informations renseignées, validez.

💡Dans la case « Trésorerie actuelle », Axonaut va reprendre automatiquement le solde de votre compte bancaire, que vous aurez connecté au préalable dans l’onglet « Rapprochement bancaire ».

### Visualisation de votre prévisionnel de trésorerie

Vous allez ensuite visualiser un graphique avec plusieurs données : les encaissements réels, les encaissements prévisionnels, les décaissements réels, les décaissements prévisionnels, la trésorerie réelle et la trésorerie prévisionnelle.
 
A partir de vos codes comptables, Axonaut créé des catégories vous indiquant les encaissements et les décaissements sur une période choisie. Vous pouvez les ajuster également directement depuis le tableau et en ajouter si besoin.

 
Dans l’ajout de données dans chaque case du tableau, vous pouvez également à l’aide de l’icône verte prévoir une augmentation sur plusieurs mois. Les lignes seront ainsi remplies automatiquement.
 
L’ensemble des informations prévisionnelles sont comparables avec la trésorerie réelle. Ces cases sont remplies à partir des informations d’Axonaut et ne sont pas modifiables. Vous pouvez cependant avoir un détail.
 
💡Dans autres encaissements et décaissements, vous retrouverez les codes comptables qui ne sont pas utilisées sur votre compte. Vous pouvez cliquer sur l’œil à côté pour les passer dans les codes comptables « principaux ».
 

### Création de scénarios pour anticiper l’impact sur votre trésorerie

En parallèle de votre scénario principal, vous pouvez ajouter un ou plusieurs scénarios de trésorerie. Il vous suffit de cliquer sur le « + » bleu en haut à gauche de votre écran :

## Le restant à encaisser

Si vous n’avez pas ajouté de paiement sur des factures, Axonaut prend en compte ces factures dans le prévisionnel de trésorerie.

 

## Les commandes à facturer

Si vous n’avez pas facturé l’ensemble d’une [commande](https://support.axonaut.com/commandes-clients-fournisseurs/fonctionnement-dune-commande-client/), Axonaut utilisera le temps moyen de facturation après l’acceptation d’un devis.

 

## Les factures prévisionnelles

Si vous avez créé des factures prévisionnelles dans Axonaut, Axonaut prendra en compte les factures qui n’ont pas encore été créées et que vos clients vous paieront prochainement.

 

## Les opportunités commerciales

Axonaut prend en compte le montant des [opportunités](https://support.axonaut.com/optimisez-gestion-commerciale/les-opportunites-dans-axonaut/) en cours pondéré par leur probabilité de réussite*. *Cela utilise la date de chaque opportunité ainsi que le temps moyen de facturation pour ce client.

Si vous préférez utiliser les devis plutôt que les opportunités, c’est possible dans la clé à molette, Configuration, Avancée et « Utiliser les devis plutôt que les opportunités pour le prévisionnel ».

 

## La TVA

C’est dans cette partie que vous retrouverez le total de TVA encaissé et décaissé. Cela vous permettra d’effectuer votre déclaration de TVA également. Vous avez plus de détail en cliquant sur le “i” sur la ligne.

 

## Les dépenses prévisionnelles

Axonaut prendra également en compte les commandes fournisseurs avec un prévisionnel de dépense. Par exemple, vous avez créé une commande avec des dépenses récurrentes pour l’électricité, le loyer etc.

 

## Les dépenses moyennes

Ceci est une moyenne de toutes les dépenses que vous avez créées au cours de ces 6 derniers mois (sans compter les dépenses récurrentes).

 

## Les Dépenses à payer

Dans ce calcul, Axonaut utilise le délai moyen de paiement pour chaque fournisseur ou si vous avez ajouté une date de paiement prévue pour une dépense.

 

## Les opérations diverses

Si vous avez ajouté des opérations diverses dans Pilotage, Factures et l’onglet “Opérations diverses”, Axonaut les prendra en compte dans le prévisionnel de trésorerie.
