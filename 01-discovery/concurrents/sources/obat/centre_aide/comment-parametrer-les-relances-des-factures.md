# Comment paramétrer les relances des factures ?

## Récupérez plus rapidement de la trésorerie avec nos relances automatiques pour les paiements client en retard



### Etape par étape


- Veuillez accéder au **paramétrage** de votre compte, puis sélectionnez l'onglet**"Mes documents"** et naviguez vers la rubrique **"Factures"** (indiquée par les flèches rouges).


- **Choisissez l'échéance de paiement** par défaut pour vos factures (indiqué par les flèches rouges).



- Vous avez également la possibilité d’**ajuster cette échéance individuellement pour chaque facture** directement depuis l'éditeur de facture (flèches rouges).



- Depuis la section "Facture" de votre compte obat (flèche rouge), vous pouvez facilement **consulter toutes vos factures arrivées à échéance en sélectionnant l'onglet "En retard"** (flèche bleue).
- Chez Obat, **vous avez la possibilité d'émettre jusqu'à trois relances pour vos factures.** Le numéro de chaque relance est clairement indiqué sur les cases rouges (flèches vertes).



- **Lorsque vous cliquez sur une relance, un e-mail est automatiquement créé.** Vous avez la possibilité d'ajuster le contenu de cet e-mail selon vos besoins (flèche rouge).



- Pour **personnaliser le contenu des relances de facture,** rendez-vous dans le paramétrage de votre compte, sous la section "Envoi d'emails" (flèche rouge). Ensuite, sélectionnez "Envoi des relances" où vous aurez la possibilité d'**adapter le texte par défaut selon vos préférences** (flèches bleues).



- Pour **consulter toutes vos notifications d'échéance, cliquez sur l'icône en forme de cloche** située en haut à droite de votre compte (flèche rouge).
