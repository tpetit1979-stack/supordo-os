# Comment faire une facture proforma avec Obat

## La facture proforma est un BROUILLON DE FACTURE qui n'a aucune valeur comptable ou légale. La seule règle est de mentionner “Facture Proforma” sur le document.

Une facture **proforma** (“pour la forme” en latin) correspond à une facture qui est seulement émise à **titre informatif pour le client**. Elle vient détailler les informations à propos d'un achat de marchandise ou d'une prestation de service en amont de la création d'une vraie facture.

Pour faire une facture proforma vous pouvez créer une nouvelle facture puis **ajouter une description** (flèche rouge)



Ajoutez la **mention Facture proforma** dans la description de votre facture (flèche rouge)

Puis **enregistrez** votre facture pour qu' elle reste en **statut brouillon** (flèche verte) .



Puis passez en **mode prévisualisation** (flèche rouge) puis **téléchargez** votre facture (flèche orange) et **envoyez la via votre propre adresse email.**




Dès lors, une fois la facture validée, vous pourrez la passer en **statut finalisée** pour qu' elle prenne un **numéro de facture** (flèche rouge).




**Attention :** il faudra effacer la mention Facture PROFORMA dans la description (flèche rouge).
