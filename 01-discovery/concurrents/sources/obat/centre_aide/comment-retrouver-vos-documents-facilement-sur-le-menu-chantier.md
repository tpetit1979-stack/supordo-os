# Comment retrouver vos documents facilement sur le menu chantier ?

## L'onglet chantier permet la centralisation de tous les documents liés à vos chantiers.




Dans le menu **"chantier"**, vous retrouverez dans chaque encadré la mention de **votre client, du chantier et tous les documents liés à ce chantier.**


- Depuis l'**onglet chantier** (flèche rouge), vous retrouverez **tous vos chantiers que vous pourrez sélectionner** (flèche bleue).
- **Lorsque un chantier est sélectionné** , une fenêtre s'ouvre sur la droite. Vous pourrez y**consulter tout les documents liés à ce chantier** (flèches vertes), ainsi que leur**différents statuts** (brouillon / finalisé / envoyé / signé / payé / annulé).
- Vous retrouverez aussi l **avancement de facturation et de paiement** de ce chantier (flèches oranges).
- Enfin, il vous sera possible de facilement **créer de nouveaux documents** sur ce chantier en clinquants sur**nouveau devis ou nouvelle facture** (flèches jaunes).
