# Comment rechercher des éléments dans votre bibliothèque personnalisée?

## Vous pouvez avoir accès à vos éléments de fourniture, main d'œuvre et ouvrage directement dans le menu bibliothèque ou depuis l'onglet bibliothèque sur votre éditeur de devis / factures.


- Pour accéder à votre bibliothèque rendez-vous sur l' **onglet bibliothèque** (flèche rouge).
- En cliquant sur le **bouton bibliothèque** (flèche verte) vous pourrez filtrer  tout les éléments par **Fourniture / Main d'œuvre / Ouvrage / Sous-traitance / Matériels / Textes / Divers.**
- Vous pourrez également rechercher des éléments dans la **barre de recherche** grâce à un**mot clé** (flèche bleue).
- **Créez** facilement de**nouvelles unité** ou de **nouvelles familles** (flèches oranges).

- Retrouvez vos éléments de fourniture, main d'œuvre et ouvrage directement dans votre **éditeur de devis / facture** en cliquant sur l'**onglet bibliothèque** en haut à gauche (flèche rouge).

- Recherchez vos éléments dans la **barre de recherche** (flèche bleue) ou dans l**'arborescence** de votre bibliothèque (flèches rouges).

- Vous pourrez ensuite **faire "glisser"** ces éléments sur votre devis ou bien**cocher les cases** correspondantes puis les**"ajouter au document"**  ( flèches bleues).
