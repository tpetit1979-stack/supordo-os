# Les achats reçus par facturation électronique ne peuvent plus être supprimés dans Obat

## Des achats électroniques protégés pour une comptabilité fiable et conforme.

La **facturation électronique** prend progressivement une place importante dans le secteur du **BTP**. De plus en plus d’artisans reçoivent leurs **factures fournisseurs** directement dans leur logiciel de gestion.

Pour accompagner cette évolution et anticiper les obligations légales à venir, **Obat bloque désormais la suppression des achats reçus électroniquement** via la plateforme **Iopole**.

Objectif : garantir la **traçabilité**, la **conservation des documents** et la **conformité réglementaire**.

#### Pourquoi ce changement dans Obat ?

La réglementation évolue rapidement.

En **Belgique**, l’obligation de réception des **factures électroniques** est déjà en vigueur.

En **France**, cette obligation s’applique à partir de **septembre 2026**.

Cela signifie que les entreprises doivent **conserver l’intégralité des factures reçues électroniquement**, afin de garantir :

- 
la **traçabilité des échanges commerciaux**
- 
l’ **intégrité des documents**
- 
la conformité en cas de **contrôle fiscal ou d’audit comptable**

Or, auparavant, un utilisateur pouvait encore **supprimer un achat reçu électroniquement** ou **supprimer la pièce jointe associée**.

Avec cette nouvelle fonctionnalité, **Obat protège automatiquement ces documents sensibles**.

#### Ce qui change concrètement pour vous dans Obat

Lorsque vous recevez un **achat via la facturation électronique (Iopole)**, certaines actions deviennent volontairement impossibles.

### Dans la liste des achats

Si vous ouvrez le menu d’actions d’un achat reçu électroniquement :

- 
l’option **Supprimer** apparaît**grisée**
- 
elle ne peut pas être sélectionnée

Un message explicatif apparaît lorsque vous passez la souris dessus :

👉 *« Vous ne pouvez pas supprimer un achat transmis via la facturation électronique »*

Toutes les **autres actions restent disponibles**.

### Dans le panneau de détail d’un achat

Lorsque vous consultez un achat :

- 
le bouton **Supprimer** est également**désactivé**
- 
un message explique la raison du blocage

Vous pouvez toujours :

- 
enregistrer un **règlement**
- 
créer un **avoir**
- 
**modifier l’achat**

Seule la **suppression est bloquée**.

### Pour les pièces justificatives

La **pièce justificative associée à une facture électronique** est également protégée.

Dans la section **Pièce justificative** :

- 
l’icône de suppression n’apparaît plus
- 
la pièce jointe **ne peut plus être retirée**

En revanche, vous pouvez toujours :

- 
**télécharger le document**
- 
**consulter la facture**

Un message précise :

👉 *« Les pièces jointes ne peuvent plus être supprimées pour des raisons de traçabilité »*

#### Quels achats sont concernés ?

Cette protection concerne uniquement les **achats reçus par facturation électronique via Iopole**.

Les **achats saisis manuellement** dans Obat continuent de fonctionner comme avant :

- 
ils peuvent toujours être **modifiés**
- 
ils peuvent toujours être **supprimés**

La règle est donc simple :

➡️ **Seuls les achats provenant de la facturation électronique sont verrouillés.**

#### Une protection appliquée à tous les niveaux

Pour garantir la sécurité des documents, Obat applique cette protection à plusieurs niveaux.

### Dans l’interface

Les boutons de suppression sont **grisés** avec un message explicatif.

Vous comprenez immédiatement pourquoi l’action est impossible.

### Dans le système

Si une tentative de suppression est faite directement dans le système, Obat **refuse automatiquement la demande**.

### Pour tous les rôles

Cette règle s’applique à **tous les utilisateurs** :

- 
**Propriétaire**
- 
**Administrateur**
- 
**Expert-comptable**
- 
**Comptable**

Personne ne peut supprimer un achat reçu par **facturation électronique**.

#### Un vrai gain de sécurité pour votre entreprise

Grâce à cette évolution, vos **factures fournisseurs électroniques** sont désormais **protégées automatiquement**.

Pour vous, artisan du bâtiment, cela signifie :

- 
**zéro risque de suppression accidentelle**
- 
un **dossier comptable toujours complet**
- 
une **préparation sereine à la réglementation de 2026**

Votre **expert-comptable** retrouve facilement toutes les pièces nécessaires, et vos documents restent disponibles en cas de **contrôle ou de vérification**.

Avec cette fonctionnalité, **Obat sécurise vos documents et simplifie votre conformité réglementaire**. 🧾✅
