# Créer facilement un événement dans votre calendrier OBAT

## Avec le calendrier OBAT, vous organisez simplement vos rendez-vous, interventions et tâches de chantier. En quelques clics, vous ajoutez un événement et vous informez votre équipe si nécessaire. Voici comment procéder.


### 1️⃣ Sélectionnez la **ressource concernée**

Pour commencer, choisissez les **ressources** sur lesquelles vous souhaitez ajouter un événement.

Il peut s’agir par exemple d’un **collaborateur** ou d’un **véhicule**.



### 2️⃣ Paramétrez votre **événement**

Une **fenêtre de paramétrage** s’ouvre automatiquement. Elle vous permet de renseigner toutes les informations utiles.

Vous pouvez alors :

- 
ajouter le **type d’événement** (rendez-vous client, intervention, visite de chantier…)

- 
sélectionner le **client**


- 
choisir le **chantier concerné**


Les **ressources associées** à l’événement apparaissent également. Vous pouvez les **modifier directement depuis l’onglet dédié** si besoin.


### 3️⃣ Ajoutez des **notes et informations utiles** 📝

Dans le champ **notes**, vous pouvez saisir toutes les informations importantes pour votre équipe :

- 
détails de l’intervention
- 
consignes particulières
- 
matériel nécessaire
- 
informations communiquées par le client

Ces notes permettent à vos collaborateurs d’avoir **toutes les informations au bon moment**.


### 4️⃣ Vérifiez la **date et les horaires**

Avant d’enregistrer, prenez le temps de **contrôler la date et les horaires** de votre événement.

Vous pouvez facilement **ajuster l’heure de début ou de fin** directement dans la fenêtre.

- Vous pouvez également utiliser, [la récurrence d'évènement.](https://aide.obat.fr/creez-des-evenements-recurrents-dans-votre-calendrier-obat?hsLang=fr)

### 5️⃣ Créez rapidement de nouveaux éléments

Depuis les différents onglets, vous pouvez également créer directement :

- 
un **nouveau type d’événement**


- 
un **nouveau client**


- 
un **nouveau chantier**


- 
une **nouvelle ressource**


Vous ne perdez donc pas de temps à quitter votre calendrier pour ajouter ces informations.


### 6️⃣ Gérez les **notifications envoyées à vos équipes** 🔔

Comme pour le **planning de chantier**, vous pouvez choisir :

- 
d’ **envoyer une notification** à votre équipe lorsqu’un événement est modifié
- 
ou de **ne pas notifier** ces changements

Cela vous permet d’adapter la communication selon l’importance de la modification.

### 7️⃣ Consultez rapidement le **résumé d’un événement**

En passant simplement votre souris sur un événement dans le calendrier, vous voyez apparaître un **résumé rapide** contenant :

- 
le **type d’événement**
- 
le **client**
- 
l’ **adresse**
- 
l’ **adresse du chantier**
- 
les **notes**
- 
les **lots et tâches**
- **Les bordereaux liées au chantier**

Cette vue rapide vous permet de **retrouver immédiatement les informations essentielles**, sans ouvrir l’événement.


**Notifications push pour le calendrier**

En plus de l'e-mail déjà envoyé, les utilisateurs assignés à un chantier reçoivent désormais une notification push dès qu'une modification est enregistrée sur le calendrier via le bouton « Enregistrer et notifier les ressources ».

Chaque utilisateur peut activer ou désactiver ces notifications push depuis l'application mobile, dans **Paramètres > Notifications**.
