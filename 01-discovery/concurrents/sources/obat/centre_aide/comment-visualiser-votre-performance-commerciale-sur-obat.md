# Comment visualiser votre performance commerciale sur Obat ?

## Vos indicateurs de performance commerciale vous permettent de contrôler facilement l'évolution de votre activité depuis l'onglet "pilotage"

Nous vous invitons à consulter la vidéo suivante pour découvrir comment visualiser votre performance commerciale 👇



- Pour visualiser vos **performances commerciales** , cliquez sur **l'onglet pilotage** en haut à droite de votre compte **Obat** (flèche rouge).

- Vous pourrez visualiser rapidement vos **performances commerciales** .
- **Les performances commerciales sont calculées sur le ratio de vos devis signés sur envoyés.**

- Vous pouvez sélectionner **une période** sur laquelle vous retrouverez l'évolution de vos indicateurs (flèche rouge).
