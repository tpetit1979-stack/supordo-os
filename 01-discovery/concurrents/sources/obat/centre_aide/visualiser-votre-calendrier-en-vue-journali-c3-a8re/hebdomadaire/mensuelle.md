# Comment visualiser votre calendrier en vue journalière /hebdomadaire/mensuelle ?

## En utilisant différentes vues du calendrier, vous pourrez améliorer votre organisation, gérer efficacement votre temps et vos ressources, et ainsi augmenter votre productivité et la satisfaction de vos clients.


**Visualiser votre calendrier en vue jour, semaine et mois présente plusieurs avantages pour vous 👇**

  **💡Vue journalière :** Vous permet de gérer vos tâches quotidiennes avec précision, d'optimiser vos déplacements et de vous assurer que chaque journée est bien remplie.

**💡Vue hebdomadaire :** Vous aide à planifier vos projets et vos tâches sur une semaine complète, offrant une vision d'ensemble sur les deadlines proches et permettant d'ajuster vos priorités.

**💡Vue mensuelle :** Vous offre une perspective à long terme, facilitant la planification de projets de plus grande envergure et l'anticipation des périodes de forte activité ou de creux.


### Etape par étape


- **Depuis le calendrier** , cliquez sur le bouton à droite de configuration (flèche rouge).
- Vous avez la possibilité de **sélectionner une vue quotidienne, hebdomadaire ou mensuelle** (flèches bleues).


**👉 Vue journalière**


- Vous avez la possibilité de **choisir plusieurs ressources** (flèches rouges).
- Clic sur les flèches (flèches bleues) : **Vers la gauche :** affiche le jour précédent**Vers la droite :** affiche le jour suivant**Clic sur Aujourd’hui :** affiche le jour actuel
- Vous avez aussi la possibilité d**'utiliser le calendrier pour sélectionner une date spécifique** (flèches vertes).



**👉 Vue hebdomadaire** 


- Vous avez la possibilité de **choisir plusieurs ressources** (flèches rouges).
- Clic sur les flèches (flèches bleues) : **Vers la gauche :** affiche la semaine précédente**Vers la droite :** affiche la semaine suivante**Clic sur Aujourd’hui :** affiche la semaine actuelle
- Vous avez aussi la possibilité d**'utiliser le calendrier pour sélectionner une date spécifique** (flèches vertes).



**👉 Vue mensuelle**


**La vue mois vous permet d’avoir une vision d’ensemble des évènements prévus sur l’ensemble du mois. Vous pouvez visualiser le calendrier de une ou plusieurs ressources d’un coup.**

- Vous avez la possibilité de **choisir plusieurs ressources** (flèches rouges).
- Clic sur les flèches (flèches bleues) : **Vers la gauche :** affiche le mois précédent**Vers la droite :** affiche le mois suivant**Clic sur Aujourd’hui :** affiche le mois actuel
- Vous avez aussi la possibilité d**'utiliser le calendrier pour sélectionner une date spécifique** (flèches vertes).



- En sélectionnant "autre" depuis la vue mensuelle, vous pourrez consulter tous les événements d'une journée spécifique (flèches rouges).
- Vous avez aussi la possibilité de cliquer sur l'événement pour accéder aux détails et voir à qui il est assigné (flèches vertes).
