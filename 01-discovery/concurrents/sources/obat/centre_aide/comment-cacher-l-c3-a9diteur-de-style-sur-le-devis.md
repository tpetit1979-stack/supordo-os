# Comment cacher l'éditeur de style sur le devis?


**Etape par étape :**

1. **Rendez-vous dans un devis**
2. **Cliquez sur "options" puis cocher la case "Cacher l'éditeur de style"**


Vous ne retrouverez donc plus l'éditeur de style dans chaque ligne de votre devis.
