# Notifications Push : Simplifiez la Réception d'Alertes en Temps Réel

## Notre application vous permet de recevoir instantanément des notifications push pour les nouvelles annonces Marketplace, les appels manqués et les messages du répondeur intelligent.


Le système de notifications push a été conçu pour que les artisans puissent rester informés de toutes les informations importantes en temps réel. Vous gagnez en réactivité et en efficacité, sans interruption dans votre travail. Nous vous recommandons d’activer et de configurer vos notifications pour profiter pleinement de ces avantages.





Dans le cadre de notre engagement à optimiser la **gestion de vos informations** et à vous fournir des **alertes en temps réel**, nous avons intégré un système de **notifications push** au sein de notre application. Grâce à ce système, vous pouvez recevoir **instantanément** des notifications concernant les **nouvelles annonces,** les **appels manqués** et les **messages reçus**, directement sur votre appareil.

Les notifications push sont spécifiquement élaborées pour **répondre à vos besoins** **d'immédiateté et de réactivité.** Elles assurent que vous **restez informé** sans avoir à vérifier manuellement votre application, vous permettant ainsi de ne **manquer aucune information** essentielle liée à votre activité.



### 1. Collecte du Consentement : Première Étape pour Recevoir des Notifications


Avant d’envoyer des notifications, nous nous assurons que vous êtes d’accord pour les recevoir. La collecte du consentement est une étape cruciale pour respecter la vie privée de chaque utilisateur. Voici comment elle se déroule :


**👉 Lors de la première utilisation de l’application mobile**  : Au premier accès, une demande de consentement s’affiche. Cela vous permet de décider si vous souhaitez ou non activer les notifications.




💡 A savoir 💡

Vous avez la possibilité de modifier votre choix à tout moment



👉 Rendez-vous dans le menu "**paramètres**" de votre application




👉 Allez dans le menu "**Préférences**".


👉  Cliquez sur " **Autoriser les notifications**" 






💡 A savoir 💡


Une fois le consentement donné, vous avez la possibilité de configurer les notifications à recevoir, afin qu’elles s’adaptent précisément à votre activité


- 
**En cas de refus** : Un écran d’information vous rappelle que les notifications doivent être autorisées. Vous pouvez modifier cette autorisation soit via les paramètres de votre appareil, soit dans votre navigateur.


- 
**En cas d’acceptation** : Une fois les notifications activées, accédez à votre panneau de contrôle pour sélectionner les types de notifications que vous souhaitez recevoir :

### 2. Si Vous Utilisez la Version Web Mobile : Invitation à Installer l’Application



💡 **A savoir** 💡


Pour bénéficier de notifications optimisées, l’application vous invite à passer à la version mobile en téléchargeant l’application sur Android/iOS. Ainsi, les notifications push s’intègreront mieux à votre appareil.





👉 **Lorsque cette page s'affiche**, sélectionnez le store **correspondant à votre appareil** afin de télécharger **l'application mobile**. 



**Notifications push pour le calendrier**

En plus de l'e-mail déjà envoyé, les utilisateurs assignés à un chantier reçoivent désormais une notification push dès qu'une modification est enregistrée sur le calendrier via le bouton « Enregistrer et notifier les ressources ».

Chaque utilisateur peut activer ou désactiver ces notifications push depuis l'application mobile, dans **Paramètres > Notifications**.
