# Comment cacher certaines informations sur votre devis?

### Vous avez la possibilité de personnaliser vos devis en choisissant de cacher certaines informations qui n'apparaitront pas à la prévisualisation, et ne seront donc plus visibles par votre client.


Nous vous invitons à visionner la vidéo suivante pour découvrir comment cacher certaines informations sur votre devis :



**Etape par étape :**

1. **Rendez-vous dans un devis**
2. **Cliquez sur l'onglet "Options" puis dirigez vous vers le menu "Document**



**Vous pourrez ainsi cacher certains éléments afin qu'ils ne figurent pas sur votre devis final**

**Remarque : Les éléments seront toujours visibles en mode "Edition" mais bien cachés lorsque vous passerez en "Prévisualisation"**
