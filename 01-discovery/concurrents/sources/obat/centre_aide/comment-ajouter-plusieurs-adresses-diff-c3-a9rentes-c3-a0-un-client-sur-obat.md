# Comment ajouter plusieurs adresses différentes à un client sur Obat?

## Vous avez la possibilité d'ajouter plusieurs adresses différentes pour un même client. Découvrez le multi adresse.

Nous vous invitons à consulter la vidéo suivante pour découvrir comment ajouter plusieurs adresses différentes à un client 👇



**Etape par étape :**

- Rendez-vous dans un nouveau devis
- Diriger vous sur **"Sélectionner un client"** puis cliquez sur**"nouveau client"** .

- Renseignez ensuite les coordonnées de votre client puis cliquez sur **"Ajouter une adresse"** .


- **Une 2ème ligne d'adresse apparaît juste en dessous** :



**Vous pourrez ensuite choisir de faire apparaître ces libellés sur votre document en cliquant sur le petit oeil situé à droite du libellé**
