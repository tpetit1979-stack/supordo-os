# Comment ajouter un taux de TVA personnalisé sur OBAT ?



Pour ajouter un **taux de TVA personnalisé** sur Obat, rendez-vous dans le **paramétrage de votre compte** (flèche verte) en cliquant sur votre nom en haut à gauche (flèche rouge).

Cliquez ensuite sur l'**onglet préférence** (flèche rouge), puis sur **Ajouter une TVA** (flèche bleue).

**Ajouter le taux de votre choix** (flèche rouge) puis cliquez sur Ajouter (flèche bleue).

Votre **taux de TVA personnalisé** sera automatiquement pris en compte par le logiciel et vous le retrouverez dans **la liste déroulante dans les préférences mais également dans l'éditeur de devis** .


**⚠️ATTENTION⚠️**

**Tout taux de tva ajouté est définitif et ne pourra être supprimé**
