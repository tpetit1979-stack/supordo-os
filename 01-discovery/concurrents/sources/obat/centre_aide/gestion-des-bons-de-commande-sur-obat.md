# Gestion des bons de commande sur OBAT

## OBAT vous propose une toute nouvelle fonctionnalité pour faciliter votre quotidien : la création de bons de commande. Vous allez pouvoir gagner du temps et améliorer le suivi de vos achats fournisseurs 📈.


### 🎯 Pourquoi cette nouveauté ?

Jusqu’à maintenant, vous ne pouviez pas créer facilement un **bon de commande fournisseur** à partir d’un **devis**. C’est désormais possible, de **deux manières** :

- 
depuis un **devis existante**
- 
ou via un **bon de commande vierge**

#### 🛠️ Une solution pensée pour vous

### 🔢 Une numérotation personnalisée

Dans vos **paramètres > Mes documents**, une nouvelle section **Bon de commande** vous permet de gérer votre **numérotation**. Par défaut, elle commence par **BC-année-00001**, mais vous pouvez tout personnaliser.

### 🧱 Le **Builder** des bons de commande

Il fonctionne comme ceux des devis, avec différentes sections claires :

#### 1. 🧾 **Le haut de page (header)**

Vous y renseignez :

- 
le **numéro** du bon de commande
- 
la **date** de création
- 
une **date de livraison souhaitée**
- 
le **fournisseur** , à choisir dans votre liste ou à créer rapidement

#### 2. 📋 **Le tableau des éléments**

Ajoutez vos éléments en cliquant sur **Fournitures**, **Matériel** ou **Divers** :

- 
ligne numérotée
- 
désignation
- 
référence fournisseur
- 
quantité
- 
unité

Vous pouvez :

- 
déplacer les lignes
- 
supprimer, dupliquer ou insérer une ligne
- 
ajouter des sections, du texte, ou des sauts de page

#### 3. 🚚 **Adresse de livraison**

Dans la section Livraison, vous pouvez sélectionner l’adresse de livraison. Par défaut, un menu déroulant vous propose :

- 
Votre adresse : qui est l’adresse de l’artisan
- 
Autre adresse : qui permettra de définir une adresse manuellement

#### 4. 🗒️ **Notes complémentaires**

Un champ libre pour ajouter des informations spécifiques à la commande.

#### 5. 📚 **Accès à la bibliothèque** (en version 2)

Retrouvez vos éléments dans la **bibliothèque OBAT**, y compris les anciens devis, factures, et désormais... vos **bons de commande précédents**. Si vous créez un bon à partir d’un devis, vous pouvez réutiliser les éléments.

#### 6. ✅ **Enregistrement et finalisation**

Deux boutons :

- 
**Enregistrer** (le bon reste en brouillon)
- 
**Finaliser et envoyer** (par mail, téléchargement, impression…)

#### 📄 Créer un bon de commande : plusieurs chemins possibles

### 🧾 Depuis un **devis** 


Depuis les **listings de devis**, vous pouvez, quel que soit le **statut du devis**, créer un **bon de commande**. Cette action est possible directement depuis le **sidepanel** ou via le **menu contextuel**.

Vous avez la possibilité de générer un bon de commande **avec ou sans lien direct vers un fournisseur**. Lorsque vous cliquez sur le **menu déroulant** du bouton *Bon de commande*, la liste des **fournisseurs associés aux éléments** du document s’affiche.

Si vous sélectionnez un fournisseur, le bon de commande s’ouvre avec ce fournisseur déjà renseigné. Dans le cas contraire, le **champ fournisseur reste vide** à l’ouverture.

Par défaut, le bon de commande reprend **tous les éléments du document d’origine**, à savoir les **fournitures**, le **matériel**, les **éléments divers**, ainsi que les composants à l’intérieur des **ouvrages**.

Si vous choisissez de lier le bon de commande à un fournisseur précis, alors à l’ouverture, **seules les lignes correspondant à ce fournisseur** sont visibles. Les éléments qui ne sont pas associés au fournisseur sélectionné sont **supprimés automatiquement**.

### 🧑🔧 Depuis un **fournisseur**

Allez dans la fiche fournisseur pour :

- 
créer un bon vierge
- 
ou le générer à partir d’un **devis** existant(e)


#### 🗂️ Le listing des bons de commande

Un nouveau menu **Achat > Bons de commande** affiche tous vos documents :

- 
n° du bon
- 
statut
- 
fournisseur
- 
date de création
- 
date de livraison

Avec des options de **tri**, **filtre**, et un **Sidepanel** qui donne accès à tous les détails du document, son **historique** et les **documents liés**.

### 🔗 Liens visibles dans les devis, factures, et chantiers

Dans les fiches devis, facture et chantier, un **pictogramme “B”** indique les bons de commande liés :

- 
Couleur selon le statut
- 
Info-bulle avec numéro, date, statut
- 
Clic pour ouvrir le bon directement

Afin de **lier vos bons de commande** à vos **devis**, et **chantiers**, nous ajoutons, dans les **sidepanels**, une nouvelle section **Documents liés**. Vous y retrouvez désormais les **bons de commande associés** aux devis, en plus des autres documents déjà existants.

#### ✅ Ce que ça change pour vous

- 
Vous pouvez désormais créer facilement des **bons de commande** depuis vos**devis** ou**fournisseurs**
- 
Ces bons de commande contiennent uniquement : **désignation** ,**quantité** et**unité** (pas de prix)
- 
Tout est pensé pour vous faire **gagner du temps** et**centraliser vos documents**
