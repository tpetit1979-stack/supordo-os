# Gagnez du temps sur vos devis grâce à l'extension Google Chrome OBAT !

## Préparer un devis peut vite devenir une corvée : rechercher des produits, copier les informations, puis les saisir manuellement dans OBAT… Tout cela prend du temps et comporte des risques d’erreur. Mais une nouvelle solution arrive pour vous simplifier la vie !


### 🧩 Une extension Chrome pour automatiser la copie de fiches produits

OBAT met à votre disposition une **extension pour navigateur Chrome** qui vous permet de **copier automatiquement** les informations produits depuis les sites de vos fournisseurs (comme **Cedeo**, **ManoMano**, **Point P**, etc.).

Fini les allers-retours entre les sites et votre devis OBAT : **en un clic**, vous récupérez tout ce qu’il vous faut 👇

**⚠️Attention⚠️** **Veuillez désactiver toutes les extensions de blocage de publicités et de fenêtres pop-up sur le site OBAT avant d’utiliser l’extension.**

### 🔍 Comment ça fonctionne ?

**Détection automatique** : Lorsque vous naviguez sur un site fournisseur, l’extension détecte les **fiches produits** et affiche un bouton **“Copier la fiche”** directement sur la page.

**Extraction intelligente**: En un clic, toutes les

**informations utiles**(désignation, prix, description, référence, dimensions…) sont extraites automatiquement grâce à l’

**intelligence artificielle**d’OBAT.

**Panier temporaire** : Les produits copiés sont stockés dans un **panier accessible** depuis l’extension, avec un **compteur** et une **liste chronologique**.

**Import en un clic dans OBAT** : Depuis votre bibliothèque ou votre builder de devis/factures, vous pouvez **importer ces produits automatiquement**, sans rien ressaisir. Tous les champs sont **pré-remplis** ✅

| **Depuis l'éditeur de devis**  | **Depuis ajout élément dans la bibliothèque**   | 
|  |    | 


**⚠️A SAVOIR⚠️**

Lorsque vous êtes **dans l'éditeur de devis** ou que vous **ajoutez un élément à votre bibliothèque**, **la fenêtre de l’extension s’ouvre automatiquement dès qu’au moins un produit est disponible**. Si vous la fermez, **vous pouvez la rouvrir** à tout moment grâce au **bouton “Importer depuis l’extension”,** visible uniquement lorsqu’un produit est enregistré.

### 🧰 Exemple concret : Pierre, plombier

Pierre prépare un devis pour rénover une salle de bain. Il visite les sites de Cedeo, ManoMano et Point P pour trouver ses produits.

🔹 Il clique sur **“Copier”** sur chaque fiche produit : radiateur, robinetterie, carrelage…

🔹 L’extension enregistre tout automatiquement.

🔹 Dans OBAT, il retrouve ses **8 produits** directement intégrés. Il clique, les lignes se créent avec **désignations complètes, prix et références**.
