# Comment afficher les références des articles sur le devis?

**Etape par étape**

1. **Rendez-vous dans votre devis**
2. **Cliquez sur "Options" puis cocher la case "Voir références"**


**Une colonne "Référence" apparaît alors dans le corps du devis.**

**Attention! Il n'est pas encore possible de faire de recherche d'article par référence.**
