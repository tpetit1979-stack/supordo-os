# Affichage du numéro de Siret du professionnel

## La facture est un document détaillé des prestations et/ou marchandises vendues. Elle doit comporter des mentions obligatoires pour être valable, sous peine d'amende. Ces mentions sont différentes pour un client particulier ou professionnel.

Nous avons rendu l’affichage du champ Siret plus visible lors de la **création d’un client de type professionnel** (flèche rouge), de plus, sur la modification d’une fiche contact de type professionnel, si le Siret est absent, un avertissement indiquera à l'utilisateur que le **Siret est manquant** (flèche orange). N’oubliez pas de paramétrer **le numéro de TVA** (flèche verte) et **Siret** (flèche bleue).



- Lors de la création d’un devis ou d’une facture pour un client de type professionnel, nous avons prévu un **avertissement** dans le Builder de documents si pour le professionnel en question,  son numéro de Siret n’est pas complété (flèche rouge).
- Lors de la création d’un devis ou d’une facture, nous avons prévu que si le client est de type professionnel, l’option **“Afficher le SIREN** ” disponible dans les options du Builder, soit cochée par défaut (flèche rouge)
