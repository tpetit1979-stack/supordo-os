# Comment exporter les lignes de vos devis/factures ?

## Vous avez la possibilité d'exporter les lignes de votre devis au format Excel / CSV depuis votre éditeur de devis.

nous vous invitons à consulter la vidéo suivante pour découvrir comment exporter les lignes de votre devis 👇

VIDEO EN COURS DE CREATION


Pour **exporter les lignes de vos documents**, rendez vous sur **l'onglet option** de l'éditeur de devis / factures (flèche bleue), puis cliquez sur **exporter des lignes**, vous aurez le choix de les exporter au format CSV ou XLSX (flèches rouges).


**Vos obtiendrez un fichier Excel / Csv contant les lignes de votre devis dans vos téléchargements.**
