# Export comptable et comptes auxiliaires client sur Obat

## L'export comptable aussi appelé journal des ventes vous permet de récupérer les écritures comptables de toutes les factures validées éditées, pour les réintégrer ensuite dans le logiciel de votre expert comptable.



**Suivez l'avancement de vos paiements et choisissez parmi l'un des formats d'export pour récupérer votre fichier.**


En comptabilité, un **compte auxiliaire** représente une subdivision d’un compte général. En pratique, les comptes auxiliaires ne sont créés que pour les comptes tiers; il s’agit des comptes **401 Fournisseurs, 411 Clients ou 421 Salaires nets.**

**L’utilisation de comptes auxiliaires va permettre un meilleur suivi comptable des postes concernés.** 

### 1. Export comptable

- Pour réaliser votre Export comptable rendez vous de **le paramétrage de votre compte en haut à gauche, en cliquant sur le nom de votre entreprise** (flèche rouge), puis cliquez sur paramètre (flèche verte).



- Vous pourrez alors cliquer sur **comptabilité** (flèche rouge) .

- Puis choisissez votre **période d’export** (flèche bleue) .
- Vous aurez le choix d' exporter plusieurs types de documents (flèches vertes).**- Factures****- Devis****- Achats**



Vous aurez la possibilité de choisir plusieurs types de format pour votre export :

- **Liste au format CSV Un fichier CSV** (valeurs séparées par des virgules) est un type de fichier spécial qu'il est possible de créer ou de modifier dans Excel. Plutôt que de stocker les informations en colonnes, les fichiers CSV les stockent en les séparant par des points-virgules.
- **Liste au format XLSX** le fichier XLSX est le format ordinaire des fichiers enregistrés sans macros avec Microsoft Excel.

- **Archiver des documents PDF**

- **Archive PDF + Liste CSV**

- **Archive PDF + Liste XLSX**
- **Format FEC**

### 2. Comptes auxiliaires


- Cliquer sur **exporter les comptes auxiliaires,** Un fichier se télécharge dans votre ordinateur.
- Vous pourrez alors c**hoisir votre numérotation des comptes auxiliaires de vos anciens clients** , déjà créés sur OBAT (flèche verte).



- Après avoir modifié votre fichier vous pourrez cliquer sur **importer les comptes auxiliaires** (flèche rouge).
- **Sélectionner votre fichier d'export précédemment créé** (flèche verte) et cliquer sur ouvrir (flèche bleue).



- Pour commencer une nouvelle numérotation pour les nouveaux clients, cliquez sur **modifier la numérotation,** vous aurez le choix de commencer une**numérotation alphanumérique** (flèche rouge) ou une**numérotation numérique** **(flèche bleue).**
