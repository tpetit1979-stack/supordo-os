# Ajoutez facilement une TVA à 0 % sur vos factures de situation ou finales

## Vous pouvez désormais ajouter une ligne avec une TVA à 0 % sur vos factures de situation détaillées ou factures finales.


### 📌 Pourquoi cette amélioration ?

Jusqu’à présent, si vous réalisiez une **facture de situation** ou une **facture finale** liée à un devis, vous ne pouviez pas y insérer de ligne avec une **TVA à 0 %**. Cette option était **grisée** dans le menu déroulant des taux de TVA.

Résultat : impossible, par exemple, de facturer des travaux bénéficiant d’une exonération de TVA (chantier à l’étranger, auto-liquidation, etc.) sans contourner le système.

### 🔧 Ce qui change avec cette mise à jour

Désormais, la **TVA à 0 % est bien disponible** dans le menu de sélection des taux de TVA, **même sur les factures liées à un devis**. Vous pouvez l’utiliser **en toute simplicité**, comme sur une facture vierge.


### 🎯 Concrètement, quel est l’intérêt pour vous ?

- 
Vous respectez **plus facilement les cas d'exonération** ou de**TVA auto-liquidée** .
- 
Vous **gagnez du temps** : plus besoin de ruser pour insérer une ligne sans TVA.
- 
Vos **factures sont plus conformes** aux exigences de vos clients ou des donneurs d’ordre.
