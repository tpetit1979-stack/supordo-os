# Dupliquer le planning d'un chantier

## La solution consiste à dupliquer des plannings de chantier déjà définis vers d’autres chantiers (déjà configurés ou pas), évitant ainsi de devoir recréer intégralement chaque planning.

Pour copier un planning, cliquez sur les 3 petits points à côté du chantier que vous voulez dupliquer puis cliquez sur copier ( flèche rouge )
















Sélectionnez le chantier sur lequel vous voulez coller votre planification, puis cliquez sur **coller** (flèche rouge).

Il vous sera demandé de définir

**la date de début et le nombre total de jours assignés.**
Votre chantier remontera automatiquement dans la planification ainsi que toute sa structure (flèches rouges).

- 
Vous pourrez également copier et coller la planification d’un chantier sur un chantier déjà planifié ,  **ATTENTION****cette manipulation vous demandera d’écraser la planification existante** ( un message vous sera alors adressé )

**Attention :** **Il impossible de copier un planning et de le coller de nouveau sur le même chantier**
