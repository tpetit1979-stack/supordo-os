# Le Chat OBAT : communiquez efficacement depuis votre application

## Grâce au Chat OBAT, les utilisateurs peuvent désormais échanger directement dans l'application. Les conversations de chantiers facilitent les échanges entre ouvriers et encadrants, améliorent la coordination, et réduisent les oublis ou doublons.



#### 📌 Un Chat pensé pour les pros du bâtiment

Avec le **Chat OBAT**, vous pouvez **communiquer facilement avec votre équipe** sans quitter votre espace de travail. Que ce soit pour un message rapide à un ouvrier ou une discussion complète autour d’un chantier, tout est prévu.

### 🛠️ Accès au Chat

Le **Chat OBAT** est disponible sur **ordinateur et mobile** :

- 
**Depuis la barre de menu** : un nouvel icône donne accès au chat et indique le nombre de messages non lus.
- 
**Depuis le widget Chantiers** du tableau de bord : accès direct à la conversation d’un chantier.
- 
**Depuis le panneau latéral d’un chantier** : bouton “Messages” pour ouvrir ou créer une conversation liée au chantier.

💡 Si un ouvrier fait partie d’un chantier, il verra automatiquement le bouton d’accès, sans qu’on ait à l’inviter manuellement.

### 👷 Conversations de type Chantiers

#### 🏗️ Création automatique

Les chantiers dont la **date de début est proche (moins de 3 mois)** ou non planifiés auront **automatiquement une conversation pré-créée**.

Sinon, la conversation se crée :

- 
via le bouton “Messages” sur le chantier
- 
via l’icône Chat dans le widget du tableau de bord

#### 👥 Participants par défaut :

- 
Propriétaire
- 
Administrateurs
- 
Chefs de chantier
- 
Ouvriers assignés au chantier

#### ➕ Créer une conversation manuellement

- 
Cliquez sur le **“+”** dans l’interface du Chat
- 
Choisissez l’onglet **“Chantier”**
- 
Sélectionnez le chantier concerné

🔍 Une barre de recherche permet de retrouver facilement un chantier existant. Si une conversation existe déjà, elle est indiquée avec un **tag “conversation existante”**.

📛 Nom de la conversation : **{Nom du client} - {Nom du chantier}**

🔐 Seuls les **propriétaires**, **administrateurs** et **chefs de chantier** peuvent créer une conversation de chantier.

Les **experts-comptables** et **ouvriers** ne voient pas cette option.




Retrouvez alors la conversation de ce chantier dans la liste des conversations

### 🔒 Conversations de type Privées

#### 💬 Conversation 1 à 1

- 
Cliquez sur **“+”** , puis**“Privée”**


- 
Sélectionnez un ou plusieurs utilisateurs du compte

- 
Tous les rôles peuvent créer ce type de conversation

📛 Le nom affiché dépend de l’utilisateur (ex. : Hervé verra “Charles”, Charles verra “Hervé”).

#### 💼 Conversation avec un expert-comptable

- 
Seuls les **propriétaires** et**administrateurs** peuvent initier une conversation avec l’expert-comptable
- 
L’expert-comptable ne peut écrire qu’à eux en retour



### 👁️ Vue globale de l’interface du Chat

Une interface simple et claire, aussi bien sur ordinateur que sur mobile. Chaque conversation est visible dans une **liste organisée**.
