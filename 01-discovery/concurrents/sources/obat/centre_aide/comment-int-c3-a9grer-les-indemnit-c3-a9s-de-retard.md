# comment intégrer les indemnités de retard ?

### Les indemnités de retard concernent vos clients professionnels. Cette mention est obligatoire sur vos devis mais vous pouvez la personnaliser.


Nous vous invitons à visionner la vidéo suivante pour découvrir comment passer votre devis en "autoliquidation" :



**Etape par étape :**

1. **Rendez vous dans un nouveau devis**
2. **Vous allez ensuite créer un nouveau client en cliquant sur l'encadré "Sélectionner un client" puis "Nouveau client"**


3.  **Cliquez sur l'onglet "Professionnel", renseignez les coordonnées puis       "Enregistrer"**


**Votre mention d'indemnités légale figurera automatiquement sur votre devis**


**Cette mention est obligatoire, toutefois vous aurez la possibilité de la modifier** 

**Etape par étape :**

1. **Rendez vous dans "Mon compte" puis "Paramètre"**
2. **Cliquez ensuite sur "Mes documents" puis le menu "Devis"**
3. **Modifiez votre mention et cliquez sur "Enregistrer"**
