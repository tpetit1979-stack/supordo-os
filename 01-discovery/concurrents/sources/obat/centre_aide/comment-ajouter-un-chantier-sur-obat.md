# Comment ajouter un chantier sur Obat ?

## Ajouter un chantier lors de la création de vos documents vous permet de centraliser tout les documents importants liés à vos chantiers, dans l'onglet chantier de la page d'accueil d'Obat.

Nous vous invitons à consulter la vidéo suivante pour découvrir comment ajouter un chantier sur vos devis 👇

**Etape par étape**

1. **Rendez-vous dans un nouveau devis.**
2. **Dirigez vous vers l'encadré "Sélectionner un chantier" puis "Nouveau chantier".**
3. **Renseignez ensuite votre chantier puis "Enregistrer".**
4. **Cliquez ensuite sur "ajouter une description" pour faire apparaitre le nom du chantier sur votre le devis.**



**Vous pourrez enregistrer une autre adresse ci celle de votre chantier est différente de l'adresse de facturation de votre client**
