# Comment s'abonner à Batichiffrage sur Obat?

## Depuis 1995, BatiChiffrage© est le spécialiste des outils de chiffrage de travaux et des bibliothèques de prix pour tous les métiers du bâtiment. Vous retrouverez cette bibliothèque directement dans votre éditeur de devis Obat.

Nous vous invitons à consulter la vidéo suivante pour découvrir comment vous abonner à Batichiffrage sur Obat 👇

VIDEO EN COURS DE CREATION


**Etape par étape :**

- Rendez-vous sur votre tableau de bord dans le menu **"Bibliothèque"** (flèche rouge).
- Dirigez vous ensuite vers la droite et cliquez sur **"S'abonner à Batichiffrage"** (flèche verte).

- **Choisissez ensuite la ou les familles d'ouvrages qui correspondent à votre activité.**

| **Mensuel** | **Annuel** | 
| 12€/mois pour une bibliothèque | 120€/an pour une bibliothèque | 
| 36€/mois pour 5 bibliothèques | 360€/an pour 5 bibliothèques |
