# Comment utiliser l'éditeur de style ?

### Vous pouvez utiliser l'éditeur de style pour personnaliser les lignes de votre document.


**Etape par étape :**

1. **Ajoutez une ligne de fourniture / main d'oeuvre / ouvrage dans votre devis ou votre facture.**
2. **Écrivez votre désignation.**
3. **Sélectionnez votre texte.**
4. **Cliquez sur le T en bout de ligne pour faire apparaitre l'éditeur de style.**




**Vous pourrez ensuite :**

- **Mettre en gras, italique ou souligné**
- **Effacer la mise en forme**
- **Modifier la taille du texte**
- **Choisir la couleur du fond ou de la police**
- **Créer une liste à puce**
- **Créer une liste numérotée**
- **Définir l'alignement du texte**
