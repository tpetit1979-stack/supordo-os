# Comment créer un raccourcis OBAT sur le bureau / écran d'accueil depuis google chrome ?

## Cette manipulation vous permettra d'accéder rapidement à votre compte Obat sans avoir à ouvrir à chaque fois, votre navigateur google chrome.


- Pour créer **un raccourcis sur votre écran d' accueil de votre ordinateur / téléphone / tablette** , depuis la page **google chrome** , cliquez sur l'icône en haut à droite de votre écran (flèche rouge) puis cliquez sur**Enregistrer la page sous** (flèche bleue)👇

- Sélectionnez votre **bureau** ( flèche rouge ) puis le **nom de votre raccourcis 👇**

- Un **raccourci** sera dès lors créé sur votre **écran d'accueil** ( flèche rouge)👇
