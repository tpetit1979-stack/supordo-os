# Comment facturer un acompte depuis un devis sur Obat ?

## Lorsque vous prévoyez un acompte sur votre devis, la facture d'acompte sera générée automatiquement lors de la facturation.

Nous vous invitons à consulter la vidéo suivante pour découvrir comment facturer un acompte depuis un devis 👇


**Etape par étape :**

- **Rendez vous sur votre devis à éditer**
- Dans la section **"condition de paiement"** , cliquez sur**"Ajouter une condition"** puis**"Ajouter un acompte".**
- Choisissez **le montant de l'acompte en %, € HT ou € TTC** ainsi que les**conditions de règlement de l'acompte.**
- **Enregistrez**




**Vous pouvez prédéfinir un acompte qui apparaitra automatiquement dans tous vos devis depuis les paramètres de votre compte : Mon compte > Paramètres > Mes documents > Paiement**

### **Une fois votre devis finalisé, vous allez pouvoir le facturer :**


**Etape par étape :**

- Pour **facturer un acompte sur un devis** , rendez vous sur l'**onglet devis** (flèche rouge).
- Cliquez sur **facturer** puis sur l **acompte qui aura été paramétrer dans le devis** (flèches bleues).

- Si votre devis n'a pas encore été signé, cliquez sur **"signer et facturer"** 
- La facture d'acompte est alors **générée automatiquement.** 


**Vous pouvez encore ajouter une description ou des notes de bas de pages si besoin.**

-  Vous pouvez maintenant la **finaliser / l'imprimer / la télécharger / l'envoyer.**

**Attention⚠️ Pour facturer un devis, celui-ci doit être signé. Vous ne pourrez alors plus le modifier ni le supprimer.**
