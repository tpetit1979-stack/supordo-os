# L’achat de packs de licences utilisateurs sur OBAT

## Vous travaillez avec plusieurs collaborateurs dans votre entreprise ? Jusqu’à présent, pour les inviter à utiliser OBAT, vous deviez faire un paiement par utilisateur. Cela signifiait autant de transactions, de clics, et de factures que de membres dans votre équipe. Avec la nouvelle mise à jour, c’est de l’histoire ancienne !


### 🛠️ **Ce qui change concrètement**

Désormais, vous pouvez **acheter plusieurs licences d’un coup**, en **un seul paiement**. Que vous choisissiez une formule **mensuelle** ou **annuelle**, tout est plus simple :

- 
Vous sélectionnez le **nombre de licences** souhaitées
- 
Vous payez **en une seule fois**
- 
Vous **attribuez les licences** plus tard, selon votre besoin

💡 Parfait si vous gérez une équipe de plusieurs personnes (ex : chefs de chantier, ouvriers, commerciaux…).

### 👨👩👧👦 Une nouvelle interface claire et intuitive

La page **Utilisateurs** a été **entièrement repensée** :

- 
Une présentation claire des **4 rôles disponibles** sur OBAT :**Commercial** ,**Chef de chantier** ,**Ouvrier** ,**Administrateur**


- 
Une **modale explicative** pour chaque rôle 💬

- 
La possibilité de **lancer un essai gratuit de 15 jours** pour tester le mode multi-utilisateur

Vous visualisez en un coup d'œil :

- 
Les **licences disponibles**
- 
Les **licences déjà achetées**
- 
Les **licences Assistant Devis Vocal** , si vous les utilisez

👉Possibilité d**’acheter un pack** de licences mensuelles OU annuelles en **un seul paiement**

👉en cas d’erreur de paiement

👉Confirmation avec redirection vers l’invitation d’utilisateurs

### 🧾 Une **gestion simplifiée**

Finies les **factures multiples** et les **opérations répétitives** : avec cette nouvelle fonctionnalité, vous gagnez en **efficacité**, en **visibilité** et en **sérénité** dans votre gestion quotidienne.

De plus, l'achat s'effectue via **Stripe** si votre **carte bancaire est enregistrée** — un processus rapide et sécurisé. 🔐

### 📲 Quand utiliser cette fonctionnalité ?

Voici les différents boutons qui apparaissent selon votre situation :

- 
**"Découvrir le multi-utilisateur"** : si vous n’avez jamais utilisé cette fonction
- 
**"Démarrer mon essai gratuit"** : pour activer 15 jours d’essai
- 
**"Acheter des licences"** : toujours disponible si vous avez fini l’essai ou déjà acheté une licence
- 
**"Inviter des utilisateurs"** : si vous avez des licences disponibles
- 
**"Je souhaite être rappelé"** : si vous n’avez ni licence ni utilisateur actif
- 
**"Inviter mon expert-comptable"** : s’il n’est pas encore rattaché à votre compte


### 📈 Quels bénéfices pour vous ?

- 
**Gain de temps** ⏱️ : un seul paiement au lieu de plusieurs
- 
**Moins de paperasse** 📄 : une seule facture
- 
**Plus de flexibilité** : invitez vos collaborateurs quand vous le souhaitez
- 
**Parcours utilisateur amélioré** : interface moderne, plus fluide
