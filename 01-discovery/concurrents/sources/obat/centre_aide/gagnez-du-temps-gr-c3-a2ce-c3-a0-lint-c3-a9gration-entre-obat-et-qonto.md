# Gagnez du temps grâce à l'intégration entre OBAT et Qonto !

## Vous utilisez Qonto pour gérer votre compte professionnel ? Grâce à la nouvelle intégration directe entre OBAT et Qonto, vous simplifiez dès aujourd’hui le suivi de vos opérations bancaires et la gestion de votre comptabilité.

Pour tous les artisans du bâtiment qui utilisent OBAT et Qonto : une connexion directe entre les deux outils est désormais disponible pour vous faire gagner du temps et simplifier votre gestion quotidienne 📲💼."

### ✅ Étape 1 : **Connexion à Qonto**

Rendez-vous dans l’onglet **Paramètres > Banques**. Si aucun compte n’est encore connecté, 3 options s’affichent :

- 
**Qonto** : ✅ nouvelle option directe
- 
**Autre banque** : via Bridge (ancienne méthode)
- 
**IBAN manuel** : pour recevoir des virements (inchangé)

Un clic sur **"En savoir plus"** la carte Qonto affiche une fenêtre avec les avantages de cette connexion.


### 🔐 Étape 2 : **Authentification sécurisée**

En cliquant sur **"Connecter"**, vous êtes redirigé vers une **interface Qonto sécurisée**. L’autorisation se fait via le protocole **OAuth2**, garantissant une connexion **fiable et protégée**.

En cas d’erreur de synchronisation, un **message clair** s’affiche avec la possibilité de réessayer ou de contacter le support OBAT.

### 🔄 Étape 3 : **Gestion multi-comptes et doublons**

- 
Si plusieurs comptes Qonto sont détectés, vous choisissez ceux à connecter à OBAT.

- 
Une **modale de succès** s'affiche si la connexion est réussie.
- 
En cas de **doublon d’IBAN** (par exemple, un compte déjà connecté via Bridge), OBAT vous propose de**remplacer** l’ancien lien par la**nouvelle connexion directe** .

- 
Vous recevez une confirmation de réussite ou un message d’échec selon le résultat.

**💡A savoir💡**

Si des **rapprochements bancaires existent sur le compte Qonto connecté via Bridge, ils seront conservés** en cas de remplacement par la connexion bancaire directe depuis Qonto


### 👁️ Étape 4 : **Vue après connexion**

Une fois la connexion active, vous visualisez chaque compte Qonto synchronisé avec :

- 
le **logo Qonto**
- 
le **libellé du compte**
- 
l’ **IBAN**
- 
l’ **état de connexion** : connecté 🔸 ou déconnecté 🔴
- 
des options (menu "...") : **définir par défaut** ,**modifier**

Vous pouvez **ajouter un compte**, **supprimer** une connexion, ou **forcer la synchronisation** si nécessaire.(disponible dans une prochaine version)



### 📥 Étape 5 : **Synchronisation des justificatifs d’achats**

Qonto permet de **joindre un justificatif** juste après un achat. Ce document descend automatiquement dans OBAT en tant qu’**achat à saisir**.

Vous retrouvez ces achats avec :

- 
un **tag spécial Qonto**
- 
une **image du justificatif**

Le processus de saisie reste inchangé, mais il est désormais **plus rapide**, **plus fluide** et **sans risque d’erreur**.

### 🛜Etape 6 : Consultation bancaire

Vous pouvez désormais **connecter votre compte bancaire Qonto** directement depuis **Paramètres > Banques** dans votre logiciel OBAT. Une fois la connexion réussie, ce compte apparaît automatiquement dans la **liste de vos comptes bancaires connectés** 🏦.

En vous rendant dans l’onglet **Banques**, vous verrez une **nouvelle tuile** qui correspond à ce compte. À partir de là, vous pouvez :

- 
**Consulter facilement toutes les transactions** liées à ce compte 💳
- 
Si vous disposez du **pack Croissance** , vous avez aussi la possibilité d’**effectuer le rapprochement bancaire** de vos**factures d’achat** , directement à partir de ce compte 🧾✅

Sur votre **tableau de bord d’accueil**, si ce compte Qonto est **le seul connecté** et qu’il s’agit d’un **compte professionnel**, son **solde s’affiche automatiquement** dans le widget **Banque connectée** 📊.

💡 À noter : la **fonction de consultation bancaire reste inchangée**, seule la **source des données évolue**. Vous conservez ainsi vos habitudes de travail, avec encore plus de **fluidité** dans le suivi de votre trésorerie.
