# Créez des événements récurrents dans votre calendrier OBAT

## Bonne nouvelle pour tous les artisans qui gèrent leur emploi du temps depuis le calendrier OBAT : vous pouvez désormais créer des événements récurrents en quelques clics !

Grâce à cette nouveauté, vous pouvez maintenant **définir une récurrence** à la création ou à la modification d’un événement dans votre calendrier.

📌 Une fois la **récurrence sélectionnée**, l’événement s’affiche selon ce rythme.

🛠️ Tous les événements liés sont connectés entre eux. Si vous modifiez l’un d’eux, vous pouvez choisir d’appliquer le changement à **un seul événement** ou **à toute la série**.

#### **⚙️Accès au paramétrage de la récurrence**

Lors de la **création ou modification d’un événement**, vous accédez à une **fenêtre de paramétrage** où vous choisissez le type de récurrence souhaité.

#### **👀Différents types de récurrences**


| **Récurrence** | **Détails** | **Commentaire** | 
|---|---|---|
| **Une seule fois** | C’est le choix par défaut, équivaut à aucune récurrence |  | 
| **Tous les jours** |  | Y compris samedi/dimanche, pour toutes les semaines à venir | 
| **Toutes les semaines le {jour pour lequel l’utilisateur crée l'évènement}** |  | Ex : Je crée un event le jeudi, alors on me propose de le rendre récurrent tous les jeudis de chaque semaine | 
| **Tous les mois le {Xème} {jour pour lequel l’utilisateur crée l'évènement}** | X = on compte le nombre de fois où le jour pour lequel l’utilisateur crée l'évènement est déjà passé dans le mois | Ex : Je crée un event le 3e mercredi du mois, alors on me propose de le rendre récurrent tous les 3e mercredis de chaque mois | 
| **Tous les ans le {N°jour pour lequel l’utilisateur crée l'évènement} {Nom du mois pour lequel l’utilisateur crée l'évènement}** |  N° jour = 1, 2, 3 → 30, 31  Nom du mois = janvier, février → décembre | Ex : Je crée un event le 15 juin, alors on me propose de le rendre récurrent tous les 15 juin de chaque année | 
| **Tous les jours de la semaine (du lundi au vendredi)** |  | Ex : Je crée un event le mardi, alors on me propose de le rendre récurrent sur tous les jours de la semaine, pour toutes les semaines à venir | 
| **Personnaliser** | La modale suivante s’ouvre pour détailler la récurrence : L’affichage de cette modale dépend du dropdown Jour/semaine/mois/année :  Jour ou Année :   Semaine : (choix par défaut)  Permet à l’utilisateur de sélectionner uniquement que certains jours de la semaine  Mois : L’utilisateur a le choix entre :  “Tous les mois le {N° du jour sélectionné}”  “Tous les mois le {Xème} {nom du jour sélectionné}” | Exemple possible :  Je veux que mon évènement soit uniquement les mercredis et jeudis toutes les 2 semaines, et se termine au bout de 4 occurrences. | 


#### **📆Affichage de la récurrence sélectionnée**

Une fois votre récurrence enregistrée, elle s’affiche :

- 
dans le champ **« Récurrence »** de la fenêtre d’édition,
- 
dans la **fiche de l’événement** ,
- 
et bien sûr **dans le calendrier** .

Vous identifiez rapidement **les événements récurrents** à l’œil 👀.



### 🔄 **Synchronisation avec Google Agenda** 

Si vous utilisez aussi **Google Agenda**, pas de panique : vos **événements récurrents se synchronisent automatiquement** entre OBAT et Google si vous avez activé la synchronisation.


**Notifications push pour le calendrier**

En plus de l'e-mail déjà envoyé, les utilisateurs assignés à un chantier reçoivent désormais une notification push dès qu'une modification est enregistrée sur le calendrier via le bouton « Enregistrer et notifier les ressources ».

Chaque utilisateur peut activer ou désactiver ces notifications push depuis l'application mobile, dans **Paramètres > Notifications**.
