# Protégez vos données bancaires avec OBAT : la vérification par code email

## Chez OBAT, votre sécurité est notre priorité. Pour cela, nous mettons en place une nouvelle fonctionnalité qui permet de sécuriser toutes les actions sensibles liées à vos données bancaires grâce à l’envoi d’un code de vérification à 6 chiffres par email.

### 🛠️ Quelles actions sont sécurisées ?

Dès que vous réalisez une action critique, un **code temporaire** vous est demandé. Cela concerne notamment :

- 
l’ **ajout** , la**modification** ou la**suppression** d’un**compte connecté** (comme**Bridge** ou**Qonto** )
- 
l’ **ajout** , la**modification** ou la**suppression** d’un**IBAN** (utile pour recevoir vos paiements) ;
- 
la **modification de votre adresse email de connexion** à OBAT.

### ⚙️ Comment ça fonctionne ?

Le système est simple et automatique :

1. 
Dès qu’une de ces actions est déclenchée, **un code à 6 chiffres est envoyé à votre adresse email actuelle** .
2. 
Ce code est **valable 5 minutes** .
3. 
Vous devez le saisir dans une **interface dédiée** .
4. 
Vous avez **10 essais** , renouvelables toutes les**30 minutes** .
5. 
En cas d’erreur ou de dépassement de temps, **vous pouvez redemander un nouveau code** .

### 🔧 Comment activer cette sécurité ?

Bonne nouvelle : **aucune configuration n’est nécessaire** !

La sécurisation s’**active automatiquement** dès qu’une action sensible est détectée. 


*Fenêtre de saisie du code à 6 chiffres👇*


*Erreur en cas de code incorrect👇*



*Erreur en cas de code expiré👇*



*Erreur en cas de nombre de codes max envoyés👇*



### ✅ Ce que cela change pour vous

Avec ce système :

- 
Vos **données bancaires** sont**mieux protégées** 🛡️.
- 
Les **risques de fraude** sont fortement réduits 🚫.
- 
Vos **modifications importantes** sont mieux encadrées 📋.

### 💼 Exemples concrets

- 
Vous ajoutez un nouvel **IBAN** pour recevoir vos paiements ? Un**code de sécurité** est envoyé pour valider cette opération.
- 
Vous changez d’adresse email professionnelle ? Ce changement est **confirmé par un code** reçu sur l’ancien email.
- 
Vous supprimez un ancien compte bancaire connecté ? Là encore, **une validation est**
- 
 **exigée** .
