Le secteur du bâtiment regroupe une multitude de classes et sous-classes d’activités. Il n’y a donc pas un seul et unique **code NAF dans le bâtiment** : tout dépend des caractéristiques de votre activité. Alors, comment s’assurer que vous avez le bon **code APE** ? Est-il possible de le changer et quel impact sur votre activité et votre convention collective ? Découvrez notre guide complet sur les **codes NAF/APE dans le BTP** ces codes attribués au moment de la création de votre entreprise et qui définissent votre activité principale !

## Qu’est-ce que le code NAF ?

### Définition code NAF/code APE

Le **code NAF** (Nomenclature d’Activité Française) classe toutes les activités professionnelles grâce à l’attribution d’un code composé de 4 chiffres + 1 lettre. Ce qu’il faut savoir, c’est qu’il n’y a aucune différence entre le **code NAF** et le **code APE** : ce sont deux données identiques. Votre entreprise sera simplement identifiée par un classement. 

L’**INSEE** répertorie alors votre activité principale sous le terme code APE pour « Activité Principale exercée par l’Entreprise ». Entre NAF ou APE, les terminologies changent, mais le code est identique. Les documents officiels peuvent autant mentionner votre code APE que le code NAF pour les **métiers du bâtiment**.

### Attribution d’un code NAF bâtiment

Le **code NAF en BTP** est donc automatiquement attribué par l’INSEE (Institut national de la statistique et des études économiques) au moment de l’immatriculation de l’entreprise, démarche aussi connue sous le nom de **déclaration d’activité de l’entreprise**. 

Il n’y a aucune demande à faire de votre côté. Dès que vous avez finalisé les formalités de création de votre société, vous allez recevoir divers documents officiels pour officialiser cette procédure. Vous recevrez alors plusieurs **codes uniques** dont le numéro SIREN, numéro SIRET, numéro RCS, numéro de TVA et et bien sûr le code APE (ou NAF).

## Comment trouver son code APE bâtiment ?

Pour retrouver votre **code NAF en bâtiment**, vous pouvez lancer une recherche par mots-clés dans la NAF afin de trouver le code APE qui correspond le plus précisément à votre **activité dans le BTP**. 

Par exemple, si vous êtes artisan en terrassement, indiquez « terrassement » dans le moteur de recherche. Il est possible que l’on vous propose plusieurs codes, vous devez alors choisir celui qui **décrit avec le plus de précision votre activité.** Sachez que la [nomenclature NAF complète](https://www.insee.fr/fr/information/2406147) est disponible sur le site de l’INSEE.

## Quel intérêt de connaître mon code NAF BTP ?

### Conventions collectives

Votre **code NAF d’entreprise** n’impacte pas directement votre valeur juridique, mais il va déterminer votre **convention collective du BTP**. Il s’agit de toutes les règles particulières applicables aux salariés des entreprises adhérentes. 

Vous devez choisir la convention collective la plus adaptée à votre activité du bâtiment puisqu’il n’existe pas une convention unique pour les **métiers du BTP**. Vous avez le choix entre :

- la Convention collective nationale des ouvriers employés par les entreprises comptant moins de 10 salariés ;
- la Convention collective nationale des ouvriers employés par les entreprises comptant plus de 10 salariés ;
- la Convention collective nationale des employés, techniciens et agents de maîtrise du bâtiment ;
- la Convention collective nationale des cadres du bâtiment.

*A lire : [Convention collective du BTP : connaître vos droits en 2022](https://www.obat.fr/blog/convention-collective-btp/)*

### Appels d’offres

Le **code APE en bâtiment** possède aussi une valeur « commerciale ». Si vous participez à des appels d’offres, sachez que certains donneurs d’ordre présélectionnent les prestataires candidats en se basant sur le **code NAF d’entreprise**. Si votre code APE ne correspond pas directement à l’activité exigée dans l’appel d’offres, vous pouvez donc être écarté du marché.

## Comment changer mon code NAF ?

Si vous avez besoin de changer de **code NAF d’entreprise**, on distingue deux cas de figure :

- **Votre activité principale a changé** : si vous n’exercez plus la même activité professionnelle qu’au moment de l’immatriculation de votre société, adressez-vous à votre Centre de Formalités des Entreprises (CFE). Vous pourrez leur signaler ce changement pour obtenir une modification de la part de votre RCS.
- **Le code APE est erroné** : si le code NAF BTP qui vous a été attribué au moment de votre inscription n’est pas le bon, vous êtes dans l’obligation de signaler cette erreur à la direction régionale de l’INSEE. Pour cela, envoyez un courrier ou un mail avec en pièce jointe[formulaire de demande de changement de code APE](https://www.economie.gouv.fr/files/2021-01/Demandemodificationcodeactiviteentreprise.pdf) .

Il n’y a donc aucune différence entre le **code NAF BTP** et le **code APE bâtiment** : il s’agit d’un code identique qui identifie votre secteur d’activité principal. Il est toutefois important de vérifier que le code attribué est le bon puisqu’il impacte votre convention collective et vos chances de décrocher des marchés en appel d’offres !
