# Les documents privés

Il est possible de "privatiser" un devis ou une facture, pour éviter qu'il ne soit consulté, modifié, supprimé ou facturé par un autre utilisateur.

Un document privé est réservé :

- A l'utilisateur qui a créé le document,
- Au chargé d'affaire affecté au document,
- Aux Administrateurs du compte
- Et à tout utilisateur [ayant les droits sur les documents privés](https://docv5.progbat.com/pour-bien-demarrer/parametrage/utilisateurs/gestion-des-droits-dacces) .

## Public ou privé

### Statut public/privé par défaut

Pour que tous vos devis et factures soient par défaut publics ou privés, activez les options dans vos paramètres d'utilisation.

### Statut public/privé d'un document

Pour changer le statut d'un devis ou d'une facture en public ou privé, ouvrez le menu d'action, et activer ou désactivez "Le document est privé".

## Héritage

Lorsque l'on crée un document à partir d'un autre document, le nouveau document sera privé si :

- Le document source est privé
- et/ou vous avez activé par défaut que ce type de document est privé.

### Par exemple :

si un devis est privé, tous les documents associés à ce devis seront privés, quel que soit [statut public/privé par défaut](https://docv5.progbat.com/presentation-generale/les-documents-prives#statut-public-prive-par-defaut)

- Révisions du devis, Avenants,
- Acomptes, factures, situations, avoir, ...

Mais si le devis est public, et que le [statut public/privé par défaut](https://docv5.progbat.com/presentation-generale/les-documents-prives#statut-public-prive-par-defaut) est privé, alors les documents suivants seront privés.
