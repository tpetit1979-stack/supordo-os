# Comptes financiers

Saisissez le compte comptable correspondant à chacun de vos comptes bancaires ou caisse.

##  💡 Vous pourrez paramétrer une extension du compte banque, en fonction du mode de paiement.

- Définissez par exemple 5120 pour le compte banque
- Définissez par exemple 10 pour le paiement par chèque ( [paramétrage moyen de paiement](https://docv5.progbat.com/le-menu-principal/comptabilite/parametrage-comptable/moyens-de-paiement) )
- Le compte utilisé pour un encaissement par chèque sera 512010.
