# Gestion des ouvrages

## Gérer les ouvrages depuis les devis

➡️ Gérer votre bibliothèque d'ouvrages, en même temps que vous réalisez vos devis = Gain de temps considérable !

### Créer un ouvrage

- Ajoutez une ligne d'ouvrage dans votre devis, et saisissez : 
  - La désignation,
  - L'unité,
  - et si vous le connaissez, le prix de vente. 
    - La composition de l'ouvrage sera disponible immédiatement après l'enregistrement.
- Cliquez sur la petite disquette dans le menu de ligne.

- Saisissez un identifiant pour retrouver facilement cet ouvrage pour un autre devis. 
  - Pour l'exemple, nous avons saisi "MON OUVRAGE", il faudra trouver plus explicite pour les vôtres 😉.
- Créez l'ouvrage. Il est maintenant enregistré dans votre bibliothèque d'ouvrages, prêt à être intégré dans un autre devis.

### Composition de l'ouvrage

➡️ Il est recommandé de lire l'article sur [les ouvrages composés](https://docv5.progbat.com/le-menu-principal/bibliotheque/ouvrages/les-ouvrages-composes).

L'ouvrage est créé, vous pouvez maintenant ouvrir sa composition :

- Pour réaliser un chiffrage "Avancé". Le formulaire s'ouvre par défaut sur cette configuration.
- Pour réaliser un chiffrage "Expert".

### Mise à jour de l'ouvrage

Vous avez apporté des modifications à votre ouvrage, ou mis à jour sa composition, et souhaitez enregistrer ces modifications dans votre bibliothèque ?

#### ➡️ Mise à jour de l'ouvrage existant

- Cliquez sur la petite disquette dans le menu de ligne, comme pour la [création de l'ouvrage](https://docv5.progbat.com/le-menu-principal/bibliotheque/ouvrages/gestion-des-ouvrages#creer-un-ouvrage) .
- Vous pouvez modifier l'identifiant si vous le souhaitez.
- Cliquez sur "Mettre à jour l'ouvrage".

#### ➡️ Créer un nouvel ouvrage à partir de celui-ci.

Une méthode très efficace d'enrichir votre bibliothèque est de créer un ouvrage à partir d'un ouvrage similaire.

- Ajoutez dans votre devis un ouvrage similaire à celui que vous souhaitez chiffrer
- Apportez les modifications (désignation, composition).
- Cliquez sur la petite disquette dans le menu de ligne, comme pour la [création de l'ouvrage](https://docv5.progbat.com/le-menu-principal/bibliotheque/ouvrages/gestion-des-ouvrages#creer-un-ouvrage) .
- Cliquez sur "Créer un nouvel ouvrage". 
  - Un nouvel identifiant vous sera demandé avant de valider.

Votre bibliothèque compte désormais un ouvrage supplémentaire.

## Gérer les ouvrages depuis la bibliothèque d'ouvrages

➡️ Gérer votre bibliothèque d'ouvrages depuis la bibliothèque permet de saisir des informations complémentaires, d'ajouter de la documentation dans la ProGBox, ou encore de retrouver dans quels devis ou quelles factures cet ouvrage a été utilisé.

### Créer un ouvrage

- Ouvrez la liste des ouvrages depuis le menu "Bibliothèque ➡️ Ouvrages".
- Cliquez sur le bouton vert "Nouvel ouvrage".

### Modifier un ouvrage

- Ouvrez la liste des ouvrages depuis le menu "Bibliothèque ➡️ Ouvrages".
- Recherchez l'ouvrage à modifier, et sélectionnez le dans la liste pour ouvrir le formulaire.

### La fiche ouvrage

#### ▶️ Actif / inactif

Un ouvrage utilisé dans un devis ou une facture ne peut plus être supprimé.

Si vous n'utilisez plus cet ouvrage, désactivez-le, pour qu'il ne soit plus proposé dans vos devis.

💡 Dans la liste des ouvrages, activez le filtre "Actif" pour n'afficher que les ouvrages utilisés.

#### ▶️ Contrôlé

Un ouvrage peut être en cours de création ou de mise à jour, et ne pas être encore utilisable dans un devis.

En activant l'option "Contrôlé" une fois terminé, un tag apparaît lorsque l'ouvrage est recherché dans un devis, confirmant qu'il peut être utilisé en toute confiance.

#### ▶️ Identifiant

Quelques mots pour retrouver facilement l'ouvrage.

#### ▶️ Libellé

C'est le texte qui s'affichera dans vos devis et factures. Vous pouvez le mettre en forme grâce à l'éditeur de texte intégré.

#### ▶️ Déboursé

Si vous connaissez le prix de revient de votre ouvrage, et/ou que vous ne composez pas vos ouvrages, saisissez-le, le prix de vente sera automatiquement calculé en fonction de la marge.

#### ▶️ Marge

Par défaut, la marge appliquée est celle [définie dans vos paramètres](https://docv5.progbat.com/pour-bien-demarrer/parametrage/parametres-de-lentreprise/marges).

Vous pouvez modifier la marge de l'ouvrage pour ajuster son prix de vente par rapport à son déboursé.

#### ▶️ Prix de vente

C'est le prix qui sera proposé dans votre devis :

- Si vous n'avez pas renseigné de déboursé, saisissez directement le prix de vente, le déboursé sera calculé automatiquement en fonction de la marge.
- Si vous avez saisi un déboursé, la marge se mettra à jour en fonction du prix de vente que vous allez saisir.

#### ▶️ Prix fixe

En activant l'option, le logiciel ne mettra pas à jour le prix de vente même si vous mettez à jour vos prix d'achat, vos marges, ou si vous appliquez un coefficient dans un devis.

### Composition de l'ouvrage

➡️ Il est recommandé de lire l'article sur [les ouvrages composés](https://docv5.progbat.com/le-menu-principal/bibliotheque/ouvrages/les-ouvrages-composes).

L'ouvrage est créé, vous pouvez maintenant ouvrir sa composition pour réaliser un chiffrage "Expert".

### Activité

Cet onglet vous permet de voir dans quels devis et factures cet ouvrage a été utilisé.

### ProGBox

La [ProGBox](https://docv5.progbat.com/presentation-generale/progbox-archivage-de-documents) de l'ouvrage permet de stocker de la documentation technique, des images, et tout document relatif à cet ouvrage.
